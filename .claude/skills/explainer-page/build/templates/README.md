# templates

Files to copy into a new page's `src/` (scripts and `01_head.html` into `src/parts/`, `build.sh` into `src/`). How they fit together is in [../scaffold.md](../scaffold.md).

| File | Goes to | What it is | What to change |
|---|---|---|---|
| `build.sh` | `src/build.sh` | The fail-safe build: head, header, Reading parts, tab parts, the `#jsErr` box, one `<script>` per JS part, tabs last; expands `{{text\|n:<id>}}` and `{{text\|#t-tab}}`; warns on unexpanded links and em-dashes; prints the size. | Nothing for the standard layout. Uncomment the `tex2mathml` line for a page with LaTeX. |
| `01_head.html` | `src/parts/` | Doctype, viewport, `<title>`, the theme CSS and the opening `<div class="w">`. The theme: tinted page with `--card` cards on a soft shadow, serif headings with a real scale, 16 px body with prose capped at 46em, pill buttons and segments with a filled `.an-play`, tinted callouts and step captions (`.an-cap`), the step-control row (`.an-ctl`), photo figures (`figure.ph`, in the right column of the split), the eased-step classes (`rd-new`, `rd-gone`, `rd-fade`), colour tokens for light and dark, stats, tables, bars, tabs, the 520 px rules. Restyle `.an-cap` and `.an-ctl` in a page only when it needs to; their base look is here. Built pages carry their own copy of the look (older ones as a marked `kb-look` style block); there is no rerun tool, so to change the look on every page, edit this file and each page's look block deliberately (write the block into each page's source part and its built page rather than rebuilding every page, then compare with HEAD). It ends with the AI buddy loader ([../scaffold.md](../scaffold.md), AI buddy); never edit it here. | Replace `PAGE_TITLE` with the exact Notion title. Add page-wide classes here; tab-specific CSS goes in the tab's own part, scoped under its id. |
| `02_split.html` | `src/parts/` | The split layout: `.s3sp` two columns at 1100 px and wider, `.s3L` text, `.s3R` visual (sticky), `.s3side` for a figure card, `.stg` for a stage, `ol.sx` step lists, `.s3chips` chooser buttons, `.s3q .s3k .s3v` query, key and value colours, `.s3stick` for a compact 2D animation that stays in view on a phone. Use: [../../visuals/mechanics.md](../../visuals/mechanics.md). | Nothing. |
| `25_js_s3.js` | `src/parts/` | `window.S3` (v2): the 3D renderer on Canvas 2D (boxes with contact shadows, glass plates, flowing dots, fading floor, upright labels) and `S3.stage` (controls, step list, autoplay on view, camera views per step, drag to turn). Use: [../../visuals/three-d.md](../../visuals/three-d.md). | Nothing. |
| `05z_errbox.js.html` | `src/parts/` | The global error handler that shows any script error in the hidden `#jsErr` box (the box itself is emitted by `build.sh`). | Nothing. |
| `10_js_common.js` | `src/parts/` (optional) | Older shared helpers from the Topic: llm-landscape pages: `TAB_RENDER` hook `onTab`, number and byte formatting, seeded random `mulberry32`, SVG boxes and arrows, a log-log frame, end labels pushed apart. | Use when the page needs these; it defines globals (`$`, `fmt`), so a page with many tab agents usually prefers each tab's own namespaced core file. |
| `21_js_rd_common.js` | `src/parts/` | `window.RD`: the step-animation controller `RD.anim` (play, pause, step back and forward, scrubber, speed; plays by itself once in view, pauses off screen, stops for good on a reader control or the last step, never under reduced motion; marks the card `rd-fwd` on a forward step so `rd-new` marks ease in and the caption fades), `RD.width` (measured width), `RD.onRender`, `RD.onResize`, `RD.svg`, `RD.t`, `RD.seg`, `RD.tabLinks` for links in script-written HTML, and the section-nav highlight. | Nothing. Tab agents may copy it into their own `3x_js_<p>_1core.js` under their own namespace. |
| `99_js_tabs.js` | `src/parts/` | Tab wiring (links may carry `data-to="<element id>"` to scroll to it after switching): `aria-selected`, hides other tabs, runs `TAB_RENDER[id]` when a tab opens, arrow keys, `data-tab` links, remembers the last tab in `localStorage` inside try/catch. | Replace `STORAGE_KEY` with the page prefix plus `-tab` (for example `gm-tab`). |

Not templated (write per page, shapes in [../scaffold.md](../scaffold.md)): `10_header.html` (h1, subtitle, tab bar), `20_read_a.html` ... `20_read_z.html`, `3x_tab_<name>_a.html` ..., `39_tab_more.html`.
