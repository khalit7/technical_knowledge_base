# 2026-08-24: founding build

The knowledge base was created and populated breadth-first in one session: 21 topics (138 files), 31 papers (PDF + summary each), the tracker, and the four maintenance skills. Every topic from the GDM preparation document (Appendices 2-9) was folded into the relevant deep dives. This entry doubles as a "start here" guide: the must-read-first resources each topic's research surfaced.

### Must-read-first, by topic

- **llms**: Raschka's Big LLM Architecture Comparison + llm-architecture-gallery; the DeepSeek-V3 and R1 papers (both in Papers); Artificial Analysis for the live frontier; Interconnects (Nathan Lambert) to stay current.
- **llm-training-and-post-training**: HuggingFace Ultra-Scale Playbook; the RLHF Book ([rlhfbook.com](http://rlhfbook.com/)); LoRA Without Regret (Thinking Machines); Anthropic's emergent misalignment from reward hacking; Aman Arora's RoPE context-extension walkthrough.
- **ml-fundamentals**: Karpathy's Recipe for Training Neural Networks; Ruder's gradient descent overview; Lilian Weng on contrastive learning; colah's LSTM post; Keller Jordan's Muon post.
- **rl**: David Silver's UCL course; Sutton & Barto 2nd ed; RLHF Book; The 37 Implementation Details of PPO; a GRPO derivation + verl's rollout-correction docs.
- **benchmarks**: The Leaderboard Illusion; Berkeley RDI on gaming agent benchmarks; Epoch AI Benchmarking Hub; FutureHouse's HLE errata; Anthropic's Adding Error Bars to Evals.
- **evaluation-and-llm-judges**: Hamel Husain's LLM-as-judge guide; Adding Error Bars to Evals; JudgeBench; the null-model benchmark-cheating paper; Inspect docs + its [CONTRIBUTING.md](http://contributing.md/) (the contribution on-ramp).
- **cuda-and-gpu-programming**: PMPP 5th edition; GPU MODE lectures; Simon Boehm's CUDA matmul post; Horace He's Making Deep Learning Go Brrrr; official Triton tutorials.
- **inference-and-serving**: kipply's Transformer Inference Arithmetic; the PagedAttention paper (in Papers); Anyscale's continuous-batching explainer; the vLLM V1 blog post; NVIDIA's Dynamo post + DistServe.
- **pytorch-ecosystem**: torch.compile "the missing manual"; the Dynamo deep-dive docs; torchtitan; the FlexAttention blog post; the torchtune-future GitHub issue.
- **jax-and-tpu**: DeepMind's How to Scale Your Model; JAX official tutorials; Flax NNX basics; MaxText source; apply to TPU Research Cloud early.
- **hardware**: How to Scale Your Model; Horace He again; kipply + EleutherAI's Transformer Math 101; Modal's GPU Glossary; SemiAnalysis.
- **generative-and-multimodal**: Lilian Weng on diffusion; Meta's Flow Matching guide; Raschka's Understanding Multimodal LLMs; the Moshi paper; HF's VLM landscape post.
- **rag-and-retrieval**: Anthropic's Contextual Retrieval; LightOn's retrieval-in-the-agent-era post; LazyGraphRAG; the long-context-vs-RAG evaluation (2501.01880); RAGAS docs.
- **data-curation-and-datasets**: the FineWeb blogpost; the DCLM paper; Nemotron-CC; the CMR scaling law paper; Tulu 3.
- **ml-infra-and-orchestration**: Kueue docs; Pyxis + Slurm container docs; Kubeflow Trainer v2 intro; SageMaker HyperPod resiliency docs; FineWeb + datatrove as the pipeline reference.
- **agentic-harnesses**: Anthropic's effective context engineering; the SWE-agent paper; Claude Code best practices; the Terminal-Bench leaderboard; Anthropic on harnesses for long-running agents.
- **agentic-frameworks**: Anthropic's Building Effective Agents; Cognition's Don't Build Multi-Agents paired with Anthropic's multi-agent research system; 12-factor agents; the Claude Agent SDK post; LangGraph docs.
- **protocols**: High Performance Browser Networking; the MCP spec + changelog; MDN's HTTP guide; OAuth 2.1 + Aaron Parecki's OAuth 2 Simplified; Stripe on idempotency and webhooks.
- **programming-languages**: Python 3.14 release notes + the free-threading guide; Herb Sutter's C++26 trip report; the Rust Book ch. 4 + Rustlings; uv docs; the PyO3 guide.
- **swe-and-system-design**: Designing Data-Intensive Applications 2nd ed; Chip Huyen's AI Engineering + her ML systems design booklet; the System Design Primer; Stripe idempotency + AWS Builders' Library on retries; Eugene Yan on testing ML.
- **math**: the MML book; Parr & Howard's matrix calculus; colah's Visual Information Theory; Boyd's Convex Optimization; the CS229 notes.
