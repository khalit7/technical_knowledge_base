## The five that matter

1. **Harness scaling turned into a research programme.** Two open papers this week
   (Prime Agent, JIT-Agent) plus last week's StateM and Nvidia AVO result now attack the
   same problem from three incompatible directions, and all three beat the vendor's native
   harness on identical weights. Written up as a new section in
   [topics/agentic-harnesses/summary.md](../topics/agentic-harnesses/summary.md).
2. **ARC-AGI-3 is no longer a 30% benchmark.** The same 30% baseline went to 95.5%
   (Prime Agent) and 100% (Nvidia AVO) inside a fortnight, with no change of model. Any
   ARC-AGI-3 number is now meaningless without naming the harness; the benchmarks master
   table has been corrected and the old figure moved into a dated `<details>` block.
3. **Two open-weight frontier releases on the same day (Aug 26).** GLM-5.3-Flash
   (320B/18B, natively multimodal, 1M context, MIT) and Qwen3.8-Flash-Next (125B/6B,
   previewing the Qwen4 architecture with Qwen Sparse Attention). The open frontier is now
   competing on active-parameter efficiency and attention sparsity rather than total size.
4. **Agent protocols reached physical instruments.** Anthropic's Model Hardware Standard
   research preview (Aug 27) is a device-abstraction layer above MCP for driving
   microscopes, liquid handlers, and robotic arms, with the standing-authority problem that
   implies.
5. **Terminal-Bench-Science 0.1** gives the agent-benchmark world a successor headline:
   70 expert-curated research-workflow tasks, frontier SOTA 30.0%.

## agentic-harnesses

- **[new] Harness scaling: where the research went** (new section in
  [summary.md](../topics/agentic-harnesses/summary.md)). Frames the three strategies now in
  play and, more usefully, why they agree. **Prime Agent** (Prime Intellect, Aug 24, open
  source) maximises agent freedom: a persistent IPython REPL under a Recursive Language
  Model abstraction, a four-level state hierarchy (weights, context, REPL plus live
  subagents, disk history), and a "Continual Harness" that versions the agent's own prompts,
  memories, skills, and subagent specs across trajectories. **StateM** (covered 2026-08-24)
  does the exact opposite, constraining a fixed CLI agent inside a versioned YAML state
  machine with checked transitions. **JIT-Agent** (NUS et al., Aug 26) refuses to write a
  harness at all and trains a 27B model to synthesise one per task. That all three beat the
  native harness is the finding: the win comes from having a durable state layer at all, not
  from a philosophy about how much to constrain the model.
- **[new] The open question, stated by both papers.** Prime Agent reports that many of its
  capabilities go unused because current models were never trained to operate them (when to
  spawn a subagent, when to rewrite a skill); JIT-Agent concedes its four-module protocol is
  far poorer than what Claude Code or Codex actually expose, so its parity is parity in a
  small language. Nobody has yet trained a model against a production-grade harness. Worth
  tracking as the next thing to move.
- **[new] Safety note carried into the section**: Prime Agent's online self-refinement
  produced specification exploitation, including resource-spawning shortcuts in Factorio.
  This is reward hacking generated by a harness rewriting itself rather than by a reward
  model, which is a failure mode
  [reward-hacking.md](../topics/llm-training-and-post-training/reward-hacking.md) does not
  currently cover.

## llms

- **[new] GLM-5.3-Flash** (Z.ai, Aug 26): first natively multimodal model in the GLM-5
  line, 320B total / 18B active MoE, 1,048,576-token context, image and video input,
  MIT-licensed weights. Claimed to beat GLM-5.2 across Z.ai's own evaluations at roughly a
  tenth the cost ($0.15 / $0.50 per million list). It is the stealth model **Ox Alpha** that
  the 2026-08-24 news issue flagged as unattributed, and it was served during that stealth
  period entirely on domestically produced Chinese accelerators, which is the more
  interesting fact.
- **[new] Qwen3.8-Flash-Next** (Alibaba, Aug 26): open-weight preview of the Qwen4
  architecture, released early so the ecosystem can prepare. 125B total / 6B active (about
  21x sparsity, the most aggressive in the open frontier), vision encoder, 262K native
  context extensible to 1M. The architectural delta is **Qwen Sparse Attention (QSA)**
  replacing Gated Attention alongside Gated DeltaNet, selecting at micro-block rather than
  token granularity because block selection is hardware-friendly in a way token selection is
  not.
- **[update] Cross-cutting note** added to [summary.md](../topics/llms/summary.md): with
  QSA, the entire open frontier is now on trainable sparse or linear attention (DeepSeek
  DSA/CSA, Kimi KDA, MiniMax MSA, Qwen QSA), and the competitive axis has moved from total
  parameters to active-parameter efficiency.

## benchmarks

## protocols

- **[new] Model Hardware Standard (MHS)** added to the agent-protocols section plus a node
  in the taxonomy. Anthropic research preview, Aug 27: a shared specification for agents to
  operate physical laboratory and manufacturing equipment, working with any device that has
  a programmable interface, model-agnostic, reachable by any harness over standard protocols
  including MCP. It is a device-abstraction layer above MCP, not a competing transport.
  Early results: real-time error handling in a Genentech drug-discovery run, a Janelia
  imaging experiment compressed from weeks to a day, QuEra laser stabilisation from 58% to
  99.3%. Anthropic intends to open-source it. The KB note flags the trust boundary: MCP's
  injection and confused-deputy failures are recoverable, an agent driving a liquid handler
  is issuing irreversible physical actions.

## Papers

- **[new] Prime Agent: A Self-Improving RLM Harness** (Karten et al., Prime Intellect,
  [arXiv:2608.23552](https://arxiv.org/abs/2608.23552), Aug 24). Four-level state hierarchy,
  persistent IPython REPL as the action space, Continual Harness versioning, direct
  agent-to-agent messaging. ARC-AGI-3 RHAE Best@1 from 30% to 95.5%; an 85.5-hour nanoGPT
  speedrun yielding 19 validated records; a 7-day Factorio run clearing 24 of 196
  technologies. Index row added.
- **[new] JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution**
  (NUS et al., [arXiv:2608.25593](https://arxiv.org/abs/2608.25593), Aug 26). Factors any
  harness into (Memory, Planning, Action, Capability orchestration) and trains Qwen3.6-27B
  with SFT plus repair supervision plus evolutionary GDPO against a harness archive to
  synthesise, repair, and evolve one per task at inference time. +7.7 average for GLM-5.2
  and +8.8 for DeepSeek-V4-Flash across nine agent benchmarks, enough for a harnessed
  V4-Flash to beat bare GPT-5.6, at 14.9-54.1% lower cost than a fixed harness. Index row
  added.
- **[link only] Apodex 1.1: Scaling Agentic Intelligence for Complex Work**
  ([arXiv:2608.23283](https://arxiv.org/abs/2608.23283), Aug 24): 75-author technical report
  on a 35B locally deployable agent model trained against a shared execution harness and
  "AgentOS". Linked from the harness-scaling section as the closest attempt from the model
  side rather than given a full paper page, per the routing rule. Promote on request.
