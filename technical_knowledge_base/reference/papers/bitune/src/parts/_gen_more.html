The paper

Bitune: Leveraging Bidirectional Attention to Improve Decoder-Only LLMs (arXiv HTML v2)

Best resources

Bitune project page

Kopiczko, Blankevoort, Asano: the authors' one-page summary with the overview figure.

(5 min)

LLM2Vec: Large Language Models Are Secretly Powerful Text Encoders

BehnamGhader et al., 2024: the same diagnosis applied to embeddings: switch on bidirectional attention in a decoder, then teach it to use it with masked next-token prediction.

(40 min)

Repetition Improves Language Model Embeddings (echo embeddings)

Springer et al., 2024: the zero-training way around the causal mask: repeat the input so the second copy sees the whole first one.

(30 min)

Encoder-Decoder Gemma

Zhang et al., Google, 2025: adapts a pretrained decoder-only model into an encoder-decoder: a bidirectional encoder over the input, a causal decoder for the output.

(40 min)

Unified Language Model Pre-training (UniLM)

Dong et al., 2019: one Transformer, three attention masks (left-to-right, bidirectional, prefix sequence-to-sequence); the clearest picture of masks as the only difference.

(30 min)

The Illustrated GPT-2

Jay Alammar: the causal (masked) self-attention this paper partly removes, drawn step by step.

(30 min)

Connected papers in this knowledge base
