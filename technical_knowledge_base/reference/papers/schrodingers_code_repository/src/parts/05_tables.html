Table I: SWE-bench Verified

Stars as printed (* p<0.05, ** p<0.01, test not named). Gemini-3.1-Flash-Lite: 300 leakage-selected instances, baseline and full setting only. Every Pass@1 is a whole number of instances out of 500 (300 for Gemini, 110 for Table III), consistent with one run per setting or with three-view averages alike.

How wide is each Pass@1 change?

Unpaired 95% interval for the change, N instances on each side (conservative: the same instances are used, so a paired test can be tighter). The last column is the McNemar arithmetic for a paired test: a drop of k instances is significant at p<0.05 only if the instances that flip the other way (fail to pass) number at most (k²/3.84 − k)/2. The paper's single-star rows need very few such flips; whether that held cannot be checked without the per-instance results.
