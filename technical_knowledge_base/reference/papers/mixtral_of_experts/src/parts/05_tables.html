Llama 2 70B in this paper against the Llama 2 paper

Mistral re-ran every Llama model. Where the Llama 2 paper prints the same benchmark, the two numbers for Llama 2 70B differ, sometimes by a lot, which is why only comparisons inside one table are fair.

Llama 2 paper ({{arXiv 2307.09288|https://arxiv.org/html/2307.09288v2}}): MMLU and GSM8K from Table 4, the commonsense set from Table 20, NaturalQuestions and TriviaQA (5-shot, TriviaQA on the Wiki validation subset) from Table 22, code from Table 21. Figures 7 and 9, decoded: which experts each Pile subset uses

The paper prints no numbers for its routing figures, but they are vector graphics in the arXiv HTML: every bar is a path with exact coordinates and every tick label is a glyph carrying its character, so decode_figs.py turns them into numbers by fitting each panel's gridlines to its labels. Checks: each subset's eight shares sum to 1.000 in every panel, and Figure 10 decoded at layers 0, 15 and 31 matches Table 5's printed values within points.
