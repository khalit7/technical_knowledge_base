Follow the router through the library

The paper's claim about cost is that an agent can "hold thousands of skills yet read just the few a task needs" ({{§1|ax:S1}}). The release lets that be measured rather than illustrated: it ships the router, every repository graph, and an exported Researcher session in which DisCo (GPT-5.6-sol) benchmarks and tunes vLLM against SGLang on two A100s ({{session export and report|https://github.com/VectorSpaceLab/AREX-Skill/tree/main/examples/researcher}}). This tab replays that session's skill reads, lets you walk the router yourself, and draws the one task-oriented graph whose structure the paper describes.

1. Replay the session's reads

The request (quoted from the session): "Use the installed vllm and sglang skills to benchmark and tune vLLM against SGLang using ./model/Qwen3.5-4B." Note that it names the two packages, so routing here is easy; what the replay shows is progressive disclosure, how little of each graph gets opened.

Each block is one file the agent read, drawn to scale by bytes. Switch to the two alternatives the design avoids, on the same scale: listing every repository's description up front instead of a router, and loading both graphs whole instead of following links.

Sizes from the release; times from the session export.

Tokens are estimated at 4 bytes per token, a rough rule for English and Markdown; the session's own token counts include everything else in context (the 15,911-character system prompt, tool output, the agent's reasoning). "Every description up front" uses the 1,000 one-line descriptions in the router's repository index (154,710 characters), which is what a flat skill list of only the entry skills would show; listing all 5,353 skills would cost more. The agent also read one skill from outside the library (karpathy-guidelines, 2,506 characters), shown separately.

3. A task-oriented graph: the FrontierCS recovery skill

The single graph shared by all 188 FrontierCS tasks ({{Appendix A.2.3|ax:A1.SS2.SSS3}}): an entry skill that activates only after a focused first attempt fails, then routes to one of eight modules. The paper says nine nodes and 42 distinct directed links; this page recounted the links from the released files (Markdown links between the nine SKILL.md files) and gets exactly 42 of the 72 possible. Tap a node to see where it routes and what routes to it.

Node size is proportional to the SKILL.md's bytes. The graph keeps three artefacts apart throughout: a guaranteed-valid fallback, the best validated champion, and experimental challengers; "a weaker or invalid challenger cannot replace the champion".
