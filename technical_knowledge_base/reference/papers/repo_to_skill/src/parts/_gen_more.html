Connected papers in this knowledge base

Demystifying Agent Skills: Why They Work - Until They Don't

The mechanistic account: skills act as procedural anchors, and they add a failure mode of their own (guidance misapplied or ignored, 10.0% of the skill arm's labels). The caution this paper only half engages with.

HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

Skills are one component a self-built harness has to assemble; this paper is the supply side of that component, at library scale.

Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments

Same week, same shape of idea applied to environments: mine artifacts that already exist (trajectories) for something the field was making by hand.

EnvHarness: Awakening Static Worlds for Agent Learning

Listed with Prime Agent on the old page as a different answer to the same complaint about hand-made agent context.

Prime Agent: A Self-Improving RLM Harness

Lets the agent version its own skills inline and finds the policy underuses it; Repo-To-Skill removes the authoring burden instead.
