The paper

Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks (arXiv HTML v4)

NeurIPS 2020, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(45 min)

transformers-research-projects/rag

the authors' Hugging Face port (fine-tuning and evaluation scripts; Apache-2.0). Transformers moved its examples/research_projects folder, where the old page's link pointed, to this separate repository in 2025 (the folder's README now says so), so that link returns 404 (checked 2 October 2026); the models themselves are RagSequenceForGeneration and RagTokenForGeneration in Transformers. About 20 minutes for the README and entry path.

(20 min)

Best resources

Meta AI blog: Retrieval Augmented Generation

Meta AI (Facebook AI), September 2020: the authors' own framing; short and good on the motivation of hot-swapping the index instead of retraining.

(10 min)

Hugging Face Transformers: RAG

Hugging Face docs: the original model as runnable code (RagSequenceForGeneration, RagTokenForGeneration, RagRetriever over the wiki_dpr index); the clearest way to see how the pieces compose (core pages).

(20 min)

facebook/rag-token-nq

Hugging Face model card (Apache-2.0): the released RAG-Token checkpoint fine-tuned on Natural Questions; the paper's demo address, huggingface.co/rag, now redirects here (checked 2 October 2026), so the interactive demo is gone. Its twin is facebook/rag-sequence-nq.

(5 min)

Retrieval-Augmented Generation for Large Language Models: A Survey

Gao et al., 2023 (arXiv 2312.10997): the standard bridge from this paper to the modern stack; its Naive, Advanced and Modular RAG taxonomy is the usual map of what the field became (survey).

(1h 30m)

How to Build an Open-Domain Question Answering System?

Lilian Weng, October 2020: places RAG among the 2020 retriever-reader and retriever-generator systems (DrQA, ORQA, REALM, DPR, FiD) with their equations side by side.

(45 min)

The Illustrated Retrieval Transformer

Jay Alammar: a visual walk through RETRO, the 2021 descendant that moved retrieval inside the network with chunked cross-attention.

(15 min)

Connected papers in this knowledge base

BERT

the DPR retriever is a pair of BERT-base encoders; retrieval embeddings remain BERT's main living habitat.

GPT-3: Language Models are Few-Shot Learners

the same month's parametric-only counterpoint; GPT-3-style in-context learning is what later let deployed RAG drop this paper's end-to-end training.

ReAct

retrieval moved from a fixed pipeline step to a tool an agent decides to call: the road to agentic RAG.

T5: Exploring the Limits of Transfer Learning

the closed-book baselines of Table 1 are T5 models (fine-tuned by Roberts et al., with salient span masking for T5+SSM).

Attention Is All You Need

the generator (BART) and both retriever encoders (BERT) are Transformers; the toy generator on this page is built like that page's toy model.
