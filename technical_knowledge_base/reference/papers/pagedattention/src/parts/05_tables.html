The paper's figures, rebuilt

The paper has one table; its evidence is in its figures. The arXiv HTML ships them as vector graphics, so every line and bar here is read from the plotted paths, calibrated on each panel's own tick marks (worst tick residual below 0.001 of a unit; see src/extract_figs.py), not by eye. Printed labels are transcribed. Every derived number is recomputed in src/recompute.py.

Throughput curves: how much higher a request rate at the same latency?

The paper's throughput claims are read off curves of normalized latency against request rate: a system "sustains" a rate until its curve turns up. The paper does not say at which latency it compares. Here you choose: the table gives the rate at which each curve first crosses your threshold (linear between the plotted points) and vLLM's ratio to each baseline, beside what the text claims.
