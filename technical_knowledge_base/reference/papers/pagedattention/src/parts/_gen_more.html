Best resources

vLLM: Easy, Fast, and Cheap LLM Serving with PagedAttention (announcement blog, June 2023)

the vLLM team: the authors' own short version, with the clearest animations of block tables and copy-on-write sharing, and the up-to-24x-over-Hugging-Face headline.

(10 min)

How continuous batching enables 23x throughput in LLM inference

Anyscale: the best explanation of iteration-level (continuous) batching, the Orca idea that PagedAttention composes with; benchmarks vLLM against static-batching baselines.

(20 min)

Inside vLLM: anatomy of a high-throughput LLM inference system

Aleksa Gordić: a code-level walkthrough of the modern engine (scheduler, KV cache manager, paged attention kernels), the bridge from this paper to today's codebase.

(45 min)

vLLM V1: a major upgrade to vLLM's core architecture (January 2025)

the vLLM team: what the project learned in a year and a half of production, and how the rebuilt V1 engine changes the scheduler and cache manager described here.

(15 min)

vAttention: dynamic memory management for serving LLMs without PagedAttention

Prabhu, Nayak, Mohan, Ramjee and Panwar (Microsoft Research India): the strongest critique: it measures what paging costs inside attention kernels and keeps the KV cache contiguous in virtual memory instead.

(40 min)

Connected papers in this knowledge base

Attention Is All You Need (Transformer)

2017: the KV cache being paged here is the per-token key and value state of its self-attention.

FlashAttention

2022: the complementary attention-systems paper; FlashAttention optimises compute and IO inside the kernel, PagedAttention where the KV operands live across requests. Modern engines use both (vLLM V1 integrated FlashAttention 3).

Megatron-LM

2019: vLLM's distributed execution uses Megatron-style tensor parallelism, with the KV cache manager centralised above it.

DeepSeek-V3 Technical Report

2024: multi-head latent attention shrinks the KV cache at the architecture level, the model-side attack on the same bottleneck; vLLM ships FlashMLA kernels for it.

DeepSeek-R1

2025: reinforcement-learning post-training generates rollouts with vLLM-class engines (verl, for one, integrates vLLM and SGLang).

Language Models are Few-Shot Learners (GPT-3)

2020: the 175B size of the largest model served here, and the source of Figure 10's few-shot translation prefix.

ZeRO

2019: the training-side counterpart, memory as the binding constraint and removed by not storing redundant state.
