The paper

Megatron-LM: Training Multi-Billion Parameter Language Models Using Model Parallelism (arXiv HTML v4)

arXiv preprint, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(45 min)

NVIDIA/Megatron-LM

the authors' code (repo, about 25 minutes for the README and entry path); still developed, now as Megatron-Core, and the reference implementation of everything in the paper.

(25 min)

Best resources

The Ultra-Scale Playbook: tensor parallelism

Hugging Face (nanotron), 2025: the clearest modern walkthrough of column- and row-parallel linears, with communication-cost analysis and profiles.

(40 min)

How to Train Really Large Models on Many GPUs?

Lilian Weng, 2021: situates Megatron-style tensor parallelism among the other parallelism and memory-saving techniques.

(45 min)

Efficient Large-Scale Language Model Training on GPU Clusters Using Megatron-LM

Narayanan et al., 2021 (arXiv 2104.04473): the follow-up: this paper's tensor parallelism combined with pipeline and data parallelism (PTD-P) and an interleaved 1F1B schedule, 502 PFLOP/s on 3,072 A100s.

(45 min)

Reducing Activation Recomputation in Large Transformer Models

Korthikanti et al., 2022 (arXiv 2205.05198): sequence parallelism: the same f and g idea, with each all-reduce split into a reduce-scatter and an all-gather so LayerNorm and dropout are no longer duplicated.

(40 min)

Connected papers in this knowledge base

Attention Is All You Need

2017: the layer structure being partitioned (attention heads and a two-matrix MLP).

BERT

2018: the architecture whose LayerNorm and residual placement this paper changes to scale it past 336M.

ZeRO

2019, a month later: the memory-side alternative, sharding optimizer state, gradients and weights under data parallelism instead of splitting layers; Turing-NLG used both.

GPT-3

2020: trained with "a mixture of model parallelism within each matrix multiply and model parallelism across the layers", at the scale this line of work enabled.

Switch Transformers

2021: expert parallelism, the axis that later replaced tensor parallelism in some MoE training runs.

The Llama 3 Herd of Models

2024: 4D parallelism with tensor parallelism of 8 inside each NVLink machine, citing this paper.

DeepSeek-V3 Technical Report

2024: trains without tensor parallelism (pipeline 16, expert 64, ZeRO-1 data parallel), but serves with 4-way TP plus sequence parallelism for attention.

Bounding the memory bottlenecks of large mixture-of-experts training

2026: the same memory accounting (weights, optimizer state, activations per GPU) applied to MoE training.
