Split a layer across GPUs

One MLP block, Z = Dropout(GeLU(XA)B), run forward and backward on 2, 4 or 8 GPUs, two ways. Megatron splits A by columns and B by rows, the paper's choice ({{§3|ax:S3}}). Option 1 splits A by rows, the alternative the paper rejects because it needs a synchronisation before the GeLU ({{Eq. 2|ax:S3.E2}}). Each lane is one GPU; each bar is what that GPU holds for one token at that moment, drawn to scale (the lane's full width is 4H, so a bar of width H is a quarter of it).

Blue: this GPU's own slice, drawn at its position in the full tensor. Orange, dashed: a partial sum, full width but not yet the answer. Grey: the full tensor, identical on every GPU. Elements sent per GPU use the ring algorithm: an all-reduce of n elements sends 2(t − 1)/t × n, an all-gather (t − 1)/t × n, at 2 bytes (fp16) for b × 1,024 tokens. Time is elements ÷ link speed, with no overlap and no latency. Megatron's two collectives are the paper's ({{Figure 3a|ax:S3.F3}}); Option 1's backward collectives are derived here (the conjugate of each forward step), not given in the paper. The animation stops when off screen, and starts paused if your system asks for reduced motion.

The attention block has the same shape (heads split by columns, output projection by rows, one g and one f), so a whole Megatron layer is twice this: 4 all-reduces, 2 forward and 2 backward ({{Figure 4|ax:S3.F4}}). With activation checkpointing, as the paper trains, each layer's forward pass runs a second time during the backward pass, and its 2 all-reduces with it: 6 per layer in practice (our reading of how checkpointing works; the paper counts 4).
