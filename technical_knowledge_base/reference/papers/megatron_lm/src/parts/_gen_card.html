Megatron-LM: Training Multi-Billion Parameter Language Models Using Model Parallelism (Megatron-LM)

Mohammad Shoeybi, Mostofa Patwary, Raul Puri, Patrick LeGresley, Jared Casper, Bryan Catanzaro
NVIDIA · September 2019 (arXiv v1 17 September 2019; v4 13 March 2020)

In one line: Introduced tensor (intra-layer model) parallelism: column-split the GEMM feeding each nonlinearity and row-split the one after it, so a transformer layer needs only 4 all-reduces, enabling an 8.3B GPT-2 on 512 V100s at 76% scaling efficiency.

How far to trust it: Trust the mechanism fully: it is exact algebra, and every later training and serving stack uses it. Read the 76% as weak scaling in model size against a strong baseline, not as a speedup, and the state-of-the-art results as single runs on different training data. The evidence, point by point.
