Best resources

REFRAG: Rethinking RAG based Decoding

Lin et al., Meta, 2025: the RAG-specific version of the same idea, with precomputable chunk embeddings and an RL policy choosing what to expand; useful as the narrower, more deployable sibling (the paper cites it for W = N token pooling).

(45 min)

Prompt Compression for Large Language Models: A Survey

Li et al., NAACL 2025: the map of the field this paper is arguing with, covering the gist, ICAE, AutoCompressor, 500xCompressor and xRAG lineage.

(1h)

KVzip: Query-Agnostic KV Cache Compression with Context Reconstruction

Kim et al., 2025: the strongest KV baseline at 4x and 8x here; scores each cache entry by the attention it gets while the model reconstructs its own context.

(40 min)

KVPress

NVIDIA: the library whose SnapKV, KVzip, FastKVzip and Expected Attention implementations and timing notebook the paper uses for every baseline.

(20 min)

RULER: What's the Real Context Size of Your Long-Context Language Models?

Hsieh et al., NVIDIA, 2024: the synthetic suite behind the paper's headline: needle retrieval, multi-hop tracing, aggregation and QA, 13 tasks per length.

(30 min)

LCLM checkpoints (4x, 8x, 16x)

latent-context on Hugging Face: model cards with the configuration of each released model (encoder window 1024, mean pooling, causal encoder, MLP adapter, no overlap); Apache-2.0.

(10 min)

Connected papers in this knowledge base

Encoder-Decoder Gemma and T5Gemma 2

the other route to spending more parameters on reading than writing, restructuring the model rather than compressing the input; the two disagree on whether the encoder should be causal.

Trained Persistent Memory for Frozen Encoder-Decoder LLMs

the same instinct applied to memory rather than input context, putting state in continuous latents so reads and writes are differentiable.

Efficient Memory Management for LLM Serving with PagedAttention (vLLM)

the KV cache layout this paper's baselines are constrained by, and the reason systems-realisability is a real distinction.

DeepSeek-V3 Technical Report

MLA compresses the KV cache inside attention, the same goal one layer down; it composes with this rather than competing.

Prime Agent: A Self-Improving RLM Harness

the recursive-language-model direction the authors name as naturally compatible, where a compressed working memory is the substrate.

Mamba: Linear-Time Sequence Modeling with Selective State Spaces

the other way to avoid a growing cache, a fixed-size recurrent state, with the same exact-recall cost that shows up here at high compression.

Attention Is All You Need (Transformer)

the encoder-decoder and the attention whose per-token KV cache this paper is trying to shrink.

DeepSeek (deep dive, with the MLA animation)

the KV cache arithmetic for latent attention, animated token by token.
