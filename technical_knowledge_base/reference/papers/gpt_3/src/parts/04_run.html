Refit the scaling curves

GPT-3 is an empirical paper: its evidence is how 63 evaluations change across eight model sizes. Every number the paper has for every size is in {{Table H.1|ax:A8.T1}}; this tab replots any of them and asks the question the paper's whole design is built on: could the seven smaller models have predicted 175B? Pick a task, choose which smaller models the line is fitted on, and compare its prediction with what 175B actually scored.

Try: 3-digit addition (the prediction is about 7%, the result 80.4%); TriviaQA (smooth all the way, and the line overshoots); WiC (flat at chance); the average of all 41 accuracy tasks in "Few minus zero" view, which is Figure 1.3's claim.

Every accuracy task at once

The same fit for all 41 rows of Table H.1 whose metric is accuracy, in the setting chosen above: each dot is one task, placed at 175B's actual score minus the line's prediction. Right of zero, 175B did better than the smaller models' trend; left, worse. Click a dot to plot that task above.

What this shows, and what it does not

The line is straight in log(parameters), the simplest trend; it is not the paper's method (the paper fits no task curves) and a sigmoid would bend differently. Parameters come from {{Table D.1|ax:A4.T1}}; every model saw 300B tokens, so log compute is the same axis shifted. Defaults reproduce nothing printed in the paper (it gives no such fit); they reproduce recompute.py, which gets the same counts (independently, in Python). The shape the paper claims, a gap between few-shot and zero-shot that widens at every size, does come out of its own Table H.1: 1.8, 2.6, 3.7, 4.2, 5.9, 6.0, 9.2 and 14.8 points (choose the 41-task average and "Few minus zero"). Figure 1.3 itself has no printed values, so its curve is not transcribed here.

The loss law, as printed on Figure 3.1

{{Figure 3.1|ax:S3.F1}} fits validation loss against training compute with the line printed in its legend, L = 2.57 · C−0.048 (C in petaflop/s-days, embedding parameters excluded). Move the compute and read off the loss it predicts; the dots mark each model's full training compute from Table D.1.

Illustrative: the dots use Table D.1 compute, which counts embedding parameters that Figure 3.1's axis leaves out (about 0.4% of 175B but 31% of GPT-3 Small, recounted), and the paper prints no losses to check the line against; only the coefficients are transcribed (from the figure's legend). Each halving of loss takes 21/0.048 ≈ 1.9 × 106 times the compute.
