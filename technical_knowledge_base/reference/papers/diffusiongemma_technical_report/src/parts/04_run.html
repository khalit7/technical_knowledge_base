Run the toy

A toy DiffusionGemma, built as the paper describes and trained offline: one set of transformer weights used as a causal encoder (prompt and finished canvases into a KV cache) and as a bidirectional decoder (one noisy canvas attending to itself and to the cache), with the self-conditioning FFW of Eq. 6, trained with Eq. 13's two losses (the encoder's next-token loss plus the decoder's denoising loss on one random canvas, half the batch self-conditioned). Everything below runs in your browser: the forward pass in plain JavaScript on the shipped 6-bit weights, and Algorithm 1 exactly as printed (entropy budget, temperature annealing, uniform re-noising, adaptive stopping).

Try: pick a held-out rule and run the sequential task, then the parallel one, and compare passes per canvas. Turn the entropy budget up and watch TPF rise and accuracy fall; turn self-conditioning off; switch to the masked twin and count revisions; then run the test over 64 held-out problems.
