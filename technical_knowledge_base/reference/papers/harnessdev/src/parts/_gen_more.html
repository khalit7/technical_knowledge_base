Self-Developing Agents: From Half-Loop to Closed-Loop RSI

ByteDance Seed and TokenWave, project page, 1 September 2026: the authors' page for HarnessDev and its two sibling benchmarks (Aspire: can a model turn a vague goal into a target; S3Gym: can it learn from its own experience). A 48-minute architecture playbook for building a reliable agent harness

Stencil blog, filed on Topic: agentic-harnesses on 2026-09-07: the human-written counterpart: state management, runtimes, control planes, tools and interfaces, with the thesis that unavoidable complexity belongs in a harness's core abstractions rather than in extensions.

(48 min)

Evo-Bench: Can language models improve agent harness?

Huang et al., arXiv 2608.09096, 2026: the closest concurrent benchmark for the Evolution stage: evolver models improve a shared CodeAct seed with the runtime model fixed, scored on a disjoint multi-domain suite.

(40 min)

HarnessOpt-Bench: Evaluating LLMs at harness optimization

Ursekar et al., arXiv 2608.06301, 2026: an optimizer gets a seed harness, graded feedback and a fixed budget; a trusted environment scores its nominated candidate on an inaccessible test partition. The paper calls it the closest concurrent work to Evolution.

(40 min)

Harness updating is not harness benefit

Lin et al., arXiv 2605.30621, 2026: separates producing a useful harness update from an executor's ability to exploit it; the paper cites it as the motivation for splitting the creator from the executor.

(35 min)

Meta-Harness: End-to-end optimization of model harnesses

Lee et al., arXiv 2603.28052, 2026: a coding-agent proposer that reads prior candidates, scores and traces before proposing the next harness: the method this benchmark measures in the wild.

(35 min)

Inside the scaffold: a source-code taxonomy of coding agent architectures

Rombaut, arXiv 2604.03515, 2026: what mature coding harnesses (Claude Code, Codex, OpenHands, SWE-agent) are made of; the background to the six modules E, T, C, S, L, V.

(30 min)

Terminal-Bench 2.1 leaderboard

Laude Institute: the source of the paper's opening example: the same GPT-5 weights at 35.2% in Terminus 2 and 49.6% in Codex CLI.
