## What reproduces

- Independently: every win count stated in the text except one; Table 22's printed changes (within 0.1, rounding); the eight parameter counts from config.json; Figure 2's non-thinking lines equal Table 12 (calibration self-check); 1,800 / 17,920 = 10.0%.
- Does not reproduce: Qwen3-32B-Base beating Llama-4-Scout-Base "on all 15" (Scout wins INCLUDE); Figure 2's 32K points against Table 11; "about twice" (1.7 times); "consistently superior" small models (0.6B and 1.7B lose math and code rows to R1 distills); "1/10 of the four-stage method" (only RL is measured).

## What the methodology lacked here

A claim that a capability "emerges" from a training stage has no number to reproduce; the useful visual was a controlled toy with and without the stage (and with explicit training), which the scoring does not reward directly. Decoding the figure's SVG (P-qwen3_technical_report.4) took minutes and exposed the Table 11 mismatch, as the ReAct and InstructGPT lessons predicted.
