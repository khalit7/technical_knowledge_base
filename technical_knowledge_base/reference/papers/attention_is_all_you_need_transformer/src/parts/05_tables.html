The paper's tables, rebuilt

Every number below is transcribed from the arXiv HTML (v7) of the paper, and every derived number is recomputed in recompute.py. Each section links the table it rebuilds.

Table 1: cost per layer as the sequence grows [[S4.T1|Table 1]]

Try: slide the sequence length past the representation size and watch self-attention's n²d overtake recurrence's nd². Table 1 gives orders of growth; the curves drop the constants, as the table does.

At the paper's d = 512 the crossover is n = d = 512 tokens (recompute.py). The default n = 30 is an illustrative sentence length, not a figure from the paper. Restricted self-attention is the paper's own suggestion for long sequences ({{§4|ax:S4}}).

Table 2: translation quality against training cost [[S6.T2|Table 2]]

BLEU on newstest2014 against training FLOPs (log scale). Filled: single models; rings: ensembles; Transformers in blue. The paper prints one cost per Transformer model for both pairs. ByteNet (EN-DE 23.75) and Deep-Att + PosUnk (EN-DE) have no cost in the table and are listed beside the chart. Defaults reproduce: 3.3 × 1018 and 2.3 × 1019 for the two Transformers, independently, from 12 hours and 3.5 days × 8 GPUs × 9.5 TFLOPS (footnote 2; recompute.py).

Table 3: every ablation, as a change from the base model [[S6.T3|Table 3]]

Dev-set (newstest2013) results; base model 25.8 BLEU and perplexity 4.92 per word-piece; unlisted values equal the base model's. Rows (A) keep computation constant as heads change ({{§6.2|ax:S6.SS2}}).

Parameters: the paper's column where it has one, and this page's count from each configuration (with a 37,000-token shared vocabulary, biases and LayerNorm; see the recount below). The big row trains 300K steps with dropout 0.3.

The parameter count, recounted from the configuration [[S6.T3|Table 3, params]]

Embedding: one shared 37,000 × 512 matrix, 18,944,000. Each attention sub-layer: four 512 × 512 matrices plus biases, 1,050,624. Each FFN: 512 × 2048 and 2048 × 512 plus biases, 2,099,712. Each LayerNorm: 1,024. Encoder layer 3,152,384; decoder layer (two attentions, three norms) 4,204,032; six of each: 44,138,496. Total 63,082,496, against the paper's 65M.

Does not reproduce exactly: with the stated vocabulary of "about 37000 tokens" ({{§5.1|ax:S5.SS1}}) the count is 63.1M, 1.9M (3%) below 65M; a vocabulary of 40,745 would give 65.0M exactly. The other rows show the same shortfall of about 1.2M to 4.1M (proportional to dmodel, as an embedding term would be), except the big model, which comes out 1.3M above 213M; the paper does not say how it counted (what "about 37000" was exactly, or which biases and norms it included), so the gap is left open rather than fitted.
