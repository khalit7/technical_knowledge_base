Then and now: the 2017 block becomes a 2026 block, one change at a time

Each step makes one change that later work introduced, names the paper, and recounts the block. The widths stay at the paper's base model (dmodel 512, 8 heads of 64) so every count is comparable; only the design changes. Counts are per decoder layer and computed from the formulas in the caption, not from any one model.

2017 Transformer to a 2026 decoder-only block (Llama 3, Qwen3 style).

Parameters per decoder layer at d = 512: attention 4d² (with GQA, 2d² + 2d · g · 64 for g KV heads), FFN 2d · dff (SwiGLU: 3d · dff), plus biases and norm gains while they exist. KV cache: numbers stored per token per layer, 2 × (KV heads) × 64. The animation stops when off screen, and starts paused if your system asks for reduced motion.

What survived

  • Untouched: scaled dot-product attention, softmax(QK⊤/√dk)V; multi-head projections; residual connections with a norm around every sub-layer; an FFN at every position.
  • Survived in form, changed in detail: the 4× FFN expansion survives as a parameter budget. A SwiGLU FFN with inner size 8/3 × d has the same parameters as a 4× ReLU FFN; current configs go further: {{Llama 3.1 8B|https://huggingface.co/unsloth/Meta-Llama-3.1-8B/raw/main/config.json}} uses 14,336 / 4,096 = 3.5× and {{Qwen3 8B|https://huggingface.co/Qwen/Qwen3-8B/raw/main/config.json}} 12,288 / 4,096 = 3.0×, with three matrices each.
  • Tied embeddings survive only in small models: {{Llama 3.2 1B|https://huggingface.co/unsloth/Llama-3.2-1B/raw/main/config.json}} and {{Qwen3 0.6B|https://huggingface.co/Qwen/Qwen3-0.6B/raw/main/config.json}} set tie_word_embeddings to true; {{Llama 3.1 8B|https://huggingface.co/unsloth/Meta-Llama-3.1-8B/raw/main/config.json}}, {{Qwen3 8B|https://huggingface.co/Qwen/Qwen3-8B/raw/main/config.json}} and {{DeepSeek-V3|https://huggingface.co/deepseek-ai/DeepSeek-V3/raw/main/config.json}} set it to false (PaLM ties them, {{§2|https://arxiv.org/abs/2204.02311}}). Llama 3.1 is read from the unsloth mirror because Meta's repository is gated.
  • The warmup: still used everywhere, now before a cosine decay rather than the inverse square root.
