Replay the traces

The paper releases five Terminal-Bench 2.0 tasks run twice: Claude Sonnet 4.5 alone, and Sonnet 4.5 with the Claude Opus 4.6 memory agent. Step through either run turn by turn: the actor's prompt size, what it concluded, and, in the memory run, what the memory agent wrote to its bank and whether it spoke.

Try: sqlite-with-gcov (silent at 7 of 10 steps) against git-multibranch (speaks at 28 of 31), and watch how often a "reminder" is a fresh diagnosis of the last output. Switch to the baseline run of the same task: two of the five ran longer with memory than without.

Bars: the action agent's prompt tokens at each turn, as logged; both runs of a task share one scale. Squares under the memory run: one per memory step, run just before the turn above it; filled when it injected a reminder, coloured by this page's reading of the reminder ({{labels|tab:t-run:rpLeg}}). Memory-agent tokens are estimated from the prompt text in the export at 3.76 characters per token (calibrated on the actor's first prompt in all ten runs, where both the text and the logged token count are known), counted twice per step because both phases are sent the bank and the window; its thinking tokens, if any, are not in the export. Costs use list prices without caching: Sonnet 4.5 $3 and $15, Opus 4.6 $5 and $25 per million input and output tokens ({{pricing|https://platform.claude.com/docs/en/about-claude/pricing}}). Snippets, bank edits and reminders are shortened; the full texts are in the {{repository's examples|https://github.com/yifannnwu/proactive-memory-agent/tree/main/examples}}. The exports do not record whether the verifier passed.

How the reminders were labelled

recall brings back something from earlier in the run that the actor was about to repeat or had left open (a requirement, an environment fact, a failed attempt, an old diagnosis): what the paper says the memory agent is for. diagnose analyses what the latest command just printed, usually with a fix: advice from a stronger model, visible in the actor's own window. check asks for verification before finishing. This is a reading of the text, not a measurement; each label is shown with its reminder so it can be checked.
