How big is the noise?

The paper reports one run per cell. Two yardsticks it does not give: the unpaired standard error of each difference, and the paired (McNemar, exact) test, which needs the number of tasks whose outcome changed between the two runs. That number is not reported, so the table gives the largest number of changed tasks for which the gain would still be significant at 5%.

Reference for run-to-run spread: the Terminal-Bench paper runs every agent and model pair at least five times and reports Claude Sonnet 4.5 with Terminus 2 at 42.8% ± 2.8% (95% interval) and Claude Opus 4.5 with Terminus 2 at 57.8% ± 2.5% ({{Terminal-Bench, Table 2|https://arxiv.org/html/2601.11868#A1.T2}}); this paper's Sonnet baseline is 37.6%, one run. In this paper, the same full memory configuration run twice solved 172 and 170 τ²-Bench tasks.
