The paper's tables and figures, rebuilt

Every table that carries the argument, transcribed from the arXiv HTML (v3) with the printed precision, and the two plots rebuilt from the vector paths of the paper's own figure files. Every derived number (gaps, standard errors, sums, the figure values) is computed by recompute.py, which also checks the figures against the tables.

Table 1: HotpotQA and FEVER, PaLM-540B prompting

{{Table 1|ax:S3.T1}}. Standard error of a gap: √(p1(1−p1)/n + p2(1−p2)/n) with n = 500, an assumption: the paper gives no question count for Table 1; the released code runs 500 random dev questions for its GPT-3 numbers (out of 7,405 HotpotQA dev questions). Independent samples are conservative for methods run on the same questions; a paired test needs per-question results, which are not published. Wang et al. (2022b) report 27.1, 28.9 and 33.8 for Standard, CoT and CoT-SC on HotpotQA (the table's footnote 4).

Three sources, three sets of numbers

Table 1 (main text), {{Table 5|ax:A1.T5}} (Appendix A.1, "a subset of 500 validation questions") and the {{code README|https://github.com/ysymyth/ReAct}} ("PaLM-540B (paper)", 500 random dev examples) give different ReAct numbers for the same model. The likeliest reading is different question subsets; the paper does not say. This page uses Table 1 throughout, as the paper's own text does.

Figure 2: the combinations against the number of CoT-SC samples

{{Figure 2|ax:S3.T1.fig2}}, rebuilt: recompute.py reads each line's vertices from the figure's SVG (the arXiv HTML's cots_scale.svg and fever_cots_scale.svg) and converts them with the figure's own gridlines and printed tick values, to about 0.01 point; nothing is read by eye. The HotpotQA panel has no legend; its colours are the FEVER panel's. Samples were plotted at 1, 3, 5, ..., 21.

Two things the figure shows that the text does not say. At one sample, CoT-SC → ReAct on HotpotQA starts at CoT-SC's value (25.1), as the back-off rule implies (one sample is always a majority), while on FEVER it starts at ReAct's (60.9): the rule seems to have been applied differently on the two tasks. And on FEVER the dashed CoT line sits at 59.3 and CoT-SC ends at 61.0, where Table 1 prints 56.3 and 60.4.
