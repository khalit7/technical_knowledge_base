Then and now

The loop survived; almost everything around it was replaced. Below, one step of the paper's own Apple Remote episode (Thought 2, Act 2, Obs 2 of {{Figure 1|ax:S1.F1}}) is written the way each generation of agent stack would carry it, from the 2022 prompt to a 2025 reasoning model thinking between tool calls. Step through it: what changes is who writes the thought, how the action reaches the tool, who parses it, and how the behaviour was learned.

Same step, six formats. The wire formats follow each provider's documented shape; field values are this episode's, so the messages are illustrative.
