Follow the audit

The paper's method is a pipeline: pick the questions, grade them, send some to experts, label, exclude or repair, re-grade. Its appendices give the count at every stage for every benchmark ({{Appendix B|ax:A2}}, {{Appendix C|ax:A3}}), so the whole pipeline can be replayed question by question: one square per question, drawn to scale.

Try: play HLE-Physics and watch how many squares leave at the exclusion step; then play CMT-Benchmark, where every question was reviewed and almost none left. Compare the counters at the last step.

Counts are the paper's; which square is which question is not published, so squares are grouped by label (the arrangement is illustrative, the numbers are exact). What the protocol can and cannot see

The animation shows what the paper counted. This simulator asks what it could not count. It builds a benchmark from a few rates, runs the paper's protocol on it (audit only the rejections, exclude benchmark errors, count grader errors as correct, re-grade the rest) and compares the result with the model's true accuracy on the well-posed questions. Each preset sets the first three rates from that benchmark's audit counts, with the other three at zero; at those settings the protocol is exact by construction and reproduces the audit's counts. The last three are what the paper never measured.

Try: on the HLE-Physics preset, raise "judge accepts a wrong answer" to 5%: the protocol's corrected score rises while the true accuracy does not move. Then raise "reviewers call a model error a defect": the excluded set swallows real failures.

The simulator uses expected counts, not random draws, and one attempt per question, like the paper's PRISM-Physics and UGPhysics audit runs. Formulas: with d defective, accuracy a, false rejection g, false acceptance f, defective-accepted c and mislabel e, the share accepted is (1 − d)(a(1 − g) + (1 − a)f) + dc; the protocol keeps everything except the rejections labelled defective, d(1 − c) + e(1 − d)(1 − a)(1 − f), and scores the kept accepted answers plus the grader errors as correct.
