The paper

LoRA: Low-Rank Adaptation of Large Language Models (arXiv HTML v2)

ICLR 2022, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(45 min)

microsoft/LoRA (loralib)

the authors' package, MIT licence; about 15 minutes for the README. It releases the RoBERTa, DeBERTa and GPT-2 adapters (1.5 to 2.3 MB each for GPT-2) but no GPT-3 code or weights.

(15 min)

Best resources

Practical Tips for Finetuning LLMs Using LoRA

Sebastian Raschka: the best empirical guide to r, alpha, which layers, and QLoRA trade-offs, from hundreds of runs.

(30 min)

Code LoRA from Scratch

Sebastian Raschka, Lightning AI: implement the roughly 20 lines that LoRA actually is; makes the mechanics stick.

(45 min)

LoRA Without Regret

John Schulman and Thinking Machines Lab, 29 September 2025: the modern authority on when LoRA matches full fine-tuning and how to configure it; partially overturns the original paper's layer advice.

(35 min)

Hugging Face PEFT documentation

Hugging Face: the library everyone actually uses to apply LoRA (LoraConfig, use_rslora, use_dora); the conceptual guides double as a good method overview.

(30 min)

QLoRA: Efficient Finetuning of Quantized LLMs

Dettmers, Pagnoni, Holtzman, Zettlemoyer, May 2023: LoRA on a frozen 4-bit NF4 base with paged optimisers: a 65B model fine-tuned on one 48 GB GPU.

(40 min)

What is Low-Rank Adaptation (LoRA), explained by the inventor

Edward Hu (video linked from the repository README; 7 min 28 s): the first author's own short walk through the reparametrisation and why the update can be low rank.

(8 min)

Connected papers in this knowledge base

QLoRA

2023: 4-bit quantised frozen base plus LoRA, the combination that put fine-tuning on one GPU.

GPT-3

2020: the 175B model whose deployment cost motivated LoRA and on which it was stress-tested.

BERT

2018: the encoder family (RoBERTa, DeBERTa) of the GLUE experiments.

DPO

2023: preference post-training, in practice often run on LoRA adapters.

DeepSeekMath (GRPO)

2024: RL post-training; LoRA Without Regret found RL needs very little adapter capacity.

PagedAttention (vLLM)

2023: the serving side; vLLM batches many LoRA adapters over one base model.

ZeRO

2019: the 16-bytes-per-parameter accounting of Adam training that LoRA's memory saving is measured against.

Attention Is All You Need

2017: the Wq, Wk, Wv, Wo projections LoRA adapts.
