Mamba-2.8B against Pythia-2.8B: is the gap bigger than the noise?

Standard error of a difference of two accuracies, √(p₁(1 − p₁)/n + p₂(1 − p₂)/n), with n the size of the split lm-evaluation-harness scores ({{LAMBADA|https://huggingface.co/datasets/EleutherAI/lambada_openai}} test, {{HellaSwag|https://huggingface.co/datasets/Rowan/hellaswag}} validation, {{PIQA|https://huggingface.co/datasets/baber/piqa}} validation, {{ARC|https://huggingface.co/datasets/allenai/ai2_arc}} test, {{WinoGrande|https://huggingface.co/datasets/allenai/winogrande}} validation). It treats the two models as independent samples; they answer the same questions, so the true (paired) error is smaller and these z values are conservative. It says nothing about training-run noise, which one run per model cannot measure.
