Mamba: Linear-Time Sequence Modeling with Selective State Spaces (Mamba)

Albert Gu, Tri Dao (equal contribution, listed alphabetically)
Carnegie Mellon University (Gu), Princeton University (Dao) · December 2023 (arXiv v1 1 December 2023; v2 31 May 2024, with the same numbers in every table)

In one line: Made SSM parameters (B, C, delta) input-dependent, breaking LTI so the model selectively remembers or forgets per token, and paired it with a fused parallel-scan GPU kernel; first attention-free model to match Transformer++ quality with linear-time training and 5x inference throughput, seeding today's hybrid attention-SSM production models.

How far to trust it: Believe the mechanism: letting the input set Delta, B and C is what lets a recurrent model select, the synthetic gaps are huge, and this page's toy reproduces the selective-copying one. Read "Transformer quality" narrowly: models stop at 2.8B, every number is one run, the 5x throughput is against the unoptimised Hugging Face Transformer, and a later same-data 8B study found pure Mamba level on common zero-shot tasks but 18 points behind on 5-shot MMLU, which is why production models became hybrids.
