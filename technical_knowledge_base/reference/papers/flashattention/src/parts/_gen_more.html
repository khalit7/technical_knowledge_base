Connected papers in this knowledge base

Attention Is All You Need (Transformer)

2017: the O(N²) attention this paper makes fast without changing its output.

Efficient Memory Management for Large Language Model Serving with PagedAttention

2023: the complementary inference-side memory result; FlashAttention optimises HBM to SRAM traffic inside the kernel, PagedAttention optimises KV-cache allocation across requests. Serving stacks use both.

Megatron-LM

2019: the training-systems baseline FlashAttention beats in Tables 2 and 4, and later integrated into (Megatron-LM pull request 267).

Mamba: Linear-Time Sequence Modeling with Selective State Spaces

2023: Tri Dao's other line of attack on sequence length; its selective-scan kernel reuses the same IO-aware recipe (fuse, keep state in SRAM, recompute in backward).

DeepSeek-V3 Technical Report

2024, and every modern LLM report: FlashAttention-class kernels are assumed infrastructure for the published long-context and MFU numbers.

BERT

2018: BERT-large is the model of Table 1's 15% training-speed result.

ZeRO

2019: the other half of training memory; ZeRO shards the model states, FlashAttention removes the N × N activations.
