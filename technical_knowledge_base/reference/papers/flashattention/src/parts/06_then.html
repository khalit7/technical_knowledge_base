Then and now

The math of FlashAttention has not changed since 2022: exact attention, tiles, online softmax, recomputation. What changed four times is how it is mapped onto each new GPU, because each generation moved the bottleneck. Step through the versions; each card says what the previous one left on the table and quotes the paper that fixed it.

Speedups are each paper's own, on its own target GPU, against the previous version or the vendor library; they are not comparable across cards. Abstracts and quoted sentences are saved in src/inputs/later_extracts.txt.

Compiling IO-aware attention instead of hand-writing it

The paper's first limitation was that every attention variant needs its own CUDA kernel ({{§5|ax:S5}}). That became a research direction: Triton and torch.compile attention templates; FlexAttention, whose announcement names the problem directly ("You can no longer try out a new attention variant by writing a few PyTorch operators: you often need to write a new custom kernel!", {{PyTorch blog, August 2024|https://pytorch.org/blog/flexattention/}}) and which vLLM now lists as a backend of its own; and FA-4 itself, written in the CuTe DSL embedded in Python with 20 to 30× faster compile times than C++ templates.

Using it today

  • Most people never call it directly: PyTorch's built-in attention and the serving engines above pick a FlashAttention kernel when the GPU and the shapes allow.
  • The library is {{Dao-AILab/flash-attention|https://github.com/Dao-AILab/flash-attention}}, BSD 3-Clause. pip install flash-attn gives FlashAttention-2 (version 2.8.3.post1 on {{PyPI|https://pypi.org/project/flash-attn/}} on 3 October 2026), needing CUDA or ROCm, PyTorch 2.2 or later and Linux.
  • FA-3 is still described in the README as a beta for Hopper (H100, H800; CUDA 12.3 or later, 12.8 recommended), installed from the hopper folder: FP16 and BF16 forward and backward, FP8 forward.
  • FA-4 installs with pip install flash-attn-4 for Hopper and Blackwell, but every release on {{PyPI|https://pypi.org/project/flash-attn-4/}} is still a beta: 4.0.0b3 in March 2026 to 4.0.0b33 on 30 September 2026.
  • When it buys little: the paper's own numbers show the gain shrinking with head dimension 128 and on GPUs with less SRAM (T4), and vanishing against an already fused kernel at short lengths (within ±8% of Apex FMHA up to 512, {{Table 7|ax:A5.T7}}). The win is largest when N is long relative to d, which is the long-context regime.
