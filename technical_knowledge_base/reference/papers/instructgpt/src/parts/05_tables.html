The paper's numbers, rebuilt

The paper's results are mostly figures, not tables. Its arXiv HTML embeds every chart as vector graphics whose labels are text, so each bar, point and error bar below was decoded from the SVG's exact coordinates against its tick labels (decode_figs.py; the fit of ticks to labels is exact to 10-6), not read off an image. Tables are transcribed as printed. Every derived number is recomputed in recompute.py.
