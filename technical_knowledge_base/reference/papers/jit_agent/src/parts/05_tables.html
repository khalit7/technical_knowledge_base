Sampling noise where it can be computed

For success-rate metrics on a known number of tasks: standard error of a difference between two independent runs, √(p₁(1 − p₁)/n + p₂(1 − p₂)/n). Runs on the same tasks are positively correlated, so the paired error would be smaller; the paper gives no per-task results to compute it. F1, rubric and match-rate metrics are left out because their spread is unknown. Set sizes are the released repository's.

Scores that cannot be one pass over the released set

A success rate over N tasks is k/N; a printed score is "reachable" if some whole k rounds to it at one decimal.
