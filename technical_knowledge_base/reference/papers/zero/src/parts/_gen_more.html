Connected papers in this knowledge base

Megatron-LM

2019: the tensor-parallel baseline ZeRO measures against and composes with; ZeRO-R's P_a partitions Megatron's replicated activations.

GPT-3

2020: the scale regime (175B) this systems line made trainable.

FlashAttention

2022: a complementary attack on activation memory, at the kernel level rather than the sharding level.

Switch Transformers

2021: the mixture-of-experts route to parameter scale, orthogonal to state sharding.

T5

2019: the 11B model, trained with Mesh-TensorFlow model parallelism, that the paper calls the largest in the literature.

LoRA

2021: the other way to shrink the 12 bytes of optimizer state per parameter, by training far fewer parameters.

QLoRA

2023: adds paged optimizers and 4-bit frozen weights to LoRA, for fine-tuning on one GPU.

DeepSeek-V3 Technical Report

2024: trained with ZeRO-1 data parallelism alongside 16-way pipeline and 64-way expert parallelism.

The Llama 3 Herd of Models

2024: trained with FSDP that shards optimizer states and gradients but keeps parameters gathered between forward and backward.

Bounding the memory bottlenecks of large mixture-of-experts training

2026: bounds expert dispatch, vocabulary projection, activation checkpointing and optimiser state inside a fixed memory budget by scheduling when each tensor exists, where ZeRO partitions the same state.
