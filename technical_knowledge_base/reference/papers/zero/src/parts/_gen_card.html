ZeRO: Memory Optimizations Toward Training Trillion Parameter Models (ZeRO)

Samyam Rajbhandari, Jeff Rasley, Olatunji Ruwase, Yuxiong He
Microsoft · October 2019 (arXiv v1); v3 May 2020; published at SC20

In one line: ZeRO shards optimizer states, gradients, and parameters across data-parallel ranks (16 bytes/param for mixed-precision Adam down to 16 Psi/N_d at stage 3, at most 1.5x DP communication), making memory scale with cluster size and spawning DeepSpeed and FSDP.
