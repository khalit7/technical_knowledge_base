Quantise real weights

The paper's storage side, run on real LLaMA-7B weights in your browser: pick a matrix, a data type and a block size, and see where the weights land, how evenly the 16 values are used and what the rounding costs. Then the whole-matrix measurements, and two small-model experiments run for this page.

Try: block size 64 and each data type in turn (NF4 should have the lowest error and the highest entropy); then block size 2,048 (one block), where one outlier per block squeezes everything else towards zero; then layer 0's query projection, the heavy-tailed matrix.

Whole matrices, measured offline

The browser sample is 2,048 weights per matrix; these are every block of 64 of each whole matrix (16.8 to 45.1 million weights), with Appendix F's Shapiro-Wilk test rerun on every output unit (row) and every input column.

fetch_weights.py on huggyllama/llama-7b (LLaMA-1 7B, FP16). Relative squared error is Σ(q − w)² / Σw² over the matrix. Shapiro-Wilk at the 5% level; for samples this large the test is very sensitive, as Appendix F notes, so the share rejected in the middle layers (5.9 to 6.5%) is close to the 5% false-positive rate and to the paper's 7.5%, while the first and last matrices are clearly non-normal.
