The paper

NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness (arXiv HTML v1)

Technical report (preprint), the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(45 min)

Code: weights only, Apache 2.0. weights only, Apache 2.0

The repository holds the README, the report's PDF, two inference examples (chat and tool calls) and the later NeoHorse-Jev decision model. The 4B and 9B checkpoints are on Hugging Face (text-only BF16 weights, the vision tower of Qwen3.5 removed) with GGUF quantisations. No training code, curation pipeline, router, curriculum scores or training data are released.

(10 min)

Best resources

Agentic Routing: The Harness-Native Data Flywheel

Liu et al. (TokenRhythm), arXiv 2607.11399, 2026: the companion paper NeoHorse-1 builds on: the step-level router, the four-pass OpenSquilla routing stack (admission, demand construction, risk pricing, capability matching with an open LightGBM ranker), and the argument that every routing decision is a labelled training record.

(40 min)

OpenSquilla

TokenRhythm, GitHub, Apache 2.0: the open agent harness used to evaluate QwenClawBench and PinchBench here, with the cold-start router; the closest thing to the paper's harness that anyone outside the company can run.

(20 min)

NeoHorse-1-4B model card

TokenRhythm, Hugging Face: the released weights (Apache 2.0, text only), the SGLang and vLLM recipes and the evaluation tables; the 9B card is in the same collection.

(10 min)

On-Policy Distillation of Language Models: Learning from Self-Generated Mistakes

Agarwal et al., ICLR 2024 (arXiv 2306.13649): the method §4.3 extends: the student samples, the teacher scores every token of the student's own response, and a divergence such as reverse KL is minimised on those prefixes.

(40 min)

On-Policy Distillation

Thinking Machines Lab blog, October 2025: the clearest explanation of why on-policy distillation is dense like supervised learning but on the student's own states like RL, with per-token reverse KL as the reward; the background to Eq. 3.

(25 min)

TOUCAN: Synthesizing 1.5M Tool-Agentic Data from Real-World MCP Environments

Xu et al., arXiv 2510.01179, 2025: the public dataset Table 3 compares against; worth reading before trusting that comparison, since how a public set is sampled and serialised decides how it does in someone else's recipe.

(30 min)

Co-Harness: Co-evolving Harnesses and Model Weights for LLM Agents

Chen et al., arXiv 2607.22688, 2026: the closest related work the paper cites: harness and weights updated jointly, rather than the harness only supplying data.

(35 min)

Agent Lightning v1.0: Towards Harnessed Agentic RL

He et al., arXiv 2608.17528, 2026: keeps the RL environment loop inside the deployment harness: the RL counterpart of NeoHorse-1's supervised and distillation recipe.

(35 min)

Connected papers in this knowledge base

2026-09-14: tech news

the issue that covered this paper (Research and papers, with 412 Hugging Face upvotes at the time) next to MOLE and Φ-Bench; its check accepted the arXiv listing's "eleven benchmarks", which the paper's own tables put at ten.

HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

the other half of the loop: models building and evolving the harness rather than the harness training the model; its finding that visible gains moved with held-out gains only about half the time is the warning for any self-improvement loop judged on its own feedback.

Prime Agent: A Self-Improving RLM Harness

found that rich harnesses offer affordances models are not trained to use; NeoHorse-1 is one answer, training on the harness's own traffic.

JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

trained a model to emit harnesses, but in a language far poorer than a production one; NeoHorse-1 trains inside a production harness instead.

Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments

supplies the environments; NeoHorse-1 supplies the trajectories from live traffic instead of synthesised tasks.

Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills

supplies skills mined from repositories; together with Terminal-Universe and this paper, three different feeds into an agent's training.

Φ-Bench: Can Large Language Models Engineer the Infrastructure That Powers Them?

measures whether a model can build its own infrastructure and finds it mostly cannot; NeoHorse-1's loop keeps humans building the infrastructure and lets the model only learn from it.

MOLE: Detecting Insider Threats in AI Agents

asks what a loop like this does when it is subverted: an agent inside the organisation whose traffic becomes the next model's training data.

Learn What's Left, Not What's Mastered (SA-MRPO)

saturation-aware reweighting of RL training objectives: the same shape as capability-guided allocation (spend data where the model is still weak), arrived at from the training side.

Dream-RSI: Recursive Self-Improvement through Evolving Worlds

a later recursive self-improvement loop in which the environments evolve with the agent.

RRSI: Regularized Recursive Self-Improvement of Agent Harnesses

regularises a harness self-improvement loop against overfitting its own feedback, the failure mode a multi-pass NeoHorse loop would have to guard against.

Llama 3 Herd of Models

the iterative SFT, rejection sampling and DPO recipe with synthetic multi-step tool-use data that §2.1 names as the trajectory-SFT baseline approach.
