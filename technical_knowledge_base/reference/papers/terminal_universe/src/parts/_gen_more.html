Best resources

Terminal-Bench: Benchmarking Agents on Hard, Realistic Tasks in Command Line Interfaces

Merrill, Shaw, Carlini et al., ICLR 2026: The benchmark the headline is measured on; what an expert-built environment (container, instruction, verifier) looks like, which this paper tries to manufacture at scale.

Terminal-Bench leaderboard

harbor-framework on GitHub: The paper's footnote for how 2.1 differs from 2.0.

(5 min)

EvoCode-Bench: Evaluating Coding Agents in Multi-Turn Iterative Interactions

Shen et al., 2026: The multi-round benchmark behind MT@4 and the Case score: 26 tasks, 227 rounds, persistent workspaces, cumulative verifiers.

(25 min)

LFM2-Terminal-SFT-Processed

Hugging Face dataset, gyung: The source of 96% of the sufficient terminal environments. Every row this page sampled is a Terminus-2 rollout by DeepSeek-V3.2 on a generated task; open a row to see what a "trajectory" is here.

(10 min)

Tmax: A simple recipe for terminal agents

Ivison, Yin, Shao, Xiao, Lambert, Hajishirzi (Ai2), 2026: The strongest open comparison in Table 3 from a different route (combinatorial task sampling), with its own released recipe.

(30 min)

SWE-smith: Scaling Data for Software Engineering Agents

Yang et al., NeurIPS 2025 Datasets and Benchmarks: The perturbation route this paper contrasts itself with, and one of its SWE source corpora.

(30 min)

Training frontier knowledge-work agents: a 397B RL training guide with SkyRL

Mercor and SkyRL, filed in this knowledge base on 7 September 2026: The practitioner side: argues that environment robustness and harness design decide an RL run as much as the algorithm, which is the input this paper industrialises.

Connected papers in this knowledge base

EnvHarness: Awakening Static Worlds for Agent Learning

The complement: wraps existing frozen environments with composable Stage, Contract and Chain components and customises them against a policy's diagnosed weaknesses; Terminal-Universe manufactures new environments from artifacts nobody treated as environments. Together they cover supply and adaptation.

Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills

The same week, the same move applied to skills instead of environments: both mine artifacts that already exist.

HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

A harness-building model needs somewhere to practise; this is that somewhere.

StateM: Reaching 95.3% Raw Accuracy, or a $15 Frontier Run, on Terminal-Bench 2.1 via Harness Scaling

The same benchmark version from the harness side: how much of a Terminal-Bench 2.1 score the scaffold, not the model, can move.

Demystifying Agent Skills: Why They Work - Until They Don't

Another way to reuse recorded trajectories: distil them into skills at run time instead of rebuilding environments for training.

Schrödinger's Code Repository: Have LLMs Learned SWE-bench or Memorized It?

Why the decontamination step matters: benchmark repositories leak into training data. Terminal-Universe filters Terminal-Bench sources and SWE-bench Verified repositories.

Qwen3 Technical Report

The model family whose later members (Qwen3.5-27B, Qwen3.7-Max) are the student and the teacher here.

ReAct: Synergizing Reasoning and Acting in Language Models

Where the trajectory format comes from: interleaved reasoning, actions and observations, which is exactly what replay mines.
