The paper's tables and figures, rebuilt

Every table that carries the argument, parsed from the {{arXiv HTML|https://arxiv.org/html/2609.06966v1}} by mk_tables.py with the printed precision kept, and the figures' printed values read from the vector PDFs in the arXiv source (decode_figs.py; Figure 3 prints no numbers, so its bars are read from the vector rectangles, calibrated on the figure's own axis). recompute.py checks every derived number; the list is at the end.

Table 22 and Figure 8: cost against budget-AUC

{{Table 22|ax:A12.T22}}'s seven validation-selected strategies on each test corpus. The dashed line on the single-day view is the separate rarity-gated escalation study ({{Appendix L.4|ax:A12.SS4}}): (1.00, 0.304), (1.23, 0.391), (1.75, 0.407), (2.50, 0.449). During the search the best validation score was 0.513, at about 9.5× cost ({{Figure 16|ax:A12.F16}}); counting input lengths instead of a fixed token count moves costs by a few percent ({{Table 23|ax:A12.T23}}: selective routing 2.349×, sending 17.1% of account-days and 18.7% of tokens to GPT-5.5).
