# Visualisation ideas: Emergence World (Study 2)

The question the paper keeps returning to: when hostile content enters a long-running agent society, does recognising it stop the society acting on it? The released tool-call records make that measurable, so the live ingredient is a replay of those records rather than a toy model or an illustration.

Scores: reproduces a published figure (0 to 2, counts double), computable from released data (0 to 2, counts double), shows what a sentence cannot (0 to 2), measures the central question (0 to 2), step animation against an alternative (0 to 2), absent elsewhere (0 to 2), minus build cost (0 to 2).

What the Methodology lacked for this page: a rule for released logs. When a paper releases raw records, (1) deduplicate before counting (two files here repeat records exactly), (2) try each plausible counting rule and report which one reproduces each printed number (breach searches match "calls with a response" for three worlds and "all calls" for two), and (3) publish the classification rules beside any count that depends on them, with a hand-checked precision.
