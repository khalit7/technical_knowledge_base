Replay the MoE training run

The paper's iteration study and case study use one E2EO task: inside the full nanoGPT training system, on one H20, train the best mixture-of-experts language model you can in a fixed wall-clock budget while keeping at least a floor of total parameters; the score is validation bits per byte (BPB), lower is better ({{Performance over iterations|ax:Sx4.SSx3.SSS0.Px1}}). The released package fills in what the paper leaves out: the budget is 600 seconds of training, the floor 150 million parameters, and the shipped starter is a plain dense model at the floor, which a sparse top-k MoE beats only if its token dispatch is really fast on one card ({{task.toml|https://github.com/one2piece2hello/faibench_Frontier_InfraBench/blob/main/tasks/e2e/a3-moe-train-budget/task/task.toml}}).

Every value below is decoded from the paper's vector {{Figure 8|ax:Sx6.F8}} (each submission) and {{Figure 6|ax:Sx4.F6}} (best so far), using the figures' own gridlines; the decoded best-so-far curves match the authors' leaderboard data in 191 of 192 points.

Try: play Claude Opus 5, then switch to DeepSeek-V4-Pro on the same rounds. Watch the gap between each submission and the dashed "reference recipe" line, the only line that earns reward on this task.

Dots: each round's submission; crosses: submissions that failed the correctness check (plotted at the previous value, as in the paper). Step line: best so far. Horizontal lines, from the task's frozen constants in the {{released manifest|https://github.com/one2piece2hello/faibench_Frontier_InfraBench/tree/main/tasks/e2e/a3-moe-train-budget/task/tests}}: the dense starter's calibrated 1.955 BPB, the reference MoE recipe's 1.275 (reward 0 at or above it), and the about 1.22 the manifest calls the demonstrated in-budget ceiling. Full marks would need 0.831, below the 0.9 that the grader rejects as a forged loss. The plotted values are development measurements; the scored run uses a hidden split at the full budget, so the rewards here are indicative.
