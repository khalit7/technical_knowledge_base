Context Language Models (CLMs)

Rulin Shao, Shannon Zejiang Shen, Junjie Oscar Yin, Yuetai Li, Minheng Wang, Hamish Ivison, Radha Poovendran, Nathan Lambert, Teng Xiao, Mike Lewis, Wen-tau Yih, Luke Zettlemoyer, Pang Wei Koh
University of Washington, Meta Superintelligence Labs, MIT, Trillium Labs · 29 September 2026 (arXiv v1, the only version as of 19 October 2026)

In one line: Letting the model rewrite its own context as a file beats harness-side context management at lower cost in zero-shot runs (BrowseComp-Plus +11.4% accuracy with 21.5% fewer FLOPs) and makes context management learnable; after online RL the solid gain is cost (38.8% fewer FLOPs), since the +47.6% is measured against CLM's own untrained start and an equally trained summary harness is within noise.

How far to trust it: Believe the design (the live context as a file the model edits) and the FLOPs accounting, which reproduces to the digit. Treat the size of the accuracy wins as provisional: one run per setting, CLM alone gets retries, free editing turns and budget nudges, the RL win over a trained summary harness is 0.4 points, and on the 9B model zero-shot Self-Compact beats CLM on BrowseComp-Plus.
