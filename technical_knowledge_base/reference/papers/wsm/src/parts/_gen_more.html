The paper

WSM: Decay-Free Learning Rate Schedule via Checkpoint Merging for LLM Pre-training (arXiv HTML v2)

arXiv preprint, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(45 min)

Code

None released: the arXiv page links no code, and a GitHub search on 3 October 2026 found no repository. The method needs none beyond a weighted average of saved weights; this page's toy (the second tab) implements it in a few lines.

Best resources

Scaling Laws and Compute-Optimal Training Beyond Fixed Training Durations (Hägele et al., arXiv 2405.18392)

Alexander Hägele, Elie Bakouch, Atli Kosson, Loubna Ben Allal, Leandro von Werra, Martin Jaggi: background on why the decay phase is worth attacking: constant LR plus a short cooldown matches cosine, the 1-sqrt cooldown beats linear, and weight averaging as a partial substitute.

(45 min)

Model Merging in Pre-training of Large Language Models (Li et al., arXiv 2505.12082)

ByteDance Seed (reference 36 in the paper): the concurrent, purely empirical take: WMA, SMA and EMA merging during constant-LR pretraining, reaching the performance of an annealed model.

(40 min)

Understanding Warmup-Stable-Decay Learning Rates: A River Valley Loss Landscape Perspective (Wen et al., arXiv 2410.05192)

Kaiyue Wen, Zhiyuan Li, Jason Wang, David Hall, Percy Liang, Tengyu Ma: the river-valley picture behind the paper's canyon-and-river analogy (§4.4): a high constant LR makes progress along the river while bouncing between the canyon walls; decay or averaging settles onto the floor.

(40 min)

The Road Less Scheduled (Defazio et al., arXiv 2405.15682)

Aaron Defazio, Xingyu Yang, Harsh Mehta, Konstantin Mishchenko, Ahmed Khaled, Ashok Cutkosky: schedule-free optimisation: deletes the schedule by iterate averaging inside the optimiser, where WSM does it outside, on saved checkpoints.

(40 min)

Every Activation Boosted: Ling 2.0 technical report (arXiv 2510.22115), §3.2.3

Ling Team, Ant Group: the same lab's production use of WSM for Ling-mini-2.0, Ling-flash-2.0 and Ling-1T, plus the top-32-by-validation checkpoint average it added on top.

(15 min)

Connected papers in this knowledge base

The Llama 3 Herd of Models

Llama 3 405B annealed the LR linearly to 0 on its last 40M tokens and averaged checkpoints during the anneal (§3.4.3): exactly the Decay-then-Merge hybrid that WSM found adds nothing (Figure 5b).

DeepSeek-V3 Technical Report

keeps an EMA of the weights in CPU memory "for early estimation of the model performance after learning rate decay" (§3.2.3): WSM's evaluation-proxy use, already in production, with the EMA shape WSM ranks last.

Training Compute-Optimal Large Language Models (Chinchilla)

why cosine needs the run length up front: a cosine cycle longer than the run leaves the LR high at the end, which is how Chinchilla explained part of the gap to Kaplan's laws (Appendix B).

Scaling Laws for Neural Language Models

the cosine-to-zero schedules WSD and WSM were designed to replace.

2 OLMo 2 Furious (OLMo 2)

model souping at the end of mid-training: the same weight-averaging machinery, used as ensembling rather than as a schedule.
