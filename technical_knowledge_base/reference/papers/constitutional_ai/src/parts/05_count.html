Count the refusals

The paper says HH RLHF learned "canned responses like 'I can't answer that'" and that "RL-CAI is virtually never evasive" ({{§4.4|ax:S4.SS4}}), but gives no count. The repository releases 17 sampled answers from each of four 52B models on the same 66 prompts (40 PALMS sensitive questions, 13 LaMDA and 13 InstructGPT prompts), 4,488 answers in all, so the count can be made. The rule is deliberately plain so you can audit it: an answer is a canned refusal if it is short and contains a refusal construction ("won't", "cannot", "unable to", "not designed to", "do not understand" and a few more, listed in mk_data.py). Change the word limit, or drop the phrase test to count every short answer.

    What this count can and cannot say

    The repository does not say which training snapshot, which sampling temperature or which PM produced these files; the scores' scales differ by model (RL-CAI with CoT's are lower, consistent with clamped labels but not proof of it), so this page uses them only for order. The classifier is this page's, not the paper's, and is shown whole above; "contains I'm here to" counts a phrase, not whether the answer was good. The prompts are the paper's evaluation prompts from earlier work, not the red-team training distribution.
