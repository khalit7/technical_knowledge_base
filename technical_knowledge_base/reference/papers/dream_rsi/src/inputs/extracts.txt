== SimpleTES default budget

Unless otherwise stated, we use C=32 , L=100 , and K=16 as a default configuration.

total evaluation budget N=C\times K\times L has been decomposed into three scaling dimensions: global independent trajectories C , local sample size K , and the actual refinement depth L=\frac{N}{CK}

== GitHub README https://github.com/zhengkid/Dream-RSI (fetched 2026-10-03)

Algorithm engineering: 1.22x faster downstream runtime, 1.74x less discovery compute, 162x fewer calls than SimpleTES. Mathematical optimization: 2 of 3 tasks at or above the selected baseline.
