Equipping agents for the real world with Agent Skills

Anthropic engineering, 16 October 2025: the canonical description of the SKILL.md abstraction this paper dissects: progressive disclosure, the folder layout, and when to write a skill. Agent Skills became an open standard on 18 December 2025.

(15 min)

anthropics/skills

GitHub: the public skill repository the paper cites as its reference skill-usage protocol; useful for seeing what production skills actually contain (about 20 minutes for the README and a couple of skills).

(20 min)

SkillsBench: Benchmarking How Well Agent Skills Work Across Diverse Tasks

Li et al., arXiv 2602.12670: the benchmark behind the retrieval study and the worked example; its own paired evaluation (87 tasks, 18 model and harness configurations) finds curated skills raise the average pass rate from 33.9% to 50.5%.

(30 min)

SWE-Skills-Bench: Do Agent Skills Actually Help in Real-World Software Engineering?

Han et al., arXiv 2603.15401: the sceptical counterpart: 39 of 49 public skills give no pass-rate gain on real repositories, and three hurt through version-mismatched guidance, which is this paper's misapplication mode seen from outside.

(25 min)

Agent Workflow Memory

Wang, Mao, Fried, Neubig, arXiv 2409.07429: the workflow-memory representation this paper uses as its contrast arm, induced from past web-navigation trajectories.

(25 min)

Terminal-Bench: Benchmarking Agents on Hard, Realistic Tasks in Command Line Interfaces

Merrill et al., arXiv 2601.11868: the 89-task Terminal-Bench 2.0 used in two of the three benchmarks here, with its containerised tasks and test-based verification.

(25 min)
