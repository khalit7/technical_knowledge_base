Best resources

SkillOS: Learning Skill Curation for Self-Evolving Agents

Ouyang et al. (Google, UIUC), 2026: the closest prior work: an RL-trained write-time skill curator that needs grouped task streams for its delayed reward. Its Tables 1 and 2 are the source of most of JitMem's baseline rows.

(40 min)

ReasoningBank: Scaling Agent Self-Evolving with Reasoning Memory

Ouyang et al., ICLR 2026: the strongest heuristic write-time baseline: distil each trajectory into at most three strategy items, retrieve by embedding similarity. JitMem's 'w/o raw traj.' ablation uses its distillation prompt.

(35 min)

Memp: Exploring Agent Procedural Memory

Fang et al., Findings of ACL 2026: the third baseline: procedural memory items at several granularities, built, retrieved and updated at write time.

(30 min)

MemHarness: Memory Is Reconstructed, Not Replayed

Wu et al., 2026 (concurrent): the same read-time idea, but one GRPO policy both adapts the retrieved experience and executes the task, so it cannot be moved to another executor; JitMem's separate curator can.

(35 min)

Reflexion: Language Agents with Verbal Reinforcement Learning

Shinn et al., NeurIPS 2023: the origin of write-time verbal memory: after a task, write a reflection and reuse it next time.

(30 min)

Decocted Experience Improves Test-Time Inference in LLM Agents

Shen et al., 2026: query-independent lesson distillation; the source of the paper's 'higher information density, more efficient completion' reading of Table 4.

(30 min)

Understanding R1-Zero-Like Training: A Critical Perspective (Dr. GRPO)

Liu et al., COLM 2025: why JitMem drops GRPO's standard-deviation normalisation of advantages.

(30 min)

ALFWorld: Aligning Text and Embodied Environments for Interactive Learning

Shridhar et al., ICLR 2021: the household benchmark; the 140 'valid_seen' games are the test set, six task types. This page's stream replay uses their real goal texts.

(25 min)

ALFWorld game files (json_2.1.1_tw-pddl.zip)

ALFWorld release 0.2.2: where the 140 test goals on this page come from (valid_seen, solvable games).

(10 min)

WebShop: Towards Scalable Real-World Web Interaction with Grounded Language Agents

Yao et al., NeurIPS 2022: the shopping benchmark: 500 test instructions, a 0 to 100 attribute-match score, and success when the score is 100.

(25 min)

tau2-Bench: Evaluating Conversational Agents in a Dual-Control Environment

Barres et al., 2025: the airline, retail and telecom customer-service benchmark used without training in Table 2.

(30 min)

Connected papers in this knowledge base

Proactive Memory Agent: selective reminding for long-horizon agents

decides when to remind an agent of something it already holds, inside one task; JitMem cites it as arXiv 2607.08716 (Wu et al. 2026b) and contrasts in-session with cross-task memory.

SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness

context compaction found by an auto-research loop: it shrinks what is carried forward, the opposite design choice to keeping trajectories raw.

JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

the same just-in-time move one level up: synthesise the harness itself per task at inference time instead of fixing it in advance.

Demystifying Agent Skills: Why They Work, Until They Don't

finds skills distilled from the same trajectories beat raw workflow memory handed to the agent. JitMem never hands raw traces to the executor either: it distils them, just later.

Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills

write-time distillation at library scale: knowledge fixed into skills before any task asks for it.

Trained Persistent Memory for Frozen Encoder-Decoder LLMs

memory folded into a fixed latent bank at write time, with the write rule untrained; the opposite end of the design space from raw storage.

End-to-End Context Compression at Scale (Latent Context Language Models)

query-independent compression of context, learned end to end: what JitMem argues against for cross-task memory.

Agora: Git as Shared Memory for Collective AutoResearch

an append-only raw record as shared memory: keep everything, decide what matters when it is read.

ReAct: Synergizing Reasoning and Acting in Language Models

the reason-then-act executor loop and the original agent results on ALFWorld and WebShop.

Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

the general pattern underneath: store raw, retrieve at query time, let the reader condition on the query.

DeepSeekMath (GRPO)

where GRPO, the group-relative advantage JitMem trains its curator with, was introduced.
