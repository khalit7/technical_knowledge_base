Run the modules

A toy copy of the paper's architecture, trained offline and running in your browser: a frozen "large" model that knows 560 arithmetic facts and never explains them, and a trainable bridge plus "small" decoder that learned, from 140 reasoning traces, to explain them. Two trained versions ship with the page: as released (the cross-attention masks padding only, as in {{model.py|https://github.com/k-kolomeitsev/LLM-Modules/blob/main/model.py}}) and fixed (a causal mask added). Everything else is identical, including the training data, steps and seed.

The toy, in one paragraph
Facts: a + b for a, b in 0 to 19, and a % b for a in 0 to 19 and b in 2 to 9. The frozen model (2 blocks, width 48, 60,432 parameters; Qwen2-1.5B's role) is pretrained on all of them in a brief format after a random prefix, so it knows them anywhere in a text: it answers %%big_in_trace%% of them correctly at the answer position of a reasoning trace it never saw. The trainable side copies model.py at a smaller width: pre_proj, proj, the intermediate MLP, 2 Enhanced Cross-Attention layers (4 heads, adapter width 12, sigmoid gate), a GPT-Neo-style decoder (2 blocks, width 32, no attention scaling, zeroed positional embeddings, its token embeddings unused) and a new output layer: 51,872 trained parameters. Traces exist for 140 facts (25%); 56 are for picking the learning rate; the other 364 appear in no trace and are the test. The loss covers every token, prompt included, as in model.py.
