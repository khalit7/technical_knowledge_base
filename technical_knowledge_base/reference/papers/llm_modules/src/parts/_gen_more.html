The paper

LLM Modules: Knowledge Transfer from a Large to a Small Model using Enhanced Cross-Attention (arXiv HTML v1)

arXiv preprint (cs.CL), not peer reviewed, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(15 min)

k-kolomeitsev/LLM-Modules (GitHub)

the whole method is one file, model.py (979 lines, MIT licence), plus the full model outputs the paper's Table 1 summarises (compare-responses-from-models.md). The same files and the 7.2 GB checkpoint are on Hugging Face (kkolomeitsev/llm-modules), where they sit behind an access request; the GitHub copy is open. About 25 minutes for model.py and the outputs.

(25 min)

Best resources

How to Teach a Model to Reason Without Overtraining It, for Less Than $10

Kolomeitsev (the author's blog post): the same work told informally, with what the paper leaves out: one NVIDIA L4 for about 5 hours, under 10 dollars, how the GPT-Neo controls were trained, and the reshuffle rule.

(10 min)

Flamingo: a Visual Language Model for Few-Shot Learning, Section 2.2

Alayrac et al., DeepMind, 2022: the careful version of "a frozen model, read through new cross-attention": gated cross-attention layers inserted into a frozen language model, the gate starting at zero so training begins from the unchanged model.

(30 min)

LLM Augmented LLMs: Expanding Capabilities through Composition (CALM)

Bansal et al., Google, 2024: two frozen models joined by trained cross-attention at several layers, evaluated on real benchmarks against fine-tuned baselines; the large anchor model reads the small one, the opposite direction.

(40 min)

Distilling the Knowledge in a Neural Network

Hinton, Vinyals, Dean, 2015: the distillation this paper sets itself against: train a small student on a large teacher's softened outputs.

(30 min)

Parameter-Efficient Transfer Learning for NLP (adapters)

Houlsby et al., 2019: the bottleneck adapter the paper's "Adapter Block" copies (down, non-linearity, up, residual), here inserted into a frozen BERT.

(30 min)

Bespoke-Stratos-17k (dataset card)

Bespoke Labs, 2025: the training data: 16,710 questions with DeepSeek-R1's reasoning traces and answers (math, code, science, puzzles), made for fine-tuning Qwen2.5 7B and 32B.

(10 min)

Connected papers in this knowledge base

DeepSeek-R1

2025: the teacher behind both sides of the comparison. Bespoke-Stratos-17k is R1's reasoning traces, and DeepSeek-R1-Distill-Qwen-1.5B is a Qwen model fine-tuned on 800,000 of them.

Bitune

adjacent in the same batch: a pretrained model read a second way, with small trained adapters and a learned mix.

Trained Persistent Memory for Frozen Encoder-Decoder LLMs

adjacent in the same batch: trainable memory attached to a frozen backbone instead of retraining it.

LoRA

2021: the cheap way to adapt the large model itself, which the paper cites but never compares against.

QLoRA

2023: LoRA on a 4-bit frozen model; fine-tunes a 1.5B model on one small GPU, the missing like-for-like baseline.

Attention Is All You Need

2017: the encoder-decoder cross-attention (queries from one stream, keys and values from another) the Enhanced Cross-Attention is built from, and the causal mask it leaves out.

T5

2019: cited by the paper for transfer learning; an encoder read by a decoder through cross-attention, trained end to end.

CLIP

2021: the kind of frozen encoder later joined to language models by adapters (Flamingo, LLaVA).
