LLM Modules: Knowledge Transfer from a Large to a Small Model using Enhanced Cross-Attention (LLM Modules)

Konstantin Kolomeitsev
Independent researcher, Almaty, Kazakhstan · arXiv v1 12 February 2025 (the only version); code and weights released 11 to 13 February 2025

In one line: Freeze Qwen2-1.5B, pass its last hidden states through two trainable cross-attention layers with an adapter and a gate, feed the result into a GPT-Neo-sized decoder trained on Bespoke-Stratos-17k reasoning traces: on two arithmetic prompts the pair writes R1-style reasoning that GPT-Neo trained alone does not.

How far to trust it: Read it as an idea, not a result. The evidence is two hand-picked prompts, one sample each, graded by the author. The released code adds problems the paper does not mention: its cross-attention lets every position see later tokens during training, so the loss curves cannot show learning; once the training subset starts being redrawn, the validation set is mostly reused training data; the "small" model is initialised at random rather than from GPT-Neo-125M, and running the pair takes 1.14 times the parameters of the frozen model alone. The idea of a frozen model read by a trained adapter is sound; Flamingo and CALM show it working with real evaluations. The evidence, judged.
