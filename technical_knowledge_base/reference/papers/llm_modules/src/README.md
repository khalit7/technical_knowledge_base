# LLM Modules: page source

`sh build.sh` writes `../index.html`, the whole body of the Notion row page (https://app.notion.com/p/3ce5c17b0d0d810191d0ebcffc54f608, a row of the Papers database; its properties Paper, Takeaway, Topics and Year stay in Notion). The row page has no child pages, databases or video. Built from `html_utils/methods/papers.md` with the reference folder's shared pieces, taken from the Bitune page's copies (`01_css`, `05z_errbox`, `10_js_common`, `11_js_ui`, `90_js_tabs`, `mk_paper.py` with the verdict line, `build.sh`, `check_page.mjs`, `extract_paper.py`; `mk_coverage.py` with this paper's own item list).

## Departures from papers.md, and why

- **The live ingredient tests the released code, not only the paper's text.** The paper is an architecture paper (the table's first row), so the toy is the architecture, built exactly as `model.py` builds it at a smaller width. But the code differs from the text in four places (the cross-attention sits in front of GPT-Neo, not in its stack; GPT-Neo is randomly initialised; the cross-attention has no causal mask; sequences are cut at 2,048), and the missing mask decides what the paper's only quantitative evidence (the loss) means. So the toy trains the released version and the fixed version side by side, plus the controls the paper did not run (the small model alone, plain cross-attention, the frozen model fine-tuned instead, one linear layer). The task was designed before training to need the frozen model's knowledge at exactly one step (the answer after "="), and was not tuned afterwards.
- **"The paper's tables, rebuilt" became "The evidence, rebuilt".** The paper has one qualitative table and no figures; what carries the argument is the released transcripts, the data pipeline and the parameter count, so the tab rebuilds those.
- **No "Then and now" tab**: a 2025 preprint with no descendants; the family it belongs to (Flamingo, CALM, adapters, distillation) is one table in "Why it matters".
- **The card's one-line takeaway is corrected**, not copied from the Takeaway property, which says the cross-attention layers are inserted into GPT-Neo and that GPT-Neo-125M is trained (it is a randomly initialised copy of its architecture). The property itself stays in Notion; Khalid may want to edit it.

## Files

- `live.md`: the Notion fetch of 2026-09-20, written from the session's tool result unchanged (the reference folder's `save_live.py`, which copies it from the session transcript, could not be used here: reading the transcript file was not permitted). `extract_paper.py` (arXiv HTML v1 to `inputs/paper_v1.txt` and `inputs/table_S5_T1.txt`).
- `stratos_stats.py`: the dataset through model.py's pipeline (filter, 2,048 cut, loss tokens, 30% subset redraws and validation overlap under every reshuffle scenario) to `inputs/stratos_stats.json`. Needs the 125 MB parquet and Qwen2's tokenizer.json downloaded to a scratch directory (not kept).
- `recompute.py`: every parameter count, the checkpoint-size check, the data numbers the page shows, to `inputs/recompute.json`. Inputs: the two configs, `stratos_stats.json`, `inputs/repo_facts.json` (the model.py lines the page cites, the checkpoint size, the tokenizer length).
- Toy: `train.py` (`pretrain`, `lr`, `finetune`, `export`), `check_forward.py` (the JS forward pass in node against PyTorch on identical 6-bit weights), `mk_toydata.py` (`parts/_gen_toy.js` and `inputs/toy_summary.json`, whose values build.sh substitutes for `%%key%%` in the prose, so the text always matches the last run). `model/` (828 KB) holds the frozen model `big.pt`, the seed-0 weights of the two shipped variants (`ft_released_s0.pt`, `ft_causal_s0.pt`, what export needs), `results.json` (every seed of every variant), `lr.json`, the logs and `check_forward.json`; the other seeds' weights are not kept (remove their keys from `results.json` and rerun `finetune` to regenerate them; `extras` needs the bigft seeds); `q_*.pt` (the dequantised float64 weights check_forward.py loads) are regenerated by export and git-ignored.
  - `uv run --with torch --with numpy python train.py pretrain` (about 3 minutes on 2 threads), `... train.py lr` (24 runs, about 18 minutes), `... train.py finetune` (18 runs, about 15 minutes), `... train.py export`, `... check_forward.py`; then `sh build.sh`.
- `paper.json`, `tables.json` (Table 1, the model list, the eleven graded transcripts), `mk_paper.py`.
- `inputs/`: paper text and table, the two configs, `compare-responses-from-models.md` and `repo_LICENSE.txt` (the released outputs, MIT), `blog_extract.txt` (the author's blog post as text), `repo_facts.json`, `stratos_stats.json`, `recompute.json`, `toy_summary.json`.
- Parts: `03_paper`, `04_run`, `05_tables`, `13_js_read` (diagram, size reveal, tiles, toy and family tables), `20_model_data` (generated weights), `22_js_model` (forward pass), `23_js_run`, `24_js_tables`, `26_js_leak` (the animation).
- `check_page.mjs` (node, from the repo root): every control in both themes and widths, the animation stepped, the in-browser test run. `mk_coverage.py`: `coverage.json`.
