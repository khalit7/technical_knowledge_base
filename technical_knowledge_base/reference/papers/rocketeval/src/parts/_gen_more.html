The paper

RocketEval: Efficient Automated LLM Evaluation via Grading Checklist (arXiv HTML v1)

ICLR 2025 (poster), the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(45 min)

Joinn99/RocketEval-ICLR

MIT-licensed code: checklist creation, grading through vLLM or any OpenAI-compatible API, the score predictor and rankings; data (queries, checklists, responses, GPT-4o labels and a few example gradings) on Hugging Face as Joinn/RocketEval. About 20 minutes for the README and score.py.

(20 min)

Best resources

OpenReview: RocketEval (ICLR 2025)

OpenReview: the accepted version, its abstract and the reviews. The reviews load only in a browser; this page could not read them, so the old summary's note that they press hardest on instance-level agreement is unconfirmed here.

(30 min)

WildBench: Benchmarking LLMs with Challenging Tasks from Real Users in the Wild

Lin et al., ICLR 2025: the benchmark whose 1,024 real queries, per-query checklists and GPT-4o grades RocketEval builds on; its checklist idea is where RocketEval starts.

(45 min)

Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena

Zheng et al., NeurIPS 2023: MT-Bench, its 3,355 expert votes (the human judgments RocketEval's agreement numbers use) and the original catalogue of judge biases.

(45 min)

Chatbot Arena: An Open Platform for Evaluating LLMs by Human Preference

Chiang et al., ICML 2024: how the Arena Elo ratings that serve as ground truth here are fitted (Bradley-Terry), with bootstrap confidence intervals.

(45 min)

Replacing Judges with Juries (PoLL)

Verga et al., 2024: the neighbouring result: a panel of small judges from different families beats one large judge at a fraction of the cost.

(45 min)

CheckEval: Robust Evaluation Framework using Large Language Model via Checklist

Lee et al., 2024: an earlier checklist-of-Boolean-questions evaluator, with fixed, human-curated checklists rather than per-query ones.

(30 min)

Prometheus 2: An Open Source Language Model Specialized in Evaluating Other Language Models

Kim et al., EMNLP 2024: the fine-tuned 7B judge that RocketEval beats with untuned small models; the other way to make a small judge.

(40 min)

Joinn/RocketEval dataset

Hugging Face: queries, GPT-4o checklists, responses and GPT-4o grades for four benchmarks, and a few example gradings by small judges: the files this page re-analyses.

(10 min)

Evaluate an LLM with RocketEval in Colab

Wei et al.: the authors' notebook: run checklist grading with a small judge end to end on a free GPU.

(20 min)

Ollama v0.12.11 release notes: log probabilities

Ollama: 12 November 2025: Ollama's native and OpenAI-compatible APIs return token log probabilities, which is what reading P(Yes) and P(No) on a local model needs.

(5 min)

Connected papers in this knowledge base

LLM-as-judge: design, biases, calibration, reliability

the bias catalogue (position, verbosity, self-preference) that explains why removing the channel works, and where RocketEval sits among judge designs.

Constitutional AI

the same shape one level up: a written list of principles stands in for human judgment, at training time instead of evaluation time.

Demystifying Agent Skills

a checklist here is a procedural anchor there: writing the procedure down is what transfers, and its misapplication failure mode is the one to expect from a spec the executor half understands.

StateM

"expensive artifact, cheap execution" in the harness layer: an expensive run writes a runbook that a cheaper model follows.

JIT-Agent

a trained model synthesises a harness that a cheaper executor runs: the same economics again.

PagedAttention (vLLM)

the serving engine the paper runs its small judges on; prefix caching is what makes grading every checklist item separately cheap.
