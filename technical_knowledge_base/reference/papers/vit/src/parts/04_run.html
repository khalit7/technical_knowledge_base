Run a ViT

A real Vision Transformer, built exactly as Eq. 1 to 4 say, trained offline at toy scale and running here in plain JavaScript. The task makes every answer checkable: each 28 × 28 image holds three outline shapes (ring, square, triangle, plus, x), two of the same kind, and the model must name the kind that appears twice. That needs both local work (recognise a shape from its strokes) and global work (compare shapes far apart), which is what attention from the class token is for.

How the toy was built, and what it costs

  • Model (Eq. 1 to 4): 4 × 4 patches (49 tokens plus a class token), D = 32, 4 layers, 4 heads, MLP 128 (4D, as in Table 1), pre-LayerNorm, tanh-approximated GELU, learnable 1D position embeddings, y = LN(zL0) and a zero-initialised linear head (the paper's fine-tuning head; there is no separate pre-training stage here).
  • Baseline: a BiT-style ResNet (GroupNorm, a stride-2 stem, three residual blocks of 16, 32 and 48 channels, global average pooling). It is not shipped; only its accuracy and curves are.
  • Training (§4.1, §4.3 recipe at toy scale): AdamW, β1 0.9, β2 0.999, weight decay 0.1, 100 warmup steps then linear decay, batch 128 (the paper's 4096 is far beyond this task), 2,000 steps for every training-set size, early stopping on 2,000 validation images. No augmentation, dropout or label smoothing.
  • Honesty checks:
  • Data: the generator in this page (the same file made the training data with node), so drawn images are exactly the training distribution; training, validation, test and this tab's test use disjoint seed ranges. Two images from different seeds can coincide only by chance, which is negligible given random sizes, positions, intensities and noise.
