Connected papers in this knowledge base

StateM: Reaching 95.3% Raw Accuracy, or a $15 Frontier Run, on Terminal-Bench 2.1 via Harness Scaling

the opposite design from the same fortnight: a checked state-machine runbook around a fixed agent, where Prime Agent hands the model a REPL and subagents. Its page finds the same pattern of a benchmark-tuned upper bound.

HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

the general test of what Continual Harness does: when a model refines its own harness from feedback, the score it can see moved the same way as the held-out score in only 34 of 64 version changes.

NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness

the training-side answer to Prime Agent's closing claim that models are not trained to use their harness: it turns harness traffic into a training curriculum.

JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

complementary: Prime Agent hands a rich harness to an untrained model; JIT-Agent trains a 27B model to write the harness for each task.

Demystifying Agent Skills: Why They Work - Until They Don't

Continual Harness generalises SKILL.md from procedures to prompts, memories and subagent specifications, and inherits the misapplication failure that paper measured.

2026-08-31: tech news

the issue that added this paper to the knowledge base, with JIT-Agent, WikiSkill and Apodex 1.1, under "harness scaling became a research programme".

2026-08-24: tech news

the week before: Nvidia's Agentic Variation Operators result (Opus 5, 30% to 100% on ARC-AGI-3) and StateM.

RRSI: Regularized Recursive Self-Improvement of Agent Harnesses

a later attempt to keep self-editing harnesses from overfitting, the risk Prime Agent's refinement loop runs.
