Rescore the ARC-AGI-3 run

The authors released one trace: the {{scorecard of their median Opus 5 run|https://arcprize.org/scorecards/2af780b4-f2a1-43e9-a794-b23da3cd3f9f}} (95.2% in the blog; the best of the three runs, 95.5%, is the paper's headline). ARC Prize serves every scorecard's per-level data: for each of the 25 public games, how many levels the agent completed and how many actions each level took, beside the human baseline for that level. This tab recomputes the score from those numbers with the {{ARC-AGI-3 paper's|https://arxiv.org/abs/2603.24621}} RHAE formula, lets you change the rules, and puts the run beside the ten community scorecards on the same games (fetched 2026-10-03; their scores are self-reported and the ARC Prize Foundation does not verify them).

The rule, as the scorecards apply it. For level l of game e, with the agent's actions a and the upper-median human's h:

S = min(1.15, (h / a)p)   with p = 2,  0 for a level not completed

E = min( Σl ≤ k wl / Σ wl,  Σ wl Sl / Σ wl )   with wl = l, k levels completed

RHAE = mean of E over the 25 games

The cap of 115% lets a level done more efficiently than the human make up for a weak one in the same game; the first term caps a game at the weighted share of its levels completed. The ARC paper's Equation 1 writes the cap inside the square, min(1.15, h/a)2, which would allow 132%; its own text says levels score "between 0% and 115%", and every scorecard here matches the text, so the page uses that.
