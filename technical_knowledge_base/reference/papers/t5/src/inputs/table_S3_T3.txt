Table 3: 
Examples of inputs and targets produced by some of the unsupervised objectives we consider applied to the input text “Thank you for inviting me to your party last week .”
Note that all of our objectives process tokenized text. For this particular sentence, all words were mapped to a single token by our vocabulary.
We write (original text) as a target to denote that the model is tasked with reconstructing the entire input text.
<M> denotes a shared mask token and <X>, <Y>, and <Z> denote sentinel tokens that are assigned unique token IDs.
The BERT-style objective (second row) includes a corruption where some tokens are replaced by a random token ID; we show this via the greyed-out word apple.
