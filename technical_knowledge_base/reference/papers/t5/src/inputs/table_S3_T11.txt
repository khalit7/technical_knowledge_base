Table 11: 
Comparison of multi-task training using different mixing strategies.
Examples-proportional mixing refers to sampling examples from each data set according to the total size of each data set, with an artificial limit ( $K$ ) on the maximum data set size.
Temperature-scaled mixing re-scales the sampling rates by a temperature $T$ .
For temperature-scaled mixing, we use an artificial data set size limit of $K=2^{21}$ .
