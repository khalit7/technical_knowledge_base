Best resources

Evaluating Very Long-Term Conversational Memory of LLM Agents (LoCoMo)

Maharana et al., ACL 2024: the benchmark this paper evaluates on: how the conversations were generated, the five question types, and the text-memory and RAG baselines (GPT-3.5 with retrieved observations reaches 41.4 F1).

(40 min)

LoCoMo data and code

Snap Research: the released 10 conversations (locomo10.json) with per-answer evidence turns; this page's lag and overlap counts come from it.

(15 min)

MemGPT: Towards LLMs as Operating Systems

Packer et al., 2023: the text-level memory system the paper positions itself against: paging facts in and out of the context window.

(40 min)

Flamingo

Alayrac et al., NeurIPS 2022: gated cross-attention inserted into a frozen LM, zero-initialised so training starts from the frozen model; the template for M.2 and M.5.

(30 min)

Memorizing Transformers

Wu et al., ICLR 2022: extends attention with a kNN-retrieved cache of past keys and values; the KV-extension idea behind M.3, with real long-range retrieval.

(30 min)

Linear Transformers Are Secretly Fast Weight Programmers

Schlag, Irie and Schmidhuber, ICML 2021: the outer-product (Hebbian) write that M.4 uses, and why a plain sum of outer products runs out of capacity: the delta rule fix.

(35 min)

Learning to Compress Prompts with Gist Tokens

Mu, Li and Goodman, NeurIPS 2023: compressing a prompt into a few learned latent tokens: the compression-into-latents relative of this paper's bank.

(25 min)

Learning by Distilling Context

Snell, Klein and Zhong, 2022: context distillation: moving what a prompt says into the weights instead of into a memory.

(25 min)

OpenClaw: Memory overview

OpenClaw docs: the text-level memory personal agents actually ship: plain Markdown files (MEMORY.md, USER.md, daily notes), no hidden state.

(10 min)

Hermes Agent: Persistent Memory and Memory Providers

Nous Research docs: bounded MEMORY.md and USER.md injected at session start, plus pluggable external providers (Honcho, mem0 and others).

(10 min)
