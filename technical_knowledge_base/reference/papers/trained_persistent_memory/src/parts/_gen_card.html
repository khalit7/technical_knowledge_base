Trained Persistent Memory for Frozen Encoder-Decoder LLMs: Six Architectural Methods (latent-space memory pilot)

Hong Jeong
Inha University in Tashkent, Uzbekistan · 17 March 2026 (arXiv v1, the only version)

In one line: Proof-of-concept pilot putting memory in a frozen encoder-decoder's continuous latent space rather than in text, so writes and reads are differentiable; six variants across three injection points and four write mechanisms, with the bank accumulating at inference without gradients. LoCoMo forgetting-curve: stateless baseline scores zero, all six adapters positive at 10x capacity. No RAG or text-memory baseline, single backbone.

How far to trust it: Read it as a map of the design space, not as evidence that latent memory works. The headline metric cannot go below zero, the zero baseline is zero by construction, three of six methods make answers worse at 1x, the write rules of five methods as written all but erase a turn within about 100 turns while 62% of test questions sit 256 or more turns back, it is one seed on about 639 questions with no text or retrieval baseline, and several ranking statements contradict the paper's own tables. The evidence, judged.
