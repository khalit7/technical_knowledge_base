Table 3: memory recall rate by evidence lag

[[S6.T3|Table 3]]

Recall rate in %, isotonic-smoothed as printed ({{Table 3|ax:S6.T3}}). "Mean" is the paper's column, which is the unweighted average of the five buckets; "weighted" averages over questions (28, 24, 62, 130 and 395 per bucket), recomputed here. "± SE" is the largest possible standard error of the weighted mean for a 0-to-1 score, √(p(1 − p)/n) per bucket; it ignores the isotonic pooling and seed-to-seed variation, so the real uncertainty is larger. Bold: best in the column.
