Agora: Git as Shared Memory for Collective AutoResearch

Yifan Zhang, Yunheng Zou, Shaokun Zhang, Jian Hu, Hao Zhang, Binfeng Xu, Jan Kautz, Yi Dong
NVIDIA · arXiv v1 16 September 2026; v4 (read here) 30 September 2026

In one line: Record collective agent research as an append-only DAG of Git commits, so every claim is a commit anyone can check out and rerun; 13 workers over 12 days published 1,703 contributions, cut the evaluator from 3.39 to 1.899 bits per byte, and 165 independent reproductions failed zero times.

That is the database's Takeaway, written from an earlier version. Version 4 is more careful: 165 verification posts by accounts other than the author, covering 95 targets and 141 distinct verifier and target pairs, none reporting a failure; an unposted failed attempt would leave no trace (§4.5, §4.8).

Verdict: Believe the record-keeping design, and the 3.39 to 1.90 drop as one archived run (our own CPU rebuild of the recipe's first stage gets close to it). Do not read the paper as evidence that Agora makes agent research better: there is one task, one run and no comparison, and the human changes made mid-run cannot be separated from the effect of the diversity views.
