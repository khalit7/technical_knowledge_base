The paper

EnvHarness: Awakening Static Worlds for Agent Learning (arXiv HTML v1)

Preprint, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(45 min)

Code: google-research/envharness, Apache-2.0. google-research/envharness, Apache-2.0

Released with the paper (repository created 7 August 2026, last push 21 August 2026): the ActionableEnv interface, the three components (named Setup, Rules and Link in the code), six Bridges (Toy24, ALFWorld, SWE-bench, OfficeQA, SpreadsheetBench, WebArena; the paper counts seven with WebShop, which appears only as an adaptation inside the optional verl-agent patch), the designer agent, per-benchmark corpus configs with their designer prompts, reproduce scripts, and the GRPO integration with verl-agent for ALFWorld. The configs default to gpt-4.1-mini; the paper's tables used Gemini. The README and the entry path take about 20 minutes.

(20 min)

Best resources

EnvHarness project page, with a live playground

the authors, envharness.com, August 2026: the paper's idea in short sections, plus an in-browser Python playground on the 24 game where you edit a Stage, Contract or Chain and apply it to a live Toy24Env: the release's own reference environment, complementary to the household toy on this page.

(15 min)

google-research/envharness README

GitHub, Apache-2.0: the practical entry point: provider setup, the per-benchmark reproduce scripts, how to add a Bridge or a new harness layer, and the results tables. The corpus.yaml files hold each benchmark's designer prompt and acceptance rule.

(20 min)

ReasoningBank: Scaling Agent Self-Evolving with Reasoning Memory

Ouyang et al., arXiv 2509.25140, 2025 (same group): the skill extraction and retrieval pipeline every skill-learning result here runs through; EnvHarness changes only where the trajectories come from.

(40 min)

GenEnv: Difficulty-Aligned Co-Evolution Between LLM Agents and Environment Simulators

Guo et al., arXiv 2512.19682, 2025: the ALFWorld baseline: an LLM simulates the environment at the edge of the agent's ability. EnvHarness's main argument against it is that simulated transitions and verdicts can drift.

(35 min)

Safe and Scalable Web Agent Learning via Recreated Websites (VeriEnv)

Chae, Park and Ritter, arXiv 2603.10505, 2026: the WebArena baseline: clones websites into executable synthetic environments with programmatic rewards.

(30 min)

SWE-smith: Scaling Data for Software Engineering Agents

Yang et al., arXiv 2504.21798 (NeurIPS 2025): the SWE-bench baseline: synthesizes new repository task instances by breaking working code. Figure 5 compares it with EnvHarness at equal environment counts.

(40 min)

Emergent Complexity and Zero-shot Transfer via Unsupervised Environment Design (PAIRED)

Dennis et al., arXiv 2012.02096, NeurIPS 2020: the classic statement of the problem EnvHarness inherits: environments should be designed against the current policy, at the edge of what it can do.

(35 min)

Prioritized Level Replay

Jiang, Grefenstette and Rocktäschel, arXiv 2010.03934, ICML 2021: the curriculum view: replay the levels with the most learning signal. EnvRigger's band of target success rates is a hand-written version of the same idea.

(30 min)

Don't Just Fine-tune the Agent, Tune the Environment

Lu et al., arXiv 2510.10197, 2025: the closest earlier work on reshaping what the environment says back to the learner (corrective feedback, reward shaping), which the paper cites as hand-designed.

(30 min)

Effective harnesses for long-running agents

Anthropic engineering blog, 2025: the agent-harness side of the paper's central analogy, one of the three harness write-ups it cites.

(15 min)

verl-agent

GitHub, langfengQ: the RL framework the release patches, at a pinned commit, to run GRPO inside EnvHarness environments: ALFWorld by default, with WebShop only in the optional full patch.

(15 min)

Connected papers in this knowledge base

Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments

the authoring route EnvHarness argues against: build 37,300 new terminal environments from recorded agent runs. EnvHarness instead wraps the environments that already exist and keeps their verifiers; the two could combine (wrap the generated worlds).

HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

the agent-harness side of the analogy, measured: models building and evolving the wrapper around a frozen model. Its warning that evolution gains are unstable and executor-specific applies to EnvRigger's write-and-validate loop as well.

NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness

another way to close the loop between a harness and training data: the serving router orders a curriculum. EnvHarness closes it on the environment side, with diagnosed weaknesses choosing the next environment.

DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models

where GRPO comes from, the algorithm of the RL experiment (Table 4).

DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

the RL with verifiable rewards lineage; EnvHarness keeps rewards verifiable by never touching the original verifier.

Demystifying Agent Skills: Why They Work - Until They Don't

the skill abstraction EnvHarness feeds through ReasoningBank-style extraction; its finding that skills act as procedural anchors fits the skills shown in Appendix F, which are procedures forced by the components.

ReAct: Synergizing Reasoning and Acting in Language Models

the think-then-act interaction loop the policies here run (the ALFWorld policy is prompted to reason in think tags, then act); ReAct also introduced ALFWorld as an LLM-agent benchmark.
