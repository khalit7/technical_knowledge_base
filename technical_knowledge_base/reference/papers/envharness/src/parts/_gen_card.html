In one line: An agent harness for environments: wrap frozen training environments with composable Stage/Contract/Chain components at the reset/step interface (keeping the trusted human-built verifier) while EnvRigger auto-customizes them against the target policy's diagnosed weaknesses, beating static and generated environments for skill learning and GRPO RL and still scaling where they flatten.

How far to trust it: Believe the design: wrapping a frozen environment at its reset/step interface keeps the original verifier, ports across five very different benchmarks, and the released code does what the paper says. Treat the sizes of the gains as provisional: most single margins sit within three-run noise, the RL comparison is one run per arm, and the paper's own Figure 5 shows the original environments gaining as many tasks as EnvHarness after the first 100 environments.
