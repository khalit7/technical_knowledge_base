Connected papers in this knowledge base

HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

the benchmark for exactly what StateM's hyper-agent does by hand: build a harness, then evolve it from feedback. Its main warning (the score a creator can see moved with the held-out score in only 34 of 64 changes) is the risk StateM's Terminal-Bench numbers carry, and it names StateM among the harness-scaling results it was written to test.

Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments

turns agent trajectories into 37,300 terminal environments and fine-tunes Qwen3.5-27B on them for +11.9 on Terminal-Bench 2.1: the model-side route to the benchmark StateM attacks from the harness side.

Demystifying Agent Skills: Why They Work - Until They Don't

skills-as-files: procedural knowledge an agent may or may not follow. StateM's answer is to make the procedure an enforced transition instead of advice.

ReAct: Synergizing Reasoning and Acting in Language Models

the reason-act-observe loop that CLI agents such as Codex still run inside each StateM state.

EnvHarness: Awakening Static Worlds for Agent Learning

the same August 2026 harness-over-model wave, on the environment side.

JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

harness evolution at run time rather than between versions.

Prime Agent: A Self-Improving RLM Harness

another self-improving harness from the same month.

SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness

automated loops that improve a harness, the step StateM leaves to a hyper-agent plus human golden rules.

RRSI: Regularized Recursive Self-Improvement of Agent Harnesses

Proactive Memory Agent: selective reminding for long-horizon agents
