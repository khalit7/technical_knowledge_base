Run a toy BERT

A real BERT, built as {{§3|ax:S3}} says (learned token, position and segment embeddings; post-LN encoder layers with GELU and a 4H feed-forward; the masked-LM head tied to the token embeddings; a tanh pooler and NSP layer on [CLS]), at toy scale: L = 2, H = 24, A = 4, parameters. It was pretrained on a made-up English with the paper's two objectives and masking rule, then fine-tuned with one output layer, and it runs here in plain JavaScript on its exported weights. Beside it, the same model pretrained left to right (the paper's "LTR & No NSP"), so the paper's central ablation can be run on any sentence you build.

The toy language, and why it is built this way

Eight names (austin, paris, jordan, sydney, florence, chelsea, victoria, georgia) are each a person or a place equally often, so the name alone says nothing. Context decides: a cue before the name ("we flew to austin", "i met austin") or a cue after it ("austin is a city", "austin has a cold"). Animal sentences fix the animal by a verb after it (dog barked, cat purred, duck quacked, cow mooed). Pretraining text comes in documents about one entity, so next sentence prediction has something to learn. The fine-tuning task tags each name PER or LOC, like CoNLL NER; half of every cue list is kept out of the labelled data (never out of pretraining), to test what pretraining transfers. Tag the names

Both taggers were fine-tuned from their pretrained model with one new 3-way layer on every token, on the same 128 labelled sentences (seen cues only), learning rate chosen on dev as the paper does ({{§4.1|ax:S4.SS1}}). The left-to-right tagger keeps its causal mask, as in Table 5.
