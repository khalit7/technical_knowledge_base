One agent session, with and without routing

The same five requests in a Java codebase, run twice. Without routing, Claude reads every file itself, so the text stays in its context and is re-read on every later turn. With the post's routing, a PreToolUse hook blocks any Read of a file over 350 lines and sends the files to a bulk-reader mode on a cheap worker model, which returns a short summary; boilerplate goes to a code-writer mode that writes straight to disk. Targeted reads, edits and reasoning stay with Claude. Both lanes are drawn to one scale: the full bar is 70,000 tokens.
