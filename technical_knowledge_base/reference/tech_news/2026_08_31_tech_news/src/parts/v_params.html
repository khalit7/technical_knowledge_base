This week's models, counted every way

A mixture-of-experts model has two sizes: all the parameters you must store, and the few that each token uses. Headline counts and checkpoints do not always agree: Qwen3.8-Flash-Next's 125B leaves out 51B of n-gram embeddings and a 4B prediction head that the checkpoint holds. Switch the count, then pick a precision to turn parameters into bytes; "as shipped" uses the actual mix of number formats in each Hugging Face checkpoint.

NVFP4 is counted as 4 bits per value plus one 8-bit scale per 16 values (4.5 bits), applied to every weight, which overstates the saving for real builds that keep some layers in higher precision. Weights only: no KV cache, activations or runtime overhead.
