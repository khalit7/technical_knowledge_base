One agent turn, two architectures: V4-Flash against V4.1-Flash

The same turn of an agent loop: a tool result of tokens arrives that is not in the cache, the model reads it (prefill), keeps its cache, then writes its reply (decode). Each row of the grid is one layer, drawn to scale (43 for V4-Flash, 40 for V4.1-Flash); the wide block is the prompt, all its tokens processed together layer by layer, and each narrow column on the right is one generated token. V4-Flash is decoder-only: every prompt token runs every layer and 41 layers each keep their own cache. V4.1-Flash splits the stack: the prompt runs only the 20 encoder layers, the decoder's cache is projected once from the encoder's output, and only the last 128 prompt tokens are replayed through the decoder. Play V4-Flash first, then switch.

Where the factor of four comes from

The global cache each prompt token leaves in HBM, built up one change at a time from the two models' config.json files. Each bar is to scale.

Defaults reproduce DeepSeek's published 890 bytes per token for V4.1-Flash and 3,514 for V4-Flash (the {{V4.1-Flash report|https://arxiv.org/abs/2609.19969}}, Figure 1) independently, from the {{V4.1-Flash|https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash}} and {{V4-Flash|https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731}} configs (layer counts, compress_ratios, kv_source_layer_ids, head and indexer widths) with the entry sizes worked out in {{zartbot's breakdown|https://zartbot.github.io/blog/model_arch/dsv41flash_arch/en.html}} (src/recompute.py); the same arithmetic gives the report's 437x against DeepSeek LLM 67B. The prompt's layer passes follow the report's own formula, N x L against N x L/2 + 128 x L/2. Derived: parameter compute is 2 x active parameters per token (13B for V4-Flash, 8B for V4.1-Flash's encoder and 8B more for its decoder), spread evenly over the layers; attention compute, which grows with context, is left out. Published, not recomputed: the persistent cache ratio (about 1/8: SWA cache no longer persisted, which nearly halves it, times the 1/4 global cache).
