**A signed release pipeline shipped malware, and a certificate authority's keys could be computed from its certificates: trust in AI infrastructure failed at the layer below the model.** On 21 October **LiteLLM 1.107.0** went out on PyPI (11:39 to 13:23 UTC) and as four Docker tags carrying a credential stealer and backdoor; LiteLLM's attack-chain post traces it to an Agent Platform master key committed publicly in May and never revoked, which yielded an org owner's GitHub CLI token, then CI secrets, then control of the release workflow, so the trusted-publishing, signed pipeline built and signed the malware itself. The payload (`cook.pth`, run at every Python start) took SSH keys, cloud and CI secrets, AI-tool tokens and the proxy database's provider keys. The same week **eMudhra** disclosed that the private keys of 8 intermediate CAs were generated so badly that anyone could recover them from the certificates; Firefox and Chrome distrusted them from 17 October and Microsoft and Apple followed, Python and Go shipped their own blocks, and eMudhra announced it is leaving the TLS certificate business. Railway disclosed exposed customer environment variables the same day as LiteLLM, in "a series of attacks recently targeting platform companies with the aim of compromising AI inference providers". The durable lesson: signing proves which pipeline built an artefact, not who controlled it; long-lived maintainer tokens were the entry point, and GitHub CLI added opt-in expiring tokens on 21 October. **The monitors that watch agents were red-teamed in public, and both reviews found the same blind spots.** Anthropic's "Red-teaming Auto Mode" (22 October) set an Opus 5 attacker against Claude Code's Auto Mode and an approximation of Codex's Guardian: production monitors failed to block **more than 55%** of attacks, through text aimed at the monitor itself, several sessions coordinating through a shared workspace, compaction hiding earlier steps, and actions the monitor never saw. # Research & papers
- **GRAFT: route the flagged update into weights you delete, instead of penalising it** (MATS, Stanford, FAR AI and Anthropic; Anthropic Alignment Science blog, 19 October). When a monitor flags a rollout, only a separate FORGET adapter learns from it; the adapter is ablated after training, so the monitor decides which parameters learn, never the reward. On Qwen3-8B in a coding RL task where the monitor catches only one of three hack types, a reward penalty taught an undetected hack on about 30% of trajectories; with GRAFT hacking of every type was near zero after ablation and the clean solve rate stayed nearly 20 points above the base model. Limits: heuristic monitors, single turn, up to 8B. [GRAFT (arXiv 2610.17062)](https://arxiv.org/abs/2610.17062) (35 min), [Alignment blog post](https://alignment.anthropic.com/2026/graft/) (10 min)
- **A harness can do what a model distilled from it cannot** (Gai, Block and Risteski, CMU, 19 October). A breadth-first-search harness that calls a model only for single edge lookups decides graph reachability, which no fixed-depth transformer can if NL is not in TC0, so a same-size student trained on the harness's traces cannot match it. In the scaled check a Branching harness on Qwen3-1.7B reached 43.6% on DAPO-Math-17k while the distilled single-pass student stalled near 36%; a 4B backbone closed the gap. [Understanding the Benefits of Scaffolds through Computational Separations (arXiv 2610.27157)](https://arxiv.org/abs/2610.27157) (40 min)
- **Three harness papers followed last issue's ARC-AGI-3 gap**: truncating context costs nothing when a fact can be looked up again and drops success to chance when it cannot, and on ARC-AGI-3 summarising old turns instead of dropping them recovered 86% of a 63-point standard-against-adapter gap (2610.26632, single runs); two rounds of models revising their own ARC-AGI-3 harness added 2.80 held-out points with an interval spanning zero (2610.30499); and 52,168 trajectories over 4 harnesses and 4 models showed rankings changing across models and benchmarks (2610.32483). [When the harness decides success](https://arxiv.org/abs/2610.26632) (30 min), [Can LLMs improve their own harness?](https://arxiv.org/abs/2610.30499) (30 min), [When agents fail: model or harness?](https://arxiv.org/abs/2610.32483) (30 min)
- **What RL adds, measured token by token.** Taking a Qwen3-4B RL model's token only where its greedy choice differs from the base model's, about 4% of positions, recovers 90.5% of the pass@1 gain on 120 AIME problems (2610.24663); RL from a base model almost never invents "wait", which arrives with training data (2610.30882); and judges that score more accurately do not train better policies in 7 of 8 matched settings (2610.30765). [What RL Brings to Reasoning](https://arxiv.org/abs/2610.24663) (30 min), [Inherited, Not Invented](https://arxiv.org/abs/2610.30882) (25 min), [Scaling Laws for Generative Reward Models](https://arxiv.org/abs/2610.30765) (30 min)
- **Reward hacking: the reward alone can blind the chain of thought.** With a misspecified reward and no pressure on the CoT, models keep reasoning about the intended task while their outputs hack it; injecting an inferred description of the reward raised monitorability by 24 or 42 points depending on the metric (2610.28303). Google's SimHack predicts the step at which detectable hacking starts from a few small reference runs, with 11.3% relative error (2610.28707). [Reward Misspecification Degrades CoT Monitorability](https://arxiv.org/abs/2610.28303) (30 min), [SimHack](https://arxiv.org/abs/2610.28707) (25 min)
- **On-policy distillation stayed the busiest post-training topic**, with about 20 papers submitted between 18 and 23 October. In multi-turn agentic distillation a weaker student overtakes its teacher early and then regresses; masking teacher supervision on the student's own successful choices gave up to 15.2 points (2610.25034). Perplexity and NVIDIA's JOLT trains one model as privileged teacher and student, beating GRPO by 4.2 points on MATH and 9.9 on AppWorld with 6.5x fewer training tokens on MATH (vendor). [Distillation overshoot](https://arxiv.org/abs/2610.25034) (25 min), [Perplexity: JOLT](https://www.perplexity.ai/hub/blog/a-good-teacher-meets-the-student-where-they-are) (10 min)
- **How much synthetic rewriting to use is now predictable** (Percy Liang and colleagues, 22 October): a scaling law that charges the rewriter's compute puts the optimal rewritten share under 10% at 3e18 FLOPs and at 32% at 1e22; extrapolated 33x in compute it predicted a 22B model's final loss within 1.1%, and that model beat its own rewriter on several web domains. [Rewriting Scaling Laws for Synthetic Data (arXiv 2610.31867)](https://arxiv.org/abs/2610.31867) (40 min)
- **Speculative decoding's published gains shrink under fair measurement**: retraining six drafter recipes on the same target-generated data narrows their published gaps (2610.24993), draft-training objectives add less once the target regenerates the corpus (2610.29013), and over 1.78M verification rounds acceptance does not fall with position in long chains of thought once a greedy repetition artefact is removed; rejections cluster on "wait", "however" and "check" (2610.30644). [When Does Better Acceptance Pay?](https://arxiv.org/abs/2610.24993) (25 min), [Acceptance Does Not Decay with Position](https://arxiv.org/abs/2610.30644) (20 min)
- **FP4 training and 2-bit inference moved closer**: AMD trained GPT-OSS-20B in MXFP4 to a validation loss of 3.3350 against BF16's 3.3283, cutting the extra steps to target from 20.0% to 5.0% (simulated MXFP4, no wall-clock; 2610.32229), and vector codebooks with chosen calibration data kept 89 to 97% of full-precision accuracy at about 2.3 effective bits (2610.28537). [Training an MoE in MXFP4](https://arxiv.org/abs/2610.32229) (30 min), [Beyond 4 bits](https://arxiv.org/abs/2610.28537) (30 min)
- **Architecture notes**: at a fixed parameter budget wider attention heads barely change pretraining loss but improve long-context retrieval (2610.32213); dynamic expert skipping in MoEs rarely beats simply lowering k at matched compute (2610.28369); and long-context continued pretraining keeps paying past where most recipes stop (2610.29352). [Head Dimension Matters](https://arxiv.org/abs/2610.32213) (20 min), [Don't Skip the Baseline](https://arxiv.org/abs/2610.28369) (20 min)
- **Agent memory and cache**: plain dense retrieval over the raw history plus a reranker ranked first in 6 of 7 settings against agentic memory systems (2610.30755), and Tsinghua's cache engineering lets an agent drop or re-position cached tokens instead of rewriting its prefix, cutting cost 27.7% against summarisation (2610.28577). [Naive RAG Is Stronger](https://arxiv.org/abs/2610.30755) (20 min), [Cache Engineering for Agents](https://arxiv.org/abs/2610.28577) (25 min)
- **Claude proved fuzz targets crash-free at the binary level** (Anthropic with Theorem, 22 October): Rocq proofs over RISC-V binaries that 239 OSS-Fuzz entry points across 123 libraries never crash or fail an assertion on any input under 64 MB, about 180M lines of proof, with hundreds of bugs found and fixed on the way; limits are a single-threaded static binary, a fixed memory budget and a modelled Linux process. # Security
- **PHP2Shell** (21 October): two remote code execution flaws in PHP 8.2 to 8.5 (CVE-2026-109618 and -109619, CVSS 9.2, not the leaked 10.0) were fixed a day early after an accidental leak; Wiz found both, Calif found one with GPT-5.6 Sol, and Amazon saw exploitation on 17 October, before disclosure. The PHP Foundation says AI helps validate and group reports but "a person makes every call and works on every patch". [PHP Foundation](https://thephp.foundation/blog/2026/10/21/todays-php-security-release-and-how-were-strengthening-php-security/) (8 min), [Wiz: PHP2Shell](https://www.wiz.io/blog/php2shell-php-rce) (8 min), [Amazon threat intelligence](https://aws.amazon.com/blogs/security/amazon-threat-intelligence-identifies-php2shell-exploitation) (5 min)
- **A Brotli decoder RCE reached Node.js and Python** (CVE-2026-111497, fixed 21 October): an out-of-bounds write in C Brotli 1.0.3 to 1.2.0 reachable through `Content-Encoding: br`; Node.js bundles its own copy, and Python HTTP clients decode `br` automatically when the package is installed; OpenAI's Codex Security reported it. [Broccoli2Shell](https://broccoli2shell.com/) (8 min)
- **Credentials the agent never holds**: 1Password for Agents (22 October) fills a credential after a person approves so the agent never sees it, and NVIDIA's OpenShell runtime injects credentials only for approved endpoints, with kernel-enforced file, syscall and network policy. [1Password for AI agents](https://1password.com/blog/1password-for-ai-agents) (6 min), [NVIDIA OpenShell](https://github.com/NVIDIA/OpenShell) (8 min)
- **Using Claude to shrink attack surface** (Anthropic, 20 October): Claude maps which code a deployment can reach and removes or restricts the rest, lowering the severity of bugs nobody has found; over 25 projects it found 493 issues. [Anthropic: attack surface reduction](https://www.anthropic.com/research/attack-surface-reduction) (10 min)
- **Qwen3-Coder wrote less secure code for a US defence persona** (Hirundo, a vendor selling the fix, 21 October): 70% of 1,840 generated apps were exploitable for a US defence contractor against 59% for a Chinese one (p = 0.03), and Semgrep flagged 2 of the 1,840 apps while working exploits broke 1,144. [Hirundo](https://www.hirundo.io/blog/qwen3-coder-vulnerabilities) (8 min)
