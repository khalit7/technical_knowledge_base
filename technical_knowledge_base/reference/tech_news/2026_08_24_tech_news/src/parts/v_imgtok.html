How many image tokens can one request carry?

Each image is resized and then costs at most a fixed number of tokens, counted image by image, so the ceiling for a request is a product. Move the number of images; switch to the limits as documented on 2026-10-02 to see what changed after the issue.

Formula: request image tokens at most = images x cap per image. Caps and the 600-image limit from the {{docs archived 2026-08-21|https://web.archive.org/web/20260821125242/https://api-docs.deepseek.com/guides/vision/}} and the {{current docs|https://api-docs.deepseek.com/guides/vision/}}. Smaller images cost fewer tokens (they are scaled to a pixel budget), so this is an upper bound. The defaults reproduce nothing published; 230,400 is derived.
