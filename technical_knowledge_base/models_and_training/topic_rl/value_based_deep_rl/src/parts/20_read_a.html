The idea in one screen

Value-based deep RL is Q-learning with a neural network in place of the table. Because one update now moves the values of other states, including the state its own target was read from, DQN made the problem look like supervised regression again (a replay buffer of past transitions and a frozen target network), and every later method repairs one failure that remained.

Every method on this page changes one part of DQN's training loop

  1. Act. The emulator's last 4 frames (84 × 84, greyscale) go into the online network θ, which outputs one Q-value per action; the agent takes the argmax, or a random action with probability ε (annealed from 1.0 to 0.1).
  2. Store. The transition (s, a, r, s′) joins the replay buffer, which keeps the last 1M.
  3. Sample. A minibatch of 32 is drawn uniformly at random from anywhere in the buffer, so consecutive, nearly identical frames rarely train together.
  4. Target from the frozen copy. The target network θ− reads s′ and gives (2.0, 3.5, 3.0) for three actions; with r = 1 and γ = 0.99 the target is y = 1 + 0.99 × 3.5 = 4.465 (section 3's example).
  5. Regress the online network onto it. θ says Q(s, a) = 4.0: a TD error of 0.465, a Huber loss and one gradient step on θ, never on θ−.
  6. Copy every C. Every C = 10,000 updates the online weights are copied into the target network; in between, the targets stand still.
  7. Where each later fix acts. NoisyNet changes how the agent acts (§9), multi-step what is stored as a target (§7), prioritised replay what is sampled (§6), dueling and distributional the network's head (§5, §8), Double DQN how the target picks its action (§4). Rainbow (§10) turns all six on.

The loop is DQN 2015 as published (Mnih et al., Nature); the numbers in steps 4 and 5 are section 3's worked update. Drag the figure to turn it.

1Why a network breaks Q-learning

A table needs one entry per state. Go has about 2 × 10170 legal positions ({{Tromp|https://tromp.github.io/go/legal.html}}); an Atari screen is 210 × 160 pixels in a 128-colour palette ({{Mnih et al. 2015, Methods|https://storage.googleapis.com/deepmind-media/dqn/DQNNaturePaper.pdf}}), and two screens that differ in one pixel share nothing in a table. So the table becomes a function q̂(s, a, w) ≈ Q(s, a): an update at one state also moves similar states, including ones never visited. That generalisation is the point, and the problem. TD learning then differentiates only the prediction, not the bootstrapped target:

w ← w + α [ Rt+1 + γ v̂(St+1, w) − v̂(St, w) ] ∇w v̂(St, w)
semi-gradient
the target is treated as a constant although it depends on w ({{Sutton and Barto §9.3|http://incompleteideas.net/book/RLbook2020.pdf#page=225}}); it is not the gradient of any objective, which is why it can fail
Q-learning version
maxa′ q̂(St+1, a′, w) as the target and ∇w q̂(St, At, w) as the gradient: the update DQN performs on minibatches

With on-policy data and linear features this converges, to the TD fixed point, within a factor 1/(1 − γ) of the best fit the features allow (proof and conditions on {{Model-free prediction and control|n:3c65c17b0d0d81898a0cd4c05c744969}}); at γ = 0.99 that factor is 100 derived. A network trained on RL data breaks the three assumptions of supervised learning, and each fix in the figure above answers one of them:

  • Correlated data. Consecutive transitions are nearly identical; stochastic gradient descent assumes roughly independent, identically distributed (i.i.d.) samples. Answer: replay.
  • Moving targets. The target r + γ maxa′ Q(s′, a′; θ) uses the weights being trained, so each update moves what it chases. Answer: the target network.
  • Data that depends on the policy. "If the maximizing action is to move left then the training samples will be dominated by samples from the left-hand side", and the parameters "could get stuck in a poor local minimum, or even diverge catastrophically" ({{Mnih et al. 2015, Methods|https://storage.googleapis.com/deepmind-media/dqn/DQNNaturePaper.pdf}}). A bad update makes bad data, which makes worse updates.
Kinds of approximator, and why Monte Carlo regression is safe (1 min)
  • Linear in features: v̂(s, w) = w⊤x(s) with hand-made features: polynomials, Fourier bases, coarse coding, tile coding (several overlapping grids, one active tile per grid), radial basis functions ({{Sutton and Barto §9.4 to 9.5|http://incompleteideas.net/book/RLbook2020.pdf#page=226}}). The gradient is simply x(s). One-hot features recover the table exactly: tabular learning is linear approximation with no generalisation.
  • Neural networks: the features are learned too. DQN's network reads the last four 84 × 84 greyscale frames and outputs one Q-value per action in one forward pass. Nothing in the classical convergence theory covers this case.

Monte Carlo regression onto returns is ordinary supervised learning: the target Gt does not depend on w, so SGD on the squared error is a true gradient method. The bound for linear TD is VE(wTD) ≤ minw VE(w) / (1 − γ) ({{Sutton and Barto eq. 9.14|http://incompleteideas.net/book/RLbook2020.pdf#page=229}}, from {{Tsitsiklis and Van Roy 1997|https://www.mit.edu/~jnt/Papers/J063-97-bvr-td.pdf}}).

2The deadly triad, and how often it bites on Atari

Function approximation, bootstrapping (targets built from current estimates) and off-policy training together can make value estimates diverge: "if any two elements of the deadly triad are present, but not all three, then instability can be avoided" ({{Sutton and Barto §11.3|http://incompleteideas.net/book/RLbook2020.pdf#page=286}}); it appears even in prediction, and even in dynamic programming with a known model, and with the on-policy distribution of updates convergence is guaranteed (§11.2). Q-learning with replay has all three. The mechanism, with two states that read one weight as w and 2w (each off-policy update multiplies w by 1 + α(2γ − 1)) and Baird's seven-state counterexample with each leg switchable, is drawn on {{Model-free prediction and control|n:3c65c17b0d0d81898a0cd4c05c744969}}, Reading section 7. This section is DQN's side of it.

Less than the theory suggests. {{Van Hasselt et al. 2018|https://arxiv.org/abs/1812.02648}} ran 336 configurations of DQN variants on all 57 Atari games, three replications each, about 20M frames per run. With rewards clipped to [−1, 1] and γ = 0.99 no true value exceeds 1/(1 − γ) = 100, so estimates beyond that are soft divergence. Estimates "frequently grew quickly to over a million" and came back down; no run became unbounded.

Fixes that keep all three elements: gradient-TD and emphatic TD (under 1 min)

In the linear case, gradient-TD methods (GTD2, TDC) descend the projected Bellman error, and emphatic TD reweights updates toward the on-policy emphasis ({{Sutton and Barto §11.7 to 11.8|http://incompleteideas.net/book/RLbook2020.pdf#page=300}}). They are provably stable with linear features but "have mostly not been extended to non-linear function approximation, and have not been widely adopted in practice" (van Hasselt et al. 2018). Deep value methods instead live with the triad and tame it with the engineering below.

Share of runs that soft-diverged, by bootstrap target (labels printed on their Figure 2 transcribed): Q-learning 61%, inverse double Q 33% (corrects overestimation but bootstraps on the online network), DQN's target 14%, Double DQN's 10%.
