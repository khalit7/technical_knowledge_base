## Decisions worth knowing

- Seeds: mulberry32 streams keyed `hs(seed, purpose, index)`; purposes 11 (gridworld samples), 21 (5-state walks), 31 (19-state walks), 40 to 42 (cliff agents).
- The sampled gridworld methods share one stream, so TD(0) and Monte Carlo see identical episodes. The two random-walk methods see identical walks. The cliff agents have separate streams (their trajectories diverge anyway).
- Figure 4.1 needs synchronous sweeps; in-place sweeps give different intermediate values.
- Policy iteration keeps the current action when it is among the greedy ties, so it does not cycle between equally good policies.
- The cliff's alpha (0.5) is assumed: the book does not state it.
