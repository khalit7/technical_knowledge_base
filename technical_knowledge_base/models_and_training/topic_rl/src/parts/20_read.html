Reinforcement learning in one screen

Every RL method estimates the same thing, the expected return that the Bellman equation describes, and improves its behaviour against that estimate; the methods differ in what they put in place of the expectation (an exact model, a sampled return, one step plus a guess, a learned critic, a search, a group of answers) and in what they store. Reinforcement learning is learning to act from a score rather than from a correct answer, which makes it the tool for problems whose behaviour can be judged but not demonstrated: games, control and, since InstructGPT in 2022, the post-training of language models.

1The problem, and the words every page uses

Three things set RL apart from supervised learning ({{Sutton and Barto, §1.1|http://incompleteideas.net/book/RLbook2020.pdf#page=23}}; {{Silver, Lecture 1|https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/intro_rl.pdf}}). The feedback is a score, not a label: it says how good an action was, not which action was right. The feedback can be delayed: a chess move is rewarded only when the game ends, so the agent must work out which earlier action earned a later reward (the credit assignment problem). And the agent's own actions decide what data it sees next, so it must trade exploiting what it knows works against exploring to find something better. The agent maximises cumulative reward, so it can pay now to gain later. All of this rests on the reward hypothesis, that every goal can be written as maximising expected cumulative scalar reward; for language models "helpful" has no formula, so training maximises a proxy (a learned reward model, a test suite, a judge), and a policy that optimises a proxy hard enough finds shortcuts such as longer answers, flattery or special-cased tests: reward hacking, the subject of {{Reward Hacking|n:3c65c17b0d0d8196a6f1f29a817aa974}}.

At each step t the agent sees an observation and a reward, chooses an action At, and the environment answers with the next observation and the reward Rt+1 (the reward for At arrives at t + 1, in Silver's and Sutton and Barto's indexing). It maximises the return, the discounted sum of future rewards:

Gt = Rt+1 + γRt+2 + γ²Rt+3 + ... = Rt+1 + γGt+1
γ ∈ [0, 1]
the discount: a reward k steps away counts γk as much (steps 4 to 6 of the figure).
  1. The agent sees a state. The environment hands the agent its observation St (teal).
  2. It acts. The agent picks an action At (orange) from its policy, and the environment moves.
  3. The world answers, one step later. The next observation St+1 and the reward Rt+1 for At (green) come back together; the loop repeats until the episode ends.
  4. Rewards further away count less. Unrolled in time, the return adds every later reward, the one k steps away weighted γk: the bars are those weights at γ = 0.9, and each stream carries a reward back to step t. The weights sum to 1/(1 − γ), so γ = 0.9 looks about 10 steps ahead derived.
  5. γ = 0.99 looks about 100 steps ahead. The weights barely fall: the last of the 30 steps drawn still counts 0.9929 ≈ 0.75 derived, so the agent plans far, and every distant reward's noise enters its estimate.
  6. γ = 1 for language models. Language-model RL uses γ = 1, because every response ends and the reward comes at the end: every weight is 1, and the single reward at the last token flows back whole.
State, Markov, partially observable
what the agent summarises its history into; Markov if the future depends only on it. A single Atari frame is not (it shows where the ball is, not where it is going); a poker hand is partially observable; a language model sees its whole prefix, so generation is fully observable.
Markov decision process (MDP)
states, actions, transition probabilities, rewards and γ: the formal object every page solves.
Policy π(a | s)
how the agent acts.
State value Vπ(s), action value Qπ(s, a)
the expected return from a state, or after taking a there. Picking the best action from Q is a lookup, while from V it needs a model of where each action leads, which is why model-free control learns Q. Reward is not value: in Silver's student example a lecture costs −2 now yet the state is worth +1.5, because it leads toward passing ({{Silver, Lecture 2|https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-2-mdp.pdf}}).
Learning and planning
in learning the environment is unknown and the agent improves by interacting; in planning a model is known and the agent improves by computing with it, for example by searching a game whose rules are known.
Bootstrapping
building a target from the agent's own current estimate of the next state, instead of waiting for the real return.
On-policy, off-policy, offline
learning from the current policy's own experience; from anyone's, including old data; from a fixed dataset with no interaction at all. Off-policy is not offline: Q-learning is off-policy yet learns online.

2One target, many estimators

Take expectations of Gt = Rt+1 + γGt+1 and you get the Bellman equation: the value of a state is the immediate reward plus the discounted value of where you land, on average.

Vπ(s) = 𝔼π[ Rt+1 + γVπ(St+1) | St = s ]
𝔼π
an average over the actions π chooses and the next states the environment produces. Replace the average by a max over actions and you get the optimality equation, whose solution is the best policy's value.

No agent can compute that expectation unless it knows the environment. So every method substitutes something for it and nudges its estimate toward that substitute, the target: V(St) ← V(St) + α (target − V(St)). Policy-gradient methods use the same substitutes as the weight on "make that action more likely". Rows jump to the family's section:

MethodWhat stands in for the expectationBias and variance
Dynamic programmingThe exact expectation over a known modelExact; needs the model
Monte CarloThe whole sampled return to the end of the episodeUnbiased; high variance
TD(0), SARSA, Q-learningOne real reward plus the current estimate of the next state (SARSA: the action actually taken next; Q-learning: the best next action)Biased by the estimate; low variance
n-step, TD(λ), GAEA blend: n real rewards, then the estimateA dial between the two above
DQNThe Q-learning target, computed by a frozen copy of the networkAs Q-learning, plus approximation error
REINFORCEThe sampled return, optionally minus a baselineUnbiased; high variance
Actor-critic, PPOAn advantage from a learned critic: the TD error, or GAE's blend of themLower variance; biased by the critic
AlphaZero, MuZeroA tree search: its improved move distribution and the game's outcomeBetter than the raw networks, at a large compute cost per move
GRPOThe response's reward minus the mean of a group of responses to the same prompt, divided by their standard deviationMonte Carlo with a sampled baseline; no critic
RLVRAny of the above, with the reward from a program that checks the answerNo reward-model error; checkable tasks only

Why there is a dial. A target built from real rewards is unbiased but carries every step's randomness; a target that stops after one step and trusts the estimate carries little randomness but inherits whatever error the estimate has. Short targets win when the estimate is good, long ones when it is poor. This one trade-off runs through five of the eight pages, so it is drawn here once, on one episode. Predict, before the figure reaches step 4: with the estimates as given, will Monte Carlo's target for S0 be above or below TD's? Then move the V(S1) slider below the steps to see which targets follow it.

  1. The episode. S0 → S1 → S2 → end, γ = 0.9, rewards 0, 0, 1 (green) and the agent's current estimates 0.2, 0.4, 0.7 (blue). Every method builds a different target for S0 from it, on the row in front; the streams show what each target is made of.
  2. TD(0): one real reward, then trust the estimate. R1 + γV(S1) = 0.36. Low variance, available after one step; wrong if V(S1) is wrong: move that slider and only this target and the blends move.
  3. Two-step return. R1 + γR2 + γ²V(S2) = 0.567: two real rewards, then the estimate, one notch along the dial.
  4. Monte Carlo: all real rewards. G0 = R1 + γR2 + γ²R3 = 0.81. No estimate at all: unbiased, but every step's randomness is in it, and it waits for the end.
  5. λ-return: a blend. At λ = 0.5 the TD, two-step and Monte Carlo targets weigh 0.5, 0.25 and 0.25 (the stream sizes): 0.52425. λ slides between TD (λ = 0) and Monte Carlo (λ = 1); GAE in PPO is the same dial.
  6. Dynamic programming: the exact expectation. With a known model (the glass plate: S0 reaches S1 with probability 0.8, otherwise the episode ends) the target is the expectation itself, with no sample: 0.8 × (0 + 0.9 × 0.4) = 0.288.
  7. Policy gradients: the same targets as weights. They do not move V(S0); they make the first action more likely in proportion to a weight built from the same targets: the return minus a baseline (REINFORCE, G0 − V(S0) = +0.61) or the critic's TD error (actor-critic, δ0 = +0.16).
  8. GRPO: the group is the baseline. A separate case: four answers to one prompt score 1, 0, 0, 0 (mean 0.25, standard deviation 0.433). No estimate of any state is used; each answer's advantage (r − mean) / std is +1.732 or −0.577, and applies to all its tokens.
