# Topic: rl

Notion: https://app.notion.com/p/3c65c17b0d0d8195a6c6c11ad093c16e

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). An intuitive 16-minute overview of RL on the spine "one target, many estimators" (RL foundations folded in; depth and the Estimator lab kept in `src/for_children/` for the child pages), with tabs Taxonomy, Method atlas, Milestones and benchmarks, Further reading. Its eight child pages (Bandits and exploration, Dynamic programming, Model-free prediction and control, Value-based deep RL, Policy gradients and actor-critic, Model-based RL and planning, Offline RL and imitation, RL for LLMs) are each an interactive page in their own folders.
