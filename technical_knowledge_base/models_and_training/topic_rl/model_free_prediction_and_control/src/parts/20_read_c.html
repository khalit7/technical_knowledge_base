4SARSA, Expected SARSA and Q-learning: which next action the target assumes

Put TD in the control loop: update Q after every step, act ε-greedily on the latest Q. One transition shows the whole difference. illustrative The agent is in S beside a cliff, took A = right, got R = −1; γ = 1, α = 0.5, Q(S, right) = −5. In S′, Q(S′, right) = −4 is best and Q(S′, down) = −100 steps into the cliff; exploration happened to pick A′ = down.

  • SARSA uses the action taken: target −1 + (−100) = −101, new Q(S, right) = −5 + 0.5 × (−101 + 5) = −53.
  • Q-learning uses the best action: target −1 + (−4) = −5, so Q(S, right) stays −5.

SARSA's value of "right, beside the cliff" absorbs the risk that its own exploration stumbles in; Q-learning's assumes greedy behaviour from S′ on. Change the numbers (the two other actions in S′ are −5 and −6, for Expected SARSA's average):

SARSA learns the value of the policy it runs, exploration included: on-policy TD control. Q-learning ({{Watkins 1989|https://www.cs.rhul.ac.uk/~chrisw/new_thesis.pdf}}; proof {{Watkins and Dayan 1992|https://doi.org/10.1007/BF00992698}}) behaves ε-greedily (the behaviour policy) but its target evaluates the greedy policy (the target policy): off-policy, and needing no importance ratio, because the target never uses the action the behaviour chose next; behaviour only decides which pairs get updated. That is what lets DQN learn from a replay buffer. Its max is the Bellman optimality backup, so it is sampled value iteration. Expected SARSA removes the variance of the random A′ and, with a greedy target policy, is exactly Q-learning ({{§6.6|https://incompleteideas.net/book/RLbook2020.pdf#page=155}}).

The optimal path hugs the edge: up 1, right 11, down 1, 13 steps, return −13, and Q-learning learns its values. But on each of the ten edge cells the random 10% of actions picks "down" a quarter of the time, 0.1/4 = 0.025 per step, so a pass survives with probability 0.97510 ≈ 0.776 and about 22% of passes fall at least once derived. SARSA learns a longer path through the upper part of the grid, because its values include its own stumbles, and so earns more while ε stays at 0.1.

What the rerun checks, and which path SARSA learns (live numbers, a correction)
    Which path SARSA learns
    The parent page's overview said SARSA learns "a safer path one row up". After 500 episodes SARSA's greedy path is a 17-step route that climbs to the top row (up 3, right 11, down 3) in 73 of 100 runs, 19 or 21 steps in 11, and in 16 its greedy moves loop through rarely visited cells; the 15-step route one row above the edge never appears. Q-learning's greedy path is the 13-step edge path in all 100 runs. The book's wording is "the longer but safer path through the upper part of the grid".

    Which is "right" depends on the question. Q-learning answers "what is optimal if I stop exploring?"; SARSA "what is best given that I keep exploring like this?". For a robot exploring on real hardware, SARSA's answer is the safer one; Q-learning's values are not the return you will get while exploration continues (−50.8 expected, against −13 for the greedy path).

    Convergence conditions, Expected SARSA at α = 1, n-step SARSA and SARSA(λ), history (depth)

    SARSA converges to Q* with probability 1 under GLIE policies and Robbins-Monro step sizes, Σt αt = ∞ and Σt αt2 < ∞: big enough in total to overcome any initial values, shrinking fast enough for the noise to average out ({{§6.4|https://incompleteideas.net/book/RLbook2020.pdf#page=151}}; proof {{Singh, Jaakkola, Littman and Szepesvári 2000|https://doi.org/10.1023/A:1007678930559}}). Those conditions are for proofs: they "are seldom used in applications and empirical research", where a constant α is the norm and never fully settles but tracks change ({{§2.5|https://incompleteideas.net/book/RLbook2020.pdf#page=55}}). With ε fixed, SARSA settles on the best policy given that it keeps exploring.

    Q-learning needs only that every pair keeps being updated, plus "a variant of the usual stochastic approximation conditions" on the step sizes ({{§6.5|https://incompleteideas.net/book/RLbook2020.pdf#page=153}}; general proofs {{Jaakkola, Jordan and Singh 1994|https://doi.org/10.1162/neco.1994.6.6.1185}}, {{Tsitsiklis 1994|https://doi.org/10.1007/BF00993306}}); ε need not decay for the values to converge, only for the behaviour to become optimal.

    Expected SARSA on the deterministic cliff "can safely set α = 1 without suffering any degradation of asymptotic performance, whereas Sarsa can only perform well in the long run at a small value of α" (Figure 6.3, from {{van Seijen, van Hasselt, Whiteson and Wiering 2009|https://doi.org/10.1109/ADPRL.2009.4927542}}); it "subsumes and generalizes Q-learning while reliably improving over Sarsa", at a small extra cost per step.

    n-step SARSA targets Rt+1 + ... + γn−1Rt+n + γnQ(St+n, At+n) ({{§7.2|https://incompleteideas.net/book/RLbook2020.pdf#page=167}}); SARSA(λ) keeps one trace per state-action pair ({{§12.7|https://incompleteideas.net/book/RLbook2020.pdf#page=325}}). On a gridworld with one reward at the goal, an episode of one-step SARSA strengthens only the last action before the goal, n-step SARSA the last n (Figure 7.4). Expected SARSA goes back to George John (1994).

    History: SARSA came after Q-learning. Rummery and Niranjan introduced it in 1994 as "Modified Connectionist Q-learning"; the name "Sarsa" is from Sutton (1996) ({{chapter 6 notes|https://incompleteideas.net/book/RLbook2020.pdf#page=161}}).

    5Maximisation bias and Double Q-learning

    A max over noisy estimates is biased upwards. If 10 actions are all truly worth 0 and each estimate carries unit noise, the expected largest estimate is 1.539 derived: whichever got lucky wins. Q-learning's target is that max, and an ε-greedy SARSA uses it through the greedy part of its policy; the optimism flows back into every state that leads there ({{§6.7|https://incompleteideas.net/book/RLbook2020.pdf#page=156}}). The cause is using the same samples to pick the action and to value it. Double learning keeps two independent estimates and values one's choice with the other, Q2(argmaxa Q1(a)), whose expectation is the true value of the chosen action.
