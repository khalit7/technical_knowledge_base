Q-learning (off-policy TD control)

Same shape, but the bootstrap uses the best next action rather than the one actually taken ({{Watkins 1989|https://www.cs.rhul.ac.uk/~chrisw/new_thesis.pdf}}, whose convergence outline was made rigorous by {{Watkins and Dayan 1992|https://doi.org/10.1007/BF00992698}}):

Q(S, A) ← Q(S, A) + α ( R + γ maxa′ Q(S′, a′) − Q(S, A) )
maxa′ Q(S′, a′)
the largest current estimate over all actions in S′ (0 if S′ is terminal); every other symbol is as for SARSA

The agent still behaves ε-greedily (the behaviour policy μ), but the target evaluates the greedy policy π(S′) = argmaxa′ Q(S′, a′) (the target policy). Learning about π from experience generated by μ is what makes it off-policy. No importance-sampling correction is needed, because the target does not use the action μ chose next; the policy only decides which pairs get updated ({{Silver, Lecture 5 slides|https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-5-model-free-control-.pdf}}). The same property is what lets DQN learn from a replay buffer of old experience.

Classification: off-policy, model-free, TD control. It is the sampled, model-free counterpart of value iteration (the max in the target is the Bellman optimality backup), and it is the direct ancestor of DQN ({{Value-based deep RL|n:3ee5c17b0d0d818689b2c0dbce434ece}}). All it needs to converge to Q* with probability 1 is that every state-action pair keeps being updated, plus "a variant of the usual stochastic approximation conditions" on the step sizes ({{Sutton and Barto, §6.5|https://incompleteideas.net/book/RLbook2020.pdf#page=153}}; more general proofs: {{Jaakkola, Jordan and Singh 1994|https://doi.org/10.1162/neco.1994.6.6.1185}}, {{Tsitsiklis 1994|https://doi.org/10.1007/BF00993306}}); ε does not have to decay for the values to converge, although it does for the behaviour to become optimal.

Worked example: one transition, two targets

illustrative The agent is in S next to a cliff, took A = right, and got R = −1, with γ = 1, α = 0.5 and Q(S, right) = −5. In the next state S′, Q(S′, right) = −4 is the best action and Q(S′, down) = −100 steps into the cliff. The ε-greedy policy happened to pick the exploratory A′ = down.

  • SARSA uses the action taken: target = −1 + (−100) = −101; new Q(S, right) = −5 + 0.5 × (−101 − (−5)) = −53.
  • Q-learning uses the best action: target = −1 + (−4) = −5; new Q(S, right) = −5 + 0.5 × (−5 − (−5)) = −5, unchanged.

SARSA's value of "right, next to the cliff" absorbs the risk that its own exploration will stumble in; Q-learning's value ignores it, because it assumes greedy behaviour from S′ onwards. Change the numbers (the two other actions in S′ are set to −5 and −6 for Expected SARSA's average):

Cliff walking: SARSA against Q-learning

The standard demonstration is Sutton and Barto's cliff-walking gridworld ({{Example 6.6|https://incompleteideas.net/book/RLbook2020.pdf#page=154}}): a 4 by 12 grid, with the start in the bottom-left corner and the goal in the bottom-right corner ({{Gymnasium, Cliff Walking|https://gymnasium.farama.org/environments/toy_text/cliff_walking/}}). The ten cells between them along the bottom row are the cliff. Actions are up, down, left and right; every step costs −1, stepping into the cliff costs −100 and sends the agent back to the start, and the task is undiscounted. Both methods act ε-greedily with ε = 0.1.

  • The optimal path runs along the edge of the cliff: one step up, eleven right, one down, 13 steps and a return of −13. Q-learning learns the values of this path, because its target assumes greedy behaviour.
  • But the agent is not greedy. On each of the ten cells along the edge, the random 10% of actions picks "down" a quarter of the time, a probability of 0.1/4 = 0.025 per step of falling in. The chance of one pass along the edge without a fall is 0.97510 ≈ 0.776, so about 22% of passes fall at least once, and Q-learning's online return is poor derived. Exactly, acting ε-greedily around the edge path is worth −50.80 per episode (policy evaluation on the known grid, in the {{Cliff walking|#t-cl}} tab), which is what Q-learning's simulated average converges to.
  • SARSA learns a longer path through the upper part of the grid, because its values include its own exploratory stumbles, and it collects more reward per episode than Q-learning while ε stays at 0.1: −27.4 against −50.3 per episode over episodes 401 to 500 in the live rerun (100 runs; the book does not state α, 0.5 is assumed).
  • If ε were gradually reduced, both would converge to the optimal edge path.
How often the exploring agent falls off the edge path derived
Which path SARSA learns
The parent page's overview says SARSA learns "a safer path one row up". The live rerun finds something more specific: after 500 episodes SARSA's greedy path is a 17-step route that climbs to the top row (the shortest such route: up 3, right 11, down 3) in 73 of 100 runs, 19 or 21 steps in 11, and in 16 its greedy moves loop through rarely visited cells; the route one row above the edge (15 steps) never appears. Q-learning's greedy path is the 13-step edge path in all 100 runs. The book's own wording is "the longer but safer path through the upper part of the grid".

Which is "right" depends on the question. Q-learning answers "what is optimal if I stop exploring?"; SARSA answers "what is best given that I will keep exploring like this?". For a robot that must explore on real hardware, SARSA's answer is the safer one.

Maximisation bias and Double Q-learning

Taking a max over noisy estimates is biased upwards: if several actions all have true value 0 but their estimates scatter above and below 0, the max of the estimates is positive. With 10 such actions and unit noise the expected max is 1.539 derived (the expected maximum of 10 standard normals). Q-learning uses that max as its target, and an ε-greedy SARSA uses it implicitly through the greedy part of its policy ({{Sutton and Barto, §6.7|https://incompleteideas.net/book/RLbook2020.pdf#page=156}}). The bias propagates: every state that leads to the noisy one inherits the optimism.

The cause is using the same samples both to pick the maximising action and to estimate its value. Double learning splits them: learn two independent estimates Q1 and Q2, choose with one and value with the other, Q2(argmaxa Q1(a)), which is unbiased in the sense that its expectation is the true value of the chosen action. Double Q-learning ({{van Hasselt 2010|https://papers.nips.cc/paper/2010/hash/091d584fced301b442654dd8c23b3fc9-Abstract.html}}) flips a coin on each step and updates one table:

Q1(S, A) ← Q1(S, A) + α ( R + γQ2(S′, argmaxa Q1(S′, a)) − Q1(S, A) )
Q1, Q2
two tables, treated symmetrically: on tails the same update runs with their roles swapped
behaviour
ε-greedy on Q1 + Q2

It doubles the memory but not the computation per step. Sutton and Barto's Example 6.7 makes the bias cost reward: from state A, "left" leads to a state B whose many actions each pay a reward with mean −0.1, so left is always a mistake, yet Q-learning "initially learns to take the left action much more often than the right action", while Double Q-learning "is essentially unaffected" (Figure 6.5). The {{Maximisation bias|#t-mx}} tab reruns it with 10,000 runs and animates one run, showing B's noisy estimates and the max that Q-learning bootstraps from. Double DQN is the same idea with the two networks DQN already has ({{van Hasselt, Guez and Silver 2015|https://arxiv.org/abs/1509.06461}}; on {{Value-based deep RL|n:3ee5c17b0d0d818689b2c0dbce434ece}}).

Off-policy learning and importance sampling

On-policy learning ("learn on the job") learns about π from experience sampled from π. Off-policy learning ("look over someone's shoulder") learns about a target policy π from experience sampled from a different behaviour policy b. It is useful for learning from human demonstrations or other agents, reusing data from old policies, learning a greedy target while behaving exploratorily, and learning about several policies from one stream of behaviour ({{Silver, Lecture 5|https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-5-model-free-control-.pdf}}). It needs coverage: every action π might take must have a non-zero probability under b ({{Sutton and Barto, §5.5|https://incompleteideas.net/book/RLbook2020.pdf#page=125}}).

The general correction is importance sampling: weight each return by how much more or less likely the target policy was to produce that trajectory. The environment's transition probabilities appear in both and cancel, so the ratio needs only the two policies:

ρt:T−1 = ∏k=tT−1 π(Ak | Sk) / b(Ak | Sk),    Eb[ρt:T−1 Gt | St = s] = vπ(s)
ρ
the importance-sampling ratio of the rest of the episode (equations 5.3 and 5.4)
  • Ordinary importance sampling averages the scaled returns, V(s) = Σ ρG / (number of returns). Its first-visit version is unbiased, but its variance is in general unbounded.
  • Weighted importance sampling divides by the sum of the ratios instead, V(s) = Σ ρG / Σ ρ. It is biased (after one return it simply equals that return), with the bias falling to zero as returns accumulate, and its variance is bounded: with bounded returns it goes to zero "even if the variance of the ratios themselves is infinite" (Precup, Sutton and Dasgupta 2001). "In practice, the weighted estimator usually has dramatically lower variance and is strongly preferred" ({{§5.5|https://incompleteideas.net/book/RLbook2020.pdf#page=127}}). Every-visit versions of both are biased, with the bias vanishing asymptotically.
  • Example: the behaviour policy took an action with probability 0.25 that the target policy would take with probability 0.5, so the sample counts double (ρ = 2); an action the target policy never takes gets weight 0, and so does the whole rest of the trajectory before it.

Two of the book's examples make this concrete, and the {{Importance sampling|#t-is}} tab reruns both. On one blackjack state evaluated from random play (Example 5.4), the weighted estimator's error is far lower over the first episodes and both errors approach zero by 10,000 episodes; the state's value, −0.27726 in the book from 100 million simulated games, is −0.27720 computed exactly derived. On a one-state MDP whose target policy loops (Example 5.5), the scaled returns have expectation 1 and infinite variance, E[(ρG)2] = 0.2 Σj≥0 1.8j = ∞, and ten runs of ordinary importance sampling are still scattered after millions of episodes, while the weighted estimate is exactly 1 from the first episode consistent with π.

Incremental and control versions

  • Weighted importance sampling, incrementally: keep a cumulative weight C per pair; for each new return with weight W, C ← C + W and Q ← Q + (W/C)(G − Q) (equations 5.7 and 5.8, {{§5.6|https://incompleteideas.net/book/RLbook2020.pdf#page=131}}). With π = b every W is 1 and this is the ordinary running mean.
  • Off-policy Monte Carlo control makes the target greedy and the behaviour soft, walks each episode backwards, and stops at the first action that is not greedy, since from there on π would have weight 0 ({{§5.7|https://incompleteideas.net/book/RLbook2020.pdf#page=132}}). The catch, in the book's words: "this method learns only from the tails of episodes"; if non-greedy actions are common, learning is slow. TD methods are the usual remedy.
  • Off-policy n-step methods multiply the ratios of the actions inside the n-step window (n-step SARSA uses ρt+1:t+n, which starts and ends one step later than n-step TD's ρt:t+n−1, because the first action is already given; {{§7.3|https://incompleteideas.net/book/RLbook2020.pdf#page=170}}). The tree-backup algorithm avoids ratios altogether by taking expectations over the actions not taken at each step; its one-step case is Expected SARSA ({{§7.5|https://incompleteideas.net/book/RLbook2020.pdf#page=174}}); Watkins's Q(λ) instead cuts its traces at the first exploratory action ({{§12.10|https://incompleteideas.net/book/RLbook2020.pdf#page=334}}). Deep RL's safe multi-step corrections, such as Retrace, which truncates the ratios at 1, descend from these ({{Munos et al. 2016|https://arxiv.org/abs/1606.02647}}).
  • One-step Q-learning and Expected SARSA need no ratio, because their targets average or maximise over the next action instead of using the one b chose.

The same ratio, clipped, is the heart of PPO and GRPO: their rollouts come from a slightly stale copy of the policy, and an inference engine whose probabilities differ slightly from the trainer's, so language-model RL is mildly off-policy and corrects for it per token ({{RL for LLMs|n:3c65c17b0d0d818c9bcff7177325fe56}}; {{Policy gradients and actor-critic|n:3ee5c17b0d0d8101a262d3620e75747c}}).

DP and TD: the same backups, sampled

Each TD control method is a sampled version of a DP method on Q, with x ←α y meaning x ← x + α(y − x) ({{Silver, Lecture 5 slides|https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-5-model-free-control-.pdf}}):

Bellman equationFull backup (DP, needs the model)Sample backup (TD, model-free)
Expectation equation for VIterative policy evaluation: V(s) ← E[R + γV(S′) | s]TD learning: V(S) ←α R + γV(S′)
Expectation equation for QQ-policy iteration: Q(s, a) ← E[R + γQ(S′, A′) | s, a]SARSA: Q(S, A) ←α R + γQ(S′, A′)
Optimality equation for QQ-value iteration: Q(s, a) ← E[R + γ maxa′ Q(S′, a′) | s, a]Q-learning: Q(S, A) ←α R + γ maxa′ Q(S′, a′)

Silver's "unified view" adds the two other corners: a backup that is full-width and goes to the end of the episode is exhaustive search; one that is sampled and goes to the end is Monte Carlo. Expected SARSA sits between the two columns, sampling the next state but not the next action.

Trade-offs and when to use which

  • MC or TD for prediction. TD when the task is continuing, episodes are long, or the state is close to Markov: lower variance and learning mid-episode usually win. MC when episodes are short, the state is only partially observed (MC does not rely on the Markov property), or when you will use a function approximator and need the more robust convergence. An intermediate n or λ is often better than either end.
  • SARSA or Q-learning for control. Q-learning when you want the optimal greedy policy and mistakes during learning are cheap (a simulator), or when learning from old or someone else's data. SARSA when the exploring agent's own performance during learning matters, because it optimises the policy it actually runs. Expected SARSA is a low-variance compromise and becomes Q-learning when its target policy is greedy; it tolerates larger step sizes.
  • Maximisation bias. When the rewards or transitions are noisy and many actions compete, consider Double Q-learning (or Double DQN with networks).
  • Off-policy Monte Carlo. Prefer weighted importance sampling; expect slow learning when the target and behaviour policies differ often.
  • The step size α. Larger α learns faster and fluctuates more around the answer; a constant α never settles exactly but tracks a changing problem. TD with a large constant α can even get worse after a while (the {{TD or Monte Carlo|#t-rw}} tab: α = 0.15 bottoms out and rises, Exercise 6.5).
  • ε. More exploration finds better actions and costs reward while learning; decay it (GLIE) when the final policy should be greedy.
  • Tables. Every method here stores one number per state or state-action pair and learns nothing about a state it has not visited; that stops working as soon as the state space is large or continuous.

Common mistakes and misconceptions

"TD is always better than MC."
It usually is on Markov tasks with a table, but it is biased, depends more on the initial values, and can diverge with non-linear function approximation or off-policy data where MC does not.
Thinking MC and TD converge to the same thing on finite data.
On a fixed batch MC fits the observed returns and TD solves the maximum-likelihood Markov model: V(A) = 0 against 0.75 in the AB example.
Acting greedily on V without a model.
The greedy step over V needs the transition model; model-free control learns Q so that the greedy step is a plain argmax.
Choosing SARSA's A′ twice.
SARSA's A′ must be the action actually executed next. If you compute A′ for the update and then pick a different action to execute, you have built something that is neither SARSA nor Q-learning.
"Q-learning is off-policy, so it needs importance sampling."
One-step Q-learning does not: its target never uses the behaviour policy's next action. Off-policy MC and off-policy n-step methods do need importance ratios, and those multiply along the trajectory and can blow up the variance (infinitely, in Example 5.5).
"On-policy means online, off-policy means offline."
Q-learning is off-policy while learning online; the distinction is which policy the values describe. Learning from a fixed dataset with no interaction is offline RL, a different problem ({{Offline RL and imitation|n:3ee5c17b0d0d81d4995ec47e428de9b3}}).
Reading Q-learning's values as the return you will get.
They are the returns of the greedy policy; while ε-greedy exploration continues, the actual return is lower, as on the cliff (−50.8 expected, against −13 for the greedy path).
Forgetting maximisation bias.
The max over noisy estimates overestimates; Double Q-learning fixes it.
Bootstrapping from a terminal state.
V(S′) and Q(S′, ·) are 0 at a terminal state; bootstrapping from a stale estimate there leaks value past the end of the episode.
"SARSA is the older method and Q-learning improved on it."
The other way round: Q-learning is from 1989, SARSA from 1994, introduced as a modification of Q-learning.
"Weighted importance sampling is unbiased because it is normalised."
It is the ordinary (first-visit) estimator that is unbiased; the weighted one is biased, with the bias vanishing as returns accumulate. Its advantage is variance.
"The Robbins-Monro conditions are how you set α in practice."
They are what the convergence proofs need; practice mostly uses a constant α, which never fully converges but tracks change.

Where this goes next

Everything above stores Q as a table, which dies with large or continuous state spaces. Replacing the table with a neural network, plus the tricks needed to make that stable (a replay buffer, which Q-learning's off-policy target makes legitimate, and a frozen target network), is {{Value-based deep RL|n:3ee5c17b0d0d818689b2c0dbce434ece}}. There, DQN regresses a network onto the Q-learning target, Double DQN applies the double-learning fix above, and n-step targets return as one of Rainbow's components. Actor-critic methods learn a critic with TD targets ({{Policy gradients and actor-critic|n:3ee5c17b0d0d8101a262d3620e75747c}}). Dyna mixes Q-learning on real experience with Q-learning on simulated experience from a learned model ({{Model-based RL and planning|n:3ee5c17b0d0d8116be5fd39e10bd94c5}}).

The MC-against-TD dial also reappears in language-model RL ({{RL for LLMs: RLHF, GRPO, RLVR|n:3c65c17b0d0d818c9bcff7177325fe56}}). GRPO's single end-of-sequence reward, compared against the mean of a sampled group, is a Monte Carlo return: unbiased, no value model, high variance. PPO with a value model uses generalised advantage estimation (GAE), a λ-weighted average of the TD errors r + γV(s′) − V(s) from its critic, so it sits partway along the TD(λ) dial, with its own λ choosing the bias-variance trade-off.

Up the tree, {{Topic: rl|n:3c65c17b0d0d8195a6c6c11ad093c16e}} places these methods on its axes: all four are model-free and value-based; SARSA is on-policy and Q-learning off-policy; Monte Carlo does not bootstrap and TD does.
