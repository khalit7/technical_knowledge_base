6Off-policy Monte Carlo: importance sampling

Off-policy learning learns about a target policy π from data of a behaviour policy b: from demonstrations or other agents, from old policies' data, a greedy target while behaving exploratorily, several policies from one stream ({{Silver, Lecture 5|https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-5-model-free-control-.pdf}}). It needs coverage: every action π might take has non-zero probability under b ({{§5.5|https://incompleteideas.net/book/RLbook2020.pdf#page=125}}). Q-learning gets away without a correction; a Monte Carlo return does not, because the whole rest of the episode followed b's choices. The correction weights each return by how much more likely π was to produce it; the transition probabilities appear in both policies' trajectory probabilities and cancel. Concretely: if b took an action with probability 0.25 that π takes with probability 0.5, the sample counts double (ρ = 2); an action π never takes gives weight 0 to the whole return from before it.

Every-visit versions of both are biased, the bias vanishing asymptotically. Normalising is what makes it biased, not unbiased.

      • Incrementally: keep a cumulative weight C per pair; for each new return with weight W, C ← C + W and Q ← Q + (W/C)(G − Q) (equations 5.7 and 5.8, {{§5.6|https://incompleteideas.net/book/RLbook2020.pdf#page=131}}). With π = b every W is 1 and this is the running mean.
      • Off-policy MC control makes the target greedy and the behaviour soft, walks each episode backwards and stops at the first non-greedy action, where π's weight becomes 0 ({{§5.7|https://incompleteideas.net/book/RLbook2020.pdf#page=132}}). "This method learns only from the tails of episodes": slow if non-greedy actions are common. TD is the usual remedy.
      • Off-policy n-step methods multiply the ratios inside the window: n-step SARSA uses ρt+1:t+n, one step later than n-step TD's ρt:t+n−1, because the first action is given ({{§7.3|https://incompleteideas.net/book/RLbook2020.pdf#page=170}}). Tree backup avoids ratios by taking expectations over the actions not taken; its one-step case is Expected SARSA ({{§7.5|https://incompleteideas.net/book/RLbook2020.pdf#page=174}}). Watkins's Q(λ) cuts its traces at the first exploratory action ({{§12.10|https://incompleteideas.net/book/RLbook2020.pdf#page=334}}). Deep RL's Retrace truncates the ratios at 1 ({{Munos et al. 2016|https://arxiv.org/abs/1606.02647}}).

      The same ratio, clipped, is the heart of PPO and GRPO: their rollouts come from a slightly stale copy of the policy and from an inference engine whose probabilities differ slightly from the trainer's, so language-model RL is mildly off-policy and corrects per token ({{RL for LLMs|n:3c65c17b0d0d818c9bcff7177325fe56}}; {{Policy gradients and actor-critic|n:3ee5c17b0d0d8101a262d3620e75747c}}).

      7Beyond tables: function approximation and the deadly triad

      Every method so far stores one number per state or state-action pair and learns nothing about a state it has not visited, which fails as soon as the state space is large or continuous. Replace the table with v̂(s, w) and move the weights along the gradient of the estimate, treating the target as fixed: semi-gradient TD(0), w ← w + α [R + γv̂(S′, w) − v̂(S, w)] ∇v̂(S, w) ({{§9.3|https://incompleteideas.net/book/RLbook2020.pdf#page=224}}). Monte Carlo with the same update is true gradient descent on squared error; TD is not, because its target moves with w. With linear features and on-policy data it still converges, to the TD fixed point, whose error is at most 1/(1 − γ) times the best the features allow ({{§9.4, equation 9.14|https://incompleteideas.net/book/RLbook2020.pdf#page=229}}): a factor of 100 at γ = 0.99 derived.

      Correction to the old page
      The old page's table said TD with function approximation "not always" converges, without the condition. Linear on-policy semi-gradient TD(0) provably converges, to the TD fixed point above; the failures need non-linear approximation or off-policy updates.

      The failure has a name. The deadly triad is function approximation (generalising across states), bootstrapping (targets built from current estimates, as in TD and DP) and off-policy training (updates on a distribution other than the target policy's): "If any two elements of the deadly triad are present, but not all three, then instability can be avoided" ({{§11.3|https://incompleteideas.net/book/RLbook2020.pdf#page=286}}). It needs neither control nor sampling: it appears in prediction, even with DP's expected updates. The smallest case is two states whose estimates share one weight, w and 2w, with a transition from the first to the second paying 0 ({{§11.2|https://incompleteideas.net/book/RLbook2020.pdf#page=282}}): the TD error is γ · 2w − w = (2γ − 1)w, so each update multiplies w by 1 + α(2γ − 1), above 1 whenever γ > 0.5. With α = 0.1 and γ = 1, w goes 10, 11, 12.1 derived: raising the first state raises the second twice as much. On-policy, the 2w state's own update would pull w back; off-policy, nothing does.

      Baird's counterexample is the complete version ({{Baird 1995|http://www.leemon.com/papers/1995b.pdf}}; {{Figure 11.1|https://incompleteideas.net/book/RLbook2020.pdf#page=283}}). Seven states, eight weights: the six upper states have value 2wi + w8, the seventh w7 + 2w8; every reward is 0, so every true value is 0, which w = 0 represents exactly. The target policy always takes the "solid" action to state 7; the behaviour policy takes "dashed" (to a random upper state) with probability 6/7, so all seven states are updated equally often. With γ = 0.99 the weights diverge "for any positive step size, no matter how small", even with expected updates of every state at once.

      8The map: DP and TD backups, what to use, where it goes next

      Each TD control method samples a DP method on Q, with x ←α y meaning x ← x + α(y − x) ({{Silver, Lecture 5|https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-5-model-free-control-.pdf}}). His "unified view" adds the other two corners: full-width to the end of the episode is exhaustive search, sampled to the end is Monte Carlo; Expected SARSA sits between the columns, sampling the next state but not the next action.

      Where it goes next. Replace the table with a network, plus a replay buffer (legitimate because Q-learning is off-policy) and a frozen target network: {{Value-based deep RL|n:3ee5c17b0d0d818689b2c0dbce434ece}}, where Double DQN is the double-learning fix and n-step targets return in Rainbow. Actor-critic methods learn a critic with TD targets and use GAE as the dial ({{Policy gradients and actor-critic|n:3ee5c17b0d0d8101a262d3620e75747c}}). Dyna mixes Q-learning on real experience with Q-learning on experience simulated from a learned model ({{Model-based RL and planning|n:3ee5c17b0d0d8116be5fd39e10bd94c5}}). Learning from a fixed dataset with no interaction is offline RL, a different problem from off-policy learning ({{Offline RL and imitation|n:3ee5c17b0d0d81d4995ec47e428de9b3}}). In language-model RL ({{RL for LLMs: RLHF, GRPO, RLVR|n:3c65c17b0d0d818c9bcff7177325fe56}}), GRPO's single end-of-sequence reward against a group mean is a Monte Carlo return (unbiased, no value model, high variance), and PPO with a value model sits partway along the TD(λ) dial through GAE, its λ choosing the trade-off. On {{Topic: rl|n:3c65c17b0d0d8195a6c6c11ad093c16e}}'s axes all four methods are model-free and value-based; SARSA is on-policy and Q-learning off-policy; Monte Carlo does not bootstrap and TD does.

      Depth: misconceptions, and how the experiments are run

      Misconceptions worth a second look (seven)
      • "TD is always better than MC." Usually, on Markov tasks with a table; but it is biased, leans more on initial values, and can diverge with non-linear approximation or off-policy data where MC does not.
      • "MC and TD converge to the same thing on finite data." On a fixed batch MC fits the observed returns and TD solves the maximum-likelihood Markov model: V(A) = 0 against 0.75 in the AB example.
      • "Q-learning is off-policy, so it needs importance sampling." One-step Q-learning does not; off-policy MC and n-step methods do, and their ratios multiply along the trajectory (infinitely, in Example 5.5).
      • "On-policy means online, off-policy means offline." Q-learning is off-policy and online; the distinction is which policy the values describe.
      • "SARSA is older and Q-learning improved on it." The other way round: Q-learning is from 1989, SARSA from 1994, introduced as a modification of Q-learning.
      • "Weighted importance sampling is unbiased because it is normalised." The ordinary (first-visit) estimator is the unbiased one; the weighted one wins on variance.
      • "The Robbins-Monro conditions are how you set α." They are what the proofs need; practice uses a constant α.
      How the experiments are run, checked and defined (provenance)
      • Seeded and deterministic. Every random draw comes from a seeded generator (mulberry32), one stream per purpose and run, so a run replays identically, both sides of a comparison see the same walks where that makes sense, and a Python port matches the page exactly. Long averages run in small slices between frames, so the page stays responsive on a phone; each starts when its chart scrolls into view.
      • Checked against Python. src/lab/check.py ports the engine of the random-walk, 19-state and cliff experiments line by line and reproduces their numbers bit for bit; it also checks independently: true values by linear solve, the batch closed forms against replayed batches, the λ-return recursion against equation 12.3, the cases where methods coincide (n = 1 and λ = 0 are TD(0); n ≥ episode length and λ = 1 are Monte Carlo), and the cliff's exact ε-greedy returns by linear solve. src/checks/recompute.py does the same for the maximisation-bias, importance-sampling and Baird experiments and the four-learner animation.
      • Exact definitions. Undiscounted everywhere except Baird's (γ = 0.99). Monte Carlo on the walks is every-visit constant-α (equation 6.1). n-step TD follows the box in Section 7.1. The off-line λ-return takes its targets from the values held at the start of the episode and applies them in time order at its end (equation 12.4). TD(λ) uses accumulating traces. On the cliff, ties between equal Q-values break at random; the greedy path reported takes the first best move and counts as "none" if it loops or falls.
      • Assumed, and not compared. The book does not state α for the cliff (0.5 here) or how many runs its cliff graph averages, nor how many actions B has in Example 6.7 (10 here); it states 100 runs for the random walks and 10 episodes for the 19-state sweeps, used here. Its results exist only as plotted curves, and this page never reads numbers off a plot: it tests the shapes and orderings the text and captions state.
