Experiment: maximisation bias. Why a max over noisy estimates is biased upward, and Sutton and Barto's Example 6.7 rerun live: Q-learning against Double Q-learning on a two-state MDP built so that the bias costs reward. It goes with the Reading tab's section {{Maximisation bias and Double Q-learning|#t-read/rd-mx}}. Checked against an independent Python port (src/checks/recompute.py).

The bias in one picture

Take a state where every action is worth exactly 0, and estimates that are each unbiased but noisy. The largest estimate is, on average, above 0: whichever action happened to get lucky wins the max. Q-learning's target uses exactly that max, so the optimism flows back into every state that leads here ({{Sutton and Barto, §6.7|https://incompleteideas.net/book/RLbook2020.pdf#page=156}}). The fix splits the job: one set of estimates chooses the action, an independent second set values it, and the second set's value of the first set's choice is unbiased.

Example 6.7, one run at a time

Example 6.7 and Figure 6.5 ({{book p. 134 to 135|https://incompleteideas.net/book/RLbook2020.pdf#page=156}}); the MDP is adapted from {{van Hasselt (2010)|https://papers.nips.cc/paper/2010/hash/091d584fced301b442654dd8c23b3fc9-Abstract.html}}

Every episode starts in A. Right ends the episode with reward 0. Left moves to B with reward 0, and every action in B ends the episode with a reward drawn from a normal distribution with mean −0.1 and variance 1. So left is worth −0.1 and always a mistake. Both learners act ε-greedily with ε = 0.1, step size α = 0.1, no discounting, estimates starting at 0, ties broken at random, as in the book. The book says only that B has "many possible actions"; 10 is assumed here, as in {{Zhang's reproduction of the book's figures|https://github.com/ShangtongZhang/reinforcement-learning-an-introduction/blob/master/chapter06/maximization_bias.py}}, and you can change it below.
