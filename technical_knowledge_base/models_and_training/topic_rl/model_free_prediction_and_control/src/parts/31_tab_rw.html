TD or Monte Carlo: one step and a guess, or the whole episode

Example 6.2 ({{p. 125|https://incompleteideas.net/book/RLbook2020.pdf#page=147}}) and Figure 6.2 ({{p. 127|https://incompleteideas.net/book/RLbook2020.pdf#page=149}})

Five states A to E; every episode starts in C and steps left or right with equal probability until it falls off an end. Falling off the right pays 1, everything else 0, so the true value of a state is its chance of ending on the right: 1/6, 2/6, ..., 5/6. All estimates start at 0.5. TD(0) moves V(S) a step α toward R + V(S′) after every step. Constant-α Monte Carlo waits until the episode ends, then moves every visited state toward the return that actually followed (here 0 or 1). Same walks for both.

Batch updating: after each new episode, all episodes so far are replayed with a tiny α until the values stop moving. This page jumps straight to where that converges: batch Monte Carlo gives each state the mean return seen after it; batch TD gives the values that would be exactly right for the Markov chain estimated from the transitions seen (the certainty-equivalence estimate, {{p. 128|https://incompleteideas.net/book/RLbook2020.pdf#page=150}}). check.py replays batches with α = 0.001 and lands on the same values to 5 × 10−10.

    How these experiments are run
    • Seeded and deterministic. Every random draw comes from a seeded generator (mulberry32), one stream per purpose and run, so a run replays identically, the two sides of each comparison see the same walks where that makes sense, and a Python port can match the page exactly. Long averages run in small slices between frames, so the page stays responsive on a phone.
    • Checked against Python. src/lab/check.py ports the engine of the TD or Monte Carlo, n-step and TD(λ) and Cliff walking tabs line by line and reproduces their numbers bit for bit (random walks, every parameter and step size of the three 19-state families, the three cliff agents, the step-by-step traces). It also checks independently: true values by linear solve, the batch closed forms against replayed batches, the λ-return recursion against equation 12.3, the cases where methods coincide (n = 1 and λ = 0 are TD(0); n ≥ episode length and λ = 1 are Monte Carlo), and the cliff's exact ε-greedy returns by linear solve. src/checks/recompute.py does the same for the Maximisation bias and Importance sampling tabs and the Reading tab's animation.
    • Exact definitions. Undiscounted everywhere (γ = 1). Monte Carlo on the walks is every-visit constant-α (equation 6.1). n-step TD follows the box in Section 7.1. The off-line λ-return takes its targets from the values held at the start of the episode and applies them in time order at its end (equation 12.4). TD(λ) uses accumulating traces (Section 12.2). On the cliff, ties between equal Q-values are broken at random; the greedy path reported afterwards takes the first best move and counts as "none" if it loops or falls.
    • What is assumed, and what is not compared. The book does not state α for the cliff (0.5 here, labelled) or how many runs its cliff graph averages; it states 100 runs for the random walks and 10 episodes for the 19-state sweeps, used here. The book's results exist only as plotted curves, and this page never reads numbers off a plot: it tests the shapes and orderings the text and captions state.
