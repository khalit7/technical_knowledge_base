Source of the interactive HTML on the Notion page "Model-based RL and planning" (child of Topic: rl).

Build: `sh build.sh` writes `../index.html` (part order in the comment at the top of build.sh; the reading time replaces RT_MIN).

Pipeline (all from `src/`):
1. `uv run --with numpy python3 train_ttt.py 60` writes `inputs/ttt_net.json` (AlphaZero-style self-play on tic-tac-toe; about 30 s; log in `inputs/train_ttt.log`).
2. `uv run --with numpy python3 fit_pendulum.py` writes `inputs/pendulum_models.json` (5-member MLP ensemble on Gymnasium Pendulum-v1 dynamics).
3. `python3 recompute.py > recompute_output.txt` (pure Python reference `mb_ref.py`; about 75 s) writes `expected.json`.
4. `python3 mk_data.py` writes `parts/20_js_mb_data.js` (weights, training log, the few offline results the page quotes).
5. `node check_engine.mjs` compares the page's engine (`parts/21_js_mb_engine.js`) with `expected.json`: 2,697 values, 0 mismatches, largest relative difference 3.7e-15.
6. `node check_page.mjs [light|dark] [width]` drives every control in headless Chrome (no errors, no NaN, and fails if any animation moves before the reader acts), screenshots each visual to `../.shots/`; then `sh html_utils/checkpage.sh <page folder>` and `python3 html_utils/ledger.py check <page folder>`.
