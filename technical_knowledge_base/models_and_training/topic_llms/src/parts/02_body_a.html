The comparison in one screen

A large language model (LLM) predicts the next token of text, and every serious lab now ships the same skeleton: a sparse mixture-of-experts model that reasons before it answers and reads about a million tokens of context. With that shared, labs differ on three axes, and every difference on this page is one of them:

1 · Where the thinking goes

How a model spends computation before answering, and what the caller sees of it. Compare

2 · What it costs to serve

Memory for the weights, compute per token, memory for a long context. Compare

3 · How open it is

Closed behind an API, downloadable weights, or fully open with data and recipe. Compare

The result, on one independent scale: the closed labs lead on capability and the open labs on price. Axis 1: where the thinking goes

Test-time compute is computation spent at inference, deliberating before answering. A reasoning (or "thinking") model is trained to use it well, and every flagship is now one. The labs differ in where the computation goes, who decides how much, and what the caller can see.

Try: step through the four designs and watch what reaches the caller. Recurrent depth is the only one that leaves no text at all.

Thinking is paid for as output tokens, so these designs are also price decisions: more effort buys more score for more tokens (Cost per task). The open labs mostly expose thinking as an on, off or effort switch. Depth on every design: Reasoning models and test-time compute.

Axis 2: what it costs to serve

Weights: total against active parameters

In a mixture-of-experts (MoE) model each layer's feed-forward block is split into many small networks, the experts, and a learned router sends each token to a few. Total parameters must all sit in memory; active parameters are the ones a token passes through, which sets the compute per token. "600B/27B" means 600 billion total, 27 billion active. Total divided by active is the sparsity ratio; a dense model, where every weight works on every token, has a ratio of 1.

Mweights = Ntotal × b / 8     Ctoken ≈ 2 Nactive
Mweights

Ntotal, Nactive

b

Ctoken
floating-point operations (FLOPs) per generated token: one multiply and one add per active weight, attention left aside

Context: the KV cache

Attention stores a key and a value for every earlier token, the KV cache, so it does not recompute them. It grows with the context, so a million-token window is first a memory problem:

MKV = 2 × L × nkv × dhead × T × b / 8
2
one key and one value
L
layers
nkv
key-value heads per layer
dhead
dimension of each head
T
tokens in context
b
bits per cached number

Try: the bars use Mixtral 8x7B's layout (32 layers, 8 key-value heads of dimension 128, 16-bit; Mixtral paper), stretched to a million tokens as an illustration: 128 KiB per token, 128 GiB per sequence, past one 80GB accelerator (red line). Drag the context down to 128K.

grows with T², so 1M is 8² = 64 times 128K

Linear attention replaces the growing cache with a fixed-size state updated at every token; sparse attention attends to a learned selection of earlier positions. A fixed-size state cannot hold every token exactly, so real designs mix them with some full-attention layers. Every open-frontier lab that publishes its architecture now ships one of them:

Axis 3: how open it is

Closed
reachable only through an API
Open weights
the trained weights can be downloaded, under a licence that may be permissive (MIT, Apache 2.0) or restrictive (non-commercial, revenue thresholds)
Fully open
weights plus training data, code and recipe, which independent study of training needs. "Open source" in the strict sense means this, not open weights

The US frontier labs are closed; OpenAI and Google also ship small open models (gpt-oss, Gemma), and Meta, once the open-weights standard with Llama, took its frontier line closed with Muse Spark. Open weights are led from China (DeepSeek, Qwen, Moonshot, Zhipu, MiniMax, Xiaomi, Tencent), with Mistral the main Western counterweight. Only Ai2's OLMo and the Institute of Foundation Models' K2 Horizon are fully open. Licences now differ checkpoint by checkpoint, even within one family.

How the market divides

On Vercel's AI Gateway in August 2026 open-weight models carried 56% of tokens and 14% of spend (Vercel).

Closed cost per token ÷ open cost per token = (86/44) ÷ (14/56) = 7.8, the figure Vercel reports: open models do the volume, closed models take the money.

Open weights in practice means Hugging Face, which Nvidia agreed in September 2026 to buy for $12.93 billion, with a promise that the platform stays open (TechCrunch).

Price per token is not cost per task

List prices are per million tokens, but a task's cost also depends on how many tokens the model spends, thinking included, and how much of the input is a cached prefix re-read at a discount:

Ctask = ( Tcached pcache + Tin pin + Tout pout ) / 106
Ctask
dollar cost of one task or agent turn
Tcached, Tin, Tout
cached input, fresh input and output tokens (output includes thinking)
pcache, pin, pout
prices in dollars per million tokens; the one-off cost of writing the cache is left out

The index measures that second effect directly (Artificial Analysis). Common mistakes

Reading total parameters as cost or quality
Memory follows total parameters, compute per token follows active ones, and neither is a score.
"Mixtral 8x7B is eight 7B models"
Only the feed-forward blocks are replicated; attention and embeddings are shared, so it is about 47B total and 13B active, not 56B and 14B (Mixtral paper).
Treating a tier name as an architecture
OpenAI's Sol, Terra and Luna are price bands; OpenAI has published nothing about how they differ inside (VentureBeat).
Taking an unchanged token price for an unchanged cost
Gemini 3.8 Flash kept 3.7 Flash's token price but takes more steps, so it costs $1.24 per index task against $0.93, about a third more (Artificial Analysis); Google itself put the rise at about 40% (Google).
Treating open weights as open source
Downloadable weights under a custom licence are not a fully open release; only OLMo and K2 Horizon publish the data and recipe.
Believing a vendor table because it is detailed
Weight the independent reruns, such as ARC Prize's harness and Artificial Analysis' runs.
