How Claude is trained

Constitutional AI and RLAIF

Constitutional AI runs in two phases ({{Bai et al., 2022|@cai}}). A constitution is a short, public list of explicit principles; the paper's has 16 about harmlessness, one drawn at random at every step. In the supervised phase the model answers, critiques its own answer against a principle and rewrites it, and the rewrites become fine-tuning data. In the RL phase a feedback model judges pairs of responses by which better satisfies a principle, giving RLAIF (reinforcement learning from AI feedback) where RLHF would have used human rankings. Step through it:

What it buys is scale and auditability: harmlessness labels stop being the human bottleneck, and the values are a document you can read, diff and argue with rather than an aggregate of contractor judgements. What it costs is that the judge shares the model's blind spots, so the constitution has to carry the work that disagreement between humans used to. Note what the paper did not replace: helpfulness labels were still human, and only the harmlessness labels came from the AI, mixed into one hybrid preference model.

Verifiable rewards and agentic RL

Constitutional AI and RLAIF remain the base, now combined with RLVR (reinforcement learning from verifiable rewards) for reasoning, where a program checks the answer (a test suite, a maths grader) rather than a learned preference model, so it cannot be gamed by producing text a judge likes; and with heavy agentic RL, where an episode is a whole task inside a sandboxed environment with real tools and the reward depends on whether the task ended up done. That is the expensive part and the likeliest source of the family's agentic lead: the environments, not the objective, are the moat. The Task length tab shows the lead from outside: on METR's measurements six of the record-setting time horizons between June 2024 and April 2026 belong to Claude models.

What Anthropic publishes

Unusually detailed system cards, alignment evaluations and interpretability research, and almost nothing about architecture. Two interpretability lines worth knowing by name. Circuit tracing replaces the model's MLP layers with a cross-layer transcoder of sparse, human-readable features and traces which features actually drove a given output, producing an attribution graph for one behaviour; it was applied to Claude 3.5 Haiku ({{Anthropic, March 2025|@circ}}). The introspection work injects a concept's activation pattern into the model and asks whether it notices: Claude Opus 4.1 did in about 20% of trials at the best layer and strength, and "failures of introspection remain the norm" ({{Anthropic, October 2025|@intro}}). The practical asymmetry: you can learn a great deal about what these models do and essentially nothing about how they are built. Preserved thinking extends the same asymmetry to the reasoning itself, which is summarised or hidden and now also protected against extraction.

Business shape

Revenue skews to API, enterprise and coding against OpenAI's consumer skew, which explains the product priorities: agentic tooling, long context and reliability over voice, image generation and consumer surface area. The restricted Mythos releases add a second shape: capability sold first to vetted security and life-sciences organisations, with a safeguarded twin for everyone else.

Worked example: what one agent session costs

An agent session re-reads the same long context every turn, so its cost splits into four parts: writing the context to the cache once, re-reading it from the cache each turn, the new input each turn, and the output each turn (thinking included).

C=Pw+T(Pc+Ni+Oo)106
C
session cost in dollars
P
cached prefix in tokens (system prompt, tools, files already read)
T
number of turns
N
new, uncached input per turn (the latest tool result and message)
O
output per turn, thinking included
w, c, i, o
5-minute cache-write price (1.25 times input), cache-read price, input price and output price, all in dollars per million tokens

The formula assumes the prefix stays fixed and the cache stays warm (each read refreshes it), which understates a real session whose context grows, but it isolates the effect of the price list. The Session cost tab also runs the growing version. Take P = 100,000, T = 50, N = 5,000 and O = 2,000:

What it shows. On Fable 5 the cached prefix was 40% of each turn's cost ($0.10 of $0.25); after the cut it is 14% ($0.025 of $0.175), and output, thinking included, is 57%. The cache cut alone makes the same session 27% cheaper, in line with Anthropic's "around 25% for typical workloads"; without caching at all, Fable 5.1 costs almost six times as much. Once caching is on and priced this low, the lever left is how many tokens the model writes, which is what effort controls. Two caveats keep the comparison honest: the example gives every model the same token counts, but Opus 4.7 and later count the same text as about 30% more tokens than Haiku 4.5 does, so per-token prices understate how much cheaper Haiku is per word; and a cheaper model that needs more turns or more output tokens to finish can cost more per task, which is the quantity that matters. Artificial Analysis's runs show it happening: Sonnet 5.5 at max effort costs $7.62 per index task against Opus 5.5's $5.98 at half the per-token price, because it used 1.6 times the output tokens and 1.7 times the input (Effort and cost per task).

Which model when

  • Start with Opus 5.5 for most work, at its default medium effort, which is Anthropic's own recommendation. Raise effort before changing model.
  • Move up to Fable 5.1 for demanding reasoning and long-horizon agentic work where Opus 5.5 at xhigh or max still falls short on your evaluations, or where writing quality is the product. It costs 2.5 times Opus 5.5 per token, and on Anthropic's published table it does not beat Opus 5.5 on any listed evaluation.
  • Move down to Sonnet 5.5 for high-volume agentic coding, well-scoped tasks and anything latency-sensitive: close to Opus 5.5 on most rows (ahead on Terminal-Bench 4.0, eight points behind on FrontierCode 1.1) at half the price, and faster. Its docs suggest starting agentic coding at medium effort; its thinking can be reduced to between_tools (accepted at high effort or below) when up-front deliberation is not worth paying for.
  • Use Haiku 4.5 for the cheapest, fastest classification, extraction and sub-agent work that needs neither 1M tokens of context nor adaptive thinking, and plan for its successor: its retirement date is not sooner than 15 October 2026.
  • Mythos 5.1 is not a choice for most teams: it is restricted to vetted cybersecurity and life-sciences organisations.
  • Batch anything that can wait (half price), and cache any prefix that is read more than once.

Common mistakes

Sending budget_tokens to a current model
It returns a 400 error on Opus 4.7 and everything after; steer with effort and cap with max_tokens instead.
Treating effort as a budget
Effort is guidance the model interprets; only max_tokens is a hard limit, and it bounds thinking plus response together.
Assuming hidden thinking is free
With the default display: "omitted" the thinking text is empty but every thinking token is billed as output.
Editing the conversation history
Rewriting an earlier turn, the system prompt or the tool list in place invalidates every later thinking block under preserved thinking, and restarts the cache from the edit. Append instead.
Comparing per-token prices across tokenizers
Opus 4.7 and later count the same text as about 30% more tokens than Sonnet 4.6, Haiku 4.5 and earlier. Compare cost per task.
Carrying effort settings across models
Opus 5.5 defaults to medium where Opus 5 defaulted to high, and Sonnet 5.5's levels are recalibrated against Sonnet 5; rerun an effort sweep on your own evaluations.
Quoting a benchmark number without its harness
Anthropic's Opus 5.5 figures are at max effort except Terminal-Bench 4.0 (xhigh), OSWorld comes in 2.0 and 2.1 versions and in partial and strict scoring, and GDPval-AA v2 and v2.1 sit on different Elo anchors; a number moved without those is a future false comparison (see the grid under Lineage).
Carrying an old index score forward
The roughly 63 and 62 Artificial Analysis figures belong to Opus 5 and Fable 5 on the pre-v4.2 scale. On v4.3 Opus 5 (max) is 50.8 and Fable 5.1 (max) 53.4.
