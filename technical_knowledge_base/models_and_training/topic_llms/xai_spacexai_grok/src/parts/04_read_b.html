Grok 1.5 to Grok 4.5: catching up, then reasoning

Every release with its date and source is on the Lineage tab; this is what changed.

Grok-1.5 and Grok-2 (2024): catching up to the GPT-4 class. Grok-1.5 was announced on 29 March 2024 with "improved reasoning" and a 128,000-token context, and reached all X Premium users on 15 May; its vision variant, Grok-1.5V, was never released. Grok-2 and Grok-2 mini followed on 14 August 2024, with image generation through Black Forest Labs' Flux ({{Wikipedia|@wg}}).

Grok 3 (17 February 2025): Think and DeepSearch. xAI says it was trained on Colossus "with 10x the compute of previous state-of-the-art models" ({{xAI|@g3}}); Wikipedia reports Musk's version, 10 times Grok-2 ({{Wikipedia|@wg}}). The two are different baselines, and neither comes with a FLOP count. It added Think mode, an extended chain of thought before answering, trained with reinforcement learning "to refine its chain-of-thought process", which spends inference tokens to raise accuracy on problems that need many steps, and DeepSearch, xAI's "first agent": an agentic browsing loop in which the model issues its own searches across the web and X, reads results and iterates, rather than doing a single retrieval pass ({{xAI|@g3}}). Its launch also produced the first lesson in reading Grok numbers: the headline 93.3% on AIME 2025 was "cons@64", the most common answer of 64 runs, and an OpenAI employee pointed out that the comparison chart showed o3-mini-high without the same technique ({{xAI|@g3}}; {{Wikipedia|@wg}}).

Grok 4 (9 July 2025): reasoning first. Grok 4 shipped with native tool use and real-time search, a 256K API context, and Grok 4 Heavy (below). xAI reported 15.9% on ARC-AGI-2, "new state-of-the-art for closed models", nearly double Claude Opus 4's 8.6% ({{xAI|@g4}}): ARC-AGI-2 is a set of novel grid-transformation puzzles built to resist memorisation, so it probes whether a model generalises to rules it has not seen rather than recall. It called Heavy "the first model to score 50%" on Humanity's Last Exam (HLE): several thousand expert-written questions across academic fields, designed to be unanswerable by search and to sit near the ceiling of current models; xAI's charts give that figure on the text-only subset with Python and search tools ({{xAI|@g4}}). Both are xAI's own runs. Then came cheaper lines: Grok Code Fast 1 (28 August 2025) for high-volume agentic coding, Grok 4 Fast (September 2025, 2M tokens of context and, by Artificial Analysis's count, 40% fewer thinking tokens than Grok 4), Grok 4.1 and the agentic Grok 4.1 Fast with a 2M-token context (17 November 2025) ({{Wikipedia|@wg}}).

2026: a release every month or two. Grok 4.20 (February, with a multi-agent version on the API in March), Grok 4.3 (April: a new pretrained model with a December 2025 cutoff and a 1M-token context at $1.25 / $2.50), Grok Build 0.1, a model trained for agentic coding, with the Grok Build terminal agent (May), and Grok 4.5 (8 July), trained on "tens of thousands" of GB300 GPUs with an RL stage over hundreds of thousands of mostly software-engineering tasks, and data from Cursor, at $2 / $6 per million input and output tokens ({{Wikipedia|@wg}}; {{xAI release notes|@xdrn}}; {{MarkTechPost|@mtp45}}). Musk called Grok 4.5 "Opus-class"; that is the company's own assessment ({{Wikipedia|@wg}}).

Heavy: parallel attempts instead of one longer chain

A reasoning model buys accuracy with tokens. The serial way is to let one chain of thought run longer; its cost is latency, because every token waits for the one before it. Grok 4 Heavy took the parallel way: "parallel test-time compute, which allows Grok to consider multiple hypotheses at once" ({{xAI|@g4}}). Several attempts run at the same time and their answers are reconciled, so the bill grows with the number of attempts while the wall-clock time stays close to one attempt's. It works because independent attempts make errors that are only partly correlated: where one goes wrong, the others often do not, so reconciling them catches mistakes a single chain would keep. It stops working where all attempts share the same blind spot.

The API exposes the same idea as grok-4.20-multi-agent: several agents work the query and a designated leader agent synthesises their discussion into the answer. There are two setups, 4 agents (effort low or medium) and 16 agents (high or xhigh); only the leader's output is returned, and "all tokens consumed by both the leader agent and sub-agents are billed" ({{multi-agent docs|@xdma}}). The animation runs one query both ways on the same scale.

Illustrative inputs. Each attempt is drawn as 8,000 reasoning tokens and the leader's synthesis as 2,000, one square per 1,000 tokens, decoding at one token per unit of time; xAI publishes no per-agent token counts. The agent counts and the billing rule are xAI's ({{docs|@xdma}}). The single chain is given the same total budget as the parallel run, so the comparison isolates where the tokens go, not how accurate each is: no published curve gives Grok's accuracy against either budget. The animation stops when it is off screen, and starts paused, one step at a time, if your system asks for reduced motion.

What it shows. With the same tokens billed, the single chain takes about as many units of time as there are agents, while the parallel run takes one attempt plus the synthesis. Parallelism is a way to spend money instead of time. The general mechanism, and how Gemini's Deep Think and OpenAI's tiers spend test-time compute, is on {{Reasoning models and test-time compute|n:3c65c17b0d0d8190b9b4cd0acbcb66df}}.

Training: brute force on two axes

  • Compute scale and cadence. The strategy is iteration rather than a better published recipe: Colossus 1 and 2, expanding toward a million GPUs, with the fastest release cadence of any lab in 2026 (Grok 4.20, 4.3, 4.5, 4.6 and 4.7 in eight months). Its stated roadmap is "multi-trillion parameter models" ({{S-1|@s1}}).
  • RL at pretraining scale. xAI's own words for Grok 4: "we utilized Colossus, our 200k GPU cluster, to run reinforcement learning to refine Grok's reasoning abilities at a pretraining scale", with infrastructure and algorithmic work that "increased the compute efficiency of our training by 6x", verifiable training data expanded "from primarily math and coding data to many more domains", and "over an order of magnitude more compute than previously" ({{xAI|@g4}}). It is the concrete form of the industry's 2025 realisation that post-training is a second scaling axis rather than a finishing step: very large volumes of rollouts on tasks whose outcome can be checked (maths, code, tool use), scored by checking the outcome, which is why reasoning and agentic behaviour improved faster than raw knowledge. The often-repeated claim that Grok 4 spent as much compute on RL as on pretraining comes from a chart in the launch stream, not from the text, and is unconfirmed here. The method itself is on {{RL for LLMs: RLHF, GRPO, RLVR|n:3c65c17b0d0d818c9bcff7177325fe56}}.
  • Later runs, as described. Grok 4.6: a longer training run on an AI-generated dataset designed to improve reasoning ({{SiliconANGLE|@sa46}}). Grok 4.7: "a new, larger base model", "a longer reinforcement learning run on a harder mix of tasks, weighted toward problems that take many hours to complete" ({{xAI|@g47}}). From Grok 4.5 on, training used data from Cursor, which SpaceXAI went on to buy ({{Wikipedia|@wg}}). In April 2026, in Musk v. Altman, Musk said Grok had been developed "partly" by distillation from OpenAI's models; in August OpenAI said it would stop providing its models to the SpaceXAI-owned Cursor ({{Wikipedia|@wsx}}).
  • The data edge. Owning X (since the March 2025 merger) gives a real-time, conversational corpus that competitors must license or scrape. At inference time it is only live when a search tool is on: the API docs say Grok "has no knowledge of current events" beyond its training data unless Web Search or X Search is enabled ({{xAI models docs|@xdm}}). DeepSearch and those tools are what turn the firehose into live retrieval.

Grok 4.6 (12 August 2026): the value pick, and an index that moved

Grok 4.6 was the flagship for six weeks, built for long-running agents, coding, knowledge work and visual projects, with a 500,000-token context, text and image in and text out, at $2 per million input tokens, $0.50 cached and $6 output ({{xAI release notes|@xdrn}}). Musk described it as a 1.5-trillion-parameter model ({{CometAPI|@comet46}}); Wikipedia describes 4.5 and 4.6 as built on a "1.5 trillion-parameter V9 foundation" ({{Wikipedia|@wg}}). Neither is an xAI publication, so treat the size as a statement, not a spec.

At launch it scored 61 on the Artificial Analysis Intelligence Index, a composite that averages a fixed basket of benchmarks into one number (useful for coarse ranking and nothing finer): level with GPT-5.6 Sol, one point behind Claude Fable 5, and ahead of Kimi K3 ({{SiliconANGLE|@sa46}}; {{VentureBeat|@vb46}}). That was the index before its v4.2 and v4.3 revisions of September 2026 (v4.3 swapped Terminal-Bench 2.1 for 4.0 and raised the private-test weight), and the scores are on different scales. On v4.3 the tie is gone:

Never join the two columns: a 61 and a 44.3 are not a fall of 17 points, they are two rulers. Only the order within a column means anything.

The price against the position is the product claim. At $2 / $6 against Claude Opus 5.5's and GPT-5.6 Sol's $4 / $20, a 3-input-to-1-output blend comes to $3 against $8, 37.5% of the price ((3·2 + 6) / 4 = 3; (3·4 + 20) / 4 = 8), and 15% of Fable 5.1's or GPT-6 Astra's $20 blend. Per task the gap narrows, because Grok writes more tokens: Artificial Analysis puts Grok 4.6 (high) at $1.86 per index task against $5.98 for Opus 5.5 (max) and $1.99 for GPT-5.6 Sol (max) ({{AA leaderboard|@aalb}}; Price and position). The index placing also does not transfer to private code: on Real-SWE, ten licensed tasks from private enterprise codebases, Grok 4.6 running in Grok Build resolved 23.8%, level with Meta's Muse Spark 1.3 and well behind Claude Fable 5.1's 38.8% in Claude Code, and 41 of its 61 failed runs (67.2%) missed a requirement rather than breaking the code. These are model-plus-harness results from Specific Labs, collected in a {{Real-SWE roundup|@rswe}}.
