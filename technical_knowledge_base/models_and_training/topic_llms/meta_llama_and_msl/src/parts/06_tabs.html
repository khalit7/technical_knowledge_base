Run it yourself: parameters, memory and fit

Every open Meta model's parameter count rebuilt from its config.json, then weights plus key-value cache against the memory you have. Weights are parameters times bytes per parameter; the cache is 2 × layers × KV heads × head size × bytes per token for each layer that keeps the whole context, and a fixed window's worth for each local layer.

Overtraining explorer: how long should a model be trained?

Chinchilla's answer counts training only. Count serving as well and the cheapest way to reach a given quality changes: fix the loss you need, then pick the size N and training tokens D on the curve of equal loss that minimise 6ND + 2NT over a lifetime of T served tokens ({{Sardana et al.|@sard}}). Quality is the fitted loss law

L(N,D)=E+ANα+BDβ
L
pre-training loss (nats per token on Chinchilla's data)
E
the irreducible loss
A, α
how fast loss falls with parameters
B, β
how fast loss falls with training tokens

The optimum moves with demand

Optimal tokens per parameter against lifetime tokens served, for the quality chosen above, under each fitted law; Meta's actual ratios are the dashed lines.

Try: start on the Sardana preset; the defaults reproduce their Table 2. Then choose "Llama 3 8B on 15T" and slide T: under Hoffmann's law Meta's 1,875 tokens per parameter is the optimum only for a lifetime around 1014 served tokens. Switch to the Epoch fit and the same loss is reached sooner, so the optimum moves. Sardana et al. also trained models up to 10,000 tokens per parameter and found the law overestimates the gain from extra data at such extreme ratios, so read the far right as an upper bound on the benefit.

Loss values from a law fitted to Chinchilla's data are illustrative for Meta's models, which used other data and tokenizers; the explorer uses them to compare shapes, not to predict Llama's loss. Fits: {{Hoffmann et al. 2022|@chin}}; {{Sardana et al.|@sard}} (α = 0.336, β = 0.283, after De Vries); {{Besiroglu et al. 2024|@epoch}} (precise Hoffmann values and Epoch's refit). Hoffmann's own fit implies about 70 tokens per parameter at the training optimum; Epoch's refit about 20, matching how Chinchilla itself was trained.
