Pipeline lab

One raw Common Crawl file through a FineWeb-style curation pipeline, stage by stage, cheapest first: URL filtering, text extraction, language identification, heuristic filters, deduplication and PII scrubbing. Every number here was measured on the running example (defined in {{Reading, section 0|#t-read}}): the 20,991 web pages of one WARC file from the July 2024 crawl, processed with datatrove 0.10.1 on an Apple M1 Pro (CPU), on 2026-10-14. Published numbers are kept apart and labelled.

Words used in this tab

WARC: Common Crawl's archive format; each record is one HTTP response exactly as the server sent it (headers plus raw HTML). WET: Common Crawl's own plain-text version of the same responses, every visible string kept. Extraction: turning HTML into the main text of the page, dropping menus, footers and cookie banners. Language ID: a classifier (here fastText's lid.176) that gives each document a probability per language. Heuristic filter: a rule computed from the text alone (for example "fraction of lines that end in punctuation") with a threshold; a document past the threshold is dropped. Funnel: the count that survives each stage. datatrove: Hugging Face's pipeline library that built FineWeb; each stage is a Python object (a reader, a filter, a writer) and a pipeline is a list of them.
