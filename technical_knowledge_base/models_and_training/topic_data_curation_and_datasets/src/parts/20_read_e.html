6. Decontamination: keeping the test out of the training set

The problem. Benchmarks are on the web: questions are copied into forums, study sites and GitHub repositories, and end up in the crawl. A model that trained on a test item can score well by remembering it, and the score then measures memory instead of ability. Decontamination removes training documents (or spans) that overlap the test sets you will report. It belongs to both sides of the field: this section is the training-data side; how to detect contamination in a model you did not train is in {{Topic: evaluation-and-llm-judges|n:3c65c17b0d0d8181b351e1b8fc6a1546}} and {{Topic: benchmarks|n:3c65c17b0d0d811fb43fece56e40041a}}.

How it works. Almost everyone uses n-gram overlap: split test items and training documents into runs of n words or tokens and look for shared runs. GPT-3 used 13-grams. Llama 3 and Tulu 3 use 8-grams; Tulu 3's rule is precise enough to reuse: a test item counts as matched by a training example if more than half of its tokens fall inside an 8-gram shared with that one example, and a whole training dataset was dropped or cleaned if it matched more than 2% of any evaluation's items ({{Tulu 3, Section 3.2|https://arxiv.org/abs/2411.15124}}). DCLM looked for pages containing a question together with one of its answer options. A Bloom filter seeded with every test n-gram (the Dolma toolkit's approach) does the lookup in one streaming pass.

What the evidence says. DCLM removed the MMLU and HellaSwag overlaps it detected from DCLM-baseline and retrained a 7B model: scores did not fall (MMLU 51.8 before, 52.7 after; HellaSwag 77.9 and 78.4; {{DCLM, Table 7|https://arxiv.org/abs/2406.11794}}), so its gains were not from leaked items. Tulu 3 found that several popular public instruction datasets overlapped its evaluations, and dropped each one or released a version with the overlapping examples removed. Paraphrases defeat n-grams: a rewritten or translated item shares few runs, so post-training sets built by distillation (a teacher that memorised GSM8K writes "new" problems that are paraphrases) need embedding similarity or an LLM check on top.
