Choosing weights without paying for the big run

Sizes say how much of each domain exists, not how much it helps. Every published method answers the second question the same way: train proxy models (small models, cheap runs) on different mixtures, measure, and transfer the answer to the big run. They differ in what they train and how they read the answer.

One table, six mixtures: RegMix's 1B-parameter check

RegMix trained a 1B model on 25B tokens of The Pile with each mixture and averaged 14 downstream tasks. The differences are a point or two of average accuracy, and the simplest alternative, web text only, ties DoReMi.

{{RegMix, Table 4|https://arxiv.org/abs/2407.01492}}, published; values as transcribed on the child page. "Best on" counts the 14 tasks where a mixture scored highest. The axis starts at 44, not 0. Search compute in FLOPs: DoReMi 3.7e19, RegMix 3.5e18 (); Human, ODM and Pile-CC need no search.

Correction kept from the child page
DoReMi's "baseline" and RegMix's "Human" are not The Pile's own Table 1 weights: they are a document-count weighting from DoReMi's repository (Wikipedia 9.19% against 1.53% in The Pile's Table 1). So "+6.5 points over The Pile's default weights" really means over that weighting. The child page compares the two weightings domain by domain.

The running example's own proxy experiment (pending GPU run)

The child page designed one small experiment on the five domains above, so the page can show a mixture regression fitted on its own data rather than only quoting papers. This tab reuses it unchanged (no second experiment): the same script, the same pools, the same outputs.

PartDesign
DataAbout 25M GPT-2 tokens per domain streamed from the five datasets above (same files and revisions as the topic's samples), 5% of documents held out per domain. The pools are about equal, so the experiment's "natural" shares are about 20% each, not the real-world shares of the table above (web ).
Proxy modelA tiny GPT: 793,344 parameters outside the embedding (7,259,008 with the tied 50,257-token embedding), context 256.
Sweep48 mixtures drawn as in RegMix (a Dirichlet whose parameters are the pool shares times a scale drawn between 0.1 and 5, so some mixtures are near-uniform and some almost one domain), 2,000 steps of 32 × 256 tokens (16.4M tokens) each; plus three anchors: natural, uniform, temperature 2.
Target and fitMean held-out loss over the five domains (one choice among several: RegMix targeted Pile-CC validation loss); the Data Mixing Laws form fitted to the sweep; then RegMix's selection: score 100,000 sampled mixtures, average the best 128.
DoReMiA reference proxy on natural shares, then Group DRO, 2,000 steps each.
Rank checkTwo larger models (10.6M non-embedding) on about 98M tokens each: natural shares against the predicted best. If the best still wins at this scale, the regression transferred.
