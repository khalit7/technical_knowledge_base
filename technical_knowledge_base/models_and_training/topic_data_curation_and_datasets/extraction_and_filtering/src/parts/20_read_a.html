The idea in one screen

A web crawl becomes training text through a cascade of cheap, imperfect decisions: extract the main text from each HTML page, keep one language, then drop documents that fail heuristic rules. Each stage removes a measurable share, its mistakes are visible only by reading what it dropped, and the library defaults quietly decide part of the result.

One WARC file, stage by stage: most of the crawl goes at language ID, and the rules halve what is left

The running example: one WARC file of Common Crawl's July 2024 crawl (CC-MAIN-2024-30), 20,991 responses of which 20,463 are HTML pages, through a FineWeb-style chain built with datatrove 0.10.1 (run0, the root's Pipeline lab). Bars to scale; each stage is a section below. FineWeb kept 2,425 documents from this file; 2,404 of our 2,692 are among them measured. Near-duplicate removal comes next and belongs to {{Deduplication|n:3f95c17b0d0d8171ac17e43ab5ea276f}}.

You need: what a WARC and a WET file are ({{Pretraining corpora|n:3c65c17b0d0d81f382b6e75707d00663}}). Everything else starts from zero here.

WARC, WET
Common Crawl's raw HTTP responses (HTML as sent), and its own text conversion of the same pages, which keeps every visible string.
Main content, boilerplate
What the page is about, against menus, sidebars, footers, cookie notices and share buttons.
Link density, stop-word density
Share of a block's characters inside links; share of its words that are function words ("the", "of").
Language ID threshold
The minimum probability for a language that keeps a document (0.65 for English in RefinedWeb and FineWeb).
Heuristic rule
One statistic of the text, one threshold, drop the document past it (Gopher, C4 and FineWeb rules).
Wrong-drop share
Of a rule's drops that a person read, the share that was text worth training on.

Labels used on numbers: published a paper's, vendor's or library's own number; derived computed here, formula shown; measured run here (Apple M1 Pro, CPU), deterministic, so it reproduces anywhere with the same inputs and versions; rough a timing on a shared machine at low priority (load average 20 to 90), good for ratios only; hand-labelled read and judged by one reader (Claude, the agent that built this page), a pattern rather than a gold standard; illustrative made-up inputs that teach a mechanism.
