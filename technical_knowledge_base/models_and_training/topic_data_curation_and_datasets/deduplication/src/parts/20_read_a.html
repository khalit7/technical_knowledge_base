Every dedup method turns "is this a copy?" into a key that copies share (a hash, a band of MinHash minimums, neighbouring entries of a sorted suffix list, a nearby embedding), groups items by that key so nothing is compared pair by pair, and keeps one item per group. The key decides which copies a method can see; the scope it runs over (one file, one crawl, every crawl) decides how many it finds.

Four keys, four kinds of copy: each step catches what the one before cannot see

1Exact hash

key: a 64-bit hash of a URL, document, paragraph or line
catches byte-identical copies, recrawls, menu lines

2MinHash + LSH

key: all 8 minimums of one band equal (FineWeb 14 × 8)
catches near copies, Jaccard about 0.75 and up: templates, syndication

3Semantic

key: cosine ≥ 1 − ε inside one k-means cluster
catches paraphrases that share no 5-word phrase

4Suffix array

key: neighbours in sorted suffix order sharing ≥ 230 bytes
catches a banner or disclaimer repeated inside otherwise unique pages

web scaleDolma 3: 14% of text

New terms

shingle
a run of n consecutive words (FineWeb: 5); a document becomes the set of its shingles
Jaccard similarity
shared shingles over all distinct shingles of two documents, |A ∩ B| / |A ∪ B|
MinHash signature
k numbers per document, each the smallest hash of its shingles under one hash function
band, candidate pair
a slice of r signature values; two documents equal on a whole band become a candidate pair
connected component
documents linked by any chain of candidate pairs; one is kept per component
suffix array
every position of a text, sorted by the text that follows it, so repeated spans sit next to each other
Bloom filter
a bit array that answers "seen before?" in fixed memory, with no misses and a few false alarms
ε (SemDeDup)
remove a document whose embedding has cosine ≥ 1 − ε to a kept one
scope
the set deduplicated together: a shard, a crawl, every crawl ("global")
rehydration
repeating kept documents in proportion to how many copies dedup removed
