Format comparer

The same FineWeb documents written in every format the Reading tab discusses, with the real libraries: bytes on disk, bytes per token, how fast the text can be read back, and how fast one document can be fetched by number. Pick the sample and the measure; hover or tap a bar for its exact value.

What is measured, and how far it transfers
Sizes are deterministic measured: anyone with the same rows and library versions gets the same bytes, and they transfer directly to a cluster (per token they scale linearly). Speeds are rough: one Python process on a shared Apple M1 Pro at low priority, files in the page cache, best of three; they measure the format plus its Python reader (the tar and MDS readers here go sample by sample in Python, which dominates), so use them for orders of magnitude, not for choosing between two formats within a factor of two.

What each format can do

From each format's documentation and from the measurements above. "Random access" means fetching record k without reading records before it; JSONL can do it only with a separate byte-offset index and no stream compression.
