7. Environments and trajectories: the row is a task

For agents a row is a task the model acts in. A software-engineering (SWE) task is a repository at a commit, an issue, a container image that can run the tests, and the tests that decide success: FAIL_TO_PASS (tests the fix must make pass) and PASS_TO_PASS (tests that must keep passing). The model explores and edits through tools; its trajectory (actions, observations) is recorded and the tests score it. How harnesses and rollouts run is on {{Harnesses for training and evaluation|n:3f15c17b0d0d815ea579d6c80065aa36}} (its Environment lab tab, and section 6 for turning rollouts into training data); this section is about the rows.

Choices a trajectory set forces
Keep failures? SFT on resolved trajectories only (SWE-Gym, SWE-smith) is rejection sampling; failed ones still serve as preference negatives or to train a verifier (SWE-Gym trained one). Decontaminate by repository and date: a training task from the same repository and period as an evaluation task can share code and fixes; SWE-rebench records creation dates so tasks after a model's cutoff can be held out. Licences: each repository has its own; SWE-rebench records it per task (@@env_reb_mit@@ MIT of @@env_reb_n@@).
Newer ways to manufacture environments (published 2025 to 2026; not run here)

Answer first, question second: ToolGrad builds a valid chain of tool calls first and only then writes the user query for it, reaching a 99.8% pass rate on ToolBench's 16k+ real APIs against 63.8% for query-first search; Gemma 3 12B fine-tuned on 500 of its examples scored 83.1 on BFCL against Gemini 2.5 Pro's 83.2 ({{arXiv 2508.04086|https://arxiv.org/abs/2508.04086}}). The half that must be correct is constructed, not sampled and then checked. A trajectory contains its environment: Terminal-Universe replays the file operations recorded in agent trajectories to rebuild their workspaces, lets an agent fill in missing files and dependencies, and grows tasks from them: 37.3k task-sufficient environments; SFT of Qwen3.5-27B on them gained 11.9 points on Terminal-Bench 2.1 ({{arXiv 2609.04148|https://arxiv.org/abs/2609.04148}}). Reshape an existing environment: EnvHarness wraps a static environment in plug-in components, written by an LLM from the policy's diagnosed failures, keeping the original verifier (up to 9.0 points on held-out instances; {{arXiv 2608.19880|https://arxiv.org/abs/2608.19880}}). A fourth data type sits beside instructions and traces: operational know-how, such as Repo-To-Skill's AREX-Skill Library of 5,000+ verified skills distilled from 1,000 ML repositories, which made a GPT-5.5 research agent score 134.3% higher on MLE-bench (relative) at a fixed budget ({{arXiv 2609.02749|https://arxiv.org/abs/2609.02749}}).
