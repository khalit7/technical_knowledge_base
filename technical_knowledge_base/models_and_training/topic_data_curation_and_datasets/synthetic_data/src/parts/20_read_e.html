4. Math and code: synthesis with a checker

Math and code are where synthetic data is easiest to trust, because an executor or an answer checker can reject wrong output. Three patterns recur.

  • Generate, execute, keep what passes. phi-1's exercises (section 2); OpenCoder's annealing data (2.71 billion tokens of synthetic code snippets kept "only if they pass generated tests" and 0.91 billion of code textbooks, beside 96 billion real tokens, Table 3, {{arXiv 2411.04905|https://arxiv.org/abs/2411.04905}}); MegaMath's interleaved text and code blocks, generated, run and packed (50.3 billion tokens).
  • Rewrite the web into problems and solutions. MegaMath (LLM360, April 2025) turned math web pages into question-answer text with Qwen-2.5-72B-Instruct and Llama-3.3-70B-Instruct; its Table 1 lists 64.5 billion synthetic tokens out of 371.6 billion ({{arXiv 2504.02807|https://arxiv.org/abs/2504.02807}}). In its 1B-model ablation (5B tokens, Table 6) the question-answer form beat the source web pages by a wide margin (Core average 28.3 for FineMath-4+ against 48.8 for the best prompt), and the prompt mattered almost as much as the format (39.2 for a plain prompt). MAmmoTH2's WebInstruct harvested 10 million question-answer pairs that already existed on the web (recall, extract, refine with open models), taking Mistral-7B from 11% to 36.7% on MATH without in-domain training data ({{arXiv 2405.03548|https://arxiv.org/abs/2405.03548}}). self-reported
  • Translate and restyle code. NVIDIA rewrote all its Python with Qwen3 32B using style-guided and self-contained rewriting prompts, checked with syntax checks and Pylint, and transpiled Python into C++, which "improved downstream C++ code-generation accuracy" (Nemotron 3 Nano report, Section 2.2.2, {{arXiv 2512.20848|https://arxiv.org/abs/2512.20848}}; data in {{Nemotron-Pretraining-Code-v2|https://huggingface.co/datasets/nvidia/Nemotron-Pretraining-Code-v2}}, gated).

One caution for the measurements in section 6: in the samples here MegaMath's text-and-code blocks have the lowest distinct-bigram ratio (@@mm_tcb_d2@@) and the highest compression ratio (@@mm_tcb_gz@@) of all 24 sets, and its question-answer set is next to them. Math and code repeat symbols and keywords by nature, so diversity numbers are only comparable within a domain: a math set is not "less diverse" than Wikipedia in any sense that matters.
