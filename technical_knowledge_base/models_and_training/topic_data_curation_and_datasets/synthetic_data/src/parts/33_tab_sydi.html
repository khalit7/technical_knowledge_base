Twelve measures on 24 sets of 1,000 documents: real web and reference text, rephrased and transformed web pages, and text generated from seeds. Pick a measure, click a set for its details, or paste your own text to measure it at the same word budget. measured on an Apple M1 Pro (CPU), October 2026; scripts measure_sets.py, embed_sets.py, budget_curves.py in src/scripts/.

Measure your own text

Paste documents separated by blank lines (a few thousand words or more gives stable numbers). Computed in your browser: word count, distinct-1, 2 and 4, the compression ratio of the lowercased words (gzip, if your browser supports CompressionStream) and the top openings. Each number is compared with every set at the same word budget, because these ratios fall as text grows: the nearest measured budget at or below your word count is used.

How each set was sampled

    Each sample is one seeded random row group (or the first rows of one file), not a uniform sample of the whole dataset: subsets with file-order effects (Wikipedia's first file is alphabetical, Nemotron-CC files are shuffled) are labelled. Nemotron-CC rows are from the crawl the running example uses (CC-MAIN-2024-30).
