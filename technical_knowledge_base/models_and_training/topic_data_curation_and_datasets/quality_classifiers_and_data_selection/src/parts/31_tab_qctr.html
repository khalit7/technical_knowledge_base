Classifier replay: what each reference set taught fastText

Six fastText classifiers that differ in their positive examples: DCLM's published model and five trained here with DCLM's settings (100 dimensions, word bigrams, 5 epochs, learning rate 0.05) except 500,000 buckets and a minimum word count of 3, to fit the shared machine's memory (Reading, section 3). Pick one to see a few of the examples it learned from, the words that push it hardest each way, where all 2,617 run0 documents fall on its scale, and how it reads one document token by token. All weights are real; every prediction is rebuilt exactly from them (section 2 of Reading).

What it was shown as "high quality"

Three random training positives, first 260 characters. Negatives for every classifier here: random RefinedWeb pages.
