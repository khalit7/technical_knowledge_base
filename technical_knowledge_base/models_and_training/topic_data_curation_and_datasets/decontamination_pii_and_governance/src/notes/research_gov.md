## A3. How corpora handled PII
### Dolma (Soldaini et al., arXiv 2402.00159, ACL 2024)
- Regex only, three types (email, IP, phone), chosen as high-precision; Presidio judged too slow at this scale | "Dolma's size makes it impractical to use model-based PII detectors like Presidio ( Microsoft, 2018 ) ; instead, we rely on carefully-crafted regular expressions that sacrifice some accuracy for significant speed-up." | https://arxiv.org/html/2402.00159#S5 (Filtering Personally Identifiable Information) | v2, Jun 2024 | read 2026-10-14
- Threshold N = 5: 5 or fewer spans masked, 6 or more removes the document | "5 or fewer PII spans detected : we replace all spans on a page with special tokens |||EMAIL_ADDRESS|||, |||PHONE_NUMBER|||, and |||IP_ADDRESS|||" ; "6 or more PII spans detected : we remove any document that contains 6 or more matching PII spans" | https://arxiv.org/html/2402.00159#A9 (Appendix I, Details on PII Filters) | 2024 | read 2026-10-14
- Shares (of documents in the 25 Common Crawl snapshots): masked 0.02%, removed 0.001% | "In total, we find that 0.02% of documents in the 25 Common Crawl snapshots match this filter." ; "0.001% of documents in the 25 Common Crawl snapshots match this filter." | same, Appendix I | 2024 | read 2026-10-14
- Masking tokens added to tokenizer vocabulary; same regexes used for Common Crawl, C4, Reddit and GitHub subsets; ablation found removal vs masking made no difference | "we find that execution details around PII (e.g., removal versus special token replacement) had no effect on model performa[nce]" | same, Sec 5 and App. I | 2024 | read 2026-10-14

## B6. RFC 9309, Robots Exclusion Protocol
- Standards Track, September 2022 (authors Koster, Illyes, Zeller, Sassman); standardises the 1994 rules: user-agent groups, allow/disallow, longest (most octets) match wins, allow wins ties, file at /robots.txt | "This document specifies the rules originally defined by the "Robots Exclusion Protocol" [ROBOTSTXT] that crawlers are requested to honor when accessing URIs." | https://www.rfc-editor.org/rfc/rfc9309#section-1 | Sep 2022 | read 2026-10-14
- Not access control | "These rules are not a form of access authorization." | https://www.rfc-editor.org/rfc/rfc9309#section-1 | Sep 2022 | read 2026-10-14
- Security considerations | "The Robots Exclusion Protocol is not a substitute for valid content security measures. Listing paths in the robots.txt file exposes them publicly and thus makes the paths discoverable." | https://www.rfc-editor.org/rfc/rfc9309#section-3 | Sep 2022 | read 2026-10-14
