In one screen

Attention compares every query with every key by a dot product, and a dot product does not care about order: shuffle the tokens and each one gets the same scores. Something has to tell the model where each token sits. There are three broad answers: add a position vector to the input once (absolute: learned or sinusoidal), change the attention score by the distance between the two tokens (relative: Shaw, T5, ALiBi, DeBERTa, and RoPE, which does it by rotating queries and keys), or add nothing and let the causal mask carry the order (NoPE). Since 2023 almost every open LLM uses RoPE, and the practical questions are about RoPE: which base, how many dimensions to rotate, and how to stretch it past the length it was trained on.

Absolute or relative, embedding or encoding

Two distinctions organise the whole field.

  • Learned or fixed. A positional embedding in the strict sense is a learned table: row p is a trained vector added to the token at position p (GPT-2, BERT). It is simple, but the table has as many rows as the training length, so there is nothing to look up beyond it and no extrapolation at all. A positional encoding is a fixed function of position. The 2017 Transformer's sinusoidal encoding was chosen because it "may allow the model to extrapolate to sequence lengths longer than the ones encountered during training" ({{Vaswani et al. §3.5|https://arxiv.org/html/1706.03762v7#S3.SS5}}); learned embeddings gave "nearly identical results" there (Table 3, row E). In practice it interpolates well and extrapolates poorly: ALiBi's authors measured its perplexity stop improving about 20 tokens past a 512-token training length and degrade from about 50 ({{Press et al. 2021 §2|https://arxiv.org/abs/2108.12409}}). The naming is loose in the literature: RoPE is "rotary position embedding" although nothing in it is learned.
  • Absolute or relative. Absolute methods answer "where is this token?" and are added to the input once, before the first layer. Relative methods answer "how far apart are these two tokens?" and act inside attention, at every layer, which matches what attention uses: the score between a query and a key. A relative method gives the same score to the same pair of tokens wherever the pair sits in the sequence.

Switch to Attention weights: NoPE spreads attention evenly over however many tokens the mask lets it see, ALiBi decays exponentially (head 1 looks a few tokens back, head 8 hundreds), T5 is flat from 113 tokens on, and RoPE with base 10,000 decays and ripples. Go to 0 to 2,048: the learned table stops at 512 because there is no row 512.

The T5 decoder's last bucket, offsets 113 and beyond (the dotted line, computed with T5's bucket function), holds values from −40.8 to 32.8 across heads where every other bucket stays between −22 and 5.4; the chart clips them. Span corruption makes a 104-token target per 512 tokens of text ({{T5 page|n:3d45c17b0d0d81ec8ebfec02e953a7fd}}), shorter than 113, so the denoising objective alone never reaches that bucket; the released checkpoints were also trained on supervised tasks with longer targets, so why its values sit so far out is unconfirmed.
