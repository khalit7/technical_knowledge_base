## Runs (all CPU float32, 4 threads, `nice -n 15`; the GPU bench lock was never taken)
```sh
export GM_SCRATCH=<shared setup folder>; PY="nice -n 15 $GM_SCRATCH/venv/bin/python -I"
$PY runs/embed_ssl.py dino; $PY runs/embed_ssl.py mae      # 15,000 Fashion-MNIST embeddings each -> GM_SCRATCH/ve/
$PY runs/dense.py clip|siglip|dino|dinoreg|mae             # patch tokens of the 16 colour test images, every block
$PY runs/probes.py                                         # probes, kNN, retrieval, gallery neighbours -> out/
$PY runs/layerwise.py clip|siglip|dino|mae                 # probe per block
$PY runs/resolution.py; $PY runs/flops.py; $PY runs/textq.py; $PY runs/mae_shuffle.py; $PY runs/recompute.py
$PY runs/make_data.py && python3 runs/make_lab_data.py && sh build.sh
python3 runs/check_data.py      # page embeds exactly out/*.json; typed prose numbers recomputed
node runs/check_calc.mjs        # JS ports of NaFlex, smart_resize and the MACs formula against transformers
node runs/check_page.mjs <dir>  # every control, 390 dark and 920 light; nothing moves before the reader acts (normal and reduced motion)
```
Models: the root's CLIP B/32 and SigLIP 2 B/16 loaders, plus facebook/dinov2-base, facebook/dinov2-with-registers-base and facebook/vit-mae-base pinned in `runs/ve_env.py`. Large arrays stay in `GM_SCRATCH/ve/`; `out/` holds the small recorded results.

Notes: `facts.md` (every verified fact and measurement), `viz_ideas.md` (ideas built and rejected), `coverage.md`, `inputs/published.json` (numbers transcribed from papers), `inputs/configs/` (config.json files and revisions).

- **Top.** Core idea in one sentence, a static hero (one backbone, three training signals, two outputs, with measured numbers on the lanes), You need, New terms. The old "In one screen" bets and the "what this page adds to the root" note were cut as fat; the five-encoder table is a closed reference block.
- **Visuals inline beside their claims** (13 before, 21 now as the audit counts them). New: the hero (`25_js_ve_rd3.js`), a patchify stepper with a patch-size switch (section 1), the contrastive-loss widget on the real matrix (model, softmax or sigmoid, batch size, scale; the loss-against-scale curve, section 4), a before/after of the softmax all-gather against the chunked sigmoid with SigLIP's own accounting (section 4), the typographic before/after on the real cat images and a minimal-pair table with the probe images (section 6). Kept: the position-table resize stepper, token-norm maps, CLIP-score filter, scoreboard, layer chart, dense PCA stepper.
- **No autoplay.** `21_js_rd_common.js` and `99_js_tabs.js` are the skill templates; `check_page.mjs` loads the page fresh under normal and reduced motion, scrolls through it and confirms every stepper is still on step 0.
