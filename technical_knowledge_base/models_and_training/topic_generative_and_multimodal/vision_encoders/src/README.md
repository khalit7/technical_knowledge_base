# Source of "Vision encoders: ViT, CLIP and SigLIP"

Child page 5 of Topic: generative-and-multimodal (prefix `ve`, storage key `ve-tab`). `sh build.sh` writes `../index.html` from `parts/`.

Tabs: Reading (`20_read_*.html`, scripts `23_js_ve_rd1.js`, `24_js_ve_rd2.js`), Encoder comparison (`31_*`), Retrieval (`32_*`), Tokens and cost (`33_*`), Further reading (`39_tab_more.html`). Shared: `01_head.html` (the root's CSS), `05z_errbox.js.html`, `21_js_rd_common.js` (the root's helpers; `RD.anim` takes an optional tab id), `22_js_ve_common.js`, `99_js_tabs.js`. Page data: `20_js_ve_0data.js`, generated by `runs/make_data.py`; never edit by hand.

Shape: follows `html_utils/methods/topic_pages.md` Part B (child page). It builds on the root's Vision lab (`../../src/vision/`): CLIP and SigLIP 2 embeddings, probes and the 16 x 16 similarity matrix are reused, never recomputed differently (`runs/probes.py` asserts its CLIP and SigLIP 2 probe numbers equal the lab's).

## Runs (all CPU float32, 4 threads, `nice -n 15`; the GPU bench lock was never taken)
```sh
export GM_SCRATCH=<shared setup folder>; PY="nice -n 15 $GM_SCRATCH/venv/bin/python -I"
$PY runs/embed_ssl.py dino; $PY runs/embed_ssl.py mae      # 15,000 Fashion-MNIST embeddings each -> GM_SCRATCH/ve/
$PY runs/dense.py clip|siglip|dino|dinoreg|mae             # patch tokens of the 16 colour test images, every block
$PY runs/probes.py                                         # probes, kNN, retrieval, gallery neighbours -> out/
$PY runs/layerwise.py clip|siglip|dino|mae                 # probe per block
$PY runs/resolution.py; $PY runs/flops.py; $PY runs/textq.py; $PY runs/mae_shuffle.py; $PY runs/recompute.py
$PY runs/make_data.py && sh build.sh
python3 runs/check_data.py      # page embeds exactly out/*.json; typed prose numbers recomputed
node runs/check_calc.mjs        # JS ports of NaFlex, smart_resize and the MACs formula against transformers
node runs/check_page.mjs <dir>  # every control, 390 dark and 920 light
```
Models: the root's CLIP B/32 and SigLIP 2 B/16 loaders, plus facebook/dinov2-base, facebook/dinov2-with-registers-base and facebook/vit-mae-base pinned in `runs/ve_env.py`. Large arrays stay in `GM_SCRATCH/ve/`; `out/` holds the small recorded results.

Notes: `facts.md` (every verified fact and measurement), `viz_ideas.md` (ideas built and rejected), `coverage.md`, `inputs/published.json` (numbers transcribed from papers), `inputs/configs/` (config.json files and revisions).
