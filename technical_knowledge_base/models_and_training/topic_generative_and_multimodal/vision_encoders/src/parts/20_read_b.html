The idea

Every encoder here is the same machine, a vision transformer that cuts an image into patches and turns each patch into a token. What it is trained to put into those tokens (a match to its caption, agreement with another view of the same image, or its missing pixels) decides what the vectors are good for: text search and VLMs, frozen per-patch features, or a starting point for fine-tuning.

One backbone, three training signals, two kinds of output

An image becomes (R / P)² patch tokens; twelve blocks mix them; you read one pooled vector (search, classification) or every patch token (segmentation, depth, a VLM). Lanes: the three training signals, with this page's linear probe at 16 labels per class on Fashion-MNIST measured and DINOv2's published dense score published.

You need: what attention and a transformer block do ({{The transformer from zero|n:3fd5c17b0d0d8174980ddde4a20c7b3c}}), and the idea of a contrastive loss ({{Contrastive and self-supervised learning|n:3c65c17b0d0d811db6a7d02d0ee7215c}} owns InfoNCE, DINO's self-distillation and MAE as methods; this page owns them as encoders). How a VLM plugs an encoder into a language model is on {{Vision-language models|n:3fc5c17b0d0d81adbb7be5bc41c4d9d0}}; image tokenizers for generation (VQ) are on {{Autoencoders and VAEs|n:3c65c17b0d0d814da93bdb159b7c1e11}}.

New terms

Patch, patch embedding
a P × P square of pixels, and the one shared matrix that turns each into a token of width D.
Position embedding
a vector per grid slot added to each token so the model knows where the patch was.
[CLS], pooling
how many tokens become one image vector: an extra summary token, a learned attention query (MAP), or the mean.
Contrastive loss, temperature
train image and text vectors so true pairs score higher than the other pairs in the batch; the temperature (or its inverse, the scale t) sets how sharp that choice is.
Register
an extra learned token that carries no image content, giving the model scratch space so patch tokens stay clean.
Linear probe, kNN
two tests of frozen features: train only a linear classifier on them, or label by a vote of the nearest labelled vectors.
NaFlex, NaViT
encoders that take each image at its own size and aspect ratio instead of a fixed square.
The five encoders run on this page (reference)

All five are base-size (about 86 million parameters in the image tower), so differences come from how they were trained, not from size. Each image goes through the model's own preprocessor, as anyone using the model would do.
