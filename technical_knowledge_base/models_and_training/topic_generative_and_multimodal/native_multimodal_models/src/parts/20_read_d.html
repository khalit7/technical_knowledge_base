3. Writing an image one token at a time

How it works. Put the image's codes in a fixed order (raster: left to right, top to bottom) and model them like words. The chain rule turns the probability of a whole image into a product of next-token probabilities:

p(x1, …, x64 | c) = ∏i p(xi | c, x1, …, xi−1)
xi
the code at position i (one of 1,000 here)
c
the condition: a class here, a text prompt in a real model, both as tokens before the image

Training is next-token cross-entropy with teacher forcing: the network sees the true codes 1 to i − 1 and is scored on code i, for all 64 positions in one pass, under a causal mask. Generating is a loop: one call, one sampled code, append, repeat. The running example's model is a 6-layer transformer of width 192 ( parameters), the class embedding as the first position (LlamaGen's layout), trained with the Diffusion lab's exact recipe (batch 128, AdamW 5 × 10-4, EMA 0.999, 10% of labels dropped for guidance) for steps, s on the M1 Pro's GPU. The sampling loop that produced every number below, copied from src/ar/tinyar.py (sample_ar, without its recording lines):

for i in range(m.n_tok):
    inp_tokens = out if (not use_cache or i == 0) else out[:, -1:]
    if cfg not in (0, 1):
        inp_tokens = torch.cat([inp_tokens, inp_tokens])
    if use_cache:
        lg = m(inp_tokens if i > 0 else inp_tokens[:, :0], yy, caches=caches, start=0 if i == 0 else i)[:, -1]
    else:
        lg = m(inp_tokens, yy)[:, -1]
    if cfg not in (0, 1):
        lc, lu = lg.chunk(2); lg = lu + cfg * (lc - lu)
    f = _filter(lg.float(), temperature, top_k)
    if f is None:
        nxt = lg.argmax(-1)
        p = lg.float().softmax(-1)
    else:
        p = f.softmax(-1)
        if u is not None:
            nxt = _draw(p, u[:, i].to(dev))
        else:
            nxt = torch.multinomial(p.cpu(), 1, generator=gen).squeeze(1).to(dev)
    out = torch.cat([out, nxt[:, None]], 1)

Checks that ran: the cached and uncached loops give logits within 1.4 × 10-6 and identical samples (CPU); one image at batch 1 takes s with the cache and s without (MPS, median of 3): at 64 tokens recomputing the short prefix is cheaper than the cache's bookkeeping on this GPU; the cache pays off for the thousands of tokens of a real image or conversation, where recomputation grows with the square of the length. measured

Three knobs, the same as for text

  • Temperature T divides the logits before the softmax: below 1 sharpens toward the likeliest codes, above 1 flattens, 0 means always take the top code (greedy).
  • Top-k keeps only the k likeliest codes and renormalises.
  • Classifier-free guidance on logits: run the conditional and the null-class input together and use lu + s(lc − lu), with s = 1 the plain conditional model. LlamaGen states this form, ℓg = ℓu + s(ℓc − ℓu), and its best ImageNet result uses s = 1.65 ({{arXiv 2406.06525v1|https://arxiv.org/html/2406.06525v1}}); transformers implements the same line for Janus as scores_processed = uncond_logits + (cond_logits - uncond_logits) * self.guidance_scale ({{logits_process.py line 2205, v5.20.1|https://github.com/huggingface/transformers/blob/v5.20.1/src/transformers/generation/logits_process.py#L2205}}), and Janus's generate falls back to 5 when no scale is given (modeling_janus.py line 1194).

The same knobs for text, with real logits, are on {{Sampling and Decoding|n:3c65c17b0d0d8115bafcda29a2c7086e}}. For images the verdicts differ, as the measurements show.

What the measurements say. On this model the best FD without guidance is at temperature 1, the temperature it was trained for: cooling to 0.7 makes every class look tidier (the classifier accuracy rises) but the samples cluster around the most typical shapes, diversity drops and FD gets worse; heating to 1.3 adds noise faster than variety. Top-k behaves like cooling: keeping only the 10 likeliest codes gives FD against with all 1,000. Guidance helps most: the best scale, s = , brings FD to with of samples recognised as the asked-for class; s = 0 (the unconditional model) gives FD and the right class only of the time, chance level. measured The lesson that transfers: for image tokens, temperature and top-k trade diversity for typicality, and FD punishes the loss of diversity; guidance is the knob that buys fidelity, as it is for diffusion (the Diffusion lab's best was s = 2).
