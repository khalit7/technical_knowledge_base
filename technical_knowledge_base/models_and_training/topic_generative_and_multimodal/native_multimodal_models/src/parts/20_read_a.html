In one screen

A language model reads and writes one thing: a sequence of tokens. A native multimodal model is one where images, sound and video also become positions in that sequence, so the same network can read them and, in the designs that go furthest, write them. Everything on this page is a variation on two questions: what does an image become inside the sequence (continuous vectors or discrete codes), and how is an image written out (one token per network call, a few parallel rounds, or a diffusion process inside the same transformer).
