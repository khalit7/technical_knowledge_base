5. Pitfalls: the same images, a different FID

FID is a function of the pixels that reach Inception, so anything between the generator and the metric changes it: file format, resizing, the reference set, the code. The rule: process both sets identically, with the same code, and say how. Each case below uses real training images as the "model", so the right answer is "nothing is wrong" and any change from the floor is pure artefact.

Resizing

Inception wants 299 x 299. Downsampling with a fixed-width bilinear filter (TensorFlow 1, PyTorch's F.interpolate) aliases: fine detail folds into false patterns. Here the images are 28 px, so the resize is an upsampling and cannot alias; resizing one set differently still moves FID. Pick a case:

The reference set, the features and the code

  • Reference set. Training or held-out images, how many, which split: each gives a different number. ADM and EDM2 use statistics of the whole training set against 50,000 samples; this topic uses the 10,000 test images.
  • ImageNet leakage. {{Kynkäänniemi et al. 2022|https://arxiv.org/abs/2203.06026}} resampled generated images so that Inception's top-1 class histogram matched the real data's: FID fell by about 10% with no visible change (FFHQ 5.30 to 4.70, Table 1), while FID in CLIP space barely moved (2.76 to 2.74). Matching all of Inception's "fringe" features cut FFHQ FID from 5.30 to 1.78. A generator (or a discriminator built on ImageNet features) can game FID without looking better.
  • Implementation. Inception weights ported from TensorFlow, the resize, float precision and the square-root method differ between libraries. The topic's setup found MPS features differ from CPU features by at most 1.8e-5 over 200 images; differences between libraries are larger. Compute every number you compare with one tool.
What to write next to an FID
Features and weights (for example torch-fidelity 0.4.0, inception-v3-compat), resize (library and filter), file format of both sets, reference set and its size, number of generated samples, and the spread over seeds. Without these, two FIDs are not comparable.
