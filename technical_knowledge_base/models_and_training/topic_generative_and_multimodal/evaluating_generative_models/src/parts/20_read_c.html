2. FID from zero

FID, the Fréchet Inception Distance ({{Heusel et al. 2017|https://arxiv.org/abs/1706.08500}}), is the standard score for image generators. Four steps:

  1. Features. Resize every image to 299 x 299 and pass it through Inception-v3, an ImageNet classifier from 2015; keep the 2,048 numbers of its last pooling layer (one vector per image).
  2. Fit a Gaussian to each set. For the real images: the mean vector μr (2,048 numbers) and covariance matrix Σr (2,048 x 2,048: how features vary together). The same for the generated images: μg, Σg.
  3. Distance between the two Gaussians, the Fréchet (or 2-Wasserstein) distance, which has a closed form for Gaussians:
FID = ‖μr − μg‖² + Tr(Σr + Σg − 2 (ΣrΣg)1/2)
‖μr − μg‖²
the mean term: how far apart the centres of the two clouds are (wrong content on average)
Tr(...)
the covariance term: how differently the clouds are spread (too little variety, or variety in the wrong directions); zero when Σr = Σg
  1. Report it, lower is better, 0 only for identical Gaussians. Its unit is squared feature distance, so FIDs are comparable only with the same features, preprocessing and sample count.

The code that computes it

The topic's own implementation (shared by every lab), the formula line for line:

def frechet(mu1, s1, mu2, s2):
    """||mu1 - mu2||^2 + Tr(S1 + S2 - 2 (S1 S2)^(1/2)) (Dowson and Landau 1982; Heusel et al. 2017)."""
    diff = mu1 - mu2
    covmean = linalg.sqrtm(s1 @ s2)          # scipy >= 1.16: no disp argument
    if not np.isfinite(covmean).all():
        off = np.eye(s1.shape[0]) * 1e-6
        covmean = linalg.sqrtm((s1 + off) @ (s2 + off))
    covmean = covmean.real
    return float(diff @ diff + np.trace(s1) + np.trace(s2) - 2 * np.trace(covmean))

3. Sample count: the bias that never goes away by itself

The Gaussians are fitted from N samples, and the covariance term uses a matrix square root, a nonlinear function of noisy estimates. Noise in the estimated covariance makes the generated cloud look more spread out than it is, and the formula turns that into extra distance: FID measured with N samples is larger than the true FID, on average, and the gap shrinks roughly as 1/N. {{Chong and Forsyth 2020|https://arxiv.org/abs/1911.07023}} showed that FIDN ≈ FID∞ + K/N, where the slope K depends on the generator. So fixing N does not make two models comparable: the model with more spread pays more bias. Their Figure 3 shows two identical DCGANs whose order swaps with N.

This is why papers use 50,000 generated images against statistics of the whole training set (the convention since Heusel et al., and stated for ADM by {{Dhariwal and Nichol 2021|https://arxiv.org/abs/2105.05233}} and for EDM2 by {{Karras et al. 2024|https://arxiv.org/abs/2312.02696}}), and why the official FID code warns: "We recommend using a minimum sample size of 10,000 to calculate the FID otherwise the true FID of the generative model is underestimated" ({{TTUR README|https://github.com/bioinf-jku/TTUR}}; read "misestimated": the finite-N error is an overestimate, as the curves show). With fewer than 2,048 samples the covariance is not even full rank.
