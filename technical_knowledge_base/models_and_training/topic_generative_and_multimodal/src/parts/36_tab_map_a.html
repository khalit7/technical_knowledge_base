Generative and multimodal models from DALL-E (2021) to FLUX 3 Image Klein (two days before this check), on one set of axes: what the model does, its architecture family, its size, its licence and whether it is still the current version.

How this tab was checked
Every open-weights row reads its licence tag, gating and repository date from the Hugging Face API, and every paper date from the arXiv API (both fetched ). Closed models carry the vendor announcement, or a secondary tag when only press or Wikipedia confirmed the date. Sizes say who counted them: the vendor, the paper, Hugging Face's safetensors metadata, or this page (safetensors headers read with HTTP range requests, no weights downloaded). The one-line verdicts are judgement, not measurements. This table is curated, not complete.
