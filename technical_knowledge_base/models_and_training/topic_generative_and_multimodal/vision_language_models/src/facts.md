## Published (paper text, arXiv HTML)
- LLaVA (2304.08485 sec. 4.1): "a simple linear layer to connect image features into the word embedding space".
- LLaVA-1.5 (2310.03744 sec. 3.3): "a two-layer MLP can improve LLaVA's multimodal capabilities"; 558K + 665K, "~1 day on a single 8-A100 node" (FACTS rd).
- BLIP-2 (2301.12597 sec. 3.1): "we use 32 queries where each query has a dimension of 768"; "(32x768) is much smaller than the size of frozen image features (e.g. 257x1024 for ViT-L/14)"; cross-attention "inserted every other transformer block"; initialised from BERT-base; "In total, Q-Former contains 188M parameters"; sec. 3.3 "prepended to the input text embeddings", "soft visual prompts"; intro: "an information bottleneck between the frozen image encoder and the frozen LLM"; sec. 3.4: 129M images, "using a single 16-A100(40G) machine, our largest model with ViT-g and FlanT5-XXL requires less than 6 days for the first stage and less than 3 days for the second stage".
- Flamingo: as verified by the root VLM lab (resampler 64 outputs; tanh(alpha), alpha initialised to 0).
- Idefics2 (2405.02246 sec. 3.2, Table 3): FA no perceiver frozen 51.8; FA frozen 60.3; CA frozen 66.7; CA LoRA 67.3; FA LoRA 69.5. Prose: CA "performs 7 points better" (table 6.4); "a 12.9 points increase under the fully autoregressive architecture" (table 9.2); "0.6 point under the cross-attention" (matches); full unfreezing "would yield loss divergences"; "even though the latter has more parameters"; ~15% (FA) and ~25% (CA) of parameters trained when frozen. Perceiver: "increases the performance by 8.5 points" (matches 60.3 - 51.8), tokens "from 729 to 64"; Table 4: 128 tokens 71.2, 64 tokens 71.7; "no gains when using more than 64 visual tokens". Instruction tuning with DoRA; PDFs at up to 980 pixels.
- InternVL 1.5 (2404.16821): sec. 3.1 "a simple pixel shuffle to reduce the number of visual tokens to one-quarter", "a 448x448 image is represented by 256 visual tokens", training tiles 1 to 12, test up to 40; sec. 3.3 "35 possible combinations of aspect ratios formed by 1 to 12 tiles", thumbnail 448; sec. 4.1 two stages, stage 1 InternViT-6B + MLP, stage 2 "the entire model's 26 billion parameters".
- Qwen2-VL (2409.12191): sec. 2.1 2D-RoPE replacing absolute positions in the ViT; "compress adjacent 2x2 tokens into a single token"; 224 x 224 -> "66 tokens"; M-RoPE quotes (identical IDs for text; image temporal IDs constant; next modality starts at max + 1; "reduces the value of position IDs"); video "two frames per second", 3-D convolutions "depth of two", "3D tubes instead of 2D patches", "each image is treated as two identical frames", "limiting the total number of tokens per video to 16384"; 675M ViT. sec. 2.2 three stages (ViT only; all; ViT locked + LLM instruction), 600B + 800B, "a cumulative total of 1.4 trillion tokens", supervision on text tokens only; sec. 2.2.1 boxes "normalized within [0, 1000)".
- Qwen2.5-VL (2502.13923 sec. 2.1.2): "Unlike traditional approaches that normalize coordinates, our model directly uses the actual dimensions of the input image".
- Qwen3-VL (2511.21631): sec. 1 interleaved MRoPE reason ("imbalanced frequency spectrum"), DeepStack, text timestamps; sec. 2 SigLIP-2 encoder (SO-400M default, Large 300M for 2B/4B), 2-layer MLP merger of 2 x 2; sec. 2.3 "a timestamp expressed as a formatted text string" (example <3.0 seconds>); sec. 3.1 S0 merger only (~67B tokens), S1 all unfrozen (~1T), S2 32,768, S3 262,144; sec. 3.2.4 "Different from Qwen2.5-VL, we adopt a normalized coordinate system scaled to the range [0,1000]".
- SmolVLM (2504.05299): quotes as in the root lab's facts.md.
