## Models
- SmolVLM-500M-Instruct @ a7da5b986cb5 (the root's, Apache 2.0).
- Qwen3.5-0.8B @ 2fc06364715b (Apache 2.0, 1.75 GB bf16): the second VLM, because it teaches what SmolVLM cannot: native resolution, 3-D positions, boxes, video, and a hybrid language model whose cache grows in 6 of 24 layers. Peak memory is in `out/qwen_timing.json`.

## Runs (shared venv, `nice -n 15`, 4 threads; GPU only under the shared bench lock)
```sh
export GM_SCRATCH=<shared setup folder>; PY="nice -n 15 $GM_SCRATCH/venv/bin/python -I"
$PY runs/make_inputs.py          # synthetic OCR pages, grounding scenes, video clips, viewer images (CPU, seconds)
$PY runs/smol_cpu.py             # SmolVLM processor views and encoder norms (CPU)
$PY runs/siglip_norms.py         # SigLIP 2 B/16 at 224 and 512, same statistic (CPU)
$PY runs/encoder_drift.py        # SmolVLM's encoder against google/siglip-base-patch16-512 (CPU)
$PY runs/token_rules.py          # real processors on 24 image sizes and 7 video shapes (CPU)
# GPU, one process per model, under the bench lock:
sh <lock.sh> acquire bench vm 3600 && { GM_LOCK=<lock.sh> $PY runs/run_vlm2.py smol; sh <lock.sh> release bench vm; }
sh <lock.sh> acquire bench vm 3600 && { GM_LOCK=<lock.sh> $PY runs/run_vlm2.py qwen; sh <lock.sh> release bench vm; }
$PY runs/score_ground.py         # box parsing under three coordinate readings (CPU)
python3 runs/score_qa.py         # strict and content scoring of the 30 questions, both models
$PY runs/make_data.py && sh build.sh
node runs/check_rules.mjs        # the budget tab's ports against the processors (91 cases)
python3 runs/check_data.py       # the page embeds exactly out/*.json; prose numbers recomputed
node runs/check_page.mjs <dir>   # every control, 390 dark and 920 light
```
What actually ran (2026-10-17): the Qwen3.5 phases `errors saw kv` and the SmolVLM phase `kv` on the CPU (their outputs do not depend on the device; META.device says cpu), everything else on MPS in one bench-lock hold of 22 minutes. `VM_DEV=cpu VM_QUICK=1` runs one item per loop of `run_vlm2.py` on the CPU as a smoke test (writes `out/quick_*.json`, not used; deleted).

Notes: `facts.md` (every verified quote and number), `viz_ideas.md` (ideas built and rejected), `coverage.md`, `inputs/synthetic.json` (ground truth of the synthetic inputs with small thumbnails), `inputs/thumbs/` (small WebP thumbnails of the viewer images).
