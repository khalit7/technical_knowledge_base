An autoencoder squeezes an image into a small latent and draws it back. What you ask that latent to be decides what a generator can do with it: any numbers (a plain autoencoder: good copies, but random codes decode to nonsense), a Gaussian per image pulled towards N(0, I) (a VAE: you can sample it), or a grid of integers from a codebook (VQ, FSQ, LFQ: tokens a transformer can predict). Whatever the generator makes, the decoder has to draw, so its skill caps every image.

Why 64 tokens of 7 bits beat 16 real numbers (depth)

From the old root Latent lab: the VQ-VAE reconstructs better than the 16-number autoencoder ( dB against dB above), although each of its slots holds only 7 bits. A real number in a network is not infinitely precise in practice: the decoder can only use the precision training made it sensitive to, so spatial layout (64 positions, each with its own code) beats a few global numbers.

New terms

Latent (code)
the encoder's output, the small description the decoder rebuilds the image from.
Reparameterisation
z = μ + σε with ε drawn outside the network, so gradients reach μ and σ.
KL term, rate
KL(q(z | x) ‖ N(0, I)): how many nats the code carries about the image; its weight is β.
Active unit
a latent dimension whose mean varies across images (variance over 0.01); an inactive one carries nothing.
Posterior collapse
the KL falls to about 0 and the decoder ignores the code.
Codebook, VQ
K learned vectors; vector quantization replaces each encoder vector by the nearest one and keeps its index as a token.
Straight-through
copying the decoder's gradient past the non-differentiable lookup or rounding to the encoder.
FSQ, LFQ
quantizers with a fixed grid instead of a learned codebook: round each channel to a few levels, or keep only its sign.
Scaling factor
the constant (SD 1.x: 0.18215) that brings a diffusion VAE's latent to unit scale before noising.
LPIPS, rFID
a perceptual distance between two images; a Fréchet distance between a set of reconstructions and the originals.
