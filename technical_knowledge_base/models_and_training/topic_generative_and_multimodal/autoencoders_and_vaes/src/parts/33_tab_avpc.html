First two decoded rows: each pixel is written as the decoder's predicted probability (grey levels, deterministic given the code), in raster order. Writing probabilities back into an autoregressive model is not how it was trained, so these rows show what the code changes, not what a good sample looks like; the last row samples properly. This small PixelCNN (6 masked layers, 5,000 steps, with the original PixelCNN's blind spot) samples poorly in either mode; the animation reveals the recorded outputs (the 28 × 28 crop of the 32 × 32 model image) row by row, in the order the sampler wrote them; the real run took 1,024 decoder passes per image. measured (CPU); src/collapse/eval_collapse.py.
