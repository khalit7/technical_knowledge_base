# Source of "Diffusion from zero: DDPM, samplers and guidance"

Child page 2 of Topic: generative-and-multimodal (prefix `dz`, storage key `dz-tab`). `sh build.sh` writes `../index.html` from `parts/`.

Tabs: Reading (`20_read_a` to `20_read_z`, scripts `23_js_dz_toy.js`, `24_js_dz_rd.js`), Sampler workbench (`31_*`), Schedule designer (`32_*`), Guidance explorer (`33_*`; its script also fills the Reading tab's SD image cards), Further reading (`39_tab_more.html`). Shared: `01_head.html` (the root's CSS), `05z_errbox.js.html`, `21_js_rd_common.js` (the root's helpers, as the vision-encoders sibling copied them), `22_js_dz_common.js` (schedules, PRNG, a line chart), `99_js_tabs.js`. Page data: `20_js_dz_0data.js`, generated by `runs/make_data.py` (sentences that quote numbers come from `runs/notes.py`); never edit it by hand.

Shape: `html_utils/methods/topic_pages.md` Part B (child page). It builds on the root's Diffusion lab (`../../src/diff/`): the same checkpoint (`df_ddpm_eps_4000`), noise seeds, chunking and classifier-space scoring, so every tiny-model number lines up with the lab's; `dz_sample.py samplers` first reproduces two of the lab's numbers. The lab's own recordings (DDPM, DDIM, DPM-Solver++, Euler; the CFG sweep) are read from `../../src/diff/out/` and never recomputed. Derivations are linked to the Math page and the DDPM paper page, not repeated.

## Runs
```sh
export GM_SCRATCH=<shared setup folder>; PY="nice -n 15 $GM_SCRATCH/venv/bin/python -I"
$PY runs/gmm_toy.py; $PY runs/recompute.py                      # CPU, seconds
# GPU, each under the bench lock (lock.sh acquire bench dz ... release), one at a time:
$PY runs/dz_train.py bad; $PY runs/dz_train.py more             # 2.3 min and about 15 min
$PY runs/dz_sample.py samplers; $PY runs/dz_sample.py extra; $PY runs/dz_sample.py guide
$PY runs/dz_sd.py                                                # SD 1.5 fp16 + LCM-LoRA; needs peft in GM_SCRATCH/dz/pylib
$PY runs/make_data.py && sh build.sh
python3 runs/check_data.py      # page embeds exactly out/page_data.json; prose numbers recomputed from out/
node runs/check_toy.mjs         # JS toy and schedules against Python
node runs/check_page.mjs <dir>  # every control, 390 dark and 920 light
```
peft 0.21.2 (needed by diffusers' LoRA loader) was installed with `uv pip install --target GM_SCRATCH/dz/pylib peft --no-deps`, not into the shared venv. Large outputs (strips as .npz, full-size SD PNGs, the two checkpoints) are in `GM_SCRATCH/dz/`; `out/` holds the small recorded results and 256-pixel WebP thumbnails.

Notes: `facts.md` (every verified fact and measurement), `viz_ideas.md`, `coverage.md`, `inputs/published.json` (numbers transcribed from 20 papers with table and page).
