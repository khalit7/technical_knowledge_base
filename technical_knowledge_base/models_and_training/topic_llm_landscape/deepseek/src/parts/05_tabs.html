The DeepSeek template across the field

DeepSeek's layout (MLA attention, many narrow routed experts plus a shared one, a few dense layers first) became a template other labs reuse. Pick two models: the card highlights every configuration value that differs, and the rows beneath compute what those values buy. MLA's cache depends only on the latent, the RoPE key and the layer count, never on the number of heads, so models that change the heads change their attention compute and not their cache.

Predict: Kimi K2 halves V3's heads and has 384 experts; what happens to its cache per token? The default pair answers it: exactly the same 70,272 bytes, and half the attention FLOPs. Then pick Mistral Large 3 (same cache again) and GLM-4.5, which uses grouped-query attention instead.
