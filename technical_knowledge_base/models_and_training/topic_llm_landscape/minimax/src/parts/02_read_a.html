The idea in one sentence
MiniMax, a Shanghai lab founded in December 2021 ({{Wikipedia|@wiki}}), has run one experiment three times at production scale: replace most softmax attention with linear attention (MiniMax-01, M1), go back to full attention when exact recall broke at scale (M2), then keep full attention's cache but let each query read only 16 selected blocks (M3), in every layer from M3.1 Flash on.

Which layers keep a cache that grows with every token, in each generation

One square per layer, from each model's config.json ({{01|@c01}}, {{M2|@cm2}}, {{M3|@cm3}}). Bytes are BF16 keys and values per token, summed over layers. The question each generation answers differently: what a decoded token must store and read.

Lightning attention
MiniMax's block-wise kernel for causal linear attention (01, M1).
7:1 hybrid
seven lightning layers, then one softmax layer, repeating.
MSA
MiniMax Sparse Attention (M3): a light index branch picks 16 blocks of 128 tokens per GQA group; exact softmax runs on those.
KV outer, gather Q
MSA's kernel loop order: load each selected key block once and serve every query that chose it.
CISPO
M1's RL objective: clip the importance weight, not the update.

How the design got here: three routes in twenty months

The order is the argument. Each switch came with a written reason, and the reversal in the middle (M2 abandoning the hybrid MiniMax had called "the first successful large-scale implementation of linear attention") is more informative than either claim around it.
