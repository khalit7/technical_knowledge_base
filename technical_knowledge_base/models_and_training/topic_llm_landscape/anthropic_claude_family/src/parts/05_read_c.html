What one agent session costs

An agent re-reads the same long context every turn. Take a 100,000-token prefix (system prompt, tools, files already read), 50 turns, 5,000 new input tokens and 2,000 output tokens (thinking included) per turn. The bill splits into four parts: writing the prefix to the cache once, re-reading it each turn, the new input, and the output:

C=Pw+T(Pc+Ni+Oo)106
C
session cost in dollars
P, T
cached prefix in tokens (100,000); number of turns (50)
N, O
new, uncached input per turn (5,000); output per turn, thinking included (2,000)
w, c, i, o
5-minute cache-write price (1.25 times input), cache-read price, input price and output price, all in dollars per million tokens

The formula holds the prefix fixed and the cache warm (each read refreshes it), which understates a real session whose context grows, but isolates the price list. The Session cost tab frees every input and runs the growing version on every model.

Turn by turn, the context grows and caching turns most of it from full price into cheap reads

Same P, N and O, 16 turns. One square is 1,000 tokens, to scale. Each turn's input and output (thinking included, since current models keep it in context) join what the next request sends; with automatic caching each request reads everything the previous one cached and writes only what is new. What it shows. On Fable 5 the cached prefix was 40% of each turn's cost ($0.10 of $0.25); after the 5.1 cut it is 14% ($0.025 of $0.175), and output, thinking included, is 57%. The cache cut alone makes the same session 27% cheaper, in line with Anthropic's "around 25% for typical workloads"; without caching at all, Fable 5.1 costs almost six times as much. Once caching is cheap, the lever left is how many tokens the model writes, which is what effort controls. And a cheaper model that needs more tokens can cost more per task: on Artificial Analysis's runs Sonnet 5.5 at max effort costs $7.62 per index task against Opus 5.5's $5.98 at half the per-token price, because it used 1.6 times the output tokens and 1.7 times the input (Effort and cost per task).

Bars: dollars per million tokens, each on its own scale; Haiku 5.5 at its rate for requests up to 100K tokens. Fable 5.1 charges 5 times Opus 5.5's input price but only 1.25 times its cache-read price, which is why the ladder is not what it looks like for an agent.

Cache reads cost 10% of the base input price on most models (Haiku 5.5 included), 5% on Opus 5.5 and Sonnet 5.5 and 2.5% on Fable 5.1 and Mythos 5.1; a 5-minute cache write costs 1.25 times the input price (the 1-hour cache, 2 times), and the Batch API halves input and output prices, stacking with the cache multipliers. A 5-minute write pays for itself after one read, a 1-hour write after two ({{pricing|@pricing}}). All are sold through the Claude API, the major clouds (which set their own prices), an Anthropic-operated Claude Platform on Google Cloud billed through Google Cloud Marketplace (from 22 October 2026, {{Anthropic|https://claude.com/resources/articles/claude-models-on-google-cloud-anthropic-managed}}), and Anthropic's own apps, which since 21 October 2026 include Claude Duet, a proactive personal agent on Opus 5.5 that works in its own cloud computer and messages you (research preview, US Pro and Max waitlist; how it compares: {{Personal agents|n:3c75c17b0d0d81bf9462fbeb09593e1c}}).
