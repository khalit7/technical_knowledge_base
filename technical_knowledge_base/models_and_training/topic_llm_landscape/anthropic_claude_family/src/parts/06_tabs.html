Effort and cost per task

Artificial Analysis runs each model through its Intelligence Index (v4.3, methodology 4.3.2, read 1 October 2026) and reports the score, the cost per index task and the tokens it used ({{leaderboard|@aalb}}). Effort settings of the same model are joined by a line. Cost is on a log scale.

One run taken apart

The cost of a whole index run splits into output (published output tokens times the output price), cached input and uncached input. Artificial Analysis does not publish the cache-hit share it assumes ("live measurements of the model's typical cache hit rate", {{methodology|@aameth}}), so the share below is fitted: the value that makes the three parts add up to its published run cost. The split therefore reproduces Artificial Analysis by construction.

Try: Run "Sonnet 5.5 (max)", price it at Opus 5.5: half the per-token price did not make it cheaper per task, because it used more tokens. Then run "Fable 5.1 (max)" priced at Fable 5: the old cache price makes the same run about 31% dearer.

Task length: how long a task each model can finish

METR measures a model's 50% time horizon: the length of task, timed by how long it takes skilled humans, that the model completes half the time. The data are METR's own (METR-Horizon-v1.1, updated 8 May 2026, {{raw data|@metry}}, {{METR|@metr}}); no Claude 5.x model has been measured yet. The fitted line is an ordinary least-squares fit of log2(horizon) on release date over the points you select, and its slope gives the doubling time.
