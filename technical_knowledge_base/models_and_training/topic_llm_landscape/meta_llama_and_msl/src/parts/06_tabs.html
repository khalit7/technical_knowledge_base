Parameters and fit: every open Meta model rebuilt from its config

Every open Meta model's parameter count rebuilt from its config.json, then weights plus key-value cache against the memory you have. Weights are parameters times bytes per parameter; the cache is 2 × layers × KV heads × head size × bytes per token for each layer that keeps the whole context, and a fixed window's worth for each local layer.

Every model at a glance

Weights at the precision chosen above, cache at the context chosen above, on the hardware chosen above.

Assumptions: half a byte per parameter for Int4 ignores the scales and the layers a real 4-bit build keeps at higher precision, so real files are a little larger (Glimmer's 4-bit build is 17 GB against the 14.8 GB computed here); the cache is BF16; activations, the vision encoder's work and framework overhead are not counted. Glimmer's 29.6B is reproduced only if its gated attention adds one gate matrix the size of the query projection per layer, an assumption: the card says "Gated attention: Yes" without the shape.
