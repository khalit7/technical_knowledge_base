An activation function is the elementwise nonlinearity between two linear maps, and what decides how well a network trains is its slope: backpropagation multiplies every unit's gradient by it, so a slope near 0 (saturation) or exactly 0 (a dead unit) stops learning. Since 2020, language models replace the single function with a gate: a second projection of the same input that sets each unit's slope, token by token (SwiGLU).

Why a nonlinearity, and what it must be

  • Non-linear, or the stack collapses: W2(W1x) = (W2W1)x, one linear map however many layers there are.
  • Not a polynomial, the exact condition for a one-hidden-layer network to approximate any continuous function (Leshno et al. 1993, below). x2 alone would not do; squared ReLU, max(0, x)2, is piecewise and is not a polynomial, so it qualifies.
  • Differentiable almost everywhere is enough for gradient descent: ReLU has no derivative at exactly 0 and frameworks simply pick one (PyTorch's autograd uses 0 there; this page's derivatives agree with autograd everywhere else, src/recompute.py).

Everything else is a trade between four properties: slope near 1 over a wide range (gradients survive depth), outputs centred on zero (updates do not zig-zag), cheap to compute, and smooth (the optimiser sees a smooth surface). No function has all four.

The universal approximation condition, quoted (Leshno, Lin, Pinkus and Schocken 1993)

"A standard multilayer feedforward network with a locally bounded piecewise continuous activation function can approximate any continuous function to any degree of accuracy if and only if the network's activation function is not a polynomial" (Leshno, Lin, Pinkus and Schocken 1993).

Tanhtanh x = 2σ(2x) − 1(−1, 1)1, at x = 0zero-centred: outputs, and so the next layer's updates, can have either signstill saturates: slope below 0.01 once |x| > 3.0 derived

Backpropagation multiplies the gradient by the activation's slope at every unit of every layer. A sigmoid's slope is at most 0.25, so even at its best a gradient shrinks by 4 per layer, and in a saturated unit the slope is close to 0: below 0.01 once |x| > 4.6 derived from σ(1 − σ) = 0.01. On the root's "one batch through five networks", the first layer of the 16-layer sigmoid network receives a gradient about 2 billion times smaller than the last (step 2 of the {{Reading tab of Topic: ml-fundamentals|n:3c65c17b0d0d81d796ccc0a293218c57}}). Tanh is a rescaled sigmoid (the identity above) with four times the slope at 0, which is why it was preferred for hidden layers before ReLU.

ReLU passes the least: its mean slope, 0.112, is the share of positive inputs, and it does not move with scale, because only signs matter. Sigmoid never saturates here but caps every unit at 0.25. GELU's few "below 0.01" units at × 1 sit at the bottom of its dip (x near −0.75, where the slope crosses 0), not in a flat tail.

Why zero-centred matters. A unit's weight gradient is its input times one shared error term. If every input is positive (a sigmoid layer's output always is), every weight of that unit moves in the same direction at each step, so reaching a target that needs some weights up and others down takes a zig-zag. LeCun et al. recommend inputs with mean close to zero for this reason, and a scaled tanh, 1.7159 tanh(2x/3), for hidden units (Efficient BackProp, 1998, sections 4.3 and 4.4).

Where they still live. Inside gates, where a value between 0 and 1 is the point: the LSTM's forget, input and output gates are sigmoids and its cell candidate a tanh ({{Sequence models: the pre-transformer lineage|n:3c65c17b0d0d818da4ded61ace6847ce}}); the gated units below move this idea into the feed-forward block. And at the output, for a binary or multilabel probability.

The ReLU family

ReLU, max(0, x), has slope exactly 1 for every positive input, so the gradient passes through any number of active layers unshrunk, and it costs one comparison. AlexNet made it the default: a four-layer convolutional network with ReLUs reached 25% training error on CIFAR-10 six times faster than the same network with tanh (Krizhevsky, Sutskever and Hinton 2012, section 3.1). Where ReLU came from (2010 and 2011)

It entered deep learning through restricted Boltzmann machines (Nair and Hinton 2010) and deep supervised networks (Glorot, Bordes and Bengio 2011, who stressed that it makes representations sparse: many units output exactly 0).

SELU's fixed point, reproduced (and ReLU's factor of 2)
