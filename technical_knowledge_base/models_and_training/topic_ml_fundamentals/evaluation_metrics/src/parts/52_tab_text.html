Text metrics lab: your sentences, every overlap score

Edit the reference or the candidate and every score recomputes in your browser with the same ports used in Reading, section 5 (sacreBLEU's sentence BLEU and chrF, rouge-score's ROUGE, NLTK's METEOR without WordNet; ROUGE-S is implemented from Lin 2004). BERTScore needs roberta-large, which cannot run in this page, so it is shown for the preset sentences only, from the library.

Try: start from the reference and change one word at a time. Swap two clauses, drop "new", turn "approved" into "did not approve", or write the sentence in your own words. Watch which scores move and which do not.
