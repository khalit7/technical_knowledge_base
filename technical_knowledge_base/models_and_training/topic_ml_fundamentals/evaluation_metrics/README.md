# Evaluation metrics

Notion: https://app.notion.com/p/3c65c17b0d0d81a29acef722e842a29b

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). Threshold metrics, ROC and precision-recall, calibration, multi-class averaging, BLEU / ROUGE / METEOR / chrF / BERTScore, perplexity across tokenizers and error bars, computed on real model outputs (SST-2 classifiers, three small language models, roberta-large) with every metric engine checked against scikit-learn, sacrebleu, rouge-score, NLTK and bert-score. Tabs: Reading, Threshold lab, Text metrics lab, Further reading. No child pages, databases or video. A child of Topic: ml-fundamentals.
