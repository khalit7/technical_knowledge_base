Site: https://khalit7.github.io/technical_knowledge_base/models_and_training/topic_ml_fundamentals/evaluation_metrics/

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). Threshold metrics, ROC and precision-recall, calibration, multi-class averaging, regression and ranked-list metrics, BLEU / ROUGE / METEOR / chrF / BERTScore, perplexity across tokenizers and error bars, computed on real model outputs (SST-2 classifiers, a diabetes regression, three small language models, roberta-large) with every metric engine checked against scikit-learn, sacrebleu, rouge-score, NLTK and bert-score. Tabs: Reading (the threshold explorer is its hero), Further reading; rebuilt 2026-10-24 to the teaching contract. No child pages, databases or video. A child of Topic: ml-fundamentals.
