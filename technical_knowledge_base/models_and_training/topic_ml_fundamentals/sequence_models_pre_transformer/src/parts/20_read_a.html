The idea in one screen

A recurrent network carries the whole past in one state, updated one step at a time, so the first token reaches the last output only through one multiplication per step, forward and backward. Each model in this lineage shortened or protected that path: gates gave it an additive lane (LSTM, GRU), attention let the output read every state directly (Bahdanau 2014), dilated convolutions cut it to log2 n layers with no recurrence (WaveNet 2016), and the transformer kept only attention: one hop between any two positions, every position computed at once in training.

The figure beside this is the whole page in five lanes: each design below it in the order the page takes them, with the path from the first token to the last output drawn in blue.

Attention in its modern forms (multi-head, GQA, MLA) is {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846}}'s; this page has only the 2014 form that bridged RNNs to transformers.

Recurrence: one state, carried forward

The running example is a task that needs memory and nothing else: a key (a, b, c or d), then a run of random distractors (w, x, y, z), then "?", and the network must answer the key. An 8-unit network reading b w w z y y x w w ? has to carry "b" across every distractor in 8 numbers. A recurrent network does it with one update applied at every step (Elman 1990):

at = f(U xt + W at−1 + b),   yt = g(V at)
at
the hidden state, the network's whole memory of the past
U, W, V
input, recurrent and output weights, the same at every step: a fixed number of parameters whatever the sequence length (the toy plain RNN has 188 with its 4-way readout)
f, g
usually tanh for the state; softmax for a distribution over outputs

Fig. 2 runs that sequence through a trained plain RNN, the one trained on sequences of 5 to 10 symbols (the Measured section has why that matters), with its real weights and states.

  1. Ten symbols, one per step. The key "b", eight distractors and "?" enter from below, left to right. Nothing else reaches the network.
  2. One cell. At step 1 the input weights U (orange glass) read the key and the recurrent weights W (blue glass) read the previous state, all zeros: the new state a1 is 8 numbers, drawn as bars above and below a white plinth.
  3. The same cell at every step. Ten copies of one cell with the same U and W: the state flows from each copy into the next, and each new state mixes the old one with one more symbol. This is the unrolled network; its size grows with the sequence, its weights do not.
  4. The answer at "?". V reads the last state and a softmax gives the four keys' probabilities: "b" gets 0.999. The key crossed nine updates to get there.
  5. Backpropagation through time. The gradient goes back from the answer through the same ten copies, once through W and the tanh slope per step. Each column is the factor it has been multiplied by on the way, ‖∂a10/∂ak‖ on this sequence (log scale): 0.16 three steps back, 0.011 at its smallest and 0.023 at the key.
  6. Every copy adds to the same weights. The copies share W, so the gradient each copy contributes is added into the one matrix: the update that teaches the network to store "b" arrives from the key's copy, already shrunk.

It is trained by backpropagation through time (BPTT; Werbos 1990): unroll the network into one layer per time step, all sharing weights, run ordinary backpropagation, and add up the gradients each copy contributes to the shared weights. Long sequences are usually cut into windows (truncated BPTT), which also caps how far back any gradient can reach.

The gradient shrinks by a roughly constant factor per step, and the LSTM's factor is closest to 1

Measured: norm of the loss gradient with respect to the hidden state k steps before the answer, relative to the answer's, mean of the same 256 sequences of length 100, untrained networks (seed 0; the LSTM's forget-gate bias starts at 1, so its gates begin near σ(1) ≈ 0.73), PyTorch autograd (grad_init, src/model/train_memory.py).

The gradient through time: vanishing and exploding

The loss at "?" teaches the network to store the key only through the gradient that reaches the key's step, and that gradient crosses one Jacobian per step: ∂at/∂ak = ∏j diag(f′)W. Fig. 2 showed it on one sequence; the chart beside this measures it over 100 steps on the toy's untrained networks: the plain RNN before, the LSTM after.

Predict how many orders of magnitude separate the plain RNN from the LSTM 50 steps back, then watch it.

  1. At the answer. The gradient of the loss with respect to the last hidden state is the unit: every value on the chart is relative to it.
  2. 10 steps back. Each step multiplies by one Jacobian. On average the plain RNN loses a factor of 0.58 per step, the GRU 0.64 and the LSTM 0.79 derived (from the curves between 10 and 50 steps back).
  3. 30 steps back. A constant factor per step compounds: the curves are straight lines on a log scale, which is what "exponential" means. The gap is already 3.0 orders of magnitude.
  4. 50 steps back: the key of a 50-symbol sequence. This is what the training signal must cross to teach the network to store the key: 10−11.8 for the plain RNN, 10−9.6 for the GRU, 10−6.1 for the LSTM, 5.7 orders of magnitude apart.
  5. 86 steps back. The plain RNN's recorded gradient is now exactly zero, too small for the arithmetic to hold; the LSTM's is still 10−9.4.
  6. 99 steps back. Even the LSTM is at 10−10.7, far below 1: untrained, its forget gates start near σ(1) ≈ 0.73, so the gate path protects the gradient but does not keep it whole until training opens the gates.

The rule behind the picture (Pascanu, Mikolov and Bengio 2013, §2.1): if the largest eigenvalue of W (in absolute value) is below 1/γ, where γ bounds |f′| (1 for tanh, 1/4 for the sigmoid), the long-term terms vanish exponentially; above it is necessary, not sufficient, for them to explode. Exploding gradients have a cheap fix the same paper proposed, clipping the gradient's norm (the toys clip at 1); vanishing ones need a change of architecture. The difficulty was first identified in Hochreiter's 1991 diploma thesis and by Bengio, Simard and Frasconi 1994.
