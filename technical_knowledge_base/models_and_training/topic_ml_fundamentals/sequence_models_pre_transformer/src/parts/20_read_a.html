The idea in one screen

A recurrent network carries the whole past in one state, updated one step at a time, so the first token reaches the last output only through one multiplication per step, forward and backward. Each model in this lineage shortened or protected that path: gates gave it an additive lane (LSTM, GRU), attention let the output read every state directly (Bahdanau 2014), dilated convolutions cut it to log2 n layers with no recurrence (WaveNet 2016), and the transformer kept only attention: one hop between any two positions, every position computed at once in training.

The path from the first token to the last output shrinks from 8 hops to 1, and the steps that must run in order from 8 to none

Recurrence: one state, carried forward

The running example is a task that needs memory and nothing else: a key (a, b, c or d), then a run of random distractors (w, x, y, z), then "?", and the network must answer the key. An 8-unit network reading b x w z y ... ? has to carry "b" across every distractor in 8 numbers. A recurrent network does it with one update applied at every step (Elman 1990):

at = f(U xt + W at−1 + b),   yt = g(V at)
at
the hidden state, the network's whole memory of the past
U, W, V
input, recurrent and output weights, the same at every step: a fixed number of parameters whatever the sequence length (the toy plain RNN has 188 with its 4-way readout)
f, g
usually tanh for the state; softmax for a distribution over outputs

It is trained by backpropagation through time (BPTT; Werbos 1990): unroll the network into one layer per time step, all sharing weights, run ordinary backpropagation, and add up the gradients each copy contributes to the shared weights. Long sequences are usually cut into windows (truncated BPTT), which also caps how far back any gradient can reach.

The gradient through time: vanishing and exploding

The loss at "?" teaches the network to store the key only through the gradient that reaches the key's step, and that gradient crosses one Jacobian per step: ∂at/∂ak = ∏j diag(f′)W. The gradient shrinks by a roughly constant factor per step, and the LSTM's factor is closest to 1

Measured: norm of the loss gradient with respect to the hidden state k steps before the answer, relative to the answer's, mean of the same 256 sequences of length 100, untrained networks (seed 0; the LSTM's forget-gate bias starts at 1, so its gates begin near σ(1) ≈ 0.73), PyTorch autograd (grad_init, src/model/train_memory.py). 50 steps back: 10−11.8 plain RNN, 10−9.6 GRU, 10−6.1 LSTM. Past 86 steps the plain RNN's is exactly zero.

The rule behind the picture (Pascanu, Mikolov and Bengio 2013, §2.1): if the largest eigenvalue of W (in absolute value) is below 1/γ, where γ bounds |f′| (1 for tanh, 1/4 for the sigmoid), the long-term terms vanish exponentially; above it is necessary, not sufficient, for them to explode. Exploding gradients have a cheap fix the same paper proposed, clipping the gradient's norm (the toys clip at 1); vanishing ones need a change of architecture. The difficulty was first identified in Hochreiter's 1991 diploma thesis and by Bengio, Simard and Frasconi 1994.
