# Classical ML

Notion: https://app.notion.com/p/3c65c17b0d0d81ffb886ff30176bc6ce

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). Linear models and naive Bayes, decision trees, bagging and boosting (XGBoost, LightGBM, CatBoost), the dated evidence on whether boosted trees still win on tables (TabArena and BeyondArena, 2 October 2026), SVMs, kNN, clustering, anomaly detection, PCA / t-SNE / UMAP and hyperparameter search. Every model runs live in the page, written to match scikit-learn and checked against it. Tabs: Reading, Boundary lab, Further reading. No child pages, databases or video. A child of Topic: ml-fundamentals.
