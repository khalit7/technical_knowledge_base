## Decisions and notes
- Muon follows `torch.optim.Muon` (PyTorch 2.14 source read on 2026-10-03): buffer lerp with momentum 0.95, Nesterov, Newton-Schulz with (3.4445, -4.7750, 2.0315), five steps, Frobenius normalisation with eps 1e-7, decoupled decay `p *= 1 - lr*wd` with the unadjusted rate, and `adjust_lr_fn="match_rms_adamw"` (0.2 sqrt(max(A, B))) so one learning rate serves Muon and the AdamW used for non-square and non-hidden weights. PyTorch casts to bfloat16 inside Newton-Schulz; the check patches in a float64 copy and reports the bfloat16 difference (2e-3 to 5e-3 relative on the weights after 40 steps).
- Weight decay applies to weight matrices only (PyTorch param groups in the check).
- The plotted loss is cross-entropy for every run so that MSE, focal and smoothed runs share an axis.
- Overfitting presets use two moons, 80 points, 20% flipped labels, width 48, depth 3, Adam at 0.003 constant, 2,000 steps; tested first on spirals and circles at width 64 and 3,000 steps (same conclusions, slower).
- Warmup preset found by a sweep (see `viz_ideas.md` LB-12).
