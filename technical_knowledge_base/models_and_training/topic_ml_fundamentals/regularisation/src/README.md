Source of the interactive HTML on the Notion page "Regularisation" (child of Topic: ml-fundamentals).

Build: `sh build.sh` writes `../index.html` (parts listed explicitly). Data parts are generated: `uv run --with scikit-learn --with numpy python mk_diabetes.py` (parts/20_js_diab.js, inputs/diabetes.csv); `OMP_NUM_THREADS=2 uv run --with torch --with scikit-learn --with numpy python train_digits.py` (parts/30_js_digits.js, inputs/digits_mlp.json; a few minutes); `OMP_NUM_THREADS=2 uv run --with scikit-learn --with numpy python double_descent.py && python3 mk_parts_data.py` (parts/31_js_dd.js).

Shape: Part B of `html_utils/methods/topic_pages.md` (a child page). Reading follows the subject's logic: in one screen (technique, where it acts, knob, use in 2026), what regularisation is (penalty, constraint, prior), penalties with the geometry animation, weight decay (the regularisation side only; AdamW mechanics stay on the Optimisers sibling and the parent's thread 4), dropout (corrected retention, p conventions, train/inference animation, linear-model equivalence, production table), augmentation and mixing, early stopping, what each buys (published comparisons), big networks (memorisation, double descent, grokking), common mistakes. Tabs: Coefficient paths, Dropout as an ensemble, Further reading. The parent's Training lab presets and When training goes wrong runs are linked by name, not rebuilt; "Debugging training" was folded into that tab, so the old cross-link points there.

Checks:
- `node check_core.mjs && uv run --with scikit-learn --with numpy --with torch python recompute.py`: the page's JS (lasso path by LARS, ridge, elastic net, gradient descent, held-out splits, PRNG, the dropout network's forward pass and thinned networks) against scikit-learn 1.9 and PyTorch, plus the published figures (Efron et al. section 1) and Srivastava et al.'s input-dropout = ridge result by Monte Carlo; 37 checks, results in `check/`.
- `node src/check_page.mjs` (from the repo root): every control and animation step in headless Chrome, light 920 px and dark 390 px; fails on script errors, NaN, undefined or Infinity; element screenshots in `../.shots/`.
- `coverage.json`: every fact of `live.md` and where the page carries it. `viz_ideas.md`: ranked ideas.
