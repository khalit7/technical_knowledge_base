The core idea. Almost every LLM in 2026 is one decoder block repeated L times around a residual stream: each block lets every position read earlier positions (the sequence mixer), then transforms each position on its own (the feed-forward network), and nearly every design choice since 2017 trades quality against what one token costs to keep, read and compute in one of those two places.

You need a neural network, a matrix multiply and a softmax. If the transformer itself is rusty, {{The transformer from zero|n:3fd5c17b0d0d8174980ddde4a20c7b3c}} first.

New terms on this page (each defined again where it is used):
Residual stream: the vector each position carries through the stack; blocks only add to it.
Sequence mixer: the sublayer where a position reads other positions (attention, or a recurrent layer).
KV cache: the keys and values of past tokens that attention keeps so it never recomputes them.
Prefill / decode: processing the prompt at once (compute-bound) / one new token per step (memory-bound).
Total / active parameters: what must sit in memory / what one token multiplies through (they differ in MoE).
Hybrid: a stack that mixes a few attention layers with many fixed-state recurrent layers.

1. The decoder in one screen

Fig. 1 is one block of Llama 3.1 8B, the model sections 2 and 3 count, with tokens in and a distribution out. Every plate is a weight matrix d = 4,096 tall and as deep as its other side, to scale, so the sizes are the real ones; only the two vocabulary tables are drawn shortened. Each step lights one part and names the page that owns it.

  1. Tokens in. A tokenizer cuts text into ids from a vocabulary of 128,256; each id picks one row of the 128,256 × 4,096 embedding table, 525.3M weights (the four words are illustrative). Owner: {{Tokenizers|n:3c65c17b0d0d817187bcd94a1b0f15ea#stg-hero}}.
  2. The residual stream and its norms. The stream holds one vector of d numbers per position (4,096 here); each sublayer reads an RMSNorm copy (4,096 learned gains) and adds its result back, so blocks only ever add. Owner: {{Normalisation, residuals and stability|n:3fd5c17b0d0d8163b50dc5e9d9240e89#stg-place}}, whose Fig. 2 moves the norm.
  3. Attention, with position. Wq and Wo are 4,096 × 4,096, but Wk and Wv only 4,096 × 1,024, because the 32 query heads share 8 KV heads (GQA): 41.9M weights in all. RoPE turns each query and key by its position before they meet. Owners: {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846#stg-gqa}} (Fig. 3, heads sharing KV heads) and {{Positional Encodings|n:3c65c17b0d0d81a5b7c9e578fcdfac00#stg-rope}} (Fig. 4, the RoPE dials).
  4. The KV cache grows. Every past token leaves its keys and values in every layer: 2 × 32 layers × 8 KV heads × 128 × 2 bytes = 128 KiB per token, 16 GiB for one 128K request (derived), and every decode step reads all of it (section 4). Owners: {{Long context|n:3fd5c17b0d0d81059ee1ce20c0326dc5#stg-hero}} sizes it; {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846#stg-cache}} shrinks each entry.
  5. Or a fixed state. A recurrent or state-space layer folds each token into a state of fixed size instead (drawn illustrative), so memory per sequence stops growing, at the price of exact recall; hybrids keep a few attention layers that still grow a cache (section 4). Owner: {{Beyond attention|n:3fd5c17b0d0d8142bc9ecac1fc366966#stg-rec}}.
  6. The FFN: four fifths of the block. SwiGLU's three plates hold 3 × 4,096 × 14,336 = 176.2M weights, 81% of the block's 218.1M. Mixture of experts cuts this part into many experts and a router runs a few for each token (8 and 2 drawn, illustrative): MoE targets the FFN because the weights are there. Owner: {{Mixture of experts|n:3fd5c17b0d0d81fda06bf955af7c2b58#stg-rt}}.
  7. 32 blocks on one stream. The block repeats 32 times, 218.1M weights each; with the two vocabulary tables that makes 8.03B, the model's size. Owners: {{The transformer from zero|n:3fd5c17b0d0d8174980ddde4a20c7b3c#stg-hero}} builds and trains this block; the {{LLM architecture gallery|n:3c65c17b0d0d81be8a07f2562fa2030a#stg-hero}} stacks released models layer by layer from their configs.
  8. A distribution out. A final RMSNorm and the 4,096 × 128,256 unembedding give one logit per vocabulary entry, and a softmax turns them into next-token probabilities (bar heights illustrative). Training predicts every position's next token at once under a causal mask; what the mask and the objective can be instead: {{Families and objectives|n:3fd5c17b0d0d8105b616c17c1439f766#stg-mask}}.
