The core idea. Almost every LLM in 2026 is one decoder block repeated L times around a residual stream: each block lets every position read earlier positions (the sequence mixer), then transforms each position on its own (the feed-forward network), and nearly every design choice since 2017 trades quality against what one token costs to keep, read and compute in one of those two places.

One decoder block, repeated L times: every part is a choice, and one child page owns each

Each box opens the page that owns it. The left rail is the residual stream, one vector of d numbers per position (4,096 in Llama 3.1 8B); each sublayer reads a normalised copy and adds its result back at ⊕. The two rows inside the block are where the choices compared on this page live. {{The transformer from zero|n:3fd5c17b0d0d8174980ddde4a20c7b3c}} builds this exact block from an empty file and trains it; the {{LLM architecture gallery|n:3c65c17b0d0d81be8a07f2562fa2030a}} reads real 2026 configs part by part.

You need a neural network, a matrix multiply and a softmax. If the transformer itself is rusty, {{The transformer from zero|n:3fd5c17b0d0d8174980ddde4a20c7b3c}} first.

New terms on this page (each defined again where it is used):
Residual stream: the vector each position carries through the stack; blocks only add to it.
Sequence mixer: the sublayer where a position reads other positions (attention, or a recurrent layer).
KV cache: the keys and values of past tokens that attention keeps so it never recomputes them.
Prefill / decode: processing the prompt at once (compute-bound) / one new token per step (memory-bound).
Total / active parameters: what must sit in memory / what one token multiplies through (they differ in MoE).
Hybrid: a stack that mixes a few attention layers with many fixed-state recurrent layers.
