0. In one screen

A decoder-only transformer is nine pieces of code: a table that turns token ids into vectors, an attention layer that lets each position read earlier positions, a small MLP applied to every position on its own, a residual sum and a normalisation around each of those two, a stack of such blocks, a matrix that turns the last vector into one score per vocabulary entry, and a cross-entropy loss against the next token. This page writes those pieces into an empty file, gpt_zero.py ([[f:file_lines|i]] lines when finished), tests each one on the running sequence as it is added, trains the result, samples from it, counts its parameters and FLOPs by hand, and then removes one piece at a time to see what each one buys.

1. The task, the running example and the notation

A language model assigns a probability to the next token given the tokens before it. A decoder-only transformer computes, in one pass over a sequence of T tokens, T such distributions at once: position t predicts token t + 1 using only positions 0 to t. Training lowers the average cross-entropy, minus the log probability the model gave to the token that actually came next, measured in nats (natural-log units; a loss L means the model was, on average, as unsure as a uniform choice among eL tokens, the perplexity).

The running example (defined once for the whole topic by the root page): TinyStories (Eldan and Li 2023, {{arXiv 2305.07759|https://arxiv.org/abs/2305.07759}}; licence CDLA-Sharing-1.0), short stories written by GPT-3.5 and GPT-4 for training small models; a byte-level BPE tokenizer of V = 4,096 tokens trained on it; and the running sequence, the first 256 tokens of validation story 1, never seen in training:

Once upon a time, in a big forest, there lived a rhinoceros named Roxy. Roxy loved to climb. She climbed trees, rocks, and hills. One day, Roxy found an icy hill. She had never seen anything like it before. It was shiny and cold, and she wanted to climb it. ...

The model is the root's tiny GPT: D = 256 numbers per position, L = 6 blocks, H = 8 heads of hd = 32, a 1,024-wide feed-forward network, a context of 256 tokens, tied embeddings. Every shape on this page uses these letters:

Bbatch: sequences processed together (32 in training, 1 for the running sequence)
Ttokens per sequence (256)
Dmodel width, the length of the vector each position carries (256; 4,096 in Llama 3.1 8B)
H, hdattention heads and the width of each, hd = D / H (8 and 32; 32 and 128 in Llama 3.1 8B)
Ffeed-forward hidden width (1,024 = 4D; 14,336 in Llama 3.1 8B)
V, Lvocabulary size and number of blocks (4,096 and 6; 128,256 and 32)

Real-model numbers are from the configs saved by the root ({{Llama 3.1 8B config.json|https://huggingface.co/unsloth/Meta-Llama-3.1-8B/raw/main/config.json}}, read 2026-10-18). The code that follows is the file that produced every measurement on this page; the {{Build it up|#t-build}} tab steps through it with each step's shapes and test output.
