1. One block, four masks

Attention scores form a T by T matrix: row i is the query (the position asking), column j the key (the position read). The mask adds minus infinity to forbidden cells before the softmax, so their weight is exactly zero. Left unmasked, a model asked to predict token i+1 while it can see token i+1 learns to copy; the mask is how one architecture serves both understanding and writing. Which keys each query may read, and what that lets you cache

The mask is free and decides the cache. Same FLOPs, same parameters. A causal model's past keys and values never change when a token arrives, so they are computed once and kept: the KV cache. Under a bidirectional mask every new token changes every earlier position's output, so an encoder or a diffusion LM recomputes the whole sequence every pass. An encoder-decoder's decoder caches its own causal KV plus the cross-attention keys and values of the encoder output, computed once per input; T5Gemma 2 fuses the decoder's self- and cross-attention into one attention with one mask.

A mask is a training-time contract. We took the reference tiny GPT, trained causally, and changed only the mask at inference (src/lab/masks.py, the topic's 20 fixed held-out batches of 32 windows, 640 windows of 256 tokens; correction: the 2026-10-18 page said "20 windows", checked against the script). The code that ran. The topic's tiny GPT builds an additive mask in attn_bias (root src/data/tiny_gpt.py); this page swaps in a version with a mode switch without editing the shared file (src/lab/fo_common.py):

MASK = {"mode": "causal", "prefix": 0}

def attn_bias(cfg, layer_idx, q_pos, k_pos, device, slopes=None):
    diff = q_pos[:, None] - k_pos[None, :]
    if MASK["mode"] == "causal":
        keep = diff >= 0
    elif MASK["mode"] == "bidir":
        keep = torch.ones_like(diff, dtype=torch.bool)
    elif MASK["mode"] == "prefix":
        keep = (diff >= 0) | (k_pos[None, :] < MASK["prefix"])
    return torch.zeros(keep.shape, device=device).masked_fill(~keep, float("-inf"))[None]

def enable_masks():
    tiny_gpt.attn_bias = attn_bias
    tiny_gpt.is_local = lambda cfg, li: True   # forces the explicit softmax path (SDPA would apply is_causal)


Output of masks.py (scrubbed of timings), Apple M1 Pro, CPU, torch 2.14.1. The is_local override matters: the tiny GPT's fast path calls F.scaled_dot_product_attention(..., is_causal=True) and would ignore any custom mask.

Which positions are masked or corrupted is one seeded draw (illustrative positions); the rules are the real ones.




    

  • Causal LM (CLM). Target: the text shifted left by one; a 256-token window gives 255 loss terms (the topic's trainer reads 257 tokens and scores all 256). It won because every token of every document is a training example, any task can be written as a prompt, and the model generates with the same forward it was trained with; {{Pretraining|n:3c65c17b0d0d814f82cffd0d5c0dd5ba}} runs it at scale. The costs: a strict left-to-right loop at inference and no right-hand context for the token being predicted.
    • 

  • Masked LM (MLM). BERT ({{BERT paper page|n:3c65c17b0d0d81e5ad9bd09cbf18ad7c}}) picks 15% of positions; of those, 80% become [MASK], 10% a random token, 10% stay unchanged, because [MASK] never appears at fine-tuning and a model that only sees [MASK] at scored positions learns nothing useful about real tokens there. transformers 5.20.1 keeps these defaults in DataCollatorForLanguageModeling: mlm_probability = 0.15, mask_replace_prob = 0.8, random_replace_prob = 0.1 (data/data_collator.py lines ). The cost is signal: about 38 loss terms per 256-token window against CLM's 255. ELECTRA ({{Clark et al. 2020|https://arxiv.org/abs/2003.10555}}, ICLR 2020) answered with replaced-token detection, where "the task is defined over all input tokens rather than just the small subset that was masked out"; ModernBERT raised the masking rate to 30%.
    • 

  • Span corruption (T5). Contiguous spans are replaced by one sentinel each (<extra_id_0>, ...); the target is each sentinel followed by the tokens it replaced. T5's default corrupts 15% in spans of mean length 3 ({{T5 paper page|n:3d45c17b0d0d81ec8ebfec02e953a7fd}}, whose Reading runs T5's own masking code on text you type). Per 512 input tokens the target is  tokens ( corrupted,  sentinels, one end token), so the decoder, the expensive autoregressive half, works on about a fifth of the text.
    • 

  • Prefix LM, MTP and masked diffusion have their own sections (6, 7, 8). Masked diffusion is MLM with the rate drawn at random between 0 and 1 per sequence and each term weighted by one over it: at rate 0.15 it is exactly BERT's objective, and the random rate is what makes it a generator.
