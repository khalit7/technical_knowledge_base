0. In one screen

A language model is a stack of identical transformer blocks. Two choices turn that one stack into every family on this page: the attention mask (which positions each position is allowed to read) and the training objective (which tokens the model is asked to predict, from what input). Everything else (width, depth, attention variant, MoE) is shared.

The three things to remember

1. A mask is a training-time contract: a causal model run with a bidirectional mask is a different, untrained model (measured below: held-out loss becomes ). 2. Every objective is a trade between how much training signal each sequence gives and what the model can do at inference. 3. MTP and diffusion attack the same cost from two sides: the one-token-per-forward loop of a decoder. MTP keeps the loop and guesses one more token; diffusion drops the loop and pays for full bidirectional passes instead.

1. One block, four masks

The problem. Self-attention, left alone, lets every position read every other position. That is right for understanding a finished text and wrong for writing one: a model that learns to predict token i+1 while it can see token i+1 learns to copy. The mask is how one architecture serves both jobs.

How it works. Attention scores form a T by T matrix: row i (the query, the position asking) against column j (the key, the position being read). The mask adds minus infinity to the forbidden cells before the softmax, so their weight is exactly zero. Which keys each query may read

  • Causal: query i reads keys 0 to i (the lower triangle). In transformers 5.20.1 this is literally kv_idx <= q_idx (masking_utils.py line ).
  • Bidirectional: every query reads every key; the same file's bidirectional_mask_function returns q_idx >= 0, always true (line ). ModernBERT sets self.is_causal = False (modeling_modernbert.py line ).
  • Prefix LM: the first P positions (the prompt) read each other both ways; positions after P read everything before them, causally.
  • Encoder-decoder: two stacks. The encoder runs bidirectionally over the input; the decoder runs causally over the output and, in each block, a cross-attention layer reads every encoder output. T5Gemma 2 merges the decoder's self- and cross-attention into one attention over the concatenation, with one fused mask (modeling_t5gemma2.py line : "Fused causal and encoder mask").

What it costs. The mask itself is free: same FLOPs, same parameters. What changes is what can be cached. A causal model's keys and values for past tokens never change when a new token arrives, so they are computed once and kept (the KV cache, owned by {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846}}). Under a bidirectional mask every new token changes every earlier position's output, so nothing can be reused: an encoder or a diffusion LM recomputes the whole sequence every pass. An encoder-decoder caches two things in its decoder: its own causal KV, and the cross-attention keys and values of the encoder output, computed once per input.

When it matters, and how to check it. A causal model can be run with a different mask only if it was trained with it.
