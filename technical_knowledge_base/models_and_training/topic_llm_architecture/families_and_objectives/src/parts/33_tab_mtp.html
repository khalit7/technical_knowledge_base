MTP lab

Depth-1 MTP modules on the topic's reference tiny GPT (frozen), used as drafts for self-speculative greedy decoding. One prompt, the running sequence's opening, decoded twice: with the sequential module that is told the next token (DeepSeek-V3's design) and with a parallel head that is not (Gloeckle et al.'s). Every forward of the main model checks the previous draft and makes a new one; it emits 2 tokens when the draft was right and 1 when it was wrong. The output is identical to plain greedy decoding either way; only the number of forwards changes. Reading section 7 has the design, the published results and the joint-training runs; the {{Speculative decoding|n:3f35c17b0d0d81e086fde85940ebac1c}} page owns serving.

Acceptance counts every forward after the first (which has no draft yet). The joint-trained column uses the main model and module trained together from scratch (Reading section 7), decoding that model's own greedy text.

Acceptance to tokens per forward

derived: expected tokens per forward = 1 + a + a² + ... + ak when each further draft token is accepted with the same probability a and only after the previous one (the chain stops at the first rejection). Defaults: DeepSeek-V3's lower reported acceptance (85%) at its trained depth 1, which gives 1.85 tokens per forward against the 1.8x TPS they report (vendor, section 5.4.3): the small gap is the cost of the extra module and verification. Training the two modules

Training loss on the token two places ahead, 600 steps of 16 windows of 256, AdamW lr 1e-3, only the module learning (the trunk, embedding, final norm and head are the reference's, frozen). The sequential module starts from a better place because it is given the real next token. Parameters: sequential (one block plus the 512 to 256 projection and two norms), parallel ; main model .
