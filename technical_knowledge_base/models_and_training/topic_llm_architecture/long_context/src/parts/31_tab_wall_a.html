Usable memory per GPU is taken as 92% of capacity, vLLM's default gpu_memory_utilization (read in vLLM v0.31.0 source on {{Batching, KV cache and scheduling|n:3c65c17b0d0d819db53bd2c48909e5b2}}); weights are split evenly across the GPUs; activations and engine workspace live in the other 8%. Recurrent layers (Mamba-2, Gated DeltaNet) add a constant state per sequence, in fp32 as the calculator assumes. Eviction is counted as if every dropped entry were freed: that is the algorithmic saving; a paged engine reclaims only whole blocks, which per-head policies rarely empty (measured on Batching, KV cache and scheduling).
