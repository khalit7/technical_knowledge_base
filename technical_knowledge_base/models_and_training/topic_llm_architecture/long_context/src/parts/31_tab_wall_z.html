Predict. Gemma 3 27B on one 80 GB GPU, bf16 weights and cache, 128K-token requests. How many fit as released (5 local : 1 global, window 1,024), and how many if every layer were global?
One as released (11.17 GB of cache per request after 54 GB of weights), none if every layer were global (66.57 GB for a single request). The local layers are what make 128K servable at all on one GPU; for many concurrent long requests the weights would go to fp8 and the cache to fp8 as well. Set the Memory wall to Gemma 3 27B and try it.

What this tab does not model: activation memory during a long prefill (chunked prefill bounds it), fragmentation and block granularity (PagedAttention keeps waste under a block per sequence), tensor-parallel replication of KV heads when there are fewer KV heads than GPUs, and quality: every lever but the dtype changes the model (the Eviction lab measures what imposing them costs).
