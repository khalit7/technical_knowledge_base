4. The per-layer strips

A card's "layer mix" line ("52 sliding-window + 10 global") hides where those layers sit, and position matters: Gemma 3 puts a global layer after every five windowed ones so that information never travels more than five layers before it can reach the whole context, while a model that put all its global layers at the end would not. The strips draw each layer in order, left (layer 0, next to the embedding) to right (the last layer, next to the output head), each model stretched to the same width.

Three bars per model: mixer, FFN, position. The number on the right is the KV cache per token in bf16 (every layer at full cost). Click a name to open that model in {{Decode a config|#t-dec}}. The tiny GPT is this topic's running example (6 layers of multi-head attention with learned positions, 6,144 bytes per token), drawn on the same scale of colours.

How to read one. Count the blue, green and purple cells in the top bar: full attention, MLA and trained sparse layers, the ones whose cache grows with every token. Yellow cells (linear) and teal cells (windowed) stop growing. Orange cells in the middle bar are expert layers, so a grey first cell is the dense prefix DeepSeek-style models keep. A black cell (white in dark mode) in the bottom bar is a layer with no positional encoding: Llama 4 Maverick's every fourth layer, SmolLM3's every fourth, Kimi K3's attention layers. The {{Compare architectures|#t-cmp}} tab has the strips for every model, sortable and filterable.

5. Seven answers to one question

The mixer bar has seven colours because there are, in practice, seven answers to one question: what must this token leave behind in this layer so that later tokens can use it? A key and a value for every query head (MHA), one per group of heads (GQA) or one for all (MQA), a compressed latent from which every head rebuilds its own (MLA), the same entries kept only for the last W tokens (a sliding window), or a fixed-size recurrent state instead of a growing cache (Gated DeltaNet, KDA). How the attention answers work and what each costs in quality, MLA's absorbed form and decoupled RoPE key included, is taught once, with a figure of what one past token leaves behind under each, on {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846}}; the recurrent ones on {{Beyond attention|n:3fd5c17b0d0d8142bc9ecac1fc366966}}; what a whole model holds at a given context in the {{KV-cache calculator on Long context|n:3fd5c17b0d0d81059ee1ce20c0326dc5#t-kv}}. This page's question is narrower: which answer each released model chose, and in what mixture. The next sections take the deltas one at a time.
