5. Delta one: what each token stores

Every decoded token reads the keys and values of every earlier token in every attention layer, so the bytes per entry are decode time as well as memory. At Llama 3.1 70B's shape with all 64 heads (MHA) that would be 2,560 KiB per token, 320 GiB for one 128K request; GQA keeps one key and value head per group (Llama 3.1 70B: 64 query heads, 8 KV heads, 320 KiB per token), and MLA a 512-number latent plus a 64-number positional key per layer whatever the head count (DeepSeek-V3: 61 × 576 × 2 = 68.6 KiB per token). Fewer KV heads cost a little quality and MLA costs extra projections and its own kernels; why, and how MLA rebuilds the heads, is on {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846}}.

How to check: num_key_value_heads × head_dim × 4 bytes per attention layer (K and V, 2 bytes each), or (kv_lora_rank + qk_rope_head_dim) × 2 for MLA, then count the layers that grow a cache. The table does that for ten models.

Sparse attention does not shrink the cache. Selecting the top k keys cuts arithmetic, not storage: every key must stay available to be selected, and the indexer adds keys of its own. DeepSeek V3.2 keeps V3's 68.6 KiB per token plus 15.25 KiB of indexer keys (61 × 128 × 2 bytes); storage falls only when entries are also compressed, as in V4 (section 10).

6. Delta two: how long it is kept (sliding windows)

Most layers attend only to the last W tokens (a sliding window) and every few layers a global layer attends to everything. A windowed layer stores the same entry per token as its base design but drops entries older than W, so one request at context T holds the sum over layers of bytes per token × min(T, W). That is why the card's figure, which counts windowed layers at full cost, overstates a windowed model's long-context cache. The price: information more than W tokens back reaches a token only through the global layers, so exact retrieval far back depends on how many there are. What windows cost in recall is on {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846}} and {{Long context|n:3fd5c17b0d0d81059ee1ce20c0326dc5}}; this section counts who uses them.
