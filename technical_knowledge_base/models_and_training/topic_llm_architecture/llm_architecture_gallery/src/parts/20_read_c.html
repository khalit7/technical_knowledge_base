5. Delta one: what each token stores

Every decoded token reads the keys and values of every earlier token in every attention layer, so the bytes per entry are decode time as well as memory. At Llama 3.1 70B's shape with all 64 heads (MHA) that would be 2,560 KiB per token, 320 GiB for one 128K request; GQA keeps one key and value head per group (Llama 3.1 70B: 64 query heads, 8 KV heads, 320 KiB per token), and MLA a 512-number latent plus a 64-number positional key per layer whatever the head count (DeepSeek-V3: 61 × 576 × 2 = 68.6 KiB per token). Fewer KV heads cost a little quality and MLA costs extra projections and its own kernels; why, and how MLA rebuilds the heads, is on {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846}}. 6. Delta two: how long it is kept (sliding windows)

Most layers attend only to the last W tokens (a sliding window) and every few layers a global layer attends to everything. A windowed layer stores the same entry per token as its base design but drops entries older than W, so one request at context T holds the sum over layers of bytes per token × min(T, W). That is why the card's figure, which counts windowed layers at full cost, overstates a windowed model's long-context cache. The price: information more than W tokens back reaches a token only through the global layers, so exact retrieval far back depends on how many there are. What windows cost in recall is on {{Attention variants|n:3fd5c17b0d0d8120859ecc2d0236e846}} and {{Long context|n:3fd5c17b0d0d81059ee1ce20c0326dc5}}; this section counts who uses them.

  1. Gemma 3 27B at 1,024 tokens: every layer holds the same. 62 layers of 8 KiB per token (16 KV heads of 128), each a bar as long as the tokens it holds. Below the window the windowed (teal) and global (blue) layers coincide: 496 MiB, card and held alike.
  2. At 8,192 tokens the windows stop. The 52 windowed layers keep their last 1,024 tokens (the band at the front) and drop older entries; the 10 global layers keep all 8,192. Held 1.03 GiB, against 3.88 GiB if every layer were global.
  3. At 131,072 tokens the windows are a sliver. 52 × 8 KiB × 1,024 = 416 MiB for the windowed layers, 10 × 8 KiB × 131,072 = 10 GiB for the global ones: 10.4 GiB held, against the card's 496 KiB × 131,072 = 62 GiB.
  4. gpt-oss-120b: one to one, 128-token windows. 18 windowed and 18 global layers of 2 KiB: the windows save half, 4.5 GiB held against 9 GiB on the card, because half the layers still grow.
  5. Gemma 4 31B: windows on the big layers. Its 50 windowed layers keep 16 KiB per token and its 10 global layers only 4 KiB (4 KV heads of 512, keys and values shared): 800 MiB + 5 GiB = 5.8 GiB held against 105 GiB on the card, 18 times less.

The ratios released. The local-to-global ratio runs from 1:1 (gpt-oss) through 3:1 (11 models, the most common) to 5:1 (Gemma 3 and 4), and windows from 128 tokens (11 models, gpt-oss and MiMo among them) to 8,192 (Llama 4's chunks).
