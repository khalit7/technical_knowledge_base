- DIFF Transformer (arXiv 2410.05258v2, Microsoft Research and Tsinghua): DiffAttn = (softmax(Q1K1/sqrt d) - lambda softmax(Q2K2/sqrt d)) V; lambda = exp(lq1.lk1) - exp(lq2.lk2) + lambda_init, lambda_init = 0.8 - 0.6 exp(-0.3 (l - 1)); per-head RMSNorm x (1 - lambda_init); "about 65% of model size or training tokens"; 6.8B matches 11B, 160B tokens match 251B; Table 8 (3B, 350B tokens) zero-shot 55.4 vs 56.2, 5-shot 56.4 vs 58.0; Table 2 multi-needle 4K N=6 R=2 0.55 vs 0.85; Table 3 answer 0.03 vs 0.27, noise 0.51 vs 0.01; Table 5 attention logit top-1 318.0 vs 38.8.
- GQA paper (arXiv 2305.13245): mean pooling of key and value heads "works better than selecting a single key and value head or randomly initializing"; alpha = 0.05; "GQA already achieves reasonable performance after conversion while MQA requires uptraining to be useful"; Figure 4 values not printed.
- Evan Miller, "Attention Is Off By One", 2023-07-24: softmax_1(x)_i = exp(x_i) / (1 + sum_j exp(x_j)).
