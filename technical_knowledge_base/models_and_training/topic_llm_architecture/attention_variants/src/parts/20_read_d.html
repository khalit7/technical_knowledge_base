4. Sliding windows and local : global layers

Concrete. Mistral 7B v0.1 lets every layer attend only to the last W = 4,096 tokens. The cache becomes a ring buffer of W entries per layer: "the keys and values for the timestep i are stored in position i mod W of the cache", which its paper says "reduces the cache memory usage by 8x" at 32K ({{Mistral 7B, section 2|https://arxiv.org/abs/2310.06825}}, vendor). Each entry is unchanged; what a layer keeps, and what a decoded token reads, stops growing at W.

Reach grows with depth (Fig. 5): after L local layers the last token can be influenced by the previous L · (W − 1) tokens. Mistral's paper says "hi can access tokens from the input layer at a distance of up to W × k tokens", about 131K for 32 layers of 4,096, a "theoretical attention span".

  1. One local layer. The last token of the 226-token running sequence (orange) reads only the last W = 16 tokens of layer 1 (lit); everything older is out of reach.
  2. Layer 2 relays. Each of those tokens had already mixed its own window in layer 1, so after two layers the last token can be influenced by the previous 2 × (W − 1) = 30 tokens: the reach climbs one window per layer.
  3. Six local layers. After all 6 layers the reach is 6 × (W − 1) = 90 tokens; Mistral 7B v0.1's 32 layers of 4,096 give the "about 131K" its paper calls a theoretical span.
  4. 2 local : 1 global. The front stack makes layers 3 and 6 global: after layer 3 every token reaches the last one directly, whatever W is (the tiny GPT's swa64_g3 pattern; Gemma 3 uses five then one).
  5. Theoretical, not guaranteed. In the all-local stack a far token must be relayed through every layer, one window per hop (back); through a global layer it arrives in one (front). Nothing guarantees a model learns the relay, which is why most window designs keep global layers.

Fig. 5 is a calculation of reachability (which positions can influence the query through some path), not of attention weights.

Interleaves. Most models that use windows keep some global layers. Gemma 3 uses "a pattern of 5 local layers for every global layer" with a span of "only 1024 tokens", introduced because of "the memory explosion of the KV cache" at 128K ({{Gemma 3 report|https://arxiv.org/abs/2503.19786}}, vendor); with a global layer after every five, information never travels more than five layers before it can reach the whole context. gpt-oss alternates "banded window and fully dense patterns, where the bandwidth is 128 tokens" ({{model card|https://arxiv.org/abs/2508.10925}}). Gemma 3's report measured the trade (section 5.2): ratio and window changes have "minimal impact on perplexity", and the cache overhead at 32K falls from 60% of model memory with global-only attention to under 15% with 1 : 3 and W 1,024 (figures as the Long context child quotes them).

Interleaves in other released models: Gemma 2 and 4, Llama 4's chunks (configs)

Gemma 2 alternates 1 : 1 with W 4,096 (context 8,192). Gemma 3 uses RoPE base 10K on local layers and 1M on global ones. Gemma 4 keeps 5 : 1 with W 1,024 (50 and 10 layers in the 31B config). Llama 4 uses chunked attention instead: 36 of Maverick's 48 layers attend only within fixed 8,192-token chunks (attention_chunk_size), a window that resets at each chunk boundary, and 12 are global (its config, as the {{LLM Architecture Gallery|n:3c65c17b0d0d81be8a07f2562fa2030a}} child reads it).

Cost, when, how to check. A local layer forgets everything older than W unless another layer carried it; interleaving brings back one full cache per global layer, so the long-context saving is set by the share of global layers (5 : 1 keeps about a sixth of the full cache). Kernels must handle the window (FlashAttention's window_size) and the cache must be a ring buffer or a paged cache that frees old blocks. It matters at contexts several times W; below W the window changes nothing. Check sliding_window and layer_types (Gemma 3: sliding_window_pattern, every 6th layer global). In transformers 5.20.1 a window keeps keys with kv_idx > q_idx - sliding_window, W keys including the query. Whole-model memory with windows credited, and what windows do to recall at 128K, are on {{Long context|n:3fd5c17b0d0d81059ee1ce20c0326dc5}}.
