6. Sinks and gates: where unused attention goes

Concrete. Softmax weights must sum to 1, so a head with nothing useful to read for this token still has to put its weight somewhere. Trained LLMs park it on a token whose value contributes little, nearly always the first: an attention sink (Xiao et al. 2023, StreamingLLM, {{arXiv 2309.17453|https://arxiv.org/html/2309.17453}}). In SmolLM2-135M the root's Inside lab found it switching on at layer 12 (Fig. 7, steps 1 to 3), together with a massive activation (dimension 507 of token 0's residual reaching 20,155 against a median 1.56), and found the sink to be a cache problem: evicting token 0 from a sliding cache breaks the model, and keeping the first four tokens instead of one also gives 1.81. StreamingLLM keeps the first four tokens beside the window and runs on streams of "up to 4 million tokens".

  1. The sink switches on at layer 12. SmolLM2-135M's weight on token 0 in each of its 30 layers (counted from 0, as the root's Inside lab does): at most 0.085 in layers 0 to 11, then 0.31 to 0.74 (red) from layer 12 on.
  2. Where the last token's weight goes. The last token of the running sequence in six layers (1, 6, 12, 18, 24, 30 counted from 1; mean of 9 heads; the rest binned by 9 positions): in the deep layers one column, token 0, outweighs whole stretches of real text.
  3. Evict token 0 and the model breaks. A 64-token sliding cache (lit) that drops token 0 (dashed) takes SmolLM2's loss on 1,024-token stories from 1.62 to 3.36; keeping token 0 as well gives 1.81.
  4. A learned sink logit sends weight nowhere. The tiny GPT trained with a sink logit per head (the topic's sink preset, gpt-oss style; layer 4, head 5, its most sink-heavy head, at the last position): 97% of this head's weight goes to the sink (red), a score with no value, so the real tokens get the 3% the head chose to spend.
  5. Remove the sink, renormalise. The same scores forced to sum to 1 over real tokens: weight the head wanted to discard lands on tokens it did not choose, and held-out loss rises from 2.074 to 2.175 (192 windows).
  6. Or close a gate. With a sigmoid gate on each head's output a head with nothing to say closes it instead of finding a sink: in the gated-attention paper's 15B MoE, attention on the first token falls from 46.7% to 4.8% (authors' runs).

Three fixes that remove the need for a real token.

  • A learned sink logit per head: an extra score column with no value, so a head can send weight "nowhere" and the real weights sum to less than 1. gpt-oss: "each attention head has a learned bias in the denominator of the softmax ... which enables the attention mechanism to pay no attention to any tokens" (model card, {{arXiv 2508.10925|https://arxiv.org/abs/2508.10925}}); DeepSeek-V4 uses one too. StreamingLLM's pretraining test (Table 10, 160M models, PG19): with one learned sink token the model reaches 18.01 perplexity with a 1 + 1,023 cache, against 18.49 for the vanilla model keeping one real token and 27.87 keeping none.
  • An output gate: multiply each head's attention output by a sigmoid of the token's own input, elementwise, before the output projection; a head with nothing to say closes its gate instead of finding a sink. Qiu et al. (Qwen team, {{arXiv 2505.06708|https://arxiv.org/html/2505.06708}}, authors' runs) found this position and form best: on a 15B MoE, perplexity 6.026 to 5.761 and MMLU 58.79 to 60.82; attention on the first token 46.7% to 4.8%; the largest hidden activation 1,053 to 94; mean gate 0.116 (mostly closed); and a 48-layer model that diverged at a learning rate of 8e-3 trained with it. Qwen3-Next and Qwen3.5 ship it (attn_output_gate: true); Kimi K3 gates its MLA layers.
  • Softmax with an extra 1 in the denominator: Evan Miller's "{{Attention Is Off By One|https://www.evanmiller.org/attention-is-off-by-one.html}}" (2023-07-24), exp(xi) / (1 + Σj exp(xj)), is a sink logit fixed at 0; a learned logit generalises it.

Cost, when, how to check. A sink logit is H parameters per layer and one more softmax column (transformers 5.20.1 concatenates it in the eager path and drops it after the softmax); the gate is a dmodel by H · dh matrix per layer (Qwen3-Next fuses it into the query projection), about 7% more parameters for the tiny GPT. They matter when serving with windows or evicted caches, for quantisation (massive activations are what break low-bit formats) and for stability at high learning rates. Check sinks in gpt-oss's weights and attn_output_gate in Qwen's configs; otherwise measure the weight on token 0 by layer with eager attention (SDPA returns no weights).
