6. Attention sinks, learned sinks and output gates

The problem. Softmax weights must sum to 1. A head that has nothing useful to read for this token (a "previous-name" head on a token with no name nearby) still has to put its weight somewhere. Trained LLMs learn to park it on a token whose value contributes little, nearly always the first one: an attention sink (Xiao et al. 2023, StreamingLLM, {{arXiv 2309.17453|https://arxiv.org/html/2309.17453}}). The root's Inside lab found SmolLM2-135M's sink switching on at layer 12 (weight on token 0 at most 0.085 before, 0.31 to 0.74 after), together with a massive activation (dimension 507 of token 0's residual reaching 20,155 against a median 1.56). The sink matters to the cache: a sliding window that evicts token 0 breaks the model (SmolLM2, window 64: loss 3.36 against 1.62 full; keeping token 0 as well: 1.81), which is why StreamingLLM keeps the first few tokens beside the window.

Three fixes that remove the need for a real token.

  • A learned sink logit per head: an extra score column with no value, so a head can send weight "nowhere" and the real weights sum to less than 1. gpt-oss: "Each attention head has a learned bias in the denominator of the softmax" (model card, {{arXiv 2508.10925|https://arxiv.org/abs/2508.10925}}); DeepSeek-V4 uses one too. StreamingLLM's own pretraining test added a learned sink token to a 160M model: perplexity with a window of 1,023 plus one kept token 18.01, against 18.49 for the vanilla model, and the vanilla model with no kept token at all 27.87 (Table 10).
  • An output gate: multiply each head's attention output by a sigmoid of the token's own input, elementwise, before the output projection. A head with nothing to say closes its gate instead of finding a sink. Qiu et al. (Qwen team, {{arXiv 2505.06708|https://arxiv.org/html/2505.06708}}) compared gate positions and forms on a 15B MoE and a 1.7B dense model with up to 3.5T tokens; the gate after attention, elementwise, was best (Table 1, 15B MoE: average perplexity 6.026 to 5.761, MMLU 58.79 to 60.82); the share of attention on the first token fell from 46.7% to 4.8% and the largest hidden activation from 1,053 to 94 (Table 4); the mean gate value was 0.116 (mostly closed); and a 48-layer dense model that diverged at a learning rate of 8e-3 trained with the gate (authors' runs). Qwen3-Next and Qwen3.5 ship it (attn_output_gate: true).
  • Softmax with an extra 1 in the denominator: Evan Miller's "{{Attention Is Off By One|https://www.evanmiller.org/attention-is-off-by-one.html}}" (2023-07-24), exp(xi) / (1 + Σj exp(xj)), is a sink logit fixed at 0; a learned logit generalises it.

One head, before and after its sink: where the weight goes

The cost. A sink logit is H parameters per layer and one more column in the softmax; FlashAttention-style kernels need it passed in (transformers 5.20.1 concatenates it in the eager path, section 9). The gate is a dmodel by H · dh matrix per layer (Qwen3-Next fuses it into the query projection, doubling its width), about 7% more parameters for the tiny GPT. When it matters: serving with windows or evicted caches (a model with a learned sink or a gate does not depend on keeping token 0), quantisation (massive activations are what break low-bit formats), and training stability at high learning rates. How to check: sinks in gpt-oss's weights, attn_output_gate in Qwen's configs; in a model without either, measure the weight on token 0 by layer with eager attention (SDPA returns no weights), as the root's Inside lab does.
