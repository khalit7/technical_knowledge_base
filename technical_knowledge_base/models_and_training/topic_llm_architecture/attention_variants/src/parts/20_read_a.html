The idea in one screen

Decoding reads every cached key and value once per new token, so the bytes each past token leaves behind are decode time. Every attention variant changes one factor: how big each entry is (MHA, GQA, MQA, MLA), how many entries are kept (sliding windows, V4's compression), or how many are read (NSA, DSA); sinks and gates change where attention goes when nothing is worth reading.

You need: what attention and a KV cache are ({{The transformer from zero|n:3fd5c17b0d0d8174980ddde4a20c7b3c}}, or the root's {{attention section|n:3fd5c17b0d0d8172b490dc9f9ac281df}}) and RoPE ({{Positional Encodings|n:3c65c17b0d0d81a5b7c9e578fcdfac00}}), which MLA's decoupled key works around. Whole-model cache sizes at a context length (bytes per sequence, what fits on a GPU) are on {{Long context|n:3fd5c17b0d0d81059ee1ce20c0326dc5}}; this page is the mechanism.

KV head
one key and one value projection; MHA has one per query head, GQA one per group of query heads, MQA one in all.
Latent (MLA)
a short vector per token from which every head's key and value are rebuilt; only it is cached.
Absorption
folding the latent's up-projections into the query and output projections, so decode never rebuilds keys.
Decoupled RoPE key
a small extra key that carries position for MLA, because RoPE cannot pass through the absorbed product.
Local, global layer
a layer that attends to the last W tokens (a sliding window) or to all of them.
Indexer, top-k
a cheap scorer that picks which k cached entries the real attention reads (DSA).
Compressed entry
one cache entry that stands for a block of tokens (NSA's summaries, V4's CSA and HCA).
Sink
where a head puts weight it does not want to spend: the first token, a learned logit, or a closed gate.
