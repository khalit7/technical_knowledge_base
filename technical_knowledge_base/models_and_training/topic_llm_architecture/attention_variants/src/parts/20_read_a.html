1. The problem, the notation, the running example

The problem. When a decoder generates token t, every layer computes a query qt and compares it with the keys of all earlier tokens; the earlier keys and values do not change, so they are stored: the KV cache. Decoding one token reads the whole cache once and does about two multiply-adds per number read. That ratio, about 1 FLOP per byte in bf16 for MHA, is far below what a GPU can do per byte of memory (an H100 does about 295), so decode attention waits on memory: cache bytes are decode time, and at long context or large batch they are also the memory that limits how many requests fit. The root's {{Attention lab (on Topic: llm-architecture)|n:3fd5c17b0d0d8172b490dc9f9ac281df}} draws the cache and measures it (one MPS layer at Llama 3.1 8B's shape, 32K tokens, batch 4: MHA 17.49 ms, GQA-8 5.97 ms, MQA 1.54 ms); this page asks why each smaller cache works, and what each one gives up.

Notation. One layer, input xt (dmodel numbers, already normalised), H query heads of size dh. Head h computes qht = WQh xt, khj = WKh xj, vhj = WVh xj, weights ahtj = softmaxj(qht · khj / √dh) over j ≤ t, output oht = Σj ahtj vhj, then the heads are concatenated and multiplied by WO. With RoPE, q and k are rotated by their positions before the dot product, so the score depends on j − t.

The running example. The topic's tiny GPT (6 layers, dmodel 256, 8 heads of 32, context 256, RoPE) trained on TinyStories for 1,500 steps of 8,192 tokens, with the same seed and batches for every variant, so two runs differ only in their attention. The root's Attention lab trained MHA, GQA-4, GQA-2, MQA, MLA, a 64-token window and a 2 local : 1 global interleave; this page reuses those checkpoints and adds eight runs (MLA with a bigger latent and a wider RoPE key, a learned sink, an output gate, windows of 16, 32 and 128, and a 16-token interleave). Held-out loss is the mean next-token cross-entropy on fixed validation windows; differences under about 0.016 are inside the spread between two seeds of the same model (MHA 2.160 and 2.175 on 100 windows). Real-model behaviour comes from SmolLM2-135M (30 layers, 9 query heads and 3 KV heads of 64), inference only.
