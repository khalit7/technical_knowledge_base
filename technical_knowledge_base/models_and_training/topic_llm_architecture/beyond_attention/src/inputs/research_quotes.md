# Research notes: SSMs, linear attention, RWKV, hybrids (verbatim quotes)

All sources accessed 2026-10-19. Quotes are verbatim from the paper text (PDF text extraction or HTML); math is transcribed from the PDF and may lose sub/superscripts. Long dashes replaced with "--".

## 1. Katharopoulos et al. 2020, "Transformers are RNNs" (arXiv 2006.16236)
URL: https://arxiv.org/abs/2006.16236 (text from https://arxiv.org/pdf/2006.16236), accessed 2026-10-19

- Abstract: "we express the self-attention as a linear dot-product of kernel feature maps and make use of the associativity property of matrix products to reduce the complexity from O(N^2) to O(N), where N is the sequence length. We show that this formulation permits an iterative implementation that dramatically accelerates autoregressive transformers and reveals their relationship to recurrent neural networks. Our linear transformers achieve similar performance to vanilla transformers and they are up to 4000x faster on autoregressive prediction of very long sequences."
  - Supports: O(N) linear attention, recurrent form, the "up to 4000x" headline.
- Eq. 5 (linearized attention): "V'_i = phi(Q_i)^T sum_{j=1..N} phi(K_j) V_j^T / ( phi(Q_i)^T sum_{j=1..N} phi(K_j) )"; and: "our proposed linear transformer from equation 5 has time and memory complexity O(N) because we can compute sum_j phi(K_j) V_j^T and sum_j phi(K_j) once and reuse them for every query."
  - Supports: the reassociation trick.
- Eq. 7, feature map: "phi(x) = elu(x) + 1, (7) where elu(.) denotes the exponential linear unit (Clevert et al., 2015) activation function. We prefer elu(.) over relu(.) to avoid setting the gradients to 0 when x is negative."
  - Supports: the elu+1 feature map and why not relu.
- Sec 3.4: "any transformer layer with causal masking can be written as a model that, given an input, modifies an internal state and then predicts an output, namely a Recurrent Neural Network (RNN)." ... "The resulting RNN has two hidden states, namely the attention memory s and the normalizer memory z." Eqs: "s_0 = 0, z_0 = 0, s_i = s_{i-1} + phi(x_i W_K)(x_i W_V)^T, z_i = z_{i-1} + phi(x_i W_K)".
  - Supports: recurrent form with matrix state s and normaliser z.
- Constant memory: "The cumulative sum terms in equations 9, 13-15 are computed in linear time and require constant memory with respect to the sequence length." Intro: "an autoregressive transformer model with linear complexity and constant memory for both inference and training."
- Where 4000x comes from: Figure 4 caption (CIFAR-10 image generation): "As the sequence length grows linear transformers become more efficient compared to softmax attention. Our model achieves more than 4,000 times higher throughput and generates 17.85 images/second." MNIST: "more than 300 times higher throughput, generating 142 images/second."
  - Supports: the 4000x is pixel-by-pixel CIFAR-10 image generation (sequence length 3072), versus softmax baseline; 300x on MNIST.

## 2. S4: Gu, Goel, Re, "Efficiently Modeling Long Sequences with Structured State Spaces" (arXiv 2111.00396)
URL: https://arxiv.org/abs/2111.00396 (text from https://arxiv.org/pdf/2111.00396, latest version), accessed 2026-10-19

- Abstract: "A promising recent approach proposed modeling sequences by simulating the fundamental state space model (SSM) x'(t) = Ax(t) + Bu(t), y(t) = Cx(t) + Du(t), and showed that for appropriate choices of the state matrix A, this system could handle long-range dependencies mathematically and empirically." ... "S4 achieves strong empirical results across a diverse range of established benchmarks, including (i) 91% accuracy on sequential CIFAR-10 with no data augmentation or auxiliary losses, on par with a larger 2-D ResNet, (ii) substantially closing the gap to Transformers on image and language modeling tasks, while performing generation 60x faster (iii) SoTA on every task from the Long Range Arena benchmark, including solving the challenging Path-X task of length 16k that all prior work fails on, while being as efficient as all competitors."
  - Supports: SSM equations, 60x generation, Path-X solved.
- Sec 2.1: "The state space model is defined by the simple equation (1). It maps a 1-D input signal u(t) to an N-D latent state x(t) before projecting to a 1-D output signal y(t). x'(t) = Ax(t) + Bu(t), y(t) = Cx(t) + Du(t) (1)" ... "we will omit the parameter D for exposition (or equivalently, assume D = 0) because the term Du can be viewed as a skip connection and is easy to compute."
- HiPPO (Sec 2.2): "Prior work found that the basic SSM (1) actually performs very poorly in practice. Intuitively, one explanation is that linear first-order ODEs solve to an exponential function, and thus may suffer from gradients scaling exponentially in the sequence length (i.e., the vanishing/exploding gradients problem)." "HiPPO specifies a class of certain matrices A in R^{NxN} that when incorporated into (1), allows the state x(t) to memorize the history of the input u(t)." "the LSSL found that simply modifying an SSM from a random matrix A to equation (2) improved its performance on the sequential MNIST benchmark from 60% to 98%." HiPPO matrix (eq. 2): "A_nk = -( (2n+1)^{1/2} (2k+1)^{1/2} if n > k; n+1 if n = k; 0 if n < k )".
  - Supports: HiPPO purpose and the 60% to 98% sMNIST anecdote.
- Discretisation (Sec 2.3, eq. 3): "To discretize the continuous-time SSM, we follow prior work in using the bilinear method, which converts the state matrix A into an approximation A-bar. The discrete SSM is x_k = A-bar x_{k-1} + B-bar u_k, y_k = C-bar x_k, A-bar = (I - Delta/2 . A)^{-1} (I + Delta/2 . A), B-bar = (I - Delta/2 . A)^{-1} Delta B, C-bar = C." "the state equation is now a recurrence in x_k, allowing the discrete SSM to be computed like an RNN."
  - Supports: bilinear (Tustin) discretisation in S4 (note: Mamba later uses ZOH).
- Convolution view (eqs. 4-5): "y = K-bar * u. K-bar in R^L := K_L(A-bar, B-bar, C-bar) := (C-bar A-bar^i B-bar)_{i in [L]} = (C-bar B-bar, C-bar A-bar B-bar, ..., C-bar A-bar^{L-1} B-bar). (5)" "equation (4) is a single (non-circular) convolution and can be computed very efficiently with FFTs, provided that K-bar is known." "We call K-bar the SSM convolution kernel or filter."
- Intro: "S4 is the first model to solve the difficult LRA Path-X task (length-16384), achieving 88% accuracy compared to 50% random guessing for all prior work."
- Table 4 (LRA), columns ListOps / Text / Retrieval / Image / Pathfinder / Path-X / Avg (latest arXiv version):
  - "Transformer 36.37 64.27 57.46 42.44 71.40 (x) 53.66"
  - "Linear Trans. 16.13 65.90 53.09 42.34 75.30 (x) 50.46"
  - "Performer 18.01 65.40 53.82 42.77 77.05 (x) 51.18"
  - "S4 59.60 86.82 90.90 88.65 94.20 96.35 86.09"
  - Body text in the same version still says: "S4 substantially advances the SoTA, outperforming all baselines on all tasks and averaging 80.48% compared to less than 60% for every baseline." ((x) = failed / random guessing.)
  - Supports: Path-X 96.35 and Avg 86.09 in the updated table; 88% and 80.48% are the original (v1) numbers kept in the prose.

## 3. Mamba: Gu and Dao, "Mamba: Linear-Time Sequence Modeling with Selective State Spaces" (arXiv 2312.00752)
URL: https://arxiv.org/abs/2312.00752 (text from https://arxiv.org/pdf/2312.00752 and https://arxiv.org/html/2312.00752), accessed 2026-10-19

- Abstract (selection): "We identify that a key weakness of such models is their inability to perform content-based reasoning, and make several improvements. First, simply letting the SSM parameters be functions of the input addresses their weakness with discrete modalities, allowing the model to selectively propagate or forget information along the sequence length dimension depending on the current token."
  - Supports: selection = input-dependent SSM parameters.
- Abstract (hardware-aware): "Second, even though this change prevents the use of efficient convolutions, we design a hardware-aware parallel algorithm in recurrent mode. We integrate these selective SSMs into a simplified end-to-end neural network architecture without attention or even MLP blocks (Mamba)."
- Abstract (5x): "Mamba enjoys fast inference (5x higher throughput than Transformers) and linear scaling in sequence length, and its performance improves on real data up to million-length sequences."
- Intro: "Our Mamba language model has 5x generation throughput compared to Transformers of similar size, and Mamba-3B's quality matches that of Transformers twice its size (e.g. 4 points higher avg. on common sense reasoning compared to Pythia-3B and even exceeding Pythia-7B)."
- Sec 4.5 (HTML): "Mamba achieves 4-5x higher inference throughput than a Transformer of similar size, since without the KV cache it can use much higher batch sizes." "For example, a Mamba-6.9B (untrained) would have higher inference throughput than a 5x smaller Transformer-1.3B."
  - Supports: the 5x comes from bigger batch sizes (no KV cache); the precise claim is "4-5x".
- Intro (algorithm): "We overcome this with a hardware-aware algorithm that computes the model recurrently with a scan instead of convolution, but does not materialize the expanded state in order to avoid IO access between different levels of the GPU memory hierarchy. The resulting implementation is faster than previous methods both in theory (scaling linearly in sequence length, compared to pseudo-linear for all convolution-based SSMs) and on modern hardware (up to 3x faster on A100 GPUs)."
- Sec 3.3.2: "instead of preparing the scan input (A-bar, B-bar) of size (B, L, D, N) in GPU HBM (high-bandwidth memory), we load the SSM parameters (Delta, A, B, C) directly from slow HBM to fast SRAM, perform the discretization and recurrence in SRAM, and then write the final outputs of size (B, L, D) back to HBM."
- Algorithm text: "The main difference is simply making several parameters Delta, B, C functions of the input, along with the associated changes to tensor shapes throughout."
- Discretisation (eq. 4, ZOH): "A-bar = exp(Delta A), B-bar = (Delta A)^{-1} (exp(Delta A) - I) . Delta B"
- State dimension N: the paper does not state "default N = 16" in so many words. It uses N=16 as the top of its ablation and for benchmarks: Sec 4.5 "We benchmark the speed of the SSM scan operation (state expansion N=16)"; Fig 15 caption "State size fixed to N=16". State-size ablation (caption): "Increasing the SSM state dimension N, which can be viewed as an expansion factor on the dimension of the recurrent state, can significantly improve performance for a negligible cost in parameters/FLOPs, but only when B and C are also selective." Perplexity, constant B,C vs selective B,C: N=1 9.88 / 9.73; N=2 9.86 / 9.40; N=4 9.82 / 9.09; N=8 9.82 / 8.84; N=16 9.81 / 8.71.
  - Official code default (https://github.com/state-spaces/mamba README): Mamba: "d_state=16,  # SSM state expansion factor"; Mamba2: "d_state=64,  # SSM state expansion factor, typically 64 or 128"; Mamba3: "d_state=128,  # SSM state size".
  - Supports: N=16 is the code default and the paper's experimental setting; larger N helps only with selective B, C.

## 4. Mamba-2 / SSD: Dao and Gu, "Transformers are SSMs" (arXiv 2405.21060)
URL: https://arxiv.org/abs/2405.21060 (text from https://arxiv.org/html/2405.21060 and https://arxiv.org/pdf/2405.21060), accessed 2026-10-19

- Abstract: "Our state space duality (SSD) framework allows us to design a new architecture (Mamba-2) whose core layer is an a refinement of Mamba's selective SSM that is 2-8x faster, while continuing to be competitive with Transformers on language modeling." (sic: "an a refinement")
- Intro: "A dedicated implementation of SSD is 2 - 8x faster than the optimized selective scan implementation of Mamba, while simultaneously allowing for much larger recurrent state sizes (8x the size of Mamba or even higher, with minimal slowdown). SSD is highly competitive with optimized implementations of softmax attention (FlashAttention-2 (Dao 2024)), crossing over at sequence length 2K and 6x faster at sequence length 16K."
- Sec 9.3: "SSD, thanks to its reformulation to use matrix multiplication as a subroutine, can exploit specialized matrix multiplication (matmul) units on GPUs, also known as tensor cores. As a result, it is 2-8x faster than Mamba's fused associative scan, which does not leverage matmul units."
  - Supports: the 2-8x is the SSD kernel vs Mamba-1's scan (a layer/kernel speedup, not end-to-end model throughput).
- Scalar-times-identity A (Sec 2 overview): "The structure on A is further simplified from diagonal to scalar times identity structure. Each A_t can also be identified with just a scalar in this case." "We use a larger head dimension P, compared to P = 1 used in Mamba. Typically P = {64, 128} is chosen which is similar to conventions for modern Transformers." "these changes can be viewed as slightly decreasing the expressive power in return for significant training efficiency improvements."
- Sec 5.1: "let us consider the case where A_j is simply a scalar; in other words, an instantiation of a structured SSM where the A matrices are extremely structured: A = aI for scalar a and identity matrix I. Then we can rearrange M_ji = A_{j:i} . (C_j^T B_i). And this can be vectorized into L := 1SS(a), M = L o (C B^T)".
- Sec 5.2 (masked attention): "Structured masked attention allows for the use of any structured mask L. When L is the causal mask, it is standard linear attention. Note that the causal mask is L = SS(1_T), i.e. the 1-SS mask is generated by a_t = 1 in definition (6). This motivates generalizing L to the class of 1-semiseparable masks, or 1-semiseparable structured masked attention (1-SS SMA), where the cumsum in linear attention's recurrence is replaced by a more general recurrence -- the scalar SSM scan".
- Summary of the duality: "A natural special case of each one -- more precisely, state space models with scalar-identity structure on the A matrices, and structured masked attention with 1-semiseparable structure on its L mask -- are duals of each other with the exact same linear and quadratic forms."
  - Supports: SSD = linear attention with a 1-semiseparable (decay) mask.
- Chunked algorithm (intro): "We introduce a new SSD algorithm, based on block decompositions of semiseparable matrices, that takes advantage of both the linear SSM recurrence and quadratic dual form, obtaining optimal tradeoffs on all main efficiency axes". Sec 6: the output of a "chunk" is split into "two components: the effect of inputs within the chunk x_{jQ:(j+1)Q}, and the effect of inputs before the chunk x_{0:jQ}." "for small chunk lengths Q, this problem is computed more efficiently using the dual quadratic SMA form. Additionally, the chunks can be computed in parallel." "If we set N = P = Q (in other words the state dimension, head dimension, and chunk length are equal) ... Total FLOP count of O(TN^2). Total memory of O(TN). The work consists primarily of matrix multiplications on matrices of shape (N, N)."
  - Supports: four-step chunked algorithm (intra-chunk quadratic, chunk states, inter-chunk scan, state-to-output).
- State size: Sec 7: "The state size N and head dimension P are analogous to the QK head dimension and V head dimension of attention, respectively. ... in Mamba-2 we generally choose these to be constants around 64 or 128". Table 5 caption: "All models have state expansion factor N=64 and head size P=64". Kernel-ablation text: "use state size N=64 for 130M models and N=256 for 380M models." Official code: "d_state=64,  # SSM state expansion factor, typically 64 or 128" (github.com/state-spaces/mamba README).
  - Supports: "N = 64 to 256" is a fair range; the paper's own phrase is "around 64 or 128"; 8x larger than Mamba-1's 16.
- MQAR (Sec 9.1): "The multi-query associative recall (MQAR) task is a particular formulation of this task that requires the model to memorize multiple associations (Arora et al., 2024)." "The MQAR task is also closely related to 'phonebook look-up' tasks which has been shown to be challenging for recurrent models such as SSMs, due to their finite state capacity (Jelassi et al., 2024; De et al., 2024)." "Results are shown in Figure 8. While Mamba-1 struggles on this task, Mamba-2 performs well across all settings. Surprisingly, it is significantly better than Mamba-1 even when the state sizes are controlled (N=16). (We are not sure which aspect of the architecture is the predominant factor, which remains a question to explore in future work.) Additionally, this task validates the importance of state size: increasing from N=16 to N=64 and N=256 consistently improves performance on MQAR, as the larger state allows more information (key-value pairs) to be memorized."
  - Figure 8 caption: "(Multi-Query Associative Recall (MQAR)). Associative recall tasks are challenging for SSMs, which must memorize all relevant information into their recurrent state. The SSD layer combined with improved architecture allows for much larger state sizes in Mamba-2, which performs significantly better than Mamba-1 and even vanilla attention." Panels: sequence length 256 / 512 / 1024; x-axis model dimension 32, 64, 128, 256; y-axis accuracy; lines Attention, Based, Mamba (N=16), Mamba-2 (N=16), Mamba-2 (N=64), Mamba-2 (N=256).

## 5. RWKV family

### 5a. RWKV-4: Peng et al., "RWKV: Reinventing RNNs for the Transformer Era" (arXiv 2305.13048)
URL: https://arxiv.org/html/2305.13048, accessed 2026-10-19

- Abstract: "We propose a novel model architecture, Receptance Weighted Key Value (RWKV), that combines the efficient parallelizable training of transformers with the efficient inference of RNNs. Our approach leverages a linear attention mechanism and allows us to formulate the model as either a Transformer or an RNN, thus parallelizing computations during training and maintains constant computational and memory complexity during inference. We scale our models as large as 14 billion parameters, by far the largest dense RNN ever trained".
  - Supports: RNN at inference, constant memory, 14B.
- Sec 2.2 (time decay): "Each w_{t,i} in RWKV is a channel-wise time decay vector multiplied by the relative position and traced backward from current time as it decays: w_{t,i} = -(t-i) w, (10) where w in (R_{>=0})^d, with d the number of channels. We require w to be non-negative to ensure that e^{w_{t,i}} <= 1 and the per-channel weights decay backwards in time."
- Sec 3.1.2 WKV operator: "unlike AFT where W is a pairwise matrix, our model treats W as a channel-wise vector that is modified by relative position." Eq. 16: "wkv_t = ( sum_{i=1}^{t-1} e^{-(t-1-i)w + k_i} (.) v_i + e^{u + k_t} (.) v_t ) / ( sum_{i=1}^{t-1} e^{-(t-1-i)w + k_i} + e^{u + k_t} )". "To circumvent any potential degradation of W, we introduce a vector U that separately attends to the current token."
- Appendix E: "w_i (16), also known as 'time decay', ... Intuitively, it is the discount factor applied to previous tokens over time. u_i (16), also known as 'bonus', ... It is the special weighting applied to the current token in equation 16."
  - Supports: w = per-channel decay, u = bonus for the current token.
- Sec 3.3: "RWKV takes advantage of this RNN-like structure, known as time-sequential mode. In this context, RWKV can be conveniently formulated recursively for decoding during inference". Sec 3.2: training uses "time-parallel mode, reminiscent of Transformers".
- Limitations: "the model's recurrent architecture inherently limits its ability to 'look back' at previous tokens, as opposed to traditional self-attention mechanisms. While learned time decay helps prevent the loss of information, it is mechanistically limited compared to full self-attention." and "carefully designed prompts may be even more crucial for the model to perform well on tasks."
  - Supports: RWKV's own admission of the recall limit and prompt-order sensitivity.

### 5b. RWKV-5 / RWKV-6: Peng et al., "Eagle and Finch" (arXiv 2404.05892)
URL: https://arxiv.org/html/2404.05892, accessed 2026-10-19

- Abstract: "We present Eagle (RWKV-5) and Finch (RWKV-6), sequence models improving upon the RWKV (RWKV-4) architecture. Our architectural design advancements include multi-headed matrix-valued states and a dynamic recurrence mechanism that improve expressivity while maintaining the inference efficiency characteristics of RNNs." ... "We release all our models on HuggingFace under the Apache 2.0 license."
- Intro: "Eagle improves upon the architecture and learned decay schedule from RWKV-4 through the use of expressive multi-headed matrix-valued states (as opposed to vector-valued states), a reformulated receptance, and an additional gating mechanism. Finch further improves the expressivity and flexibility of the architecture by introducing new data-dependent functions for both the time-mixing and token-shift modules".
- Sec 4.2.2 Finch: "w_t = exp(-exp(d_t)) (18)"; recurrent form "wkv' = s + diag(u) . k^T . v (21), s' = diag(w) . s + k^T . v (22)". "Unlike in Eagle, w_t here is not static across the sequence ... This is the core change to decay in Finch, as each channel of w_t can now vary independently over time, in a data-dependent manner, whereas previously it was a fixed learned vector."
  - Supports: RWKV-5 = matrix state with fixed decay; RWKV-6 = data-dependent per-channel decay (like GLA).
- Sec 7: "We have pre-trained and publicly released the six Apache 2.0 licensed Eagle and Finch models: Eagle 0.4B, Eagle 1.5B, Eagle 3B, Eagle 7B, Finch 1.6B, and Finch 3B. All of the models were trained on the 1.12 trillion token RWKV World v2 multilingual corpus."

### 5c. RWKV-7: Peng et al., "RWKV-7 'Goose' with Expressive Dynamic State Evolution" (arXiv 2503.14456)
URL: https://arxiv.org/html/2503.14456, accessed 2026-10-19

- Abstract: "RWKV-7 introduces a newly generalized formulation of the delta rule with vector-valued gating and in-context learning rates, as well as a relaxed value replacement rule. We show that RWKV-7 can perform state tracking and recognize all regular languages, while retaining parallelizability of training. This exceeds the capabilities of Transformers under standard complexity conjectures, which are limited to TC0." ... "train four RWKV-7 models ranging from 0.19 billion to 2.9 billion parameters" ... "our 2.9 billion parameter language model achieves a new 3B SoTA on multilingual tasks and matches the current 3B SoTA on English language downstream performance."
- Contributions: "Proofs that the generalized delta rule employed in RWKV-7 can solve problems outside of TC0 under the widely held complexity conjecture that TC0 != NC1. This includes solving an S5 state tracking problem known to be in NC1 using only a single layer, and recognizing all regular languages using only a constant number of layers."
- Recurrence (eq. 17): "wkv_t = wkv_{t-1} (diag(w_t) - kappa-hat_t^T (a_t (.) kappa-hat_t)) + v_t^T . k-tilde_t". "The wkv (Weighted Key Value) is a multi-headed matrix-valued state of fast weights that undergoes dynamic evolution."
- Background on decay vs delta: "use per time-step decay to remove some portion of such older values from the state in a data-dependent manner. However, decay is a blunt tool that cannot remove only the values stored at specific keys." "DeltaNet (Schlag et al., 2021) sidesteps the problem of numerically increasing state by partially replacing the value stored at the current key with the same amount of a new value, allowing the model to both take away old memories and add new ones on a per-key basis."
- Table 1 lists state evolutions, e.g. "Mamba-2 S_t = w_t S_{t-1} + v_t^T k_t"; "RWKV-6 & GLA S_t = S_{t-1} diag(w_t) + v_t^T k_t"; "RWKV-7 (ours) S_t = S_{t-1}(diag(w_t) - kappa-hat_t^T (a_t (.) kappa-hat_t)) + v_t^T k_t" (row-vector convention; note: transposed vs DeltaNet papers).
- Licence: "on GitHub; all under the Apache 2.0 License."
  - Supports: RWKV models and code are Apache 2.0 (RWKV-5/6/7 papers).

## 6. DeltaNet

### 6a. Schlag, Irie, Schmidhuber 2021, "Linear Transformers Are Secretly Fast Weight Programmers" (arXiv 2102.11174)
URL: https://arxiv.org/abs/2102.11174 (text from https://arxiv.org/pdf/2102.11174), accessed 2026-10-19

- Abstract: "We show the formal equivalence of linearised self-attention mechanisms and fast weight controllers from the early '90s" ... "We infer a memory capacity limitation of recent linearised softmax attention variants, and replace the purely additive outer products by a delta rule-like programming instruction, such that the FWP can more easily learn to correct the current mapping from keys to values. The FWP also learns to compute dynamically changing learning rates."
- Sec 4.2: "Sec. 4.1 argues that the linear Transformers can end up in an overcapacity regime, if the sequence length L exceeds the dimension d_dot of the keys. Once in overcapacity, an ideal memory model should dynamically interact with the memory contents and selectively determine which associations to remember or to forget."
- "we propose a basic instruction that essentially implements the famous error-correcting delta rule (Widrow & Hoff, 1960) in an end-to-end differentiable way" ... "Given a new input key-value pair (k(i), v(i)), the FWP first accesses the current state of the memory W(i-1) and retrieves the value v-bar(i) currently paired with the key k(i). Then the model stores a convex combination v_new(i) of the retrieved value v-bar(i) and the input v(i) using an interpolation weight 0 <= beta(i) <= 1 also generated by the model."
- Equations: "v-bar(i) = W(i-1) phi(k(i)) (20)"; "beta(i) = sigma(W_beta x(i)) (21)"; "v_new(i) = beta(i) v(i) + (1 - beta(i)) v-bar(i) (22)"; "W(i) = W(i-1) + v_new(i) (x) phi(k(i)) [write] - v-bar(i) (x) phi(k(i)) [remove] (23) = W(i-1) + beta(i) (v(i) - v-bar(i)) (x) phi(k(i)) (24)"; "y(i) = W(i) phi(q(i)) (25)".
- "The interpolation weight beta(i) is the 'write-strength' as it defines to which extent the new value will replace the previous value." "As shown in Eq. 24, our programming instruction or update rule is effectively a delta rule with a dynamic learning rate beta(i). The model thus learns to correct the current key to value association."
  - Supports: delta rule origin; capacity limit when L > d_key.

### 6b. Yang, Wang, Zhang, Shen, Kim 2024, "Parallelizing Linear Transformers with the Delta Rule over Sequence Length" (arXiv 2406.06484, NeurIPS 2024)
URL: https://arxiv.org/html/2406.06484 (v6), accessed 2026-10-19

- Sec 2.2: "DeltaNet, on the other hand, uses the delta update rule or the Widrow-Hoff learning rule for fast weight update: S_t = S_{t-1} - beta_t (S_{t-1} k_t - v_t) k_t^T, where beta_t is the learning rate, S_{t-1} k_t represents the current prediction, v_t is the target value." "This process can also be regarded as optimizing an online regression loss using a single step of SGD": "L_t(S) = 1/2 ||S k_t - v_t||^2, S_t = S_{t-1} - beta_t grad L_t(S_{t-1}) = S_{t-1} - beta_t (S_{t-1} k_t - v_t) k_t^T". "In contrast, linear transformers can be regarded as optimizing an online linear (negative inner-product) loss L_t = -<S k_t, v_t>."
  - Supports: exact update rule as requested (confirmed verbatim).
- Algorithm: "We reparameterize the DeltaNet as a matrix-valued RNN whose recurrence is given by a generalized Householder transformation. This reparameterization enables the use of the compact WY representation for products of Householder matrices, eliminating the need to materialize the hidden states of matrix size at each time step during parallel training".
- Abstract: "We train a 1.3B model for 100B tokens and find that it outperforms recent linear-time baselines such as Mamba and GLA in terms of perplexity and zero-shot performance on downstream tasks. We also experiment with two hybrid models which combine DeltaNet layers with (1) sliding-window attention layers every other layer or (2) two global attention layers, and find that these hybrids outperform strong transformer baselines."

## Corrections or surprises
1. "Transformers are RNNs 4000x": the 4000x is pixel-by-pixel CIFAR-10 image generation throughput (Figure 4, "more than 4,000 times higher throughput"), not text LLM decoding; MNIST gives "more than 300 times".
2. S4 Path-X: the commonly repeated "88% on Path-X" and "80.48% LRA average" are the original v1 numbers still in the prose; the updated Table 4 in the latest arXiv version shows Path-X 96.35 and Avg 86.09. Also S4 uses the bilinear discretisation; Mamba switched to zero-order hold (ZOH).
3. Mamba "5x throughput": Sec 4.5 says "4-5x higher inference throughput", attributed to larger batch sizes without a KV cache; the 5x is not a per-token latency speedup.
4. Mamba-2 "2-8x faster" is the SSD kernel vs Mamba-1's selective scan, not end-to-end model speed. SSD vs FlashAttention-2: crossover at 2K, 6x faster at 16K.
5. MQAR in Mamba-2: Mamba-2 beats Mamba-1 even at equal state size N=16 (authors unsure why), so state size is not the only factor.
6. Qwen3-Next "10x": the official numbers are vs dense Qwen3-32B: prefill "nearly 7x" at 4K and "over 10x" beyond 32K; decode "nearly 4x" at 4K and "over 10x" beyond 32K. Training cost "9.3% of the compute cost of Qwen3-32B" (card rounds to "10%"). Part of the gain is MoE sparsity (3B active vs 32B dense), not only Gated DeltaNet.
7. Kimi Linear Table 1 confirmed exactly. Ratio = KDA : MLA layers; "0:1" is the pure full-attention (MLA) baseline, which had the worse validation PPL (5.77) than 3:1 (5.65). 1:1 (5.66) nearly ties 3:1; 7:1 matches training PPL but is worse on validation. Kimi Linear's MLA layers use NoPE.
8. Jamba: 1:3 and 1:7 give identical HellaSwag/WinoGrande/OLLM at 1.3B (only NQ differs: 16.5 vs 16.0); 1:7 was chosen for compute. In Table 6 the hybrid beats pure attention on IMDB (90.9 vs 84.1) but is slightly below on QuAC (26.6 vs 27.9) and NarrativeQA (43.7 vs 45.8).
9. Nemotron-H-8B "8% attention" = 4 of 52 layers; but counted only among sequence mixers it is 4 attention vs 24 Mamba-2 (1:6). Similarly Nemotron 3 Super: 8 of 88 layers (about 9%), 8 attention vs 40 Mamba-2 (1:5).
10. Granite 4.0 "9:1" = 36 Mamba-2 : 4 attention layers out of 40; IBM's memory claim is "over 70% reduction in RAM needed to handle long inputs and multiple concurrent batches" (RAM, vs "conventional transformer-based models"), not specifically KV cache.
11. Falcon-H1 channel ratio is SSM : attention : MLP of about 2:1:5 (from (alpha_S, alpha_A, alpha_M) = (28, 18, 58) optimum), and it uses the semi-parallel SA_M block (SSM and attention in parallel, then MLP), not a fully parallel block.
12. Equation conventions differ: DeltaNet / Gated DeltaNet papers write S_t k_t (column convention, S_t = S_{t-1}(...) + beta_t v_t k_t^T); RWKV-7 and Kimi use transposed/row conventions. Do not mix them on one page without a note.
13. Qwen3.5 card labels the line "Hidden Layout" (Qwen3-Next used "Hybrid Layout"); 397B-A17B has 60 layers = 15 x (3 Gated DeltaNet + 1 Gated Attention); 0.8B has 24 layers = 6 x (3 + 1) with dense FFN.
14. Nemotron 3 Super throughput claim is "up to 2.2x and 7.5x higher inference throughput compared to GPT-OSS-120B and Qwen3.5-122B" at 8k input / 64k output on B200; the report also says Qwen3.5-122B was run in BF16 while GPT-OSS used MXFP4 weights.
