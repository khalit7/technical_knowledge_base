4. State-space models: S4, then Mamba, then Mamba-2

S4: a continuous system, discretised

The idea. A state-space model (SSM) comes from control theory: a 1-D input signal u(t) drives an N-dimensional state x(t), x′(t) = A x(t) + B u(t), read out as y(t) = C x(t) (+ D u(t), a skip). {{S4 (Gu, Goel and Ré 2021)|https://arxiv.org/abs/2111.00396}} applies one such system to each channel of the model. To run it on tokens it is discretised with a step size Δ: S4 uses the bilinear method, Ā = (I − Δ/2·A)−1(I + Δ/2·A), B̄ = (I − Δ/2·A)−1ΔB, giving the recurrence xk = Āxk−1 + B̄uk, yk = Cxk. Mamba later switched to zero-order hold, Ā = exp(ΔA).

Why it trains fast. Ā, B̄ and C are the same at every position (the model is linear time-invariant, LTI), so the output is one convolution of the input with the kernel K̄ = (CB̄, CĀB̄, CĀ2B̄, ...), computed with FFTs. Why it remembers. A random A forgets fast or explodes; the HiPPO matrix makes "the state x(t) to memorize the history of the input u(t)", and in an earlier model "simply modifying an SSM from a random matrix A to equation (2) improved its performance on the sequential MNIST benchmark from 60% to 98%". S4 was "the first model to solve the difficult LRA Path-X task (length-16384)". authors The arXiv version read on 2026-10-19 has two sets of numbers: its prose keeps "88% accuracy" on Path-X and an "80.48%" LRA average, its Table 4 prints 96.35 and 86.09 (updated runs); quote the table.

What it cannot do. Because Ā, B̄, C ignore the input, the layer weighs a token by its distance only, never by what it is. It cannot decide to keep a name and skip filler. The Mamba paper's Selective Copying task makes that failure measurable; its {{paper page|n:3c65c17b0d0d8179984fc3a1fee4c36a}} trains an S4-style and a selective layer side by side (99.8% against 67.4% on its toy).

Mamba: make the system depend on the input

{{Mamba (Gu and Dao 2023)|https://arxiv.org/abs/2312.00752}}: "simply letting the SSM parameters be functions of the input addresses their weakness with discrete modalities, allowing the model to selectively propagate or forget information along the sequence length dimension depending on the current token". Δt, Bt and Ct become projections of xt: a large Δt resets the state toward the current token, a small one keeps the past. The convolution is gone (the kernel changes every step), so Mamba computes the recurrence with "a hardware-aware parallel algorithm in recurrent mode": the expanded state (batch × length × channels × N) never touches GPU main memory; parameters are loaded into on-chip SRAM, discretised and scanned there. Per layer the state is dinner × N with N = 16 (the code's default and the paper's setting), dinner = 2 × dmodel: 5,120 × 16 per layer for Mamba 2.8B. Throughput: "4-5x higher inference throughput than a Transformer of similar size, since without the KV cache it can use much higher batch sizes" (section 4.5; the abstract rounds to 5x). authors

Mamba-2: restrict A to a scalar, and the layer becomes masked attention

{{Mamba-2 (Dao and Gu 2024)|https://arxiv.org/abs/2405.21060}} simplifies A "from diagonal to scalar times identity structure": one decay at = exp(ΔtA) per head per step, shared by all its channels and state entries, with head dimension P = 64 or 128 like a transformer. Then unrolling gives

yi = ∑j≤i (Ci·Bj) · (aj+1aj+2…ai) · xj   ⇒   Y = (L ⊙ C B⊤) X
C B⊤
a T × T matrix of query-key scores: C plays the query, B the key, x the value
L
the decay mask, Lij = product of a's between j and i (1 on the diagonal, 0 above it): "1-semiseparable"

That is linear attention (section 2) with a decaying mask instead of the plain causal mask: "When L is the causal mask, it is standard linear attention", and the two are "duals of each other with the exact same linear and quadratic forms". The name is state space duality (SSD). It matters for speed: split the sequence into chunks, use the quadratic form inside each chunk (matrix multiplies) and the recurrence between chunks; the SSD kernel is "2-8x faster than Mamba's fused associative scan, which does not leverage matmul units" (a kernel speedup, not a whole-model one) and crosses FlashAttention-2 "at sequence length 2K", "6x faster at sequence length 16K". The same speed buys state: Mamba-2 uses N "around 64 or 128" (code default 64; Nemotron-H 8B uses 128) against Mamba's 16. authors

The topic's tiny GPT uses exactly this layer. Its SSM mixer (16 heads of 32 channels, N = 16, a short causal convolution, a gate) trains in the quadratic dual form and decodes with the recurrence (code in section 11). On the trained SSM-only model, the two forms give logits that differ by at most on the running sequence (src/inside/ssm_inside.py, CPU, fp32). Because Y = (L ⊙ CB⊤)X, every SSM head has an implicit attention map ("Mamba models give rise to three orders of magnitude more attention matrices than transformers", {{Ali et al. 2024|https://arxiv.org/abs/2403.01590}}); the {{Inside the trained SSM|#t-inside}} tab draws them beside real attention maps for the same tokens, with each head's decay.

Mamba-3 (2026, published only)
{{Mamba-3|https://arxiv.org/abs/2603.15569}} adds "a more expressive recurrence derived from SSM discretization", "a complex-valued state update rule that enables richer state tracking" and a multi-input multi-output form; the authors report "comparable perplexity to Mamba-2 despite using half of its predecessor's state size" at 1.5B. authors Not run here (no released small checkpoint in the topic's environment).
