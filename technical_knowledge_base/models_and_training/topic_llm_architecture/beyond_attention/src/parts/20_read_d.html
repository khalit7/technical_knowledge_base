5. RWKV: an RNN built from attention's pieces

RWKV-4 ({{Peng et al. 2023|https://arxiv.org/abs/2305.13048}}) keeps, per channel, a weighted average of past values whose weights decay with distance: wkvt = (∑i<t e−(t−1−i)w + ki vi + eu + kt vt) / (same sum without v), with w "a channel-wise time decay" and u a "bonus" for the current token. The scores are a key-only term plus a fixed linear distance penalty, so numerator and denominator can be carried as running sums: a normalised linear attention with exponential decay (the hero grid's fixed-decay row). The authors state the cost: it "inherently limits its ability to 'look back' at previous tokens", and "carefully designed prompts may be even more crucial".

Then RWKV walked the grid: "multi-headed matrix-valued states" in RWKV-5, decay that changes with the input per channel in RWKV-6 ({{Eagle and Finch, 2024|https://arxiv.org/abs/2404.05892}}: "each channel of w_t can now vary independently over time, in a data-dependent manner"), and "a newly generalized formulation of the delta rule with vector-valued gating and in-context learning rates" in RWKV-7 ({{Goose, 2025|https://arxiv.org/abs/2503.14456}}). It stayed a community line (Apache-2.0) that no 2026 frontier hybrid uses, but its path is the one the others took.

RWKV's scale, state tracking and code (depth)

The RWKV-4 authors trained up to 14B parameters, "by far the largest dense RNN ever trained". RWKV-7 is proved to "perform state tracking and recognize all regular languages" (solving an S5 permutation tracking problem with one layer), which the authors set against transformers' TC0 limit under standard complexity conjectures; models from 0.19B to 2.9B. authors transformers 5.20.1 ships only RWKV-4; its CPU fallback carries the two running sums plus a running maximum for numerical safety (quoted in section 11).

6. Gated DeltaNet and Kimi Delta Attention in production

Gated DeltaNet is section 3's gated delta rule with learned, input-dependent αt (per head) and βt, L2-normalised queries and keys, a short convolution on q, k and v, and an output gate. Qwen3-Next-80B-A3B (September 2025) ships it: "Hybrid Layout: 12 * (3 * (Gated DeltaNet -> MoE) -> 1 * (Gated Attention -> MoE))", Gated DeltaNet heads "32 for V and 16 for QK; Head Dimension: 128". Qwen3.5 keeps the layout from 0.8B ("6 x (3 x (Gated DeltaNet -> FFN) -> 1 x (Gated Attention -> FFN))") to 397B-A17B ("15 * (3 * ...)"), context "262,144 natively". Qwen model cards, read 2026-10-19

Kimi Delta Attention (KDA), {{Kimi Linear 2025|https://arxiv.org/abs/2510.26692}}, changes one thing: "While GDN, similar to Mamba2, employs a coarse head-wise forget gate, KDA introduces a channel-wise variant in which each feature dimension maintains an independent forgetting rate".

One forget rate per head against one per key channel

One head's state, dk rows (key channels) by dv columns, drawn 8 × 8 (Qwen3-Next's is 128 × 128). Shade: the share kept this step. Gated DeltaNet (and Mamba-2) multiply the whole matrix by one αt; KDA (and RWKV-6) multiply each key channel's row by its own rate, so one head can keep a slow channel for a name while clearing fast ones. Rates illustrative.

In code the difference is one broadcast (section 11): Qwen3-Next's loop multiplies the state by decay[:, :, i].exp()[..., None, None] (one number per head), Kimi Linear's by g[:, i][..., None].exp() (one number per key channel); the delta step is line for line the same. Kimi Linear 48B-A3B interleaves KDA and MLA "in a uniform 3:1 ratio" with no positions in its MLA layers; Kimi K3 keeps the pattern at 93 layers (69 KDA, 24 MLA) and bounds the decay (config gate_lower_bound −5, so every retention factor exceeds e−5 ≈ 0.0067), which lets every 16-token tile of the kernel run as a dense tensor-core matrix multiply ({{Moonshot AI: Kimi|n:3c65c17b0d0d81f5abf5dbdbac821a12}}). authors

Kimi Linear's claims and its NoPE choice, quoted (depth)
Kimi Linear reports "reducing KV cache usage by up to 75% and achieving up to 6x decoding throughput for a 1M context". On positions: "we apply NoPE to all full attention (MLA) layers. This design delegates the entire responsibility for encoding positional information and recency bias to the KDA layers." authors Qwen tried the same NoPE choice for Qwen3.8-Flash-Next's full-attention layers: it looked the same in pre-training, but after post-training showed "a substantially higher rate of endless generation", so those layers keep RoPE ({{Alibaba: Qwen|n:3c65c17b0d0d81fd8c36ce06672bb235#s-att}}). authors
Gated DeltaNet's published results, and how to check a delta-rule layer (depth)

The authors ({{Yang, Kautz and Hatamizadeh 2024|https://arxiv.org/abs/2412.06464}}) report at 1.3B parameters and 100B tokens: Wikitext perplexity 16.42 against 16.56 for Mamba-2, 17.71 for DeltaNet and 18.53 for their Transformer++ (Table 3); on recall-heavy tasks with 2K inputs, average 30.6 against 37.0 for the Transformer++ and 39.0 to 40.1 for their hybrids with sliding-window attention (Table 4); on single-needle retrieval at 8K, 91.8 (pass key) where Mamba-2 falls to 30.4 because it "decays historical information too quickly" (Table 2). authors
