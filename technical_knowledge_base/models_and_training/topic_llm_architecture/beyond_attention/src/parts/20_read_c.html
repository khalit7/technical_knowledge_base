3. Forget or overwrite: decay, gates and the delta rule

Decay (forgetting everything a little). Multiply the state by a number a < 1 before each write: St = at St−1 + vtkt⊤. A write made n steps ago then counts an, so old memories fade and stop interfering. RetNet used a fixed a per head; Gated Linear Attention and RWKV-6 make it depend on the input and on the channel; Mamba-2 makes it one input-dependent scalar per head (section 4). A half-life h = ln 0.5 / ln a says how many tokens a memory survives at half strength (a = 0.9 gives 6.6 tokens). Decay is, in RWKV-7's words, "a blunt tool that cannot remove only the values stored at specific keys".

The delta rule (overwrite what this key held). Before writing value v under key k, read what the state currently returns for k, S k, and write only the difference: St = St−1 + βt(vt − St−1kt)kt⊤, with a write strength β between 0 and 1. With unit keys and β = 1 the read S k returns exactly v afterwards, so a key written twice keeps only its latest value. {{Yang et al. 2024|https://arxiv.org/abs/2406.06484}} read it as learning: "This process can also be regarded as optimizing an online regression loss using a single step of SGD", L(S) = ½‖S kt − vt‖2, whereas plain linear attention follows the "negative inner-product" loss −⟨S kt, vt⟩. The rule is the Widrow-Hoff rule of 1960, brought to transformers by DeltaNet ({{Schlag et al. 2021|https://arxiv.org/abs/2102.11174}}).

Both together. Gated DeltaNet ({{Yang, Kautz and Hatamizadeh 2024|https://arxiv.org/abs/2412.06464}}, eq. 10): St = St−1(αt(I − βtktkt⊤)) + βtvtkt⊤. Their motivation: "gating enables rapid memory erasure while the delta rule facilitates targeted updates". (The papers write S as dv × dk and multiply S k; RWKV-7 and Kimi write the transpose. This page follows the DeltaNet papers.)

Softmax over a full cache recalls every single-write word almost perfectly at every size, but averages the two values of a re-written key ("Roxy" ), because nothing in a bare key says which write is newer; real attention gets recency from positions.

Predict: a Gated DeltaNet head in Qwen3-Next has dk = dv = 128. Roughly how many unrelated (key, value) facts can its state hold before writes start to damage each other?
About dk. Exact retrieval needs keys that do not overlap, and at most dk unit vectors can be mutually orthogonal (the toy above: ten keys fit at dk = 16, not at 8). The 128 × 128 = 16,384 entries are the price of storing dv = 128 numbers under each of those directions. Learned keys are not random, so a trained model can do better on structured text and worse on adversarial lists; this is why Qwen3-Next keeps one attention layer in four.
