4. State-space models: S4, then Mamba, then Mamba-2

S4: a continuous system, discretised

A state-space model (SSM) comes from control theory: a 1-D input signal u(t) drives an N-dimensional state x(t), x′(t) = A x(t) + B u(t), read out as y(t) = C x(t) (+ D u(t), a skip). {{S4 (Gu, Goel and Ré 2021)|https://arxiv.org/abs/2111.00396}} applies one such system to each channel of the model and runs it on tokens by discretising it with a step size Δ, giving the recurrence xk = Āxk−1 + B̄uk, yk = Cxk. Ā, B̄ and C are the same at every position (the model is linear time-invariant, LTI), so the output is one convolution of the input with the kernel K̄ = (CB̄, CĀB̄, CĀ2B̄, ...), computed with FFTs: that is why it trains fast. It remembers because A is not random but the HiPPO matrix, which makes "the state x(t) to memorize the history of the input u(t)".

What it cannot do. Because Ā, B̄, C ignore the input, the layer weighs a token by its distance only, never by what it is. It cannot decide to keep a name and skip filler. The Mamba paper's Selective Copying task makes that failure measurable; its {{paper page|n:3c65c17b0d0d8179984fc3a1fee4c36a}} trains an S4-style and a selective layer side by side (99.8% against 67.4% on its toy).

S4's discretisation, HiPPO's evidence and the Path-X numbers (depth; a correction)

S4 uses the bilinear method, Ā = (I − Δ/2·A)−1(I + Δ/2·A), B̄ = (I − Δ/2·A)−1ΔB; Mamba later switched to zero-order hold, Ā = exp(ΔA). A random A forgets fast or explodes; in an earlier model "simply modifying an SSM from a random matrix A to equation (2) improved its performance on the sequential MNIST benchmark from 60% to 98%". S4 was "the first model to solve the difficult LRA Path-X task (length-16384)". authors

Checked: two sets of numbers in one paper
The arXiv version read on 2026-10-19 keeps "88% accuracy" on Path-X and an "80.48%" LRA average in its prose, while its Table 4 prints 96.35 and 86.09 (updated runs). Quote the table.

Mamba: make the system depend on the input

{{Mamba (Gu and Dao 2023)|https://arxiv.org/abs/2312.00752}}: "simply letting the SSM parameters be functions of the input addresses their weakness with discrete modalities, allowing the model to selectively propagate or forget information along the sequence length dimension depending on the current token". Δt, Bt and Ct become projections of xt: a large Δt resets the state toward the current token, a small one keeps the past. In the trained tiny SSM below, one head's decay at moves with the text; an S4-style layer would draw a flat line.

Selection, measured: a trained head forgets hardest at the start of a name

The decay at = exp(ΔtAh) of one head of the SSM-only tiny GPT (run ba_ssm, section 9) over the 256-token running sequence (1 keeps everything, 0 resets the state). The default is layer 1's most variable head: it forgets hardest at the "R" pieces that start "Roxy" and at quotation marks, where a name or a line of dialogue begins. src/inside/ssm_inside.py, CPU, fp32. measured on Apple M1 Pro (CPU)

How it stays fast. The convolution is gone (the kernel changes every step), so Mamba runs the recurrence as "a hardware-aware parallel algorithm in recurrent mode": the expanded state never leaves on-chip SRAM. Its state per layer is dinner × N with N = 16: 5,120 × 16 for Mamba 2.8B. Without a KV cache it serves "4-5x higher inference throughput than a Transformer of similar size" because it "can use much higher batch sizes". authors

Mamba's kernel and state, in detail (depth)
The expanded state (batch × length × channels × N) never touches GPU main memory; parameters are loaded into on-chip SRAM, discretised and scanned there. N = 16 is the code's default and the paper's setting, dinner = 2 × dmodel. The throughput quote is section 4.5 ("since without the KV cache it can use much higher batch sizes"); the abstract rounds it to 5x.

Mamba-2: restrict A to a scalar, and the layer becomes masked attention

{{Mamba-2 (Dao and Gu 2024)|https://arxiv.org/abs/2405.21060}} simplifies A "from diagonal to scalar times identity structure": one decay at = exp(ΔtA) per head per step, shared by all its channels and state entries, with head dimension P = 64 or 128 like a transformer. Then unrolling gives

yi = ∑j≤i (Ci·Bj) · (aj+1aj+2…ai) · xj   ⇒   Y = (L ⊙ C B⊤) X
C B⊤
a T × T matrix of query-key scores: C plays the query, B the key, x the value
L
the decay mask, Lij = product of a's between j and i (1 on the diagonal, 0 above it): "1-semiseparable"

That is linear attention (section 2) with a decaying mask instead of the plain causal mask: "When L is the causal mask, it is standard linear attention", and the two are "duals of each other with the exact same linear and quadratic forms". The name is state space duality (SSD). So every SSM head has an implicit attention map ("Mamba models give rise to three orders of magnitude more attention matrices than transformers", {{Ali et al. 2024|https://arxiv.org/abs/2403.01590}}); here they are, on real weights:

Why it matters for speed. Split the sequence into chunks, use the quadratic form inside each chunk (matrix multiplies on tensor cores) and the recurrence between chunks. The SSD kernel is "2-8x faster than Mamba's fused associative scan" (a kernel speedup, not a whole-model one), and the speed buys state: Mamba-2 uses N "around 64 or 128" (code default 64; Nemotron-H 8B uses 128) against Mamba's 16. authors

SSD against FlashAttention-2 (depth)
The full quote: "2-8x faster than Mamba's fused associative scan, which does not leverage matmul units"; SSD crosses FlashAttention-2 "at sequence length 2K" and is "6x faster at sequence length 16K". authors

The topic's tiny GPT uses exactly this layer. Its SSM mixer (16 heads of 32 channels, N = 16, a short causal convolution, a gate) trains in the quadratic dual form and decodes with the recurrence (code in section 11). On the trained SSM-only model the two forms give logits that differ by at most 1.9e-5 on the running sequence (src/inside/ssm_inside.py, CPU, fp32).

How long each trained head remembers (depth: 96 half-lives)

Each head's decay at = exp(ΔtAh) is the share of its state that survives one token. Its median over the story, as a half-life ln 0.5 / ln a, in tokens (log scale): one dot per head, one row per layer.

96 heads: half-lives from 1.1 to 910 tokens, median 7.1; 22 heads keep half their state for 64 tokens or more. Most heads are short-range (local syntax); a few per layer carry the story. Head 0 of each layer starts with the slowest decay (A initialised from 1 to 16 across heads) and stays the longest in 5 of 6 layers. In the maps above, the long-memory SSM head draws vertical stripes (a few tokens written strongly, read by every later query, so which tokens are read is decided mostly when they are written); the short-memory head is a band along the diagonal broken where its decay falls to near zero; the attention head's stripes are short and scattered, because softmax compares every query with every key. measured on Apple M1 Pro (CPU)

Mamba-3 (2026, published only) (depth)
{{Mamba-3|https://arxiv.org/abs/2603.15569}} adds "a more expressive recurrence derived from SSM discretization", "a complex-valued state update rule that enables richer state tracking" and a multi-input multi-output form; the authors report "comparable perplexity to Mamba-2 despite using half of its predecessor's state size" at 1.5B. authors Not run here (no released small checkpoint in the topic's environment).
