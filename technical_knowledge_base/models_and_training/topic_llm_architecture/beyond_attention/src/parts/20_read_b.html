3. Forget or overwrite: decay, gates and the delta rule

Decay (forget everything a little). Multiply the state by a < 1 before each write: St = at St−1 + vtkt⊤. A write made n steps ago counts an, so old memories fade and stop interfering (a = 0.9 gives a half-life of 6.6 tokens). RetNet used a fixed a per head; Gated Linear Attention and RWKV-6 make it depend on the input and on the channel; Mamba-2 makes it one input-dependent scalar per head (section 4). In RWKV-7's words decay is "a blunt tool that cannot remove only the values stored at specific keys".

The delta rule (overwrite what this key held). Before writing v under k, read what the state returns for k, S k, and write only the difference: St = St−1 + βt(vt − St−1kt)kt⊤, with write strength β between 0 and 1. With unit keys and β = 1, S k returns exactly v afterwards, so a key written twice keeps only its latest value. {{Yang et al. 2024|https://arxiv.org/abs/2406.06484}}: "This process can also be regarded as optimizing an online regression loss using a single step of SGD", L(S) = ½‖S kt − vt‖2, where plain linear attention follows the "negative inner-product" loss −⟨S kt, vt⟩. It is the Widrow-Hoff rule of 1960, brought to transformers by DeltaNet ({{Schlag et al. 2021|https://arxiv.org/abs/2102.11174}}).

Both together, Gated DeltaNet ({{Yang, Kautz and Hatamizadeh 2024|https://arxiv.org/abs/2412.06464}}, eq. 10): St = St−1(αt(I − βtktkt⊤)) + βtvtkt⊤: "gating enables rapid memory erasure while the delta rule facilitates targeted updates". (DeltaNet papers' convention, S is dv × dk; see the conventions mistake in section 11.)

One state, five write rules: linear attention blends, decay forgets the old, the delta rule overwrites

Ten words of the running story, each with a fixed random unit key, written in order with a fresh random value; "Roxy" and "hill" are written again at the end with new values (underlined). After each write the state is read with every key so far and compared (cosine) with the value last stored under it. Same keys, values and order under each rule. illustrative input (random vectors, seed 1); exact arithmetic, equal to src/state/state_rules.py.

What it shows. At dk = 8, ten distinct keys overfill the state. Linear attention blends (mean cosine after all 12 writes 0.58; the re-written "Roxy" returns a mix of its old and new values). Decay keeps the recent and loses the old (0.61). The delta rule returns the re-written words almost exactly (1.00 for "hill") but its overwrites damage overlapping keys (mean 0.44; "climb" turns negative). At dk = 16, room for ten keys, the delta rule is the best recurrent rule (0.86 against 0.81 for linear). Softmax over a full cache recalls every single-write word at every size, but averages a re-written key's two values ("Roxy" 0.56): a bare key does not say which write is newer; real attention gets recency from positions.

Predict: a Gated DeltaNet head in Qwen3-Next has dk = dv = 128. Roughly how many unrelated (key, value) facts can its state hold before writes start to damage each other?
About dk. Exact retrieval needs keys that do not overlap, and at most dk unit vectors can be mutually orthogonal (the toy above: ten keys fit at dk = 16, not at 8). The 128 × 128 = 16,384 entries are the price of storing dv = 128 numbers under each of those directions. Learned keys are not random, so a trained model can do better on structured text and worse on adversarial lists; this is why Qwen3-Next keeps one attention layer in four.
