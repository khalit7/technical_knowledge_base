Inside the trained SSM

The SSM-only tiny GPT (run ba_ssm: 6 layers, each 16 heads of 32 channels with state 16, trained 1,500 steps on TinyStories) read on the 256-token running sequence: how long each head remembers, how its forgetting moves token by token, and the attention map hidden in its dual form, beside the attention model's real maps for the same tokens. src/inside/ssm_inside.py, CPU, fp32. measured on Apple M1 Pro (CPU)

1. How long each head remembers

Each head's decay at = exp(ΔtAh) is the share of its state that survives one token. Its median over the story, as a half-life ln 0.5 / ln a, in tokens (log scale): one dot per head, one row per layer.

2. The same 48 tokens: an attention head's map against an SSM head's hidden map

Mamba-2's layer is masked attention, yi = ∑j Mij xj with Mij = (Ci·Bj) × (decays between j and i) × Δj. Shown: |M| for one head, each row scaled to its maximum (the SSM's weights are not normalised like softmax). Beside it, the attention model (run at_mha, the Attention lab's) at the same layer: its head with the most weight far back, or its strongest previous-token head. Rows are queries (the token being produced), columns the earlier tokens. Step through the layers.

3. Forgetting, token by token

The decay at of one head at every token of the story (1 keeps everything, 0 resets the state to the current token). Selection means this line moves with the text; an S4-style layer would draw a flat line.
