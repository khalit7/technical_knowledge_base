10. Serving a recurrent or hybrid model

Memory. Per sequence, an attention model needs KV bytes per token × context; a recurrent layer needs its state once. At batch B both multiply by B, so the saving is what lets a server run more sequences at once, which is where the published throughput gains come from (Mamba: "since without the KV cache it can use much higher batch sizes"; Nemotron-H: "lower memory footprint from Mamba-2 layers facilitates using higher batch sizes"). The state is not free: at short contexts it is the bigger cost. Nemotron-H 8B's 98.8 MiB of fp32 state per sequence equals its attention layers' cache at tokens; Kimi K3 carries MiB of KDA state per sequence before its first token's cache. A server must reserve state memory for every live sequence even if it is 10 tokens long.

Compute. Decoding one token reads the weights (the same for both), plus the whole KV cache for attention or the fixed state for a recurrent layer. Prefill (processing the prompt) is matrix multiplies either way: attention's cost grows with T2, a chunked recurrent layer's with T. Vendor speedups compare whole systems: Qwen3-Next's "over 10x" beyond 32K is against dense Qwen3-32B, so its 3B active parameters (mixture of experts) carry part of it; Nemotron 3 Super's "up to 2.2x and 7.5x" against gpt-oss-120b and Qwen3.5-122B is at 8K input and 64K output on B200. vendor

What a state makes harder (follows from the mechanism, no measurement needed). A KV cache can be cut at any token: share a prompt prefix between requests, roll back rejected tokens in speculative decoding, branch for beam search. A recurrent state exists only at positions where it was saved. Prefix caching needs state snapshots at block boundaries, speculative decoding needs the state from before the draft (or a recomputation), and every branch needs its own copy of the state. Serving engines handle this with per-sequence state slots beside the paged KV cache ({{Batching, KV cache and scheduling|n:3c65c17b0d0d819db53bd2c48909e5b2}}, {{vLLM|n:3c65c17b0d0d8113b976d8bcaf2c0722}}); in the hybrid, only the attention layers use the paged cache.

Precision. States accumulate over thousands of steps, so they are kept in fp32 even when weights and the KV cache are bf16 (transformers' delta-rule loops cast to fp32: "calculations happen in float as states are more susceptible to rounding errors", modeling_kimi_linear.py). Section 12 measures what low precision does to a decay mask.
