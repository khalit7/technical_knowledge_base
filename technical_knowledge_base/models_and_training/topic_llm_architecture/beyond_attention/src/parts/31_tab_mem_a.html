State vs KV cache

How much memory one sequence needs, split into the cache that grows with context and the recurrent state that does not, for real configs. The numbers come from the root Config calculator's code (window.CC, included unchanged) plus this page's two additions for Kimi Delta Attention and Qwen3.5, checked against src/mem/statecalc.py at six contexts for every model. Conventions: KV in bf16 unless changed below, state in fp32, windows credited, one sequence (multiply by the batch). derived from configs, no model run.
