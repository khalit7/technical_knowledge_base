The idea in one screen

These layers replace attention's growing KV cache with a fixed-size state, updated once per token by a rule that is linear in the state, so they train in parallel like attention and decode at constant memory and cost. The designs differ only in how the state forgets and how it writes; and because a fixed state cannot hold arbitrary text exactly, every 2026 model that uses one keeps a few attention layers (a hybrid).

1. Recurrence against attention

Attention keeps everything: memory grows with every token and each new token reads all of it. To produce token t, causal attention compares qt with every earlier key and averages every earlier value, ot = ∑j≤t softmaxj(qt·kj/√d) vj, so generation keeps all of them (the KV cache): T reads at position T, and T2/2 for a whole sequence. The topic's tiny GPT keeps 6,144 bytes per token in bf16 (6 layers × 8 heads × 32 × 2 for K and V × 2 bytes); Llama 3.1 8B keeps 128 KiB per token, 16 GiB at 131,072 tokens (sizing for any model: {{Long context|n:3fd5c17b0d0d81059ee1ce20c0326dc5#t-kv}}).

A recurrent layer keeps a state ht of fixed size, updated once per token, ht = f(ht−1, xt), and reads out yt = g(ht, xt): memory and work per generated token no longer depend on t. Step through the same 8 tokens under both:

Why recurrence lost, and how it came back. RNNs and LSTMs ({{Sequence models: the pre-transformer lineage|n:3c65c17b0d0d818da4ded61ace6847ce}}) lost to attention for one reason: with a nonlinear f, ht needs ht−1, so training walks the sequence one step at a time and cannot use a GPU's parallelism across positions. The new designs make the update linear in the state, ht = At ht−1 + bt, with At and bt allowed to depend on xt but not on h. Unrolled, every ht is a sum of earlier inputs weighted by products of A's, computable for all t at once: by a parallel scan (an associative combine in log T rounds; the Mamba paper page animates Blelloch's version), by a convolution when A does not depend on the input (S4), or as one masked matrix product that looks exactly like attention (sections 2 and 4). Training is parallel; decoding is the cheap recurrence. What At is and how bt writes are the hero grid's two axes.

What it costs. Whatever the state does not hold is gone: a state of b bits cannot reproduce a string carrying more than b bits, the copying bound of {{Jelassi et al. 2024|https://arxiv.org/abs/2402.01032}} ("GSSMs cannot accurately copy strings with more bits than the size of the latent state"). Attention pays memory to avoid that limit. So the state wins on long contexts, many concurrent sequences and long generations, and loses on tasks that look up exact earlier text (copying, retrieval, few-shot formats). To check a config, compare its state with KV bytes per token × context ({{State vs KV cache|#t-mem}}); to check a model, probe recall (section 8).

2. Linear attention is a recurrence

The derivation. Softmax attention's weight for key j is exp(q·kj) divided by the sum over all keys. {{Katharopoulos et al. 2020|https://arxiv.org/abs/2006.16236}} replace exp(q·k) by a dot product of feature maps φ(q)·φ(k), with φ(x) = elu(x) + 1 to keep weights positive ("We prefer elu(.) over relu(.) to avoid setting the gradients to 0 when x is negative", eq. 7). Then the sum can be reassociated:

ot = ∑j≤t (φ(qt)⊤φ(kj)) vj / ∑j≤t φ(qt)⊤φ(kj) = St⊤φ(qt) / zt⊤φ(qt)
St = St−1 + φ(kt) vt⊤    zt = zt−1 + φ(kt)
St
the state: a dk × dv matrix, the sum of every key's outer product with its value
zt
the normaliser: the sum of the keys
φ
a feature map applied to queries and keys (elu + 1 here; later work uses identity with L2-normalised keys)

In the paper's words, "any transformer layer with causal masking can be written as a model that, given an input, modifies an internal state and then predicts an output, namely a Recurrent Neural Network" with "two hidden states, namely the attention memory s and the normalizer memory z". For one head of the tiny GPT (dk = dv = 32) the state is 1,024 + 32 numbers whatever the context, against 64 numbers per past token for its KV cache: the state is cheaper past 16 tokens.

Two ways to compute the same output: a masked T × T product for training, a d × d state for decoding

Left: stack all positions, O = ((φ(Q)φ(K)⊤) ⊙ M) V with M the causal mask, a T × T matrix like an attention map (row-normalised by the same sums): quadratic, parallel. Right: the recurrence, one outer product added per token, then one read with the query: linear, sequential. src/code/demos.py (CPU, float64, T = 64, d = 16): the two forms agree to 4.4e-16, with a state of 272 numbers whatever T is, where a KV cache here holds 2,048. measured

The cost. The parallel form is quadratic like attention; the recurrence is linear but sequential; production kernels split the sequence into chunks, use the quadratic form inside each chunk (matrix multiplies, which tensor cores are built for) and pass the state between chunks (section 4). MiniMax's lightning attention is this split as a kernel: the masked quadratic "left product" inside a block, one multiplication by the carried state for all earlier blocks ({{MiniMax|n:3c65c17b0d0d813ba1c0cb4ba00659b8#s-light}} steps through it).

The catch. S is a sum. Every write adds to it and nothing is ever removed, so once more keys than dk have been written they cannot all be orthogonal and reads return blends. {{Schlag, Irie and Schmidhuber 2021|https://arxiv.org/abs/2102.11174}}: "linear Transformers can end up in an overcapacity regime, if the sequence length L exceeds the dimension d_dot of the keys".
