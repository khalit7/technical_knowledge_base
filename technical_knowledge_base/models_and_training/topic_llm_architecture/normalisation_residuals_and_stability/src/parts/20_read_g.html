5. Output logits and z-loss

The problem. The last layer's softmax has the same weakness at the other end of the model. Cross-entropy depends only on differences between the output logits yj, so the whole vector can drift up or down for free; Z = Σj eyj is the softmax's normaliser and log Z measures that drift. {{Wortsman et al. 2023 (section 3.1.2)|https://arxiv.org/abs/2309.14322}} describe an instability where the logits "diverge and become very negative", far from the log-probabilities, which in low precision loses the small differences that matter.

loss = cross-entropy + c · (log Z)2,   log Z = log Σj exp(yj),   c = 10−4
log Z
0 when the logits are already log-probabilities; the penalty pulls them there without changing which token wins
c
PaLM's coefficient: "z loss = 10−4 · log2 Z to encourage the softmax normalizer log(Z) to be close to 0, which we found increases the stability of training" ({{PaLM, section 5|https://arxiv.org/abs/2204.02311}}); OLMo 2 and Wortsman et al. use the same value

How to check. Log mean log Z on a fixed batch; a value drifting steadily away from 0 is the symptom z-loss treats, and it costs one logsumexp you already pay for in the cross-entropy. Do not switch the z-loss implementation mid-run (OLMo 2's trap, in the mistakes at the end).
