The idea in one screen

Attention is blind to order, so position has to be put in. Nearly every open model does it with RoPE: each pair of query and key dimensions is turned by position × its own frequency, so a score depends only on the distance between two tokens. Its slow pairs, whose period is longer than the trained length, are what break past that length, and every context-extension method (PI, NTK, YaRN, Llama 3) is a rule for slowing them down.

RoPE is a bank of clocks; past the trained length only the slow ones leave the angles they learned

Absolute, relative
"where is this token" (added once to the input) against "how far apart are these two" (acting on each attention score, in every layer).
Embedding, encoding
a learned table of position vectors against a fixed function of position. The naming is loose: RoPE is "rotary position embedding" although nothing in it is learned.
Pair, θi, wavelength
RoPE turns dimensions two at a time; pair i turns θi radians per token and completes a turn every λi = 2π/θi tokens.
Base
rope_theta: θi = base−2i/d, so a larger base makes the slow pairs slower.
L, s
the length the model was pretrained at, and the stretch factor s = Lnew / L.
Fast, slow pair
wavelength shorter or longer than L: a fast pair has seen every angle in training, a slow pair only a wedge.
NoPE, partial RoPE
no position signal at all (the causal mask still orders tokens); rotating only some of a head's dimensions.

1. Why attention needs positions at all

A head scores the token at i against every key j with sij = qi · kj / √d, and q, k, v are linear maps of each token's vector, which says nothing about where the token is. Shuffle the inputs and the outputs shuffle the same way: attention is permutation-equivariant, so "Roxy climbed the hill" and "the hill climbed Roxy" are the same bag of vectors. The causal mask leaks some order: one layer still sees a set (shuffle tokens 0 to i − 1 and token i's output is unchanged), but each earlier token saw a different prefix, so from the second layer on the stack can count. A decoder with no positions (NoPE) can learn order; a bidirectional encoder cannot.
