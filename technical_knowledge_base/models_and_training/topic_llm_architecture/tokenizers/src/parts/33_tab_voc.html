Vocabulary size

A bigger vocabulary packs more text into each token, so every request is shorter; it costs one row of the embedding matrix per entry (and a second row in the output layer unless the two are tied). This tab puts both sides of that trade on data: vocabularies over time, what they cost in parameters, and what they save in tokens.

All rows, with sources

Vocabulary = vocab_size in each model's config.json on Hugging Face (fetched 3 October 2026, the 2026 additions 18 October 2026; padded, see the Reading tab), or the tiktoken encoding size for OpenAI's closed models. Date = the paper or announcement for the 2018 to 2020 models, LLaMA and the closed models; for the others, the day the Hugging Face repository was created, a proxy for the public release of the weights (the official repository where it is not gated, otherwise the named mirror).
