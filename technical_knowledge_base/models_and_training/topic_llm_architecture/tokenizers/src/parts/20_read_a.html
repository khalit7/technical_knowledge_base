The idea in one screen

A tokenizer is a lossless compressor with a frozen dictionary: learned from a corpus before pretraining, it cuts text into pieces from a fixed vocabulary of V entries and hands the model their integer ids, so the vocabulary decides how many tokens every text costs, how large the model's input and output tables are, and what the model can see inside a word.

One sentence of the running story becomes 11 ids; the vocabulary sets three costs

The running example's real tokenizer (4,096 entries, byte-level BPE trained on TinyStories) on a sentence of its running story. Ids are laid out in the order the vocabulary was built: 0 the special token, 1 to 256 the bytes, 257 to 4,095 the merges in the order learned. "Roxy" never earned a merge, so it is four byte tokens (the full stop is a single byte too); every other word is one token with its leading space. Each id selects one row of the embedding table, and the tied output layer scores all 4,096 entries for every token.

You need: what an embedding and an output layer (unembedding) are; both are built from zero in {{The transformer from zero|n:3fd5c17b0d0d8174980ddde4a20c7b3c}}. This page owns the vocabulary that feeds them. The running example is the one of {{Topic: llm-architecture|n:3fd5c17b0d0d8172b490dc9f9ac281df}}: the tiny GPT (6 layers, width 256, 5.84M parameters) reads TinyStories through a byte-level BPE of 4,096 tokens trained on TinyStories itself, and the running sequence is the 256-token opening of a held-out story about Roxy the rhinoceros (root src/data/README.md).

Token, vocabulary, id
a piece of text; the fixed list of all pieces (V entries); a piece's position in that list.
Merge (BPE)
one learned rule "these two adjacent tokens become one new token"; a BPE vocabulary is 256 bytes plus its merges in order.
Pre-tokenizer
a fixed rule (usually a regular expression) that cuts text into chunks no token may cross.
Byte-level
the base alphabet is the 256 byte values, so no text is ever unknown.
Special token
a reserved id (end of text, chat roles, tool calls) matched as a whole string, never learned by merging.
Chat template
the rule that writes a conversation as one string of special tokens and text.
Premium
how many tokens a language needs for the same content relative to English.
Glitch token
a vocabulary entry the model almost never saw in training, so its row stayed untrained.
