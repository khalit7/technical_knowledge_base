The idea in one screen

A step's time is the sum of the parts that do not overlap. Between kernels a GPU waits in three ways: for the CPU to launch the next kernel, for a copy over PCIe, and for other GPUs to exchange gradients. Streams let copies, compute and communication run side by side, CUDA graphs launch a whole sequence with one call, and NCCL on its own stream hides the all-reduce under backward. Overlap hides the smaller of two things under the larger; it never makes the larger one shorter.

The same work, with the three waits removed: what is left is the larger of each pair

One GPU, one training step, one row per stream. Top: everything in series; the numbered pale blocks are the SMs idle, waiting for 1 the copy, 2 the CPU to launch each small kernel, 3 the all-reduce. Bottom: the next batch is copied on a copy stream under compute, the small kernels replay as one CUDA graph with no gaps, and gradient buckets are all-reduced under backward; the last bucket is still exposed (section 6 says why). Stream
a queue of GPU work: in order inside a stream, possibly overlapping across streams.
Event
a marker in a stream: other streams can wait on it, and two events time the GPU.
Pinned memory
page-locked host memory; required for a copy to run asynchronously.
Copy engine
a DMA unit separate from the SMs, so a copy and a kernel can run together.
CUDA graph
a recorded sequence of kernels and copies, instantiated once, launched with one call.
Peer access
a kernel on one GPU loading and storing another GPU's memory directly.
Communicator, collective
NCCL's group of ranks; an all-reduce or all-gather queued as kernels on a stream.
Bucket
a group of gradients DDP all-reduces together as soon as all are ready.
Symmetric memory
the same buffer on every GPU, which kernels on the others can read and write.
Provenance: what could run here without an NVIDIA GPU

There is no NVIDIA GPU. Every CUDA program on this page was compiled with CUDA 13.4.2 and NCCL 2.31.2 in a container compiled here; runs stop at the first runtime call with "CUDA driver version is insufficient for CUDA runtime version (35)". Gradient overlap was run with real PyTorch DDP on CPU processes (Gloo instead of NCCL) measured on CPU; launch and queueing costs were measured on the Apple M1 Pro's GPU through Metal measured on Apple M1 Pro GPU. NVIDIA timings come from NVIDIA's posts and docs published; the training-step timelines are a model built from stated inputs derived.
