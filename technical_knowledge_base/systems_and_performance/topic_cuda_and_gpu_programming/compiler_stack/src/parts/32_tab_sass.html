SASS, decoded: the scheduling bits of four real kernels

Every instruction below was compiled here (CUDA 13.4.2) and disassembled with nvdisasm -hex; the control bits are decoded with Jia et al.'s layout, which the Reading tab's section 3 checks on six kernels (no violations). Step through a kernel: each instruction either issues after its stall count, or first waits for the scoreboards in its mask. The six boxes are the six scoreboards: which register each is guarding, set by which instruction.

Try: in the softmax, find the first LDG.E (it sets a scoreboard) and step to the FMNMX that waits for it; in the wgmma tile, watch HGMMA and the WARPGROUP instructions; compare the softmax on sm_90a and sm_100a.

"Issue cycles" adds the stall counts of the instructions so far: the time a single warp would take if no scoreboard ever made it wait and the scheduler never switched warps. It is a lower bound from the encoding, not a measurement.
