The compiler stack: PTX, SASS, NVRTC, torch.compile and Inductor

How your code becomes GPU instructions, on both roads you will use: CUDA C++ through nvcc (front end, NVVM, PTX, ptxas, SASS, fat binaries, the driver's JIT) and PyTorch through torch.compile (Dynamo, AOTAutograd, Inductor, Triton or C++). How to read PTX and SASS, including the scheduling bits hidden in every instruction; which binary runs on which GPU and why; NVRTC and inline PTX; where the MLIR-based stacks sit. Everything compiled or run here: CUDA 13.4.2 and torch 2.14.1 in a Docker image on a laptop with no NVIDIA GPU, so nothing here ran on an NVIDIA GPU.
