Will it run? The driver's choice, step by step

When a kernel is first used, the CUDA driver looks inside the binary's fat binary for something this GPU can run: first a compatible SASS image, then a PTX image it can compile. Pick a binary (the real objects compiled on this page, PyTorch 2.14's wheels, or your own mix), a GPU and a driver, and step through the search. The toggle runs the same binary with its PTX removed, the usual difference between a binary that survives a new GPU and one that does not.

What this is
A model of NVIDIA's documented rules (CUDA Programming Guide 1.3 for SASS and PTX compatibility, the May 2025 blog for a and f, the compatibility guide for drivers, the environment-variable appendix), checked against a Python reference (src/code/compat.py) on all combinations. The binaries' contents are real (cuobjdump on objects compiled here, and PyTorch's build table); nothing was loaded on a GPU. Section 4 of the Reading tab has the sources.
