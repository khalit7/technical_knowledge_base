Which thread holds which element: draw any 2D blocked layout from its four fields, on any tensor shape, and see each thread's registers, broadcast copies and the linear-layout bases Triton uses internally.



Each cell is one tensor element, coloured by warp, labelled T(thread):register when there is room; outlined cells belong to the highlighted thread; a number in the corner counts broadcast copies (several threads holding the same element). The bases are built the way Triton converts a blocked layout to a linear layout: register bits for sizePerThread, then lane bits, then warp bits, each in order, then extra register bits for repeats; a basis that falls outside the tensor becomes [0, 0], which is broadcast. Element of (warp, lane, register) = XOR of the bases of its set bits. Checked against Triton 3.8.0's own to_linear_layout output for the 8 presets marked "Triton printed" (src/out/gluon.json), and against the table printed in Gluon tutorial 02.
