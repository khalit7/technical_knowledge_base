Compiled for NVIDIA: what nvcc made of each kernel

The page's CUDA kernels (the reduction ladder, CUB's block reduce and scan, Boehm's matmul ladder rewritten, and the 4-bit GEMV) compiled with CUDA 13.4.2 for three GPUs, without a GPU, in the kb-gpu-lab:1 container the topic root built: sm_80 (A100), sm_90a (H100) and sm_120 (RTX 5090). Registers, shared memory and spills come from ptxas -v; instruction counts from cuobjdump -sass. All compiled, nothing run. Counts are static (how often an instruction appears in the binary; a loop body counts once).

FFMA: fused multiply-add (float32). LDS / LDS.128: shared-memory loads, 4 or 16 bytes per lane. LDG: global loads. STS: shared stores. BAR: barriers (__syncthreads). SHFL: warp shuffles. I2F: integer-to-float conversions. "FFMA per LDS" is the reuse ratio of section 4: multiply-adds per shared-memory load instruction. Blocks per SM from registers alone use NVIDIA's allocation rules as reproduced by the topic root's GPU simulator (registers per warp rounded up to 256, 64K per SM, at most 64 warps on sm_80 and sm_90a, 48 on sm_120) derived; shared memory and the block's other limits can lower it.
