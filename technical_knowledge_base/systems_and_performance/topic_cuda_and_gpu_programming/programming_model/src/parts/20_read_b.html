A GPU runs one function, the kernel, on tens of thousands of threads at once. The programming model is the contract between you and the hardware: how you launch those threads, how each one finds its piece of data, which threads may talk to each other and how they wait for each other, and what the launch costs. This page teaches that contract from zero with real CUDA code compiled by NVIDIA's own compiler, and real runs on a real GPU (an Apple M1 Pro, the only GPU available here; every number says where it comes from).

The running example. Attention scores s, a 4,096 by 4,096 float32 matrix, need two things on the way to a softmax: an elementwise step (scale every score, e = a * s: every element independent) and a reduction (the sum of each row: many elements combine into one). The elementwise step teaches launches and indexing; the reduction forces threads to cooperate, which teaches warps, shared memory, barriers and atomics. The parent page, {{Topic: cuda-and-gpu-programming|n:3c65c17b0d0d81c39f34d5e070d783c1}}, follows the full softmax and attention from PyTorch down to the instructions; this page owns the model underneath.
