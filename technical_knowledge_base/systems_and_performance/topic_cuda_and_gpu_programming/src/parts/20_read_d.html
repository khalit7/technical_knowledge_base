Triton: 9 lines; the whole row is one block of values
@triton.jit
def softmax(x_ptr, y_ptr, ncols, stride, BLOCK: tl.constexpr):
    row = tl.program_id(0)          # one program per row
    offs = tl.arange(0, BLOCK)
    mask = offs < ncols
    x = tl.load(x_ptr + row * stride + offs,
                mask=mask, other=-float("inf"))
    x = x - tl.max(x, axis=0)       # reduction: compiler's job
    e = tl.exp(x)
    tl.store(y_ptr + row * stride + offs,
             e / tl.sum(e, axis=0), mask=mask)

tl.program_id replaces blockIdx; tl.arange with a mask replaces per-thread indexing and bounds checks; tl.max and tl.sum emit the shuffles written by hand on the left. One Triton matmul source, compiled here without a GPU, picks HMMA on sm_80 and sm_120, HGMMA on sm_90a and UTCHMMA on sm_100a compiled here. The often-quoted "within 0 to 20% of expert CUDA in a tenth of the code" is a rule of thumb from the old page unconfirmed as a general figure; the line counts above are one data point.

7. Tensor cores: one instruction per generation

A tensor core multiplies small matrix tiles in one instruction. You reach it, from most to least abstract, through a library, Triton's tl.dot, CUTLASS/CuTe, or PTX directly, and the instruction changed shape every generation, which is what makes peak kernel code generation-specific:

GenerationInstruction (PTX, then SASS)Issued by; accumulators inFed by
Ampere sm_80 (and consumer sm_86, sm_89, sm_120)mma.sync → HMMAone warp; registerscp.async
Hopper sm_90awgmma → HGMMAa warpgroup of 4 warps, asynchronously; registers, operands from shared memoryTMA: one thread starts a bulk tile copy
Datacenter Blackwell sm_100atcgen05.mma → UTCHMMAone thread for the block; TMEM, tensor memory beside the SMTMA

The trap compiled here: wgmma assembles only for sm_90a and tcgen05 only for sm_100a, while TMA and clusters compile for sm_90a, sm_100a and sm_120. So an RTX 5090 (sm_120) has TMA and clusters but no wgmma, tcgen05 or TMEM, and a Hopper tutorial does not run on it as written; the a suffix marks features that do not carry forward. A modern Hopper or Blackwell kernel is warp-specialised: producer warps only issue TMA copies, consumer warps only issue matrix instructions, linked by barriers in shared memory with several tiles in flight. Once you can name those four parts, FlashAttention-3 or a CUTLASS mainloop becomes readable.
