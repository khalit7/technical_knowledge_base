Interview rehearsal: ten questions with short answers

What is a warp, and why does it matter for performance? 32 threads that execute one instruction at a time together. Branch divergence, memory coalescing and shuffles are all defined per warp; a warp is the unit the scheduler switches between to hide latency.

Why is softmax memory-bound and matmul compute-bound? Softmax does a handful of operations per element read, under one per byte, far below the roughly 295 operations per byte an H100 needs to be compute-bound. An N × N matmul does 2N³ operations on 3N² values, so its intensity grows with N, provided tiling keeps the reuse on chip.

What does shared memory buy you in a matmul? Each tile of A and B is fetched from global memory once and reused by every thread in the block, cutting global traffic by the tile width; register tiling repeats the trick one level down.

Explain FlashAttention in three sentences. Standard attention writes the N × N score and probability matrices to HBM. FlashAttention tiles Q, K and V so each block of scores is computed and consumed on chip, using the online-softmax rescaling to combine blocks, and recomputes scores in the backward pass instead of storing them. It does the same FLOPs with far fewer HBM bytes and O(N) extra memory.

High occupancy is good, right? Only as a means. It helps memory-bound kernels hide latency; fast matmul and attention kernels run at low occupancy on purpose because registers per thread buy reuse. Measure achieved bandwidth or FLOPs, not occupancy.

Your custom kernel is 2 times faster than PyTorch. What do you check before believing it? Correctness against a reference at several sizes; synchronisation and warmup in the timing; L2 effects (data larger than the cache, or flushed); the baseline (compiled, right dtype and layout); clocks and load; spread over repeated runs.

What is the difference between PTX and SASS? PTX is a stable virtual instruction set; SASS is the real machine code of one GPU generation, produced from PTX by ptxas (or by the driver at load time). You read SASS to see what really runs: vector loads, tensor-core instructions, spills.

Why does a Hopper kernel not run on an RTX 5090? sm_120 has TMA and clusters but not wgmma, tcgen05 or TMEM; a Hopper kernel built on wgmma will not even assemble for it. Consumer Blackwell kernels look like Ampere ones (mma.sync, register accumulators) plus TMA.

Nsight Systems or Nsight Compute first? Systems: it shows where the time goes across the whole program (gaps, overlap, launch overhead) at little cost. Then Compute on the kernels the timeline convicts, to see why each is slow.

When would you write Triton, CUDA, or neither? Neither if torch.compile or a library already does it. Triton for a new fusion or algorithm. CUDA or CUTLASS when you need control Triton hides (warp specialisation, exotic layouts) or the last few percent on a kernel that dominates the profile.
