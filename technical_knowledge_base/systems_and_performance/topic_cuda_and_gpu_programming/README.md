# Topic: cuda-and-gpu-programming

Notion: https://app.notion.com/p/3c65c17b0d0d81c39f34d5e070d783c1

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`). Follows one operation (softmax of attention scores, then a multiply by V) from PyTorch down to the instructions, taught from zero: dispatch and launches, the SIMT model, the memory hierarchy, the kernel optimisation ladder, fusion and FlashAttention, Triton, libraries and tensor cores, the compiler, profiling and correctness, other stacks and a learning path. Tabs: Reading (`src/read/`), GPU simulator (`src/sim/`: divergence, coalescing, bank conflicts, occupancy validated against NVIDIA's cuda_occupancy.h, latency hiding, tiling), Compiler explorer (`src/compile/`: real CUDA 13.4.2 and Triton 3.8.0 output, PTX and SASS for sm_80, sm_90a, sm_100a and sm_120, built in a Docker image without a GPU; raw cubins and dumps are git-ignored and regenerated by `run_all.sh`), Kernel lab (`src/lab/`: softmax, matmul and attention ladders as Metal kernels timed on the Apple M1 Pro GPU and as Triton kernels checked with the interpreter), Further reading.
No NVIDIA GPU was available: measurements are on the Apple M1 Pro GPU and labelled; NVIDIA behaviour is from compiler output, documentation and published measurements, each labelled. The old written root and its six children are saved verbatim in `src/read/old/` and checked in `src/read/coverage.md`.
