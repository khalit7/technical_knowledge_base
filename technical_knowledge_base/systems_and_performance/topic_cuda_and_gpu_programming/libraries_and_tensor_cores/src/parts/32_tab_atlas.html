Each row is one small CUDA kernel written around one tensor-core, copy or synchronisation instruction (in inline PTX); each column a compilation target. Every cell is a real nvcc and ptxas run from CUDA 13.4.2 in the Docker image kb-gpu-lab:1, without a GPU compiled here: green if it assembled (the cell names the SASS opcode), grey with the reason if ptxas refused. Click a cell for the PTX, ptxas's report and the SASS lines. Nothing here was run; numerical results are not verified.
