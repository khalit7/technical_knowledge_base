Layout lab: CuTe's algebra, checked against CuTe

Type a layout as shape:stride (nested parentheses allowed), pick an operation, and see the result as CuTe prints it and as a grid of offsets (rows are mode 0, columns the rest, index counted with the leftmost mode fastest). The algebra is this page's JavaScript port of include/cute/layout.hpp from CUTLASS 4.8.0; every preset was also computed by CuTe itself, compiled and run in the CUDA 13.4.2 image, and the badge says whether the two agree compiled here. Section 7 of the Reading tab explains each operation.

Swizzles and banks

Eight rows of 64 BF16 values (128 bytes each) in shared memory. Each cell is a 16-byte chunk, coloured by the group of four 4-byte banks it lands in; reading one column of chunks down the eight rows (what an MMA operand load does) is conflict-free only if the eight colours differ. Compare no swizzle with CuTe's Sw<3,3,3> (in 16-bit elements; Sw<3,4,3> on byte addresses, CUTLASS's 128-byte atom).

Thread-value layouts of tensor-core instructions

Which thread holds which element of an instruction's operand tile, from CuTe's MMA_Traits (printed by CuTe in the image). Hover or tap a cell; the colour is the thread.
