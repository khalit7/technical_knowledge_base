# Libraries and tensor cores: sources, scripts, outputs

- `build.sh`: assembles `../index.html` from `parts/` (Reading `20_read_a` to `20_read_f.html` with JS `21` to `27`; tabs `31` Layout lab, `32` Instruction atlas, `39` Further reading; every JS part in its own script, `99_js_tabs.js` last; error box from `.claude/skills/explainer-page/build/templates/`). `21_js_rd_common.js` and `99_js_tabs.js` are the explainer-page skill templates (storage key `cuda-lib-tab`; nothing moves before the reader acts). `22_js_cute.js` is the CuTe layout algebra (pure functions); `23_js_data.js` is generated by `recompute.py` (window.LT); `24_js_rd_static.js` fills the Reading charts and tables; `25_js_rd_gen.js` is the three-generation tile animation; `26_js_rd_hero.js`, `26_js_rd_mma.js`, `26_js_rd_bud.js` are the hero, the MMA tile shapes and the SM budget; `27_js_rd_sched.js` is the GEMM scheduler (window.GS, formerly its own tab); `31_js_layout.js` also draws the swizzle bank view that now sits in Reading section 7.
- `run_all.sh`: reproduces everything (Docker image kb-gpu-lab:1 with CUDA 13.4.2 from the CUDA root, no GPU; a CUTLASS v4.8.0 checkout outside the repo; the shared MLX env for the M1 runs; large raw listings kept outside the repo in `$RAW`).
- `cuda/`: `gen_kernels.py` writes 20 one-instruction kernels (`kernels/i01..i21`: mma.sync in six types, ldmatrix/stmatrix, wgmma SS/RS/FP8/N=256, tcgen05 f16/tf32/f8f6f4/MX/NVFP4/cta_group::2, TMA load/multicast/store, setmaxnreg); `compile_all.sh` compiles each for sm_80, sm_89, sm_90a, sm_100a, sm_100f, sm_103a, sm_120, sm_120a (ptxas reports and errors kept, SASS in `out/`); `extra_targets.sh` adds sm_107a, sm_110a, sm_121a; `host/` holds a cuBLASLt GELU_BIAS program and a TMA descriptor program, compiled and run without a GPU (outputs in `out/host/`); `summarise.py` writes `out/matrix.json`.
- `cute/layouts.cu`: CuTe (CUTLASS 4.8.0 headers) prints 21 layouts and 5 thread-value layouts with every value; `out/layouts.txt`. `check/check_layouts.mjs` checks `parts/22_js_cute.js` against it (21 cases, 6,326 values, 0 differences; `out/layout_check.json`).
- `cute_dsl/dsl_layouts.py`: nvidia-cutlass-dsl 4.8.0 without a GPU: layouts printed from Python and a kernel compiled to sm_90a PTX (`out/`).
- `cutlass_sass/`: CUTLASS examples 48, 70, 79a and six CuTe tutorials compiled to SASS (`compile_cutlass.sh`); the SASS (0.4 to 3 MB each) stays outside the repo; `summarise.py` keeps per-kernel registers and opcode counts in `out/cutlass_sass.json`.
- `cublas/`: `scan.sh` lists libcublasLt 13.8.0.4's kernels per architecture, scans each kernel's SASS for matrix and copy opcodes (`opscan.sh`), and extracts the CUTLASS 3.x kernel names stored as strings; `inventory.py` keeps the summary in `out/cublas_inventory.json`.
- `cudnn/probe.py`: cuDNN 9.27.0.42 and frontend 1.30.0 in the image: API surface and the handle failure without a GPU (`out/probe.txt`).
- `m1/measure.py`, `m1/run3.sh`: MLX 0.32.3 on the M1 Pro GPU: a library GEMM at nine shapes and a GEMM with a bias+GELU epilogue unfused, partly fused and fused, 3 runs (load 9.7 to 10.2); `m1/out/run_*.json`.
- `inputs/`: excerpts of `cublasLt.h` (epilogue and scale-mode enums with NVIDIA's comments) and the PyTorch header list.
- `recompute.py`: medians, derived numbers (tile counters, waves, stages, epilogue bytes), the scheduler model mirrored from `33_js_sched.js`; writes `out/data.json` and `parts/23_js_data.js`. `check_embed.py`: the page embeds exactly `out/data.json`, 48 tagged prose numbers equal the data, no private paths. `check/check_page.mjs`: puppeteer at 390 px dark and 920 px light, every control, the scheduler JS against `recompute.py`, every Layout-lab preset "matches CuTe", the swizzle view, and in normal motion that neither the tile animation nor the scheduler moves before the reader acts; element screenshots in `../.shots/el-*`.
- `live.md`: the old Notion page verbatim (fetched 2026-10-05, last edited 2026-09-22; identical to the root's `src/read/old/06_*.md`). `coverage.json`: its 50 claims with verdicts. `ledger.json`: the knowledge ledger of the 2026-10-23 rebuild. `viz_ideas.md`: visuals built and rejected.

Shape: `.claude/skills/explainer-page/page-kinds/topic-child.md`, rebuilt 2026-10-23 to `teaching/teaching-contract.md`.
