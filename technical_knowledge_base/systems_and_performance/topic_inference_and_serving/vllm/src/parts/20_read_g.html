6. Reading the metrics

vLLM's API server exports Prometheus metrics at /metrics, defined in one class, PrometheusStatLogger ({{loggers.py L509 onward|https://github.com/vllm-project/vllm/blob/v0.31.0/vllm/v1/metrics/loggers.py#L509}}). Their values come from two places, and knowing which tells you how fresh they are: gauges and counters about the scheduler (running, waiting, KV usage, prefix-cache queries and hits) arrive with every step's outputs as a SchedulerStats object built in the engine core ({{scheduler.py L2859|https://github.com/vllm-project/vllm/blob/v0.31.0/vllm/v1/core/sched/scheduler.py#L2859}}); per-request histograms (TTFT, ITL, queue time, prefill and decode time) are computed in the API server from timestamps the engine attaches to each request's events. The {{Knob lab|#t-knob}} lists every metric the live server exported, with values before and after a run.

Symptom in the metricsWhat it meansWhat to change
num_requests_waiting grows, kv_cache_usage_perc near 1, num_preemptions risingMemory-bound: prompts do not fit; running requests evict each other.More cache (utilization, FP8 KV), shorter max_model_len, more replicas.
num_requests_running pinned at max_num_seqs, waiting grows, KV usage well below 1The concurrency cap, not memory, is the limit.Raise max_num_seqs if TPOT allows.
request_queue_time_seconds high while running and KV are lowHead-of-line blocking or an engine stuck on something else (start-up, a long prefill without chunking).Check chunking; look at the iteration logs.
inter_token_latency_seconds has a long tail, TPOT mean finePrefill chunks are lengthening some decode steps.Smaller max_num_batched_tokens, or disaggregate.
prefix_cache_hits / prefix_cache_queries low on traffic that shares promptsPrefixes differ in the first block (a timestamp at the top of the system prompt), requests land on different replicas, or blocks are evicted before reuse.Put the variable part last; prefix-aware routing; more cache.
time_to_first_token_seconds high but queue time lowPrefill itself is slow: long prompts, or a budget too small to finish them in few steps.Raise max_num_batched_tokens; prefix caching.

Gaps worth knowing. No exported metric counts how many cached blocks are evicted to make room (only residency histograms, which need --kv-cache-metrics sampling) or how much work preemption threw away. Section 8 adds the first one, as a worked example of a contribution.
