4. The GGUF types measured: what each one costs

How quality was measured. Each file was compared with the F16 file on the same text (the first 40 windows of 512 tokens of WikiText-2's test split, the last 255 tokens of each window scored: 10,200 tokens). Three numbers, all from llama-perplexity --kl-divergence: perplexity (how surprised the model is by the real text; lower is better), KL divergence (KLD: how far the quantized model's whole next-token distribution moved from the F16 model's, averaged over tokens; 0 means identical) and same top token (how often both pick the same most likely token). KLD is the one to rank by: perplexity can improve by luck on one text, while KLD only grows as the model drifts from what was trained. Seven lessons from the ladder

  1. The importance matrix is the cheapest quality there is. Same file size, same speed: KLD fell by % at Q4_K_M, % at Q3_K_M and % at Q2_K. When you download a GGUF, prefer one made with an importance matrix; makers usually state it on the model card or in the file name.
  2. Legacy types are worse per bit. Q4_0 at bits drifts , more than Q4_K_M at without an imatrix (). Its one advantage is speed on this GPU (section 1).
  3. I-quants buy size, not magic. IQ4_XS with an importance matrix is bits against Q4_K_M's (8% smaller) and drifts against : about the same quality per byte, on the same curve. Choose between them by the size you need, and measure speed on your hardware (on this laptop IQ4_XS generated slightly faster than Q4_K_M).
  4. The averages hide the bad tokens. At Q4_K_M with an imatrix, mean KLD is but the worst 1% of tokens have KLD above , and the top token changes on % of tokens. Most text is unaffected; a few tokens, often the ones where the model was uncertain, flip. That is what users notice as an occasional odd word or a wrong digit.
  5. Perplexity can point the wrong way. On Qwen3-4B, Q4_K_M with an importance matrix has the lower KLD ( against ) but the higher perplexity ( against ; F16 ). Perplexity rewards a model for being confidently right on this one text, even when it got there by moving away from the original; KLD measures the move itself.
  6. Who made the file matters. The Q4_K_M GGUF that Qwen publishes for Qwen3-4B ({{Qwen/Qwen3-4B-GGUF|https://huggingface.co/Qwen/Qwen3-4B-GGUF}}, revision bc640142), measured the same way against this page's F16 conversion, drifted : twice this page's Q4_K_M without an imatrix and three times the one with. The same name, a different file (made with an older llama.cpp or from different source weights; the card does not say). Measure before you trust a download.
  7. Small models suffer more. llama-quantize's own help text quotes, for Llama-3-8B, +0.18 perplexity at Q4_K_M and +3.5 at Q2_K; on Qwen3-1.7B the same types cost and . Fewer weights carry more of the function each. Qwen3-4B, in the tab, sits between.
Predict: you have about 2.3 GB for weights. Which is the better model: Qwen3-1.7B at Q8_0 (2.2 GB) or Qwen3-4B at about 4 bits (2.3 to 2.5 GB)?
The old page's rule of thumb, "prefer a bigger model at Q4 over a smaller one at Q8", holds here, by measurement. Both models share a tokenizer, so their perplexities on the same text are comparable. It stops holding once the bigger model must go below about 3 bits.
