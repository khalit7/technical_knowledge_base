10. Very low bits: ternary and 1-bit models

Ternary weights (−1, 0, +1) need log23 ≈ 1.585 bits each, but rounding a normally trained model that far breaks it: Qwen3-1.7B at IQ1_M reached perplexity against (measured here). Such models must be trained ternary and stored in formats built for it.

What rounding does, measured (depth)

If weights could be only −1, 0 or +1 (ternary), each would need log23 each would need log23 = 1.58 bitsasymp; 1.585 bits, a 70B model would fit in about 14 GB, and multiplication would become addition and subtraction. You cannot get there by rounding a normally trained model. Measured here on Qwen3-1.7B: at IQ2_M with an importance matrix ( bits per weight) perplexity rose from to ; at IQ1_M ( bits) to ; llama.cpp's binary Q1_0 type (one scale per 128 weights and a sign bit each, 1.125 bits; the file averages bits with its embeddings kept at higher precision) gave , no longer a language model. Bigger models fall less far (llama-quantize's help gives +3.5 perplexity at Q2_K for Llama-3-8B, against here), but no normally trained model survives 1 or 2 bits. The working route is to train the model ternary from the start, or retrain it heavily, and store it in a format built for it.

Packing is a format question. GGUF's TQ1_0 packs mostly five ternary weights per byte (35 = 243 fits in 256) plus an F16 scale per 256 weights, 1.6875 bits per weight; TQ2_0 spends 2.0625 (2 bits each, faster to unpack). BITCOS notes that ternary models are up to 51.5% zeros, so storing a bitmap of the non-zero weights plus their signs costs 2 − z bits (z the zero share), down to 1.485. Same model, different bytes.

Reading "N-bit model at M tokens per second" claims

Ask four questions: was the model trained or retrained for that precision (if not, expect the cliff above); which benchmark gives the "98%" and against which baseline; what batch size, context and hardware produced the speed (decode at batch 1 on short context is the flattering case, section 1); and does stock software run it. The 1.58-bit idea is sound; the products are young.
