10. Phones and the browser, briefly

A phone is the same problem with a smaller budget: a few GB of memory shared with everything else, less bandwidth than a laptop (Apple publishes 120 GB/s for the base M4 chip, and does not publish iPhone figures), a battery and a thermal limit, and usually an NPU (a neural processing unit: fixed-function matrix hardware that runs integer and low-precision math efficiently, if the model was compiled for it). The bandwidth rule of section 1 still sets the decode ceiling, which is why Apple's on-device model (below) is about 3 billion parameters stored at 2 bits per weight. None of this was run here; these are pointers, each labelled.
