## Real engine on the M1 (`m1/`)
SGLang v0.5.21 built from source on macOS (pyproject_other.toml, `srt_mps` extra, `SGLANG_BUILD_RUST_EXTS=none`), MLX backend (`SGLANG_USE_MLX=1`),
model Qwen3-0.6B 4-bit MLX from the shared model store, port 8120, bench lock held for every run.
Patches applied to the installed package: `patch_pr41314_startup.diff` (upstream PR #41314, merged 2026-09-30, after the tag; without it the server does not start)
and `patch_pr42542_radix_flush.diff` (upstream PR #42542, open; without it cache hits can return another request's text, issue #42415).
`run_m1.sh` starts one server per configuration (chunked prefill 4096, at most 8 running, pool 24,000 tokens, no /flush_cache)
and runs `exp.py`; `summarise.py` writes `out/m1.json`; raw results in `results/`. The backend crashed (Metal "Insufficient Memory")
whenever the radix cache had to evict, when a prefill batch mixed a 512-token chunk with other requests, and on a burst after
/flush_cache; those settings avoid all three, which is why no scarce-pool experiment was run on the real engine (the isolated
scheduling model covers that case).

## Departures from the method
The page carries its own validation (real-class replays, policy shadow checks) because it compares engine internals; and a tab of real-engine runs, including two upstream bugs, because the evidence would otherwise be isolated models only.

## The 2026-10-23 rebuild: what changed and why
Rebuilt to the teaching contract (`.claude/skills/explainer-page/teaching/teaching-contract.md`); editing only, no new runs.
- **Top**: the core idea in one sentence, a new hero (static annotated diagram: router, the three processes, and inside the Scheduler the waiting queue, the radix tree mapping token runs to slots, the KV pool, the overlap loop and the grammar mask, each labelled with its section), "You need" linking the owners (root, Batching for continuous batching and prefix caching as ideas, vLLM), six new terms, the short answer. - **All four lab tabs moved into the Reading flow**, each beside the claim it proves: the Radix lab is section 3's visual (it replaced the static bars), the Scheduling lab section 4's (it replaced the ten-order bars, whose numbers are now its caption), the InferenceX chart section 10's; the SGLang on the M1 tab was split into closed "on the real engine" blocks in sections 3, 4, 5, 6 and 11. Only Reading and Further reading remain.
- **New visuals for mechanisms that had none**: the hero, a constrained-request diagram (section 6) and the router's decision diagram (section 8).
- **Frontend language** (which this page owns per OWNERS.md) got a short program with `gen`, `select` and `fork` and how it maps onto the tree (adapted from the docs, not run).
- **Owned elsewhere**: the generic constrained-decoding mechanism (masks, XGrammar's context-independent tokens) is now a link to Sampling and decoding.
- **No autoplay**: the template `21_js_rd_common.js`; mode toggles no longer start playing; the scheduling animation uses `RD.anim`. `check_ui.mjs` now fails if any animation moves before the reader acts.
- **Script-filled numbers are static text** checked against the data by `check_page.py` (36 checks added), so the ledger can see them.
- **Deleted as fat**: the common-mistakes block (each restated a section), five interview answers that restated sections (three design questions kept closed), wind-ups, headings, pointers to removed tabs.
