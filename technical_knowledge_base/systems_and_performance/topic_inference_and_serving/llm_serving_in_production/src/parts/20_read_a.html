One serving engine on one GPU answers requests. A service is many copies of it behind a router, with metrics, an autoscaler and a load test that says how much it can take. This page is about the decisions that only appear at that level, and each comes with evidence: real replicas, a real trace and real engines run on an Apple M1 Pro, the routers' and engines' own code at pinned versions (llama.cpp build 11146, vLLM v0.31.0, SGLang v0.5.21), and published datacenter results kept apart and labelled.

The parent page, {{Topic: inference-and-serving|n:3c65c17b0d0d81c08b3bc95ff45c7b13}}, explains what happens inside one engine (prefill, decode, the KV cache, batching) and gives this page's running example: a chat assistant on Llama 3.1 70B in FP8, one H200 per replica, 2,000-token prompts of which 1,000 are a shared system prompt, 300-token answers. Words used throughout: TTFT is the time to the first token of an answer, TPOT the time per output token after it; a replica is one running copy of the model; an SLO (service level objective) is a target such as "99% of first tokens within 2 seconds".

DecisionThe questionWhat the evidence here says
{{1. Routing|#t-route}}Which replica gets each request?Following the cache saves prefill only if the chosen replica still holds the prefix; a router also needs a load signal. On a real multi-turn trace a cache-plus-queue score gave the lowest TTFT.
2. AutoscalingWhen to add and remove replicas?Not on GPU utilization (96% at a tenth of capacity). Queue depth, KV usage or a TTFT SLO, with headroom for the start-up time.
3. Cold startsHow long until a new replica serves?Bytes over bandwidth plus engine initialization; measured 3.2 GB/s from this laptop's SSD; tens of seconds to minutes on GPU servers.
4. Multi-LoRAMany fine-tunes on one model?llama-server batches only requests on the same adapter: 352 tokens/s on one, 83 to 127 with two to eight different ones. vLLM mixed four adapters at no extra cost.
5. Structured outputWhat does a JSON schema cost per token?No consistent cost per token on llama-server; without the schema 0 of 50 answers parsed strictly, with it 50 of 50.
6. ObservabilityWhich signals, which alerts?TTFT and TPOT percentiles, queue, KV, hit rate; burn-rate alerts on two SLOs.
{{7. Load testing|#t-load}}How much can it take, honestly?A 5-second freeze: 2 slow requests seen by a closed-loop generator, 94 by an open-loop one.
