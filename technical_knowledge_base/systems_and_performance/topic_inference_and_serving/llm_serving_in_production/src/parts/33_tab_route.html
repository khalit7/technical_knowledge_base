Router lab: every request of the routing runs

Three llama-server replicas of Qwen3-0.6B (Q4_K_M) on one Apple M1 Pro, each with 2 slots of 2,048 tokens and a 256 MiB host prompt cache, behind a router written for this page (src/exp/route_client.py). The trace is Mooncake's released conversation trace, sampled by conversation and compressed in time (). Every number below was returned by the replicas themselves: llama-server reports, for each request, how many prompt tokens it found cached and how many it computed. measured on Apple M1 Pro

Where each request went, and what it found

One dot per request, placed by the time it was sent and the replica it went to; colour is the share of its prompt found in that replica's cache, size its prompt length. A conversation's later turns can only hit where its earlier turns went.

Beyond three replicas (simulated)

The measurement has three replicas. To see the trend, src/exp/route_sim.py replays the same trace through 1 to 16 replicas whose cache is a least-recently-used set of 16-token blocks, with each request holding its replica's load for the time it took in the measured round-robin run.
