A learning path

The order matters more than any one link: every optimisation is an answer to a constraint met earlier. (1) What a request does: this page's sections 0 and 1, then {{kipply's Transformer Inference Arithmetic|https://kipp.ly/transformer-inference-arithmetic/}} (30 min). (2) The model only as deep as the engines need: {{Brendan Bycroft's LLM Visualization|https://bbycroft.net/llm}} (30 min). (3) The hardware: Horace He's {{Making Deep Learning Go Brrrr From First Principles|https://horace.io/brrr_intro.html}} (25 min) and {{Topic: hardware|n:3c65c17b0d0d8118beeefaed56da6f8e}}. (4) The techniques: sections 2 to 8 and the {{Serving simulator|#t-sim}}. (5) The engines: section 5, then {{Inside vLLM|https://blog.vllm.ai/2025/09/05/anatomy-of-vllm.html}} (60 min) and the {{vLLM architecture overview|https://docs.vllm.ai/en/latest/design/arch_overview/}} (30 min).
