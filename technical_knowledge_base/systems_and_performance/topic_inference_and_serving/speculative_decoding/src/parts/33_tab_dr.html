What the runs show

The drafters and how they were run

Commands: llama-server -m Qwen3-4B-Q4_K_M.gguf -ngl 99 -fa on -np 1 -c 4096 plus the flags in the table; client: llama-server's /completion, temperature 0, cache_prompt off, each prompt once. llama-server's own timings give tokens per second of generation (predicted_per_second) and drafted and accepted counts. Acceptance length = generated tokens / (generated tokens − accepted guesses), the mean tokens per target pass. Not run here: Medusa (no llama.cpp support), MTP (Qwen3 checkpoints have no MTP heads; llama.cpp's draft-mtp needs a model that ships them), suffix decoding (vLLM only), and any GPU datacenter engine.
