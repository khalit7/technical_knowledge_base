Sharding and scale: Mesh, GSPMD, shard_map and multi-host

How JAX spreads one program over many devices, one level below the root page's Sharding lab: how the compiler's sharding propagation actually decides (GSPMD and Shardy, compared on the same program), explicit sharding in the types, every parallelism strategy run for real on the running example and on a 25M-parameter version (data, FSDP, HSDP, tensor, context, pipeline, expert), collective cost models checked against the compiler's byte counts, choosing a mesh for a TPU slice, and multi-process JAX run with two processes. Run on an Apple M1 Pro CPU with 8 simulated devices; TPU numbers are published ones, kept apart. Data as of October 2026.
