4. Porting pitfalls, measured

Each switch below is one mistake a port can make without any error message: a default that differs between the libraries, or a layout slip. Each was trained for 300 steps from the same weights on the same batches as the PyTorch twin (src/train/pitfalls.py). Turn them on to overlay how far each run's training loss is from PyTorch's (or the losses themselves, which mostly sit on top of each other), and see the two numbers that would have caught them: the largest logit difference before any training, and the validation loss after 300 steps.

What the numbers say

Three lessons. A mistake need not make training worse, only different: the validation loss after 300 steps is with optax's default b2 and with Flax's default initialisers, both below PyTorch's , so a falling loss proves nothing about a port (one seed, 300 steps: these are not claims that the defaults are better). The forward-pass mistakes show at step 0: the missing transpose moves the logits by , the LayerNorm epsilon by and the tanh GELU by , against for the correct port; one batch of logits with copied weights catches all three before any training. The optimiser mistakes are invisible at step 0 (logits identical) and only show as curves drifting apart, so test the optimiser separately: one step on the same gradients, as in section 2.
