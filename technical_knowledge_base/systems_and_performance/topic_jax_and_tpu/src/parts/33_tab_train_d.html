4. Porting pitfalls, measured

The seven pitfall runs this lab trained (a missing transpose, the LayerNorm epsilon, the tanh GELU, optax's default b2, Flax's default initialisers and others, 300 steps each from the PyTorch twin's weights) teach three things: a mistake need not make training worse, only different, so a falling loss proves nothing about a port; forward-pass mistakes show at step 0, and one batch of logits from copied weights catches them all; optimiser mistakes are invisible at step 0 and need a one-step test on the same gradients (section 2).
