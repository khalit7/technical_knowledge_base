7. The codebases worth reading

Production JAX for large language models lives in a few open repositories. They are where the ideas of sections 2 to 6 meet: a model in Flax NNX, an optax optimiser, orbax checkpoints, grain data, and above all the sharding rules that map each weight's named dimensions onto a mesh. Activity below is the last push to the default branch, read from the GitHub API on 2026-10-15.

CodebaseWhat it isRead it for
{{MaxText|https://github.com/AI-Hypercomputer/maxtext}}Google's "high performance, highly scalable, open-source LLM library and reference implementation" in pure JAX, for TPUs and GPUs: Gemma, Llama, Qwen, DeepSeek, Kimi, GPT-OSS, Mixtral; "migrated to Flax NNX from Linen" (README news, 2026-06-29); post-training through Tunix since 2025-10-10. Pushed 2026-10-15.The decoder and the train step; logical_axis_rules, which map logical dimension names (embed, mlp, heads) to mesh axes in a config so sharding never appears in model code.
{{Tunix|https://github.com/google/tunix}}Google's JAX post-training library ("Tune-in-JAX"): supervised fine-tuning (full and parameter-efficient), DPO and ORPO, RL with PPO, GRPO, GSPO-Token, DAPO and Dr.GRPO, multi-turn agentic RL, and a distillation package. "V2 Release", "under active development". Pushed 2026-10-15.The GRPO trainer: how sampling and training share one set of devices. What GRPO and PPO are is taught on {{RL for LLMs|n:3c65c17b0d0d818c9bcff7177325fe56}}.
levanter (now in {{Marin|https://github.com/marin-community/marin}})Stanford CRFM's trainer, built "with JAX, Equinox, and Haliax" (a named-tensor library); "bitwise deterministic ... even in the face of preemption and resumption" on TPU. "Levanter has been merged into Marin" (November 2025); development continues in Marin's lib/levanter/.A non-Google design: named axes everywhere, and what it takes to make a run reproducible to the bit.
{{AXLearn|https://github.com/apple/axlearn}}Apple's JAX library on which its foundation models were trained (section 1). Pushed 2026-07-08.A second large-company stack, configuration-heavy.
{{big_vision|https://github.com/google-research/big_vision}}Google Research's vision codebase (ViT and its descendants) in Flax Linen. Last pushed 2025-05-19: not archived, but quiet.The older functional Linen style in its cleanest form.

Older Google stacks (T5X, Pax), EasyLM and serving (vLLM's TPU backend tpu-inference, which says it unifies "JAX and PyTorch under a single lowering path", and JetStream) are dated on the {{Tool map|#t-map}}.
