5. Arrays are immutable

A JAX array never changes after it is created; operations return new arrays. This is what makes purity cheap to check, and the compiler gets the in-place update back where it is safe (inside jit, and across steps with buffer donation, measured in the {{Compiler lab|#t-xla}}). The indexed-update API is x.at[index].set / add / multiply / min / max / get.



Two behaviours that differ from PyTorch:


    

  • Repeated indices accumulate in JAX. x.at[[0, 0, 0]].add(1.0) adds 3 to x[0] (scatter-add). PyTorch's t[[0, 0, 0]] += 1 adds only 1, because it gathers, adds, then writes back; index_put_(..., accumulate=True) is the accumulating form.

  • Out-of-bounds indices do not raise in JAX.
