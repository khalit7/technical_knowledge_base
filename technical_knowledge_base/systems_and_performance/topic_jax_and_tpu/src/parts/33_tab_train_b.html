1. Modules: where do the weights live?

The problem. In PyTorch a layer is an object that owns its weights and changes them in place, and loss.backward() finds them through the object. JAX's transformations (jit, grad, vmap) work on pure functions of arrays: they only see what is passed in as arguments, as a pytree (any nesting of lists, tuples and dicts whose leaves are arrays; the {{Transforms lab|#t-xf}} builds them from zero). So every JAX neural-network library has to answer one question: how does a model's state get in and out of a pure function? There are four answers.

Flax NNX: objects that split into structure and arrays

An nnx.Module is a normal Python object, built eagerly like an nn.Module; its weights are nnx.Param attributes and other state (counters, batch-norm statistics, RNG streams) is any other nnx.Variable. To cross into a JAX transformation it is split: nnx.split(model) returns a graphdef (the structure: classes, attribute names, shapes, no arrays; static and hashable, so it can key the compile cache) and a state (a pytree of the arrays). nnx.merge(graphdef, state) builds the object back. nnx.jit, nnx.grad and the other lifted transforms do the split before the call and the merge after, and copy any mutation (an updated counter, new weights) back into your object, which is why NNX code reads like PyTorch.

Linen, Equinox and Haiku

Flax Linen modules are dataclasses that hold no weights: params = model.init(key, x) traces the model once to create a nested dict, and model.apply(params, x) runs it. Most JAX code written before 2025 looks like this; Flax says Linen will not be deprecated soon but recommends NNX for new code (quoted in the Reading tab). Equinox makes the model itself a pytree (a frozen dataclass whose array fields are leaves), so jax.jit and jax.grad take the model directly; its layers act on one example, so you jax.vmap over the batch, and its Linear.weight is [out, in] like PyTorch. Haiku (DeepMind) turns a function that creates modules into a pure (init, apply) pair with hk.transform; DeepMind recommends Flax for new projects and Haiku is in maintenance mode (see the {{Tool map|#t-map}}).
