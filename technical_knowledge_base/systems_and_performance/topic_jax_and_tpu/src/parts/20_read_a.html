1. Why JAX exists, and who uses it

PyTorch runs your Python line by line (eager execution): each operation goes to the device when Python reaches it, and autograd records a tape for loss.backward(). That is wonderful for debugging and costs two things at scale: Python is on the critical path of every operation, and no one ever sees the whole program, so no one can optimise across it or decide, for the whole step, how to split it over thousands of chips. JAX takes the opposite bet: record the function first, then transform it and compile it as a whole with XLA (Accelerated Linear Algebra, Google's compiler for array programs, which started inside TensorFlow). In its own words, "a Python library for accelerator-oriented array computation and program transformation" ({{JAX README|https://github.com/jax-ml/jax}}); an early version was described at SysML 2018 ({{Frostig, Johnson and Leary, "Compiling machine learning programs via high-level tracing"|https://mlsys.org/Conferences/doc/2018/146.pdf}}). The price is purity: parameters, optimiser state and random-number state stop hiding inside objects and become values you pass in and get back.

Who uses it. Google DeepMind trains Gemini with it: "We trained Gemini models using TPUv5e and TPUv4", where "the 'single controller' programming model of Jax and Pathways allows a single Python process to orchestrate the entire training run" ({{Gemini 1 report, section 3|https://arxiv.org/abs/2312.11805}}, vendor). Apple's foundation models "are pre-trained on v4 and v5p Cloud TPU clusters with the AXLearn framework", a JAX library: the server model on 8,192 TPUv4 chips and the on-device model on one slice of 2,048 TPUv5p chips ({{Apple AFM report, section 3.3|https://arxiv.org/abs/2407.21075}}). xAI released Grok-1 (314B parameters) with "JAX example code" ({{grok-1 repository|https://github.com/xai-org/grok-1}}). Outside the large labs PyTorch dominates: on the Hugging Face Hub, 255,916 models are tagged PyTorch and 12,404 JAX, about 21 to 1 measured 2026-10-15 from the Hub's library filter (a weak signal: the tag follows the weight files uploaded, and models trained in JAX are often uploaded as PyTorch weights).
