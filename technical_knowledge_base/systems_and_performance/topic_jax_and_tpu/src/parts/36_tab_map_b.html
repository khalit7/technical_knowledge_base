JAX API changes that break old tutorials

Inside JAX itself the multi-device API was rebuilt between 2024 and 2026: code written for pmap, pjit or xmap (most blog posts and many codebases on this map) now warns or fails. Read from the JAX changelog; the Sharding lab uses only the current APIs.

Interview questions

"Should a new JAX project use Flax Linen, Flax NNX, Equinox or Haiku?"

Flax NNX by default: it is what the Flax team points new users to, and MaxText and Tunix build on it; its stateful modules read like PyTorch. Equinox if you want models to be plain pytrees (common in scientific ML). Linen only to maintain existing code (it is not deprecated, but no longer the recommendation). Haiku is in maintenance mode by DeepMind's own notice since July 2023.

"A tutorial uses jax.pmap. What do you tell the team?"

pmap has been in maintenance mode since JAX 0.8.0 (October 2025) and since 0.10.0 it is a wrapper over jit(shard_map). Write new code with jax.jit plus NamedSharding (let the compiler place collectives) or jax.shard_map when you want per-device code; the migration guide has drop-in replacements.

"Our team is PyTorch-only. Can we use TPUs?"

Yes. TorchTPU (a native PyTorch device, torch.compile lowered to XLA) was announced in April 2026 and open-sourced on 20 October 2026; vLLM and SGLang TPU engines are built on it, and TorchTitan trains on it. It is new (one process per chip, about 450 ATen ops, collectives compiled one by one unless marked safe), so expect gaps a mature JAX stack does not have. The honest answer is "yes for serving and training through TorchTPU; port to JAX when you want the most mature TPU path".

"Which open codebase would you read to learn how LLMs are sharded on TPU pods?"

MaxText: it is Google's maintained reference, expresses every parallelism as a mesh axis, and has MLPerf-tagged configurations. Marin's Levanter is the best non-Google alternative (named tensors, reproducible). T5X, Pax and EasyLM teach the pjit era but are quiet and use deprecated APIs.

"How do you judge whether a library is alive?"

Look for the owner's notice first (README banners: Haiku, JetStream, XPK, Levanter), then the archived flag, then the date of the last release, and only then commits, reading what they are: T5X, Pax and jmp had commits in 2026 that were automated lint changes. A dependency with one maintainer (Equinox, EasyDeL) is alive but carries bus-factor risk.
