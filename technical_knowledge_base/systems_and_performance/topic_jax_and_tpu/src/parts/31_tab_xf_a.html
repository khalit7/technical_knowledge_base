The one idea
A JAX transformation (jit, grad, vmap) does not run your Python on numbers. It runs it once on tracers, stand-ins that carry only a shape and a dtype, records every elementary operation into a small typed program called a jaxpr, and then interprets that program: compile it (jit), differentiate it (grad), or batch it (vmap). Everything else in this lab, the purity rules, the recompiles, the errors, follows from that.

1. Tracing: the same function before and after

The problem it solves. PyTorch in eager mode runs each operation the moment Python reaches it, so the framework never sees your program as a whole and cannot optimise across operations (torch.compile exists to recover that view). JAX takes the opposite route: before doing anything, it captures the whole function as data.

How it works. When jax.jit(f) (or jax.make_jaxpr(f)) is called, JAX replaces each array argument by a tracer whose abstract value is a ShapedArray: shape and dtype, no numbers (printed f32[32,128,128]). Your Python then runs normally, but every jnp or lax call on a tracer is intercepted and appended to the jaxpr as one primitive (an elementary operation such as dot_general, add, exp) with its output's abstract value. Python itself (the variables, the helper functions, the for over q, k and v, the arithmetic on shapes) runs to completion and leaves no trace: only the array operations remain.

What to notice. Ten Python lines became equations, and the three projections, written once in a generator expression, appear three times. Shapes are fully known at every line, so a shape bug fails while tracing, before any compute. Python constants are folded in: / math.sqrt(dh) became div ... 5.656854152679443. jnp.tril and jnp.where appear as nested jit equations, because many jnp functions are themselves jitted functions with their own jaxpr inside. And jax.nn.softmax subtracts the row maximum under stop_gradient for numerical safety, so the max does not get differentiated.

Under grad alone the tracer still holds the real value (the primal), so Python can look at it; under jit it holds only the abstract value. That is why a Python if on an array works under grad but fails under jit (section 2). Python scalars get a weak type: jax.typeof(2.0) is , the tilde meaning "defer to the other operand's dtype", so bf16_array * 2.0 stays bfloat16.

PyTorch counterpart: torch.fx.symbolic_trace and TorchDynamo also capture graphs, but Dynamo reads Python bytecode and can fall back to eager at a graph break; JAX's tracer sees only array operations and has no fallback. Compiling the jaxpr is the {{Compiler lab|#t-xla}}'s subject.
