2. Static and dynamic values; Python control flow against lax

The rule. While tracing, a value is either static (known to Python now: shapes, dtypes, Python numbers, arguments marked static_argnums) or dynamic (a tracer: known only when the compiled program runs). Python may branch and loop on static values freely; the branch taken is simply baked into the program. It cannot branch on a dynamic value, because there is no value yet. The real errors, from this run:

@jax.jit
def f_if(x):
    if x.sum() > 0:       # needs a Python bool from a tracer
        return x
    return -x


@jax.jit
def f_int(x):
    return jnp.zeros(int(x.sum()))   # a shape that depends on data




The second error is the deeper rule: no array may have a shape that depends on data, because XLA compiles for fixed shapes. Variable-length work is padded to a fixed size and masked.
