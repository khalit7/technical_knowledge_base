2. Static and dynamic values; Python control flow against lax

The rule. While tracing, a value is either static (known to Python now: shapes, dtypes, Python numbers, arguments marked static_argnums) or dynamic (a tracer: known only when the compiled program runs). Python may branch and loop on static values freely; the branch taken is simply baked into the program. It cannot branch on a dynamic value, because there is no value yet. The real errors, from this run:

@jax.jit
def f_if(x):
    if x.sum() > 0:       # needs a Python bool from a tracer
        return x
    return -x


@jax.jit
def f_int(x):
    return jnp.zeros(int(x.sum()))   # a shape that depends on data




The second error is the deeper rule: no array may have a shape that depends on data, because XLA compiles for fixed shapes. Variable-length work is padded to a fixed size and masked.

3. jit: one trace per signature, and when it recompiles


How the cache works. jax.jit(f) returns a wrapper. On each call, a C++ fast path builds a key from the arguments and looks it up; on a miss, Python code traces f, lowers the jaxpr and asks XLA to compile it, then stores the executable. The key (read from the pinned source, section 10) is: the Python function object, the jit options, the signature (the pytree structure of the arguments and the values of static arguments) and the abstract value of every array leaf (shape, dtype, weak type, sharding). Nothing else. Not the numbers in the arrays, not the values of globals.

Rules that fall out


    

  • Pad to a few fixed shapes (buckets) instead of feeding ragged lengths; drop or pad the last batch.
    • 

  • Mark an argument static only when it changes the program (a flag, a layer count); never a value that changes every step.
    • 

  • Jit once, outside the loop. A new lambda per step compiles every step.
    • 

  • Anything that varies goes in as an argument; a global read inside a jitted function is frozen at trace time.
    • 

  • To watch a running job: jax.config.update("jax_explain_cache_misses", True) logs every miss with its reason; jax_log_compiles logs each compile.
