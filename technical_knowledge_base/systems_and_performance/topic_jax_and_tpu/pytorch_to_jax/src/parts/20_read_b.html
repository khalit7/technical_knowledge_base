One boolean tensor, three meanings

The cards take the same 4 x 4 lower-triangular boolean tensor (torch.ones(4, 4).tril().bool()) and colour the cells each API lets a query attend to. A green cell is "query row may look at key column".

Measured in pj_defaults.py: with this tensor, nn.MultiheadAttention's first row puts weight on the five positions (it attends only to the future), and with the inverted tensor (correct). jax.nn.dot_product_attention with the tril mask matches SDPA's causal output to .
Predict: you flip the mask convention in a JAX port, so each position attends only to positions after it, with -inf fill. What happens at step 0?
NaN, at step : the last position has no later position, its row is all -inf, and softmax of that is 0/0. With Flax's finfo.min fill instead there is no NaN: the row averages every value, the model learns to read the future, training loss falls to on validation with its own mask, and with the correct causal mask the same weights score . The NaN is the lucky outcome.
Fast variance: fine until the mean is large (chart)

Flax computes a LayerNorm's variance in one pass as E[x2] - E[x]2, which subtracts two large, nearly equal numbers when the mean is large against the spread. The bars are the largest error of the normalised output against PyTorch in float64, for N(0, 1) data shifted by a mean, in float32, log scale.

From pj_defaults.py. A residual stream with a mean of 1,000 and unit spread is unusual, but outlier features and un-normalised inputs (pixel values, raw sensor data) get there; use_fast_variance=False costs one more pass over the data.

Dropout: compare distributions, not values

Dropout masks come from each framework's own generator, so twins with dropout can never agree bit for bit: test the port with dropout off (as the running example is), then turn it on and compare statistics. Predict before reading the chart: a JAX port reuses one key for every step's dropout mask (PyTorch's generator advances by itself; a JAX key does not). Will the loss curve show it? The run adds dropout 0.1 to both residual branches and trains 300 steps: PyTorch, JAX with a fresh key per step (fold_in(key, step)), JAX with the same key every step, and the no-dropout anchor.

The reused key is invisible in the loss: check that the masks change between steps.
