You know PyTorch; you need a model in JAX. This page ports one, the running example of {{Topic: jax-and-tpu|n:3c65c17b0d0d81ecbc04eea6aa45ea1a}} (a 4-layer character transformer, parameters), and treats the port as an engineering problem with a test, not a translation exercise. The root's Training lab showed the port's panes and seven pitfalls; this page goes further: every default that differs, measured alone; weights converted both ways through a file; a test that tells a rounding difference from a bug; a real Hugging Face model (GPT-2) ported by hand; and the ways to avoid porting at all.

The whole method in five lines
1. Translate the code (modules become pure functions or NNX modules, the optimiser becomes an optax chain, the loop becomes one jitted step). 2. Set every default explicitly on both sides, because a dozen of them differ silently. 3. Copy the weights by a rule (rename, transpose [out, in] to [in, out]), never by hand. 4. Climb the ladder on one fixed batch: logits, loss, gradients, one optimiser step, then curves; stop at the first rung that fails. 5. Judge the drift: in float32 two correct ports separate slowly anyway; in float64 they should not.

1. The translation, line by line

The problem. A PyTorch training script mixes four things that JAX keeps apart: the model's arithmetic, its state (weights), the optimiser's state, and the random generator. JAX wants the arithmetic as a pure function (output depends only on inputs; no hidden state changes), so that jax.jit can trace it once into a program and jax.grad can differentiate it. Every row below is that one idea applied to one part of the script.

How it works. The table walks the ten parts of a training script. The middle column is Flax NNX (closest to PyTorch: objects with state), the right one plain JAX plus optax (state passed explicitly). Both are the root's real files, src/data/model_nnx.py and model_jax.py; the root's Training lab, section 3, shows them as linked panes ({{Topic: jax-and-tpu|n:3c65c17b0d0d81ecbc04eea6aa45ea1a}}, tab Training lab).

What it costs. The model itself translated almost mechanically (the three files are 116 to 148 lines each). The cost is not typing; it is that the result looks right and is subtly different. Section 2 is that list.

How to check. Run both twins on one batch from the same weights and compare logits before anything else; the root's twins agree to (largest logit ). Section 4 builds the whole test.
