1. MaxText's config is the program's input

One codebase trains a 0.6B Qwen on 8 chips and a 671B DeepSeek on thousands. PyTorch codebases carry the choices in argument parsers (Megatron's arguments.py, hundreds of flags) or TOML job files (torchtitan); MaxText reads a layered YAML into a validated object, and the model and train step read that object while they are traced, so every value is baked into the compiled program. pyconfig.initialize () builds it in this order, later layers winning:

  1. configs/base.yml: 1,669 lines, 828 top-level keys, every default with a comment.
  2. configs/models/<model_name>.yml (86 model files): shapes, activations, tokenizer, sometimes extra sharding rules.
  3. Command-line key=value pairs and Python keyword arguments.
  4. Environment variables named M_<KEY> ().

A pydantic class with 907 fields, MaxTextConfig (), then validates and derives what the code reads: emb_dim from base_emb_dim, global_batch_size_to_train_on from per_device_batch_size times the device count. Logical axis rules are merged by hand (): a model file's rule replaces every base rule with the same name. Degrees set to -1, such as ici_fsdp_parallelism, are resolved only when the mesh is built.

Each is a real call of pyconfig.initialize then maxtext_utils.get_mesh_from_config at main 1a95d1e5 on 8 simulated CPU devices (runs/lc_cfg.py, out/cfg.json), about 0.1 to 3 s each.

Predict: model_name=llama2-7b base_emb_dim=128. What does MaxText do?
It refuses. validate_no_keys_overridden_twice () raises ValueError: Keys ['base_emb_dim'] are overridden by both model config and CLI/kwargs with different values.This is not allowed, unless setting `override_model_config=True`. (the missing space is in the source). With override_model_config=True the command line wins and you get a 128-wide model with Llama 2 7B's 32 heads of 128: a shape no checkpoint will load into.

What it catches, and what it does not. A typo fails at start-up (remat_polcy=full raises ValueError: 'remat_polcy' not in 'emb_dim', 'mlp_dim', ... and lists every valid key); a valid key with a surprising default does not. Three to know before copying MaxText's numbers elsewhere: learning_rate: 3.e-5 (a fine-tuning value), adam_b2: 0.95 (optax and PyTorch default to 0.999), and adamw_mask: [], which decays every parameter including biases, norm scales and embeddings (section 4 measures what that costs). To check a run, diff resolved configs, not command lines: log_config (true by default, ) logs every resolved key, and cfg.get_keys() returns them. The {{Config explorer|#t-lccfg}} tab has 81 flags with line, default, comment and value per model file.
