You know how a PyTorch model meets a GPU: kernels, streams, tensor cores, NCCL. This page is the same knowledge for a JAX model on a TPU, taught from zero, with one question running through it: for a given model, batch and slice, what limits the step, and what can you change in your code to move that limit?

What is real on this page, and what is not
No TPU was used. Three kinds of evidence, labelled wherever they appear: published numbers from Google (the Cloud TPU pages, last updated 2026-10-13; the TPU table inside JAX's own source, jax/_src/tpu_info.py at jax-v0.11.2; MaxText's docs at commit 1a95d1e5) and from the {{scaling book|https://jax-ml.github.io/scaling-book/}} (Google DeepMind, chapters dated 2025-02-04, the TPU table edited since), all read 2026-10-15; measured here on an Apple M1 Pro CPU with jax 0.11.2 (the running example's residuals, FLOPs and memory under each rematerialisation policy; matmul precision emulated pass by pass on its trained weights; JAX's own device placement run on mock slices of every shape Cloud lists); and calculated (roofline arithmetic from published specs: what an operation would need at best on a TPU, never what it would get). The running example is the root page's tiny character-level transformer (826,368 parameters, 4 layers, width 128, batch 32 x 128 characters; {{Topic: jax-and-tpu, Reading tab|n:3c65c17b0d0d81ecbc04eea6aa45ea1a}}).
Who owns what. The silicon itself (systolic arrays cycle by cycle, optical switches, die photos) is on the Hardware topic's {{TPUs and other accelerators|n:3c65c17b0d0d8151bbc2e0ceea196187}}; general FLOP, memory and MFU arithmetic on {{Performance math|n:3c65c17b0d0d81faad1ef390b0e54d08}}; the root page's {{TPU and Pallas lab|n:3c65c17b0d0d81ecbc04eea6aa45ea1a}} draws one TensorCore, animates a matmul on a 128 and a 256 MXU and places the running example on the roofline; kernels are on {{Pallas kernels|n:3fa5c17b0d0d817699fcf65d085402e7}}; meshes, collectives and per-device memory on {{Sharding and scale|n:3c65c17b0d0d8125b084e6720cc66b3d}}; HLO layouts and the profiler on {{XLA and compilation|n:3fa5c17b0d0d8135adcedefac9e1bb48}}. This page links them and goes one level deeper on the TPU-specific part.
