67:### Causal attention
69:Due to causality only half of the (query, key) pairs need to be computed, those with query_idx >= key_idx. This accounts for the fact only prior tokens can be used to predict future ones. Prior to https://github.com/AI-Hypercomputer/maxtext/pull/1988 MaxText did not account for sparsity for theoretical flops, and used
71:Attention Flops ~= 4 * sequence^2 * batch * heads * head_dim
73:When accounting for causal masking, this should be halved
75:Attention Flops ~= 2 * sequence^2 * batch * heads * head_dim
77:Which maxtext now uses since this [PR/1988](link)
