Pallas kernels

JAX's kernel language from zero, for a PyTorch and CUDA reader: the programming model, eleven kernels written for the running example (elementwise, softmax, cross-entropy, layer norm forward and backward, flash attention forward and backward, two pipelines written by hand, paged decode attention by scalar prefetch), ten run and checked, all eleven lowered for TPU, the production kernels shipped with jax and tokamax run on the same tensors, and how block sizes are chosen. Child of Topic: jax-and-tpu. Run on an Apple M1 Pro CPU in interpret mode and lowered for TPU and GPU without one; chip speeds are Google's published figures, labelled. Data as of October 2026.
