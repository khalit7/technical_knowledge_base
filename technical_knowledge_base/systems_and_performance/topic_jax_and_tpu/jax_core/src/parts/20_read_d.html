The problem. While tracing, a Python if on a tracer has no value to test, and a Python for is unrolled into the jaxpr once per iteration (the root's {{Transforms lab|n:3c65c17b0d0d81ecbc04eea6aa45ea1a}}, section 2, shows both). 5. Autodiff from zero: JVP, VJP, linearize and transpose

The idea. Near a point x, a differentiable function f from n numbers to m numbers behaves like a linear map: its Jacobian J, an m x n matrix. Autodiff never builds J. It offers two ways to apply it:

Forward mode: JVP

jax.jvp(f, (x,), (v,)) returns f(x) and J v: push a direction v (a "tangent") from the inputs to the outputs, alongside the ordinary computation. One pass gives one column of information about J. PyTorch: torch.func.jvp; dual numbers.

Reverse mode: VJP

y, f_vjp = jax.vjp(f, x), then f_vjp(u) returns uT J: pull a weighting u of the outputs (a "cotangent") back to the inputs. For a scalar loss, u = 1 gives the gradient. PyTorch: loss.backward(), torch.func.vjp.

What each costs, and why training uses reverse mode

One JVP and one VJP each cost a small constant times one forward pass. A full Jacobian therefore costs n JVPs (one per input) or m VJPs (one per output): forward mode wins when there are few inputs, reverse mode when there are few outputs. measured here with XLA's own FLOP count (deterministic) for Jacobians of the running example's MLP restricted to k inputs and m outputs of one token:

How JAX does reverse mode: linearize, then transpose

Higher derivatives, Hessians and Hessian-vector products


Transformations compose, so second derivatives are just nesting. jax.hessian(f) is jacfwd(jacrev(f)): reverse mode for the gradient (many inputs, one output), then forward mode over it. Problem, cost, when it matters, how to check
Cost: a gradient is about 3 forward passes of FLOPs (measured 2.88) and holds the residuals; a full Jacobian is n JVPs or m VJPs. When it matters: memory at scale (residuals, remat), non-scalar objectives (choose the mode by the shape), second order (HVPs, never Hessians). How to check: jax.make_jaxpr(jax.grad(f)) shows forward and backward; jax.ad_checkpoint.print_saved_residuals(f, *args) lists what is kept and why; jax.jit(f).lower(*a).compile().cost_analysis() and .memory_analysis() give FLOPs and bytes; jax.test_util.check_grads compares against finite differences.
