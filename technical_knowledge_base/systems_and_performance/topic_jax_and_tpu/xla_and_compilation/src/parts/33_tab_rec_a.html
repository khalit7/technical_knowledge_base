Recompile detective

Eleven small cases. For each, read the code and predict whether the last call traces and compiles again; then see what JAX counted (through jax.monitoring: traces, lowerings and backend compilations) and what jax_explain_cache_misses printed. Run on JAX 0.11.2, CPU (src/lab/recompile_lab.py); inputs are NumPy arrays so that creating them compiles nothing. Counts and messages are deterministic. Why the cache works this way: {{Reading, sections 8 and 10|#t-read}}, where the recompilation storm is animated.
