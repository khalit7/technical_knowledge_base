12. Storage for training pods: volumes, claims and CSI

Checkpoints and datasets must outlive pods and be reachable from whichever node the restarted pod lands on. A pod mounts volumes. A PersistentVolumeClaim (PVC) asks for storage by size and access mode (ReadWriteOnce: one node; ReadWriteMany: many nodes; ReadOnlyMany); a StorageClass says which provisioner creates the PersistentVolume (PV) and when; a CSI driver (Container Storage Interface) is the plugin that attaches and mounts it on a node. For training the usual choices are a shared file system through CSI (Lustre, GPFS, Weka, NFS, Filestore, FSx: ReadWriteMany), object storage read by the job itself, and local NVMe for caches. kind's default StorageClass is rancher.io/local-path: a folder on one node's disk, with volumeBindingMode: WaitForFirstConsumer.

The claim stayed Pending (waiting for first consumer to be created before binding) until the writer pod was scheduled; the volume was then created on that pod's node and got a node affinity to it. A pod on any other node is unschedulable: 1 node(s) didn't match PersistentVolume's node affinity. If the checkpoint of a training job lives on such a volume, a restart after a node failure cannot run anywhere else; and if that node is gone, the checkpoint is gone too. Use node-local volumes for caches, not for state the job must resume from. Storage systems themselves are the {{Storage and data movement|n:3fc5c17b0d0d818a94ced3fc7c3331fe}} sibling's subject and the parent's {{Storage lab|n:3c65c17b0d0d81b5925bfd1d8665dd4b}} measures checkpoint writes on this cluster (the host folder these pods mount was 36 times slower than a Docker volume there).


Images are storage too: a pod on a fresh node first pulls the training image: Trainer's default torch runtime image, pytorch/pytorch:2.13.0-cuda13.0-cudnn9-runtime, is 3.04 GB compressed (Docker Hub API, read 2026-10-16), before any project code or data, which is why GPU clusters pre-pull images onto nodes, run a pull-through registry cache, or use lazy-loading snapshotters. The images here were preloaded with kind load.
