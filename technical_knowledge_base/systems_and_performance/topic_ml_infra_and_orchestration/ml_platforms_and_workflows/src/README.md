## The lab (`lab/`), what ran, 2026-10-16
Apple M1 Pro, macOS native, CPU, shared machine; own venv in scratch (`inputs/venv_freeze.txt`: mlflow 3.17.1, metaflow 2.19.39, torch 2.14.1, numpy 2.5.4).
- `train.py`: the topic's running example, byte-identical copy of the root's `src/data/train/train.py` (SHA-256 1ebb74e7...).
- `flow.py` + `common.py`: Metaflow flow start, train (torchrun 2 ranks gloo, static rendezvous on 127.0.0.1), evaluate (256 fixed windows of the held-out split), register (MLflow LoggedModel, registry version, gate on the `champion` alias), end. **Do not edit flow.py, common.py or train.py**: their SHA-256 is the `code_sha` the records and the page compare against (67873f121e99...).
- `env.sh`, `server_up.sh`: environment and a local MLflow server (sqlite + local artifacts, 127.0.0.1:5077).
- `run_sweep.sh`: runs r2 to r4. Order of the eight workflow runs: hung (`--standalone`, killed), r1 failed in register, r1 resumed, r2 lr 0.003, r3 lr 0.01, r4 lr 0.03, reproduction of the champion (`reproduce.py champion`), r6 lr 0.01 split 0.8.
- `reproduce.py`: resolve alias or version, check code/data/env, rerun, compare bits. `load_champion.py`: load by alias, score.
- `xplat.py`: compares the native run with the same command in `mi-train:1` (docker run --rm --memory 2g --cpus 2, name mp-xplat; command in `runs/xplat.json`).
- `export.py`: reads the server and Metaflow datastore into `runs/mp_lab.json` (scrubbed: ids, hashes, params, metrics, timings, sizes only).

## Records (`runs/`)
`mp_lab.json`, `xplat.json`, `rest_alias_champion.json`, `load_champion.json`, `wall_secs.json`, log excerpts (`run_r2.txt`, `resume.txt`, `register_fail.txt`, `hang_standalone.txt`), `errors.txt` (every real error message on the page).
