## 2. mlflow.pytorch.log_model(model, name="tiny-gpt", ...) without input_example
mlflow.exceptions.MlflowException: If `serialization_format` is set to 'pt2', then input_example is required. It must be a numpy array or torch tensor, or a tuple/list of numpy arrays or torch tensors. This is because 'pt2' is a traced-graph format: PyTorch traces the model graph by virtually executing model.forward with the provided example input.
