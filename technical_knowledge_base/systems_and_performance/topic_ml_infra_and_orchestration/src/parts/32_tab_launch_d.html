7. Hangs: what each broken launch really looks like

A multi-node launch rarely crashes. The processes that did start wait, politely, for the ones that did not, until some timeout fires. Which timeout fires first decides both how long you wait and what the error says, and they differ per layer: the agents' rendezvous (600 s with c10d, 900 s with static as torchrun starts it), the store client's connect (60 s with c10d), the process group (30 minutes by default; 120 s in the running example), Ray Train's worker-group start (60 s).
