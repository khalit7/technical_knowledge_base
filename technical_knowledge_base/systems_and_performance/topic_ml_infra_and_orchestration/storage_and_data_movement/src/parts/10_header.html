Storage and data movement: parallel file systems, object storage and checkpoint I/O

How the storage a training cluster shares actually works: a parallel file system's metadata servers and striped object servers, object storage's semantics and request limits, the caches and staging copies in between, moving datasets and checkpoints between them, sizing all of it for a cluster, and checkpoint formats seen as storage objects; with real runs on a toy parallel file system and on SeaweedFS.
