Message path

One message from rank 0 (GPU 0 of node A) to a peer, hop by hop through the hardware of section 1 and the fabric of section 4, on a rail-optimised fabric of 8-GPU H100 servers with one 400 Gb/s NIC per GPU. Choose two routes: both packets move at once, so the same send inside a node and across pods can be watched side by side. Every collective (all-reduce, all-to-all) is made of messages like these; how the algorithms combine them is on the {{interconnects page|n:3c65c17b0d0d81808563fd41fb163af0}} and its Collective simulator.

Latency of a small message from DeepSeek's measurements: NVLink 3.33 µs, InfiniBand 2.8 µs within a leaf, 3.7 µs across leaves ({{Zhao et al. 2025, Table 5|https://arxiv.org/html/2505.09343}}) authors; no published figure for the PXN and cross-pod routes, so none is shown. Time for 1 GB = latency + 1 GB / slowest hop. The same values as the interconnects page.
