## The 2026-10-24 rebuild: what changed and why

- **Top**: the core sentence ("each meter between the bill and the training log reads at most what the meter above it reads"), a new static hero (one GPU-hour read by seven meters, from allocation to kept model FLOPs, each rung labelled with who reports it and a published or measured reading), "You need" and a short list of new terms. - **Ownership**: goodput definitions and the badput split are linked to Fault tolerance at scale (which carries them); MFU arithmetic to Performance math; Prometheus basics to SWE Observability; serving cost per token to LLM serving in production.
- **Closed blocks**: the DCGM field table, the five-fleet table, the MFU run on one CPU core, published goodput numbers, the scrape configuration, what the running example logs, accounting commands, the counter definitions and four design questions.
