SCALE AND PERIOD
- "Fire-Flyer 2 with 10,000 PCIe A100 GPUs". NVLink here is the NVLink Bridge between pairs of PCIe GPUs.
- Table VI: "over the past year"; Table VII: Oct 2023 to Mar 2024 (six months); Table VIII: 2023/4/19 to 2024/3/31.

UNIT OF COUNTING
Table VI: GPU Xid error events (driver log messages), not job interruptions. Table VII: monthly counts of memory and
network failure events. Table VIII: IB link failure / flash-cut events per date.

KEY QUOTES
1. "Xid74, also known as NVLink errors, account for a significant proportion, comprising 42.57% of the total. This
   high frequency is due to the inherent fault rate of NVLink Bridge connectors".
2. "Notably, illegal memory access (Xid 43) accounts for 33.48% ... However, these errors may also result from
   memory data corruption, so hardware faults should be considered if software bugs are ruled out."
3. "we have encountered computational errors and GPU memory errors not detected by Error Correction Code (ECC),
   which led to models' gradnorm spikes, loss explosions and even non-convergence."
