SOURCE: Athlur, Saran, Sivathanu, Ramjee, Kwatra (Microsoft Research India). "Varuna: Scalable, Low-cost Training of Massive Deep Learning Models". EuroSys 2022. arXiv:2111.04007v2, 15 Nov 2021.
URL: https://arxiv.org/abs/2111.04007 ; code https://github.com/microsoft/varuna
LABEL: vendor (authors). Read 2026-10-16.

MECHANISM (my words): Pipeline + data parallel training on commodity-network spot (low-priority) VMs. A manager tracks heartbeats; when a VM is preempted (missed heartbeat) or capacity grows, Varuna "morphs" the job: a profile-driven simulator picks the best pipeline depth / data-parallel width for the GPUs now available, and the job resumes from the latest checkpoint in the new configuration. Checkpointing is continuous: every few mini-batches, per layer, sharded across data-parallel replicas, written to local SSD and copied to cloud storage in the background.

VERBATIM
- "low-priority VMs that cost about 5x cheaper than dedicated GPUs ... training massive models, including a 200 billion parameter model, on 5x cheaper "spot VMs", while maintaining high training throughput. Varuna improves end-to-end training time by up to 18x compared to other model-parallel approaches and up to 26% compared to other pipeline parallel approaches".
- "achieving 4-5x lower cost of training these models."
- Checkpointing: "Varuna constantly checkpoints the model state across all stages. Each layer is checkpointed independently ... we shard the checkpointing across replicas ... done at the end of a mini-batch, every few mini-batches. When the configuration changes, Varuna can resume the job from the latest checkpoint, with the new configuration ... checkpoints are written to local SSD of the VM, and copied to cloud storage in the background."
- Detection: "the manager also detects preemptions when it has not received a heartbeat from a VM, and triggers the morphing functionality to reconfigure the job."
- Simulator cost: "For a 128-GPU job that uses a batch size of 8192, the simulator takes 660ms for P=36, 376ms for P=24 and 391ms for P=18".
- GPT-2 2.5B over 60 hours on spot VMs: "training throughput (examples/s) varies from 50 to 250 (5x) while the per-GPU performance of Varuna varies by only 15% percent."
- Hardware: Azure NC24_v3 (4-GPU) / NC6_v3 (1-GPU) low-priority VMs (V100), compared with DGX-2 hyperclusters.

CAVEATS
- Recovery is still checkpoint restart (morph = restart in new shape); Oobleck reports Varuna hangs on GPT-3 6.7B under frequent preemption and pays checkpoint load time each morph.
