KINDS OF FAILURE RECORDED (verbatim from notes and logbook)
Hardware, GPU:
- "the only restarts we've had to make were all related to hardware issues (missing GPUs on instances, training
  randomly hanging after including a new node, ECC errors, partial checkpoint upload after hardware error, CUDA
  errors, NCCL errors, etc.)" (10% note).
- Logbook: "CRITICAL nvidia_smi | node-118: ecc high uncorrectables: DRAM Uncorrectable: 1335"; "Lost GPU on
  node-58"; "RuntimeError: CUDA error: unspecified launch failure"; "RuntimeError: CUDA error: unknown error";
  "CUBLAS_STATUS_EXECUTION_FAILED".
Network:
- "drained with reason Bad_infiniband"; "NCCL WARN NET/IB : Got completion with error 11"; "Found 3 hosts with bad
  NCCL"; "Why was node-55 added to the cluster in an unhealthy state (slow NCCL)?".
Node provisioning / cloud:
- "The vast majority of restarts have been due to hardware failures and the lack of ability to provision a
  sufficient number of 'buffer' nodes to replace a bad node with once it goes down with ECC errors. Replacement
  through the cloud interface can take hours for a single machine, and we started finding that more often than not
  we would end up getting the same bad machine again." (27% note)
- "5 hosts going down all together on Dec 6 (back when we only had a buffer of 4 hosts)" (56% note).
- "~2 machines go down every day" (final note).
- "Omicron Sev": "the cloud provider's support team accidentally deleted our entire cluster on December 21 ... it
  unfortunately came back with 16 machines that did not pass our infrastructure checks."
Storage / checkpoint:
- "issues with blob store when downloading 1.6TB of a single model checkpoint (992 files, each ~1.7GB) on restarts,
  at which point the downloads themselves would start hanging nondeterministically". CHECK: 992 x 1.7 GB = 1.69 TB.
  OK.
Hangs (cause often unknown):
- "it seems like the job genuinely hung in validation"; "There was some CUDA error around 1am that caused training
  to hang".
Numerical / training instability (not hardware; drove restarts in the 11.xx lineage and later):
- "grad norm explosions / loss explosions / nans after a couple hundred updates after each restart"; "Loss scale
  exploding"; LR lowered by 10%, later to 2/3 of GPT-3's.
Operator / tooling errors:
- "Due to user error, the wrong train.log file was specified, causing a false positive on the file not modified
  detector." ; "We reached the part about NCCL tests and silently failed on fixmycloud, and crashing monitor.py."

ARITHMETIC (mine)
- "40+ restarts" between Nov 17 and Dec 3 2021 (16 days) = 2.5+ restarts/day.
- "~2 machines go down every day" on 128 + buffer hosts (1024 GPUs / 8 = 128 hosts): about 1.6% of hosts per day,
  i.e. per-host MTBF of roughly 64 days. Rough.
- ~90 restarts over Nov 11 2021 to Jan 6 2022 (56 days) = about 1.6 restarts/day (one per ~15 h). This counts all
  restarts in the 12.xx lineage, hardware and numerical.
