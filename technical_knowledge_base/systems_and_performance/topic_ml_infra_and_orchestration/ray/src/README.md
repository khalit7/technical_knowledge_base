## The 2026-10-24 rebuild to the teaching contract
- **Top**: the core idea in one sentence, a new static hero (one call `y = f.remote(x)` through head, w1 and w2: lease, push, store, copy, with the owner's table highlighted; libraries above, Kubernetes or Slurm below), "You need", new terms, the measured cluster map. Provenance moved to a closed block.
- **Every mechanism has its visual inline.** The three lab tabs explained one mechanism each, so they moved into Reading: the life-of-a-task stepper into Ownership (it is where the owner's table changes), the node-loss replay into Failures (beside the fault table), the Ray Data block timeline into Ray Data, the Train failure replay into Ray Train. Their per-item tables (loss outcomes with messages, `ds.stats()` operators, storage listing, loss diffs) are closed blocks. New: a static placement-group figure (the root's measured placements, four strategies) and a Ray Serve figure (proxy, replicas, controller, defaults from source).
- **Ray Serve added** (this page owns it per the brief; it was missing): deployments, replicas as actors, controller, proxy, `max_ongoing_requests` 5, `target_ongoing_requests` 2, autoscaling delays, `@serve.batch` defaults, Ray Serve LLM; mechanisms of batching and routing link to the serving pages.
- **No autoplay**: template `21_js_rd_common.js`; mode switches no longer call `play()`; checked with normal motion (every scrubber at 0 after scrolling and toggling).
- **Deleted as fat**: problem wind-ups, the "four ideas" grid that each section restated, pointers to removed tabs, tab intros.
- **Images**: none. Ray is software and the mechanisms are drawn; no openly licensed figure or photo would teach more than the hero (the Ownership paper's figures are under USENIX terms, not an open licence).

Why 28 minutes is right: the page owns Ray Core (tasks, actors, objects, ownership, processes, scheduling, failures) and four libraries (Data, Train, Serve, Tune) plus KubeRay; the old Reading plus its labs was 36 core minutes without Serve. Every core unit in the ledger is a mechanism, a default with its source line or a measured result; the condensing came from wind-ups and from prose the visuals now carry, and the lab material now sits beside the claims it proves. The closed time grew because the labs' per-item tables and the Train code moved into closed blocks.
