Launching distributed training: torchrun, rendezvous, NCCL and hangs

What happens between "the scheduler gave me nodes" and "step 1 ran", taught from zero and run for real: the launchers (torchrun, srun, mpirun, DeepSpeed, Accelerate, Ray Train, JobSet and Kubeflow Trainer) and what each hands a process, torchrun's elastic agent and its rendezvous state machine, the store that every attempt shares, how gloo and NCCL build a communicator, every timeout on the way, how to find the one stuck rank, container networking, and a bring-up checklist for a new cluster. Every run used the topic's running example in Linux containers on one laptop (torch 2.14.1); NCCL is read from its source and documentation, because nothing here has a GPU.
