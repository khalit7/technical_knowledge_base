# Facts verified for this page (2026-10-16); also appended to scratchpad mi/FACTS.md under "ld"

Source lines: every one is in out/lines.json (file, line, URL at the pinned tag), located by pattern by scripts/ld_lines.py.

- torch 2.14.1's Linux wheel requires nvidia-nccl-cu13==2.30.7 (PyPI JSON requires_dist); NCCL quoted at v2.30.7-1 (commit 73cf112295c3).
- torchrun's launcher writes rdzv_configs timeout=900 (launcher/api.py 126-130); static reads "timeout" (static_tcp_rendezvous.py 122); dynamic reads "join_timeout" (dynamic_rendezvous.py 1385), default 600: so c10d gives up at 600 s, static at 900 s.
- Dynamic rendezvous ranks follow sorted node descriptors "<fqdn>_<pid>_<n>" (dynamic_rendezvous.py 833, 269), not arrival order.
- Rendezvous events are recorded but discarded by default ("dynamic_rendezvous": logging.NullHandler(), events/handlers.py 14); scripts/ld_torchrun.py swaps in a StreamHandler.
- Agent exit barrier 300 s (agent/server/api.py 465); --monitor-interval default 0.1 s (run.py 576); --max-restarts default 0 (run.py 564); torchrun reads PET_<FLAG> as each flag's default (argparse_util.py 45).
- Measured (c10d 2:3, store not shared): round 0 complete 30.1 s after the 2nd node; a late node joined (agents noticing to rendezvous done) in 2.3 s; after SIGKILL of a node: FAILED noticed in 1.0 s, dead node removed 13.0 s, world 2 again 43.3 s (Failure lab: 44.0 s).
- Measured (c10d 2:3, default shared store): growing the job deadlocked; all agents failed 61.5 s later on the 60 s store read timeout ("wait timeout after 60000ms, keys: /torch.rendezvous.ld-el.1/MASTER_ADDR"); cause in source: rank 0 skips republishing bootstrap info (dynamic_rendezvous.py 1209), the new node reads MASTER_ADDR (rendezvous/api.py 102).
- Measured (restart with shared store, 2 runs): attempt 1 found 3 keys in the workers' store including both gloo address keys of attempt 0; run 1: rank 1 "Connection refused", rank 0 "Connect timeout [none]" after 300 s (c10d Store default 300 s, Store.hpp 21; attribution not confirmed in gloo source); run 2: rank 0 refused, rank 1 lost the store.
