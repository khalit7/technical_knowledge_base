0. In one screen: adding what PyTorch does not ship

Sooner or later a training job needs something PyTorch does not have: a kernel you wrote (in C++, CUDA, Metal, Triton or Helion), a call into a library that is not PyTorch, a new number format for weights (int8, NF4, float8), a tensor that lives on several devices at once, or a tool that watches every operation. PyTorch has a hook for each. They differ in three ways that this page measures: what they can change, whether autograd, torch.compile and torch.export keep working, and what they cost.

The page follows the parent topic's running example, a 3,186,944-parameter character-level GPT ({{Topic: pytorch-ecosystem|n:3c65c17b0d0d8150aa65ca44b6ed2fd5}}, defined once in the root's src/model/), and changes two things in it. First, the GELU inside every block's MLP is replaced by your own kernel: a 50-line C++ GELU, then a Metal one, then a Helion one, each plugged in a different way. Second, the block weights are replaced by an int8 tensor subclass. Every result below comes from running those changes: graph counts, test results, errors, timings.

Three terms first. An operator is a named function the dispatcher knows (aten::addmm, or yours, ext::gelu), with a schema: a one-line type signature such as ext::gelu(Tensor x) -> Tensor. The dispatcher keeps, for each operator, a table of kernels (implementations) indexed by dispatch key (CPU, MPS, Autograd, Python, Meta and others) and, on every call, walks the keys that apply. The sibling page {{Tensors, the dispatcher and autograd|n:3f85c17b0d0d81138595c1c6cd52f795}} takes that machine apart; here we only plug things into it.

New computation
a custom operator

A kernel per device, plus three facts the compiler cannot guess: the output's shape (a fake), the gradient, and what is mutated.

New kernel language
C++, Metal, Triton, Helion

The kernel is written elsewhere; it plugs in as an operator's kernel at one device key.

New representation
a tensor subclass

Every operator on the tensor reaches your Python code: int8 weights, sharded tensors, float8.

Watch or transform everything
a dispatch mode

Active for a region of code; sees every ATen call: fake tensors, FLOP counting, logging.
