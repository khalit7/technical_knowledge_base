Read it this way
__torch_function__ receives what your code called (linear, gelu, layer_norm, attribute reads as __get__), and only that: autograd's engine runs backward in C++, so the backward shows one call, Tensor.backward. __torch_dispatch__ receives ATen operators after autograd has recorded its node, so linear appears as t + addmm, and the backward's own operators (mm, gelu_backward, native_layer_norm_backward) arrive too. Whether later operations reach the subclass depends on what it returns: rewrapped results spread the subclass to everything downstream (as DTensor does); plain results (as an int8 weight's matmul does) keep it to the weight. Reading section 5 explains each.
