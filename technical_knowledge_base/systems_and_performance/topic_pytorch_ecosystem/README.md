# Topic: pytorch-ecosystem

Notion: https://app.notion.com/p/3c65c17b0d0d8150aa65ca44b6ed2fd5

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`) and published to Notion as an HTML-only page. What happens inside PyTorch when you train a model, taught from zero: tensors and the dispatcher, autograd, torch.compile, distributed training with DTensor and FSDP2, performance tools, and the libraries built on top. Measured on an Apple M1 Pro and on CPU, with published GPU results kept apart. Data as of October 2026. Tabs: Reading, Inside one step, Compile lab, Distributed lab, Ecosystem map, Further reading. Child pages, each in its own folder: distributed_pytorch, extending_pytorch, libraries_on_top_of_pytorch, making_training_fast, tensors_dispatcher_and_autograd, torch_compile.
