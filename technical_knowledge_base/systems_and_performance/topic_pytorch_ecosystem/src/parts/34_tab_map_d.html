The small real runs behind this tab, on the CPU of an Apple M1 Pro with torch 2.14.1, each in src/map/checks/ with its output in src/map/inputs/checks/.

Not run here, and why
DeepSpeed, Megatron Core and NeMo were read from their released packages, not installed: DeepSpeed builds C++/CUDA operators, Megatron Core and NeMo expect NVIDIA GPUs and Transformer Engine. Unsloth, Liger Kernel, Helion, flash-attn and vLLM need a GPU backend (Triton or CUDA), so they are read from source only. torchtitan was read, not run: its training path targets GPUs and pulls tensorboard and wandb. Monarch's 73.6 MB wheel was not downloaded. Nothing on this tab is a speed measurement.
What transfers to NVIDIA GPUs and what does not
Transfers unchanged: which core class a library hands back (DDP is DDP on NCCL too), the call stacks, the identical losses under matched settings, the source counts, the parameter counts, the exported operator lists. Differs on GPUs: Accelerate does pick FSDP when you ask for it (its CPU branch ignores the plugin), torchao dispatches its tensor subclass to different kernels on a GPU than the CPU path measured here, so the logit difference will not be the same number, and ExecuTorch's XNNPACK backend is a CPU backend by design.
