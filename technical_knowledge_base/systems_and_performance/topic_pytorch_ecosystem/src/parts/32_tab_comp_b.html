3. Dynamo: one graph, and the guards that protect it

Dynamo is the front end. It hooks into CPython's frame evaluation (PEP 523), reads the bytecode of GPT.forward as it runs, follows every call into Block.forward, nn.Linear and so on, and records each tensor operation into an FX graph (PyTorch's Python-level graph format). Python control flow that does not depend on tensor values, such as the for blk in self.blocks loop, is simply unrolled: the graph has 4 copies of the block.

Guards. The graph is only valid for what Dynamo saw: these input dtypes and shapes, these parameter objects, grad mode on, 4 threads, no autocast. Dynamo wrote guards for this model; most check that a parameter is still a tensor of the same shape and has not been marked dynamic. They run in C++ before every call, which Dynamo timed at microseconds when it built them (once on CPU, once on MPS): small next to a 20 ms step, but this is the per-call price of a compiled region.

5. Recompiles and dynamic shapes


When a guard fails, Dynamo compiles again for the new situation and keeps both versions (up to torch._dynamo.config.recompile_limit,  at 2.14.1, after which that function runs eagerly). On a shape guard failure it does something smarter, automatic dynamic shapes (on by default): the second compile treats the dimension that changed as a symbol (s0) so any later size reuses it. torch._dynamo.mark_dynamic(t, dim) asks for the symbol from the first compile. 6. AOTAutograd: the backward graph, decided ahead of time


Dynamo captures only the forward. AOTAutograd runs PyTorch's autograd once on fake tensors (shapes and dtypes, no data) to trace the backward too, producing one joint graph, then a partitioner cuts it into a forward graph and a backward graph. The cut decides what the forward must save for backward: by default a min-cut algorithm that may recompute cheap values in backward instead of storing them (min_cut_rematerialization_partition, torch/_functorch/partitioners.py). Here the graphs were decomposed into ATen ops first, which is why they are longer than Dynamo's.
