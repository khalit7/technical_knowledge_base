Ecosystem map

PyTorch is the engine: tensors, the dispatcher, autograd, the compiler and the distributed APIs. Almost every training library you will meet is a wrapper around that engine: it writes the training loop, launches the processes or swaps in faster kernels for you, and then calls the same core functions you could call yourself. This tab is a dated atlas of those libraries as of 12 October 2026: what each one is, who owns it, whether it is alive, which core APIs it actually calls, and when to pick it. Go deeper: the child page {{Libraries on top of PyTorch: HF stack, torchtitan, Lightning, Axolotl, DeepSpeed|n:3c65c17b0d0d81019d98f99978dc26f6}} runs the same step through the HF Trainer, Accelerate, Lightning, DeepSpeed ZeRO 0 to 3 and torchtitan, and reads each one's defaults.

Where every number on this tab comes from
measured small real runs on an Apple M1 Pro, on the CPU, with torch 2.14.1 and the page's running example (the tiny GPT of 3,186,944 parameters); no timing, so nothing here depends on machine load. source read from each library's released package at the version shown (the wheel or source archive from PyPI, not the GitHub main branch), counted by a script (src/map/scan_source.py, scan_deps.py). docs versions and dates from PyPI, licences from PyPI and the repository's LICENSE file, statuses from the project's own README, issue or announcement, each linked. A status the project has not stated (a long silence) is labelled quiet and called an inference.
