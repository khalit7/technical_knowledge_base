Atlas

Every library around PyTorch that a training engineer is likely to meet, on one grid. The layer says where it sits: core is PyTorch itself; satellite is a PyTorch or Meta library that extends it (quantization, fault tolerance, orchestration); kernels are libraries of fast GPU code; HF is the Hugging Face stack; trainers write your training loop; scale frameworks bring their own parallelism engine; RL is post-training with generation in the loop; deploy runs a trained model elsewhere; data loads it. Click a card for owner, licence, latest release, status with its source, which core APIs its released source calls (with a real line), and when to choose it.

What the status words mean
  • active releases and development continue.
  • maintenance the project says it only fixes bugs and security issues, or part of it was retired.
  • paused the project says development has paused.
  • deprecated the project says it stopped development and points elsewhere.
  • archived the GitHub repository is read-only.
  • merged it moved into PyTorch itself.
  • quiet no statement from the project, but no release for a long time. An inference from release dates, not a fact about intent.

What calls what

"Built on FSDP2" or "uses DTensor" is easy to claim and hard to check. Here it is checked: for each library, its released Python source was searched for the names of PyTorch's core APIs (and for imports of the other libraries), and the count is the number of files that mention each one. Pick a library to see its lines into the core on the left and into other libraries on the right; thicker means more files. How to read a count, and its limits
A count is evidence of use, not of importance: one file that builds the whole model with fully_shard counts 1, and a docstring that mentions DTensor also counts 1 (the example line shows which you are looking at). Folders named tests, examples, benchmarks and docs are skipped. The scan reads Python only, so C++ and CUDA calls are invisible, and a library that receives core objects from its user (Lightning's ModelParallelStrategy, where you call fully_shard yourself) shows fewer hits than it enables. Patterns: src/map/scan_source.py; versions: the latest on PyPI on 2026-10-12, shown in the atlas.
