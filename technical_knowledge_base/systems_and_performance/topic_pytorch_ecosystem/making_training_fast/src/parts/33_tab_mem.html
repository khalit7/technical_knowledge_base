What this calculator leaves out

  • The CUDA caching allocator's overhead and fragmentation (reserved above allocated): see {{Memory allocators|n:3f05c17b0d0d81209ae9d856695dc958}}. Measure reserved memory on the real device (torch.cuda.memory_reserved()).
  • CUDA context and library workspaces (cuBLAS, cuDNN, NCCL buffers), which take memory before the first tensor.
  • Sharding across GPUs (FSDP2 divides parameters, gradients and optimizer state by the number of ranks): {{Distributed Training|n:3c65c17b0d0d8103a916c4824abbd82e}} owns that arithmetic.
  • Mixed precision: autocast keeps float32 parameters and adds bfloat16 copies of activations; this calculator counts float32 everywhere, as measured.
