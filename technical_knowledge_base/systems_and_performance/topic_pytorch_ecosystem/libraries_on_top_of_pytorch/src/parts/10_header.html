Libraries on top of PyTorch: HF stack, torchtitan, Lightning, Axolotl, DeepSpeed

Every training library runs the same loop you would write yourself, with its own defaults. This page runs the topic's running example through a plain loop, the Hugging Face Trainer, Accelerate, Lightning, DeepSpeed ZeRO and torchtitan on an Apple M1 Pro's CPU, shows which defaults change the loss and why, traces what each library calls in PyTorch, and says how to drop down a level. Data as of October 2026.
