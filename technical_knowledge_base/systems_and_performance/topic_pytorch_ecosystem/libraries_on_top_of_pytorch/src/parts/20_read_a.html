The idea in one screen

A training library adds no maths to PyTorch: it takes over duties of the loop you would write (data order, loss scaling, clipping, optimiser, precision, spreading over processes) and fills each with a default. Choosing a library is choosing which duties to hand over; moving between two is matching their defaults.

Higher layers take more of the loop from you; every column ends in the same PyTorch calls

Blue notes: a default that changes the loss if you port a plain loop without setting it. Each layer is built on the one below: TRL's trainers subclass the Trainer, which runs on Accelerate, which calls DDP or fully_shard; Axolotl ends in a Trainer or a TRL trainer. Models come from transformers (with PEFT adapters) or are your own nn.Module; torchtitan and Megatron bring their own.

You need the topic's running example and its map of these libraries ({{Topic: pytorch-ecosystem|n:3c65c17b0d0d8150aa65ca44b6ed2fd5}}, section 9 and the Ecosystem map tab). The parallelism forms ZeRO and FSDP are taught on {{Distributed Training|n:3c65c17b0d0d8103a916c4824abbd82e}}; the PyTorch APIs the libraries call (DDP, fully_shard, DeviceMesh, DTensor) on {{Distributed PyTorch|n:3c65c17b0d0d815e85aff8decd8f35ab}}; LoRA on {{PEFT|n:3c65c17b0d0d81eba08eef56b3e3b4eb}}; SFT, DPO and RL as methods on {{Alignment|n:3c65c17b0d0d81d5bed7e608d4061c7a}}.

Running example
The topic's 3,186,944-parameter character-level GPT (4 layers, d_model 256, batches of 8 windows of 64 characters), defined once in the root's src/model/; seeded, so every run starts from the same weights and sees the same batches.
Matched
A library run with every setting set equal to the plain loop's.
Probe loss
The mean loss on four fixed batches (10,000 to 10,003 of the same text), read every 10 steps: a yardstick that does not depend on data order.
Mean of means
Under gradient accumulation, each micro-batch's mean loss divided by the number of micro-batches and added up (section 3). Its rival is the token-weighted loss: summed token losses over the real-token count of the whole step.

Three results the rest of the page explains
  • Matched settings, identical losses. The HF Trainer, Accelerate and Lightning give the plain loop's 150-step curve to five decimals; DeepSpeed ZeRO 0 to 3 give DDP's losses on 2 processes measured on Apple M1 Pro, CPU.
  • Defaults move the curve. The Trainer's default clip at 1.0 was active on 145 of 150 steps; DeepSpeed turned its own clip on (1.0) in 0.19.3, July 2026, so the same script trains differently after an upgrade.
  • Loss averaging is a choice. On micro-batches of 124, 10, 90 and 13 real tokens the mean of means is 59% away from the full-batch gradient (Accelerate, Lightning, the Trainer with a model without **kwargs); the Trainer with a Hugging Face model and torchtitan divide by the token count and match.
