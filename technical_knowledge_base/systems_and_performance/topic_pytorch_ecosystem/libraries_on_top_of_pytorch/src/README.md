## Experiments (`exp/`), all deterministic (no timing, no bench lock)

The running example is imported from the root's `src/model/` (`exp/common.py` adds it to the path). Shared venv of the topic (torch 2.14.1, transformers 5.19.0, accelerate 1.15.0, lightning 2.6.6, peft 0.21.2, trl 1.15.0), Apple M1 Pro, CPU. `LIB_SCRATCH` points at a scratch folder for Trainer and Lightning output.

| Script | Output | What |
|---|---|---|
| `defaults_lab.py` | `inputs/defaults_lab.json` | 150 steps through a plain loop, the HF Trainer (matched, then one default at a time, then all), Lightning (default, clip), Accelerate: per-step loss, pre-clip gradient norm, learning rate, probe loss every 10 steps, optimizer objects |
| `accum_lab.py` | `inputs/accum_lab.json` | 8 rows with unequal real tokens: full batch vs mean of means vs token-weighted; the gradient each library computes under 4-step accumulation; 100-step probe curves |
| `hf_checks.py` | `inputs/hf_checks.json` | `attn_implementation` default and eager / sdpa / flex_attention on CPU and MPS, forward, backward and inference; `num_items_in_batch` arithmetic; decay-parameter names on the running example |
| `apitrace.py` | (module) | `sys.setprofile` tracer of calls from library code into torch, with the wrapped function's real name and first-seen order |
| `calls_trace.py single` | `inputs/calls_single.json` | Traces of plain, HF Trainer (matched and defaults), Accelerate, Lightning |
| `run_dist.sh` + `calls_trace.py <mode>` | `inputs/calls_<mode>.json` | 2 processes, gloo, ports 29561 to 29563: Accelerate DDP, HF Trainer DDP, Lightning DDP and FSDP2 (ModelParallelStrategy), DeepSpeed ZeRO 0 to 3 with and without the default clipping |
| `titan/ttrun.py`, `titan/libcfg.py`, `titan/run_titan.sh` | logs in scratch, `inputs/calls_titan_*.json` | torchtitan 0.3.0's own trainer on CPU with four patches (documented in `ttrun.py`), configs derived from `llama3_debugmodel`; ports 29564 to 29566 |
| `titan/summarize.py` | `inputs/titan.json` | Losses and grad norms parsed from the logs; the FlexAttention-vs-dense-mask check |
| `rerun_traces.sh` | all trace inputs | Re-runs every trace in order |

DeepSpeed 0.19.7 is used from an overlay folder (`pip install --target <dir> --no-deps deepspeed==0.19.7 hjson py-cpuinfo msgpack pydantic pydantic-core annotated-types typing-inspection einops`, with `DS_BUILD_OPS=0`) and `DS_ACCELERATOR=cpu`. torchtitan runs from a shallow clone of the v0.3.0 tag (it needs `tests/assets`) with tyro, torchdata, torch_checkpointing, spmd_types 0.2.3, einops and tensorboard in a second overlay folder (its pinned `datasets<4.8` is not installed; the shared venv's datasets 5.1.0 worked).

Rebuild: run the scripts with the shared venv's python, then `python3 build_data.py; sh build.sh; python3 check_data.py; node check_page.mjs ../index.html <shots dir>`.

## Sources read at pinned versions

transformers v5.19.0 (`trainer.py`, `training_args.py`, `modeling_utils.py`), accelerate v1.15.0 (`accelerator.py`, `state.py`, `utils/fsdp_utils.py`), Lightning 2.6.6 (`trainer/trainer.py`, `loops/optimization/automatic.py`, `loops/training_epoch_loop.py`, `strategies/*.py`), TRL v1.15.0 (`trainer/base_config.py`, `sft_config.py`, `dpo_config.py`, `grpo_config.py`): the installed wheels, checked byte for byte against the tagged GitHub files. DeepSpeed v0.19.7 (`runtime/constants.py`, `runtime/zero/config.py`, `accelerator/cpu_accelerator.py`) checked against the tag, plus `constants.py` at v0.14.0, v0.17.0, v0.18.0, v0.19.0 to v0.19.7 and the commit history to date the clipping change. torchtitan v0.3.0 tag clone. Axolotl 0.20.0, Unsloth 2026.10.3 and Megatron Core 0.19.2 from their released wheels (unpacked by the root's map agent). Web: the transformers v5 blog and v5.0.0 release notes, HF PR 34191 and issue 34242, DeepSpeed PR 8068 (GitHub API), PyPI versions and dates.
