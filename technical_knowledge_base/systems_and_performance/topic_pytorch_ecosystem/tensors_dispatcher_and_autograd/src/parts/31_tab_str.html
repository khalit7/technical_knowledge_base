Pick a tensor, then an expression. Every case below was evaluated by torch 2.14.1 (src/exp/tensors.py): shape, strides, offset, whether it shares the base's storage, and every value in index order. The bases are filled with arange, so each value is its own storage index: the recorded values confirm the address the formula gives for every element (and the script checks the first element against the real data pointer). Click any element to see its address computed; press play to walk the tensor in index order and watch where the reads land.

Read the strides, predict the layout
Contiguous means strides are the running products of the trailing sizes ((4, 1) for 3 × 4). A stride of 0 repeats data (expand); strides smaller than the next dimension's extent make windows overlap (unfold); a permutation of the contiguous strides is a transpose or permute. channels_last keeps the shape and puts the channel stride at 1.
