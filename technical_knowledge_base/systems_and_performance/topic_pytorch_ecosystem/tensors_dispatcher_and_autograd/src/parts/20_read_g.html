4. nn.Module, state_dict, and a training loop done right

4.1 What a Module registers

An nn.Module is a Python object whose attribute assignments are intercepted: assigning an nn.Parameter registers a parameter (a leaf tensor with requires_grad=True that optimizers will update), assigning a module registers a sub-module, and register_buffer registers a buffer (state that is saved but not trained, such as running statistics; persistent=False keeps it out of the state_dict). 4.3 Forward hooks

register_forward_pre_hook sees a module's inputs before forward, register_forward_hook its inputs and output after; both may replace them. They are the standard way to read activations without editing the model: one hook per block of the running example, one batch, collected the output standard deviation per block, measured, the residual stream growing block by block as expected at initialization. Backward hooks on modules are in 3.3.

4.4 The loop, line by line

model.train() opt = torch.optim.AdamW(groups, lr=6e-4, betas=(0.9, 0.95), weight_decay=0.1, fused=True) scaler = torch.amp.GradScaler("cuda", enabled=(amp_dtype == torch.float16)) # only float16 needs it for step in range(steps): for micro in range(accum): # gradient accumulation x, y = get_batch(cfg, step * accum + micro, device) # batch k is the same on every run with torch.autocast(device_type, dtype=amp_dtype): # bf16 or fp16 for chosen ops _, loss = model(x, y) scaler.scale(loss / accum).backward() # .grad adds up across micro-batches scaler.unscale_(opt) # clip the true gradient, not the scaled one total_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0) scaler.step(opt) # skipped if any gradient is inf or NaN scaler.update() opt.zero_grad(set_to_none=True) # free the gradients
