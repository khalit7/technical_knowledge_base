4. How DRAM is packaged: HBM, GDDR7, LPDDR

All the gigabytes on every GPU are DRAM cells like those in section 2. What differs is how many wires connect them to the processor and how fast each wire runs:

bandwidth (GB/s) = bus width (bits) × data rate per pin (Gb/s) / 8

So there are two ways to a lot of bandwidth: very many wires at a modest rate (HBM), or fewer wires at a very high rate (GDDR).

Same area, two shapes: HBM is wide and slow per pin, GDDR7 narrow and fast

HBM (high-bandwidth memory)Up to 16 DRAM dies stacked on a logic base die and wired vertically by through-silicon vias (TSVs, copper holes through each thinned die). Each stack has a 1,024-bit interface (2,048 bits from HBM4, about 3,000 wires with command and clock lines, per Rambus). Thousands of wires cannot run across a circuit board, so the stacks sit beside the GPU on a silicon interposer, a slab of silicon with very fine wiring ("2.5D" packaging). Short wires are why HBM moves a bit for a few picojoules.
GDDR7Packaged DRAM chips soldered around the GPU on the board, each with a narrow interface at a very high rate. GDDR7 signals with PAM3, three voltage levels per symbol instead of two, at 32 Gb/s per pin in Micron's parts ({{Micron GDDR7|https://www.micron.com/products/memory/graphics-memory/gddr7}}). The RTX 5090 runs a 512-bit bus at 28 Gb/s: 1,792 GB/s. Board wiring caps the bus width and so the capacity: 32 GB on the RTX 5090, 96 GB on the RTX PRO 6000.
LPDDR5 and LPDDR5XLow-power DRAM built for phones and laptops, in or beside the processor package and shared by CPU and GPU. Apple's M1 Pro: 200 GB/s and up to 32 GB. NVIDIA's Grace CPU uses LPDDR5X: a GB200 NVL72 rack holds 17 TB of it next to 13.4 TB of HBM3e, reachable by the GPUs over NVLink-C2C.

Per stack, bandwidth grew with the rate per pin, and HBM4 doubled the width: HBM3 819 GB/s, HBM3E 1,229 GB/s, HBM4 2,048 GB/s at the standard rates. An H100 SXM carries 5 HBM3 stacks for 3.35 TB/s; Rubin 12-high HBM4 stacks for 22 TB/s (announced).

Reading a spec sheet with the equation. H100 SXM: 5 stacks × 1,024 bits = 5,120 bits; 3.35 TB/s × 8 / 5,120 = 5.23 Gb/s per pin, below HBM3's 6.4 standard rate. MI300X: 8,192 bits at 5.3 TB/s = 5.18 Gb/s per pin derived. Rubin's 22 TB/s would need 10.7 HBM4 stacks at the standard 8 Gb/s; with fewer stacks the pins must run faster, consistent with SK hynix's HBM4 running "over 10Gbps" (section 8) derived. NVIDIA does not state Rubin's stack count or pin rate.

The trade. HBM needs stacked, thinned dies with TSVs, a known-good base die, an interposer and advanced packaging capacity; GDDR needs only a board. So datacenter GPUs carry HBM and consumer GPUs GDDR, and an RTX 5090 with 1.79 TB/s is a strong inference card for models that fit in 32 GB and a poor one for models that do not. Check: memory type, bus width and rate are on the datasheet; nvidia-smi -q shows the memory clock and size; the achieved bandwidth is what a stream benchmark reaches (the parent's Roofline lab does this for the M1 Pro).
