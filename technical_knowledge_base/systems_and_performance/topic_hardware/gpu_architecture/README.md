# GPU architecture: SMs, warps, tensor cores, Ampere to Blackwell and Rubin

Notion: https://app.notion.com/p/3c65c17b0d0d810682aae39bd614ec64 (child of Topic: hardware)

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). The NVIDIA GPU from the SM up, taught from zero around one running example (a 128 x 128 x 64 matmul tile): the SM and its quadrants, latency hiding and Little's law (animated scheduler), occupancy limits per compute capability, divergence, the memory ladder (Luo et al. latencies), five tensor-core generations with the same tile animated through mma.sync, wgmma and tcgen05, async copy, TMA, clusters and tensor memory, the whole chip and its dies, formats per generation, RTX 5090 against H100 and B200, and why each generation changed. Tabs: Reading, Chip floorplans (A100, H100, B200, B300, Rubin, RTX 5090 drawn from published counts, any two compared), M1 GPU lab (latency ladder, latency hiding and the occupancy cliff measured on an Apple M1 Pro GPU), Further reading. No NVIDIA GPU was available: NVIDIA numbers are vendor specs or independent microbenchmark papers, kept apart; compiler facts come from the CUDA topic's real compiles. Rebuilds the old written page "GPU architecture: Ampere to Blackwell" (verbatim in `src/live.md`, every fact accounted for in `src/coverage.json`); no child pages, databases or video.
