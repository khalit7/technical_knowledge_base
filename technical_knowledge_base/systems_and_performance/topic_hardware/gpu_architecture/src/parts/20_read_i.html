The pattern to remember
Math got cheaper faster than data movement in every generation. So each generation added hardware to move data (async copy, TMA, DSMEM, TMEM, bigger L2, faster HBM), and the fastest code overlaps moving with computing. A kernel written for the previous generation usually runs, but does not use what is new.

13. AMD's MI-series: the same machine, built from chiplets

The same idea, different names. AMD's Instinct GPUs are the same kind of machine: a compute unit (CU) is AMD's SM, its matrix cores are tensor cores, LDS (local data share) is shared memory, and a wavefront is the warp, but 64 threads wide on CDNA 3 and 4 (MI300X, MI355X), not 32. What differs is how the chip is built: past the reticle limit with many small dies instead of two big ones.

Two ways past one reticle: NVIDIA joins two big dies; AMD stacks eight small compute dies on base dies

Schematic drawn to counts, not area. B200: two reticle-sized dies joined at 10 TB/s (NV-HBI), eight HBM3e stacks. MI300X: 8 accelerator complex dies (XCDs, TSMC 5 nm, 40 CUs each with 38 enabled, "2 disabled for yield management") stacked on 4 I/O dies (TSMC 6 nm) that hold a 256 MB Infinity Cache (17.2 TB/s peak) and the controllers for 8 HBM3 stacks, two per I/O die. What it shows. AMD chose more, smaller units: an MI300X CU does half an H100 SM's BF16 work per clock and wins on count (304 against 132) and clock; MI355X doubled the per-CU rate to match an H100 SM per clock, grew LDS from 64 to 160 KB, added MXFP6 and MXFP4 at 16,384 FLOPs per CU per clock (about 10 PF dense), halved matrix FP64 and moved TF32 out of hardware ("supported through software emulation utilizing the BF16 datatype"). Chiplets yield better (a defect kills one small die) and let each part use the process that suits it. The cost is distance: each XCD's L2 is "coherent within an XCD", so data shared across the chip goes through the Infinity Cache, and an MI300X can be split into "up to eight partitions, one per XCD".

Porting kernels: 64-thread wavefronts
Code that assumes 32 lanes (a 32-bit lane mask, a 32-way shuffle reduction) silently computes the wrong thing or wastes half the machine on CDNA 3 and 4. AMD's MI400 page advertises "Wave32 execution" for CDNA 5 (MI455X), so the answer now depends on the generation.
MI455X, the next generation (vendor figures only)
