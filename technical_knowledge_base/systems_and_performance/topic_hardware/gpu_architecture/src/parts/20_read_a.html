1. The idea in one screen

A GPU is a hundred or more identical streaming multiprocessors (SMs) whose tensor cores do almost all of the arithmetic; everything else on the chip (thousands of resident threads, a huge register file, shared memory, copy engines, tensor memory) exists to keep those tensor cores fed, because in every generation math got cheaper faster than moving data.

One H100: 132 SMs share one L2 and five HBM stacks; our tile's numbers climb a ladder in which each rung is smaller and closer

Schematic drawn to counts, not to silicon area. Latencies are Luo et al.'s H800 measurements (Table IV, cycles) independent; sizes from {{Hopper in depth|https://developer.nvidia.com/blog/nvidia-hopper-architecture-in-depth/}} vendor spec. Sections 2 to 9 zoom into each part.

The running example. A training step is almost all matrix multiplies, cut into output tiles, one per SM at a time. We follow one: a 128 × 128 block of the output built from a 128 × 64 slice of one input and a 64 × 128 slice of the other, 1,048,576 multiply-adds (FMAs) derived: 128 × 128 × 64.

You need: a matrix multiply seen as tiles; the parent {{Topic: hardware|n:3c65c17b0d0d8118beeefaed56da6f8e}} (section 2) for the intuition. Programming these pieces is {{Topic: cuda-and-gpu-programming|n:3c65c17b0d0d81c39f34d5e070d783c1}}.

New terms on this page (16, a few words each)
SM
streaming multiprocessor, the repeated processor; 132 on an H100 SXM
Quadrant
one of an SM's four sub-partitions: a warp scheduler, a slice of registers, lanes, a tensor core
Warp
32 threads that issue one instruction together (AMD: a 64-thread wavefront)
Register file
256 KB per SM, the largest memory in it; every resident warp keeps its registers there
Shared memory / L1
one block of on-chip SRAM per SM, split per kernel between a program-managed scratchpad and a cache
L2, HBM
the chip-wide cache, and the stacked DRAM beside the die
Occupancy
resident warps over the maximum; the concept is on {{Programming model|n:3c65c17b0d0d8162865eec15d9dae87e}}, the per-generation limits here
Divergence
a warp's threads taking different branches, which then run one after the other
Tensor core
a fixed-function unit per quadrant that multiplies whole tiles in one instruction
TMA
Tensor Memory Accelerator, Hopper's per-SM copy engine for whole tiles
Cluster, DSMEM
up to 16 thread blocks on neighbouring SMs that can read each other's shared memory
TMEM
tensor memory, 256 KB per SM on Blackwell datacenter parts, holding tensor-core accumulators
GPC, TPC
groups of SMs (a TPC is two SMs; a GPC several TPCs)
Reticle
the largest area a lithography scanner exposes at once, which caps one die
Compute capability
the version number (8.0, 9.0, 10.0, 12.0) that decides which instructions a kernel may use
CU, XCD
AMD's compute unit (its SM) and accelerator complex die (a chiplet of CUs)
