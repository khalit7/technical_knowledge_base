Collective simulator

Pick a collective, an algorithm, a number of GPUs, a link and a buffer size. The simulator moves real chunks step by step (the same code as the Reading tab's animation, checked against a Python reference on 84 cases), charges every step one latency plus its largest per-GPU transfer over the link, and compares the algorithms. Model: each GPU has one full-duplex port into a non-blocking switch; nothing else is shared. It extends the parent page's {{Performance calculator|n:3c65c17b0d0d8118beeefaed56da6f8e}}, whose communication section uses the ring's bandwidth term only.
