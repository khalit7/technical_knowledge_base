The idea in one screen

Every message costs a fixed latency plus its bytes over the link's bandwidth, and the links form a ladder in which each rung reaches more chips and is roughly ten times slower than the one above, so each kind of parallelism belongs on the slowest rung whose bandwidth its traffic per FLOP can afford.

One cluster, five rungs: each reaches more GPUs and is slower than the one above

  1. 1HBM, inside each GPU: 3,350 GB/s on an H100.
  2. 2NVLink 4 through NVSwitch: 450 GB/s each way between any two of the server's 8 GPUs (72 in an NVL72 rack). Tensor and expert parallelism live here.
  3. 3PCIe 5.0 x16: 63 GB/s each way, joining each GPU to its network card (NIC) and the CPU.
  4. 4NIC to a rail leaf switch: 400 Gb/s, 50 GB/s each way. GPU k of every server meets on leaf k, one hop apart. Data and pipeline parallelism cross here.
  5. 5Leaf to spine: everything else, including most of an all-to-all; often oversubscribed (1:7 between Meta's pods).

Bandwidth per GPU, each direction, H100 generation unless named. HBM: 3.35 TB/s ({{H100 page|https://www.nvidia.com/en-us/data-center/h100/}}). NVLink 4: "900 GB/sec total" per H100 over 18 links ({{Hopper in depth|https://developer.nvidia.com/blog/nvidia-hopper-architecture-in-depth/}}), 450 each way; NVLink 5 on Blackwell 1.8 TB/s total ({{NVLink page|https://www.nvidia.com/en-us/data-center/nvlink/}}). PCIe 5.0 x16: 63 GB/s each way (32 GT/s per lane, 128b/130b encoding). One 400 Gb/s NIC per GPU: an AWS p5 server has 3,200 Gb/s for its 8 H100s ({{AWS P5|https://aws.amazon.com/ec2/instance-types/p5/}}). α, β
a link's latency per message and its bandwidth, one direction
n½
half-bandwidth size, α × β: below it latency dominates
NVLink domain
the GPUs joined by NVLink switches, which can load and store each other's memory
RDMA
the network card writes straight into remote (GPU) memory, no kernel, no copy
Rail, spine
leaf switch joining GPU k of every server; the layer above the leaves
Oversubscription
fewer uplinks than downlinks, written 1:7 or 7:1
Torus
a grid of chips whose rows and columns wrap around, each chip wired to its neighbours (TPU ICI)
busbw
nccl-tests' bandwidth rescaled to compare with a wire's rate
Link intensity
sustained FLOP/s over a link's bandwidth: FLOPs that must accompany each byte sent
