Every accelerator that is not an NVIDIA GPU is a bet on two choices the GPU keeps general: where the weights wait while the matrix units use them (HBM behind a scratchpad, SRAM spread over hundreds of chips, a whole uncut wafer) and how many chips share one fast fabric (8 to 9,216). Underneath most of them is one trick, the systolic array, which fetches each operand once per tile instead of once per multiply-add.

Memory per chip spans three orders of magnitude, and so does the size of the fast fabric

The running example. The root page, {{Topic: hardware|n:3c65c17b0d0d8118beeefaed56da6f8e}}, follows one Llama 3.1 8B training step down to NVIDIA GPUs; this page asks how the other machines run the same work. Its example is one matrix multiply from that step: the gate projection of one layer for one 8,192-token sequence, activations (8,192 × 4,096) times weights (4,096 × 14,336), 9.62 × 1011 FLOPs.

New terms on this page (11, a few words each)
Systolic array
a grid of multiply-add cells wired only to their neighbours; data is pumped through in rhythm
Weight-stationary
each cell holds one weight while inputs and partial sums flow past it
MXU
a TPU's matrix unit: one 128 × 128 (or 256 × 256) systolic array
TensorCore (TPU)
one of a TPU chip's one or two big cores: MXUs, a vector unit, a scratchpad
VMEM
the TPU's software-managed on-chip scratchpad
ICI
inter-chip interconnect: a TPU's own links straight to neighbouring chips
Torus
a grid whose rows and columns wrap around, so it has no edges
OCS
optical circuit switch: mirrors that decide which cube face is cabled to which
NeuronCore
one of a Trainium chip's 8 cores, built around a 128 × 128 systolic array
NKI
Neuron Kernel Interface, Trainium's Python kernel language
Wavefront
AMD's warp: 64 threads on CDNA 3 and 4
Predict before you read: the running example's weight matrix has 59 million numbers and the multiply performs 481 billion multiply-adds. If every multiply-add fetched its weight from memory, how many times would each weight be fetched?
8,192 times, once per token (and each activation 14,336 times, once per output column). Every design on this page is a different way to avoid most of those fetches; the systolic array's way is in section 1.
