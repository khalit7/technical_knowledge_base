Assistants and deep research: GAIA, Gaia2, BrowseComp

GAIA ({{Mialon et al., Meta and Hugging Face, Nov 2023|https://arxiv.org/abs/2311.12983}}) asks real-world questions that need web browsing, files, multimodal input and several steps, with one short unambiguous answer each, graded by quasi-exact match after normalisation by answer type. Of 466 questions, a 166-question development set is annotated and the answers to 300 are withheld for the leaderboard. People scored 92%, GPT-4 with plugins 15%. The {{leaderboard|https://gaia-benchmark-leaderboard.hf.space/}} now tops above the human figure, and the submission is answers, not a sandboxed run.

How GAIA was broken. It is a "submit your answers" leaderboard, and the validation answers are public on Hugging Face, so RDI's agent loaded them from a local file. Its normaliser strips all whitespace and punctuation and lowercases, so "D.R M.A.R.T.I.N L.U.T.H.E.R K.I.N.G J.R" matches "Dr. Martin Luther King Jr.". The leaderboard's 100% blocker is a check that every score equals 1, so missing one question per level gives about 98% while passing the filter. And the scorer penalises correct answers: a ground truth of "1,500" is split as a list ["1", "500"], so the correct "1500" is marked wrong.

Gaia2 ({{Meta ARE, Sep 2025|https://arxiv.org/abs/2509.17158}}) runs asynchronously in simulated apps: the environment changes while the agent works, and tasks add ambiguity, noise, collaboration with other agents and time limits. No system dominated, and budget-scaling curves plateaued.

BrowseComp ({{Wei et al., OpenAI, Apr 2025|https://arxiv.org/abs/2504.12516}}) has 1,266 questions whose short answers are hard to find and easy to check. Vendor figures now reach 91.5% (GPT-6 Astra, OpenAI, 2 Sep 2026) and 92.2% (GPT-5.6 Sol Ultra with four parallel agents, OpenAI), mixing single- and multi-agent setups; there is no independent board, and Anthropic left it out of its Opus 5.5 table.

GAIA's levels, and BrowseComp's construction and launch numbers

GAIA Level 1 needs at most one tool and five steps, Level 2 about five to ten steps and several tools, Level 3 arbitrarily long action sequences.

Each BrowseComp question was written so another person could not solve it within ten minutes and the models of the day could not either. At launch GPT-4o scored 0.6% (1.9% with browsing), o1 9.9% and OpenAI Deep Research 51.5%, a model trained on data meant to teach this kind of search; browsing also raised calibration error (confident wrong answers).

Customer service: τ-bench, τ²-bench, τ³ and Hyper-τ-bench

τ-bench ({{Yao et al., Sierra, Jun 2024|https://arxiv.org/abs/2406.12045}}) puts an agent between a simulated user (an LLM playing a customer with hidden instructions) and a domain's tool APIs, under a written policy it must obey. Success compares the database at the end with the annotated goal state, so many different conversations can pass. It introduced pass^k. τ²-bench ({{Barres et al., Jun 2025|https://arxiv.org/abs/2506.07982}}) adds a telecom domain with dual control: the user also has tools and acts on a shared device state, so the agent must guide a person through steps rather than do everything itself; agents dropped sharply from "no user" to dual control. That task passes only if the database does not change, which exposes the third caveat below. Three caveats travel with every τ number: part of what is measured is the user simulator, itself a model whose version changed (GPT-4.1 for older rows, GPT-5.2 now); agents misbehave in ways the database check can miss ({{HAL|https://arxiv.org/abs/2510.11977}}'s log inspection found agents misusing credit cards in flight-booking tasks); and there is a floor: under τ²-bench's own evaluator an agent that does nothing passes 23 of 50 airline tasks (those that need no database change), and GPT-5.2's pass^1 on the tasks that do need a change is 72.2% against 83.0% overall ({{Agent and trajectory evaluation|n:3ef5c17b0d0d81fdbabaf3582bff37f2}}, which re-grades 400 released trials).

The core leaderboard (version 1.0.1, four trials) is saturating: no 2026 frontier model has a core entry, and telecom is near the ceiling. The live frontier moved to τ³: a banking domain that needs knowledge retrieval over about 700 documents, and a voice track. Hyper-τ-bench ({{Sierra, 8 Sep 2026|https://sierra.ai/blog/hyper-t-bench-evaluating-agents-that-build-agents}}) points the same machinery at agents that build agents, scored by how the built customer-service agent handles held-out tasks: Claude Opus 5 (max) in Claude Code alone passed 23.9%; an engineer with deep context working with the same class of model reached 82.2%, 3.44 times as much. Who the agent works with moves the number as far as which harness it runs in.

τ-bench's domains, the task fixes, and how Hyper-τ-bench is built

Retail has 500 users, 50 products, 1,000 orders, 7 write and 8 read tools and 115 tasks; airline has 500 users, 300 flights, 2,000 reservations, 6 write and 7 read tools and 50 tasks. Sierra later fixed more than 50 airline and retail tasks, so legacy results are not directly comparable with current ones ({{taubench.com|https://taubench.com/}}). τ²-bench's tasks are generated compositionally from atomic parts, and its user simulator is constrained by tools and observable state.

In Hyper-τ-bench a developer agent recovers requirements from a simulated business's records (about 1,700 files for banking), builds a customer-service agent in a sandbox, and is scored on held-out tasks, with overspending the budget scoring zero. The 82.2% is a human-plus-model reference, not the same configuration. Attempted sandbox circumvention appeared in 17 to 42% of runs.

Tool use and MCP: BFCL, MCP-Universe, MCPMark, MCP-Bench, MCP Atlas

These test whether a model picks the right tool, fills its arguments and chains calls, first against mocked functions and then against real {{Model Context Protocol|n:3c65c17b0d0d813f9695dc4175c44cbb}} servers. The area is fragmented: the two research boards stopped updating in late 2025 and vendors now quote MCP Atlas, whose claim-coverage grading uses a judge model.
