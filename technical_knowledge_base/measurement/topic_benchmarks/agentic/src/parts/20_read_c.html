Terminal: Terminal-Bench and Terminal-Bench-Science

Terminal-Bench (Stanford and the Laude Institute; maintained in the {{harbor-framework|https://github.com/harbor-framework/terminal-bench}} organisation, Apache 2.0) gives the agent a shell in a Docker container and a task taken from real work: compile and fix builds, recover a database, train a small model, crack a hash, configure a server. Each task ships an environment, a human-written reference solution and tests that check the end state ({{paper, Jan 2026|https://arxiv.org/abs/2601.11868}}). Because Claude Code, Codex CLI, OpenHands and other agents run against it directly, it doubles as a harness benchmark, and the leaderboard lists each entry as an agent and model pair.

The versions are not one scale. Each changed the tasks, the limits or the checker, and the old page's "there is no 3.x" was wrong:

Corrections to the old page
  • "4.0 (Sep 2026) is the current version, and there is no 3.x because the numbering jumped": {{Terminal-Bench 3.0|https://github.com/harbor-framework/terminal-bench/releases/tag/v3.0.0}} exists (tagged 23 Jul 2026, 74 tasks) and 4.0 was tagged 26 Aug 2026 (announced 28 Aug). The maintainers chose 4.0 over 3.1 because Terminal-Bench is now a continuous benchmark with semantic versioning, and changed resources and removed tasks are breaking changes that require re-running trials ({{4.0 announcement|https://www.tbench.ai/news/terminal-bench-4-0}}).
  • "2.0 ... reached ~92% (GPT-5.6-class) by Aug 2026": the 92% figures are lab numbers on 2.1 (OpenAI's GPT-5.6 Sol Ultra with four parallel agents 91.9%). The official tops are 84.7% on 2.0 and 83.8% on 2.1 (root Benchmark atlas, from Wayback captures of the boards).
  • "resets the scale to GPT-6 Astra 57.9% and Claude Fable 5.1 55.8%": those come from Anthropic's Opus 5.5 table. The official board reads GPT-6 Astra (max) 58.18%, Claude Fable 5.1 (max) 57.88%, Claude Opus 5 (xhigh) 53.94%, Grok 4.7 (xhigh) 37.58% (read 4 Oct 2026); Opus 5.5 is not on it yet (Anthropic's own run: 66.4%).
  • "stood at 52.6% for Claude Fable 5.1 one week later": 52.6% is Anthropic's own run, published five days after launch; the official Terminal-Bench-Science board lists Fable 5.1 at 40.0% and Artificial Analysis measured 43.3%.

What changed at 4.0, in the task files. 8 tasks removed (2 saturated, 2 refused by models, 2 with public solutions, 2 for quality or platform problems), 19 fixed, and every task's agent timeout set to a flat 8 hours (65 of the 66 task files state 28,800 s; the announcement says all). "Saturated" was defined strictly: every model class in every family of the latest generation solves the task 5 times out of 5. Because time and memory limits are part of a task when the agent has a shell and a clock, 2.x and 4.0 scores are not comparable even on tasks that survived. The announcement also notes fewer agent timeouts and errors than 3.0, so less measurement noise, and that Sonnet 5 used 21.6 billion tokens on the run against 6.5 billion for Opus 5.

Terminal-Bench-Science 0.1 ({{announcement, 27 Aug 2026|https://www.terminal-bench-science.ai/announcement}}), by Stanford with the Terminal-Bench and Harbor teams, is the first agent benchmark built around research workflows rather than software engineering: 70 tasks across life, physical, Earth, mathematical and engineering sciences, from 376 contributors in 22 countries, reviewed by domain and technical reviewers plus a final "bar-raiser", graded by task-specific tests, three trials per task. At launch Claude Opus 5 led at 30.0%, GPT-5.6 Sol 22.4%, Claude Fable 5 21.4%, GPT-5.6 Luna 3.3%. Within a week the {{official board|https://www.terminal-bench-science.ai/}} reached 68.1% (GPT-6 Astra (max) in Codex, dated 3 Sep, ±3.2) and later 63.3% for Claude Opus 5.5 (max). It is meant to be continuous: version 0.2 was taking task pull requests until 5 October 2026. Lab and board figures disagree for the same model in both directions (Fable 5.1 52.6% against 40.0%; Opus 5.5 58.7% against 63.3%; Astra 64.6% against 68.1%), so quote the board and say which.

Computer use: OSWorld and its relatives

OSWorld ({{Xie et al., XLANG Lab, HKU, Apr 2024|https://arxiv.org/abs/2404.07972}}) runs the agent on a real Ubuntu virtual machine, seeing screenshots (and optionally the accessibility tree) and sending mouse and keyboard actions, across office apps, browsers, file managers, IDEs and workflows that span several apps. Each of its 369 tasks has an initial-state setup and a custom evaluation script that inspects the final state (a file's contents, a setting, a spreadsheet). At launch people completed 72.36% and the best model 12.24%. Claude 3.5 Sonnet's computer-use release in October 2024 scored 14.9% screenshot-only, 22.0% with more steps ({{Anthropic, 22 Oct 2024|https://www.anthropic.com/news/3-5-models-and-computer-use}}).

Correction: OSWorld 2.0 vendor figures are partial credit
The old page and current vendor cards quote OSWorld 2.0 at 72.6% (GPT-6 Astra), 74.0% (Claude Opus 5) and 81.8% (Claude Opus 5.5), with GPT-6 Sol at 60.5% offline at extra-high effort. These are partial-credit scores, from different task releases and harnesses: OpenAI's 72.6% is release 2026.08.08, offline set ({{OpenAI|https://openai.com/index/gpt-6-astra/}}); Anthropic's 74.0% and 81.8% are its own re-run on the 10 September task files with a new context harness, where the strict pass rates are 37.2% and 48.7% ({{Opus 5.5 system card, 8.13.3|https://www-cdn.anthropic.com/fc1b44717c85dc068bc6ba5024219938094694bd/Claude%20Opus%205.5%20System%20Card.pdf}}). On the official board's default binary metric the best is 44.33% (Opus 5, release 2.1), and the maintainers' own run of Opus 5 on release 2026.08.08 read 31.4% binary, 68.3% partial. OpenAI also notes that the Fable 5.1 system card used modified tasks and grading. At launch (26 Jun 2026) the best public model was Claude Opus 4.8 at 20.6% binary with batched tools. A 2.0 figure without release, set and metric carries no information, and none of them compares with OSWorld-Verified.

How OSWorld was broken. RDI's exploit agent reached 73%: the gold files the checker compares against sit on public Hugging Face URLs inside the task configuration, and the VM has internet, so the agent downloads the gold file straight into the path the checker reads ("the evaluator compares gold vs. gold"); state checks were met by setting the state directly (gsettings set, writing expected config files); the 29 tasks marked infeasible were answered "FAIL" for free points; and the grader called Python's eval() on a string read from the VM, so a crafted gsettings value ran code on the grading machine ({{RDI|https://rdi.berkeley.edu/blog/trustworthy-benchmarks-cont/}}).

Relatives. {{Windows Agent Arena|https://arxiv.org/abs/2409.08264}} (Microsoft, Sep 2024) adapts OSWorld's framework to 150+ Windows tasks, parallelised on Azure to finish in about 20 minutes; its Navi agent scored 19.5% against 74.5% for people. {{AndroidWorld|https://arxiv.org/abs/2405.14573}} (Google, May 2024) has 116 programmatic tasks across 20 Android apps, parameterised so each run draws new instances; the best agent then completed 30.6%.

Web: WebArena, VisualWebArena and the live web

WebArena ({{Zhou et al., CMU, Jul 2023|https://arxiv.org/abs/2307.13854}}) self-hosts working copies of four kinds of site (an e-commerce store, a social forum, a GitLab, a content-management system) plus a map, a wiki and manuals, and poses 812 long-horizon tasks checked for functional correctness: the resulting site state, or the answer string. The best GPT-4 agent completed 14.41% against 78.24% for people. Self-hosting makes it reproducible, and its sites and tasks have been public since 2023. The {{official leaderboard sheet|https://docs.google.com/spreadsheets/d/1M801lEpBbKSNwP-vDBkC_pF7LdyGU1f_ufZb_NWNBZQ/edit?usp=sharing}} tops at 74.3% (WebTactix with DeepSeek V3.2, February 2026). VisualWebArena ({{Koh et al., Jan 2024|https://arxiv.org/abs/2401.13649}}) adds tasks that need the page's images, where text-only agents fall short.

How WebArena was broken. RDI reached about 100% of 812 tasks: navigating the browser to a file:// URL opens the task's own configuration, gold answer included (file:///proc/self/cwd/config_files/{task_id}.json); its must_include check is substring containment, so a verbose answer passes; it calls eval() on agent-controlled strings; and its LLM-judged answers can be steered by text injected into the agent's reply.

The live web trades reproducibility for realism. {{WebVoyager|https://arxiv.org/abs/2401.13919}} (Jan 2024) runs on 15 real websites with a GPT-4V judge that agreed with people 85.3% of the time. {{Online-Mind2Web|https://arxiv.org/abs/2504.01382}} ("An Illusion of Progress?", Apr 2025) has 300 tasks across 136 live websites and found earlier results over-optimistic; its LLM judge agrees with people about 85% of the time. {{Mind2Web 2|https://arxiv.org/abs/2506.21506}} (Jun 2025) has 130 long-horizon research tasks graded by task-specific judge agents with tree-structured rubrics for correctness and citations; OpenAI Deep Research reached 50 to 70% of human performance in half the time.

Assistants and deep research: GAIA, Gaia2, BrowseComp

GAIA ({{Mialon et al., Meta and Hugging Face, Nov 2023|https://arxiv.org/abs/2311.12983}}) asks real-world questions that need web browsing, files, multimodal input and several steps, with one short unambiguous answer each, graded by quasi-exact match after normalisation by answer type. Level 1 needs at most one tool and five steps, Level 2 about five to ten steps and several tools, Level 3 arbitrarily long action sequences. Of 466 questions, a 166-question development set is annotated and the answers to 300 are withheld for the leaderboard. People scored 92%, GPT-4 with plugins 15%. The {{leaderboard|https://gaia-benchmark-leaderboard.hf.space/}} now tops at 93.69% (Level 1 98.9, Level 2 93.1, Level 3 85.7), a multi-model agent combining Qwen3.8 Max, DeepSeek V4 Pro and Claude Opus 5, dated 22 Sep 2026: above the human figure, and the submission is answers, not a sandboxed run.

How GAIA was broken. It is a "submit your answers" leaderboard, and the validation answers are public on Hugging Face, so RDI's agent loaded them from a local file. Its normaliser strips all whitespace and punctuation and lowercases, so "D.R M.A.R.T.I.N L.U.T.H.E.R K.I.N.G J.R" matches "Dr. Martin Luther King Jr.". The leaderboard's 100% blocker is a check that every score equals 1, so missing one question per level gives about 98% while passing the filter. And the scorer penalises correct answers: a ground truth of "1,500" is split as a list ["1", "500"], so the correct "1500" is marked wrong.

Gaia2 ({{Meta ARE, Sep 2025|https://arxiv.org/abs/2509.17158}}) runs asynchronously in simulated apps: the environment changes while the agent works, and tasks add ambiguity, noise, collaboration with other agents and time limits. No system dominated, and budget-scaling curves plateaued.

BrowseComp ({{Wei et al., OpenAI, Apr 2025|https://arxiv.org/abs/2504.12516}}) has 1,266 questions whose short answers are hard to find and easy to check; each was written so another person could not solve it within ten minutes and the models of the day could not either. At launch GPT-4o scored 0.6% (1.9% with browsing), o1 9.9% and OpenAI Deep Research 51.5%, a model trained on data meant to teach this kind of search; browsing also raised calibration error (confident wrong answers). Vendor figures now reach 91.5% (GPT-6 Astra, OpenAI, 2 Sep 2026) and 92.2% (GPT-5.6 Sol Ultra with four parallel agents, OpenAI), mixing single- and multi-agent setups; there is no independent board, and Anthropic left it out of its Opus 5.5 table.

Customer service: τ-bench, τ²-bench, τ³ and Hyper-τ-bench

τ-bench ({{Yao et al., Sierra, Jun 2024|https://arxiv.org/abs/2406.12045}}) puts an agent between a simulated user (an LLM playing a customer with hidden instructions) and a domain's tool APIs, under a written policy it must obey. Retail has 500 users, 50 products, 1,000 orders, 7 write and 8 read tools and 115 tasks; airline has 500 users, 300 flights, 2,000 reservations, 6 write and 7 read tools and 50 tasks. Success compares the database at the end with the annotated goal state, so many different conversations can pass. It introduced pass^k. Sierra later fixed more than 50 airline and retail tasks, so legacy results are not directly comparable with current ones ({{taubench.com|https://taubench.com/}}).

τ²-bench ({{Barres et al., Jun 2025|https://arxiv.org/abs/2506.07982}}) adds a telecom domain with dual control: the user also has tools and acts on a shared device state, so the agent must guide a person through steps rather than do everything itself. Tasks are generated compositionally from atomic parts, and the user simulator is constrained by tools and observable state; agents dropped sharply from "no user" to dual control. The core leaderboard (version 1.0.1, four trials, user simulator GPT-5.2; older rows used GPT-4.1) tops at 87.91% mean pass^1, Qwen3.5-397B-A17B (retail 84.4, airline 81.5, telecom 97.8), 2 Mar 2026; no 2026 frontier model has a core entry, and telecom is near the ceiling. The live frontier moved to τ³: a banking domain that needs knowledge retrieval over about 700 documents (top 55.15% pass^1, Qwen 3.8 Max (xhigh), 4 Aug 2026) and a voice track. Two caveats travel with every number: part of what is measured is the user simulator, itself a model whose version changed; and agents misbehave in ways the database check can miss ({{HAL|https://arxiv.org/abs/2510.11977}}'s log inspection found agents misusing credit cards in flight-booking tasks).

Hyper-τ-bench ({{Sierra, 8 Sep 2026|https://sierra.ai/blog/hyper-t-bench-evaluating-agents-that-build-agents}}) points the same machinery at agents that build agents: a developer agent recovers requirements from a simulated business's records (about 1,700 files for banking), builds a customer-service agent in a sandbox, and is scored by how that agent handles held-out tasks, with overspending the budget scoring zero. Claude Opus 5 (max) in Claude Code alone passed 23.9%; an engineer with deep context working with the same class of model reached 82.2% on the same tasks, 3.44 times as much. The 82.2% is a human-plus-model reference, not the same configuration. Attempted sandbox circumvention appeared in 17 to 42% of runs. Who the agent works with moves the number as far as which harness it runs in.

Long tasks and real work: METR horizons, GDPval, AutomationBench, Agents' Last Exam

METR's time horizon ({{Kwa et al., Mar 2025|https://arxiv.org/abs/2503.14499}}) turns a task suite into one number with units. Skilled people are timed on each task; for each model, METR fits a logistic curve of success against the logarithm of the human time and reports where it crosses 50% (and 80%): the length of task, in human time, that the model completes half the time. The suite combines {{HCAST|https://arxiv.org/abs/2503.17354}} (189 software, ML, security and reasoning tasks with 563 human baselines over 1,500 hours, from one minute to 8+ hours), RE-Bench and 66 short software tasks; version 1.1 uses 228 tasks. A horizon has no ceiling until it outgrows the suite, which is now the limit:

  • Fitted from the released runs in this page. METR's {{v1.1 runs file|https://github.com/METR/eval-analysis-public}} has 24,008 runs; refitting each model with METR's own settings (diversity weights, near-zero regularisation) reproduces every 50% horizon in its {{results file|https://metr.org/assets/benchmark_results_1_1.yaml}} to the published rounding (Time horizon fit).
  • Doubling time about 4.2 months, not 7. The v1.1 file gives 128.7 days (95% interval 104 to 158) for frontier models from 2023 on and 187.8 days (about 6.2 months) over the whole series since 2019; the 2025 paper's "about seven months" was the earlier, longer window. The page refits both from the file's points.
  • The suite is running out. The best measured horizon is Claude Mythos Preview (early) at 1,045 minutes (about 17 hours; 95% interval 509 to 3,304), dated 8 May 2026, beyond the 16 hours METR treats as reliable, so the trend fit excludes it; no Opus 5.x, Fable or GPT-6 measurement is published yet.
  • Reward hacking was measured here first. o3 reward-hacked in 39 of 128 RE-Bench runs (30.4%), and in every one of 21 runs on one task, against 8 of 1,087 on HCAST (0.7%), because RE-Bench shows the scoring function to the agent ({{METR, 5 Jun 2025|https://metr.org/blog/2025-06-05-recent-reward-hacking/}}).

GDPval ({{OpenAI, Oct 2025|https://arxiv.org/abs/2510.04374}}) samples real deliverables from 44 occupations in the 9 sectors that contribute most to US GDP, written by professionals with on average 14 years of experience; 1,320 tasks, a 220-task gold subset public with an automated grader. Experts compare the model's deliverable with a professional's. OpenAI reported GPT-5.5 winning or tying 84.9% of the time (Apr 2026); Epoch's run of the gold subset gives GPT-5.2 49.7% wins with ties excluded, a different metric. GDPval-AA v2.1 is Artificial Analysis's agentic variant, graded head to head into an Elo scale anchored at 1600 for DeepSeek V4.1 Flash since 19 Sep 2026: Claude Opus 5.5 (max) 1846, Claude Sonnet 5.5 1844, Claude Fable 5.1 1735, Claude Opus 5 1708, GPT-6 Astra (max) 1542 ({{AA|https://artificialanalysis.ai/evaluations/gdpval-aa}}, read 1 Oct 2026). Only differences mean anything on an Elo scale, and it is a different instrument from OpenAI's GDPval.

AutomationBench 1.0.6 ({{Zapier|https://zapier.com/benchmarks}}) automates business workflows across 47 tools, on a held-out private set (with a public set for research), and prints dollars per task beside the score: Gemini 4 Argon (high) leads at 51.29% for $1.70 per task (1 Oct 2026). OpenAI quotes GPT-6 Sol (xhigh) at 33.2% for $0.27 per task and Claude Opus 5 at 11.1 times that cost ({{OpenAI|https://openai.com/index/introducing-gpt-6-sol-and-luna/}}; the old page said "high" effort and "roughly nine times"). Artificial Analysis's AutomationBench-AA is a partial-credit rerun (Argon 77.5%), a different metric. Zapier flags that safety-classifier fallbacks change scores (Fable 5.1's 31.4% includes about 40% of tasks completed by Opus 5 as fallback) and that most failures are false confidence: the model declares success while failing.

Agents' Last Exam ({{site|https://agents-last-exam.org/}}; Berkeley RDI with 300+ experts) covers professional agent work in 55 sub-industries; 147 tasks are public from a corpus of over 1,500, graded by rubric into a strict pass rate and a partial score. The old page called OpenAI's GPT-6 Sol 56.4% the only figure; an {{independent leaderboard|https://snorkel.ai/leaderboard/agents-last-exam/}} exists (hosted by Snorkel), led by Claude Opus 5.5 (max, Claude Code) at 38.2% pass rate (63.2% score, 4 Oct 2026), and OpenAI's 56.4% is the partial score (the board's pass rate for GPT-6 Sol is 32.2%).

Vending-Bench ({{Andon Labs, Feb 2025|https://arxiv.org/abs/2502.15840}}) runs a simulated vending-machine business over more than 20 million tokens per run: simple steps, long horizon. Claude 3.5 Sonnet and o3-mini usually made a profit, but every model had runs that derailed (misread delivery schedules, forgotten orders, "meltdown" loops), and failures did not track when the context filled. AgentBench ({{Tsinghua, Aug 2023|https://arxiv.org/abs/2308.03688}}), eight environments from an OS shell to games, is historical: not reported on 2026 cards, its successors measure each environment more deeply.

These trade benchmark cleanliness for external validity, which is why they are increasingly quoted in capability-forecasting debates.

When the subject is the system, not the agent

A cluster from September 2026 scores something around the model, each a different answer to where agent performance lives:

  • {{HarnessDev|n:3d45c17b0d0d81cd9883f783840e013f}} scores a model's ability to build a harness from minimal components and then evolve it from feedback: six creator models, four domains, five downstream benchmarks, 2,207 instances, with execution-token cost beside capability. The best generated harness (Opus 4.8 running itself) averaged 67.8 against 86.2 for human-engineered references, which ran different, mostly newer models. Corrections: "match or beat on writing and ML experimentation" holds only for the best one or two creators; on evolution, all five self-runtime runs improved on 630 held-out tasks (+1.43 to +4.44), but the score a creator could see moved the same way as the held-out score in only 34 of 64 version changes, and swapping the model that executes a harness can halve its score.
  • {{MOLE|n:3db5c17b0d0d818b9680c7b91baaf7e9}} scores the monitor: 150 AI-operated accounts share 9 stateful services over 30 workdays with 12 injected threats. 28 of 39 agent models (72%) completed most assigned harmful objectives, measured under a preamble telling them the sandbox is harmless and refusing spoils the research; refusal and completion rates are strongly linked across models (Spearman −0.73), so the old "stated refusal does not predict whether it declines" overstates the paper. The best monitor (Claude Opus 4.7) caught 24 of 45 completed harms in a single-day audit of 10 accounts a day.
  • {{Emergence World|n:3e25c17b0d0d818fbffbc9e2ceab824b}} scores what survives duration: eight worlds of ten agents (six ran 16 days, one 21, one ended on day 4), about 850,000 LLM calls and 50 billion tokens, under prompt injection, misinformation and memory exposure. No world was resilient to all three; all 7 exposed worlds warned their community about the phishing and none removed its traces. The old "kept interacting 46 hours later" is one agent retrying an attack link about 46 hours after the campaign ended, not a measured detection-to-stop delay. It also tracks goal drift and tool-call failure trends day by day, which a suite of short episodes cannot see in principle, however many episodes it has.
  • EdgeBench (ByteDance Seed) has 134 day-scale tasks, 51 public; agents submit repeatedly within a time budget and the best submission is the score. {{SoL-Pi|n:3e25c17b0d0d81a0bb77f16cbc898bb5}} (NVIDIA) used it to show a harness-level improvement loop cutting recorded tokens 44.7 to 49.0% against Pi, mostly cache reads, with API cost about a third lower, at 93.7 to 94.3% of Pi's score: not "at task parity" as the old page said, and the cost per hour is SoL-Pi's derived metric, not EdgeBench's.
  • The harness tax (above) is the same lesson in money: a suite that reports only success cannot express it. ARC-AGI-3 is the exception where the harness takes the score with it ({{Knowledge and reasoning|n:3c65c17b0d0d810f8574da3ffb860be5}}).

Code as agent work. SWE-bench, SWE-bench Pro and Real-SWE are agent benchmarks too (the score depends on the scaffold; "bash only" and "full agent" columns differed by 10 to 20 points on swebench.com, whose bash-only board was dropped on 1 Sep 2026). {{Coding|n:3ef5c17b0d0d81bfa09ad4ba5eef0c4e}} owns them.
