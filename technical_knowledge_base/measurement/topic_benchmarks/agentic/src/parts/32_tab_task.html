Grade a real task

The Terminal-Bench 2.0 task {{regex-log|https://github.com/harbor-framework/terminal-bench-2/tree/main/regex-log}} (Apache 2.0; expert time estimate 45 minutes, junior 180), with its real test. Write a regex and run the test: it joins the test's 25 log lines, applies your pattern the way re.findall(pattern, log_text, re.MULTILINE) does, and passes only if the matches equal the 9 expected dates, in order. The task's instruction, verbatim:













The test runs in your browser's JavaScript regex engine, which agrees with Python's re on the constructs these patterns use (lookaheads, classes, groups, anchors with the multiline flag); Python-only syntax such as (?P<name>...) is translated, others may differ. src/recompute.py runs the presets through Python's re and checks the same verdicts. Like Python's findall, a pattern with one group returns that group, with none the whole match.
