The idea in one screen

A long-context or multimodal score measures whether the model used the context or the image only if the benchmark removes the shortcut that lets it answer without them: a needle that repeats the question's words, or a question the text alone gives away. Each generation of benchmark closed one shortcut and then saturated, so a score is read together with its shortcut control: the length bin and threshold, or the same model's blind score.

Close the shortcut and the score falls: each step below removed one way to answer without using the input

This page is about measuring the result.

Literal match
question and evidence share words, so attention can find the evidence by string matching.
Effective length
the longest tested length at which a model still clears a threshold; defined only with its threshold and task.
Blind baseline
the same model's score with the image removed; what the image added is the difference.
Yes-rate
the share of yes answers on a balanced yes/no set; 50% for an unbiased model.
CircularEval
ask an N-option question N times with the options rotated; correct only if every pass is.
ANLS
DocVQA's score: one minus the normalised edit distance, zero past a cut-off.

Long-context tests ask at three levels of difficulty: find one stated fact (needle, single-needle RULER), connect facts that are far apart or only implied (multi-hop tracing, NoLiMa's latent hops, BABILong's chained facts, MRCR's "the second of two identical requests"), and aggregate the whole input (counting the most frequent words, summarising a book, reasoning over 100 PDFs). Three protocol knobs decide what a number means: the length (and whose tokenizer counted it: AA-LCR counts with cl100k_base, MRCR bins by o200k), the depth where the evidence sits, and the threshold that turns a curve into an effective length. Why a model degrades past its training length (RoPE scaling, YaRN) is on {{Positional Encodings|n:3c65c17b0d0d81a5b7c9e578fcdfac00}}; how long context is trained is on {{Data mixing, curricula and continued-pretraining ratios|n:3c65c17b0d0d819ea5d6c59471e66875}}.
