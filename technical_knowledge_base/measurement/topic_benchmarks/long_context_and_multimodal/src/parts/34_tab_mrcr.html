This is a real row of OpenAI's MRCR dataset ({{openai/mrcr|https://huggingface.co/datasets/openai/mrcr}}, MIT licence; file 2needle/2needle_0.parquet, row 170, the shortest 2-needle row in that file), and the grader is OpenAI's own: Python's difflib.SequenceMatcher ratio, ported line by line to JavaScript and checked against Python on the presets below. It is 16,317 tokens of prompt plus answer (o200k tokenizer, counted here), so it sits in the 8K to 16K bin; longer rows add more requests, not a different task.

The final turn

Both needles repeat the request word for word ("write a short scene in a play about blueberries"), so finding them is easy; the task is telling the 1st from the 2nd and copying the right one exactly, with the random string in front.

The grader

score = 0 if the reply does not start with the prefix, else 2M ⁄ (|reply| + |target|)
M
characters in the matching blocks SequenceMatcher finds between the reply and the target, both with the prefix removed: it takes the longest common substring, then recurses on the pieces to its left and right
autojunk
when the target has 200 or more characters, any character occurring more than 1% of its length (plus one) cannot start a match; spaces and common letters are "popular" here, which is why near-copies still score close to 1 and unrelated texts close to 0

Try: the presets, then edit the reply: delete a line, change a name, drop the prefix's last character.

What the score means in the bins

A run averages this score over 100 rows per bin; the 8 bins run 4K to 8K, 8K to 16K, and doubling to 512K to 1M tokens of prompt plus answer (o200k tokenizer). Picking the wrong needle scores about 0.03 here, close to an unrelated text, so a bin's average is roughly the share of rows where the model copied the right one. Current readings, 8 needles: GPT-6 Astra 96.3% at 512K to 1M (OpenAI's own figure, 2 Sep 2026) and Gemini 3.7 Flash 63.5% at 1M (Context Arena, 23 Aug 2026); see the Reading tab for the December 2025 data fix.
