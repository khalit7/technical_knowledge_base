The families in brief

Benchmarks group by what they try to measure. Each family gets its intuition and what is active or retired; the {{Benchmark atlas|#t-atlas}} lists every benchmark with year, format, metric and status, and the child pages own construction, errata and scores.

Knowledge and reasoning

Can the model answer what experts can? These began as exams (MMLU's 57 subjects) and moved to questions chosen because models failed them: GPQA's "Google-proof" graduate science, where skilled non-experts with the web score about 34%, and HLE's roughly 2,500 expert questions. Abstract reasoning took its own road with ARC-AGI: novel puzzles that resist memorisation, interactive games since 2026. The recurring problem is the answer key.

Active: HLE, ARC-AGI-3, SimpleQA (factuality and abstention), AA-Briefcase, MMLU-Pro for mid-tier models. Saturated or retired: MMLU, GPQA Diamond at the frontier (still useful from 60 to 90%), HellaSwag, WinoGrande, BIG-Bench Hard, ARC-AGI-1.

Go deeper: {{Knowledge and reasoning benchmarks|n:3c65c17b0d0d810f8574da3ffb860be5}}: MMLU errata, GPQA's construction, HLE's judge and HLE-Verified, ARC-AGI 1 to 3.

Math

Math answers can be checked exactly, so the family is clean to grade and quick to saturate. GSM8K and MATH fell first (GSM-Symbolic showed part of GSM8K was pattern matching). The answer was freshness: each year's AIME is a benchmark the moment it is sat, and MathArena evaluates within days. At the top, FrontierMath's mostly private research problems keep headroom in the 50-problem Tier 4; Lean proofs (miniF2F, PutnamBench) remove grading ambiguity entirely.

Active: current AIME and HMMT under MathArena, FrontierMath upper tiers, PutnamBench. Saturated or retired: GSM8K, MATH and MATH-500, earlier AIME vintages, MGSM.

Go deeper: {{Math and coding benchmarks|n:3c65c17b0d0d8146b127fe43f5761bf0}}: the lineages, sampling traps, FrontierMath's governance.

Coding

Coding moved from one function against unit tests (HumanEval, MBPP) to real GitHub issues in whole repositories (the SWE-bench family), which made coding benchmarks agent benchmarks: the score depends on the scaffold. Contamination is fought with dated contest problems (LiveCodeBench; LiveCodeBench Pro rates models against humans) and with repositories the model cannot have seen. Weak test suites overstate correctness, a lesson EvalPlus taught and every code benchmark relearns.

Active: SWE-bench Pro (V2), LiveCodeBench and Pro, SWE-rebench, Real-SWE, Aider Polyglot, Phi-Bench. Saturated or retired: HumanEval, MBPP and EvalPlus, SWE-bench Verified (kept for continuity), BigCodeBench (saturating).

Go deeper: {{Math and coding benchmarks|n:3c65c17b0d0d8146b127fe43f5761bf0}}: the HumanEval lineage, the SWE-bench family and its splits.

Agentic

An agent benchmark hands the model tools and an environment (a terminal, a desktop, a website, a simulated customer) and checks the end state. The number belongs to model plus scaffold, and the environment can be attacked. τ²-bench's metric is worth knowing: pass^k, the probability that all k independent tries succeed, which measures reliability and falls far below pass@1 for most models. METR's time horizons measure the length of human task an agent completes half the time.

Active: Terminal-Bench 4.0 and Terminal-Bench-Science, OSWorld (Verified, 2.0), τ²-bench, BrowseComp, METR time horizons, GDPval and GDPval-AA, AutomationBench, Agents' Last Exam, EdgeBench, Hyper-τ-bench. Saturated or retired: GAIA and WebArena (saturating, shown gameable), AgentBench, τ-bench, Terminal-Bench 1.0.

Go deeper: {{Agentic benchmarks|n:3c65c17b0d0d811fb926d7b91ef8234e}}: the environments, pass^k, the integrity crisis, the leaderboards.

Long context

Can the model use a million tokens, not just accept them? Finding one planted fact (needle in a haystack) was solved early. Useful tests make the model trace and aggregate across the input: RULER by length, LongBench v2 on real documents, MRCR, Fiction.liveBench, and GDP.pdf's 4,592 PDF pages, where GPT-6 Astra leads at 33.2%.

Active: RULER, LongBench v2, MRCR, Fiction.liveBench, GDP.pdf. Saturated: needle in a haystack.

Multimodal

Questions that need an image, chart, document or video. MMMU saturated and its Pro version took over; chart, document and visual-math sets saturate fast because their answers are short; video is the open end.

Active: MMMU-Pro, Video-MME, VideoMMMU. Saturating: MMMU, MathVista, ChartQA, DocVQA.

Go deeper: child page planned.

Safety

Does the model refuse what it should, resist jailbreaks, stay honest, and stay safe when it acts? Early tests scored the answer text (TruthfulQA); current ones score attack success (HarmBench, StrongREJECT, AgentHarm), regulation-derived risks (AIR-Bench), belief against claim (MASK), and now the monitor and the long run (MOLE, Emergence World): what a model does matters more than what it says.

Active: HarmBench, StrongREJECT, AgentHarm, AIR-Bench, MASK, MOLE, Emergence World. Mostly retired: TruthfulQA.

Go deeper: child page planned; see {{Reward Hacking|n:3c65c17b0d0d8196a6f1f29a817aa974}}.

Human preference and instruction following

Which answer do people prefer? LMArena fits Bradley-Terry (Elo-style) ratings to anonymous pairwise votes: live, contamination-free, and a measure of preference, not capability. Votes reward confident, well-formatted, flattering answers, and style rivals substance (the 2025 GPT-4o sycophancy rollback showed the cost of optimising for approval). Arena-Hard and AlpacaEval swap voters for an LLM judge. Instruction following is checked mechanically: IFEval's verifiable constraints, MultiChallenge's multi-turn ones.

Active: LMArena (with category filters and style control), Arena-Hard v2, GDPval-AA, IFEval (saturating), MultiChallenge and IFBench. Fading or retired: AlpacaEval 2, MT-Bench.

Go deeper: child page planned; judges on {{Topic: evaluation-and-llm-judges|n:3c65c17b0d0d8181b351e1b8fc6a1546}}.

Multilingual

Does capability survive outside English? A translated English test measures translation as much as knowledge, so newer sets are culturally aware. Machine translation keeps chrF and BLEU on FLORES-200's 200 languages.

Active: Global-MMLU, MMMLU, INCLUDE, FLORES-200. Saturated: MGSM.

Go deeper: child page planned.

Tool use

Can the model pick the right tool and fill its arguments? BFCL began with function-call correctness and became agentic in v4; MCP-era suites call real Model Context Protocol servers rather than mocks. Young, fragmented, with headroom on hard multi-step tasks.

Active: BFCL v4, MCP-Universe, MCPMark, MCP-Bench, τ²-bench.

Go deeper: child page planned; MCP evals in {{Agentic benchmarks|n:3c65c17b0d0d811fb926d7b91ef8234e}}.

Before these came the classic era, now historical: ImageNet (2009), SQuAD's reading comprehension, GLUE and SuperGLUE in the BERT years.
