Other coding benchmarks worth knowing

Aider Polyglot (Aider, December 2024) replaced Aider's Python-only editing benchmark after it saturated. From Exercism's 697 exercises in C++, Go, Java, JavaScript, Python and Rust it kept the 225 "solved by 3 or fewer" of seven strong models; the model edits code through Aider's edit formats and gets a second attempt after seeing failing tests. o1 (high) launched it at 62% ({{Aider|https://aider.chat/2024/12/21/polyglot.html}}). It is cheap to run and tests the editing loop practitioners use, which made it popular with them; saturating, with few frontier entries since August 2025.

DeepSWE (Datacurve, 2026) runs every model in one fixed minimal harness (mini-swe-agent) on 113 repository tasks (v1.1) and reports pass@1 averaged over 4 runs with a 95% interval ({{DeepSWE|https://deepswe.datacurve.ai/}}). A fixed harness is what makes its readings comparable across models; it trades away the vendor agents that Real-SWE keeps on purpose. Vendor cards now quote DeepSWE above the board's top from their own runs; none is a board entry, so none displaces it.

Phi-Bench (USTC, StepFun and others, September 2026) asks whether a model can engineer the infrastructure AI runs on: 85 open-ended tasks in nine categories in three formats of rising scope (55 single-file kernel completions, 20 multi-file repository implementations, 10 end-to-end optimisations where the model must first find the bottleneck), scored as a mean reward in which matching the expert reference earns zero, not a pass rate ({{Ding et al. 2026|https://arxiv.org/abs/2609.10226}}). The {{Phi-Bench paper page|n:3db5c17b0d0d81029236da6c38f5891f}} replays its MoE training task and simulates its scoring.

Three checks of what agents leave behind (October 2026 papers, all far from saturation; the third, Doc2Harness, is in the block below), each grading something a pass rate ignores. {{Last Secure Code Benchmark|https://arxiv.org/abs/2610.14766}}: 450 tasks from 150 real vulnerabilities in seven languages and 24 CWEs; the specification asks only for functionality, hidden tests grade both, and six frontier agents pass 73.6% to 91.3% functionally but at best 25.1% functional and secure. {{TestPrism|https://arxiv.org/abs/2610.12289}} grades generated tests against 3,000 candidate implementations: a suite must fail on the starting code, accept every valid candidate and reject every invalid one, and across 14 coding-agent configurations that Joint Success Function is 28.00% against 59.67% for the usual single-reference success, the EvalPlus lesson from the other side.

Terminal-Bench (agents completing tasks in a terminal; version 4.0 current since September 2026, not comparable with 2.x) is often quoted beside SWE-bench Pro as a coding number. It belongs to the {{Agentic benchmarks|n:3c65c17b0d0d811fb926d7b91ef8234e}} page, which owns its versions and harnesses.

More on these benchmarks (Aider's old benchmark, Phi-Bench's categories and sources, Doc2Harness)

Aider's old benchmark saturated at Claude 3.5 Sonnet 84.2%: "Models as old as GPT 3.5 Turbo were able to solve half of the 133 problems".

Phi-Bench's nine categories: training systems, inference and serving, compression, kernels, I/O, hardware and edge, data infrastructure, system optimisation, system assurance. Tasks were reconstructed from pull requests and issues, mined with agent help and generated tests, or curated by experts where no history exists, grounded in 2,260 papers and 1,852 engineering artifacts.

{{Doc2Harness|https://arxiv.org/abs/2610.20344}} asks a model to build a coding-agent harness from an interface skeleton and a development document, then drives the frozen harness with a scripted mock model through 328 tests: across 19 models (three builds each) GPT-6 Astra passes 53.05%, the weakest 27.44%.

36.53 is a mean reward in which matching the expert reference earns zero, not a percentage of tasks passed. "Hardware and edge tasks collapse to 5.4%" is Qwen3.7 Max, seventh overall, on a category of 3 tasks; Claude Opus 5 scores 3.9 there. How to read a reported coding score

Every question below is one of the three levers of the hero, or the sampling around them; each has bitten a real reading on this page.

  1. Which benchmark, version and split? "SWE-bench Pro" is V1 public, V1 commercial, V2 public, V2 Hard or V2 private, and one model scores 79.2% to 99.4% across them. Prefer the split that was never public.
  2. Which harness, turn limit and cost cap, and who ran it? Bash-only, open-scaffold and vendor-agent figures are not comparable (GPT-5: 23.3% and 41.8% on one split). A vendor's own run on its own window is a claim; an independent board with a fixed harness (Vals AI, DeepSWE) is a measurement.
  3. Are the tasks newer than the model's training cutoff? A release date is not a cutoff: SWE-rebench's before-and-after-release split shows nothing, while LiveCodeBench's split around DeepSeek-V3's marker shows a 35-point drop. Verified's issues end in August 2023.
  4. How strong are the tests? HumanEval graded a sample that calls every negative number prime as CORRECT; Verified's median task has one fail-to-pass test; some issues contain their own fix. Ask how many tests, and whether anyone tried to break them.
  5. pass@what? pass@100 (70.2% for Codex-12B) is not pass@1 (28.8%); report k, n and the temperature.
  6. How many tasks? On 500 tasks one task is 0.2 points; on Real-SWE's ten it is 10 points. Gaps inside the error bar are ties.
  7. Is the board still alive? LiveCodeBench (April 2025 problems), LiveCodeBench Pro (November 2025 ratings), BigCodeBench (April 2025 models), SWE-bench Multimodal (no 2026 entry) and swebench.com's Verified board (February 2026) are frozen. "Unmaintained" and "saturated" are different reasons to stop using a benchmark.

What to use now

  • Repository-level engineering, the main question: SWE-Bench Pro V2's private split (Scale's runs; the public split is saturated), SWE-rebench's current window for fresh public issues, Real-SWE for private enterprise code (remember its ten tasks), and DeepSWE for a fixed-harness comparison. Quote each with its version, split, harness and date. Terminal-Bench 4.0 for terminal work (on the Agentic page).
  • SWE-bench Verified only for continuity with 2024 and 2025 reports, and never to rank frontier models: the top eight sit within 3.6 points on a memorised, years-old set.
  • Function-level and contest code: nothing current and independent remains. Vendor Codeforces ratings are not comparable across labs; a live contest (ICPC, IOI) is the one clean result. HumanEval+ and MBPP+ stay useful as cheap regression tests for small models.
  • Infrastructure engineering: Phi-Bench, read as a reward against an expert, not a pass rate.
  • Whether the code is safe to ship: a functional pass rate says nothing about security; the Last Secure Code Benchmark reports both, and the gap is large.
Correction to the old page's advice
"Model-level codegen: LiveCodeBench (latest window) plus LiveCodeBench Pro rating" no longer works: neither board has new problems or ratings since 2025. "SWE-bench Pro (state the split and scaffold)" now also needs the major version, and on V2 the private split.
