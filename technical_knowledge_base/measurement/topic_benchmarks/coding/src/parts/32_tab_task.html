One SWE-bench task, opened

Every SWE-bench task is a row of data: an issue, the repository commit before the fix, the real fix (the gold patch), the pull request's test changes (the test patch), and two lists of test names. This is one of the 500 tasks of SWE-bench Verified, shown in full from the {{released dataset|https://huggingface.co/datasets/princeton-nlp/SWE-bench_Verified}}: . It is short on purpose (annotated "<15 min fix", like 194 of the 500), so every part fits on screen. Background is in the {{Reading tab|#t-read}}.

1. The issue the model is given



The answer is in the question
The issue proposes the fix verbatim: replace ^...$ with \A...\Z. The merged patch kept ^ and changed only the end anchor, so a line-by-line leak check (the Reading tab's 49 of 500) misses this task, yet a model can resolve it by following the issue. This is the solution leakage SWE-Bench+ counted in 32.67% of one agent's resolved tasks.



2. The gold patch and the test patch


Gold patch (what the maintainers merged)
Test patch (applied by the harness after the model's patch)


The model never sees the test patch. It adds a username ending in a newline to the invalid lists of both validator tests.



3. The harness, run on four candidate patches


Choose what the model submitted. The two username tests are re-run on this page for each candidate with Python's re, the way Django's RegexValidator uses it (search, raise if no match; the ASCII validator with re.ASCII), on the test lists at the base commit plus the test patch (src/recompute.py). The third fail-to-pass test and the 19 pass-to-pass tests are taken as the dataset records them for the gold patch, not re-run.


















All 19 pass-to-pass test names
    

    An oddity worth knowing: the dataset lists test_help_text (UserAttributeSimilarityValidatorTest), a password-validator test the patch does not touch, as fail-to-pass. The dataset does not say why; datasets built by running tests before and after a patch can pick up tests that changed state for environmental reasons.
