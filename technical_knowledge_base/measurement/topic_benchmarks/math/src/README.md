Source of the interactive HTML on the Notion page "Math benchmarks: GSM8K to FrontierMath" (child of Topic: benchmarks).

Build: `sh build.sh` writes `../index.html` (slot order in its header comment).

Data, in order:
1. `uv run --with pyarrow python3 mk_data.py <cache dir>` downloads the MathArena datasets from Hugging Face (`MathArena/aime_2025`, `aime_2026`, `hmmt_feb_2026` and their `_outputs`, CC BY-NC-SA 4.0; about 330 MB of parquet, kept in the cache dir, never committed) and writes `inputs/matharena_samples.json` (every parsed final answer, grouped per problem; gold answer is index 0, every answer graded correct maps to it) and `parts/22_js_data.js` (compact, with problem statements converted by `tex.py`, a small LaTeX-to-HTML converter). Configurations with fewer answers than problems are dropped (one: a single-answer AIME 2025 agent entry).
2. `python3 recompute.py` recomputes every derived number on the page into `recompute_out.json`: pass@1, maj@k (exact over all k-subsets, ties split), pass@k (unbiased estimator), three intervals for every configuration; MathArena's printed ± (reproduced for all 123 table rows as 1.96·√(p(1−p)/answers)); the AIME 2025 problem 15 case; GSM-Symbolic Table 1 drops and binomial spreads; FrontierMath v2 arithmetic (42%, 285 and 41 private problems from Epoch's standard errors); error bars by item count.
3. `node check_ui.mjs [shots dir]` compares the page's JavaScript maths with `recompute_out.json` (1,516 values, worst difference 0.005 from rounding) and the permutation test with hand cases, then clicks every control at 390 px dark and 920 px light (351 actions each: every animation step in every mode, every GSM-Symbolic model, every ladder rung, every Sample lab contest, model A and B choice, interval mode, problem column and board row) and fails on errors, NaN/undefined/null text or sideways scroll. Last run 2026-10-04: 0 problems.
4. `python3 mk_coverage_split.py` writes `coverage_math_and_coding.json` (all 111 facts of the old page with their owner: 54 Math, 56 Coding, 1 split) and `coverage.json` (the 54 Math facts with where this page carries them and any correction), using `coverage_where.json`.

Inputs (`inputs/`): `arxiv_abstracts.json` (arXiv API, 13 papers), `matharena_tables_2026-10-04.json` (the three MathArena tables as displayed, with ± and the after-contest flags), `matharena_samples.json`, `epoch_frontiermath_t4v2_page_2026-10-04.txt` (Epoch's v2 description, methodology and changelog), `deedy_imo2026_README_2026-10-04.md`. Old page: `live_math_and_coding.md` (verbatim fetch of 3c65c17b0d0d8146b127fe43f5761bf0, read only).
