Handling Flaky Test Cases LLM evals are non-deterministic, and some test cases will sit right on a metric's threshold and flip between passing and failing across runs. Instead of removing them from your suite, mark them as flaky: from deepeval.test_case import LLMTestCase test_case = LLMTestCase( flaky = True , ... ) When a flaky test case fails, assert_test() prints a warning instead of raising an AssertionError , so your CI pipeline keeps going while the failure is still recorded in your test run results. Both LLMTestCase and ConversationalTestCase support the flaky parameter.
