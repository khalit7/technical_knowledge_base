Title: Path to high-quality LLM-based Dasher support automation
Org: DoorDash Engineering. Date: page metadata "Published Time: 2024-09-17" (UNVERIFIED in visible body text)

Three systems: "LLM Guardrail, LLM Judge, and a quality improvement pipeline"
"The LLM Guardrail system is an online monitoring tool that evaluates each output from the LLM to ensure accuracy and compliance."
Two tiers: "a cost-effective shallow check developed in-house followed by an LLM-based evaluator"; "A response must pass all guardrail tests to be shown to the end user."
Why not a big guardrail model: "increased response times and heavy usage of model tokens made it prohibitively expensive."
"This guardrail system has successfully reduced overall hallucinations by 90% and cut down potentially severe compliance issues by 99%."
"we manually reviewed thousands of chat transcripts between the LLM and Dashers to develop an iteration pipeline for monitoring LLM quality."
Five judge areas: Retrieval correctness; Response accuracy; Grammar and language accuracy; Coherence to context; Relevance to the Dasher's request.
"The high-frequency issues are then built into prompts or rules for further monitoring."
Promotion of failures: "Newly identified issues are systematically added to Promptfoo test suites, ensuring continuous improvement and preventing model performance regression."
"Each day, this system autonomously assists thousands of Dashers"
Latency: "can vary from a sub-second level to tens of seconds."
