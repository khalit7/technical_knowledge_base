Title: Demystifying evals for AI agents
Org: Anthropic (engineering blog). Date on page: "Published Jan 09, 2026"

"Regression evals ask, "Does the agent still handle all the tasks it used to?" and should have a nearly 100% pass rate."
"capability evals with high pass rates can "graduate" to become a regression suite that is run continuously to catch any drift."
Capability evals "should start at a low pass rate, targeting tasks the agent struggles with and giving teams a hill to climb."
"In reality, 20-50 simple tasks drawn from real failures is a great start."
"If you're already in production, look at your bug tracker and support queue. Converting user-reported failures into test cases ensures your suite reflects actual usage"
"a 0% pass rate across many trials (i.e. 0% pass@100) is most often a signal of a broken task, not an incapable agent"
pass^k: "If your agent has a 75% per-trial success rate and you run 3 trials, the probability of passing all three is (0.75)^3 ~ 42%."
"For each task, scoring can be weighted (combined grader scores must hit a threshold), binary (all graders must pass), or a hybrid."
"Once evals exist, you get baselines and regression tests for free: latency, token usage, cost per task, and error rates can be tracked on a static bank of tasks."
"Automated evals are especially useful pre-launch and in CI/CD, running on each agent change and model upgrade as the first line of defense"
"Production monitoring kicks in post-launch to detect distribution drift and unanticipated real-world failures. A/B testing validates significant changes once you have sufficient traffic."
A/B testing cons: "Slow; days or weeks to reach significance and requires sufficient traffic"
"triage feedback constantly, sample transcripts to read weekly"
Swiss Cheese Model: "no single evaluation layer catches every issue."
Claude Code: "we added evals, first for narrow areas like concision and file edits, and then for more complex behaviors like over-engineering." [dash in original]
Descript: "now regularly run two separate suites for quality benchmarking and regression testing." Bolt: "In 3 months, they built an eval system"
