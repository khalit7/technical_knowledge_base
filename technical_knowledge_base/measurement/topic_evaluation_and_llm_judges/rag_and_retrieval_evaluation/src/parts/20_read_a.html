The idea in one sentenceA RAG answer can fail at finding the evidence or at using it, so grade the two halves apart: the retrieved passages against labels of which passages hold the answer, the answer against the passages it was actually given, and only then the answer against the truth; every RAG metric compares two of five things, and which two decides what it can see.

Each metric is one comparison; faithfulness never looks at the truth, correctness never looks at the passages

Upper arcs grade the passages (the retrieval half), lower arcs grade the answer (the generation half). Recall@k needs passage labels (qrels); context precision and context recall replace them with a reference answer and a judge; faithfulness and citation accuracy compare the answer with the passages only; correctness and nugget recall compare it with a reference only. No single arc says which half failed; the pair of halves does.

You need: the ranked-list metrics themselves, recall@k, MRR and nDCG with its two gains ({{Evaluation metrics|n:3c65c17b0d0d81a29acef722e842a29b}}, section 6, owns the definitions and a one-list calculator); what an LLM judge is and how it is calibrated ({{LLM-as-judge|n:3c65c17b0d0d810ba2a2ecc08c4c233b}}); how a RAG system is built ({{Topic: rag-and-retrieval|n:3c65c17b0d0d81b89145c37dfe8a3b0b}}). Everything here is worked on released human labels: BEIR qrels, 1,584 RAGTruth answers with annotated spans, and MS MARCO's marks of which passage holds the answer.

qrels: the relevance labels of a test set, query to passage to grade.
hit@k: 1 if any labelled passage is in the top k; recall@k is the share of the labelled passages that are.
Faithfulness (also groundedness): the share of the answer's claims that the retrieved passages support.
Claim decomposition: splitting an answer into atomic claims before checking each; itself an LLM step.
NLI: natural-language inference, a classifier saying whether a premise entails, contradicts or is neutral to a hypothesis.
Context precision / recall: judge-graded stand-ins for retrieval metrics: are relevant passages ranked first; do the passages cover the reference answer.
Nugget: one atomic fact a good answer must contain (TREC RAG's unit of correctness).
Citation recall / precision: do a sentence's citations entail it; is each citation needed.

Split the halves: one score hides which one failed

End-to-end accuracy is a product of stage shares, A = rK · pk|K · g (found in the first stage's top K, kept in the k that reach the prompt, answered correctly), so the same accuracy can come from a weak retriever or a weak generator; {{The retrieval pipeline|n:3c65c17b0d0d819899fde889e1e8b782}} measures that split on its running example (section 9). Here it is done on single answers, with human labels for each half.

The one habit
For every wrong answer, first ask whether a passage that holds the answer was in the prompt. That one bit gives the failure to the retriever (not in the prompt) or to the generator (in the prompt, and still wrong) before anybody touches a component.

Before scores each answer end to end; After also scores the retrieval half against a human mark of which passage holds the answer, and the generation half against human-marked hallucinated spans. Each "no" names what to fix: a corpus gap is not a retriever bug; outside the first stage's top K is a retrieval miss (chunking, hybrid search, query rewriting); found at rank 40 when the prompt takes 10 is a ranking miss, visible only if recall is measured at the reranker's depth too; a wrong answer from the right passage is the generator's (prompt, model, context format, distraction by irrelevant passages); a refusal when the context sufficed, or an answer when it did not, is an abstention miss (instructions); both halves passing on a stale source is a corpus miss.
