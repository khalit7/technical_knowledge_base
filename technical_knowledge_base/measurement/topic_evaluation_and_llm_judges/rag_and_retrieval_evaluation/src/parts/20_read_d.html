Answer relevance, context precision and context recall: judged, and how they fail

Answer relevance

Does the answer address the question? It says nothing about truth: Llama-2-13B's answer above is about whether Kenneth Williams is alive, true, and irrelevant. RAGAS measures it backwards: an LLM writes N questions the answer would answer (N = 3 by default), and the score is their mean cosine similarity to the real question in embedding space; in RAGAS's code, not its docs, the score is set to 0 when the judge flags every generated question as noncommittal ("I don't know"; _answer_relevance.py, February 2026). DeepEval measures it forwards, as the share of the answer's statements relevant to the question. A long answer with one relevant sentence can score well on the first and badly on the second.

Context precision

RAGAS's context precision asks whether the relevant passages were ranked above the irrelevant ones, with relevance judged per passage against the reference answer (or against the response when there is none); TruLens's context relevance asks only whether each passage is relevant. On the worked example below (three relevant passages A, B and C, before and after a cross-encoder reranker), binary verdicts give the first-stage list (relevant at ranks 2 and 4) (1/2 + 2/4) / 2 = 0.5 and the reranked list (ranks 1, 2 and 4) (1 + 1 + 3/4) / 3 = 0.917:

context precision@K = Σk=1..K (precision@k × vk) / (relevant passages in the top K)
vk
the judge's 0 or 1 verdict on the passage at rank k

It is the average precision of the judged list, so irrelevant passages ranked below every relevant one do not lower it.

The worked example, every metric

The starting list is the worked example from the earlier RAG evaluation page: a query with three relevant passages A (grade 3), B (2) and C (1). First stage: X, B, Y, C, Z in the top 5 and A at rank 8, so recall@5 = 2/3, precision@5 = 0.4, RR = 1/2, and nDCG@5 = (2/1.585 + 1/2.322) / (3 + 2/1.585 + 1/2) = 1.693 / 4.762 = 0.355. Reranked: A, B, X, C, Y, so recall@5 = 1, precision@5 = 0.6, RR = 1 and nDCG@5 = 4.693 / 4.762 = 0.985. The reranker could rescue A only because the first stage had it within the 20 it was given. Context recall

The share of the reference answer's claims that the retrieved passages could support: the judged cousin of retrieval recall, usable when you have reference answers but no passage labels. A reference answer with 4 claims of which the passages support 3 scores 0.75: a quarter of what a correct answer needs never reached the generator. It fails where the reference is incomplete (a passage holding a fact the reference omits earns nothing) and wherever the claim split or the judge errs, as for faithfulness.

Citation accuracy: does each cited passage support its sentence?

When the system cites, check the citations themselves. ALCE ({{Gao et al., EMNLP 2023|https://arxiv.org/abs/2305.14627}}) splits the answer into statements, each citing a set of passages Ci, and uses an NLI model (TRUE, a T5-11B fine-tuned for entailment) as the checker. Citation recall of a statement is 1 if it cites at least one passage and the cited passages, concatenated, entail it; averaged over statements. Citation precision of a citation is 0 if it is "irrelevant": it does not entail the statement on its own, and the other citations entail the statement without it; averaged over citations. Redundant but supporting citations are not penalised.

Three statements, three citations: recall 2/3, precision 2/3

illustrative. [3] neither entails S2 alone nor is needed, so it is irrelevant; S3 cites nothing, so its recall is 0. Citation recall = 2/3 over statements; citation precision = 2/3 over the three citations.

ALCE's headline: on ELI5, even the best models of 2023 lacked complete citation support about half the time. Citation checks are the cheapest groundedness test in production, because they need no reference answer and the NLI check is a small model; their blind spot is a claim left uncited (S3). TREC RAG grades the same thing as "support": does each cited segment support its sentence (full, partial, none).
