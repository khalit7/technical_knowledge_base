Score a real retrieval run

Five retrievers run on three BEIR test sets on this machine, scored against each set's released qrels, every number below recomputed in your browser from the stored ranks of the labelled passages. Pick a set and a cutoff; then open single queries to see where the systems disagree. The Reading's {{A real run|#t-read}} section draws the conclusions.

One query at a time

16 queries per set, chosen where the lexical and the dense run disagree on whether a labelled passage is in the top 10, plus queries both find at different ranks and queries both miss (shortest queries first in each group). Labelled passages are shaded; the number is the qrels grade.
