A published case: LLaMA-65B, 48.8 or 63.6

Five readings of one checkpoint on MMLU's 14,042 test questions: the LLaMA paper's Table 9 (63.4), the original MMLU code run by Hugging Face (63.6), HELM at commit cab5d89 (63.7), the Open LLM Leaderboard v1 after its fix (63.93; macro, micro 63.74) and lm-eval-harness as of January 2023 (48.8), which scored each answer's text instead of its letter, with a different prompt and five randomly drawn shots ({{Hugging Face, 23 June 2023|https://huggingface.co/blog/open-llm-leaderboard-mmlu}}). Rule
Two scores are comparable only when every link matches, or when the gap is measured on the same items with only that link changed. Agreement is possible: Llama 3 8B scored 66.7 (Meta), 66.70 (Open LLM Leaderboard) and 66.76 (HELM) because all three used 5 shots and a letter answer.
