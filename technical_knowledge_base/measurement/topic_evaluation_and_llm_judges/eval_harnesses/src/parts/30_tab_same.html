GSM8K in every harness

GSM8K (grade-school math word problems, {{Cobbe et al. 2021|https://arxiv.org/abs/2110.14168}}) as each harness ships it: the real files, at the commits checked on 4 October 2026, every line linked to GitHub. GSM8K is the one task that lm-eval, inspect_evals, lighteval and HELM all carry; simple-evals carries its multilingual version MGSM, whose English set is 250 GSM8K test problems ({{Shi et al. 2022|https://arxiv.org/abs/2210.03057}}); openai/evals, Evalchemy, Unitxt and promptfoo have no GSM8K, so their nearest real file is shown and labelled. How much each decision moves a score is measured in the Reading tab (Reading, section 3); this tab shows where in each file the decisions live, and the Reading tab's extraction section runs every rule on real outputs.
