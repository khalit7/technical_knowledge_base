One task, every harness

GSM8K (grade-school math word problems, {{Cobbe et al. 2021|https://arxiv.org/abs/2110.14168}}) as each harness ships it: the real files, at the commits checked on 4 October 2026, every line linked to GitHub. GSM8K is the one task that lm-eval, inspect_evals, lighteval and HELM all carry; simple-evals carries its multilingual version MGSM, whose English set is 250 GSM8K test problems ({{Shi et al. 2022|https://arxiv.org/abs/2210.03057}}); openai/evals, Evalchemy, Unitxt and promptfoo have no GSM8K, so their nearest real file is shown and labelled. How the scores move is measured on the parent page (tab Same model, many harnesses); this tab shows where in each file the decisions live.

Extraction bench: seven rules, the same real outputs

Twenty real outputs: Qwen2.5-0.5B-Instruct on the first ten GSM8K test problems, once through lm-eval's gsm8k (raw 5-shot prompt) and once through inspect_evals' gsm8k (chat template, 10 shots in a system message), both run by this page on 4 October 2026 (tab {{Inside a run log|#t-logs}}). Each output is then scored by every harness's extraction rule, using the harness's own code where it installs (lm-eval, Inspect, lighteval) and a verbatim copy of the function where it does not (HELM, simple-evals, openai/evals), in src/compute_extract.py.

What this is not
A score. Ten items from a 0.5-billion-parameter model cannot rank harnesses or models (the exact Clopper-Pearson 95% interval for 1 correct out of 10 runs from 0.3% to 44.5%); the point is that the same text gets different verdicts. Sample sizes are on {{Eval statistics|n:3ef5c17b0d0d8187a7b4e5b4ec4a546d}}.
