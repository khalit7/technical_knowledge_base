Calibration lab: correct a judge's win rate with a gold slice

The question a team usually asks a judge: what share of comparisons does model X win? Here the answer is known, because every comparison also has a human vote. Pick a model and a judge, choose how many human labels to buy for the gold slice, and compare three reports: the judge's raw rate, the rate corrected with the judge's sensitivity and specificity measured on the slice ({{Lee et al. 2025, eqs. 7 to 12|https://arxiv.org/abs/2511.21140}}), and the same human labels used directly as a small sample.

Seeds 1 to 200 at the current slice size. Each dot is one draw's corrected estimate; the band is the spread of the human-only sample. Coverage counts how many corrected intervals contain the truth (the method promises about 95%).

How many labels does the correction need?

Average 95% interval width over 50 draws at each slice size, for the corrected judge rate and for the same labels used alone. Where the first line is below the second, the judge is saving human labels.

Items: every non-tie human vote on a comparison involving the model (ties by humans are left out so the truth is binary); "pass" means the model won. Judge ties count as not a win. The test set for the judge is all of those items; the gold slice is a random subset of them, so the slice and the test set share a distribution, the setting where the correction is unbiased. The truth shown is the human win rate over all items, which a real team would not have. Same data as the {{Protocol lab|#t-proto}}.
