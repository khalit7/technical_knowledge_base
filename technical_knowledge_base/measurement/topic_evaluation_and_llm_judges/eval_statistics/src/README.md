# Eval statistics: source

`sh build.sh` writes `../index.html` from `parts/` (HTML parts in name order, then every `*.js` in its own `<script>`, `99_js_tabs.js` last; `{{text|url}}` link shorthand as in the sibling pages).

## Parts
- `01_head.html`, `05z_errbox.js.html`, `21_js_rd_common.js` (RD helpers and the step-animation controller), `99_js_tabs.js`: copied from the parent topic.
- `10_header.html`: title and tab bar (Reading, Interval lab, Sample-size calculator, Small-n intervals, Further reading).
- `20_read_a.html` to `20_read_e.html`, `20_read_z.html`: the Reading tab (sections rd-one to rd-mist).
- `30_js_data.js`: `window.ES`, generated by `mk_data.py`. `31_js_common.js`: the statistics library (normal and binomial functions, incomplete beta, Wald / Wilson / Clopper-Pearson / Bayes intervals, exact coverage, clustered SE (Miller Eq. 4), paired bootstrap, sign-flip permutation, McNemar exact and chi-square, exact McNemar power and Type-M) and the data decoders.
- `40_js_rd_vals.js` (numbers filled into the text, tables), `41_js_rd_anim.js` (the before/after animation), `42_js_rd_var.js` (variance chart), `43_js_rd_more.js` (many-slice calculator, MathArena split, judge noise).
- `51_*` Interval lab, `52_*` Sample-size calculator, `53_*` Small-n intervals, `59_tab_more.html` Further reading.

## Data
- `run_race.py`: scores a model on RACE-H (test, `ehovy/race`, config high) by next-token probabilities over the letters A to D, zero-shot, on every question of the first N passages of a seed-0 shuffle. Run on 4 October 2026 for Qwen2.5-0.5B-Instruct and Qwen3-0.6B (`uv run --with torch --with transformers --with pyarrow python3 run_race.py <parquet> <model> <out.json> 600`); outputs in `inputs/race_qwen25.json` and `inputs/race_qwen3.json`. The first model ran all 600 passages on the laptop GPU (MPS, about 7 minutes). The second started on MPS, slowed under GPU contention from other jobs and was resumed on CPU (float32 both; the runner resumes from its `.part` file); it was stopped once it had covered the first 400 passages, and that partial output was saved as `inputs/race_qwen3.json`. The page uses the first 400 passages of the shuffle for both models (`NPASS` in `mk_data.py`): the cap kept the offline compute near the 20-minute budget.
- `mk_data.py`: builds `parts/30_js_data.js` from the RACE outputs, the production page's `gate_data.json` (LMSYS MT-Bench GPT-4 grades, 34 models), the Math page's `matharena_samples.json` (MathArena answers, CC BY-NC-SA 4.0) and `inputs/mt_human_votes.json` (written from the `lmsys/mt_bench_human_judgments` parquet on first run).
- `save_sources.py` and `inputs/source_extracts.json`: verbatim passages of every source whose numbers the page quotes (arXiv HTML of Miller, Madaan, Bowyer, Card, Hochlehnert, Heineman, Bean; Anthropic's post; statsforevals; Inspect's `std.py`), fetched 2026-10-04.

## Checks
- `recompute.py` (NumPy, SciPy) recomputes every published reproduction and every real-data number; `check_page.mjs` loads the built page, compares `window.ES_CHECK` with `recompute.json`, then clicks every control at 390 px dark and 920 px light (errors, NaN, undefined, missing values, sideways scroll) and screenshots to `../.shots/`.
- `sh html_utils/checkpage.sh <folder>` from the repo root.

## Shape
Part B of `html_utils/methods/topic_pages.md` (child page): Reading by the subject's own logic, one tab per standalone visual (a lab, a calculator, a coverage view), Further reading. Departure: the before/after animation compares two analyses of the same data rather than two mechanisms, because the subject is the analysis.
