Sample-size calculator: how many items a decision needs

Pick the kind of score, then set what you know. Every output is computed from the formula printed under the controls; the presets load published worked examples and say how close the calculator lands (the residual), without adjusting any input to hide a gap. Statistics behind it: the Reading tab's {{power section|#t-read}}.

paired: n = (zα/2 + zβ)² · (d − Δ²) / Δ²
unpaired: n = (zα/2 + zβ)² · 2p(1 − p) / Δ²
d
share of items where exactly one model passes (the discordant items; McNemar uses only these)
Δ
the true difference in pass rate; p the baseline pass rate (both models' variance taken at the baseline, as the parent topic does)
z
normal quantiles: z0.025 = 1.96, z0.20 = 0.84; with s slices, α becomes α/s

The paired line is the normal approximation to McNemar's test (Miller's Eq. 9 with ω² = d − Δ² for 0/1 scores). The "exact" rows run McNemar's exact binomial test itself: the probability of rejecting is summed over every possible number of discordant items and every split of them, so they also give the Type-M (exaggeration) factor: how much a difference that does reach significance overstates the true one, on average ({{Card et al. 2020|https://arxiv.org/abs/2010.06595}}, Appendix B).

n = (zα/2 + zβ)² · (ω² + σ²A/KA + σ²B/KB) · DEFF / δ²
ω²
Var(xA) + Var(xB) − 2 Cov(xA, xB): how much the two models' true per-item scores differ from item to item ({{Miller 2024, Eq. 9|https://arxiv.org/abs/2411.00640}})
σ²
mean within-item variance: how much one model's score on the same item moves from sample to sample (for 0/1 scores, the mean of x(1 − x)); K samples divide it by K
DEFF
design effect 1 + (m − 1)ρ for clusters of m items with intra-cluster correlation ρ textbook approximation: Miller's Appendix C instead plugs clustered versions of ω² and σ² into the same formula, which needs earlier data from the same eval
α, power
0.05 two-sided and 80% here; MDE inverts the formula: δ = (zα/2 + zβ)·√((ω² + σ²/K)·DEFF / n)
