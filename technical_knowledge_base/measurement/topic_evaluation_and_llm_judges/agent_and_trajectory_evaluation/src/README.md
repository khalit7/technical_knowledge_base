# Source of the Agent and trajectory evaluation page

Build: `python3 mk_inputs.py <scratch>` (reads the downloaded τ²-bench trajectory files and the re-grading outputs; writes `inputs/`), `python3 mk_data.py` (writes `parts/21_js_data.js`), then `sh build.sh` (writes `../index.html`).
Re-grading (done once, 2026-10-04): clone github.com/sierra-research/tau2-bench at 5bfa7e3, `uv sync`, then from its folder `uv run --with websockets python ../regrade.py ../gpt52_airline.json` (and telecom), `../null_env.py ../gpt52_retail.json`, `../dbdiff.py <file> 29:1 0:3 12:1 31:1` (and the Opus file 29:2). The trajectory files (13 to 20 MB each) stay out of the repository; URLs in `mk_inputs.py`.
Checks: `python3 recompute.py` (writes `recompute.json`), then from the repo root `node .../src/check_stages.mjs` (the three 3D stages: autoplay in view, every step, list lengths, off-screen and reduced-motion stillness, splits, step-list numbers against the data), `node .../src/checks/check_ui.mjs` (every control at 390 dark and 920 light, every closed block opened; the trial stepper opens on its last step and never moves by itself; compares the page's computations, the failure taxonomy and the 160 matcher verdicts with `recompute.json`; OK, 946 actions on 2026-10-24), `sh html_utils/checkpage.sh <folder>` (fail=0, emdash 0, errbox 1, clipped 0) and `python3 html_utils/ledger.py check <folder>` (problems 0).

Shape: `.claude/skills/explainer-page/page-kinds/topic-child.md` (child page), rebuilt 2026-10-24 to `teaching/teaching-contract.md`. Reading: the core idea and a hero figure, You need, new terms; then one screen, the stepped trial, outcome, actions, steps (with the path-matcher grid), judges, reliability (pass^k), failure taxonomy, environments, hacking, cost, what to log, building a suite. Departure: public agent benchmarks are linked, not covered (owned by Topic: benchmarks' Agentic page); the real data is the same τ²-bench release that page uses, but here re-graded (three graders, do-nothing agent, path matchers) rather than for pass^k.

Parts: `01_head`, `02_css`, `02_split` (template), `10_header`, `20_read_a` to `_e`, `30_tab_grade`, `39_tab_more`; JS `21_js_data` (generated), `21_js_rd_common` (the skill template, `window.RD`), `22_js_calc` (all derived numbers, window.ATJ_OUT, including `fail_tax`), `23_js_anim` (the stepped trial, its own controller: a reader-driven widget that opens on its last step and never autoplays), `24_js_inline` (task strip), `25_js_s3` (renderer v2 template), `25_js_viz` (the eight 2D Reading figures as SVG), `26_js_sc_hero`, `27_js_sc_diff`, `28_js_sc_pk` (the 3D stages), `31_js_grade`, `33_js_match` (the matcher grid, now in Reading), `99_js_tabs` (the skill template, key `kb-agent-traj-tab`).
