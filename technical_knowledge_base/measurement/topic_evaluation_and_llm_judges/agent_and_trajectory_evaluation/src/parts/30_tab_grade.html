Three graders, 400 trials

Every trial of the two released τ²-bench airline runs (GPT-5.2 high and Claude Opus 4.5 high, 50 tasks, 4 trials each), graded five ways. The question: how much does the verdict depend on which grader you chose?

Message judge
τ²-bench's natural-language assertions, graded by an LLM over the transcript and stored in the files; pass if all are met (not part of the airline reward)
Final state
The database equals the gold database (τ²-bench's DB check)
Gold actions
Every gold action, reads included, was called with the same arguments (τ²-bench's action checks); tasks without gold actions have no verdict
Write audit
Computed here: every gold write call present with identical arguments, and no other write
Reward
The recorded reward (final state and required information)

Pass rate under each grader

Where two graders disagree

Try: Final state against Message judge, then the cell where the judge passes and the state fails; open a trial. Then switch Tasks to "No change is right" and compare Final state with Gold actions.
