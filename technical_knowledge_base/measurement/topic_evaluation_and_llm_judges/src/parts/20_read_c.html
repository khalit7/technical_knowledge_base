Statistics in brief: how noisy is a reading?

An eval score is a mean over a sample of items, so it has a standard error like any other measurement. Most reported "regressions" are smaller than it.

Take a golden set of 200 pass/fail items with the champion passing 70%, and a challenger scoring 68%. The standard error of one score is √(0.7 × 0.3 / 200) = 3.2 points. Comparing two independent scores, the error of the difference is √2 times that, 4.6 points, so the 95% interval on the 2-point drop runs from about −11 to +7. The drop is noise.

Derived: standard error √(p(1 − p)/n) at p = 0.70, n = 200; difference of two independent scores √2 times that; paired difference √((d − Δ²)/n) for a fraction d of items where the two models disagree, here d = 10% (an illustrative assumption: measure yours). 95% intervals are ±1.96 standard errors. Items needed to detect 2 points at 95% confidence with 80% power: (1.96 + 0.84)² × variance / 0.02².

Three habits buy most of the sensitivity back without buying more labels:

  • Pair the comparison. Score both models on the same items and test the per-item differences (McNemar's test for pass/fail). Item difficulty is shared, so it cancels: only the items where the models disagree carry information. In the chart, pairing halves the interval; it still does not make 2 points visible on 200 items.
  • Resample when decoding is random. The same model scores differently run to run; a few samples per item (K = 3 to 5) separate item noise from sampling noise.
  • Count your tests. Items built from one template or document are not independent (use clustered standard errors), and gating 20 slices at p < 0.05 trips one by chance about two times in three (1 − 0.95²⁰ = 64%).

The rule that follows: state each gate's minimum detectable effect next to its threshold. On these assumptions a 200-item gate detects a drop of about 6 points paired (13 unpaired), not 2, and that is fine as long as nobody reads it as more.
