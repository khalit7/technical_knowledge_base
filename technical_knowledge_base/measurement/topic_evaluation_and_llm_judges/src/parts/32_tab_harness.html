Same model, many harnesses

"MMLU 64%" is not a measurement until you know the harness that produced it. One MMLU item, read two ways

A harness can ask the model for probabilities of the four answer letters and take the largest (the loglikelihood way, what the original MMLU code and lm-eval-harness's mmlu task do), or let the model write an answer and parse a letter out of it (the generative way, what HELM, Inspect and every chat API evaluation do). The first can never produce an invalid answer; the second can, and every parser decision becomes part of the score. Rule
Two scores are comparable only when every knob in this table matches, or when the gap is measured on the same items with only the knob in question changed. Agreement is possible: Llama 3 8B scored 66.7 (Meta), 66.70 (Open LLM Leaderboard) and 66.76 (HELM) because all three used 5 shots and a letter answer.
