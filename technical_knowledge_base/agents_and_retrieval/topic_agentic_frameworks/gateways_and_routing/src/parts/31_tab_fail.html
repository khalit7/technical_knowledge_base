How it was recorded
The fake providers are one small Python HTTP server each (src/code/fake_provider.py), scripted per case to answer, fail with a status or hang; each logs every call it receives with its start and end time and the request's text, which names the case and request number, so every attempt is matched to its request. Router cases: src/code/e2_failures.py (LiteLLM 1.104.0, sequential requests 0.3 s apart, a warm-up first because the first failing call in a fresh process paid about 10 s of one-off set-up in a trial run). Retry layers: src/code/e3_amplify.py (openai 2.54.0 against the proxy).
