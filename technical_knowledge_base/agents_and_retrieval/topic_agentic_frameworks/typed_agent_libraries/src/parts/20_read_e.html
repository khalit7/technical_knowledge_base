5. Handoffs and transfers are tools

A handoff passes the whole conversation to another agent, which then owns it. Neither library adds new machinery for it. In the Agents SDK each agent in handoffs=[...] becomes a tool named transfer_to_ plus the agent's name, described as "Handoff to the name agent to handle the request." plus its handoff_description (handoffs/__init__.py, line 214); its output is {"assistant": "fixer"}, and the next request goes out with the new agent's instructions and tools and, by default, "the entire previous conversation history" ({{handoffs docs|https://openai.github.io/openai-agents-python/handoffs/}}). In ADK an agent with sub_agents gets one transfer_to_agent(agent_name, transfer_reason) tool whose agent_name is an enum of the valid names, so the model cannot invent one (tools/transfer_to_agent_tool.py): one tool instead of one per target.

Recorded. Agents SDK: a triage agent with two handoffs (a fixer with the four tools, an explainer with read-only tools); greedy and sampled runs both took 6 requests, request 1 called transfer_to_fixer, and the next request carried the fixer's instructions and tools with all 4 messages so far; last agent fixer, tests still fail. ADK: the coordinator's first request offered only transfer_to_agent; request 1 called transfer_to_agent({"agent_name": "fixer"}), and later requests carried the fixer's tools; tests still fail.

Two source details matter once a reply can hand off to more than one agent: if the model calls several handoff tools in one reply, only the first runs and the others get "Multiple handoffs detected, ignoring this one." (run_internal/turn_resolution.py); an input_filter can cut the history, and the opt-in nest_handoff_history (off by default, "Opt-in beta") summarises it, with the warning that "Nesting does not redact sensitive data" (run_config.py, line 378). What handing off costs against calling an agent as a tool (a two-problem message lost its second problem after a handoff) is measured in section 6 of {{Multi-agent patterns|n:3c65c17b0d0d8194a306c37803387bf3}}, which owns when several agents help.
