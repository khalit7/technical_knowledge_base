## What was run (6 October 2026)
- **Versions**: pydantic-ai-slim 2.54.0, openai-agents 0.23.1, smolagents 1.26.0 (openai 3.24.0) in one venv; google-adk 2.11.0 with litellm 1.104.0 and a2a-sdk 1.2.2 in another (litellm 1.104.0 requires openai < 3); outlines 1.3.3 with mlx 0.32.3 and mlx-lm 0.32.0 in a third. Same versions as the parent's Same agent tab.
- **Local model**: mlx-community/Qwen3-4B-Instruct-2507-4bit on `mlx_lm.server` 0.32.0 (shared server on the coordinating machine, Apple M1 Pro 16 GB), reached through `code/proxy.py`, a logging proxy that holds the shared request lock around every call so no two prompts are batched. Labelled "local model" on the page and never compared with Claude as the same model. The server was shared with other agents: wall times are not reported.
- **Structured output** (`code/common.py`, `code/run_lib.py`, `code/run_adk.py`, `code/run_outlines.py`, `code/run_claude.py`, `code/drive.sh`): ten cases from `code/make_cases.py` (small modules written for the page, real `python3 -m unittest` output; `inputs/cases.json`), result type `Triage`. Local routes at library defaults: one greedy pass (temperature 0) and two at 0.7 (temperature set by the proxy on every request). Outlines: same weights in-process, the system text of Pydantic AI's prompted-output template copied verbatim, free and constrained, same three passes (seeded). Claude: `claude -p` with built-in tools off, Haiku 4.5 and Sonnet 5.5, once per case, schema in the prompt vs `--json-schema`.
- **Validator demo** (`code/run_validator.py`): Pydantic AI tool output plus an output validator with typed deps, `retries=2`, same cases and passes.
- **Mechanisms** (`code/oai_demo.py`, `code/adk_demo.py`, `code/drive_demo.sh`): Agents SDK handoff (greedy and one sampled), input guardrail parallel and blocking, SQLite session, default tracing with no key; ADK on the running example (`scratchpad/agents/task_repo` copied fresh per run; greedy plus three sampled), ADK transfer with two sub_agents, ADK `to_a2a` agent card (in-process, no model). Tests are re-run by the driver after each run and the test file compared with the original.
- **No-model probes**: `code/schemas.py` (each library's schema for one function), `code/smol_exec.py` (LocalPythonExecutor on benign snippets), a FunctionModel probe of Pydantic AI argument validation (recorded in the notes below).

## Housekeeping on the runs (said here so the counts can be checked)
- The library routes got one sampled pass, not two as planned: the shared server stalled for 16 minutes on one request (74 output tokens in 958 s) while other agents queued, so the second sampled pass was cancelled. Outlines (in-process, before the server was busy) and the validator demo got two sampled passes.
- One stray request from a validator run killed after a path bug (temperature 0.7, logged into the greedy file) was removed from `wire_pai_validator_greedy.jsonl` and that case's call count corrected from 2 to 1.
- The first guardrail demos gave the checker agent a typed `output_type`; on this server that failed on every request (`ModelBehaviorError`, Reading section 2), so the checker was changed to answer YES or NO in text and both demos rerun. The failed files stay in the scratch area.
