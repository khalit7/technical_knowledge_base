7. What memory costs

A memory layer moves cost from every answer (no long history in the prompt) to every conversation (model calls to write the memory), and adds a search before each answer. The table counts what the runs here spent; Claude figures are the CLI's API-price equivalent at Haiku 4.5 list prices (the subscription paid), local-model figures are tokens and seconds on a shared, busy M1 Pro and are only comparable with each other.

break-even sessions ≈ write cost per session / (history tokens saved per answer × answers per session × input price)

At this page's size (about 1,400 tokens of history) pasting everything is cheaper than any memory layer for a long time. The vendors' own numbers make the same point at their scale: Mem0's paper puts full context at 26,031 tokens per LOCOMO conversation against 1,764 for Mem0, and Zep's at about 115K against 1.6K on LongMemEval; the saving only appears once history is tens of thousands of tokens and is read many times.
