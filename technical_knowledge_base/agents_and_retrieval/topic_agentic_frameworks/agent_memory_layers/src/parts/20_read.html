The page in one screen

A model forgets everything between calls. Inside one session the harness resends the conversation; when the session ends, so does the memory. A memory layer is a store outside the context window with two policies: a write policy (after a conversation, what to keep, and what to do with what it contradicts) and a read policy (before an answer, what to put back into the prompt). Three designs dominate, each sold as a product:

Facts (Mem0)

A model turns each conversation into short sentences ("User's tests run with pytest"); a search over those sentences picks the ones to show. Cheap to read, easy to inspect. Since April 2026 the open-source library only ever adds: a changed fact becomes a second sentence beside the old one.

Temporal graph (Zep, Graphiti)

A model turns each conversation into entities and dated relations between them; a newer relation that contradicts an older one closes the older one's validity window instead of deleting it. Built for "what changed, and when".

Paging (Letta, MemGPT)

The model itself manages its memory with tools: a small block that is always in the prompt, plus archives it writes to and searches, like an operating system moving pages between RAM and disk. Nothing is stored or found unless the model decides to.

All three were run here on the same twelve invented conversations between a user, Sam, and an assistant (the parent topic's four sessions, extended), then asked 25 questions of the kinds LongMemEval tests. Every memory, edge, tool call and answer below is MEASURED from those runs; the table fills from the recordings.

Three corrections to what the parent pages and the old notes say
(1) Mem0's update step as the parent root describes it (ADD, UPDATE, DELETE, NOOP; its Production stack tab implements exactly that) is the 2025 paper and Mem0 1.x; the open-source library since v2.0.0 (16 April 2026) is "single-pass, ADD-only" ({{release notes|https://github.com/mem0ai/mem0/releases/tag/v2.0.0}}), measured below. (2) The Letta server that implements MemGPT's memory blocks, archival and recall memory was archived on 16 August 2026; the PyPI name letta now installs Letta Code, whose memory is a git-backed folder of Markdown files ("MemFS"). (3) Mem0 has no "layers (conversation, user, organisation) with promotion between layers", as the old Notion page said: it scopes memories by user_id, agent_id and run_id, and nothing is promoted ({{docs|https://docs.mem0.ai/core-concepts/how-it-works}}).
