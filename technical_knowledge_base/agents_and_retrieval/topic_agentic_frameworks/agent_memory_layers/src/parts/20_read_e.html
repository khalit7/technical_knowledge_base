5. The experiment: twelve sessions, 25 questions

Setup. Sam's history is the parent root's four sessions ({{Production stack|n:3c65c17b0d0d81ab8432c54d65b7f8c7}} tab, copied verbatim) with eight more added between and after them: small talk about a cat, a hiking weekend, an incident, budget numbers, an outage, a talk outline, and three facts that change twice. Assistant turns are fixed text, so every system saw exactly the same history; it is invented, written for this page, and about tokens long. All 25 questions were asked "on" 6 October 2026. The question set is small and the conversation short, so read every number below as a demonstration of mechanisms, not as a benchmark score.

Two measurements per answer. Evidence reached the prompt: did the text the memory put in front of the reader contain the words the answer needs (for "how many fallbacks in total", both 37 and 12)? This needs no model and isolates the write and read policies. Right: did the answer contain the reference answer (keyword rules per question, every answer readable on the {{Memory lab|#t-lab}} tab; abstention questions pass when the answer says it does not know or corrects the false premise). Two readers answered from the same memory text: Claude Haiku 4.5 and the local Qwen3-4B, with one instruction for every system: answer from the memory, or say you don't know.
