Depth: interview rehearsal

Nine questions this topic should let you answer (closed; answer aloud first, then open each)
Workflow or agent: define both and say when you pick each.
A workflow runs model calls along code paths you wrote; an agent lets the model choose each next step until it stops. Pick a workflow when steps are known and cost, latency and audit matter; an agent when the steps depend on what is found.
What does LangGraph give you that a while loop does not?
State saved after every step under a thread id: resume after a crash, human interrupts of any length, replay or fork from an old step, plus merge rules for parallel branches. Nothing else that a loop cannot do.
How do you get reliable structured output from a model?
Offer the schema as a tool or use constrained decoding, validate the result against the schema in code, and on failure send the validation error back for a bounded number of retries, counting them as a metric.
Your agent must wait two days for a manager's approval. Design it.
Checkpoint state to a durable store under a thread id; the approval request carries the id; exit; on approval, a worker reloads and resumes. Side effects after the approval only, or idempotent. A supervisor or queue restarts failed resumes.
When does multi-agent help?
Breadth-first reading that exceeds one context (research, search, review) with independent subtasks and a value that justifies several times the tokens. Not for one artifact many agents would write.
What does a gateway do and what can go wrong with fallbacks?
One endpoint, keys, budgets, rate limits, retries, fallbacks, logging. A fallback model that was never evaluated degrades quality silently; eval every model in the chain and tag traces with the model that answered.
What is in a trace of an agent run?
A root span for the run, child spans per model call (model, tokens, cost) and per tool call (name, arguments, result, error), nested subagent subtrees, all with timings, ideally with OpenTelemetry GenAI attribute names.
Fact memory or temporal graph?
Facts (Mem0 style) are compact and simple; a temporal graph (Zep style) keeps when each fact was true, so it can answer "what was true in March" and supersede instead of overwrite. Paging (Letta) lets the agent manage its own context. The measured comparison is on Context engineering, section 8.
Build, adopt a framework, or buy a hosted runtime?
Build when the loop is your product or must run in an unusual place; adopt a framework for durability or typing you would get wrong; buy when you do not want to operate sandboxes and sessions and accept the vendor's control flow, models and trace export.
