The topic in one screen

You have a model API and a job to automate. What do you build it from? The sibling topic, {{Topic: agentic-harnesses|n:3c65c17b0d0d81d881a8fe98b4cff7bb}}, takes a finished agent apart: the agent loop (call the model, run the tool it asks for, show it the result, repeat until it stops), tools, context, permissions. This topic is about the parts you assemble when you build your own: the libraries that run the loop or a fixed sequence of calls, the gateway in front of the model providers, the tracing that tells you what happened, and the memory that outlives one conversation.

Four layers, with one axis through all of them. A framework here is any library that writes some of this for you. Click a layer.

Your application: the job (a ticket, a request, a test run)
Model providers (Anthropic, OpenAI, Google, open models you serve)

The axis: how much of the loop do you own? At one end you write every model call and every if yourself; at the other a vendor runs the whole loop on its servers and you send a task. Every framework is a position on that line, and moving right buys features with control. Pick a position to see who writes each piece.

The running example. Both agent topics use one job: a tiny Python library, textstats, with two planted bugs (the tokenizer splits don't into don and t; top_words does not break ties alphabetically) and a test file that catches both. The prompt, word for word: "The tests in this repository fail. Find out why and fix the code so they pass. Do not edit the tests." Three tabs run it for real: the {{Same agent, six ways|#t-same}} tab builds one agent in a plain loop and five frameworks; the {{Orchestration lab|#t-orch}} runs Anthropic's five workflow patterns, a free agent, a crash-and-resume and a multi-agent split; the {{Production stack|#t-ops}} tab puts a gateway, tracing and memory around it. This tab gives the intuition and links them.

The one idea to keep
A framework is worth its weight only when it gives you something you would otherwise build by hand and get wrong: saved state you can resume, a human pause, typed results, traces. For the running example, two plain model calls glued by 20 lines of script fixed the visible tests in 19.4 s for $0.013, and a free agent did it in 24.8 s for $0.030 MEASURED. Neither needed a framework. Start there, and add one when a section below names a need you have.
