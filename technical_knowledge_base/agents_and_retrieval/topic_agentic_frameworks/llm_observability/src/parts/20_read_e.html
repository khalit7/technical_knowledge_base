Common mistakes

Turning on client auto-instrumentation and calling it agent tracing
It gives one trace per model call (section 3). Add the invoke_agent and execute_tool spans yourself or use a framework that does.
Reading Anthropic's input_tokens as the input size
It excludes cache reads and writes. On our first Claude Code call it was tokens out of . The GenAI value is the sum (section 2).
Trusting a backend's cost without reconciling it
Our first two Langfuse totals were $0 and 16% short, both silently (section 6). Compare with a second source on every model you use.
Error-based tail sampling on agent traces
Successful runs have ERROR spans; long runs outlive decision_wait. Decide on the root's outcome after the root arrives (section 7).
Assuming content is off by default
The conventions say opt-in; four of the five instrumentation libraries we ran capture it by default, and Claude Code adds the account e-mail to every span regardless (section 8).
Redacting with a deny-list only
Patterns catch what you anticipated. The login name in ls -la output got through ours. Allow-list keys for anything leaving your network.
Not noticing lost telemetry
Exporters drop data on errors and print a warning; the application carries on (section 4). Monitor the exporter or the collector's own metrics.
Double-counting usage on parent spans
If the agent span carries the run's total tokens under the same names as the model spans, a backend that sums all spans counts them twice. Pydantic AI writes the totals on its agent span as gen_ai.aggregated_usage.* for this reason (its use_aggregated_usage_attribute_names setting, default on).

Interview questions

What is the difference between a trace, a span and an event?
A trace is one run (all spans sharing a trace id); a span is one timed operation in it with a parent, attributes and status; an event is a timestamped record inside a span (Claude Code puts tool output in a tool.output event).
How do you get one trace across your app, an agent subprocess and the tools it runs?
Propagate W3C trace context: inject traceparent into the child's environment or headers and extract it there. Claude Code reads TRACEPARENT in -p and SDK sessions and passes it to Bash subprocesses (section 1).
Which GenAI attributes are required on a model-call span, and which do you need for cost?
Required: gen_ai.operation.name and gen_ai.provider.name (model if available). For cost: the model and the token counts by kind (input including cache, cache read, cache write, output) plus the cache lifetime where prices differ.
Head or tail sampling for agents?
Tail, deciding on the root span's outcome shortly after the root arrives, plus a small random share; count with metrics computed before sampling.
How do you keep personal data out of traces?
Content off by default, on per environment; SDK masking; a collector with an allow-list of keys (or keyed hashing where you need joins) before data leaves your network; short retention and access control where full content is kept.
Your trace tool says a run cost $0.035 and the bill says $0.042. Where do you look?
Token kinds and prices: cache writes priced at the wrong lifetime (our case), cache reads counted as fresh, a model name that does not match a price entry, or missing spans (sampled or lost).
What does an online evaluator add over tracing?
Quality: a trace shows what happened; a score says whether it was good. Scores catch soft failures that end with status OK, drive sampling and alerts, and select traces to promote into the regression set.
Langfuse or LangSmith?
Langfuse if you need to self-host without an Enterprise contract or want MIT; LangSmith if LangGraph is your runtime and a hosted service is fine. Instrument with OpenTelemetry either way.
