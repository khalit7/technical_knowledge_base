Corrections to the old version of this page (checked against primary sources on 6 October 2026)
  • "the v3 stack: Postgres + ClickHouse + Redis + S3": Langfuse is on version 4 (GA 17 Aug 2026), same four stores, observations-first storage and OpenTelemetry-only ingestion; v3 gets security fixes until the end of January 2027.
  • "Langfuse calls span-tree nodes observations (span/generation/event)": there are now ten observation types, including agent, tool, chain, retriever, evaluator, embedding and guardrail.
  • "Arize Phoenix: open source": Elastic License 2.0, source-available. It now also ingests GenAI-convention spans directly (since May 2026).
  • "LangSmith ... tracing arbitrary code means adopting their SDK anyway": LangSmith accepts OpenTelemetry at /otel/v1/traces; the SDK is optional.
  • "OpenAI's Agents API and Anthropic's Managed Agents both ... since September 2026": Managed Agents entered public beta on 8 April 2026; the Agents API on 10 September 2026. The Agents API exports OTLP JSON traces; for Managed Agents we found an event log, not OpenTelemetry.
  • "Native LiteLLM integration: point the proxy's logging callback at Langfuse": still true, but it now goes through OpenTelemetry, and LiteLLM recommends the langfuse_otel callback.
  • OpenLLMetry is still Apache 2.0, but Traceloop now belongs to ServiceNow (2026).
  • Claude Code 2.1.274's effort span attribute and managed-settings event: confirmed (September 2026).
