Super-step lab: seven graphs, every phase, every channel

Each graph below was compiled and run on langgraph 1.2.14 with an InMemorySaver; the frames are built from what the run left behind (every checkpoint's channel values, versions and versions_seen, every task's start and finish event) MEASURED. No model is involved: nodes are plain functions, so the traces are exact. Pick a graph and step through it; the before/after pairs are "with and without a reducer" and "plain edges against a join".

How to read it

  • Plan (amber outline): the nodes whose trigger channel has a version above the one recorded for them in versions_seen. The trigger of a node reached by a plain edge is branch:to:<node>; a wait-for-all edge uses one join:a+b:node channel, which becomes available only when every source has written.
  • Execute (filled blue): the tasks of this super-step and their pending writes. Each task saw the state as of the start of the step.
  • Update: all writes applied in task-path order through each channel's reducer; changed rows are highlighted; versions go up; a checkpoint is saved. The counters count node executions and saved checkpoints.
  • Version numbers here are the integer part of LangGraph's version strings (it uses a counter plus a random suffix); only their order matters.
