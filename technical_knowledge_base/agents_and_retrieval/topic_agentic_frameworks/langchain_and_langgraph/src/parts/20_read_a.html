The page in one screen

LangChain is a Python (and TypeScript) library of building blocks for model applications: one interface for every provider's chat model, tools, and since version 1.0 a ready agent loop, create_agent, customised with middleware (code that runs before or after each model or tool call). LangGraph is the runtime underneath: you describe a program as a graph of steps (nodes) that read and update one shared state, and LangGraph runs it in rounds called super-steps, saving a checkpoint of the state after each one. The 1.0 announcement put the split in one line each: LangChain is "the fastest way to build an AI agent", LangGraph "a lower level framework and runtime, useful for highly custom and controllable agents" ({{LangChain, 22 Oct 2025|https://www.langchain.com/blog/langchain-langgraph-1dot0}}).

The reason to use LangGraph rather than the thirty-line loop of the {{Topic: agentic-frameworks|n:3c65c17b0d0d81ab8432c54d65b7f8c7}} Reading tab is almost entirely the checkpoint: it is what lets a run survive a crash, wait days for a person, and be rewound. So this page spends most of its time on what a checkpoint holds and what it does and does not save you from, measured.

    1. LangChain: three eras, and what is still useful

    LangChain began as one package that wrapped everything: prompts, chains of calls, agents, retrievers, hundreds of integrations. It was then split into a small stable core plus integration packages, and in October 2025 cut down to an agent library on top of LangGraph. The dates, from the repositories, PyPI and LangChain's own posts:

    • 24 Oct 2022First commit by Harrison Chase ({{GitHub|https://github.com/langchain-ai/langchain/commit/18aeb72012}}); version 0.0.1 on PyPI the next day.
    • 4 Apr 2023$10M seed led by Benchmark ({{LangChain|https://www.langchain.com/blog/announcing-our-10m-seed-round-led-by-benchmark}}).
    • 1 Aug 2023LCEL, the LangChain Expression Language: chains composed with the | operator, "a declarative way to truly compose chains" ({{LangChain|https://www.langchain.com/blog/langchain-expression-language}}).
    • 9 Aug 2023First LangGraph commit, by Nuno Campos ({{GitHub|https://github.com/langchain-ai/langgraph}}).
    • 12 Dec 2023The split: langchain-core (interfaces and LCEL) and langchain-community (third-party integrations) ({{LangChain|https://www.langchain.com/blog/the-new-langchain-architecture-langchain-core-v0-1-langchain-community-and-a-path-to-langchain-v0-1}}); provider packages such as langchain-openai followed.
    • 6 to 8 Jan 2024langchain 0.1.0, the first stable version ({{LangChain|https://www.langchain.com/blog/langchain-v0-1-0}}).
    • 8 to 17 Jan 2024LangGraph on PyPI (0.0.8) and announced: "a module built on top of LangChain to better enable creation of cyclical graphs, often needed for agent runtimes" ({{LangChain|https://www.langchain.com/blog/langgraph}}).
    • 29 to 30 Jul 2025Deep Agents: planning tool, subagents, a file system and a detailed prompt, on LangGraph; now "The batteries-included agent harness" ({{LangChain|https://www.langchain.com/blog/deep-agents}}, {{README|https://github.com/langchain-ai/deepagents}}).
    • 13 to 17 Oct 2025"LangGraph Platform is now LangSmith Deployment and LangGraph Studio is now LangSmith Studio" ({{LangSmith changelog|https://docs.langchain.com/langsmith/changelog}}).
    • 20 Oct 2025$125M Series B at a $1.25B valuation, led by IVP ({{LangChain|https://www.langchain.com/blog/series-b}}).
    • 22 Oct 2025LangChain 1.0 and LangGraph 1.0 announced together (wheels on PyPI since 17 Oct); "no breaking changes until 2.0"; create_agent "uses LangGraph under the hood"; legacy chains, retrievers and indexes moved to langchain-classic ({{LangChain|https://www.langchain.com/blog/langchain-langgraph-1dot0}}, {{migration guide|https://docs.langchain.com/oss/python/migrate/langchain-v1}}).
    • 10 Mar 2026LangGraph 1.1: an opt-in version="v2" output format (typed stream parts; invoke returns an object with .value and .interrupts) ({{release notes|https://github.com/langchain-ai/langgraph/releases}}).
    • 12 May 2026LangGraph 1.2: per-node timeouts, node error handlers, graceful shutdown, DeltaChannel (beta) and event streaming (beta) ({{1.2.0a6 notes|https://github.com/langchain-ai/langgraph/releases/tag/1.2.0a6}}).
    • 6 Oct 2026langgraph 1.2.14, the version measured here (PyPI, released that day). No 2.x of langchain, langchain-core or langgraph exists.

    What remains useful from LangChain today is the thin layer: one chat-model interface across providers (init_chat_model("provider:model") or a class such as ChatOpenAI), message types, the @tool decorator that turns a typed Python function into a tool schema, and create_agent with middleware (section 9). The old chains and retrievers still import from langchain-classic; langchain-community never reached 1.0 (0.4.2, May 2026, {{PyPI|https://pypi.org/project/langchain-community/}}). LangGraph does not need LangChain at all: its README says it "can be used without LangChain", and every graph in sections 2 to 8 imports only langgraph.

    How widely used. In the 30 days to 6 October 2026, langgraph was downloaded 44,769,952 times from PyPI and langchain 170,457,766 times (against 12,449,784 for openai-agents and 2,442,764 for crewai) ({{pypistats|https://pypistats.org/packages/langgraph}}). Downloads count CI runs and installs pulled in as dependencies, so they measure reach, not use. Uber ({{Finch, 17 Jul 2025|https://www.uber.com/us/en/blog/unlocking-financial-insights-with-finch/}}) and LinkedIn ({{SQL Bot, 9 Dec 2024|https://www.linkedin.com/blog/engineering/ai/practical-text-to-sql-for-data-analytics}}) describe LangGraph systems on their own engineering blogs; Klarna and Replit appear only in LangChain's case studies (vendor claims). AWS's open-source blog introduced Pizza Bot, an inbox for background agents built on Deep Agents and LangGraph, on 10 September 2026, and says it "is a community project rather than an AWS service" ({{AWS Open Source Blog|https://aws.amazon.com/blogs/opensource/introducing-pizza-bot-an-open-source-inbox-for-ai-agents-that-work-in-the-background/}}).
