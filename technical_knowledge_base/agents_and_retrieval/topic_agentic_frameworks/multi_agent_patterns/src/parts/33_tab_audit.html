How the runs were made

  • Every run: claude -p <task> --output-format stream-json --verbose --no-session-persistence --setting-sources project --strict-mcp-config --model haiku in a fresh copy of the corpus; the answer key was never in the agent's folder. Claude Code 2.1.291 on 6 October 2026.
  • One agent: --tools "Read,Grep,Glob". Lead + 6 auditors: --tools "Read,Grep,Glob,Agent", an auditor subagent defined with --agents (tools Read, Grep, Glob; model haiku) and --forward-subagent-text so the subagents' messages are in the recording; the lead was told to split into six groups of eight and start all six in one message. Fan-out: six --tools "" calls started together by a Python script, each with eight modules pasted in. Blackboard: six agents with --tools "Read,Bash" and --allowedTools "Bash(python3 board.py:*)"; board.py claims a module with an exclusive file create (so two agents can never claim the same one) and appends findings to a shared file. The check round: six more agents claim findings to check, never their own.
  • Check only: the 186 findings posted by "Blackboard 2" copied onto a fresh board and checked by six new agents, shown the auditor's reason or blind (file and function only). Sharp brief: the blackboard with one extra sentence in the task and the agents' instructions: "Only these eight kinds count: a default value, a unit, an ordering, a bound (inclusive or exclusive), missing-key behaviour, a number of attempts, a scale (fraction or percentage), case handling. Do not report missing input validation, exceptions the code does not raise, thread safety, or results that are wrong only for impossible inputs (for example hits greater than total)."
  • The modules are about 528 KB; the repository copies of the recordings replace module text with a placeholder (size kept), because src/code/gen_audit.py regenerates it exactly. Everything the models wrote is kept.
  • Several of this page's experiments ran at the same time on one subscription, and other agents were using it too: wall times are real but include queueing. The extreme case is "Blackboard + blind check 1": four of its six agents waited about 16 minutes for their last model call after the board answered DONE; nothing in the recording explains the wait, so read that run's wall time as an outlier.
