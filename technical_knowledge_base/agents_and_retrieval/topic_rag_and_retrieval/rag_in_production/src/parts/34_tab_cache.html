Cache lab: what a semantic cache serves on SciFact's claims

The @@c_n@@ labelled SciFact claims (of the 1,109 train and test claims, those whose text matches exactly one query in BEIR's query file; @@rc_n@@ of them are test claims) arrive one by one in id order. Each is looked up in a cache holding every earlier claim: if the most similar earlier claim (cosine of the setup's precomputed query embeddings, with each model's query prompt) reaches the threshold, the cached answer is served. It is right only if the cached claim has the same verdict on the same abstract. measured here, deterministic.

Kinds of hit: same verdict: the cached claim shares an evidence abstract with the same label (the cached answer is right); opposite verdict: same abstract, opposite label (the cached answer is wrong); no verdict, same abstract: both claims cite the same abstract and neither has evidence ("not enough information"; arguably right); unrelated: no abstract in common (wrong).
