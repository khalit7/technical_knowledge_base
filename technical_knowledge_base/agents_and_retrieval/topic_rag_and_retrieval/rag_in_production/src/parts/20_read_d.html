Whatever the layout, the tenant id comes from the authenticated session, every cache key includes it (section 8), and a test suite asks each tenant's questions as another tenant and expects nothing back.

Time to first token rises linearly with the prompt

Reranker cost is per pair. A cross-encoder reads each (query, passage) pair, so its cost is K times one pair: the setup measured 228 to 237 pairs per second for the 22 M MiniLM cross-encoder, 14.5 for bge-reranker-v2-m3 and 5.0 for Qwen3-Reranker-0.6B on MPS, so reranking 30 candidates costs about 0.13 s, 2.1 s and 6 s (rates from the root's running example; latencies derived as 30 ÷ rate). On a server GPU all three are far faster (not run here); the ratios hold.

The tail, not the median. When a request fans out to many shards or services and waits for all of them, a rare slow response becomes a common slow request: Dean and Barroso's example is a server with 1 request in 100 taking a second, where a request touching 100 such servers is slow 63% of the time (The Tail at Scale, CACM 2013, published). Their remedies (hedged requests, sending a second copy after the 95th-percentile wait; tied requests; micro-partitions) apply to sharded vector search unchanged. Report every stage at p50, p95 and p99.

Prefix caching. A model server can keep the attention keys and values (the KV cache) of a prompt's beginning and reuse them for the next request that starts with the same tokens. In RAG the passages differ per question, so the reusable prefix is what comes before them: system prompt, tool definitions, few-shot examples. Put stable text first and per-request text last. What transfers. The shape: generation dominates, prefill grows linearly with retrieved tokens, reranking scales with K times the per-pair cost, and embedding and search are tens of milliseconds or less at this collection size. Not the milliseconds: a datacenter GPU serves the same models many times faster, and a server batches concurrent requests, which raises throughput and changes per-request latency (not run here).
