5. Communities: Louvain, Leiden and the hierarchy

A community is a set of nodes more densely linked to each other than to the rest. GraphRAG summarises communities, so "what is this corpus about" becomes "what is each community about". A partition is scored by modularity: the edge weight inside communities minus what a random graph with the same degrees would put there.

Q = (1 / 2m) Σij [ Aij − γ ki kj / 2m ] δ(ci, cj)
Aij
edge weight between nodes i and j
ki
total edge weight at node i (its degree)
m
total edge weight of the graph
γ
resolution: higher gives more, smaller communities (graphrag uses 1.0)
δ
1 when i and j are in the same community, else 0

Louvain (Blondel et al. 2008) maximises Q greedily: move each node to the neighbouring community that raises Q most, collapse each community into one node, repeat. Its flaw: a node that held a community together can move out, leaving the rest disconnected. Leiden (Traag, Waltman and van Eck 2019) adds a refinement phase between moving and collapsing, in which each community is re-split from singletons and nodes may only join well-connected sub-clusters; it guarantees connected communities.

The Leiden paper found Louvain leaving "up to 25% of the communities ... badly connected and up to 16% ... disconnected" on its test networks, the 16% on DBLP after several iterations ({{arXiv 1810.08473 v3|https://arxiv.org/abs/1810.08473}}, abstract and section IV) published. graphrag calls graspologic-native's hierarchical Leiden with max_cluster_size=10, use_lcc=True (keep only the largest connected component) and seed 0xDEADBEEF (resolution 1.0, randomness 0.001): level 0 holds a few big communities, and every one with 10 or more members is split again one level down until none splits. Global search reads one level (default 2): lower levels are fewer, broader summaries.

Two lessons. Pruning is not a detail: only @@full_keep_pct@@ of the phrase nodes survive it, almost all of the cut being phrases seen in one paragraph, which link nothing. And pruning does not cut hubs: it removes only the single highest-degree node, so month names survive among the most connected members of the subset's level-0 communities ("JULY" heads one). Louvain produced no disconnected community on either graph here (Leiden's level 0 none either, by construction): the paper's 16% is an upper range on large networks after several iterations, so Leiden is the safer default, not a rescue every graph needs.
