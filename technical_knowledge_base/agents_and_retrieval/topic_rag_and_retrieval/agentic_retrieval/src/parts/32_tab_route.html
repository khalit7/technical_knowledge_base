Router lab

Build a router from the signals a system has before it generates anything, and see what it buys on the 200 HotpotQA questions. Each question is sent to a cheap path or an expensive path; its score, tokens and seconds are the root Agentic lab's recorded results for that path (Qwen3-1.7B), so every policy is exact, with no new generation. The router's own cost is not counted (the signals come from the search the pipeline makes anyway; the cross-encoder adds under 60 ms: 58 ms for 10 pairs on this laptop, root Pipeline lab).

Try: set the signal to "random" and move the slider: that line is what any router must beat. Then try the cross-encoder's second-best score, and the learned router.

Intervals are 95% bootstrap intervals over questions (500 resamples, fixed seed). The learned router is a logistic regression on 8 query-time signals, 5-fold cross-validated, so each question's probability comes from a model that never saw it (src/scripts/s_router.py). The comparison-word rule is fixed (it escalates the questions containing one), so its share does not move.
