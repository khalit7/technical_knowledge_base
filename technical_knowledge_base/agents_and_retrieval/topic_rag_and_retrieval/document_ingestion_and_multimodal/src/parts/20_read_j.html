9. Skip the parser: retrieve the page image

The problem. Everything so far converts a page to text and loses what text cannot hold: a chart's shape, an infographic's layout, a diagram's arrows. A vision-language model (VLM: a language model that also reads images, by turning the image into a grid of patches, small squares each encoded as a vector) can read the page as a picture. The idea of page-image retrieval is to embed the screenshot of each page and search those embeddings with the text query, with no parsing at all.

ColPali: late interaction over patches

ColPali (Faysse et al., 2024) takes PaliGemma-3B, a VLM, and keeps one 128-dimension vector per image patch instead of one vector per page: 1,024 patch vectors plus 6 for the text prompt, 1,030 per page (paper section 4.1 and footnote 10). A query is also kept as one vector per token. The score is late interaction, as in ColBERT: for each query token, take its best dot product with any patch, then sum over query tokens (MaxSim). A query token for "revenue" can match the patches of a bar label, and "2019" the patches of an axis tick, each on its own. The {{rerankers and late interaction page|n:3f85c17b0d0d813fba53fc883f8a2c8f}} owns MaxSim and ColBERT; this section is what changes when the "document tokens" are image patches.

So the trade is about 18 times less indexing time per page (7.22 s against 0.39 s) for 30 times the vector storage (257.5 against 8.6 KB) and a heavier score. The paper's token pooling (mean-pooling similar patch vectors, pool factor 3) cuts the vectors by 66.7% and keeps 97.8% of the retrieval quality (paper section 5.2, the authors' runs). How to index many vectors per document (PLAID-style compression and candidate generation) belongs to the rerankers page.

Published results on ViDoRe

ViDoRe (Visual Document Retrieval benchmark, from the same paper) pairs text queries with page images; the score is nDCG@5 (normalised discounted cumulative gain over the top five pages). In the paper's Table 2, ColPali averages 81.3 against 65.5 for Unstructured + OCR + BM25 and 67.0 for the best text pipeline (Unstructured + captions written by Claude 3 Sonnet + BGE-M3). The gap is largest on figures (ArxivQA 79.1 against 31.6) and smallest on text-heavy reports (Energy 91.0 against 85.9). These are the ColPali authors' runs, not independent; section 10 reruns the comparison here with a small open model on three of those sets.
