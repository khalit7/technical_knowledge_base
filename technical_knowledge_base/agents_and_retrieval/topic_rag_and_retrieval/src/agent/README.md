# Agentic lab (tab `t-agent` of Topic: rag-and-retrieval)

The tab's parts are `../parts/33_tab_agt_a.html` to `33_tab_agt_f.html` (text and layout; `a` opens the wrapper div and holds the scoped CSS, `f` closes it), `../parts/33_js_agt_*.js` (behaviour) and `../parts/33_js_agt_0data.js` (data, generated by `make_data.py`). Every id and class is prefixed `agt-`; CSS is scoped under `#t-agent`.

Question the tab keeps returning to: who should drive retrieval (a fixed pipeline, a fixed decomposition program, or the model in a loop), and what does each cost in searches, tokens and seconds for what accuracy?

## Setup used

- Multi-hop set: the running example's HotpotQA distractor dev questions (200, seed 0) over its 9,760-paragraph corpus (`../data/README.md`).
- Search tool: bge-small-en-v1.5, exact inner-product search over the setup's precomputed corpus vectors; queries encoded on the CPU (so the search does not share the GPU with the generator). Top 10 for the 200 test questions agree with the setup's recorded run for 199 of 200 (one tie broken differently on CPU). Qwen3-Embedding is not used as the tool because it declares HotpotQA in its training data.
- Generators: Qwen3-1.7B Q4_K_M (unsloth GGUF, the Pipeline lab's file) and Qwen3-4B Q4_K_M (Qwen GGUF), both from the inference topic's model store, in llama-server (Homebrew build 11146, Metal, `-ngl 99 -c 20480 -np 1`), temperature 0, seed 0, thinking off (`enable_thinking: false`), prompt cache on. Ports 8220 and 8221.
- Prompts: chosen on 60 held-out HotpotQA dev questions (the 800 other questions whose paragraphs are in the corpus), never on the 200 (`out/tune.json`).
- Metrics: HotpotQA's official answer normalisation, exact match and F1 (`common.py`), and the share of gold paragraphs that reached any prompt.

## How to rerun

```sh
export RAG_SCRATCH=<the shared rag setup folder>
P="$RAG_SCRATCH/venv/bin/python -I -B"
$P hops.py                                   # deterministic: both gold in top k per retriever (no lock)
# generator runs: hold the bench lock ($RAG_SCRATCH/../inf/lock.sh acquire bench agt)
$P run.py closed 1.7b heldout 60 prompt=c1   # ... the held-out prompt candidates, see out/tune.json
$P run.py closed 1.7b; $P run.py single 1.7b k=5; $P run.py single 1.7b k=2; $P run.py single 1.7b k=10
$P run.py single 1.7b k=5 method=bm25; $P run.py react 1.7b; $P run.py decomp 1.7b
$P run.py longctx 1.7b; $P run.py longctx 1.7b tokens=8000; $P position.py 1.7b
# the same with 4b (AGT_CTX=20480)
$P router.py construct; $P run.py single 1.7b single 100 k=5; $P run.py react 1.7b single 100; $P router.py classify; $P router.py evaluate
$P graphrag.py index; $P graphrag.py local; $P graphrag.py communities; $P graphrag.py global; $P graphrag.py report
$P summarize.py; $P pick_replay.py; $P make_data.py && sh ../build.sh
$P check_numbers.py
node check_tab.mjs ../../index.html <screenshot folder>
```

Every generator call is cached by (model, messages, max_tokens, stop) in `$RAG_SCRATCH/agt/gen/`, so a rerun reproduces the outputs exactly without the server; the per-question trajectories are in `$RAG_SCRATCH/agt/runs/`. Small results the page embeds: `out/*.json` (committed).

## Notes

- **Prompt-choice bug, fixed by a rerun:** in the first chain the step that writes `out/tune_choice.json` failed (`choose()` was defined after the script's main block), so the 1.7B one-call test runs used prompt s2, which makes that model answer yes or no to non-yes/no questions (63 of 200 single-shot answers; 0 for the 4B). The bug is fixed; `out/tune_choice.json` now holds the held-out choice (c1, s3, r2), and every 1.7B one-call run (single shot k 2/5/10 and BM25, long context both sizes, position, the router's one-hop pipeline half) was rerun with s3 on 2026-10-14 evening under the bench lock. The first runs are kept as `$RAG_SCRATCH/agt/runs/s2prompt_*.jsonl`, summarised in `out/strategies_s2prompt.json` (and `out/router_s2prompt.json`). The 4B runs used s2 and were unaffected (0 such answers); they were not rerun.
- Replay questions are chosen by a fixed rule over the 4B runs (`pick_replay.py`).

See `viz_ideas.md` for the visuals built and rejected.
