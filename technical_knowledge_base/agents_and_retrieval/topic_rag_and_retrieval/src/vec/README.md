## How to rerun

```sh
export RAG_SCRATCH=<the shared rag setup folder>
P="$RAG_SCRATCH/venv/bin/python -I -B"
# deterministic, CPU, no lock
$P mrl_quant.py      # Matryoshka x float32/int8/binary x rescoring (Qwen3), truncation of bge-small and gte
$P two_recalls.py    # FAISS exact / HNSW / IVF / IVF-PQ sweeps, per-claim recalls, the before/after lists
$P proj.py           # PCA and t-SNE of a 705-point sample, trustworthiness, neighbours kept
$P contrastive.py    # the real batch, hard negatives, batch-size sweep
$P models.py         # model comparison from the setup's records of record
$P frontier.py       # Quora frontier summary from ../../vector_indexes/src/data/results.json
# MPS, hold the bench lock (about 4 minutes): raw gte-modernbert vectors
$P metric.py embed
$P metric.py         # cosine vs dot vs L2 on the raw vectors (CPU)
python3 make_data.py && sh ../build.sh
python3 check_numbers.py                   # embedded data = out/*.json; prose numbers; privacy; em-dashes
node check_tab.mjs ../../index.html <screenshot folder>
```

Small results in `out/*.json` (committed); the raw gte vectors in `$RAG_SCRATCH/vec/`.

## Notes
- Cross-checks against the Vector indexes child (same vectors, independent code): int8 with a float query at 1,024 dims agrees 0.996 with exact search (child: FAISS SQ8 0.995); binary without rescoring 0.674 (child 0.674); IVF72 nprobe 1 / 8 ANN recall 0.482 / 0.901 and the IVF72,PQ32 rows identical to the child's.
- `int8-sym` (query quantized with the corpus ranges, integer dot of the codes) agrees only 0.790 with exact search at 1,024 dims while its nDCG@10 is 0.700: different neighbours, same quality.
