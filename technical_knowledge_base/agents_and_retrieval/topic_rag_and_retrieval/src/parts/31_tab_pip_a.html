Pipeline lab

Every stage of a retrieval pipeline, measured on the same running example: how the documents are cut into chunks, how the first stage finds candidates (BM25, embeddings, or both fused), filters, query rewriting, reranking, and finally where a correct answer gets lost between the corpus and the generator's reply.

The running example
SciFact (5,183 scientific abstracts, 300 test claims, each with the abstracts annotators marked relevant), NFCorpus (3,633 medical documents, 323 test queries with graded labels) and, for chunking, QASPER (281 NLP papers, 892 questions whose evidence paragraphs annotators marked). Open models only, all run on one laptop: BM25 (bm25s), four embedding models, three rerankers and Qwen3-1.7B as the generator. Every number marked measured was produced here, on an Apple M1 Pro, in October 2026; published numbers come from the paper or vendor named beside them; constructed marks an input written for this page. The definitions (BM25, embeddings, nDCG, recall@K) are in the {{Reading|#t-read}} tab; the vector indexes are in the {{Vector search lab|#t-vec}}.
