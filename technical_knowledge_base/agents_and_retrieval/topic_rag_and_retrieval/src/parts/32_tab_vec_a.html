The running example

Every number marked measured was produced on an Apple M1 Pro in October 2026; published numbers come from the paper or vendor named beside them. Relevance numbers (nDCG, recall) are deterministic; timings are labelled with the load average of a shared machine. What an embedding is

The problem. BM25 matches words. A claim such as "Mitochondria are uninvolved in apoptosis" should also find an abstract that says, for example, "cytochrome c release triggers programmed cell death", which shares almost no words with it. We need a representation of meaning that can be compared quickly.

How it works. An embedding model is a neural network that reads a text and outputs a fixed list of numbers, a vector (Qwen3-Embedding-0.6B outputs 1,024 numbers; bge-small 384). It is trained so that texts which answer each other land close together and unrelated texts land far apart (how: How they are trained, below). Each number on its own means nothing; only distances between vectors carry information. Retrieval with embeddings is then geometry: embed every document once, embed the query, return the documents whose vectors are nearest. This is called dense retrieval (every one of the 1,024 numbers is used), as opposed to BM25's sparse vectors (one slot per vocabulary word, almost all zero).

Seeing it. Nobody can look at 1,024 dimensions, so the map below squeezes real Qwen3-Embedding vectors into 2. What the picture can and cannot tell you
Use a 2-D map to see that topics cluster and to spot a corpus that sits apart; never to judge whether retrieval works. Retrieval is decided in the full 1,024 dimensions, and the numbers in the next sections are measured there.
