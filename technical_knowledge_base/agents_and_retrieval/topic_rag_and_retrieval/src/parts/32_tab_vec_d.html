Smaller vectors: Matryoshka truncation and quantization

The problem. Qwen3-Embedding stores 1,024 float32 numbers per document: 4,096 bytes. SciFact's 5,183 abstracts take 21 MB, but 10 million chunks would take 41 GB of memory before any index structure, and memory is what a vector database bills for. Two independent knobs shrink a vector: keep fewer numbers, or store each number in fewer bits.

Matryoshka truncation (fewer numbers). A model trained with Matryoshka Representation Learning (Kusupati et al. 2022) gets the contrastive loss applied to the first 32, 64, 128, ... dimensions as well as to all of them, so the most useful information is packed at the front, like nested dolls. You keep the first d numbers and re-normalise. A model trained without it can be cut the same way, but nothing promised that the front holds the most. Qwen3-Embedding declares Matryoshka support from 32 to 1,024 dimensions (model card, vendor); bge-small and gte-modernbert do not.

Quantization (fewer bits per number). int8: map each dimension's range onto 256 levels, 1 byte per number (4 times smaller). Binary: keep only the sign of each number, 1 bit (32 times smaller), compared by counting differing bits (Hamming distance). Rescoring repairs most of the damage: retrieve R candidates with the small codes, then re-rank just those R with the full float32 vectors, read from disk or a cheaper tier. Product quantization (PQ), which compresses further by encoding chunks of the vector against learned codebooks, is part of the {{IVF-PQ lab on the child page|n:3f85c17b0d0d81f29707c130b2ebcfb1}}.

What transfers
The shapes do: binary codes need rescoring; int8 with a float query loses almost nothing; quantizing the query too changes which documents come back even when the quality score barely moves; truncation hurts a model not trained for it more. The exact numbers are SciFact's (5,183 short abstracts, one relevant abstract per claim for most claims). On a corpus of millions, more near-duplicates compete for the top 10, so compression costs more recall there: check on your own data at your own size. Engines implement these differently (calibration ranges, asymmetric distance, oversampling factors): the Tool map lists which store offers which, and the child page measures them on Quora's 522,931 vectors.
