The topic in one screen

The core idea. An agent is a language model called in a loop; the harness is everything except the model, and it decides what the model sees and what it is allowed to do. Anthropic's own definition: Claude Code "is the layer around the model that provides the tools and manages the context the model sees. This surrounding layer is what the term agentic harness refers to" (How Claude Code works, read 5 Oct 2026).

One turn of an agent: the model makes one decision, the harness does the other six steps

Step 2 (dashed) is the model; every other step is the harness. Each step names the section of this page that maps it and the child page that owns it in depth. The loop repeats until step 7 says stop.

The running example. A tiny Python library, textstats, with two planted bugs: the word splitter drops apostrophes (so word_count("don't stop") returns 3, not 2), and top_words breaks ties in no particular order instead of alphabetically. One test file, run with plain python3 tests/test_core.py, catches both. Every run on this page gets the same prompt: "The tests in this repository fail. Find out why and fix the code so they pass. Do not edit the tests." The same model, Claude Haiku 4.5, given the source file in a single call fixed one bug and left a test failing; inside Claude Code's loop it ran the tests, saw both failures and fixed both MEASURED (section 1).

Every measured number comes from runs recorded on 5 October 2026 with the Claude Code CLI 2.1.289 on a Claude subscription (no API key), kept redacted in this page's source; dollar figures are the API-price equivalent the CLI reports, not money paid. MEASURED marks those numbers, SOURCE marks published ones. How libraries and frameworks package these pieces (LangGraph, Pydantic AI, the Claude Agent SDK and others) is the sibling root, {{Topic: agentic-frameworks|n:3c65c17b0d0d81ab8432c54d65b7f8c7}}.

New terms, each defined where it is first used:

Harness (benchmark papers say scaffold): the program around the model.
Tool call: a structured request for an action, with a name and JSON arguments.
Action boundary: the point where the model's turn must end, right after its action.
Context window: everything the model reads on one call.
Prompt cache: a provider's stored copy of a repeated request prefix, read at a tenth of the input price.
Compaction: replacing the conversation with a model-written summary when the window fills.
Permission gate: rules that allow, deny or ask before each tool call.
Sandbox: an operating-system boundary around what does run.
Lethal trifecta: private data, untrusted content and a way out, all in one agent.
Trajectory: the full record of a run; with a verifier (the tests) it becomes a reward.
