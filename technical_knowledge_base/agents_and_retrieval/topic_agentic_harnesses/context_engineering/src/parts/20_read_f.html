8. Memory layers: Mem0, Zep's Graphiti, Letta

Notes (section 7) are files the agent writes and reads itself. A memory layer is a store a framework plugs in, where a model derives something smaller than the history (facts, a graph, a self-edited block) and decides what to do when new information contradicts old. Two policies define every one: a write policy (what is extracted, in what form, and whether a contradicted memory is overwritten, kept beside the new one, or closed with a date) and a read policy (who decides to look, the harness on every answer or the model when it chooses, with what query, and how many results go back into the prompt).

answer correct ⇒ fact written ∧ fact retrieved ∧ fact read correctly

Every failure in the experiment below sits at one of the three links. Checking whether the evidence reached the prompt (no model needed) separates the first two from the third.

Four ways carry knowledge across sessions, in rising machinery: paste the full history (the baseline every product must beat, while it fits); notes the agent keeps (section 7); search the raw history, which is retrieval over your own chat log ({{rag-and-retrieval|n:3c65c17b0d0d81b89145c37dfe8a3b0b}} owns the mechanics) and keeps "tests run with test_core.py" beside "the test command is now pytest"; and a memory layer, which consolidates. LangGraph's store is the bare key-value form ({{LangChain and LangGraph, section 10|n:3c65c17b0d0d81529358c996382224ac}}). Three designs dominate:

Facts: Mem0

Store what was learnt, not what was said: a model turns each conversation into short sentences ("User's tests run with pytest"), each embedded; before an answer the closest sentences are pasted into the prompt. Cheap to read, easy to inspect. Since v2.0.0 (16 April 2026) the open-source library is "single-pass, ADD-only": a changed fact becomes a second sentence beside the old one.

Temporal graph: Zep, Graphiti

A model turns each conversation into entities and dated relations; a newer relation that contradicts an older one closes the older one's validity window: nothing is deleted, so the graph answers both "what now" and "what before". Built for "what changed, and when".

Paging: MemGPT, Letta

The model manages its memory with tools: a small block always in the prompt plus archives it writes to and searches, like an operating system paging between RAM and disk. Nothing is stored or found unless the model decides to.

One changing fact, four write policies: rewritten, piled up, closed with a date, or filed away

Sam's gateway, as each store held it after each session (recorded 6 Oct 2026; writers: Haiku 4.5 for the paper loop, Mem0 2.2.1 and Graphiti 0.30.2, the local Qwen3-4B for Letta 0.16.8). Bars run from the session that wrote an item to the session that rewrote or closed it; struck text is gone from the store. Dashed outlines: what each store will hold by 6 October.

One changing fact, four stores. Sam's gateway changed three times in twelve sessions; the chart follows what each store held about it, with the stored text under the chart.

  1. Session 1, 1 Sep: "All our model calls go through a LiteLLM proxy." Every store writes one item: the paper loop ADDs a memory, Mem0 2.2.1 a sentence, Graphiti an edge valid from 1 September, Letta a note filed in its archive (its core block, the part always in the prompt, never held the fact).
  2. Session 5, 15 Sep: "we dropped LiteLLM; everything goes through OpenRouter now." The paper loop UPDATEs the memory in place, so the LiteLLM text is gone, and ADDs a note of the change; Mem0 adds a second sentence beside the first; Graphiti closes the LiteLLM edge on 15 September and opens one for OpenRouter; Letta files a second note.
  3. Session 9, 26 Sep: "we switched the primary model from Haiku to Sonnet for planning steps only". Nothing about the gateway changed, yet Graphiti closed the OpenRouter edge with this date (red): a model judged the new fact to contradict it.
  4. Session 12, 3 Oct: "we are putting LiteLLM back, this time in front of OpenRouter". The paper loop rewrites its change note and adds the reason; Mem0 now holds three sentences, all current; Graphiti opens a new edge with no end date; Letta files a third note.
  5. 6 Oct: "What gateway setup do we use right now?" The reference answer is LiteLLM in front of OpenRouter. With Haiku reading, the paper loop, Mem0 and Graphiti all answer it, as does the full history; Letta, run by the local 4B model, said it had no information about the gateway.
