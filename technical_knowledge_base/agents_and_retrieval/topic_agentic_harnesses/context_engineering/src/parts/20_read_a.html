Context engineering in one picture

A model reads nothing between calls: on every step of an agent the harness rebuilds the whole request, so context engineering is choosing what goes into that one request, in what order, and what stays outside it, so that it fits, stays cacheable, and holds what the next step needs.

Stable parts first, the growing history after them; everything else lives outside the window and comes back on demand

One call of Claude Code with six tools on Claude Haiku 4.5, sizes from /context at the end of a recorded session (its own estimates, in tokens); blocks in request order, not to scale. The numbers in circles are this page's sections.

You need: the agent loop (a model call, tool calls, results appended, repeat), built from scratch on {{Building a harness|n:3c65c17b0d0d817ca14fc32338707c2f}}; this page starts where that loop sends its request. The parent's {{section 3 and Trace and context lab|n:3c65c17b0d0d81d881a8fe98b4cff7bb}} measure the startup context, the caching bill and a budget model on 22 recorded runs; they are linked here, not rebuilt.

Context window: the most tokens one request may hold, prompt and reply together.
Startup context: what the harness sends before you type (tools, system prompt, memory files).
Prompt cache: the provider's store of an already-computed prompt prefix, reused at a tenth of the price.
Cache breakpoint: a marked block where a cache entry is written.
Compaction: replacing the history with a model-written summary and restarting from it.
Progressive disclosure: a short description always loaded, the body only when used (skills).
Subagent: a second agent loop with its own fresh window; only its final text returns.
Memory layer: a store outside the window with a write policy and a read policy.
Context rot: recall falling as the window fills, long before it is full.
The running example
The same tiny Python library as the parent page, textstats, with two planted bugs and the task "The tests in this repository fail. Find out why and fix the code so they pass. Do not edit the tests." Some runs add five 75 KB log files, a 30-module service package, a skill or a CLAUDE.md. Every run is Claude Code 2.1.290 headless (claude -p) on a Claude subscription, recorded on 6 October 2026, redacted, kept in src/recordings/. Dollar figures are the CLI's total_cost_usd: what the tokens would cost at Anthropic's list prices, not what the subscription paid.
