Scaffold experiment: same model, four harnesses, ten tasks

The controlled version of "the score belongs to the pair". Every rollout below was recorded for this page on 6 October 2026; click any cell to read it.

Design
  • Held fixed: the ten tasks and their prompts (Environment lab), the verifier, the cap of 16 model calls, and within each model its sampling (local model: temperature 0.7, top-p 0.8, at most 768 tokens per reply; Haiku 4.5: Claude Code's defaults).
  • Varied: the harness. bash only: one bash tool in the container. file tools: list_files, read_file (with line numbers), replace (exact text, must match once), run_tests. file tools, no line numbers: the same, with read_file returning plain text and the descriptions adjusted (the only difference). Claude Code: Claude Code 2.1.290 with its own prompt and six tools (Read, Edit, Write, Bash, Grep, Glob), Haiku only, commands run on the host.
  • Loops: the local model runs in our own 90-line loop against mlx_lm.server 0.32.0; Haiku runs our three harnesses through the Claude Agent SDK 0.2.163 (our system prompt and tools as an in-process MCP server, built-in tools off: the loop is its bundled Claude Code 2.1.286), and Claude Code through claude -p.
  • Rollouts: 4 per task and harness for the local model, 3 for Haiku. Rewards from the hidden verifier (section 3 of Reading).
