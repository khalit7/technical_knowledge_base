A harness search you can rig (simulation)

No model is involved. Each round proposes several candidate harnesses whose true success rate differs from the current one by a small random amount; each is scored on a fixed set of pass/fail tasks; the loop keeps the best candidate if its score beats the current measured score. The guarded rule additionally re-scores the winner on a fresh held-out set and keeps it only if that gain exceeds two standard errors. Lines are averages over 300 simulated searches; the shaded band is the middle 80%.
