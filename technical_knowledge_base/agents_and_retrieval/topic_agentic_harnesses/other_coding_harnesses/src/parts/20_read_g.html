Why the simplest protocol won here. An agent loop hands a weak model many decisions (which tool, which arguments, when to stop), and each is a chance to slip. Aider takes most of them away: its repository map and file-mention rule pick what the model reads, the model answers once with edits, and the harness, not the model, runs the tests and returns only the failure. With a strong model the balance changes: mini-SWE-agent's bash-only loop is the fixed harness of SWE-bench's "Bash Only" view, runs "in the mini-SWE-agent environment, so scores compare models rather than harnesses" ({{swebench.com|https://www.swebench.com/}}), and its README reports scores above 74% on SWE-bench Verified; how far a harness moves strong models' scores is on {{Coding benchmarks|n:3ef5c17b0d0d81bfa09ad4ba5eef0c4e}} and the parent's section 7.

Every call resends the whole history: OpenHands' 30 calls read 95 times the tokens of Aider's whole-file run

Prompt tokens summed over every model call of each recorded run, coloured by outcome (both tests pass, one, none) MEASURED. OpenHands' 30 calls used 322,241 input tokens, about 95 times Aider's whole-file run (3,384) derived, because the whole event history is resent each step: input tokens grow with the square of the run length. The local server's prompt cache made the repeated prefix fast to process; it did not make it smaller, and paid APIs price cached reads lower, which is why the order of the prompt matters ({{Context engineering|n:3f15c17b0d0d811292cee46514370431}}). Click a bar to open the run.

One run per setting, one task: enough to see mechanisms, not to rank products; fix the model and effort, repeat runs and report cost beside the score before comparing harnesses. At scale the ranking itself depends on the model: four harnesses (OpenCode, Codex CLI, Pi CLI, DeepAgents) with four models on six benchmarks, 52,168 trajectories, changed order across models and benchmarks, with OpenCode first on average across models; task success and finishing with a valid, gradable result could favour different pairings ({{When Agents Fail: Model or Harness (arXiv 2610.32483)|https://arxiv.org/abs/2610.32483}}). Sampling at the server default (temperature 0) except Gemini CLI, which sends temperature 1 and top_p 0.95 itself; the local server was shared with other jobs, so seconds are not compared. Em-dashes in model output were replaced with commas in the stored recordings, and paths were rewritten to /work.
