9. Beyond the terminal: cloud agents and loops you rent

The same loop also runs on someone else's machine. Three shapes matter, and they change what you can check: an edit as it lands (terminal), a pull request afterwards (cloud agent), or a loop whose context policy you never see (hosted API).

Codex cloud
Each task gets its own workspace and keeps running while your computer sleeps; tasks start from ChatGPT on the web, mobile or desktop, from the CLI (codex cloud, experimental; codex cloud exec --attempts 1-4 runs best-of-N and codex apply brings a result home), from @codex on GitHub and GitLab (beta) issues, from Linear and from Slack ({{Codex cloud|https://learn.chatgpt.com/codex/cloud}}, {{CLI reference|https://learn.chatgpt.com/codex/cli/reference}}). The environment page, now titled "Codex Cloud (Legacy)", documents the mechanics: a container with your repository checked out, a setup script, a default "universal" image, and agent internet access off by default ({{environments|https://learn.chatgpt.com/codex/cloud/environments}}). The pattern: interactive work in the terminal, a fleet of parallel attempts for small, well-specified fixes.
Jules (Google)
An asynchronous agent that clones a GitHub repository into a cloud VM, writes a plan for you to approve, makes the change and opens a pull request ({{jules.google|https://jules.google/}}). Out of beta 6 August 2025; a command-line tool on 2 October 2025 and an API on 3 October 2025 ({{changelog|https://jules.google/docs/changelog/}}); a Gemini CLI extension hands tasks from the terminal to Jules ({{extension|https://github.com/gemini-cli-extensions/jules}}). The changelog's latest entry is from 9 March 2026.
Antigravity (Google)
Launched 18 November 2025 in public preview with Gemini 3: an editor view, an Agent Manager for several agents working at once across editor, terminal and browser, and Artifacts, reviewable outputs (task lists, plans, screenshots, recordings) that move verification from the token stream to a document you can comment on ({{launch post|https://antigravity.google/blog/introducing-google-antigravity/}}). Antigravity 2.0 (19 May 2026) is a separate agent-first desktop app with "no IDE" ({{2.0 post|https://antigravity.google/blog/introducing-google-antigravity-2/}}). The Antigravity CLI replaced Gemini CLI for free and consumer users on 18 June 2026 (section 3).
Hosted loops
On 10 September 2026 OpenAI opened the Agents API in public beta: OpenAI runs the loop, with sandboxes it hosts, on your infrastructure, or at partners (Blaxel, Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop, Vercel) ({{OpenAI|https://openai.com/index/introducing-the-agents-api/}}). The same day Anthropic added an auto permission policy to Claude Managed Agents (in public beta since 8 April 2026) and ant beta:sessions connect, which attaches a terminal to a running session to watch it and approve or deny tool calls ({{release notes|https://platform.claude.com/docs/en/release-notes/overview}}). With a rented loop, the parts of the harness that most change behaviour (context policy, compaction, the loop itself) leave your process; the permission policy is what you keep. Hosted runtimes are compared on the {{Topic: agentic-frameworks|n:3c65c17b0d0d81ab8432c54d65b7f8c7}} page (tab Production stack).
Meta Muse Code
"Meta's coding agent for the terminal and CI, built for Muse Spark", with "approvals and an OS sandbox on from the first run" and a headless muse exec for pipelines; public preview ({{docs|https://dev.meta.ai/docs/muse-code}}). A launch date could not be confirmed from a dated Meta source. In CI nobody is there to approve, so policy replaces the prompt to a human.

The old note also listed the Gemini app for Windows (10 September 2026, opened with Alt + Space; {{Google|https://blog.google/innovation-and-ai/products/gemini-app/gemini-app-now-on-windows/}}) and the Google Home MCP server (early access; needs a Google Home Premium Advanced subscription and a Google Cloud project; {{Google Home Developers|https://developers.home.google.com/mcp/home}}). Neither is a coding harness; the second matters because it lets an agent act on physical devices, which belongs to the {{Personal agents|n:3c75c17b0d0d81bf9462fbeb09593e1c}} page's trust discussion.

10. The rest of the field from the old notes, checked

goose
Rust, Apache-2.0, desktop app and CLI. Block contributed it as a founding project of the Linux Foundation's Agentic AI Foundation on 9 December 2025, beside Anthropic's MCP and OpenAI's AGENTS.md ({{Linux Foundation|https://www.linuxfoundation.org/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation}}); the repository moved to aaif-goose/goose in spring 2026. Every capability, including the developer tools (shell, write, edit), is an MCP extension. Recipes are shareable YAML task packages that a scheduler can run on cron ({{docs|https://goose-docs.ai/docs/guides/recipes/session-recipes/}}). Its default permission mode is fully autonomous; an optional "Adversary Mode" has a second agent watch tool calls ({{security|https://goose-docs.ai/docs/guides/security/}}).
Cline
VS Code agent, Apache-2.0, with Plan and Act modes (read-only reasoning before any change, the pattern Claude Code's plan mode and Gemini CLI's plan share); native subagents since v3.58.0 (12 February 2026) and a CLI that runs interactive or "fully headless" ({{release|https://github.com/cline/cline/releases/tag/v3.58.0}}). The site claims "11M+ developers" (vendor figure; the old note said 5M installs).
Roo Code, Kilo Code
Roo Code, a fork of Cline, was shut down on 15 May 2026 and its repository archived ({{README|https://github.com/RooCodeInc/Roo-Code}}). Kilo Code started by merging Cline and Roo features; its current core derives from opencode. Anaconda announced it is acquiring Kilo Code on 15 July 2026 ({{Anaconda|https://www.anaconda.com/blog/anaconda-acquires-kilo-code}}); Kilo claims "10T+ tokens processed every month" (vendor figure).
Pizza Bot
"An inbox for long-running AI work" on a DeepAgents and LangGraph runtime, Apache-2.0, "developed at Amazon" but published under its own GitHub organisation, not AWS's; v1.0.0 on 8 September 2026 ({{repo|https://github.com/pizza-bot-app/pizza-bot}}). The idea it carries: background agents need a place where finished work arrives as items to review, not a terminal someone watches.
Model access is a dependency
On 28 August 2026 OpenAI said it would wind down its contract supplying models to Cursor after SpaceX's acquisition of Cursor (14 August), with a proposed shutoff on 12 November 2026, the maximum notice its contract allows, citing "our experience with Elon Musk's companies violating contracts" ({{OpenAI|https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/}}, {{Cursor|https://cursor.com/blog/joining-spacex}}). With the subscription-login rules of section 4, it makes the same point twice: a harness that is not the model maker's own runs on terms it does not control.
