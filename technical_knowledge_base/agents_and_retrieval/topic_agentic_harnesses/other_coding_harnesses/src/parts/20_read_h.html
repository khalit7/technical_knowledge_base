Codex CLI, Apache-2.0tag rust-v0.160.1, 5 October 2026Launched April 2025 in TypeScript; going native announced 30 May 2025, now the Rust workspace codex-rs ({{discussion #1174|https://github.com/openai/codex/discussions/1174}}). It speaks only the Responses API: wire_api = "chat" is now a config error ({{model-provider-info|cx:codex-rs/model-provider-info/src/lib.rs#L97-L131}}). 127,966 GitHub stars on 6 October 2026 ({{GitHub API|https://api.github.com/repos/openai/codex}}). Docs moved from developers.openai.com to {{learn.chatgpt.com/codex|https://learn.chatgpt.com/codex}}; "Codex" is also a cloud service and part of the ChatGPT desktop app. 0.162.0 (8 October): managed Git worktrees, task pinning; 0.163.0 (15 October): mid-turn steering, parallel runs of independent read-only tools ({{changelog|https://learn.chatgpt.com/docs/changelog}}).
Gemini CLI, Apache-2.0v0.62.0, stable of 29 September 2026Announced 25 June 2025 ({{Google blog|https://blog.google/technology/developers/introducing-gemini-cli-open-source-ai-agent/}}). 0.64.0 (13 October) makes file writes and state saves atomic ({{releases|https://github.com/google-gemini/gemini-cli/releases}}). Since 18 June 2026 it no longer serves the free Code Assist tier or Google AI Pro and Ultra subscribers, who were moved to the new Antigravity CLI; it remains for paid Gemini API keys, Code Assist Standard and Enterprise, and Vertex AI ({{Google Developers Blog, 19 May 2026|https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli}}). The README and quota page still describe the old free tier below a banner announcing the change.
opencode, MITv1.18.34, 30 September 2026Repository moved from sst/opencode to anomalyco/opencode; 211,898 GitHub stars on 6 October 2026; the site claims "over 16M developers every month" (vendor figure) ({{GitHub API|https://api.github.com/repos/anomalyco/opencode}}, {{opencode.ai|https://opencode.ai/}}). Since 1.19.0 (11 October) opencode upgrade --major moves an install to OpenCode 2 and updates are no longer automatic; 1.x was at 1.19.3 on 16 October ({{releases|https://github.com/anomalyco/opencode/releases}}). 17 October 2026: Anomaly disclosed a breach of the OpenCode Console, a legacy hosted system being decommissioned; 1.4% of Console users were affected, all with external provider API keys linked, and were told to revoke and rotate their OpenAI, Anthropic and Google keys ({{OpenCode on X|https://x.com/opencode/status/2111516673953935833}}): a key stored with a hosted service is as safe as that service. Subscriptions: Anthropic's terms let subscription (OAuth) credentials be used only by Claude Code and Anthropic's own apps ({{legal and compliance|https://code.claude.com/docs/en/legal-and-compliance}}); opencode removed its Claude Pro/Max login plugin in v1.3.0 (22 March 2026; {{release|https://github.com/anomalyco/opencode/releases/tag/v1.3.0}}) after a January 2026 issue reported the login broken ({{issue #7410|https://github.com/anomalyco/opencode/issues/7410}}); Claude works with an API key; ChatGPT Plus and Pro, GitHub Copilot and GitLab Duo logins work ({{providers doc|https://opencode.ai/docs/providers/}}).
Aider, Apache-2.0main at 5dc9490 (its code for the parts cited matches 0.86.2, which we ran)First released May 2023. Latest GitHub release v0.86.0 (9 August 2025), but tags v0.86.1 and v0.86.2 exist, PyPI's latest is 0.86.2 (12 February 2026), and the last commit to main is from 22 May 2026 ({{PyPI|https://pypi.org/project/aider-chat/}}, {{tags|https://github.com/Aider-AI/aider/tags}}): slowed, not stopped.
OpenHands, MITSoftware Agent SDK v1.53.0, 5 October 2026Formerly OpenDevin ({{arXiv 2407.16741|https://arxiv.org/abs/2407.16741}}). In 2026 it split: the flagship repository now headlines "Agent Canvas", a self-hosted control centre that can run OpenHands, Claude Code, Codex or Gemini CLI, while the agent lives in the {{Software Agent SDK|https://github.com/OpenHands/software-agent-sdk}}, the part you would build on.
mini-SWE-agent, MITv2.4.6The SWE-agent paper (2024) argued that an agent's tools are an interface to design, an agent-computer interface ({{ACI|https://swe-agent.com/latest/background/aci/}}; {{paper|https://arxiv.org/abs/2405.15793}}), and framed guard rails as a trade-off: whether one helps "depends on how well it reduces common model errors compared to whether such restrictions hamper models' preferred workflows". A year later the same team released mini-SWE-agent: "as LMs have become more capable, a lot of this is not needed at all" ({{README|https://github.com/SWE-agent/mini-swe-agent}}). SWE-agent is now in maintenance-only mode and recommends mini-SWE-agent. Version 2 made native tool calling the default; the version 1 style is the opt-in textbased model class.
Cloud and hostedchecked October 2026Codex cloud tasks start from ChatGPT on the web, mobile or desktop, the CLI (codex cloud, experimental), @codex on GitHub and GitLab (beta) issues, Linear and Slack; its environment page is now titled "Codex Cloud (Legacy)". Jules out of beta 6 August 2025, a command-line tool 2 October 2025, an API 3 October 2025 ({{changelog|https://jules.google/docs/changelog/}}), a Gemini CLI extension hands tasks to it ({{extension|https://github.com/gemini-cli-extensions/jules}}); latest changelog entry 9 March 2026. Antigravity (Google) launched 18 November 2025 in public preview with Gemini 3: an editor view, an Agent Manager for several agents across editor, terminal and browser, and Artifacts (task lists, plans, screenshots, recordings) that move verification from the token stream to a document you can comment on ({{launch post|https://antigravity.google/blog/introducing-google-antigravity/}}); Antigravity 2.0 (19 May 2026) is a separate agent-first desktop app with "no IDE" ({{2.0 post|https://antigravity.google/blog/introducing-google-antigravity-2/}}). OpenAI's Agents API, public beta 10 September 2026: OpenAI runs the loop, with sandboxes it hosts, on your infrastructure, or at partners (Blaxel, Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop, Vercel) ({{OpenAI|https://openai.com/index/introducing-the-agents-api/}}). The same day Anthropic added an auto permission policy to Claude Managed Agents (public beta since 8 April 2026) and ant beta:sessions connect ({{release notes|https://platform.claude.com/docs/en/release-notes/overview}}). Meta Muse Code: "Meta's coding agent for the terminal and CI, built for Muse Spark", with "approvals and an OS sandbox on from the first run" and a headless muse exec; public preview; launch date not confirmed from a dated Meta source ({{docs|https://dev.meta.ai/docs/muse-code}}).
The rest of the field from the old notes, checked
goose
Rust, Apache-2.0, desktop app and CLI. Block contributed it as a founding project of the Linux Foundation's Agentic AI Foundation on 9 December 2025, beside Anthropic's MCP and OpenAI's AGENTS.md ({{Linux Foundation|https://www.linuxfoundation.org/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation}}); the repository moved to aaif-goose/goose in spring 2026. Every capability, including the developer tools (shell, write, edit), is an MCP extension. Recipes are shareable YAML task packages that a scheduler can run on cron ({{docs|https://goose-docs.ai/docs/guides/recipes/session-recipes/}}). Its default permission mode is fully autonomous; an optional "Adversary Mode" has a second agent watch tool calls ({{security|https://goose-docs.ai/docs/guides/security/}}).
Cline
VS Code agent, Apache-2.0, with Plan and Act modes (read-only reasoning before any change, the pattern Claude Code's plan mode and Gemini CLI's plan share); native subagents since v3.58.0 (12 February 2026) and a CLI that runs interactive or "fully headless" ({{release|https://github.com/cline/cline/releases/tag/v3.58.0}}). The site claims "11M+ developers" (vendor figure; the old note said 5M installs).
Roo Code, Kilo Code
Roo Code, a fork of Cline, was shut down on 15 May 2026 and its repository archived ({{README|https://github.com/RooCodeInc/Roo-Code}}). Kilo Code started by merging Cline and Roo features; its current core derives from opencode. Anaconda announced it is acquiring Kilo Code on 15 July 2026 ({{Anaconda|https://www.anaconda.com/blog/anaconda-acquires-kilo-code}}); Kilo claims "10T+ tokens processed every month" (vendor figure).
Pizza Bot
"An inbox for long-running AI work" on a DeepAgents and LangGraph runtime, Apache-2.0, "developed at Amazon" but published under its own GitHub organisation, not AWS's; v1.0.0 on 8 September 2026 ({{repo|https://github.com/pizza-bot-app/pizza-bot}}). The idea it carries: background agents need a place where finished work arrives as items to review, not a terminal someone watches.
Model access is a dependency
On 28 August 2026 OpenAI said it would wind down its contract supplying models to Cursor after SpaceX's acquisition of Cursor (14 August), with a proposed shutoff on 12 November 2026, the maximum notice its contract allows, citing "our experience with Elon Musk's companies violating contracts" ({{OpenAI|https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/}}, {{Cursor|https://cursor.com/blog/joining-spacex}}). With the subscription-login rules above, it makes the same point twice: a harness that is not the model maker's own runs on terms it does not control.
