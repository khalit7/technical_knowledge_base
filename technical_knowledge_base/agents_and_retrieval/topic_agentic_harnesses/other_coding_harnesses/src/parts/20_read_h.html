Why the simplest protocol won here. An agent loop hands a weak model many decisions (which tool, which arguments, when to stop), and each is a chance to slip. Aider takes most of them away: its repository map and file-mention rule pick what the model reads, the model answers once with edits, and the harness, not the model, runs the tests and returns only the failure. With a strong model the balance changes: mini-SWE-agent's bash-only loop scores above 74% on SWE-bench Verified with frontier models (section 7), and the parent topic's {{Harness atlas|n:3c65c17b0d0d81d881a8fe98b4cff7bb}} tab shows how far the harness moves strong models' scores.

What it cost. Every harness resends the whole history on every call, so input tokens grow with the square of the run length: OpenHands' 30 calls used 322,241 input tokens, about 95 times Aider's whole-file run (3,384). The local server's prompt cache made the repeated prefix fast to process; it did not make it smaller. Paid APIs price cached reads lower, which is why the order of the prompt matters (the {{Context engineering|n:3f15c17b0d0d811292cee46514370431}} page).

One run per setting, one task; sampling at the server default (temperature 0) except Gemini CLI, which sends temperature 1 and top_p 0.95 itself; the local server was shared with other jobs, so seconds are not compared. Em-dashes in model output were replaced with commas in the stored recordings, and paths were rewritten to /work.
