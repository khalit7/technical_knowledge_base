4. opencode: the harness as a server, any model behind it

What it is. An MIT-licensed, provider-agnostic coding agent with a terminal UI, a desktop app and IDE integrations, made by Anomaly (the repository moved from sst/opencode to anomalyco/opencode). 211,898 GitHub stars on 6 October 2026; the site claims "over 16M developers every month" (vendor figure) ({{GitHub API|https://api.github.com/repos/anomalyco/opencode}}, {{opencode.ai|https://opencode.ai/}}). Read here: v1.18.34, 30 September 2026.

Architecture
Everything runs behind an HTTP API: opencode serve starts a headless server, the terminal UI starts the same server in a worker thread and talks to it, and even opencode run boots a local server first ({{serve.ts|oc:packages/opencode/src/cli/cmd/serve.ts#L6-L24}}). Older write-ups describe a Go/Bubble Tea terminal UI; at this version the UI is TypeScript on OpenTUI and SolidJS, and the repository has no Go. The client/server split is what lets one session be driven from the terminal, a desktop app, an editor or a script.
Loop
runLoop reloads the session's messages from its database on every pass, makes one streamed model call, runs the tool calls, and stops when the last reply has no tool call ({{prompt.ts|oc:packages/opencode/src/session/prompt.ts#L1081-L1130}}). No step limit unless an agent sets steps. A doom-loop guard: three identical tool calls in a row raise a permission question ({{processor.ts|oc:packages/opencode/src/session/processor.ts#L29-L379}}). Malformed calls are repaired (wrong-case tool names are fixed; unknown ones go to a hidden invalid tool that returns an error instead of crashing the turn).
Per model
The system prompt is chosen by matching the model id: anthropic.txt for Claude, gemini.txt, codex.txt, beast.txt for older GPT models, and default.txt (8,528 bytes) for anything else, such as our local model ({{system.ts|oc:packages/opencode/src/session/system.ts}}). The tools also depend on the model: ids containing gpt- get a Codex-style apply_patch instead of edit and write ({{registry.ts|oc:packages/opencode/src/tool/registry.ts#L292-L301}}). A provider-agnostic harness has to carry a dialect per model family.
Edits
edit(filePath, oldString, newString, replaceAll) tries nine matchers in order and takes the first that finds a unique match: exact, line-trimmed, block-anchor (first and last line fixed, the middle scored by Levenshtein similarity, threshold 0.65), whitespace-normalised, indentation-flexible, escape-normalised, trimmed-boundary, context-aware and multi-occurrence ({{edit.ts|oc:packages/opencode/src/tool/edit.ts#L682-L737}}). A comment credits Cline and Gemini CLI for the ideas. After each edit, language-server diagnostics for the file are appended to the tool result, so the model sees a type error in the same turn.
Context
Project instructions: the first of AGENTS.md, CLAUDE.md, CONTEXT.md found between the working directory and the project root (and ~/.claude/CLAUDE.md globally), plus nested AGENTS.md files attached when the read tool opens a file below them. Compaction summarises the older part when the last turn's tokens reach the usable window, keeping a recent tail of 25% of it (clamped to 2,000 to 15,000 tokens) ({{compaction.ts|oc:packages/opencode/src/session/compaction.ts#L115-L120}}). Two traps: compaction is silently off for a custom model with no limit.context in the config, and the cheap "prune old tool outputs" step is off by default. Tool output is cut at 2,000 lines or 50 KB, with the full text saved to a file.
Safety
Rules of the form permission, pattern, action (allow, ask, deny); the last matching rule wins. Defaults allow almost everything: only reading .env files, touching paths outside the project and doom loops ask ({{agent.ts|oc:packages/opencode/src/agent/agent.ts#L119-L136}}). Shell commands are parsed with tree-sitter so an "always allow" can be stored as a prefix such as git checkout *. There is no OS sandbox. In opencode run, any question is rejected unless you pass --auto.
Extend
JavaScript plugins with hooks such as tool.execute.before, permission.ask and experimental.session.compacting; MCP servers; skills (it also reads .claude/skills); custom agents and subagents (task tool, built-in general and explore).
Which subscriptions work

Anthropic's terms let subscription (OAuth) credentials be used only by Claude Code and Anthropic's own apps ({{legal and compliance|https://code.claude.com/docs/en/legal-and-compliance}}). opencode removed its Claude Pro/Max login plugin in v1.3.0 (22 March 2026; {{release|https://github.com/anomalyco/opencode/releases/tag/v1.3.0}}), after a January 2026 issue reported the login broken ({{issue #7410|https://github.com/anomalyco/opencode/issues/7410}}); Claude now works in opencode with an API key. ChatGPT Plus and Pro, GitHub Copilot and GitLab Duo logins do work ({{providers doc|https://opencode.ai/docs/providers/}}). The old page's "OpenAI now sponsors the project" has no primary source and is dropped.

Our run MEASURED

opencode has no sandbox, so we ran it inside a throwaway Docker container (our addition). Its first request was large: 9,602 characters of system prompt and 21,144 characters of tool definitions for 10 tools (the bash description alone is 4,628 characters), 7,247 prompt tokens before the model had read a file (Codex's, at 9,210, and Gemini CLI's, at 11,452, were larger). A separate call generated the session title. The 4B model delegated twice to the explore subagent (its own 5-tool context, 3,091 tokens), found the bug in top_words, and then answered in prose describing the fix ("update the sorting key to include alphabetical ordering for ties") without calling edit. A reply without a tool call ends the loop, so the run stopped after 13 calls with both tests failing. The harness did what it promises; the model's habit of explaining instead of acting is exactly what a "no tool call means done" rule cannot tell apart from finishing.

What to steal. Run the agent as a server with a typed API and let every interface be a client. Keep a prompt and tool set per model family. Append diagnostics to edit results so the model sees breakage at once.
