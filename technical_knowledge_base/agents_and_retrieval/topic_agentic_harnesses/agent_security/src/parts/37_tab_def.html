Defence-in-depth simulator

A design tool, not a run: pick the controls you would put around an agent and see which leg of the lethal trifecta each one removes, and whether a compromised agent could still exfiltrate. There is no model and no attack here, only the logic of which defence breaks which leg. The scenario is fixed to the hard case, because it is the one worth designing for.

Scenario. A coding agent reads content you do not control (a dependency, an issue, a fetched page), and it runs on a machine that holds something worth stealing (a token, a key, private source). The untrusted content leg is therefore always present: a useful agent must read the world. Your job is to remove one of the other two legs with a control that sits outside the model.

    Each enabled control links to where this page shows it working on a benign or clearly-dangerous action, with no attack performed.
