The idea in one sentenceAn agent acts with your rights on text that anyone can write, and no model reliably tells your instructions from planted ones, so agent security is the set of controls outside the model that make acting on a hostile instruction blocked, contained or harmless: name the leg of the lethal trifecta (private data, untrusted content, a way out) you removed, and enforce it where the model cannot argue.

Untrusted text gets in by design; every defence sits between the model and the world

One coding agent and its trust boundary. Text from sources nobody vetted (top) lands in the same context as your task; the model's output becomes tool calls; the controls outside the model (gate, sandbox, egress proxy, credential broker) decide what those calls can start, reach, send and hold. The red legs are the lethal trifecta: with private data in reach, untrusted content in the context and a way out, an injected instruction can complete a leak. Section numbers on the figure.

Confused deputy: a program holding more authority than whoever instructs it, tricked into using it for them (Hardy, 1988).
Indirect prompt injection: an instruction planted in content the agent reads while working, followed as if you had typed it.
Lethal trifecta: private data, untrusted content and a way out, together (Willison, 2025).
Fail closed: anything no rule foresaw is refused, not allowed.
Egress control: deciding where outbound traffic may go, by destination, below the agent.
Tool poisoning and rug pull: instructions hidden in a tool's description; a definition that changes after you approved it.
