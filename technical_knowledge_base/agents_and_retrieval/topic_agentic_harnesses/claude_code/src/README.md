## Findings worth carrying elsewhere
- Plan mode answered by Sonnet when Haiku is asked: documented in the changelog for 2.0.17 ("SonnetPlan by default").
- 33 hook events in 2.1.290 (the parent root says 32).
- Project `permissions.allow` is ignored in `-p` in an untrusted folder (stderr warning); deny and ask still apply.
- A token-capped Read returned 1,821 of 3,001 lines with no visible notice; the 256 KB Read error is not in the tools reference.
- acceptEdits refused `sed -i` although the docs list sed as approved.
- A budget stop overshoots by one call, and `result.usage` then misses that call; a resumed session's totals are cumulative.
- Subagent cache writes reproduce the cost only as 5-minute writes.

- **Closed depth blocks**: the 46-tool table, documentation against recording for the probe, the 33 hook events with timeouts and hook input, the record kinds and other headless flags, the settings keys, subagent definitions and built-ins and agent teams, plugins and mods, the old page claim by claim, the September 2026 changelog check, two design questions.

The cuts were restatement (the mistakes and interview blocks, recaps after each widget), reference tables a reader consults rather than reads, and dated version facts. Going shorter would mean dropping a mechanism or its evidence, which the ledger forbids.
