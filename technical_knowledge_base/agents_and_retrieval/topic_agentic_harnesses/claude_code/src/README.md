# Claude Code, taken apart: source

Child of Topic: agentic-harnesses. Builds `../index.html` (about 362 KB: over the usual 300 KB because the page embeds 23 recordings for the Recordings tab and the gate model's data; accepted as on the parent).

## Shape
Part B (child page) of `html_utils/methods/topic_pages.md`: a Reading tab organised by mechanism in the order a session meets them (loop, tools, permissions, hooks, memory files, skills, subagents, plan mode, headless runs, settings, the SDK boundary), then the old page checked claim by claim, common mistakes and interview questions; one lab tab (Permission lab), one data tab (Recordings), Further reading. Departure: no "in production now" section, because the product's own docs and changelog are the production facts and section 10 carries them.

## Files
- `parts/`: `20_read_*.html` Reading (20_read_a opens the t-read wrapper and holds its CSS), `22_js_hcc_data.js` (generated by `extract.py`), `23_js_hcc_static.js` (generated by `static_data.py` from `inputs/`), `24_js_hcc_gate.js` (the permission-layer model shared by Reading and the lab), `25` to `27` Reading scripts, `31_*` Permission lab, `32_*` Recordings, `39_tab_more.html`.
- `recordings/`: the 23 redacted runs (`<label>.jsonl` plus `<label>.meta.json`: test output afterwards, diff, the logging hook's file). `runs.json` names each run, its prompt and flags.
- `prompts/`, `setups/`, `hooks/`: everything the runs used. `run.sh` is how a run was made (set SCRATCH and TASK_REPO).
- `redact.py` (raw stream to repo copy; refuses to write if a home path, user name or token prefix remains), `extract.py`, `static_data.py`, `check_page.py` (data up to date and embedded, 29 prose numbers recomputed, private-string and em-dash scan).
- `live.md` (old Notion page, verbatim), `coverage.json`, `viz_ideas.md`, `inputs/` (2.1.290 docs extracts: tool table, hook events).

## Recordings (6 Oct 2026, Claude Code 2.1.290, Claude subscription)
`claude -p` with `--output-format stream-json --verbose --include-partial-messages --no-session-persistence --setting-sources project --strict-mcp-config --append-system-prompt "Never use the em-dash character."`, each in a fresh copy of the shared `textstats` task repository. Haiku 4.5 unless noted (plan mode was answered by Sonnet 5.5; one auto-mode run on Sonnet 5.5). Groups: tool probe (1), permission battery (8), hooks off/on (2), memory canaries (1), skills (3), subagent (1), parallel calls (2), headless limits and sessions (5). A planned bypassPermissions battery run was refused by the recording session's own safety check and was not made. Costs are `total_cost_usd` (API-price equivalents); `modelUsage` reproduces them at list prices in 22 of 23 runs, and in the subagent run only with the subagent's cache writes priced as 5-minute writes.

## Findings worth carrying elsewhere
- Plan mode answered by Sonnet when Haiku is asked: documented in the changelog for 2.0.17 ("SonnetPlan by default").
- 33 hook events in 2.1.290 (the parent root says 32).
- Project `permissions.allow` is ignored in `-p` in an untrusted folder (stderr warning); deny and ask still apply.
- A token-capped Read returned 1,821 of 3,001 lines with no visible notice; the 256 KB Read error is not in the tools reference.
- acceptEdits refused `sed -i` although the docs list sed as approved.
- A budget stop overshoots by one call, and `result.usage` then misses that call; a resumed session's totals are cumulative.
- Subagent cache writes reproduce the cost only as 5-minute writes.
