The same model drives the Reading tab's animation. It encodes the documented order (hooks, then deny, ask and allow rules, then the mode) and the orderings the recordings showed; it is a teaching model, not Claude Code's code, and the score above says how far to trust it. Presets load the cases that surprised the recordings.

Bash rules split the command on &&, ||, ;, | and &; an allow must match every part, a deny or ask any part; Bash(x *) matches x and x ...; Edit(path) covers Edit and Write with ** and * globs. Not modelled: protected paths, critical-path removals, wrappers such as timeout, environment-variable prefixes, the sandbox, and the auto-mode classifier (shown as "classifier decides").
