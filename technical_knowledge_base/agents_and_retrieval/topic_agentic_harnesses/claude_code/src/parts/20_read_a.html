Claude Code in one screen

Claude Code is Anthropic's coding agent: a program that runs Claude in a loop with tools on your machine (a terminal app, IDE extensions, a desktop and web app and a GitHub integration share the same core). It was introduced as a limited research preview with Claude 3.7 Sonnet on 24 February 2025 ({{Anthropic|https://www.anthropic.com/news/claude-3-7-sonnet}}) and declared generally available in version 1.0.0 on 22 May 2025 ({{changelog|https://code.claude.com/docs/en/changelog}}). This page takes apart version 2.1.290 (5 October 2026), the version installed on the recording machine.

The parent page explains what a harness is and builds one from zero (Topic: agentic-harnesses, its Reading tab and Loop lab). Its Trace and context lab already holds 22 recorded Claude Code runs of the running example (fix the two planted bugs in textstats) and measures startup context, prompt caching and run-to-run spread. This page does not repeat those. It asks a narrower question for each mechanism: what exactly does Claude Code do here, and what do the documentation and a real recording say? Every mechanism below was exercised in a recording made for this page (23 runs on 6 October 2026, Claude Haiku 4.5 unless a section says otherwise; open any of them in the {{Recordings|#t-runs}} tab).

Where each mechanism acts in a session

Click any box to jump to its section. Green boxes are code you write; the dashed box is the model; everything else is the harness.

Before the first model call
settings files (managed, flags, local, project, user)→SessionStart hooks→CLAUDE.md files, rules, imports→skill names and descriptions→tool definitions→permission mode
Each turn of the loop
request: system prompt + tools + history→model replies: text, thinking, tool calls→tool calls run (some in parallel)→results appended, call again
Each tool call
PreToolUse hooks→deny, ask, allow rules→mode and built-in checks→the tool runs (sandbox optional)→PostToolUse hooks→result, capped
Delegation and ending
Agent tool: subagent in a fresh window·Skill tool: body loads now·plan mode·Stop hook→result record (-p)

How to read the labels
MEASURED means a recording on this page (or on the parent's trace lab, named) shows it. DOCS means the Claude Code documentation for 2.1.290, read on 6 October 2026, says it, with a link. UNCONFIRMED means neither, and the claim is kept only to say so. Costs are the CLI's total_cost_usd, an API-price equivalent; the runs were paid by a Claude subscription.
