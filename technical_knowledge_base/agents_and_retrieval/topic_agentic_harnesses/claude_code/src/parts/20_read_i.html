Two design questions (interview rehearsal)
A skill and a CLAUDE.md line both say "run python3 tests/test_core.py". What is the difference in cost and reliability?
The CLAUDE.md line is paid on every call and always visible; the skill costs its description (29 tokens here) until invoked, then its body once. Neither is enforced: both are context. Choose CLAUDE.md for facts needed every session, a skill for procedures needed sometimes, a hook or rule for anything that must always hold.
How would you run Claude Code safely in CI on untrusted pull requests?
--bare (no repo hooks, skills, MCP or CLAUDE.md) or at least --settings '{"disableAllHooks": true}' and --strict-mcp-config; an explicit --permission-mode (dontAsk) with exact allow rules on the command line; a container or the OS sandbox with no secrets and egress limited; --max-turns and --max-budget-usd (knowing the budget overshoots by one call); read the result's subtype and modelUsage.
