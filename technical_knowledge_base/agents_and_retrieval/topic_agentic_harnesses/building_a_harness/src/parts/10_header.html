Building a harness: the loop, tool calling, edit formats, stop conditions

The parent page built a harness in seven steps; this page takes each of its decisions apart with measurements: how a tool call travels (as JSON on an API, as special tokens inside an open model), why the harness must cut the model off at its own action, parallel calls, streaming and interrupts, how to design tools and their errors, five edit formats measured on thirteen fixed edits, error recovery, and when to stop. Every number is from a run recorded on 6 October 2026 or from a dated source.
