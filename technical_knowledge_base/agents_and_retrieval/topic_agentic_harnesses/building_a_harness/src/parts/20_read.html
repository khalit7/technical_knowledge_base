The page in one screen

A harness is the program around a model: it sends a request, gets back either text or a tool call, runs the call, and decides whether to go round again. The parent page, {{Topic: agentic-harnesses|n:3c65c17b0d0d81d881a8fe98b4cff7bb}}, explains what an agent loop is and builds one in seven steps (its Loop lab tab). This page is for writing your own: each decision inside the loop, with a default that works and the recorded evidence for it.

How the model asks for an actionThe provider's native tool calls (JSON schemas in, typed calls out)Underneath, an open model writes the call as tokens between special tokens and ends its turn with an end-of-turn token; a malformed call can vanish silently in the server1
