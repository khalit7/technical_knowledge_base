It covers agents in general, not resident ones specifically.

9. Hosted entrants, and the layering

Meta's Muse (announced 8 Sep 2026; US, on iOS, Android, muse.ai and inside WhatsApp) is the first big hosted personal agent, with mail, calendar, browser and payment connections. Its safety post is the clearest public design for the boundary of section 6 PRIMARY ({{newsroom|https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/}}, {{How we built safety into Muse|https://security.muse.ai}}):

  • "Muse runs on Muse Secure VM, a dedicated, virtual machine (VM) that houses both the agent and a person's data", and "the harness runs in its own isolated cell, it doesn't see real credentials".
  • A separate Sentinel agent on the same machine: "Nothing Muse does reaches the internet unless the Sentinel approves it"; after a request is authorised, Sentinel "will replace any surrogate tokens with the real credential ... at the network boundary".
  • Approvals: "A dialog is presented to the user directly within the client UI, not via their conversation with Muse".
  • The browsing sub-agent "sees an accessibility tree snapshot of the page, not the raw DOM" and "has no ability to run javascript in the page context"; the email connector filters one-time codes and password-reset links with deterministic filters and a classifier. No accuracy figures for any classifier are published.

The principle transfers to anything you build: assume the agent will sometimes be persuaded, and keep credentials, egress and consent in a component it cannot talk to. (Muse Spark 1.3 is the model, released 2 Sep 2026; the old page merged the two names.)

The layering. A personal agent is a router, scheduler, memory and delivery surface; a coding harness is the best executor for coding work (six of them read from source and run on one task: {{Other coding harnesses|n:3c65c17b0d0d819fa3cefdcd2ccff2f7}}, its "Same task, every harness" tab). OpenClaw makes that explicit by running Codex as an embedded runtime and Claude Code, Gemini CLI, OpenCode or Cursor over ACP (section 2); Hermes exposes itself over ACP so an editor can host it. The {{MCP page|n:3c65c17b0d0d813f9695dc4175c44cbb}} and {{Agent-to-agent and beyond|n:3f05c17b0d0d81199373d4d0b18706d8}} own the protocols. A claw asked to fix a bug should hand that turn to a coding harness, in a sandbox, with the repository as its world.
