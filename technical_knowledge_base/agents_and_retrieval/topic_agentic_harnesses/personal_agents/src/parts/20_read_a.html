In one screen

A coding harness such as Claude Code is invoked: you open a session in a repository, it works, the session ends. A personal agent is resident: a background program that never ends, receives messages on the chat apps you already use, wakes itself on a timer to check whether anything needs doing, keeps notes about you for months, and acts on your accounts (mail, calendar, payments) rather than on a repository. Inside, it runs the same agent loop the parent page teaches ({{Topic: agentic-harnesses|n:3c65c17b0d0d81d881a8fe98b4cff7bb}}, Reading section 1). What changes is everything around the loop: who can write into its context, what authority it holds while nobody watches, and what can check or undo its work.

Coding harness (Claude Code, Codex CLI)Personal agent (OpenClaw, Hermes Agent)
How a run startsYou start a sessionA message, a timer (heartbeat), a scheduled job or a webhook
How long state livesOne session, plus memory files you keepMonths: a searchable session history, memory files the agent itself edits, a profile of you
What it acts onA repository and a terminalYour accounts: chat, mail, calendar, browser, sometimes payments and devices
Who is watchingUsually you, at the terminalOften nobody: a heartbeat or a scheduled job runs while you sleep
Who writes into its contextMostly you, plus files you chose to openAnyone who can send you a message or an email: the input channel is open to third parties by design
What checks the workTests, compiler, CI, a diff you reviewUsually nothing automatic: "was my inbox handled well?" has no test suite
UndoGit: nearly everything is revertibleA sent message, a booking or a payment usually cannot be taken back
PermissionsPer-tool approval inside a session you watchStanding access to live accounts, granted once at setup

What this page adds to the parent's one-line mention. Both projects read at pinned versions (docs and source), every number of the old page checked against a primary source (section 10 lists what changed), and a resident agent of about 240 lines written for this page (gateway, triggers, a plain-code gate, an approval queue, a searchable history) run against a fake inbox, calendar and history: 32 recorded runs (190 model calls) with Claude Haiku 4.5 and Claude Sonnet 5.5 through the CLI. Installing and running the real OpenClaw or Hermes Agent was not done here (see the note in section 2).

Three ideas to keep
  1. Same loop, different boundary. The loop, tools, compaction and skills are the coding-harness vocabulary; the difference is that the input channel is open to strangers and the output acts on accounts with no test suite and little undo.
  2. Put enforcement where text cannot reach it. A plain-code gate that knows which actions cannot be undone, approvals shown outside the conversation, and credentials the model never sees (sections 6 and 9).
  3. Never-ending sessions need tiers of memory and rules for interruptions. What stays in every prompt, what is searched when needed, and what happens to a message that arrives while the agent works (sections 4 and 5).
