7. Verification and undo, when there is no test suite

The problem. Everything the parent page says about measuring and improving harnesses leans on a free verifier: the tests pass or they do not ({{Topic: agentic-harnesses|n:3c65c17b0d0d81d881a8fe98b4cff7bb}}, section 7). A personal agent's work has none. Did it answer the garage politely, at the right time, with the right facts, and should it have answered at all? Nobody computes that. And when it is wrong, git does not help: a sent message stays sent.

The design response is to move as much work as possible into the reversible column, and to make the irreversible column small, slow and visible:

PatternHow it worksWhere it appears
Draft, do not sendThe agent prepares; you press sendThis page's heartbeat checklist; the gate refuses sends on unattended runs
Hold for approvalAn irreversible call becomes a queued request outside the chatThis page's approval queue; Muse's approval dialog
Undo logEvery reversible change records how to reverse itThis page's gate; Claude Code's file checkpoints play the same role for edits
Staged memory and skillsWhat the agent wants to remember waits for reviewHermes write_approval (opt-in); this page's remember tool
Delay windowSend after N seconds unless cancelledCommon in mail clients; not found in either project's docs
Scenario tests with fake dataScripted conversations with checks on what the agent didOpenClaw's Personal Agent Benchmark Pack

How OpenClaw tests itself. The "Personal Agent Benchmark Pack" is, in its own words, "a small repo-backed QA scenario pack for local personal assistant workflows. It is not a generic model benchmark": ten YAML scenarios (a reminder round trip, a reply in a channel thread, recalling a stored preference, not leaking a secret while redacting, following through after a tool safety check, stopping after an approval is denied, reporting task status, sharing a diagnostics file safely, not faking progress, recovering from a failure), run against a mock model with "only fake users, fake preferences, fake secrets" DOCUMENTED ({{benchmark pack|https://docs.openclaw.ai/concepts/personal-agent-benchmark-pack}}). There is no public personal-agent leaderboard comparable to Terminal-Bench; {{Agent and trajectory evaluation|n:3ef5c17b0d0d81fdbabaf3582bff37f2}} covers how to grade trajectories when no verifier exists.
