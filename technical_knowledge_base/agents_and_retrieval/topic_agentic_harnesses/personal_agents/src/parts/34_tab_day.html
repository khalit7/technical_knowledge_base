A day, replayed

The agent written for this page (section 1's pieces in about 240 lines of Python), run through one fake day: two heartbeats, two requests from Sam, one scheduled job. Every model call is a real recording (Claude through the claude CLI with tools off; the agent parses one ACTION line per reply and runs it against the fake world). Step through it to watch the gate classify each action and the state of the world change. Nothing real was touched: "sent" means appended to a list.

What to look for

    The gate in this agent: reads are allowed; reversible changes (drafts, calendar edits, messages to Sam) are allowed and logged with an undo step, except calendar changes on unattended runs, which are held; memory writes are staged; sends and payments are held for Sam's approval on his own runs and refused on heartbeats and scheduled jobs. Token counts are what the CLI reported per call (the CLI adds about 420 tokens of its own, measured on the parent page's Loop lab); cost is the CLI's API-price equivalent, while the subscription is what actually paid.
