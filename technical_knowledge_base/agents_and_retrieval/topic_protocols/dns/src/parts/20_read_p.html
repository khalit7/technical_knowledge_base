Glossary

Trust anchor: the public key (or its DS hash) a validating resolver trusts without proof; for the real DNS, the root KSK.
Anycast: one IP address announced from many sites; routing delivers to the nearest.
Apex: the top name of a zone (example.com.), which must hold SOA and NS and so cannot be a CNAME.
Authoritative server: a server that holds a zone's records and answers from them, never asking others.
conntrack: the Linux kernel's table of tracked flows, used for NAT; the source of the 5-second DNS races.
Delegation: NS records in a parent zone handing a child zone to other servers.
DNSSEC: signatures on DNS data (RRSIG, DNSKEY, DS, NSEC) so a resolver can verify it.
EDNS(0): an OPT pseudo-record that advertises a larger UDP size and carries flags and options.
FQDN: a fully qualified name, ending in a dot; never extended with a search list.
Glue: addresses of a child's name servers kept in the parent when those servers live inside the child.
Header: the 12 bytes at the start of every message: ID, flags, response code, four counts.
Headless service: a Kubernetes Service with clusterIP: None whose name returns every ready pod's address.
Root hints: the built-in list of root server addresses a resolver starts from.
Iterative query: a question a resolver asks an authoritative server, which answers or refers.
Key tag: a 16-bit checksum that names a DNSSEC key (38696 is KSK-2024).
KSK and ZSK: key-signing key (signs the key set; hashed into the parent's DS) and zone-signing key (signs the rest).
Label: one dot-separated part of a name, at most 63 bytes.
NODATA: NOERROR with no answer: the name exists without that type.
Negative trust anchor: an operator's temporary instruction to treat a zone as unsigned.
Priming: a resolver's first question, the current list of root servers.
Compression pointer: two bytes (c0 0c) standing for a name already written earlier in the message.
QNAME minimisation: sending each server only the labels it needs (RFC 9156).
Response code: NOERROR, NXDOMAIN, SERVFAIL, REFUSED and others, in the header.
Recursive query: a question asking the resolver for the final answer (RD flag set).
Referral: an answer naming the servers one level down instead of the record.
Resource record: one name, TTL, class, type and data.
RRset: all records of one name and type, cached and signed as one.
Serve-stale: answering from an expired cache entry when the source is unreachable (RFC 8767).
TTL: seconds a cache may keep a record; for a "no", min(SOA TTL, SOA MINIMUM).
Zone: the part of the name tree one set of authoritative servers answers for.
