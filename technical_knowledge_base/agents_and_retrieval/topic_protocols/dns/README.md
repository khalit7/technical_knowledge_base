# DNS: resolution, caching and the failure modes

Notion: https://app.notion.com/p/3c65c17b0d0d812387d8f92b546f07af (child of Topic: protocols)

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). How a name becomes an address from zero to production depth: names, zones and delegation, the resolution walk (with and without QNAME minimisation), the message byte by byte, EDNS and TCP fallback, the records that matter and the apex problem, TTLs, negative caching and serve-stale, glibc and musl stub resolvers (timeouts, dead servers, error texts, clients without caches), Kubernetes search lists and ndots, conntrack races, NodeLocal DNSCache and CoreDNS, headless services for training, AWS's VPC resolver and Route 53, DNSSEC and the root key roll of 11 October 2026, encrypted DNS, poisoning, rebinding against agent fetch tools, exfiltration, outages and a debugging toolkit. Recorded on a private DNS tree in containers (Unbound, CoreDNS, glibc, musl, tcpdump) and with read-only public lookups over DNS over TLS (October 2026). Tabs: Reading, Pod resolver lab (every recorded packet of two lookups side by side), Cache timeline (who still sees the old address after a change), Further reading. Replaces the old page "DNS: resolution, caching, and the failure modes"; no child pages, databases or video.
