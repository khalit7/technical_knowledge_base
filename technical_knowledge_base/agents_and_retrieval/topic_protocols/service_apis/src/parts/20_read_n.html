SituationChooseBecause

A TypeScript app whose only client is its own front endtRPCTypes end to end, nothing to generate

Tools. grpcurl -plaintext host:port list and grpcurl -d '{...}' host:port pkg.Service/Method (needs reflection or the .proto); curl --http2-prior-knowledge -H 'content-type: application/grpc' -H 'te: trailers' --data-binary @msg.bin for raw calls (the root's atlas does a health check this way); GRPC_TRACE=http for the C-core libraries' HTTP/2 debug logs (its companion GRPC_VERBOSITY is now deprecated and changes logging for the whole process, per gRPC's {{environment variables doc|https://github.com/grpc/grpc/blob/v1.84.0/doc/environment_variables.md}}); and a logging proxy like this page's frame_proxy.py (100 lines of Python) when you need every frame without packet capture.
