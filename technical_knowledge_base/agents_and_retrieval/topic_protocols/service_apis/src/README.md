Everything measured lives in `raw/` and reaches the page only through `make_data.py` -> `parts/22_js_data.js` (`window.SA`). Prose numbers that vary between runs are written through `data-sa="path"` placeholders filled from that object, so a rerun cannot leave stale text.

Rerun everything: `WORK=<scratch> NGINX=<nginx 1.31 with http_v2 and stream> sh run_all.sh` (about 2 minutes; ports 30500 to 30549 on 127.0.0.1; only its own processes are stopped; no network needed). nginx is the root Failure lab's build (`../../src/fail/README.md`). Versions: Python 3.13, grpcio 1.84.0, protobuf 7.36.2 (upb), graphql-core 3.3.0, h2 4.4.1, hpack 4.2.0, hyperframe 6.1.0, nginx 1.31.6, macOS 27 on an M1 Pro.

## What could not be seen or run
No packet capture (no sudo): the frame proxy sees exactly the bytes the two programs exchanged, not TCP segments. No real GPU or model: the inference service emits fixed tokens on a configured schedule (0.12 s, then every 0.05 s). Envoy was not run (nginx covers L7); KV-cache-aware routing is described from project sources, not measured.

## The 2026-10-24 rebuild: what changed and why
Rebuilt to the teaching contract (`.claude/skills/explainer-page/teaching/teaching-contract.md`) and to a new ownership: this page now owns service API styles, including REST done properly (resources, custom methods, long-running operations, error formats, pagination, versioning), OpenAPI and schema-first design, idempotency keys and retries across services, rate limits and quotas at the API, webhooks, and LLM provider APIs as an API-design case. Those were taught on Building a backend API (sections 7, 8, 10, 12, 13, 15, 16) and are now taught here, with their sources and that page's Postgres measurement quoted (`inputs/pagination_pg.json`, copied with its provenance); the ledger records them as "absorbed".
- **Top**: the core idea in one sentence, a hero (the running request through three styles, each hop labelled with the sections that teach it), "You need", new terms. The old "ten things to remember" list and the end glossary were restatements (fat).
- **Every core idea has its visual inline**, chosen by the kind of concept: annotated call (structure), pagination and idempotency before/after steppers, schema fan-out (structure), rate-limit headers (real shape), webhook delivery stepper (process), three LLM API designs on one tool-call round trip (before/after), status-code decisions (structure), balancer placement on measured counts (structure). The two lab tabs explained one mechanism each, so they moved into the Reading: the frame stepper into section 9 (replacing a compact table of the same frames), the balancer runs into section 13.
- **Depth closed**: Fielding and Richardson, the IETF and Stripe idempotency table, zigzag and packed fields, tensors, the 17-code table, the 11 failure cards with their three lessons, run B's accidental rescue, HTTP disconnect handling, limits, health and reflection, the inference-gateway side channel, tRPC row by row, GraphQL fan-out, ML serving reference, debugging table, drills and interview questions.
- **No autoplay**: `21_js_rd_common.js` and `99_js_tabs.js` are the skill templates; the deadline animation no longer plays on a mode switch; `check_ui.mjs` confirms every step counter is still 0 after load.
- **Corrections kept visible**: tensors against base64, retries by default, JSON-RPC in agent protocols.

Each remaining section answers one of the five questions the core sentence names, with numbers measured here or sourced inline; cutting further would drop a mechanism (deadline propagation, connection pinning, schema evolution) that the rest of the knowledge base links here for.
