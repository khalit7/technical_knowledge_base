JWT lab: twelve real tokens, one verifier you configure

Each token below was made on 5 October 2026 by src/lab/jwt_cases.py with PyJWT 2.15.1 and keys that existed only during the run. Each was then passed to two verifiers that both ran in Python: a pinned one (RS256 only, key looked up by kid in the issuer's own JWKS) and a naive one that does what the token header says (no check for alg: none, HMAC for HS256 with whatever key it finds, keys from kid file paths and jku URLs). This page replays those signature verdicts and computes the claim checks live from the decoded token, with the verifier's clock set to the recording time. Switch checks off to see which forgeries get through. Background: Reading {{section 6|#t-read}}.
