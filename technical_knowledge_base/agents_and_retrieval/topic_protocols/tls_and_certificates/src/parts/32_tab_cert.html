Certificate dissector

Twelve real certificate chains, exactly as the servers sent them on 5 October 2026 (one handshake each with OpenSSL 3.6.5, no HTTP request; src/lab/public_chains.py). Pick a host, click a certificate to see its fields and what each is for, then run the checks a client makes, and break them on purpose: move the clock, dial another name, drop the intermediate, or use a client whose trust store lacks the root.

Try: api.anthropic.com, then drag the date past 20 December 2026; dial a.b.api.anthropic.com; pick api.deepseek.com (a wildcard certificate) and dial a name two labels deep; compare a Google-issued chain (three certificates, ending in a cross-signed root) with pypi.org's (two).

    The checks follow RFC 5280 path validation, RFC 9525 name matching and Chrome's CT policy, simplified: signatures are not recomputed here (OpenSSL verified every chain when recorded: "Verify return code: 0"), and "trusted root" means a root in the certifi bundle used for the recording. Error strings are OpenSSL's verify messages, the ones curl and Python print.
