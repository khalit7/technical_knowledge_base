Throughput lab: which ceiling binds, and how many streams to move a checkpoint

One TCP connection is capped by four separate limits (Reading section 13): window over RTT, loss (the Mathis bound), a per-flow policy cap, and the link. Parallel connections multiply the first three until the link is full. Choose a path and a payload; the lab names the binding limit and the time to move it. Formulas: window / RTT; (MSS / RTT) × √(3/2) / √p ({{Mathis et al., 1997|https://dl.acm.org/doi/10.1145/263932.264023}}); per-flow caps from {{AWS|https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-instance-network-bandwidth.html}}. illustrative inputs The path presets are typical shapes, not measurements, except the home line, which is this page's measured one.
