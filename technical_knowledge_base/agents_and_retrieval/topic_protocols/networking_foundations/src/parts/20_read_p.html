Reading ss -ti. One line per connection: cubic or bbr (algorithm), wscale (send and receive window-scale shifts), rto: (current timer, ms), rtt:x/y (smoothed RTT / variance, ms), mss:, cwnd: (segments), ssthresh:, bytes_acked:, retrans: (in flight / total), pacing_rate, rcv_space: (autotuning's estimate); field list in {{man 8 ss|https://man7.org/linux/man-pages/man8/ss.8.html}}. Small cwnd with climbing retrans: loss-limited. Large cwnd and a throughput equal to window / RTT: window-limited. The macOS counterpart is netstat -s -p tcp for totals; per-connection detail needs getsockopt(TCP_CONNECTION_INFO), which this page's scripts use.
