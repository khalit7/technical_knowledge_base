Glossary

Each term links to where it is first explained.

5-tuple: protocol, source and destination IP and port; names one connection.
A2A: Agent2Agent, a protocol for delegating tasks between agents; discovery through an Agent Card.
Authentication: proving who you are. Authorization: deciding what you may do.
Bandwidth-delay product: link speed times round-trip time; the bytes that must be in flight to fill the link.
Bearer credential: a secret that works for whoever presents it (API keys, most access tokens).
Certificate authority: an organisation whose signature on a certificate clients trust.
Certificate: a signed document binding a name to a public key.
Congestion window: the sender's own limit on bytes in flight, its guess of what the network can carry.
Datagram: one self-contained UDP message.
Deadline: the time after which a caller no longer wants an answer; propagated through gRPC calls.
Diffie-Hellman: two parties derive the same secret from exchanged public shares.
DNS: the Domain Name System, which maps names to addresses and other records.
Frame: the unit of a link layer (Ethernet); HTTP/2 and QUIC also call their units frames.
Handshake: setup messages exchanged before data, each costing at least one round trip.
Header: control information a layer puts in front of the payload it carries.
Head-of-line blocking: one slow or lost item holding up everything queued behind it.
HTTP: the request and response vocabulary of the web and of APIs; versions 1.1, 2 and 3.
Indirect prompt injection: instructions hidden in content a model reads through a tool.
IP address: the address of a machine's network interface (IPv4 32 bits, IPv6 128 bits); IP forwards packets to it.
JSON-RPC 2.0: a request and response format of JSON objects with method, params and id; used by MCP and A2A.
JWT: a signed token of base64url header, claims and signature, verifiable offline.
Latency and bandwidth: time to the first byte, and bytes per second after that.
MCP: Model Context Protocol, connecting hosts and their models to tool servers.
Message: an application-level unit (an HTTP request, a JSON-RPC call).
MTU: the largest packet a link carries (1,500 bytes on most Ethernet).
NAT: a device that rewrites private addresses to public ones and tracks each connection.
OAuth: delegated authorization: an app gets a scoped token to act for a user.
Packet: the unit IP routes, with source and destination addresses.
Port: a 16-bit number that picks the program on a machine.
QUIC: an encrypted, multiplexed transport over UDP; carries HTTP/3.
RDMA: remote direct memory access; network cards write into another machine's memory without the OS.
Record: the unit TLS encrypts and authenticates.
Receive window: how many bytes the receiver can buffer; the sender never exceeds it.
Round trip (RTT): time for a message to reach the other side and a reply to come back.
Segment: the unit of TCP.
Server-Sent Events: a text event stream inside one long HTTP response.
Stream: an ordered sequence of bytes or messages; HTTP/2 and QUIC carry many in one connection.
TCP: the reliable, ordered byte stream over IP, with flow and congestion control.
TLS: Transport Layer Security; confidentiality, integrity and server authentication over a connection.
TTL: in DNS, the seconds a cache may keep an answer.
UDP: IP plus ports and a checksum; no handshake, ordering or retransmission.
