Parser test: eighteen byte streams, eight SSE parsers

Each case below is a tiny SSE stream that tests one rule of the HTML standard's parsing algorithm ({{WHATWG HTML 9.2.6|https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation}}). The lab server sent each one as the dashed chunks shown (separate network writes, 30 ms apart), and eight parsers reported what they delivered. Pick a case, predict, then see every parser's answer. measured 5 October 2026; scripts src/lab/parsers_py.py and parsers_node.mjs; raw results src/raw/parsers.jsonl.

"ok" means the parser delivered exactly the events the standard requires (type, data and last event id). Otherwise the cell shows what it delivered. Note on eventsource-parser: it reports each event's own id field rather than the last event id, by design, so its id differs from the standard's in one case; that is a different contract, not a bug. Its second row decodes each network read separately, which is the caller's mistake, not the library's.
