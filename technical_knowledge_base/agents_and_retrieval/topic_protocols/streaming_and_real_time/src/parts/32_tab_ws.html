WebSocket bytes: one recorded exchange, frame by frame

Every byte of one WebSocket session between a client written on a bare TCP socket and the websockets 17.2 library server: the handshake, the running answer as seven server messages, then a masked client message, a ping, a message sent in two fragments, and the close. Pick a frame to see its bytes coloured by field. measured 5 October 2026, src/lab/ws_bytes.py, raw src/raw/ws_bytes.json. Orange: client to server; blue: server to client.

Unmasking, byte by byte

The server recovers each payload byte by XOR with the masking key, cycling through its four bytes.

Header size for any message

The slider moves through 0, 1, 3, 83, 125, 126, 1,000, 65,535, 65,536 and 1,048,576 bytes; lengths up to 125 fit in 7 bits, up to 65,535 take 2 more bytes, larger ones 8 more (RFC 6455 section 5.2).
