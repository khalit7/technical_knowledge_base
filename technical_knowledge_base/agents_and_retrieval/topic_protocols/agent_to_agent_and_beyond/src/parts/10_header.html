Agent-to-agent and beyond: A2A, agent commerce, agents driving devices

How one agent hands work to another agent it cannot see inside (A2A), how agents buy things from merchants (UCP, with AP2 and ACP beside it), how agents drive lab instruments (the Model Hardware Standard), and where a person must stay in the loop. Every A2A exchange shown was recorded on one laptop on 5 October 2026 with the official Python SDK between two scripted agents; no model was called.
