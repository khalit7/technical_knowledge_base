In one screen

Every address your training job touches is a virtual address. Hardware translates it, page by page, through a tree of tables the kernel keeps for each process; a small cache (the TLB) makes that free most of the time; and the kernel fills the tables only when a page is first touched (a page fault). Everything else on this page, from mmap and copy-on-write to huge pages and the OOM killer, is a way of filling, sharing, enlarging or taking back those pages.

The root page, {{Topic: operating-systems|n:3f05c17b0d0d81c5a97ce991644af140}} section 4, gave the intuition and measured the TLB, page faults and copy-on-write on the running job. This page goes one level down: the kernel's actual code paths (Linux v5.10, the kernel these runs used, file and line), every knob that matters in ML work, and new measurements. Each mechanism follows the same pattern: problem, how it works, what it costs here, when it bites in ML, the command that shows it, the fix.

Five things to remember
  1. Allocating is not using. A 64 GiB mmap succeeded here on a 10 GB machine; memory is spent page by page, at first touch.
  2. Resident is not owned. The job's three processes report 815 MiB of RSS together but own only 104 MiB alone; the rest is shared (section 13).
  3. Reading a Python object writes to it (reference counts, the garbage collector), so forked DataLoader workers copy what they read. NumPy arrays and gc.freeze() stop it (section 7).
  4. The page cache counts toward your container's limit but is given back; anonymous memory and /dev/shm are not (section 12).
  5. The OOM killer sends SIGKILL: no exception, no traceback, exit code 137.

How this page was measured: Docker Desktop's Linux VM on an Apple M1 laptop (Linux 5.10.104-linuxkit, arm64, 4 KiB pages, 5 CPUs, about 10 GB, 1 GiB swap, THP in "madvise" mode, overcommit mode 1, one NUMA node, no GPU), image kb-os-vm:1 (the root's lab image plus safetensors), October 2026. Containers were not privileged. Things that need a GPU, a newer kernel, writable sysctls or real NUMA are taught from primary sources and tagged not run here.
