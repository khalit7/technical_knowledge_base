The idea in one screen

A process is a record the kernel keeps for a running program (its memory, its descriptor table, its signal state, its identity), and the program can change that record only by asking through a system call: fork copies the record, exec replaces the program inside it, wait collects its end, a signal interrupts it, and descriptors are its handles on files, pipes and sockets.

The job is a tree of records the kernel owns; every arrow into the kernel is one system call

Top: the running job of the {{root page|n:3f05c17b0d0d81c5a97ce991644af140}} as a small tree of processes on a GPU node: torchrun (the launcher, "elastic agent": starts, watches and stops the trainers), one python train.py per GPU (each in its own session, --nproc-per-node of them), each with threads (OpenMP/ATen workers, pin_memory thread, NCCL threads: same process) and two pt_data_worker DataLoader worker processes (made by fork, spawn or forkserver). Bottom: what the kernel keeps for one trainer, each part tagged with what fork, exec and a new thread do to it. The dashed line is the system-call boundary: one instruction, about 270 ns for the cheapest call (section 2).

Task, TGID
Linux's record per thread; a process is the tasks sharing one thread group id, which getpid() returns.
System call
a numbered request to the kernel through one trapping instruction; failure comes back as a negative number that becomes errno.
Copy-on-write
fork shares the parent's pages read-only and copies a page only when one side writes it.
Zombie, orphan, subreaper
an exited process not yet waited for; a process whose parent died; the ancestor that adopts orphans instead of PID 1.
Pending, blocked
a signal recorded but not yet acted on; a signal held back by the thread's mask.
Descriptor, description
the small integer in one process's table; the kernel object it points to, which holds the file offset.
Close-on-exec
a per-descriptor flag: exec closes it, so the new program does not inherit it.
Process group, session
sets of processes signalled together (Ctrl-C, killpg); a session is what setsid starts.
