Containers and isolation: namespaces, cgroups v2, seccomp, sandboxes

What a container really is: ordinary processes on the host's kernel, given private views (namespaces), resource limits (cgroups), fewer powers (capabilities, seccomp, LSMs) and a layered root file system. Each piece built by hand and measured on a Linux 5.10 kernel, then the runtimes, sandboxes, GPU containers and Kubernetes resources that sit on top.
