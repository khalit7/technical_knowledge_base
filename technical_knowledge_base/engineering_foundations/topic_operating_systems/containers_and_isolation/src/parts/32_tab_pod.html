Pod to cgroup: what the kubelet and runc write for your pod

Type a pod's requests and limits (leave a field empty for "not set"); the tab computes the QoS class and, for every container and for the pod, the cgroup v2 values that Kubernetes v1.34 and the OCI runtime write, by the formulas of Reading section 12. CPU in cores (0.5 is 500m), memory in GiB. Every formula is reproduced in src/recompute.py, which checks this page's JavaScript on the presets. not run here: no Kubernetes cluster was used; the formulas are read from the source files linked under each row.

Sources (Kubernetes v1.34.0): shares and quota, {{helpers_linux.go lines 61 to 101|https://github.com/kubernetes/kubernetes/blob/v1.34.0/pkg/kubelet/cm/helpers_linux.go#L61}}; pod-level values, {{ResourceConfigForPod, line 124|https://github.com/kubernetes/kubernetes/blob/v1.34.0/pkg/kubelet/cm/helpers_linux.go#L124}}; QoS class, {{qos.go|https://github.com/kubernetes/kubernetes/blob/v1.34.0/pkg/apis/core/v1/helper/qos/qos.go#L157}}; OOM score, {{policy.go|https://github.com/kubernetes/kubernetes/blob/v1.34.0/pkg/kubelet/qos/policy.go#L45}}; memory.oom.group, {{kuberuntime_container_linux.go line 314|https://github.com/kubernetes/kubernetes/blob/v1.34.0/pkg/kubelet/kuberuntime/kuberuntime_container_linux.go#L314}}; MemoryQoS memory.high, {{lines 163 to 185|https://github.com/kubernetes/kubernetes/blob/v1.34.0/pkg/kubelet/kuberuntime/kuberuntime_container_linux.go#L163}}. Shares to weight: runc v1.1.2 {{utils.go line 423|https://github.com/opencontainers/runc/blob/v1.1.2/libcontainer/cgroups/utils.go#L423}} (linear) and opencontainers/cgroups v0.0.3 {{utils.go line 425|https://github.com/opencontainers/cgroups/blob/v0.0.3/utils.go#L425}} (quadratic). Simplified: no init or sidecar containers, no pod-level resources, no hugepages, the default 100 ms CFS period, and the cgroupfs-style path names (the systemd driver writes kubepods.slice/kubepods-burstable.slice/...).
