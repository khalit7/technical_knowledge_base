Event loop lab: one set of connections, five ways to wait

Eight open connections; data arrives on four of them, one after another (on connection 2, then 5, then 2 again, then 7). The same input runs through five designs: a thread per connection, select, poll, epoll, and io_uring. Count what each one makes the kernel and the program do. Then scale the measured costs up to thousands of connections below. Mechanisms are explained in Reading, {{section 9|#t-read}}.
