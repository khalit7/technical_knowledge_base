## Recordings (`raw/`) and how they were made (`lab/`)
All local on 127.0.0.1, ports 30300 to 30320, except `public_headers.txt` (one credential-free GET to each of three LLM hosts). Rerun everything: `WORK=<scratch> NGINX=<nginx 1.31 binary> sh run_all.sh` (creates a venv with pinned versions and a throwaway CA in WORK; private keys never enter the repo).

## Checks
- `python3 recompute.py`: the timeout model against all 8 measured runs (8 match), flow-control stalls x RTT against the measured times, header byte counts, HOL medians, SDK attempt counts, backoff gaps and Retry-After.
- `python3 check_embed.py`: the page embeds exactly `raw/` (via a fresh `make_data.py`), prose numbers match the recordings, no private patterns (`../../src/private_patterns.py`), home path or real token anywhere.
- `python3 check_embed.py` also checks that the CORS figure's header lines and the cookie line are in `inputs/cors_cookies.txt`.
- `node <this folder>/src/check_ui.mjs <dir>` from the repo root: clicks every control at 390 px dark and 920 px light, fails on errors, NaN, undefined, sideways scroll; screenshots of each card; then, at normal motion, checks that the three widgets (frame viewer, flow control, timeout chain) never play by themselves.
- `node <this folder>/src/check_stages.mjs [shots dir]` from the repo root: the four 3D stages and the compression animation play when scrolled into view (1400 light, 920 light, 390 dark), step to their last step with one list item per step, stop redrawing off screen and never move under reduced motion; the splits are two columns at 1400 px only; the numbers in the step lists are the page's data (HOL medians, the root's loss runs, the hero's model outcomes, the timeout runs, the header byte counts).
- `python3 html_utils/ledger.py check <this folder>`: the knowledge ledger.
- `sh html_utils/checkpage.sh <this folder>` from the repo root.

## Departures from the method
The visuals are measurements of protocol behaviour rather than published figures to reproduce: the "reproduces" check is the timeout-chain model predicting 8 measured runs independently, and the flow-control formula predicting the measured download times. No images: HTTP has no physical object that teaches; diagrams carry every mechanism.

## Findings worth passing on
- nginx 1.29.7 (24 Mar 2026) changed upstream defaults (HTTP/1.1, keep-alive, no Connection header), but nginx's proxy module page still lists `proxy_set_header Connection close` as default.
- hypercorn 0.18.0 (h11 0.16.0) answers a request hidden behind Content-Length plus Transfer-Encoding on the same connection, where RFC 9112 s6.3 says the server MUST close it. Not exploitable behind nginx (which rejects such messages).
- The official Anthropic and OpenAI Python SDKs retry POSTs after read timeouts and dropped connections (3 attempts) without an idempotency key, and speak HTTP/1.1 unless given an `http2=True` client.
- Cloudflare's origin timeout (error 524) is now documented as 125 s, not the 100 s many guides quote.
