## The 2026-10-24 rebuild: what changed and why
- **Top**: the core sentence; a new hero (model API, host with policy and one client per server, a local stdio server and a remote HTTP server with their primitives and who decides each, the authorization server; numbers 1 to 4 for one tool call), which the audit found missing; "You need"; five new terms; a "Not here" line naming the owners (Claude Code section 10 for MCP configuration, Agent security for injection and the supply chain, Auth for OAuth, Streaming for SSE, A2A). The one-screen table is closed; "How this page relates" became the "Not here" line.
- **Tabs moved inline**: Two replicas became the stepper in section 5 (it no longer starts on a mode switch); the Wire lab's OAuth stepper became a drawn sequence diagram in section 7 (the audit found the flow had no diagram); its transport openings and hostile-request explorer moved into a closed block in section 4. Only Reading and Further reading remain.
- **New visuals**: hero; envelope before/after (bytes to scale, the recorded lines with `_meta` highlighted); anatomy of a tool definition and result; the two transports; token passthrough before/after; a trust map of the five attacker positions (positions and controls only, no attack walkthrough).
- **Ownership**: indirect injection, the lethal trifecta and the supply-chain defences (pinning, hashing approved definitions, sandboxing local servers) now link to Agent security; this page keeps the protocol-level threats (tool poisoning, rug pull, false annotations, localhost and rebinding, hostile OAuth metadata, confused deputy, token passthrough, forged state, header mismatch) with their specified mitigations. The confused deputy is now explained from the 2026-07-28 security best practices (read 24 October 2026), including SSRF against authorization servers that fetch CIMDs.
- **Versions**: one compact dated table (five revisions, era, the change that matters); the per-revision change lists are closed.
- **Correction**: the old text said the recorded 403 carried `scope="ckpt:write"`; it names the scope only in `error_description`. Fixed in section 7, listed in the closed corrections block, and `check_embed.py` now checks the corrected claim.
- **Depth closed**: reserved names and changed error codes, smaller utilities, the recorded progress stream and wire explorers, the dual-era code, the "MCP is dead" note, every change per revision, governance, the eight OAuth steps as text, the recording's two auth findings, the host checklist, testing, deploying (including Claude Code's managed settings and the dated LiteLLM note), debugging, interview, corrections.
- **No images**: MCP has no physical object that teaches, and no openly licensed real UI image was needed; diagrams carry every mechanism.
