## Recordings (`raw/`) and how they were made (`lab/`)
Local on 127.0.0.1, ports 30200 to 30299, plus read-only handshakes (no HTTP request) to 12 public hosts, one fetch of Chrome's CT log list and CAA lookups over DoH to 1.1.1.1. Rerun everything: `WORK=<scratch> PYBIN=<python 3.13 with OpenSSL 3.5+> OPENSSL=<openssl 3.5+> NGINX_BIN=<nginx with OpenSSL 3.5+> sh run_all.sh` (the root Failure lab's OpenSSL 3.6.5 and nginx 1.31.6 builds were used; Docker for Pebble; private keys stay in WORK, only public certificates are copied to `raw/certs/`).

Why 41 minutes is right: the page owns eleven concepts (handshake, key exchange and forward secrecy, certificates and chains, CAs and trust stores, validation failures, SNI and ECH, mTLS, resumption and 0-RTT, ACME, CT, debugging), each with a measured result from this page's own recordings. About 1,500 of the 9,500 core words are the text of the interactive cards (the decrypted record list, the dissector's fields and checks, the 0-RTT and trust tables), which the audit counts as reading. What was restatement or reference (field lists, per-CA dates, tables of statuses, interview answers, glossary) is closed. Further cuts would drop core units (every non-fat unit in the ledger is needed for one of the eleven concepts).

## Departures from the method
Part B fits. The "reproduces" check is decryption: the page's handshake numbers come from records that `recompute.py` decrypts again and whose MACs it recomputes.

## Findings worth passing on
- Python: `SSLContext.load_cert_chain()` called again on a live server context changes the certificate for new connections (the old page said a new context is required).
- requests ignores `SSL_CERT_FILE` (it reads `REQUESTS_CA_BUNDLE` or `CURL_CA_BUNDLE`), httpx 0.28 and Python's default context read it, and it replaces rather than extends the bundle.
- nginx 1.31.6 with OpenSSL 3.6.5 and shared stateless tickets accepted the same 0-RTT flight three times (two front ends); the RFC 8470 header plus a 425 from the backend stopped it.
- 10 of 12 ML-relevant public endpoints negotiate X25519MLKEM768; Bedrock (us-east-1) and github.com answered X25519.
- An ML-DSA-65 two-certificate server flight is 15,895 bytes, past TCP's 10-segment initial window; ML-DSA-44 (11,948) fits before CT timestamps.
