2. Round trips: the cost every layer adds

Light in fibre covers about 200 km per millisecond, so distance sets a floor no protocol can beat ({{High Performance Browser Networking, chapter 1|https://hpbn.co/primer-on-latency-and-bandwidth/}}). Most LLM API calls are latency-bound, not bandwidth-bound, and the latency before the first token is mostly handshakes that each wait one round trip. Which handshakes you pay depends on choices made at three different layers: the HTTP version, the TLS version, and whether a connection is reused.

Add one round trip for an uncached DNS answer before any of them, and one for the request itself after. measured on an emulated 50 ms path (On the wire tab, sections 5 and 6): a TLS 1.3 handshake took 53 ms against 107 ms for TLS 1.2, and the first byte came 108 ms after the start on a new connection against 54 ms on a reused one.

  • Reuse is the biggest lever. A connection pool (HTTP keep-alive) skips the TCP and TLS round trips on every later request; a client that opens a fresh connection per request pays them every time. The cost of reuse is an idle connection that a NAT or load balancer may silently forget (section 4).
  • TLS 1.3 halves TLS 1.2's cost because the client sends its key share in its very first message instead of waiting to be told which one to use. TLS 1.2 is now in feature freeze ({{RFC 9851|https://www.rfc-editor.org/rfc/rfc9851}}).
  • HTTP/3 merges transport and encryption into one round trip because QUIC has TLS 1.3 built into its handshake ({{RFC 9001|https://www.rfc-editor.org/rfc/rfc9001}}).
  • Resumption and 0-RTT: a resumed TLS session skips the certificate, and TLS 1.3 can even send data in the very first message, but that early data can be replayed by an attacker ({{RFC 9846, section 8|https://www.rfc-editor.org/rfc/rfc9846#section-8}}), so it is only safe for requests that may run twice; a generation request or an agent's tool call is not one of them.

Bandwidth has a round-trip ceiling too. Once data flows, one connection carries at most one window of unacknowledged bytes per round trip: throughput ≤ window / RTT. That is why one checkpoint upload between regions uses a fraction of a fast link, and why every fix is parallel streams.
