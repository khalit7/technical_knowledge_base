Outside sources

  • {{learncpp.com|https://www.learncpp.com/}}: the best free structured course; teaches modern C++, not C with classes. About 40 h for the sequence; lessons about 10 min each.
  • A Tour of C++ (Stroustrup): the short, authoritative overview once you know the basics. Book, about 7.5 h.
  • Effective Modern C++ (Meyers): still the clearest on moves, forwarding references and auto, though it stops at C++14. Book, about 8 h.
  • {{cppreference.com|https://en.cppreference.com/}}: the reference, precise where tutorials are vague; its compiler support tables answer "can I use X". About 1 h to learn to navigate, then lookup.
  • {{C++ Core Guidelines|https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines}}: the hygiene canon: ownership, RAII, interfaces. About 3 h for a full read.
  • {{Compiler Explorer|https://godbolt.org/}}: see the assembly your abstraction produced; the best learning tool in the language. Tool.
  • {{CppCon talks|https://www.youtube.com/@CppCon}}: Sean Parent's Better Code series, Chandler Carruth on optimisation, the Back to Basics track. About 1 h per talk.
  • {{Clang sanitizer docs|https://clang.llvm.org/docs/AddressSanitizer.html}}: what ASan, UBSan and TSan catch and how to run them. About 30 min.
  • Optimized C++ (Guntheroth) and {{Agner Fog's manuals|https://www.agner.org/optimize/}}: for performance work, with the machine page. Book about 9.5 h; the C++ manual about 5 h.
