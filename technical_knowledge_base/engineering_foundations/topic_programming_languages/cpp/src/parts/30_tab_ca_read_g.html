16. A learning path, with gates

C++ is the language where self-assessment is least reliable: you can be productive for years while holding a wrong model of object lifetime. The old page's ladder still fits, condensed; each stage ends with a gate, a question you should answer from the language rules, not by experiment. The {{Predict the output|#t-ca-drill}} tab has the gates with worked answers.

Best resources

learncpp.com

The best free structured course; teaches modern C++, not C with classes. About 40 h for the sequence; lessons about 10 min each.

A Tour of C++ (Stroustrup)

The short, authoritative overview once you know the basics. Book, about 7.5 h.

Effective Modern C++ (Meyers)

Still the clearest on moves, forwarding references and auto, though it stops at C++14. Book, about 8 h.

cppreference.com

The reference: precise where tutorials are vague; its compiler support tables answer "can I use X". About 1 h to learn to navigate, then lookup.

C++ Core Guidelines

The hygiene canon: ownership, RAII, interfaces. About 3 h for a full read.

Compiler Explorer

See the assembly your abstraction produced; the best learning tool in the language. Tool.

CppCon talks

Sean Parent's Better Code series, Chandler Carruth on optimisation, the Back to Basics track. About 1 h per talk.

Clang sanitizer docs

What ASan, UBSan and TSan catch and how to run them. About 30 min.

Optimized C++ (Guntheroth) and Agner Fog's manuals

For stage 3, with Part 2 of this page. Book about 9.5 h; the C++ manual about 5 h.
