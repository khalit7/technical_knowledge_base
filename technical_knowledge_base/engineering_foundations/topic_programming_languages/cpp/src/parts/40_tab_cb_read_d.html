5. The compiler's view: reading assembly

A compiler (here clang, which hands its work to LLVM) translates C++ into machine code, the instructions the processor runs. Assembly is the readable text form of machine code. You do not need to write it; reading a little of it is the only reliable way to know what your C++ became. Get it with clang++ -O2 -S file.cpp -o -, or paste code into {{Compiler Explorer (godbolt.org)|https://godbolt.org/}}, which colours each source line and its instructions alike.

6. SIMD: one instruction, several numbers


SIMD (single instruction, multiple data) instructions apply one operation to a short vector of values held in one wide register. On ARM the SIMD instruction set is NEON: 32 registers of 128 bits, each holding 4 floats, 8 16-bit values or 16 bytes. fmla v0.4s, v1.4s, v2.4s does four multiply-adds at once. On x86, the same ideas are SSE (128 bits), AVX2 (256 bits: 8 floats) and AVX-512 (512 bits: 16 floats), with intrinsics such as _mm256_fmadd_ps ({{Intel intrinsics guide|https://www.intel.com/content/www/us/en/docs/intrinsics-guide/index.html}}). This M1 Pro also reports the dot-product extension for 8-bit integers (FEAT_DotProd: 1), but not BF16, I8MM or SME (all 0 in the sysctl output above); llama.cpp's quantised kernels check for exactly these features.


There are three ways to get SIMD code: let the compiler vectorise a plain loop, write intrinsics (C functions that map one to one onto SIMD instructions, from <arm_neon.h>; {{Arm intrinsics reference|https://developer.arm.com/architectures/instruction-sets/intrinsics/}}), or call a library that did (BLAS, Accelerate, ggml). So reordering is not "less accurate" in general: it is different, and here better. -ffast-math also assumes there are no NaNs or infinities, which can silently break code that checks for them; prefer intrinsics, a local permission such as clang's #pragma clang fp reassociate(on) at the top of one function (checked here: the plain loop then compiles to fmla.4s accumulators, src/cb/code/reassoc.cpp), or a library.
