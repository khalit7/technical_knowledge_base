Object lifetimes, replayed from real runs

Nine short functions, each run once with a class, Tracer, that prints a line whenever one of its objects is constructed, copied, moved, assigned or destroyed. The animation replays that real output line by line: the code on the left (the highlighted line is the one that caused the event, taken from std::source_location), the live objects in the stack and heap columns, and the output below. Compiled with Apple clang 17, -std=c++23 -O2. Read with sections {{4|#t-ca-read}} to {{6|#t-ca-read}} of the Reading.

What to notice

  • Scopes: destruction is in reverse order of construction, at each closing brace.
  • Copy vs move: b = c is an assignment (b already exists), so no object is created; the moved-from a still gets destroyed.
  • Passing and returning: m is the object constructed inside make() at line 10: returning it cost no copy and no move (copy elision).
  • vector growth, the two versions: the same three push_back calls, 9 objects either way; with a noexcept move the reallocations move the old elements, without it they copy them. Compare the counters.
  • reserve + emplace_back: three objects, built directly in the vector's buffer: no temporaries, no moves.
  • unique_ptr and shared_ptr: one heap object each, never copied; it dies when its last owner lets go.
  • Exception unwinding: b is destroyed before the catch block runs.
