Reading the symbol tables

T (green): a function defined in this object file. U (red): used here, defined elsewhere; the linker must find exactly one T for each U across all inputs, or the system libraries (printf lives in libSystem, linked dynamically). No definition is "Undefined symbols"; two are "duplicate symbol". Names like count_tokens(std::__1::basic_string_view<...>) are C++'s mangled names decoded by nm -C: the parameter types are part of the symbol, which is how overloading works at link time.
