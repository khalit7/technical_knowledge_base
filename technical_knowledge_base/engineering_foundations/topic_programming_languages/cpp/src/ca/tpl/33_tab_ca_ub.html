UB gallery: ten bugs that compile

Each program below has undefined behaviour (Reading section {{12|#t-ca-read}}). Each was compiled with LLVM clang 23.1.2 twice, without optimisation (-O0) and with it (-O2), and run; then with the tool that catches it: a sanitizer, a warning, or a hardened standard library. Every output is the real one (addresses and process ids change from run to run). Notice how often a buggy program prints something plausible, and how often -O0 and -O2 disagree.

Commands as recorded by src/ca/steps/40_ub.sh; each run had a 5-second time limit. Sanitizer reports are shown in full: scroll inside a box to read the whole stack trace.
