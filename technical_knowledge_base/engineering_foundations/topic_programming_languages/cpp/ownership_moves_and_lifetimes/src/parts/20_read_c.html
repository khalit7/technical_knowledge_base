3. Destructors and RAII

A class can define a constructor, which runs when an object is created, and a destructor, written ~ClassName(), which runs automatically when the object dies: at the closing brace for a local, when its owner dies for a member, when delete is called for a heap object. RAII means: tie every resource (memory, a file, a lock, a GPU buffer, a socket) to an object whose destructor releases it. Then you can never forget to release it, even when an exception jumps out of the function.

To watch it happen, this page uses a small class, Tracer, that prints a line from each special member function, numbers its objects #1, #2... and says whether each lives on the stack or the heap. The animations replay that real output one line at a time: the code line that caused the event (taken from std::source_location), the live objects, and the log. Lines starting with @ are the program's own STEP markers, with their line numbers.

Predict, then step: in Scopes, in what order are a, b and c destroyed? In Temporaries, which of t and u outlives its line?

  • Scopes: b dies at its inner brace, before c is even created; at the end, c dies before a: reverse order of construction, always.
  • Temporaries: Tracer{"u"} dies at the semicolon of its own line, right after its size is printed. Tracer{"t"} is bound to const Tracer& r, which extends it to r's lifetime, so it dies at the closing brace. The extension works only for a reference bound directly to the temporary (or to one of its members); a reference returned by a function called on a temporary (make().items()), or a string_view of a temporary string, dangles at the semicolon.
  • Exception unwinding: when throw leaves the try block, C++ unwinds the stack: it destroys every local in the scopes being left (b) before the catch runs. This is why RAII and exceptions work together, and why C++ code almost never needs finally.
Python bridge
with open(p) as f: is RAII you opt into for one block. In C++ every object behaves like a with block, and the "exit" is the destructor. Python's __del__ is not the equivalent: it runs whenever the reference count or the garbage collector gets to it.
Problem it solvesLeaks and forgotten cleanup, including on error paths.
What it costsNothing at run time beyond the destructor's own work.
Common mistakesHolding a resource in a raw pointer instead of an owning object; a destructor that throws (it must not: a second exception during unwinding terminates the program).

tracer.h
// tracer.h: a class that reports every special member function call.
// Each object gets a number (#1, #2, ...) and says whether it lives on the stack or the heap.
#pragma once
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <source_location>
#include <string>
#include <utility>

inline const char* stack_anchor = nullptr;   // set to a local's address in main()
inline int next_id = 1;

inline const char* where(const void* p) {
    long d = static_cast<const char*>(p) - stack_anchor;
    return std::labs(d) < (8L << 20) ? "stack" : "heap";
}
#define STEP(text) std::printf("@%d %s\n", __LINE__, text)
// The line in lifetime.cpp that caused a constructor call (blank when called from inside the library)
inline int at(const std::source_location& l) {
    return std::strstr(l.file_name(), "lifetime.cpp") ? static_cast<int>(l.line()) : 0;
}
using Loc = std::source_location;

template <bool NoexceptMove>
struct BasicTracer {
    int id;
    std::string name;
    explicit BasicTracer(std::string n, Loc l = Loc::current()) : id(next_id++), name(std::move(n)) {
        std::printf("ctor #%d %s %s L%d\n", id, name.c_str(), where(this), at(l));
    }
    BasicTracer(const BasicTracer& o, Loc l = Loc::current()) : id(next_id++), name(o.name) {
        std::printf("copy #%d from #%d %s %s L%d\n", id, o.id, name.c_str(), where(this), at(l));
    }
    BasicTracer(BasicTracer&& o, Loc l = Loc::current()) noexcept(NoexceptMove) : id(next_id++), name(std::move(o.name)) {
        std::printf("move #%d from #%d %s %s L%d\n", id, o.id, name.c_str(), where(this), at(l));
    }
    BasicTracer& operator=(const BasicTracer& o) {
        name = o.name;
        std::printf("copy= #%d from #%d\n", id, o.id);
        return *this;
    }
    BasicTracer& operator=(BasicTracer&& o) noexcept(NoexceptMove) {
        name = std::move(o.name);
        std::printf("move= #%d from #%d\n", id, o.id);
        return *this;
    }
    ~BasicTracer() { std::printf("dtor #%d\n", id); }
};
using Tracer = BasicTracer<true>;     // move constructor marked noexcept
using TracerNX = BasicTracer<false>;  // the same class without noexcept

#include "tracer.h"
#include <cstring>
#include <memory>
#include <stdexcept>
#include <vector>

// <helpers>
void by_value(Tracer) { STEP("inside by_value"); }
void by_ref(const Tracer&) { STEP("inside by_ref"); }
Tracer make(const char* n) { Tracer t{n}; return t; }
// </helpers>

// <scope>
void scope() {
    Tracer a{"a"};
    {
        Tracer b{"b"};
        STEP("end of inner block");
    }
    Tracer c{"c"};
    STEP("end of function");
}
// </scope>

// <copymove>
void copymove() {
    Tracer a{"a"};
    Tracer b = a;             // copy constructor
    Tracer c = std::move(a);  // move constructor: steals a's string
    std::printf("a.name is now \"%s\"\n", a.name.c_str());
    b = c;                    // copy assignment (b already exists)
    STEP("end of function");
}
// </copymove>

// <calls>
void calls() {
    Tracer a{"a"};
    by_ref(a);                // no new object
    by_value(a);              // a copy for the parameter
    by_value(std::move(a));   // a move for the parameter
    Tracer m = make("m");     // no copy, no move: built in place
    STEP("end of function");
}
// </calls>

// <growth>
template <class T>
void growth() {
    std::vector<T> v;
    v.push_back(T{"x"});
    STEP("capacity 1, now push y");
    v.push_back(T{"y"});
    STEP("capacity 2, now push z");
    v.push_back(T{"z"});
    STEP("end of function");
}
// </growth>

// <reserve>
void reserve() {
    std::vector<Tracer> v;
    v.reserve(3);             // one allocation up front
    v.emplace_back("x");      // built directly inside the vector
    v.emplace_back("y");
    v.emplace_back("z");
    STEP("end of function");
}
// </reserve>

// <unique>
void unique() {
    auto p = std::make_unique<Tracer>("h");   // the Tracer lives on the heap
    std::unique_ptr<Tracer> q = std::move(p);  // ownership moves; the Tracer does not
    std::printf("p is %s, q owns #%d\n", p ? "set" : "null", q->id);
    q.reset();                                 // the owner lets go: destroyed now
    STEP("end of function");
}
// </unique>

// <shared>
void shared() {
    auto s = std::make_shared<Tracer>("s");
    {
        std::shared_ptr<Tracer> t = s;         // a second owner
        std::printf("use_count %ld\n", s.use_count());
    }
    std::printf("use_count %ld\n", s.use_count());
    STEP("end of function");
}
// </shared>

// <unwind>
void unwind() {
    Tracer a{"a"};
    try {
        Tracer b{"b"};
        throw std::runtime_error("boom");
        STEP("never reached");
    } catch (const std::exception& e) {
        std::printf("caught %s\n", e.what());
    }
    STEP("end of function");
}
// </unwind>

// <cycle>
struct Node {
    Tracer t;
    std::shared_ptr<Node> next;   // owns the node it points at
    std::weak_ptr<Node> prev;     // observes only
    explicit Node(const char* n) : t{n} {}
};
void cycle() {
    {
        auto a = std::make_shared<Node>("a");
        auto b = std::make_shared<Node>("b");
        a->next = b;
        b->next = a;              // a cycle of owners
    }
    STEP("a and b are unreachable");
    {
        auto c = std::make_shared<Node>("c");
        auto d = std::make_shared<Node>("d");
        c->next = d;
        d->prev = c;              // the back edge only observes
    }
    STEP("end of function");
}
// </cycle>

// <temps>
void temps() {
    const Tracer& r = Tracer{"t"};                // bound to a const&: lives as long as r
    STEP("r is still alive");
    std::printf("size %zu\n", Tracer{"u"}.name.size());  // dies at the semicolon
    STEP("end of function");
}
// </temps>

int main(int argc, char** argv) {
    char here;
    stack_anchor = &here;
    const char* s = argc > 1 ? argv[1] : "";
    if (!std::strcmp(s, "scope")) scope();
    else if (!std::strcmp(s, "copymove")) copymove();
    else if (!std::strcmp(s, "calls")) calls();
    else if (!std::strcmp(s, "growth")) growth<Tracer>();
    else if (!std::strcmp(s, "growth_nx")) growth<TracerNX>();
    else if (!std::strcmp(s, "reserve")) reserve();
    else if (!std::strcmp(s, "unique")) unique();
    else if (!std::strcmp(s, "shared")) shared();
    else if (!std::strcmp(s, "unwind")) unwind();
    else if (!std::strcmp(s, "cycle")) cycle();
    else if (!std::strcmp(s, "temps")) temps();
    std::printf("@0 back in main\n");
}

Every scenario was compiled with clang++ -std=c++23 -O2 -Wall -Wextra lifetime.cpp (Apple clang 17) and run once; src/ca/run_all.sh records them all. The stack or heap label is a heuristic: an address within 8 MB of a local in main counts as stack.

4. Owning heap objects: unique_ptr, shared_ptr and weak_ptr

When an object must live on the heap (it must outlive the function, it is too big for the stack, or its exact type is decided at run time), do not write new and delete. Use a smart pointer: a small stack object that owns the heap object and deletes it in its destructor.

  • std::unique_ptr<T>: exactly one owner. It cannot be copied (two owners would delete twice), only moved (section 5): ownership is handed over and the source becomes null. It is the same size as a raw pointer and costs nothing extra. Create one with std::make_unique<T>(args...). This is the default.
  • std::shared_ptr<T>: shared ownership with a reference count, like a Python object. The object dies when the last shared_ptr to it dies. It costs a separate control block holding the counts, twice the size, and an atomic (thread-safe) increment or decrement on every copy.
  • std::weak_ptr<T>: observes an object owned by shared_ptrs without keeping it alive. It breaks reference cycles, which reference counting alone never frees: Python has a cycle collector; C++ does not.

Predict, then step: in the cycle, which Tracers are ever destroyed?

  • unique_ptr: the Tracer is created once (#1, on the heap) and never copied or moved: moving the unique_ptr moved only the 8-byte pointer, and p became null. reset() destroyed it at that line, before the end of the function.
  • shared_ptr: the count is 2 while t exists and 1 after; the Tracer dies with the last owner, s.
  • The cycle: a and b own each other, so when both locals go, each node still has a count of 1: no destructor ever runs for #1 and #2, and the memory leaks until the process exits. In the second block the back edge is a weak_ptr, so c's count reaches 0 and both nodes go. Note the order: #4 (d's Tracer) dies before #3 (c's), because destroying node c destroys its members in reverse declaration order: prev, then next (releasing d, whose count reaches 0), then t.

Owning costs nothing until you copy a shared_ptr, and much more when threads share one

ptr_cost.cpp measured on the M1 Pro (Apple clang 17, -O2, best of 5 runs, load average 6.70): one non-inlined call that reads an int, 100 million times. Passing a raw pointer, a const unique_ptr& or a const shared_ptr& costs the same, 0.96 ns per call. Passing the shared_ptr by value copies it, two atomic count updates: 13.50 ns. With 4 threads copying the same shared_ptr, every update fights for the cache line holding the count: 302.42 ns per call per thread (why a shared line is that slow is measured in {{C++: the machine underneath|n:4055c17b0d0d811fa947ee576a97a516}}). Scale is logarithmic.

So pass a smart pointer only when the callee takes part in ownership (the C++ Core Guidelines' {{rule R.30|https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#Rr-smartptrparam}}); a function that only uses the object takes T&, const T& or T*. Sizes on this Mac (sizeof, in bytes): int* 8, std::unique_ptr<int> 8, std::shared_ptr<int> 16 (a pointer to the object and one to the control block).

Ruleunique_ptr by default; shared_ptr only when ownership is genuinely shared (a cache entry used by several requests); raw pointers and references only to observe an object someone else owns.
What it costsunique_ptr: nothing. shared_ptr: 16 bytes, a control block allocation, atomic count updates.
Common mistakesshared_ptr everywhere "to be safe" (slow and hides who owns what); two shared_ptrs made separately from one raw pointer (two counts, double delete); cycles of shared_ptr.
Rust bridge
Box<T> is unique_ptr; Rc<T> and Arc<T> are shared_ptr without and with atomic counts; Weak is weak_ptr. Rust's compiler enforces the "do not use after move" rule that C++ only recommends: {{Rust: lifetimes, smart pointers, threads and unsafe|n:4055c17b0d0d8160aa32df9cda0aef03}}.
The benchmark (ptr_cost.cpp), its output, and every sizeof on this Mac
ptr_cost.cpp
// What an owner costs per call: the same function called 100 million times with the object passed
// as a raw pointer, a const unique_ptr&, a const shared_ptr&, and a shared_ptr by value (a copy: two atomic
// count updates). Then 4 threads copying one shared_ptr at once, all updating the same count.
// noinline plus an empty asm statement with a memory clobber keep every call real (without them clang hoisted
// the read-only calls out of the loop and printed 0.00 ns); best of 5 runs; ns per call.
#include <atomic>
#include <chrono>
#include <cstdio>
#include <cstdlib>
#include <memory>
#include <thread>
#include <vector>

#define NOINLINE __attribute__((noinline))
#define KEEP asm volatile("" ::: "memory")
NOINLINE long by_raw(const int* p) { KEEP; return *p; }
NOINLINE long by_uref(const std::unique_ptr<int>& p) { KEEP; return *p; }
NOINLINE long by_sref(const std::shared_ptr<int>& p) { KEEP; return *p; }
NOINLINE long by_sval(std::shared_ptr<int> p) { KEEP; return *p; }

constexpr long N = 100'000'000;
volatile long sink;

template <class F> double best_ns(F f) {
    double best = 1e30;
    for (int r = 0; r < 5; ++r) {
        auto t0 = std::chrono::steady_clock::now();
        long s = 0;
        for (long i = 0; i < N; ++i) s += f();
        sink = s;
        double ns = std::chrono::duration<double, std::nano>(std::chrono::steady_clock::now() - t0).count() / N;
        if (ns < best) best = ns;
    }
    return best;
}

int main() {
    double load[1];
    getloadavg(load, 1);
    std::printf("load average %.2f\n", load[0]);
    auto u = std::make_unique<int>(1);
    auto s = std::make_shared<int>(1);
    std::printf("raw pointer              %.2f ns per call\n", best_ns([&] { return by_raw(u.get()); }));
    std::printf("const unique_ptr&        %.2f ns per call\n", best_ns([&] { return by_uref(u); }));
    std::printf("const shared_ptr&        %.2f ns per call\n", best_ns([&] { return by_sref(s); }));
    std::printf("shared_ptr by value      %.2f ns per call\n", best_ns([&] { return by_sval(s); }));
    // 4 threads, each passing the same shared_ptr by value: the count's cache line moves between cores
    for (int threads : {1, 4}) {
        double best = 1e30;
        for (int r = 0; r < 5; ++r) {
            std::vector<std::thread> ts;
            std::atomic<int> ready{0};
            auto t0 = std::chrono::steady_clock::now();
            for (int t = 0; t < threads; ++t)
                ts.emplace_back([&] {
                    ready++;
                    while (ready < threads) {}
                    long acc = 0;
                    for (long i = 0; i < N / 10; ++i) acc += by_sval(s);
                    sink = acc;
                });
            for (auto& t : ts) t.join();
            double ns = std::chrono::duration<double, std::nano>(std::chrono::steady_clock::now() - t0).count() / (N / 10);
            if (ns < best) best = ns;
        }
        std::printf("by value, %d thread%s on one shared_ptr: %.2f ns per call per thread\n", threads, threads > 1 ? "s" : " ", best);
    }
}
