8. Structs, enums and match: make illegal states unrepresentable

A struct is a record with named fields, like a dataclass. An enum in Rust is far more than Python's Enum: each variant can carry its own data, so one type says "a message is either text from a user, or a tool call with arguments, or an image of some size". This is called a sum type or tagged union. match takes it apart, and must cover every variant.

9. Option, Result and ?: errors as values

Rust has no None that can appear anywhere and no exceptions for expected failures. Two enums from the standard library carry them, written like any other enum:

  • Option<T> is Some(value) or None: maybe missing. dict.get, str.find and "first element" return one.
  • Result<T, E> is Ok(value) or Err(error): may fail. Parsing, I/O and network calls return one.

You cannot use the value inside without deciding what happens in the other case. The ? operator is the common decision: "if this is an Err, return it from my function now; otherwise give me the value". It is the explicit, typed version of letting an exception propagate.

10. Traits and generics: duck typing, checked

A trait names a set of methods a type promises to provide, like a Python Protocol, except that a type must say so explicitly (impl Tokenizer for Whitespace) and the compiler checks it before the program runs. A trait may have default methods written in terms of the others. A generic function takes a type parameter with a bound: fn total<T: Tokenizer> accepts any T that implements Tokenizer.

11. Iterators and closures: lazy pipelines that cost nothing

An iterator in Rust is any type with a next() method returning Option<Item>, the same protocol as Python's __next__ raising StopIteration. Adapters such as map, filter, zip, enumerate, take build a lazy pipeline, like a generator expression; a consumer (collect, sum, count, fold, a for loop) runs it. A closure is an anonymous function that can capture variables from where it is written: |x| x * 2 is Python's lambda x: x * 2, but with any number of statements.

[[code:lang/iters.rs]] [[pr:l_iters|Which line comes first: "built the iterator" or "computing 1"? And how many times does "computing" print?]]

Closures capture in the least demanding way that works, and the compiler records which in the closure's type: Fn (reads captured values), FnMut (changes them: count above), FnOnce (moves them out, so it can run once). move before a closure makes it take ownership of what it captures, needed when the closure outlives the current function (threads, section 16).
