Python dicts keep insertion order (guaranteed since 3.7); Rust's HashMap does not, and its default hasher (SipHash 1-3) is randomly seeded so that an attacker who controls the keys cannot force collisions ("HashDoS"), as the {{HashMap documentation|https://doc.rust-lang.org/std/collections/struct.HashMap.html}} explains. 13. Modules, crates and visibility

  • A package is what cargo new makes (one Cargo.toml); it contains a library crate (src/lib.rs), and/or one or more binary crates (src/main.rs, src/bin/*.rs). A crate is the unit the compiler builds at once.
  • A module is a namespace inside a crate: mod tokenize; in lib.rs loads src/tokenize.rs. Paths use :: (crate::tokenize::count_tokens); use imports a name, like Python's from x import y.
  • Everything is private by default, visible only inside its module and its children. pub exports it; pub(crate) exports it within the crate only. Python's leading underscore is a convention; this is enforced:

14. Testing: unit, integration, documentation

Testing is built into the language and cargo, with no framework to install. Three kinds:

  • Unit tests live next to the code in a #[cfg(test)] mod tests (compiled only for cargo test) and may test private functions.
  • Integration tests are files in tests/, compiled as a separate crate, so they see only the public API; they can also run the built binary.
  • Documentation tests: code blocks inside /// doc comments are compiled and run, so the examples in the docs cannot rot.

15. Smart pointers and interior mutability

Single ownership and compile-time borrowing cover most code. For the rest, the standard library has types that own their contents in other ways, each with a cost:

TypeWhat it gives youCostPython analogue
Box<T>one owner, value on the heap; needed for recursive types and trait objectsone allocationevery object

Reference cycles leak

Reference counting cannot free a cycle, in Rust as in Python (where the cycle collector cleans up afterwards; Rust has none). Leaking memory is safe in Rust's sense, so the compiler allows it:

[[code:lang/leak.rs:20-37]] [[pr:l_leak|Which of the four nodes print "drop"?]]

Rule of thumb: ownership should form a tree. Back pointers (child to parent, node to previous) are Weak, or better, indexes into a Vec that owns all the nodes (an "arena"), which is how most Rust graph code is written.
