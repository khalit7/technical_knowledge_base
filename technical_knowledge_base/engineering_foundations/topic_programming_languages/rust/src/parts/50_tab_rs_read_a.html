Part 3: services and command-line tools. Part 1 taught the language; Part 2 put Rust inside Python. This part builds the two other things an ML engineer writes in Rust: a command-line tool you can hand to anyone as one file, and an HTTP service that stays fast and small under load. Both are built from the root page's running program (count tokens per user in a JSONL chat log, {{Rosetta tab|n:3c65c17b0d0d81a2bb1ac0bc8aeb6aa9}}), so the logic is familiar and the new parts stand out. On the way it teaches async Rust from zero, compared step by step with Python's asyncio and JavaScript's event loop. Every output on this page is a real recording from this Mac (Apple M1 Pro, rustc 1.99.0, tokio 1.53.2, axum 0.8.9, clap 4.6.7), reproduced by src/rs/run_all.sh.
