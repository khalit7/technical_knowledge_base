Borrow-checker lab

Fifteen pieces of code a Python programmer writes in the first week, each with the compiler's real answer (rustc 1.99.0), how to read it, and a fix that was compiled and run. Pick one, decide what you think happens, then reveal. Fourteen are refused at compile time (one of them wrongly: the code is safe), and one compiles and fails at run time.

Anatomy of a borrow error

$ rustc --edition 2024 gate_err.rs
error[E0502]: cannot borrow `v` as mutable because it is also borrowed as immutable
 --> gate_err.rs:4:5
  |
3 |     let first = &v[0];
  |                  - immutable borrow occurs here
4 |     v.push(2);
  |     ^^^^^^^^^ mutable borrow occurs here
5 |     println!("{first}");
  |                ----- immutable borrow later used here

error: aborting due to 1 previous error

For more information about this error, try `rustc --explain E0502`.
[exit code 1]
  1. error[E0502]: the error code. rustc --explain E0502 prints a page about it.
  2. --> gate_err.rs:4:5: file, line, column of the main conflict.
  3. Labels in source order: where the first borrow begins (immutable borrow occurs here), the conflicting use (mutable borrow occurs here, the ^^^ span), and why the first borrow is still alive (later used here).
  4. help: lines, when present, are a concrete edit; +++ marks inserted text, ~ changed lines.
