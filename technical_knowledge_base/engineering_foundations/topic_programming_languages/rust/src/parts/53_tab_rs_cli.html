CLI replay: predict the exit code

Eleven recorded sessions of tokcount (and one naive program), in the order a user would meet them. Each command is typed out; before the output appears, guess the exit code a shell script would see ($?). All outputs are real recordings from src/rs/run_all.sh.











Exit codes used: 0 success; 1 our runtime error (anyhow, from main); 2 clap usage error; 3 our "dirty data" code from --strict; 101 a Rust panic. For pipes, the code shown is the left-hand program's (${pipestatus[1]} in zsh).
