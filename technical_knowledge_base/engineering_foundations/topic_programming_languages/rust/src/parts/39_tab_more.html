Outside sources

  • The Rust Programming Language (the Book): the canonical introduction, free. Chapter 4 (ownership) is the one not to skim. about 10 h
  • Rustlings: small exercises the compiler guides you through; pairs with the Book. about 8 h
  • Rust by Example: runnable examples per topic, for when you want code rather than prose. about 4 h
  • cheats.rs: the whole language on one dense page; read it once after the children. about 45 min
  • Learn Rust With Entirely Too Many Linked Lists: the best cure for fighting the borrow checker: ownership, Box, Rc, RefCell and unsafe on one data structure. about 4 h
  • Rust for Rustaceans (Jon Gjengset): the intermediate-to-advanced book; his streams build real crates live. about 6 h
  • The Rustonomicon: for unsafe: what you must uphold and why. about 3 h
  • Rust API Guidelines: how to design a library others will enjoy using. about 1 h
  • Compiler error index: every error code with examples; the same text as rustc --explain. reference
  • Rust blog: one post per six-week release. about 20 min per release
