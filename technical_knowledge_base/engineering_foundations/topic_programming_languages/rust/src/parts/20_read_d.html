6. Modules, crates and visibility

  • A package is what cargo new makes (one Cargo.toml); it contains a library crate (src/lib.rs), and/or one or more binary crates (src/main.rs, src/bin/*.rs). A crate is the unit the compiler builds at once.
  • A module is a namespace inside a crate: mod tokenize; in lib.rs loads src/tokenize.rs. Paths use :: (crate::tokenize::count_tokens); use imports a name, like Python's from x import y.
  • Everything is private by default, visible only inside its module and its children. pub exports it; pub(crate) exports it within the crate only. Python's leading underscore is a convention; this is enforced: calling a private tokenizer::split from outside its module is E0603, "function split is private".

8. If you know some C++

Rust's ownership is C++'s RAII plus move semantics, with the compiler enforcing what the C++ Core Guidelines only recommend ({{C++: the essentials|n:3cd5c17b0d0d81ceadcee44fe9c023a0}} and {{C++: ownership, moves and object lifetimes|n:4055c17b0d0d81819d74fa010e68ac2a}} teach the C++ side).

Nine C++ constructs and their Rust counterparts
C++RustThe difference
auto b = std::move(a);let b = a;Moves are the default and the moved-from variable is unusable (a compile error), not "valid but unspecified".
destructorimpl DropSame deterministic order (reverse of declaration).
const T&, T&&T, &mut TAliasing XOR mutation is checked, so iterator invalidation and dangling references do not compile.

templates, conceptsgenerics with trait boundsBoth monomorphise; Rust checks the generic body against the bounds once, at definition, so errors are short.
virtualdyn TraitOpt-in at the use site, no inheritance; the vtable pointer lives in the fat pointer, not in the object.
unique_ptr, shared_ptrBox, Rc/ArcRc is a non-atomic shared_ptr, allowed only on one thread (not Send).
exceptions, std::expectedResult and ?Panics exist but are for bugs.
everythingunsafe { }C++'s rules apply only inside the block, and the block is searchable.

No function overloading and no implicit conversions; prefer indexes and arenas to pointer graphs, because self-referential structs are the design Rust refuses.
