15. Common mistakes

Timing a debug build
maturin develop without --release builds without optimisation. Always benchmark release builds.
One call per element
Each crossing costs about as much as counting a 125-character message (section 4). Pass the list, return a list or an array.
Porting one function inside a Python hot path
The rest of the path still runs in Python (section 1). Move the whole path, or measure what is left first.
Owned types everywhere
Vec<String>, HashMap and Vec<f64> copy; use &str, &[u8], &Bound<PyList>, NumPy views unless Rust must keep the data.
Holding the GIL through long Rust work
Other Python threads stop (section 8). Wrap pure-Rust work in py.detach.
A &mut self class shared between threads
Works on the GIL build, raises Already borrowed on 3.14t (section 9). Use frozen plus a Mutex or atomics, and run tests on 3.14t.
Catching PanicException with except Exception
It derives from BaseException. A panic is a bug: return PyResult instead.
Forgetting to restart Python after a rebuild
A process cannot unload a shared library it has loaded, so importlib.reload will not pick up the new build. Restart the interpreter or notebook kernel.
Module name mismatch
The #[pymodule] name, the library name in Cargo.toml and module-name in pyproject.toml must agree, or import fails because CPython cannot find PyInit_<name>.
Rewriting NumPy
A plain Rust loop lost to np.dot by x (section 5).
Shipping only an abi3 wheel
Free-threaded users cannot install it (section 12): add cp314t wheels, or abi3t once you can require 3.15.
No stub file
Type checkers then know nothing about your module (section 11).
