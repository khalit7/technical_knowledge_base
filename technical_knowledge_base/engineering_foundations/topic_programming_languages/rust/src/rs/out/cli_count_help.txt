$ tokcount count --help
Count tokens per user in one or more JSONL files ("-" reads stdin)

Usage: tokcount count [OPTIONS] <FILES>...

Arguments:
  <FILES>...  Input files; "-" means standard input

Options:
  -n, --top <TOP>  How many users to list [default: 5]
      --json       Print JSON instead of text
      --strict     Exit with code 3 if any line is malformed
  -h, --help       Print help
[exit 0]
