$ tokcount --help
Count word-ish tokens per user in JSONL chat logs

Usage: tokcount <COMMAND>

Commands:
  count  Count tokens per user in one or more JSONL files ("-" reads stdin)
  text   Count tokens in a piece of text (an argument, or stdin when absent)
  help   Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
[exit 0]
