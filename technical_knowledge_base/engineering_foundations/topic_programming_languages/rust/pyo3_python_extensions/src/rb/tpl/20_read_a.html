A Rust extension pays off only when the whole hot path crosses into Rust in one big call, borrowing Python's memory instead of copying it and releasing the GIL while it works; moving one function inside a Python loop leaves the program waiting on the Python that is left.

Moving only the token loop made the program 3x faster; moving the parsing too, on 8 threads, made it 23x

The running example: the root page's count_tokens program on a 200,000-line JSONL chat log (38.8 MB), cut into phases and timed inside the process (milliseconds, medians of 5, code/ladder.py --phases), all four bars on one scale measured. In the second bar the token loop has shrunk from ms to ms, and json.loads (still Python) is now most of the bar. The third bar moves the parsing into Rust too; the fourth releases the GIL and splits the work over 8 threads. Section 10 walks every step.

You need: ownership, borrowing and Result from {{Rust: the essentials|n:3c65c17b0d0d8156bed9ead8a22f33b0}}; String against &str, Result and ? from {{Rust: enums, traits, errors and iterators|n:4055c17b0d0d8129b199c18b4bd56935}}; lifetimes, Mutex and Send from {{Rust: lifetimes, smart pointers, threads and unsafe|n:4055c17b0d0d8160aa32df9cda0aef03}}. On the Python side, profiling and why the interpreter is slow are {{Python: CPython internals and performance|n:4055c17b0d0d8111872ad7101b7e3c22}}; the GIL and the free-threaded build are {{Python: concurrency, asyncio and the GIL|n:4055c17b0d0d81bdbee8c37d80b55a0e}}; wheel tags and publishing are {{Python: typing, uv, packaging and the toolchain|n:4055c17b0d0d8192878fce7505cc612f}}.

Extension module
a compiled shared library (.so, .pyd on Windows) that import loads like a .py file; NumPy, PyTorch and orjson are extension modules.
PyO3
a Rust crate that wraps CPython's C API: Rust types for Python objects, conversions, and macros that make a Rust function callable from Python.
maturin
the build tool: compiles the crate with cargo and packs it into a wheel; also a PEP 517 build backend.
Crossing
one call from Python into Rust: argument checks and conversions in, the result converted back out.
Borrowed, owned
an argument Rust reads in place in Python's memory (a view), or copies into its own value.
Detach
py.detach(...): release the GIL while pure-Rust work runs (called allow_threads before PyO3 0.26).
#[pyclass]
a Rust struct that Python sees as a class, so state stays in Rust between calls.
abi3, abi3t
CPython's stable ABI: one wheel for many Python versions; abi3t is the version free-threaded builds can load (3.15+).

How everything on this page was measured

Every code block is a file in src/rb/ of this page's folder and every output block is its real output, recorded on 2026-10-05 on an Apple M1 Pro (8 performance and 2 efficiency cores, macOS 27) with CPython 3.14.8, Rust 1.99.0, PyO3 0.29.3 and maturin 1.15.0 (exact versions in src/rb/versions.txt; src/rb/run_all.sh reproduces everything in about 10 minutes). Timings are medians of 7 runs with the spread beside them; the laptop was in normal use (load average 9 to 12 on 10 cores during the recorded runs, up to 26 during earlier trial runs), so read the second digit of any timing as noise. The 200,000-line input is regenerated from the root's rosetta/data/gen_chat.py --lines 200000 --seed 7 (same sha256 as the root's benchmark). tokrs, the extension built here, was not published to PyPI.
