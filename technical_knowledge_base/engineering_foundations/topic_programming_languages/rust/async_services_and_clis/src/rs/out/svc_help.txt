Serve the token counter over HTTP. Every flag can also come from the environment

Usage: tokserve [OPTIONS]

Options:
      --addr <ADDR>              Address to listen on [env: TOK_ADDR=] [default: 127.0.0.1:3000]
      --max-body <MAX_BODY>      Largest request body accepted, in bytes [env: TOK_MAX_BODY=] [default: 1048576]
      --timeout-ms <TIMEOUT_MS>  Per-request time limit, in milliseconds [env: TOK_TIMEOUT_MS=] [default: 1000]
      --workers <WORKERS>        Async worker threads (default: one per CPU core) [env: TOK_WORKERS=]
      --inline                   Count large bodies inline on the async worker instead of the blocking pool
  -h, --help                     Print help
  -V, --version                  Print version
