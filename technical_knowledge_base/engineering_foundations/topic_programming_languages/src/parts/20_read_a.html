Four languages in one screen

About 40 minutes to read, plus the optional animations and code panels. It starts from zero: every term is explained where it first appears and collected in the Glossary. Every code snippet on this page was run for it, and every output and compiler message is the real text (toolchains: ). C++ examples were compiled with Apple clang 17 from the Command Line Tools (the macOS 26 SDK, which has C++23's <expected>); sanitizer runs used LLVM clang 23.1.2, because Apple's sanitizer runtimes do not start on macOS 27. The Benchmark and Rosetta tabs used this Mac's older Apple clang 14. Numbers marked measured were measured for this page on one laptop; illustrative marks a picture that shows a shape rather than data.

A programming language is a set of decisions about what the machine should do for you and what you must do yourself. Python, C++, Rust and TypeScript made those decisions differently because each was built to answer a different founding problem. Once you know the problem, almost every rule of the language follows from it, and the rules stop looking arbitrary.

How this page teaches. You know Python, so Python is the reference column everywhere: each section shows what Python does, then what each other language makes you do instead, and why. Research on experienced programmers learning a second language found that they learn by mapping onto what they already know, and that most of their trouble comes from the places where the mapping silently breaks: in 450 Stack Overflow questions across 18 languages the authors found 276 instances of interference from a faulty assumption carried over from another language, and interviews showed programmers "make failed attempts to relate a new programming language with what they already know" ({{Shrestha, Botta, Barik and Parnin, ICSE 2020|https://doi.org/10.1145/3377811.3380352}}). So every section ends with a false friends box: things that look like Python and are not.

One running program. All four languages solve the same small job, the kind of tool an ML engineer writes every week: read a chat log in JSON Lines (one JSON object per line), count word-like tokens in each message, add them up per user, and print the five heaviest users. Malformed lines are counted and skipped. The {{Rosetta|#t-rosetta}} tab has the four complete programs side by side, the {{Benchmark|#t-bench}} tab times them, and this tab uses pieces of them to explain each axis.

The one idea to keep
Each language moved one kind of mistake to a different moment. Python finds it while the program runs and tells you clearly. C++ trusts you and, when you are wrong, may give no signal at all (undefined behaviour). Rust refuses to compile until it can prove a whole class of mistakes absent. TypeScript checks while you edit, then removes every check before the code runs. Most of what feels strange in a new language is that language catching, at its moment, a mistake Python would have caught at a different one.
