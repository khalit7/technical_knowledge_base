October 2025 release notes, plus the free-threaded build's costs and status. When: before using threads for CPU work. (45 min)

C++: official references and books

cppreference.com

The community reference for the language and standard library, with the version each feature appeared in and compiler support tables. For: looking things up, precisely. When: from the first day of step 3. (lookup)

A Tour of C++, third edition

Bjarne Stroustrup, Addison-Wesley, September 2022; covers "C++20 plus a few likely features of C++23". For: the whole modern language in 254 pages, from its designer, for "experienced programmers". When: after the C basics of step 3a. (8 h)

C++ Core Guidelines

Stroustrup and Sutter, continuously updated. For: which subset of C++ to write (RAII, ownership, no naked new). When: while writing your first C++ milestone. (2 h for the "P", "R" and "ES" sections)

Clang: AddressSanitizer and ThreadSanitizer

LLVM documentation for the tools that produced the reports on this page. When: before your first C++ program with pointers. (20 min)

Compiler Explorer

See the machine code of any snippet under any compiler, as section 2 did locally. When: whenever you wonder what an abstraction costs. (tool)

llama.cpp

The reading target of step 3; this page pinned commit 8e1642198dcd (5 October 2026). Start at ggml/include/ggml.h and ggml/src/ggml-cpu/quants.c. When: end of step 3. (weeks, in pieces)

Rust: official books

The Rust Programming Language ("the Book")

Klabnik, Nichols and Krycho; the current online text assumes Rust 1.97.0 (2026-07-09) or later and the 2024 edition. For: learning the language; chapter 4 (ownership) is the one that matters most. When: step 2, first. (15 h)

Rust by Example and Rustlings

Runnable examples, and small exercises that the compiler grades. When: alongside the Book. (4 h and 8 h)

The PyO3 user guide and maturin

PyO3 0.29.3 when checked. For: writing Python extensions in Rust and building wheels. When: the first milestone of step 2. (2 h)

The Rustonomicon

The official guide to unsafe Rust: what undefined behaviour means in Rust and how to build safe abstractions over raw pointers. When: only once you need unsafe or FFI. (3 h)

The Edition Guide and release notes

What each edition and six-weekly release changed. When: when code from an older tutorial does not compile. (20 min)
