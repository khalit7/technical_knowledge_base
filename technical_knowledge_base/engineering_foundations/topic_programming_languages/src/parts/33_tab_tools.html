Toolchain atlas

Every job a project needs done, from installing the language to calling the other three, and the tool each ecosystem uses for it, with the version that was current on 2026-10-05, the official page it was read from, and the one command a beginner types. Python is the reference: every other cell says what the Python equivalent is, and where the analogy breaks.

Try: click a cell to open it below; untick languages to narrow the grid; type a tool name to find where it sits.

Each walkthrough was run for real on 2026-10-05 in an empty folder; the output is the actual terminal output, trimmed only where marked. The same tiny program in every language: count runs of ASCII letters and digits in "Hello from hello-tokens, x86_64 café!", which prints 7 (the é splits café, the underscore splits x86_64).
