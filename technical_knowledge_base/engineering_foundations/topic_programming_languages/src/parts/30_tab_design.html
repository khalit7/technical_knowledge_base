This tab is the comparison core of the topic. Every row is a design question (an axis), every column a language, and Python is the reference column, because experienced programmers learn a new language by mapping it onto the one they know, and go wrong exactly where the mapping breaks: Shrestha, Botta, Barik and Parnin found 276 such cases of interference in 450 Stack Overflow questions across 18 languages, and interviewed programmers who "make failed attempts to relate a new programming language with what they already know" ({{ICSE 2020, doi 10.1145/3377811.3380352|https://doi.org/10.1145/3377811.3380352}}). Comparing worked solutions side by side helps conceptual learning ({{Rittle-Johnson and Star 2007|https://doi.org/10.1037/0022-0663.99.3.561}}). So each cell gives the language's choice, a small real program with its real output or real compiler error, what the choice buys and costs, and the founding value it comes from. The False friends view collects the places where Python habits mislead.
