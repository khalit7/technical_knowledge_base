The idea in one screen

Every operator, loop, with block and attribute access is a call to a special method looked up on the object's type, with a fixed order of fallbacks when the method is missing or declines; implement the methods and your class behaves like a built-in, and almost every Python surprise is one of these lookups doing exactly what the rules say.

Five pieces of syntax, five lookups on the type: blue runs first, each later box only if the one before declines

v + 1→type(v).__add__(v, 1)returned NotImplemented?→type(1).__radd__(1, v)declined too?→TypeErrorsection 1
a == b→type(a).__eq__(a, b)NotImplemented?→type(b).__eq__(b, a)declined too?→a is bsection 1
for x in xs→iter(xs): __iter__→__next__ … until StopIterationno __iter__?→__getitem__(0), (1), … until IndexErrorsection 3
obj.attr→data descriptor on type(obj)→obj.__dict__→class attribute or method→__getattr__→AttributeErrorsection 5
with m as r→r = type(m).__enter__(m)→body→__exit__(type, value, tb), alwaysreturned true?→exception swallowedsection 7

Rules from the language reference's {{Data model|https://docs.python.org/3/reference/datamodel.html}} chapter. The Data model explorer in section 1 replays 19 such lookups step by step from a real run that logged every method Python called.

Type hints that describe these protocols (Protocol, Iterator[T]) are on {{Python: typing, uv, packaging and the toolchain|n:4055c17b0d0d8192878fce7505cc612f}}; this page is what happens when the code runs.

Special method
a double-underscore ("dunder") method such as __add__ that syntax calls for you.
Protocol
a set of special methods that makes an object usable somewhere (iteration, with, +); no base class needed.
NotImplemented
the value an operator method returns to say "not my type; ask the other operand".
Closure, cell
a function that keeps variables of the function that made it, stored in cells.
MRO
method resolution order: the list of classes that attribute lookup and super() walk.
Descriptor
a class attribute with __get__ (data descriptor: also __set__) that runs on attribute access; property, methods and slots are descriptors.
Exception group
one exception carrying several, handled with except*.
