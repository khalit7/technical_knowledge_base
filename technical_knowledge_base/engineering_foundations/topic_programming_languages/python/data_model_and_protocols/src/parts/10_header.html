Python: the data model and protocols

How Python turns syntax into method calls on your types: operators and equality, copying and argument passing, iterators and generators, closures and decorators, the MRO, dataclasses, slots and descriptors, exceptions and context managers. Every example was run on CPython 3.14.8 (and 3.13.16 where the versions differ) on an Apple M1 Pro; the boxes under the code are the real outputs. A child of Python: the essentials.
