The idea in one screen

CPython runs your code as bytecode in a loop written in C, and every value is a separate heap object, so a Python loop pays an interpreter step and new objects for every element. Speed comes from moving the loop out of Python (into built-ins, NumPy or native code), and from measuring first to find the one loop that matters.

The same reduction over a million floats: 47.6 ms as a Python loop, 3.2 ms as one NumPy call

Notice where the work sits. Top: a list holds a million pointers to separate float objects, and the C evaluation loop runs the loop body's bytecode once per element, making three new floats each time (x - m, the exp, the new s). Bottom: one call, three C loops over one contiguous buffer of 8-byte doubles, no objects per element. Times are the real p2_numpy run of section 4 (CPython 3.14.8, NumPy 2.5.3, Apple M1 Pro).

Within Python a remedy buys under 3x; moving the loop out buys 15x

Speed-up of each remedy measured on this page, on the same machine (different workloads, named in each bar). The specialising interpreter (section 1) is already in the "Python loop" time; the JIT (section 5) is off by default.

Bytecode
instructions for CPython's virtual stack machine, compiled from your source and cached in __pycache__/*.pyc.
Evaluation loop
the C loop (Python/ceval.c) that executes bytecode one instruction at a time.
Specialising interpreter
since 3.11, an instruction that keeps seeing the same types is rewritten in place into a faster, type-specific version.
Reference count
the number of references to an object, stored in its header; at zero the object is freed at once.
Cycle collector
the gc module's periodic search for objects that refer only to each other.
Deterministic, sampling profiler
records every call (cProfile), or looks at the stack a few hundred times a second (py-spy, Scalene).
Vectorise
replace a per-element Python loop with one call that loops in C over a typed buffer.
JIT
just-in-time compiler: turns hot code into machine code while the program runs; CPython's is experimental and off by default.
