6. What changed from 3.12 to 3.15, and what it means for your code

A new CPython ships every October ({{PEP 602|https://peps.python.org/pep-0602/}}) and gets two years of bug fixes, then security fixes until five years. 3.15.0 was released on 2026-10-09 and is the newest feature line; 3.14 (3.14.8) is in bug fixes, 3.12 and 3.13 get security fixes only ({{PEP 790|https://peps.python.org/pep-0790/}}; {{devguide|https://devguide.python.org/versions/}}). The measurements on this page used 3.15.0rc3 (2026-10-02), the last release candidate before the final.

The quiet one: UTF-8 by default

Before 3.15, open() without encoding= used the locale's encoding, so the same script read a file differently on a Windows machine or a server with a Latin-1 locale. The same two-line snippet, run under an en_US.ISO8859-1 locale (the plain C locale already turns UTF-8 mode on):

So move to 3.15 deliberately: lazy import for CLIs, and pass encoding= wherever you open text files, because on 3.15 the default is UTF-8 on every platform while older versions in your support range still use the locale.

Corrections to the old page "Python: staying current"
  • "Python 3.15 is due 2026-10-01": a third release candidate was added (2026-10-02) and the final shipped on 2026-10-09 (PEP 790).
  • "Python 3.15 ... lazy imports and abi3t are its headline items": true but incomplete; What's New also lists frozendict, sentinel, UTF-8 as the default encoding, unpacking in comprehensions, the Tachyon profiler and the JIT upgrade as highlights.
  • "abi3t lets NumPy-class extensions ship one wheel per platform": imprecise. One cp315-abi3.abi3t wheel covers 3.15 and later on both builds, but free-threaded 3.14 still needs its own wheel, and of 25 popular compiled packages only one (cryptography) ships an abi3t wheel today (the wheel survey is on {{Python: typing, uv, packaging and the toolchain|n:4055c17b0d0d8192878fce7505cc612f}}).
  • "from __future__ import annotations is finally obsolete": imprecise. It still works and is deprecated; What's New 3.14 says removal will not happen before 3.13's end of life in 2029.
  • "t-strings ... showing up in LLM prompt-templating libraries": no source given; not confirmed here, so left out.
