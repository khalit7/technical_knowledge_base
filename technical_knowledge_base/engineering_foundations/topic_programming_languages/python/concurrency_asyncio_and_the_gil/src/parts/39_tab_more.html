The language page and its siblings

  • {{Python: the essentials|n:3cd5c17b0d0d81b28acdea39e7a4d998}}: names and objects, the one interpreter, traps that cut across the Python pages, and choosing a tool.
  • {{Python: the data model and protocols|n:4055c17b0d0d816a8705e4d3f20b3da7}}: generators (the ancestor of coroutines), context managers (async with is the same protocol with awaits), exception groups (what TaskGroup raises).
  • {{Python: CPython internals and performance|n:4055c17b0d0d8111872ad7101b7e3c22}}: bytecode, reference counts, profiling and moving the loop to native code; the experimental JIT measured.
  • {{Python: typing, uv, packaging and the toolchain|n:4055c17b0d0d8192878fce7505cc612f}}: installing 3.14t with uv, and wheel tags (cp314t, abi3, abi3t).
  • {{Topic: programming-languages|n:3c65c17b0d0d81a2bb1ac0bc8aeb6aa9}}: concurrency in four languages (section 9) and the Benchmark tab, where the same token counter runs in Python (GIL and free-threaded), C++, Rust and TypeScript.

Outside sources

  • {{asyncio documentation|https://docs.python.org/3/library/asyncio.html}}, especially {{Developing with asyncio|https://docs.python.org/3/library/asyncio-dev.html}} (debug mode, blocking calls). 2 h; the developing page 15 min
  • {{Beazley, Python Concurrency From the Ground Up|https://www.youtube.com/watch?v=MCs5OvhV9S4}}: builds an event loop live from generators and sockets. 55 min
  • Fluent Python, Ramalho: the data model, functions as objects and concurrency; its concurrency chapters cover threads, processes and asyncio. about 25 h for the book
  • {{Python support for free threading (HOWTO)|https://docs.python.org/3.14/howto/free-threading-python.html}}: the official limits and overhead figures. 20 min
  • {{Python free-threading guide|https://py-free-threading.github.io/}}: the community site for porting extensions and tracking compatibility. 30 min for the porting pages
  • {{What's New in Python 3.14|https://docs.python.org/3.14/whatsnew/3.14.html}}: free-threading phase II, subinterpreters, asyncio ps. 45 min
  • {{concurrent.interpreters|https://docs.python.org/3.14/library/concurrent.interpreters.html}}: what can be shared between interpreters. 20 min
  • The rationale: {{PEP 703|https://peps.python.org/pep-0703/}} (making the GIL optional), {{PEP 779|https://peps.python.org/pep-0779/}} (phase II), {{PEP 684|https://peps.python.org/pep-0684/}} (a GIL per interpreter), {{PEP 734|https://peps.python.org/pep-0734/}} (subinterpreters in the standard library), {{PEP 525|https://peps.python.org/pep-0525/}} (async generators). 15 min each for the motivation sections
