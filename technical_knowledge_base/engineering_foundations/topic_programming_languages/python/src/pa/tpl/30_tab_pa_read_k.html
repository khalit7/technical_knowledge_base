Corrections and changes to the old "Python: zero to expert" page
  • Wrong: the trap "catching Exception around a KeyboardInterrupt-sensitive call". KeyboardInterrupt is not an Exception; the trap is a bare except: (section 7, measured).
  • Imprecise: "free-threaded builds (3.14+)". The free-threaded build was experimental from 3.13 ({{PEP 703|https://peps.python.org/pep-0703/}}) and officially supported from 3.14 ({{PEP 779|https://peps.python.org/pep-0779/}}).
  • Outdated (tooling): uv init myproj then uv run main.py no longer matches what uv init makes; mypy is actively developed (2.4.0); see the root's Toolchain atlas corrections and {{Part 2|#t-pb-read}}.
  • Confirmed by measurement: NumPy is slower than a Python loop on 10 elements and much faster on large arrays (section 12); threads do not speed up CPU-bound Python in the default build (section 9); the late-binding and mutable-default traps (sections 1 and 4).
  • New since the old page: Python 3.14.5 reverted 3.14.0's incremental garbage collector to the generational one (section 11); 3.14 warns on return in finally and names the type in unhashable-key errors.
  • Moved: packaging, the package-manager history (pip, venv, pipx, Poetry, PDM, Hatch, conda, uv), testing with pytest and the 3.12 to 3.15 changes are in {{Part 2|#t-pb-read}}; the PyTorch-specific Python (autograd, torch.compile) belongs to the {{pytorch-ecosystem|n:3c65c17b0d0d8150aa65ca44b6ed2fd5}} topic.
