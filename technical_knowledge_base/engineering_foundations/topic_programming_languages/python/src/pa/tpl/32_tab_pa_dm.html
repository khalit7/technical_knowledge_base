Data model explorer: which method does Python call?

Pick an expression. The steps show, in order, every special method Python called for it, as logged by the methods themselves in a real run of code/d2_dispatch.py (green rows), with the steps that happen inside C code and cannot be logged from Python marked grey. Several scenarios come in pairs that differ in one detail (a subclass, a return value, a missing method): compare them. Reading section 2 has the rules; section 5 has the attribute lookup.
