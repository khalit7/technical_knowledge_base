Part 2 is the Python you install and ship in October 2026: the tools (uv, ruff, three type checkers, pytest, the packaging chain) and the runtime (what changed from 3.12 to 3.15, the free-threaded build, the JIT, subinterpreters, lazy imports). Every command below was run on this Mac on 2026-10-05 and every output is the real one; every runtime claim is measured.

Machine: Apple M1 Pro (8 performance and 2 efficiency cores), macOS 27, in normal use while measuring (load averages are shown next to each timing). Interpreters: CPython 3.11.17, 3.12.15, 3.13.16, 3.14.8 and 3.15.0rc3, plus the free-threaded 3.14.8t and 3.15.0rc3t, all uv-managed builds. Tools: uv 0.12.23, ruff 0.16.10, ty 0.0.84, mypy 2.4.0, pyright 1.1.414, pytest 9.1.1. For how these tools compare with the other three languages' toolchains, see the root page's {{Toolchain atlas|n:3c65c17b0d0d81a2bb1ac0bc8aeb6aa9}} tab; this part goes deeper on Python only.

The four things worth doing this month
  1. Move every project to uv with a committed uv.lock, and run CI with uv sync --locked so a stale lock fails the build (section 2).
  2. Pin ruff's version in the project: since 0.16 an unpinned upgrade can turn on hundreds of new rules at once (section 3).
  3. Pick one type checker, run it in CI, and learn which checks it leaves off by default (section 4's drill shows three real disagreements).
  4. Plan for 3.15 (final due 2026-10-09): lazy import for CLIs, and pass encoding= wherever you open text files, because the default becomes UTF-8 on every platform (sections 7 and 8).
