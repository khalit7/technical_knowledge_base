Every runtime measurement behind Part 2's Reading, with all runs, the method and the machine's load. Same workload throughout: the root page's token counter over JSONL chat lines generated by the root's script (seed 7).

How to read these numbers
One laptop (Apple M1 Pro: 8 performance and 2 efficiency cores, 16 GB, macOS 27) in normal use, with other work running: the load average was between about 4 and 9 during the runs and is shown with each table. Treat differences under about 10% as noise. Absolute times are for this machine only; ratios on the same interpreter are more portable.

1. Free-threading: scaling with threads

100,000 lines split evenly across N threads; each thread counts into its own Counter, then the main thread merges and checks the total against a single-threaded run. Five timed runs per point after one warm-up; the chart shows the median, the table every run. Script: src/pb/ft/ft_bench.py.

2. Free-threading: lost updates

Four threads add token counts into one shared dict with shared[u] = shared.get(u, 0) + n; five runs without a lock, three with threading.Lock. "Lost" is the expected total minus the total found.

3. The JIT, on and off

Five workloads (src/pb/jit/jit_cases.py): each is timed 7 times after 3 warm-ups inside one process (median), and that process is run 3 times per setting (median of the three). PYTHON_JIT=0 and =1 on the uv builds of 3.13.16, 3.14.8 and 3.15.0rc3, all configured with --enable-experimental-jit=yes-off (built in, off by default). "JIT on" is confirmed by sys._jit.is_enabled() on 3.14 and 3.15 (3.13 has no such function).

4. Threads, processes and subinterpreters

Start-up: create a worker and run a trivial function in it (median of 20 for threads and subinterpreters, 10 for spawned processes). Job: the 100,000-line count split 4 ways with each executor, median of 5 (the result is checked every time). Script: src/pb/interp/interp_bench.py.

5. Which popular compiled packages ship free-threaded wheels

A missing cp314t wheel means an installer on 3.14t builds from the sdist (which needs a compiler, and may refuse, as orjson does) or fails. abi3 wheels do not load on free-threaded builds; abi3t (3.15+) does. polars appears as polars-runtime-32 because the polars wheel itself is now pure Python. Script: src/pb/pack/wheels.py.
