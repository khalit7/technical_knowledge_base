Start here

This page is for someone who already writes Python and wants to know why it behaves the way it does, and how to work with it the 2026 way. It has two parts; pick one with the buttons above. Every output, error message and number on the page comes from a real run (CPython 3.13.16, 3.14.8, 3.14.8t and 3.15.0rc3 on an Apple M1 Pro, 2026-10-05); each part's sources and run scripts are in the repository.

Part 1: In depth

About 45 minutes, plus drills. Tabs: Reading, Event loop, Data model, Predict the output.
How Python really works: names and objects, the data model (how syntax becomes method calls), generators, closures and decorators, classes and descriptors, typing, exceptions, context managers, threads and the GIL, asyncio from the event loop up, CPython internals you can see, and performance.
  • Start: {{Reading|#t-pa-read}}, section "In one screen".
  • Find your gaps fast: {{Predict the output|#t-pa-drill}} (26 questions).

Part 2: Python in 2026

About 35 to 45 minutes. Tabs: Reading, Version explorer, Runtime lab.
The toolchain and runtime as of October 2026: uv end to end, ruff, ty against mypy and pyright, pytest, wheels and publishing, what changed from 3.12 to 3.15, lazy imports, free-threading, the JIT and subinterpreters, all measured.
  • Start: {{Reading|#t-pb-read}}.
  • "Does this run on my version?": {{Version explorer|#t-pb-ver}}.
  • Free-threading, JIT and subinterpreter runs: {{Runtime lab|#t-pb-lab}}.

Three ways through

"I use Python every day but I want to understand it." Part 1 in order. Do the Predict tab first if you want to skip what you already know.
"I want to set up and ship a project properly." Part 2 sections 1 to 6 (packaging layers, uv, ruff, type checking, pytest, wheels), then section 7 for what changed between versions.
"I want my Python to be fast." Part 1 section 12 (measure first, then move the loop out of Python), Part 2 sections 9 and 10 (free-threading and the JIT, measured), then the Rust page's part on speeding up Python with PyO3 ({{Rust|n:3c65c17b0d0d8156bed9ead8a22f33b0}}).
