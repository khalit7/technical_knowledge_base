# Part 2 of the Python page: "Python in 2026" (part key `pb`)

Tabs: `t-pb-read` (Reading), `t-pb-ver` (Version explorer), `t-pb-lab` (Runtime lab).
Parts: `parts/12_tabs_pb.html`, `parts/40_tab_pb_read_a..z.html`, `parts/41_tab_pb_ver.html`, `parts/42_tab_pb_lab.html`,
`parts/40_js_pb_data.js` (generated by `build_data.py`, do not edit), `41_js_pb_util.js`, `42_js_pb_read_a..d.js`, `43_js_pb_ver.js`, `44_js_pb_lab.js`.
Ids and classes start with `pb-`, `vx-` (Version explorer) or `lb-` (Runtime lab); CSS is scoped to the three tab ids.

## Reproduce
`bash run_all.sh` (about 15 minutes; needs the scratch toolchain in `env.sh`, network for PyPI). It reruns every command and
measurement, rewrites `out/`, regenerates `../parts/40_js_pb_data.js` and runs `check_embed.py`, which confirms the page
embeds exactly the recorded outputs. Then `sh ../build.sh`.

| Folder | What it records |
|---|---|
| `versions/` | 21 snippets, one per 3.12 to 3.15 change, run on 3.11 to 3.15 (`run_versions.py`); descriptions and sources in `features.py` |
| `uvwalk/` | uv beyond the basics: interpreters, init flavours, lock/sync, extras, export, PEP 723 scripts, uvx, workspaces, uv pip, build, publish |
| `ruff/`, `pytest/` | one file with typical problems; a small pytest 9 project |
| `types/` | 8 cases through ty, mypy and pyright (`run_checkers.sh`); speed on rich 15.0.0 (`speed.sh`) |
| `pack/` | PyPI wheel-tag survey of 25 compiled packages (`wheels.py`); pip vs uv install time; the orjson free-threaded build failure |
| `ft/` | free-threading scaling, per-block traces and lost updates (`ft_bench.py`, workload `tokwork.py`); `cext/`: two tiny C extensions showing the GIL turned back on |
| `jit/` | five workloads, PYTHON_JIT=0/1 on 3.13 to 3.15 |
| `interp/` | threads vs processes vs subinterpreters; the sys.path mistake; NumPy refusing to load in a subinterpreter |
| `lazy/` | the same CLI with eager and lazy imports on 3.15 (`-X importtime`, hyperfine); the rejected `none` mode |

## Departures from the child-page method
This is one part of a multi-part language page, not a child page of its own: no Further reading tab (section 14 of the
Reading plays that role; the page-wide tabs belong to the integrator). Old-page facts are carried and checked in `coverage.json`.
