The idea in one screen

An LLM app in TypeScript is ordinary server code around one HTTP call: the SDK's types give every reply its shape before you run anything, your loop runs the tools the model asks for, and one zod schema checks every piece of model JSON where it crosses into your program.

Where each part of an LLM app sits, and where the model's JSON is checked

Notice the three zod marks: tool arguments, structured output and MCP arguments are all model output, so each is validated before your code trusts it. The numbers are this page's sections.

How the evidence was made
No paid API call was made for this page (no API key was set). Every request goes to a local mock model server that speaks the real Anthropic and OpenAI wire formats, so the official SDKs talk to it unchanged; its answers are synthetic, picked by a short script, and its token counts are an estimate (characters / 4, Anthropic's own rule of thumb on its pricing page). What is real: the SDKs, every byte they send and receive, the tool code, the MCP server and client, the HTTP servers, and all timings. Node 24.21.0, TypeScript 7.0.2, @anthropic-ai/sdk 0.131.0, openai 7.28.0, ai 7.0.127, @modelcontextprotocol/sdk 1.32.1, @anthropic-ai/claude-agent-sdk 0.3.289, zod 4.6.5 (all current on npm on 2026-10-05); recorded on an Apple M1 Pro, macOS 27, 2026-10-05; scripts and recordings in src/tl/.
Why TypeScript for this at all, and what the old page claimed

Agent harnesses and MCP servers are mostly TypeScript today. Measured on 2026-10-05 with GitHub's language statistics: the official MCP reference servers repository is 490,686 bytes of TypeScript against 100,153 of Python (modelcontextprotocol/servers); OpenCode is TypeScript (sst/opencode); and Claude Code "ships as a Bun executable", a compiled JavaScript project (Bun blog, 2025-12-02). The two things TypeScript gives an LLM app are the ones the TypeScript page teaches: the SDK's types tell you the shape of every response before you run anything, and a zod schema checks the model's JSON at run time.

Checking the old page
The old "JavaScript: zero to expert" page said: "Claude Code, OpenCode, and most MCP reference implementations are TypeScript." OpenCode and the MCP reference servers: confirmed (above). Claude Code: its source is not public, so "TypeScript" specifically is unconfirmed; what is confirmed is that it is a JavaScript-family program compiled into a single executable with Bun (Bun's post, above), and the Claude Agent SDK used in section 7 installs it as a native binary.
