## Departures from the topic-child shape, and why
- **No lab tabs.** The Agent loop stepper and the MCP message flow tabs were dropped (decision 17): the agent loop and its Loop lab are owned by Topic: agentic-harnesses, and the MCP protocol and a stepped session by the MCP page. In their place: a static table of the four recorded agent runs (section 4) and the MCP recordings in closed blocks (section 8).
- **Code in closed blocks.** Outputs stay in the core and each script sits in a closed block beside it; where the question is the point, the output is behind "Reveal" too.
- **Concepts linked to their owners, not taught**: the loop itself (agentic harnesses), JSON-RPC and the MCP lifecycle (MCP), retries in general (reliability engineering), the SSE format and stream cancellation on the wire (streaming and real-time), traces and evals (LLM observability, evaluation pages), the Claude Agent SDK in depth (its page), constrained decoding and typed agent libraries (sampling and decoding, typed agent libraries), prompt-caching prices (caching). What stays is what TypeScript and these SDKs do, measured.
- **Common mistakes** are one closed checklist: each one is already shown by a run in the core.
