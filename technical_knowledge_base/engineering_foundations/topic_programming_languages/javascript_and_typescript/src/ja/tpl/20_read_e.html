5. The four child pages

Read in this order if JavaScript is new; jump to the fourth if you only need to ship an agent and know the rest. Each card gives the page's core idea, its reading time (measured, 230 words a minute) and one thing its runs showed.

{{JavaScript: values, objects, functions and modules for Python programmers|n:4055c17b0d0d810c982ac6ab36f88539}}

Reading: 24 min, plus 11 in closed details. Tab: JS playground.

JavaScript looks like Python with braces; the surprises come from a few defaults: one number type, missing is undefined rather than an error, this is set by the call, and objects are bags with a prototype chain. Values, objects, functions and this, classes, modules, errors, iteration, how V8 runs it.

Try: its JS playground runs 22 short programs that catch Python programmers live in your browser, each against Node's recorded output.

{{JavaScript: the event loop, promises and streams|n:4055c17b0d0d81fe857de8b34db109ea}}

Reading: 14 min, plus 9 in closed details.

One thread that never waits: the event loop runs each callback to completion and drains every microtask before the next task. Callbacks to async/await, the two queues stepped through, concurrency on one thread, the async toolbox, async iterators and SSE streams.

Measured: a real token stream arrived in 9 chunks that split events and even an emoji: a parser that reads each chunk on its own recovered 0 of 6 tokens; a buffered decoder recovered all 6.

{{TypeScript: the type system, narrowing and runtime validation|n:4055c17b0d0d81519278df19753ab5ec}}

Reading: 27 min, plus 49 in closed details.

A checker that reads your JavaScript plus its types before the program runs and is then erased: narrowing makes unions safe inside the program, and every value from outside must be checked at run time by a schema such as zod. tsconfig, structural typing, generics, the unsound holes, publishing, TypeScript 7.

Measured: ten kinds of malformed model JSON through a plain cast: wrong data with no error in 2 cases, a crash later in 4; zod reported each one at the field that was wrong. TypeScript 7's native compiler checked zod's own 37,722 lines in 520 ms against 2.65 s for TypeScript 6 (5.1 times faster).

{{TypeScript: LLM apps and agents|n:4055c17b0d0d8109aad6e69a87b3bd6f}}

Reading: 23 min, plus 25 in closed details.

An LLM app in TypeScript is ordinary server code around one HTTP call: the SDK's types give every reply its shape, your loop runs the tools the model asks for, and one zod schema checks model JSON where it enters. The Anthropic and OpenAI SDKs, retries, streaming, tools, structured output, the Vercel AI SDK and Claude Agent SDK, MCP, serving. It needs no API key: the model's answers come from a local mock that speaks the real Anthropic and OpenAI wire formats, labelled synthetic wherever they appear.

Measured: when the user left mid-answer, passing the cancellation through stopped the model after 6 of 114 events; without it, all 114 were generated, about 2.3 s after the user had gone. A streaming server that ignored write()'s return value queued 2,070 KiB in memory; waiting for drain kept it to 64 KiB.
