JS playground: predict, then run

Twenty-two short programs that catch Python programmers. For each: read it, write down what you think it prints, then reveal what Node 24.21.0 printed (recorded) and run it live in your browser. You can edit the code and run your own version; nothing leaves the page (there is no network in this page, and your code runs in a sandboxed worker when the browser allows one). How the live run works, and its limits
The code is wrapped in an async function (so top-level await works) and run in a Web Worker made from this page, which is stopped after 3 seconds (an infinite loop cannot freeze the page). If the browser refuses workers here, it runs on the page itself without that guard; if it refuses running code at all, the page says so and the recorded output remains. The run ends when no timers are pending. console.log is captured and printed the way Node prints common values (strings bare at the top level, quoted inside arrays and objects; [ 1, 2 ], { a: 1 }, Map(1) {...}); exotic values (errors with stacks, promises, deep nesting) print differently from Node. Node-only APIs (process, require, setImmediate, process.nextTick, import statements) are not available.
