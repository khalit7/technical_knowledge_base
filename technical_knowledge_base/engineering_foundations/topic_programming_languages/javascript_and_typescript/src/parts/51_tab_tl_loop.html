The messages array (what the next request sends)
Every message, tool result, token count and tool time is from the recorded run of c1_agent_loop.ts (tools ran for real: the token counter read chat.jsonl; the profile service is a local server with synthetic teams). The model's turns are the mock's scripted answers, and its token counts are the mock's estimate (characters / 4). Cost applies Claude Sonnet 5.5's list price (US$2 in, US$10 out per million tokens) to those estimates.

What each scenario teaches: Happy path, two tool calls in one turn run concurrently and their results go back in one message. Tool error, the error is a result (is_error: true), and the model fixes its own mistake. Slow tool, AbortSignal.timeout(500) turns a hung lookup into an error the model can explain; the two lookups time out together, not one after the other. Runaway, a model that never stops asking is stopped by maxSteps, and the meter shows what it cost to get nothing.
