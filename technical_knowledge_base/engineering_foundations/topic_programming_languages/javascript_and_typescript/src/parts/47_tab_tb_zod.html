Ten replies a model can give when asked for {"city": string, "population": number}, each read four ways: a cast (JSON.parse(...) as Answer) and three zod schemas. The program then prints CITY has N people. Every cell is the real output of src/tb/zodlab/lab.ts (type-checked by tsc 7.0.2, run by Node 22.22.2, zod 4.6.5). Click a cell.

How a cell is coloured: an exception is a crash; output starting with "rejected" was caught by the reader; an output from the cast is marked "data was wrong" when the default zod schema rejected the same reply (the program printed something, from a value of the wrong type); everything else is correct.
