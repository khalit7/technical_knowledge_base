Start here

This page teaches JavaScript and TypeScript from zero to someone who knows Python, for one job above all: building LLM apps, agents and MCP servers. It has three parts, meant to be read in order; pick one with the buttons above. Every output, type error and number comes from a real run on an Apple M1 Pro on 2026-10-05 (Node 22.22.2, 24.21.0 and 26.10.0, TypeScript 7.0.2, Bun 1.4.2, Deno 2.9.7), and each part's sources and run scripts are in the repository. Part 3 needs no API key: the model's answers come from a local mock that speaks the real Anthropic and OpenAI wire formats, labelled synthetic wherever they appear; everything else (the SDKs, the bytes on the wire, the tools, the MCP server and client, the timings) is real.

Part 1: JavaScript and its runtime

About 50 minutes. Tabs: Reading, Event-loop stepper, JS playground.
Values and types, objects, functions and this, classes and prototypes, modules, errors, iteration, the event loop, promises and the async toolbox, async iterators and streamed LLM tokens, Node essentials, packages, Bun and Deno, V8, and the traps.

Part 2: TypeScript

About 40 minutes. Tabs: Reading, Narrowing stepper, Will it type-check?, LLM JSON lab.
What TypeScript is (types erased before running), tsconfig, types and inference, structural typing, narrowing, generics, utility and mapped types, any against unknown, where the type system is unsound by design, checking data at run time with zod, testing, linting, and the TypeScript 7 transition.
  • Start: {{Reading|#t-tb-read}}.
  • Why a cast is not validation: {{LLM JSON lab|#t-tb-zod}}.

Part 3: LLM apps and agents

About 40 minutes. Tabs: Reading, Agent loop stepper, MCP message flow.
The Anthropic and OpenAI TypeScript SDKs, failures and retries, streaming, an agent loop by hand and the SDK's tool runner, structured output with zod, conversation state and caching, the Vercel AI SDK and the Claude Agent SDK, an MCP server and client, serving with cancellation and backpressure, and eval hooks.
  • Start: {{Reading|#t-tl-read}}.
  • Every message of a real MCP session: {{MCP message flow|#t-tl-mcp}}.

Five things the runs showed

FindingWhere
A real token stream arrived in 9 chunks that split events and even an emoji: a parser that reads each chunk on its own recovered 0 of 6 tokens; a buffered decoder recovered all 6.Part 1, streams
Ten kinds of malformed model JSON through a plain cast: wrong data with no error in 2 cases, a crash later in 4. zod reported each one at the field that was wrong.Part 2, LLM JSON lab
TypeScript 7's native compiler checked zod's own 37,722 lines in 520 ms against 2.65 s for TypeScript 6 (5.1 times faster).Part 2, the TypeScript 7 transition
When the user left mid-answer, passing the cancellation through stopped the model after 6 of 114 events; without it, all 114 were generated, about 2.3 s after the user had gone.Part 3, serving
