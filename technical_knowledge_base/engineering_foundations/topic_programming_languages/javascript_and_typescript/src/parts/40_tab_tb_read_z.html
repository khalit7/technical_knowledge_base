The best outside resources

The TypeScript Handbook about 4 h

Official and good. Read "Everyday Types", "Narrowing" and "Type Manipulation" in that order.

TSConfig reference about 1 h

Every option with examples; look up an option before copying it from another project.

Announcing TypeScript 7.0 20 min

The port, the benchmarks, removed options, the API plan and tsc6. The TypeScript blog (about 30 min per release) is the fastest way to stay current.

Node.js: Modules: TypeScript 15 min

What type stripping supports, what it refuses, and the version history.

Effective TypeScript (Dan Vanderkam, book) about 8 h

One item per idea; the closest thing to a canon for writing TypeScript well.

Total TypeScript (Matt Pocock) about 6 h, free tutorials

The best intermediate material on generics, type transformations and library typing.

Type Challenges about 15 h (easy and medium)

Graded puzzles in the type language. Optional: worth it if you will write library types.

zod documentation about 1 h

Schemas, errors, JSON Schema, codecs. Read "Basic usage", "Defining schemas" and "JSON Schema".

Vitest guide about 1 h

Writing tests, mocking, watch mode, type tests.

typescript-eslint: typed linting and Biome: getting started 30 min

Setting up the two linters shown above.

ts-reset 15 min (the README)

Fixes some built-in typings (for example JSON.parse returning unknown instead of any), and its README explains why each default is unsafe.
