## Departures from the topic-child shape, and why
- **One lab tab kept**: the JS playground is a tool used across the whole page (22 drills from sections 1 to 8, plus five async drills taught on the event-loop sibling), so it keeps its own tab; every other visual is inline beside its claim.
- **Code in closed blocks for runs, open for predictions.** Where a run only proves the prose (`b2`, `b5`, `b7`, `c1`, `c3`, `c4`, `e1`, `e2`, `g1`, `g2`, `h2`, `n1`, `n2`), the output stays in the core and the script is a closed block beside it (`[[outc:]]`). Where the code is the question (the predict boxes), it stays open; a figure that would give the answer away sits after its predict box.
- **Not taught here**: floating-point bits (one sentence plus a link to Numerical computing), async errors and async iterators (links to the event-loop sibling), publishing with types (TypeScript sibling).
