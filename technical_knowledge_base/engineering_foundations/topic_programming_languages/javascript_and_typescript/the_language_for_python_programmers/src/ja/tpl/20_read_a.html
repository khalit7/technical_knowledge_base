The idea in one screen

JavaScript looks like Python with braces, and most of it behaves the same: names point at objects, functions are values, classes have methods, exceptions propagate. The surprises come from a few defaults: one number type, missing is undefined, not an error, this is set by the call, and objects are bags with a prototype chain.

Fig. 1: every value is a primitive or a reference to an object, and every object has a prototype

  1. Primitives: immutable, compared by value. Seven primitive types: number (a 64-bit double), bigint (2n ** 64n), string (UTF-16 units), boolean, undefined (never set), null (set to nothing) and symbol. A variable holding one holds the value itself. typeof null says "object": a bug kept since 1995 for compatibility.
  2. Objects are reached by reference, compared by identity. msg (section 2), c (section 4) and c1 (section 3) each hold a reference to an object behind the plate. Assigning one to another variable copies the reference, never the object (Fig. 2).
  3. Every object has a prototype. c's own properties are only name, k (what Object.keys(c) printed in section 4); its methods live one and two levels up, on TopCounter.prototype and Counter.prototype. The literal msg links straight to Object.prototype, the same object that tops c's chain, and every chain ends at null. class builds the first chain (section 4); {...} builds the second.
  4. A property read climbs the chain. c.total is not an own property and not on TopCounter.prototype; it is found on Counter.prototype (a getter), and the run printed 8. c.hasOwnProperty would climb one level more, to Object.prototype.
  5. A miss reaches null and gives undefined. c.counts is on no object of the chain (the private #counts is not a property), so the read returns undefined, as the run printed. Python would raise AttributeError; here the crash, if any, comes later, where the value is used.
  6. A function keeps the scope it was made in. c1 holds { inc, get }, two functions that keep the scope of the makeCounter() call that made them; after two calls of c1.inc(), that scope's n is 2. A function with its scope is a closure (section 3).

Primitive
a number, bigint, string, boolean, undefined, null or symbol: immutable, compared by value.
Prototype
the object where a missing property is looked up next; the chain ends at null.
Closure
a function together with the variables of the scope it was created in.
this
an implicit parameter set by how a function is called, not where it is written.
Surrogate pair
two UTF-16 code units that together encode one character outside the Basic Multilingual Plane (an emoji).
ESM, CommonJS
the two module systems: import/export, and Node's original require/module.exports.
Hidden class
V8's record of an object's property names in insertion order (V8 calls it a "map"); objects built alike share one.
Deoptimise
V8 throws away compiled code whose assumption broke and goes back to the interpreter.
