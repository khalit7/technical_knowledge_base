## Departures from the topic-child shape, and why
- **No lab tabs.** The Event-loop stepper explained one mechanism, so it sits inline in section 2 beside the rule it proves; its rules box came with it.
- **Code in closed blocks.** The real output stays in the core and each script is a closed block beside it (`[[outc:]]`), except the two prediction programs (`i3_order`, `i8_foreach`), where the code is the question.
- **SSE format not taught here.** One sentence plus a link to Streaming and real-time, which owns the format; the parser code, the chunk replay and the trap stay here (plan section 4).
- **Measured backpressure and cancellation of a model call** are on the TypeScript LLM apps sibling (its `h1_serve`, `h2_backpressure` runs); this page links them.
