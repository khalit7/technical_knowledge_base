Outside sources

  • {{The TypeScript Handbook|https://www.typescriptlang.org/docs/handbook/intro.html}}: official and good. Read "Everyday Types", "Narrowing" and "Type Manipulation" in that order. about 4 h
  • {{TSConfig reference|https://www.typescriptlang.org/tsconfig/}}: every option with examples; look up an option before copying it from another project. about 1 h
  • {{Announcing TypeScript 7.0|https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/}}: the port, the benchmarks, removed options, the API plan and tsc6. The {{TypeScript blog|https://devblogs.microsoft.com/typescript/}} (about 30 min per release) is the fastest way to stay current. 20 min
  • {{Node.js: Modules: TypeScript|https://nodejs.org/api/typescript.html}}: what type stripping supports, what it refuses, and the version history. 15 min
  • {{Effective TypeScript|https://effectivetypescript.com/}} (Dan Vanderkam, book): one item per idea; the closest thing to a canon for writing TypeScript well. about 8 h
  • {{Total TypeScript|https://www.totaltypescript.com/}} (Matt Pocock): the best intermediate material on generics, type transformations and library typing. about 6 h, free tutorials
  • {{Type Challenges|https://github.com/type-challenges/type-challenges}}: graded puzzles in the type language. Optional: worth it if you will write library types. about 15 h (easy and medium)
  • {{zod documentation|https://zod.dev}}: schemas, errors, JSON Schema, codecs. Read "Basic usage", "Defining schemas" and "JSON Schema". about 1 h
  • {{Vitest guide|https://vitest.dev/guide/}}: writing tests, mocking, watch mode, type tests. about 1 h
  • {{typescript-eslint: typed linting|https://typescript-eslint.io/getting-started/typed-linting/}} and {{Biome: getting started|https://biomejs.dev/guides/getting-started/}}: setting up the two linters shown in section 8. 30 min
  • {{ts-reset|https://github.com/total-typescript/ts-reset}}: fixes some built-in typings (for example JSON.parse returning unknown instead of any), and its README explains why each default is unsafe. 15 min (the README)
