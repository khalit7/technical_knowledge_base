8. Mutual information, and why processing cannot add information

The question. How much does knowing one thing tell you about another, in bits, including when the relationship is not a straight line?

The words, then the formulas

The mutual information between \(X\) and \(Y\) is the drop in uncertainty about \(X\) when you learn \(Y\). Three equal ways to write it:

\[ I(X; Y) = H(X) - H(X \mid Y) = H(X) + H(Y) - H(X, Y) = D_{\mathrm{KL}}\big(p(x, y) \,\Vert\, p(x)\,p(y)\big) \]
\(H(X) - H(X \mid Y)\)
uncertainty before, minus uncertainty left after seeing \(Y\).
\(p(x)\,p(y)\)
what the joint distribution would be if \(X\) and \(Y\) were independent.
the KL form
how far the real joint is from independence.
From the first form to the KL form:
  1. \(H(X) = -\sum_{x,y} p(x, y) \log p(x)\) (summing \(p(x,y)\) over \(y\) gives back \(p(x)\)).
  2. \(H(X \mid Y) = -\sum_{x, y} p(x, y) \log p(x \mid y)\) (section 4).
  3. Subtract: \(I = \sum_{x, y} p(x, y) \big[\log p(x \mid y) - \log p(x)\big]\) \(= \sum_{x,y} p(x, y) \log \frac{p(x \mid y)}{p(x)}\).
  4. Multiply top and bottom by \(p(y)\): \(\frac{p(x \mid y)}{p(x)} = \frac{p(x, y)}{p(x)\,p(y)}\). So \(I(X; Y) = D_{\mathrm{KL}}\big(p(x,y) \Vert p(x)p(y)\big)\).
  5. Because it is a KL divergence, \(I(X; Y) \ge 0\), with equality exactly when \(p(x, y) = p(x)p(y)\): independence. This is the proof promised in section 4 that conditioning reduces entropy on average.
Worked example (continued from section 4)
Two signals that agree 80% of the time: \(I(X; Y) = 1 + 1 - 1.722 = 0.278\) bits. The KL form gives the same: \(4\) cells, independence would put 0.25 in each, so \(I = 2 \times 0.4 \log_2 \tfrac{0.4}{0.25} + 2 \times 0.1 \log_2 \tfrac{0.1}{0.25} = 0.278\) bits.

Properties. Symmetric, \(I(X; Y) = I(Y; X)\). \(I(X; X) = H(X)\): a variable shares all its information with itself. Unchanged if you apply an invertible function to \(X\) or to \(Y\) (rescaling, a monotone transform), unlike correlation.

Zero correlation, plenty of information
Let \(X\) be \(-1\), 0 or 1 with equal probability and \(Y = X^2\). The correlation is 0 (\(\mathbb{E}[XY] = \mathbb{E}[X^3] = 0\) and \(\mathbb{E}[X] = 0\)), yet \(Y\) is a function of \(X\). \(Y\) is 1 with probability 2/3 and 0 with probability 1/3, so \(H(Y) = 0.918\) bits; knowing \(X\) leaves nothing, \(H(Y \mid X) = 0\); so \(I(X; Y) = 0.918\) bits. Only zero mutual information means independence.

The data processing inequality

Suppose \(Z\) is computed from \(Y\) alone, and \(Y\) from \(X\): a Markov chain \(X \to Y \to Z\), meaning \(p(x, y, z) = p(x)\,p(y \mid x)\,p(z \mid y)\). Then

\[ I(X; Z) \le I(X; Y) \]

In plain words: no processing of \(Y\), however clever, can tell you more about \(X\) than \(Y\) itself does. MacKay: "data processing can only destroy information" (§8.3, exercise 8.9).

Proof, using the chain rule for mutual information, \(I(X; Y, Z) = I(X; Z) + I(X; Y \mid Z) = I(X; Y) + I(X; Z \mid Y)\) (the same chain rule as section 4, applied to \(H(X) - H(X \mid \cdot)\)):
  1. The conditional mutual information \(I(X; Z \mid Y)\) is what \(Z\) tells about \(X\) once \(Y\) is known. In a Markov chain \(Z\) depends on \(X\) only through \(Y\), so it is 0.
  2. So \(I(X; Y) = I(X; Z) + I(X; Y \mid Z)\).
  3. \(I(X; Y \mid Z) \ge 0\) (it is an average of KL divergences), so \(I(X; Y) \ge I(X; Z)\).
Worked example: a message copied twice with errors
\(X\) is a fair bit. \(Y\) is \(X\) with a 10% chance of being flipped; \(Z\) is \(Y\) flipped again with 10% chance. \(I(X; Y) = 1 - H(0.1) = 1 - 0.469 = 0.531\) bits. \(Z\) differs from \(X\) when exactly one flip happens: \(2 \times 0.1 \times 0.9 = 0.18\), so \(I(X; Z) = 1 - H(0.18) = 0.320\) bits. Each copy loses information, never gains it.
What it is used for in ML
Representations: the layers of a network form a Markov chain from input to output, so a hidden layer cannot carry more information about the label than the input does. Training does not add information; it makes the useful information easier to extract by a simple final layer, which Shannon information does not measure. Feature selection: rank features by their mutual information with the label (information gain in trees is exactly this, section 2). Contrastive learning: maximise a lower bound on the mutual information between two views (section 9). The information bottleneck asks for a representation that keeps as little as possible about the input while keeping as much as possible about the label, trading \(I(\text{input}; \text{representation})\) against \(I(\text{representation}; \text{label})\) ({{Tishby, Pereira and Bialek 1999|https://arxiv.org/abs/physics/0004057}}).
