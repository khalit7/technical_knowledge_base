The idea in one screen

Every log-loss is a code length: the cross-entropy a model pays is the data's own entropy, which no model can remove, plus a KL divergence, which is the part training removes.

The loss is a floor plus a removable gap, in two codes and in two real models

Top: the same 16 symbols coded with the code built for the truth \(p\) and with one built for a wrong guess \(q\) (section 3): 1.75 against 2.375 bits per symbol, and the extra 0.625 is exactly the KL. Bottom: GPT-2 and Qwen2.5-0.5B on the same 10,376-byte Darwin passage (measured, section 6). Nobody knows the passage's floor, but it is the same for both models, so the whole 0.153 bits per byte between them is a difference in KL.

\[ \underbrace{H(p, q)}_{\text{the loss}} \;=\; \underbrace{H(p)}_{\text{floor}} \;+\; \underbrace{D_{\mathrm{KL}}(p \,\Vert\, q)}_{\text{removable}} \]

This one line (derived in section 3) is why minimising cross-entropy is maximum likelihood, why a language model's loss levels off above zero, and why the answer to "is 2.0 a good loss?" is "compared with what entropy?". The same few quantities explain why perplexity cannot be compared across tokenizers while bits per byte can, why maximum likelihood spreads probability while an RLHF-style KL penalty narrows it, and why contrastive losses such as CLIP's want huge batches.

You need: distributions, expectations and likelihood ({{Probability for ML|n:3c65c17b0d0d815f9a47d613409b5a0c}}); the tiny next-token model of the {{Topic: math root|n:3c65c17b0d0d81cdb851c0835b25a538}} (scores \(z = (2, 1, 0)\) for cat, dog, sat; softmax bet \((0.665, 0.245, 0.090)\); true word sat; loss \(-\ln 0.090 = 2.408\) nats).

Which letter is the data
This page uses the textbook convention of Cover and Thomas and of MacKay, which most papers follow: \(p\) is the truth, \(q\) is the model, so the loss is \(H(p, q)\) and the KL it reduces is \(D_{\mathrm{KL}}(p \Vert q)\). The {{Topic: math root page|n:3c65c17b0d0d81cdb851c0835b25a538}} writes the model's softmax as \(p\) and the target as \(q\), so its \(H(q, p)\) is this page's \(H(p, q)\). When reading a paper, find which letter is the data before reading anything else.
