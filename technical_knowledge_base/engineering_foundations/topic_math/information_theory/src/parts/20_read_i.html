8. Conditional entropy and mutual information: what knowing one thing tells you about another

Two fair binary signals \(X\) and \(Y\) agree 80% of the time: \(p(0,0) = p(1,1) = 0.4\), \(p(0,1) = p(1,0) = 0.1\). Each alone has 1 bit. The pair has the joint entropy \(H(X, Y) = 2 \times 0.4 \times 1.322 + 2 \times 0.1 \times 3.322 = 1.722\) bits. Once \(Y\) is known, \(X\) is 0.8 likely to match it, so what is left is the conditional entropy \(H(X \mid Y) = H(0.8, 0.2) = 0.722\) bits. The 0.278 bits that knowing \(Y\) saves is the mutual information.

\[ I(X; Y) = H(X) - H(X \mid Y) = D_{\mathrm{KL}}\big(p(x, y) \,\Vert\, p(x)\,p(y)\big) \]

The chain rule \(H(X, Y) = H(Y) + H(X \mid Y)\) says the uncertainty of the pair is the uncertainty of one plus what is left of the other (section 7 applies it to a whole text), so also \(I = H(X) + H(Y) - H(X, Y)\). The KL form says mutual information is how far the joint is from independence, \(p(x)p(y)\); here independence would put 0.25 in each cell, and \(2 \times 0.4 \log_2 \tfrac{0.4}{0.25} + 2 \times 0.1 \log_2 \tfrac{0.1}{0.25} = 0.278\) bits again. Because it is a KL, \(I \ge 0\), so conditioning never increases entropy on average, \(H(X \mid Y) \le H(X)\), with equality exactly at independence. A single value can still raise it (a usually reliable test coming back strange can make you less sure); only the average must fall. Mutual information is symmetric, \(I(X; X) = H(X)\), and, unlike correlation, unchanged by any invertible transform of either variable.

Zero correlation, plenty of information
Let \(X\) be \(-1\), 0 or 1 with equal probability and \(Y = X^2\). The correlation is 0 (\(\mathbb{E}[XY] = \mathbb{E}[X^3] = 0\) and \(\mathbb{E}[X] = 0\)), yet \(Y\) is a function of \(X\): \(H(Y) = 0.918\) bits (\(Y\) is 1 with probability 2/3), \(H(Y \mid X) = 0\), so \(I(X; Y) = 0.918\) bits. Only zero mutual information means independence.
The chain rule and the KL form, derived
  1. \(p(x, y) = p(y)\, p(x \mid y)\); take \(-\log\): \(-\log p(x, y) = -\log p(y) - \log p(x \mid y)\).
  2. Average over \((x, y) \sim p\): the left is \(H(X, Y)\), the first right term only depends on \(y\) and averages to \(H(Y)\), the second is \(H(X \mid Y)\), which is \(-\sum_{x, y} p(x, y) \log p(x \mid y)\), the same as \(\sum_y p(y) H(X \mid Y = y)\). So \(H(X, Y) = H(Y) + H(X \mid Y) = H(X) + H(Y \mid X)\).
  3. Subtract \(H(X \mid Y)\) from \(H(X) = -\sum_{x,y} p(x, y) \log p(x)\): \(I = \sum_{x,y} p(x, y) \log \frac{p(x \mid y)}{p(x)}\), and \(\frac{p(x \mid y)}{p(x)} = \frac{p(x, y)}{p(x)\,p(y)}\), which is the KL form.

The data processing inequality

A message \(X\) (a fair bit) is copied with a 10% chance of a flip to give \(Y\), and \(Y\) copied again the same way to give \(Z\). \(I(X; Y) = 1 - H(0.1) = 1 - 0.469 = 0.531\) bits; \(Z\) differs from \(X\) when exactly one flip happens, \(2 \times 0.1 \times 0.9 = 0.18\), so \(I(X; Z) = 1 - H(0.18) = 0.320\) bits. Each copy loses information and none gains it. In general, for a Markov chain \(X \to Y \to Z\) (\(Z\) computed from \(Y\) alone, \(p(x, y, z) = p(x)\,p(y \mid x)\,p(z \mid y)\)):

\[ I(X; Z) \le I(X; Y) \]

MacKay: "data processing can only destroy information" (§8.3, exercise 8.9). The layers of a network form such a chain, so a hidden layer cannot carry more information about the label than the input does. Training does not add information; it makes the useful information easier to extract by a simple final layer, which Shannon information does not measure. The same quantity ranks features (information gain in trees is exactly mutual information, section 1), and the information bottleneck asks for a representation that keeps as little as possible about the input while keeping as much as possible about the label ({{Tishby, Pereira and Bialek 1999|https://arxiv.org/abs/physics/0004057}}).

Proof of the data processing inequality
The chain rule for mutual information, \(I(X; Y, Z) = I(X; Z) + I(X; Y \mid Z) = I(X; Y) + I(X; Z \mid Y)\), follows from the entropy chain rule applied to \(H(X) - H(X \mid \cdot)\). The conditional mutual information \(I(X; Z \mid Y)\), what \(Z\) tells about \(X\) once \(Y\) is known, is 0 in a Markov chain, because \(Z\) depends on \(X\) only through \(Y\). So \(I(X; Y) = I(X; Z) + I(X; Y \mid Z)\), and \(I(X; Y \mid Z) \ge 0\) (an average of KL divergences) gives \(I(X; Y) \ge I(X; Z)\).
