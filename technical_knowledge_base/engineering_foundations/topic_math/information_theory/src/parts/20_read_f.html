4. Joint and conditional entropy: what context buys you

The question. A language model predicts the next token given the previous ones. How much uncertainty is left once you know the context, and how does that add up over a whole text?

The words, then the formulas

For two random variables \(X\) and \(Y\) with joint distribution \(p(x, y)\), the joint entropy is the entropy of the pair, and the conditional entropy is the uncertainty left in \(X\) once \(Y\) is known, averaged over the values of \(Y\):

\[ H(X, Y) = -\sum_{x, y} p(x, y) \log p(x, y), \qquad H(X \mid Y) = \sum_y p(y)\, H(X \mid Y = y) = -\sum_{x, y} p(x, y) \log p(x \mid y) \]
\(p(x, y)\)
the probability that \(X = x\) and \(Y = y\) together.
\(p(y)\)
the marginal: \(\sum_x p(x, y)\).
\(p(x \mid y)\)
the conditional, \(p(x, y) / p(y)\): the distribution of \(X\) among the cases where \(Y = y\).
\(H(X \mid Y = y)\)
the entropy of that conditional distribution, for one value \(y\).

The chain rule, derived without skipping a step

  1. Definition of the conditional: \(p(x, y) = p(y)\, p(x \mid y)\).
  2. Take \(-\log\) of both sides; the log of a product is a sum: \(-\log p(x, y) = -\log p(y) - \log p(x \mid y)\).
  3. Average both sides over \((x, y) \sim p(x, y)\). The left is \(H(X, Y)\). The first term on the right only depends on \(y\), so its average is \(-\sum_y p(y) \log p(y) = H(Y)\). The second is \(H(X \mid Y)\) by definition.
  4. Result: \(H(X, Y) = H(Y) + H(X \mid Y)\), and by the same steps with the roles swapped, \(= H(X) + H(Y \mid X)\).

In plain words: the uncertainty of the pair is the uncertainty of one, plus what is left of the other once the first is known.

Worked example: two signals that agree 80% of the time
\(p(0,0) = p(1,1) = 0.4\) and \(p(0,1) = p(1,0) = 0.1\). Each marginal is \((0.5, 0.5)\), so \(H(X) = H(Y) = 1\) bit.
  • Joint: \(H(X, Y) = 2 \times 0.4 \times 1.322 + 2 \times 0.1 \times 3.322\) \(= 1.058 + 0.664 = 1.722\) bits.
  • Chain rule: \(H(X \mid Y) = H(X, Y) - H(Y) = 1.722 - 1 = 0.722\) bits.
  • Directly: given \(Y = 0\), \(X\) is 0 with probability \(0.4 / 0.5 = 0.8\), so \(H(X \mid Y = 0) = H(0.8, 0.2) = 0.722\); the same for \(Y = 1\); the average is 0.722 bits. Both routes agree.
Knowing \(Y\) cuts the uncertainty about \(X\) from 1 bit to 0.722 bits. The 0.278 bits saved is the mutual information of section 8.

Conditioning never increases entropy on average: \(H(X \mid Y) \le H(X)\), with equality exactly when \(X\) and \(Y\) are independent (proof in section 8: the difference is the mutual information, which is a KL divergence and so non-negative). A single value can still raise it: learning that a usually reliable test came back strange can make you less sure. Only the average is guaranteed to fall.

For a sequence: the language-model factorisation

Apply the chain rule repeatedly to a sequence \(X_1, \dots, X_n\):

\[ H(X_1, \dots, X_n) = \sum_{t=1}^{n} H(X_t \mid X_1, \dots, X_{t-1}) \]

In plain words: the uncertainty of a whole text is the sum, over positions, of the uncertainty of each token given everything before it. This is exactly the shape of a language model's loss: it predicts \(q(x_t \mid x_{\lt t})\) and pays \(-\log q(x_t \mid x_{\lt t})\) at each position. Averaged per token over a long text it estimates the entropy rate of the source, the uncertainty per symbol once all the past is known.

Shannon measured this ladder for English in 1951 ({{"Prediction and Entropy of Printed English"|https://www.princeton.edu/~wbialek/rome/refs/shannon_51.pdf}}). Writing \(F_N\) for the entropy of the next letter given the previous \(N - 1\): with a 26-letter alphabet and no context, \(F_0 = \log_2 26 = 4.70\) bits; using letter frequencies, \(F_1 = 4.14\); using pairs, \(F_2 = 3.56\). From experiments where people guessed the next letter with 100 letters of context (27 symbols, counting the space), he bounded the entropy between about 0.6 and 1.3 bits per letter, "of the order of one bit per letter". Context is worth a lot.

What it is used for in ML
The loss floor of a classifier is the conditional entropy of the label given the input, \(H(Y \mid X)\): zero only when every input has exactly one correct label, above zero when labels are ambiguous or noisy (each one-hot target has entropy 0, but the population of targets for one input need not). The loss floor of a language model is the entropy rate of text under its tokenizer (section 11). Longer context lowers loss because it lowers the conditional entropy the model can reach.
