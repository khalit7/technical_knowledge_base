5. How to read an equation in a paper

An equation in a paper is a compressed paragraph, and every child page's notation meets in it. Expanding it takes five steps, always in the same order. Here they are on scaled dot-product attention, equation 1 of {{Attention Is All You Need (Vaswani et al. 2017)|https://arxiv.org/abs/1706.03762}}:

\[ \operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V \]
  1. Name every symbol. \(Q\) holds the queries (one row per position, "what should I look at?"), \(K\) the keys ("what I contain"), \(V\) the values ("what I hand over"), \(d_k\) the length of each query and key row, \(\top\) the transpose, softmax applied to each row separately. If a symbol is not defined near the equation, search the paper for its first use; the {{Notation decoder|#t-notation}} lists the conventions papers assume without saying.
  2. Write the shape beside every symbol. With \(n\) queries and \(m\) keys: \(Q\) is \(n \times d_k\), \(K\) is \(m \times d_k\), so \(QK^\top\) is \(n \times m\), one score for every query-key pair; \(V\) is \(m \times d_v\), so the result is \(n \times d_v\), one output row per query. If the shapes do not fit, you have misread a symbol.
  3. Read the operations from the inside out, in words. Dot each query with each key (how well they match); divide by \(\sqrt{d_k}\); turn each query's row of scores into weights that add up to 1; return, for each query, the weighted average of the value rows.
  4. Plug in tiny numbers. One query \(q = x = (2, 1)\), the three keys and values are the rows of the tiny model's \(W\), \(d_k = 2\). The raw scores are \((2, 1, 0)\); divided by \(\sqrt{2}\) they are \((1.414, 0.707, 0)\), and softmax turns them into weights \((0.576, 0.284, 0.140)\). The output is \(0.576\,(1, 0) + 0.284\,(0, 1)\) \(+\, 0.140\,(1, -2)\) \(= (0.716, 0.004)\): mostly cat's row. Without the division the weights would be \((0.665, 0.245, 0.090)\), sharper.
  5. Ask why each piece is there. Why \(\sqrt{d_k}\)? The paper's footnote: if a query's and a key's entries are independent with mean 0 and variance 1, their dot product has variance \(d_k\). With \(d_k = 64\) raw scores would typically be about 8 apart, softmax would put nearly all the weight on one key, and its gradients would vanish; dividing by \(\sqrt{d_k}\) brings the variance back to 1. A term you cannot justify is usually the thing the paper is really about.
The habit
Name, shape, read, plug, ask. Step 4 is also how you test your own derivations: if tiny numbers do not come out right, the algebra is wrong.
