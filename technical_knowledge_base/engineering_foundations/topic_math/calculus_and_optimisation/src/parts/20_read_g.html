6. Quasi-Newton: learn the curvature from gradients, and a race on real data

After a step \(s_k = \theta_{k+1} - \theta_k\) the gradient changes by \(y_k = g_{k+1} - g_k\). For a quadratic \(y_k = H s_k\) exactly, so ask the curvature estimate to satisfy the secant equation \(B_{k+1} s_k = y_k\). BFGS (Broyden, Fletcher, Goldfarb, Shanno, 1970) picks the solution closest to the previous estimate and keeps its inverse directly; the step is \(-M_k g_k\) followed by a line search. It still stores \(n^2\) numbers. L-BFGS ({{Liu and Nocedal 1989|https://doi.org/10.1007/BF01589116}}) keeps only the last \(m\) pairs \((s_k, y_k)\), typically 5 to 20, and applies the inverse to the gradient with a "two-loop recursion" of \(4mn\) multiplications: memory \(2mn\) numbers instead of \(n^2\). It is scikit-learn's default solver for logistic regression. It needs full-batch, deterministic gradients: with minibatch noise \(y_k\) is dominated by sampling noise rather than curvature and the estimate degrades.

The BFGS update and the curvature condition
\[ M_{k+1} = (I - \rho_k s_k y_k^\top)\, M_k\, (I - \rho_k y_k s_k^\top) + \rho_k s_k s_k^\top, \qquad \rho_k = \frac{1}{y_k^\top s_k} \]

\(M_k = B_k^{-1}\). The update needs \(y_k^\top s_k \gt 0\) (the curvature condition; the Wolfe line-search conditions guarantee it), which keeps \(M\) positive definite (Nocedal and Wright, Numerical Optimization, 2nd edition, chapter 6). Each update is a rank-two correction costing \(n^2\). The L-BFGS two-loop recursion is in chapter 7.

7. XGBoost's leaf weights are Newton steps

XGBoost adds one regression tree per round to the current prediction and takes a second-order Taylor expansion of each example's loss around it ({{Chen and Guestrin 2016|https://arxiv.org/abs/1603.02754}}, equation 3), with per-example slope \(g_i\) and curvature \(h_i\), plus a penalty \(\gamma T + \tfrac12 \lambda \lVert w \rVert^2\) on a tree of \(T\) leaves with values \(w_j\). Every example in leaf \(j\) gets the same value, so with \(G_j = \sum_{i \in I_j} g_i\) and \(H_j = \sum_{i \in I_j} h_i\) each leaf's objective is a parabola \(G_j w_j + \tfrac12 (H_j + \lambda) w_j^2\), minimised at

\[ w_j^* = -\frac{G_j}{H_j + \lambda}, \qquad \text{Gain} = \frac12 \Big[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \Big] - \gamma \]

A Newton step \(-G/H\) for the leaf, damped by \(\lambda\); a split is worth the drop in the objective (their equations 5 to 7). That is why XGBoost needs losses with a second derivative, and why its custom-objective API asks for both the gradient and the Hessian of each example.

Derivation of the leaf weight and the gain

The round-\(t\) objective (their equation 2 and 3) is \(\tilde{\mathcal L}^{(t)} = \sum_{i} [ g_i f_t(x_i) + \tfrac12 h_i f_t(x_i)^2 ] + \Omega(f_t)\), with \(g_i = \partial l/\partial \hat y\) and \(h_i = \partial^2 l/\partial \hat y^2\) at the current prediction \(\hat y_i^{(t-1)}\). Grouped by leaves it is \(\sum_{j} [ G_j w_j + \tfrac12 (H_j + \lambda) w_j^2 ] + \gamma T\); each bracket's slope \(G_j + (H_j + \lambda) w_j\) is zero at \(w_j^*\), and substituting back gives \(\tilde{\mathcal L}^* = -\frac12 \sum_j \frac{G_j^2}{H_j + \lambda} + \gamma T\). The gain is the parent's value minus the two children's. Worked: \(G_L = -1.5\), \(H_L = 0.75\), \(G_R = 0.5\), \(H_R = 0.25\), Gain \(= \tfrac12[2.25/1.75 + 0.25/1.25 - 1/2] - \gamma\).
