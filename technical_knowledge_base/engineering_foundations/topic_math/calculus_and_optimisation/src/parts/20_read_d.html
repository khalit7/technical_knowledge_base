5. The gradient of every standard loss: prediction minus target

The question. Backprop starts from the gradient of the loss with respect to the model's raw output. What is it for each loss, and why do they all look the same?

Setup and words. The model's raw output before any squashing is the logit \(z\) (a score, any real number). A final activation turns it into a prediction: nothing (identity) for regression, the sigmoid \(\sigma\) for yes/no, the softmax for one of \(K\) classes. The loss compares the prediction with the target \(y\). The gradient \(\partial L / \partial z\) is what backprop pushes into the network, so it is the one derivative worth knowing by heart. The root's {{Gradient lab|n:3c65c17b0d0d81cdb851c0835b25a538}} (panel 1, Loss explorer) checks each one numerically with sliders; here is each derivation in full.

Mean squared error, and the factor of a half

\[ L = \tfrac12 (\hat y - y)^2,\ \hat y = z \quad\Rightarrow\quad \frac{\partial L}{\partial z} = (\hat y - y) \cdot 1 = \hat y - y \]

The chain rule: the slope of \(\tfrac12 u^2\) is \(u\), and \(\hat y = z\) has slope 1. The half is a convention. Without it, \(L = (\hat y - y)^2\) has gradient \(2(\hat y - y)\); averaged over a batch of \(n\), \(L = \frac1n \sum_i (\hat y_i - y_i)^2\) gives each example the gradient \(\frac{2}{n}(\hat y_i - y_i)\) (the old page's "\(2/n\)", which the root's Gradient lab corrected by stating both conventions). PyTorch's MSELoss has no half. The constant only rescales the learning rate. Example: \(z = 1.5\), \(y = 1\): with the half, \(L = 0.125\) and gradient 0.5; without it, \(L = 0.25\) and gradient 1.0.

For linear regression, \(\hat y = Xw\), with the batch-mean loss without the half: \(\nabla_w L = \frac{2}{n} X^\top (Xw - y)\), and setting it to zero gives the normal equations \(X^\top X w = X^\top y\) (\(X\) is the \(n \times d\) table of inputs, one row per example). At the optimum the residual \(Xw - y\) is perpendicular to every column of \(X\). Worked example (old page, recomputed): points \((1, 1), (2, 3), (3, 4)\) with an intercept column give \(X^\top X = \begin{pmatrix} 3 & 6 \\ 6 & 14 \end{pmatrix}\), \(X^\top y = (8, 19)\), determinant 6, so \(w = \frac16 \begin{pmatrix} 14 & -6 \\ -6 & 3 \end{pmatrix} (8, 19) = (-1/3, 3/2)\): the line \(\hat y = -0.333 + 1.5x\). The residuals \((0.167, -0.333, 0.167)\) sum to 0 and \(1(0.167) + 2(-0.333) + 3(0.167) = 0\). How to solve this stably (QR rather than the normal equations) is on {{Linear algebra for ML|n:3c65c17b0d0d81d89c26e1dab2fcb701}}, section 9.

Binary cross-entropy with a sigmoid

\[ p = \sigma(z), \qquad L = -\big[ y \ln p + (1 - y) \ln (1 - p) \big], \qquad y \in \{0, 1\} \]

Two slopes, then the chain rule. The slope of the loss in \(p\) is \(-\frac{y}{p} + \frac{1 - y}{1 - p} = \frac{p - y}{p(1 - p)}\) (put both over \(p(1-p)\)); it blows up as \(p \to 0\) or 1. The slope of \(p\) in \(z\) is \(p(1 - p)\) (section 2). Multiply:

\[ \frac{\partial L}{\partial z} = \frac{p - y}{p(1 - p)} \cdot p(1 - p) = p - y \]

The \(p(1-p)\) cancels exactly, so nothing divides by a saturated probability. The loss itself is computed stably on the logit as \(\max(z, 0) - yz + \ln(1 + e^{-|z|})\), which never exponentiates a large positive number (PyTorch's BCEWithLogitsLoss). Examples (old page, recomputed): \(z = -6\), \(y = 1\), confidently wrong: \(p = 0.0025\), loss 6.0025, gradient \(-0.9975\), nearly the largest push possible. \(z = 2\), \(y = 1\): \(p = 0.8808\), loss 0.1269, gradient \(-0.1192\), a small push because the prediction is already right.

Softmax cross-entropy

\[ p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}, \qquad L = -\ln p_t = -z_t + \ln \sum_j e^{z_j} \]

\(t\) is the true class. The second form makes the derivative two lines: the slope of \(-z_t\) with respect to \(z_k\) is \(-1\) if \(k = t\) and 0 otherwise, written \(-\mathbb{1}[k = t]\); the slope of \(\ln \sum_j e^{z_j}\) is \(\frac{e^{z_k}}{\sum_j e^{z_j}} = p_k\) (chain rule through the log). So

\[ \frac{\partial L}{\partial z_k} = p_k - \mathbb{1}[k = t], \qquad \nabla_z L = p - e_t \]

where \(e_t\) is the one-hot vector of the true class. Going through the softmax Jacobian \(\partial p_k / \partial z_j = p_k(\delta_{kj} - p_j)\) (\(\delta_{kj}\) is 1 when \(k = j\), else 0; as a matrix \(\operatorname{diag}(p) - pp^\top\)) gives the same answer: \(-\frac{1}{p_t} \cdot p_t(\delta_{tj} - p_j) = p_j - \delta_{tj}\). With soft targets \(q\) (label smoothing, distillation), \(L = -\sum_k q_k \ln p_k\) and \(\nabla_z L = p - q\) because the \(q_k\) sum to 1.

The numbers
Old page example: \(z = (2, 1, 0.1)\), class 1 true. \(e^z = (7.389, 2.718, 1.105)\), sum 11.2125, which rounds to 11.213 (the old page printed 11.212), so \(p = (0.659, 0.242, 0.099)\), loss \(-\ln 0.659 = 0.417\), gradient \((-0.341, 0.242, 0.099)\). The components sum to 0, because adding a constant to every logit leaves the softmax unchanged. The tiny model, true word sat: \(p - e_{\text{sat}} = (0.665, 0.245, -0.910)\). With soft target \(q = (0.9, 0.05, 0.05)\) instead: \(p - q = (-0.235, 0.195, 0.040)\).

Why they all end the same way: the canonical link

Each pairing is a generalised linear model: the target follows an exponential-family distribution (Gaussian, Bernoulli, categorical, Poisson) whose natural parameter is the logit, joined by the canonical link (identity, logit, softmax, log). For every such pair, the negative log-likelihood has gradient mean minus target with respect to the logit: \(\nabla_z L = \mu - y\). A fourth instance: counts with a Poisson distribution and log link, rate \(\mu = e^z\), loss \(e^z - yz + \ln y!\), gradient \(e^z - y\); with \(y = 3\) and \(z = \ln 2\), the loss is 1.712 and the gradient \(-1\). Why each loss is a negative log-likelihood is on {{Probability for ML|n:3c65c17b0d0d815f9a47d613409b5a0c}}.

Why the cancellation matters

  1. No vanishing gradient at the output. Squared error on a sigmoid, \(L = (p - y)^2\), has \(\partial L/\partial z = 2(p - y)\,p(1 - p)\): the \(p(1-p)\) does not cancel. At \(z = -6\), \(y = 1\) it is \(2(0.0025 - 1)(0.0025)(0.9975) = -0.0049\), about 203 times smaller than cross-entropy's \(-0.9975\), exactly when the model is most wrong. That is the concrete reason classification uses cross-entropy.
  2. Numerical stability. Frameworks fuse softmax and cross-entropy (CrossEntropyLoss takes logits) and compute \(\ln \sum_j e^{z_j} = m + \ln \sum_j e^{z_j - m}\) with \(m = \max_j z_j\). For logits \((1000, 1001)\), \(e^{1001}\) overflows even in float64; the shifted form gives \(1001 + \ln(e^{-1} + 1) = 1001.313\). Floating point in depth: {{Numerical computing for ML|n:3f05c17b0d0d81d6af0be4a9a2edba8d}}.
  3. Cheap. The \(K \times K\) softmax Jacobian is never built; \(p - e_t\) costs \(K\) operations. For a language model \(K\) is the vocabulary.

From here the gradient flows back through the network by the chain rule. The mechanics, including the old page's worked logistic unit (\(z = 0.1\), \(p = 0.525\), loss 0.644, one step to \(p = 0.595\)), are on {{Matrix calculus and backprop|n:3f05c17b0d0d817e9892e01088179c93}} (sections 4, 5 and 7).
