5. Gradients through samples: score function against reparameterisation

With a neural \(q_\phi\) there is no closed-form update; we need \(\nabla_\phi\) of \(\mathbb{E}_{z\sim q_\phi}[f_\phi(z)]\), with \(f_\phi(z) = \log p(x,z) - \log q_\phi(z)\), an average whose sampling distribution moves with the parameters. {{Probability for ML, section 11|n:3c65c17b0d0d815f9a47d613409b5a0c}} introduces both estimators on \(f(x) = x^2\); here they are derived for the ELBO and pushed to the case that decides between them, many latent dimensions.

Score function (REINFORCE, likelihood ratio)

  1. Differentiate under the integral: \(\nabla_\phi \int q_\phi f_\phi = \int \nabla_\phi q_\phi\, f_\phi + \int q_\phi\, \nabla_\phi f_\phi\).
  2. Use \(\nabla q = q\, \nabla \log q\): the first integral is \(\mathbb{E}_q\big[f_\phi\, \nabla_\phi \log q_\phi\big]\); \(\nabla_\phi \log q_\phi(z)\) is the score of \(q\).
  3. The second integral is \(-\mathbb{E}_q[\nabla_\phi \log q_\phi] = -\nabla_\phi \int q_\phi = -\nabla_\phi 1 = 0\): the score averages to zero.
\[ \nabla_\phi \text{ELBO} = \mathbb{E}_{q_\phi}\big[f_\phi(z)\,\nabla_\phi \log q_\phi(z)\big]. \]

Try a \(z\), see how good it was, push \(q\) towards it in proportion. No derivative of \(f\) needed, so it works for discrete \(z\) and non-differentiable rewards ({{Williams 1992|https://doi.org/10.1007/BF00992696}}), which is why policy gradients use it.

Reparameterisation (pathwise)

  1. Write the sample as a function of the parameters and of noise that does not depend on them: \(z = g_\phi(\varepsilon) = \mu + \sigma\varepsilon\), \(\varepsilon \sim \mathcal{N}(0, 1)\) (element-wise for a diagonal Gaussian; Kingma and Welling eq. 5 and 10).
  2. The average is now over \(\varepsilon\), whose distribution has no \(\phi\), so the gradient moves inside: \(\nabla_\phi \mathbb{E}_\varepsilon[f_\phi(g_\phi(\varepsilon))] = \mathbb{E}_\varepsilon[\nabla_\phi f_\phi(g_\phi(\varepsilon))]\).
  3. The chain rule does the rest (\(\partial z/\partial\mu = 1\), \(\partial z/\partial \sigma = \varepsilon\)); autograd treats the sample as one more node.

It uses the slope of \(f\) at the sample, not only its value: one sample already says which way is uphill.

Model A: the gradient of the ELBO with respect to \(q\)'s mean, at \(q = \mathcal{N}(0.5, 0.5^2)\)

True value: \(\frac{\partial}{\partial m}\text{ELBO} = \frac{x - m}{s^2} - m = \frac{1.0}{0.25} - 0.5 = 3.5\). Pathwise, one sample gives \(\frac{x - z}{s^2} - z\) (the \(\log q\) term has no \(m\) once \(z = m + \sigma\varepsilon\)); \(z\) enters linearly with slope \(-(1/s^2 + 1) = -5\), so the variance is exactly \(25 \cdot \sigma^2 = 6.25\). Score function, one sample: \(f(z)\,(z - m)/\sigma^2\), variance 71 by simulation, 25 with a baseline (the average of \(f\), the ELBO itself) subtracted from \(f\). Both average to 3.5. Now give the latent \(d\) dimensions (\(d\) independent copies of model A) and ask for the gradient with respect to the first mean: pathwise looks only at coordinate 1, while the score function multiplies the whole \(f\), a sum of \(d\) noisy terms, by coordinate 1's score.

Same mean, different noise: the score function's variance grows with the dimension, pathwise stays at 6.25

Variance of one-sample estimates (log scale), 400,000 draws each, model A copied \(d\) times. At \(d = 100\) the score-function estimator needs about 65,000 times as many samples as the pathwise one for the same precision (variance 403,466 against 6.25), and still 200 times as many with a baseline (1,256).

A VAE latent has 16 to a few hundred dimensions. That gap is why the reparameterisation trick made VAEs trainable, and why the score function lives on in RL only with heavy variance reduction (baselines, advantages: {{Policy gradients and actor-critic|n:3ee5c17b0d0d8101a262d3620e75747c}}).

Starts from the \(q\) set in section 3's widget (model A by default) and moves it there too. Gradient ascent on \((m, \log\sigma)\), seeded so a run repeats exactly. The pathwise estimator uses the slope of \(\log p(x, z)\) at each sample and the closed-form entropy of \(q\); the score-function estimator uses only the values of \(\log p(x,z) - \log q(z)\), times the score of \(q\). Both are unbiased; the trace plots the exact ELBO of the current \(q\).

When you cannot reparameterise
Discrete latents (a category, a token) have no smooth \(g_\phi\). Options: the score function with baselines (control variates); the Gumbel-softmax relaxation, a differentiable approximation to a categorical sample ({{Probability for ML, section 10|n:3c65c17b0d0d815f9a47d613409b5a0c}}); or straight-through estimators, which VQ-VAE uses to pass gradients through its codebook lookup ({{van den Oord et al. 2017|https://arxiv.org/abs/1711.00937}}).
