17. Classifier-free guidance, as a formula

The question. A text-to-image model asked for "a red bicycle" should stick to the prompt more than plain conditional sampling does. What is the one line that achieves it, and where does it come from?

  1. Bayes' rule for scores. \(p(x \mid c) \propto p(c\mid x)\,p(x)\), so \(\nabla_x \log p(x\mid c) = \nabla_x\log p(x) + \nabla_x \log p(c \mid x)\): the conditional score is the unconditional one plus a classifier's gradient (the normalising constant \(p(c)\) has no \(x\) in it and vanishes).
  2. Turn up the classifier. Sampling with \(\nabla\log p(x) + (1+w)\,\nabla\log p(c\mid x)\) targets \(p(x)\,p(c\mid x)^{1+w}\): images the classifier is more sure about. That is classifier guidance ({{Dhariwal and Nichol 2021|https://arxiv.org/abs/2105.05233}}), which needs a separate classifier trained on noisy images.
  3. Remove the classifier. Bayes again: \(\nabla\log p(c\mid x) = \nabla\log p(x\mid c) - \nabla\log p(x)\). Substitute: \[\nabla\log p(x) + (1+w)\big(\nabla\log p(x\mid c) - \nabla\log p(x)\big) = (1+w)\nabla\log p(x\mid c) - w\,\nabla\log p(x)\].
  4. Write it with noise predictions (\(s = -\varepsilon/\sqrt{1-\bar\alpha}\), section 15) and you have {{Ho and Salimans 2022|https://arxiv.org/abs/2207.12598}}, eq. 6:
\[ \tilde\varepsilon_\theta(x_t, c) = (1+w)\,\varepsilon_\theta(x_t, c) - w\,\varepsilon_\theta(x_t, \varnothing). \]

Run the network twice, with the condition and with an empty condition \(\varnothing\), and extrapolate past the conditional prediction, away from the unconditional one. One network does both: during training the condition is replaced by \(\varnothing\) with some probability (15% for this page's toy). \(w = 0\) is plain conditional sampling.

Two conventions for the same knob
Libraries usually write \(\varepsilon_\varnothing + s\,(\varepsilon_c - \varepsilon_\varnothing)\), so \(s = 1 + w\). Hugging Face diffusers' Stable Diffusion pipeline defaults to guidance_scale = 7.5, which is \(w = 6.5\) in the paper's notation ({{pipeline_stable_diffusion.py, v0.35.1|https://github.com/huggingface/diffusers/blob/v0.35.1/src/diffusers/pipelines/stable_diffusion/pipeline_stable_diffusion.py}}).

18. Flow matching and rectified flow

The question. If generation is integrating an ODE from noise to data (sections 15, 16), why not learn the ODE's velocity directly, with the simplest possible path?

The path. Pair a data point \(x_0\) with a noise sample \(\varepsilon\) and join them by a straight line: \(x_t = (1-t)\,x_0 + t\,\varepsilon\), \(t \in [0, 1]\) ({{Esser et al. 2024 (Stable Diffusion 3), eq. 13|https://arxiv.org/abs/2403.03206}}; {{Liu, Gong and Liu 2022, rectified flow|https://arxiv.org/abs/2209.03003}}). Along that line the velocity is constant, \(\frac{dx_t}{dt} = \varepsilon - x_0\).

The loss (conditional flow matching, {{Lipman et al. 2023|https://arxiv.org/abs/2210.02747}}):

\[ \mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t \sim U[0,1],\ x_0,\ \varepsilon}\,\big\|v_\theta(x_t, t) - (\varepsilon - x_0)\big\|^2 . \]
  1. Many lines pass through the same point \(x\) at time \(t\). The best single answer for a squared loss is their average direction, the marginal velocity \(v^*(x,t) = \mathbb{E}[\varepsilon - x_0 \mid x_t = x]\).
  2. Lipman et al.'s Theorem 2: the conditional loss above and the (intractable) loss against \(v^*\) differ by a constant, so they have the same gradients. We regress on single lines and learn the average.
  3. The ODE \(dx/dt = v^*(x, t)\) moves the whole noise distribution at \(t = 1\) onto the data distribution at \(t = 0\) (the marginals of the straight-line paths are preserved). Generate by integrating backwards from \(t = 1\): Euler steps \(x \leftarrow x - \tfrac1S v_\theta(x, t)\).

It is the same family as diffusion: \(x_t\) is a scaled data point plus scaled Gaussian noise, so a velocity prediction converts to a noise prediction (\(\hat\varepsilon = x_t + (1-t)\,v\)) or a clean-data prediction (\(\hat x_0 = x_t - t\,v\)). What changes is the path (straight in \(t\) rather than variance-preserving) and the target (velocity rather than noise), and with them which errors are cheap.

Trajectories of 40 samples from the same starting noise, deterministic in both cases (50 steps, unconditional). Left: DDIM with the noise-prediction network. Right: Euler on the flow-matching network. Straightness = straight-line distance from start to end divided by the path length (1 = perfectly straight); the lines bend where they must choose a moon.

What the measurement says. On the 40 paths drawn, the flow-matching paths are less straight than DDIM's (0.55 against 0.73; recomputed in src/check_js.mjs). Each training line is straight, but lines from different (data, noise) pairs cross, and the network learns their average direction, which bends as a path has to commit to one moon; on two well-separated modes that bend is large. So the claim "flow matching gives straight paths" holds for each conditional path, not automatically for the learned ones. The flow model's good 5-step result in section 16 comes from where its steps fall in noise level, not from straightness. Rectified flow's reflow step retrains on the model's own (noise, sample) pairs, which no longer cross, to straighten the learned paths (Liu et al. 2022, section 2.1: "This reflow procedure not only decreases transport cost, but also has the important effect of straightening paths"); distillation then needs very few steps. Conventions differ: Lipman et al. put noise at \(t = 0\) and data at \(t = 1\) (their eq. 22 to 23, with a small \(\sigma_{\min}\)); Stable Diffusion 3 and this page put data at \(t = 0\).
