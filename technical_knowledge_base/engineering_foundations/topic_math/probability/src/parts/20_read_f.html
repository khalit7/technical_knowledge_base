8. From distribution to loss: the five standard losses, derived

The question. Why is BCE the loss for yes-or-no labels, squared error for real numbers, and \(e^{z} - yz\) for counts? Is the loss a free design choice?

It is not. The recipe is always the same three moves: (1) say which distribution \(y\) follows given the input, with the network outputting its parameter; (2) the loss for one example is \(-\ln p(y \mid \text{output})\); (3) drop every term that does not depend on the network's output, since it changes neither the gradient nor the optimum. Over a dataset of independent examples the losses add (section 10).

Bernoulli to binary cross-entropy (BCE)

Model \(y \in \{0, 1\}\), \(y \mid x \sim \text{Bernoulli}(\hat p)\) with \(\hat p = \sigma(z) = 1/(1 + e^{-z})\) and \(z\) the network's logit.

\[ \ell = -\ln\big(\hat p^{\,y} (1 - \hat p)^{1 - y}\big) = -\big[y \ln \hat p + (1 - y)\ln(1 - \hat p)\big]. \]

In terms of the logit, using \(\ln \hat p = -\ln(1 + e^{-z})\) and \(\ln(1 - \hat p) = -z - \ln(1 + e^{-z})\): \(\ell = \ln(1 + e^{z}) - yz\), which is the exponential-family form \(A(z) - zT(y)\). So \(\partial \ell / \partial z = \sigma(z) - y = \hat p - y\). (Through the chain rule instead: \(\partial \ell/\partial \hat p = (\hat p - y)/(\hat p(1 - \hat p))\) and \(\sigma'(z) = \hat p(1 - \hat p)\); the factors cancel. The full step-by-step derivation is on the root's section 4.)

The numbers (spam filter, carried and rechecked)
Output \(\hat p = 0.8\). Spam (\(y = 1\)): loss \(-\ln 0.8 = 0.223\), gradient \(0.8 - 1 = -0.2\) (push \(z\) up a little). Not spam (\(y = 0\)): loss \(-\ln 0.2 = 1.609\), gradient \(0.8\) (push \(z\) down hard). The confident wrong answer costs 7.2 times the right one, and the cost grows without bound as a wrong prediction nears certainty.

In code: PyTorch's torch.distributions.Bernoulli.log_prob is literally -binary_cross_entropy_with_logits(logits, value) (torch 2.14.1 source, saved in src/inputs/).

Categorical to softmax cross-entropy

Model \(y \in \{1, \dots, K\}\), \(y \mid x \sim \text{Categorical}(p)\), \(p = \operatorname{softmax}(z)\).

\[ \ell = -\ln p_y = -z_y + \ln \sum_{k=1}^{K} e^{z_k}, \qquad \frac{\partial \ell}{\partial z_k} = p_k - [k = y], \ \text{ i.e. } \ \nabla_z \ell = p - e_y. \]

The derivative of \(\ln\sum_k e^{z_k}\) with respect to \(z_k\) is \(e^{z_k}/\sum_j e^{z_j} = p_k\); the derivative of \(-z_y\) is \(-1\) for \(k = y\) and 0 otherwise. With \(K = 2\) and \(z = (z_1, 0)\) this is exactly sigmoid plus BCE.

The numbers (the tiny model)
Target sat: \(\ell = -z_{\text{sat}} + \ln 11.107 = 0 + 2.408 = 2.408\); gradient \((0.665, 0.245, -0.910)\). Had the target been cat: \(\ell = -2 + 2.408 = 0.408\), gradient \((-0.335, 0.245, 0.090)\): raise cat's score, lower the others in proportion to the probability they took.

Gaussian to squared error (MSE)

Model \(y \in \mathbb{R}\), \(y \mid x \sim \mathcal{N}(\hat y, \sigma^2)\) with \(\hat y\) the network's output and \(\sigma\) fixed.

\[ \ell = -\ln\Big(\frac{1}{\sqrt{2\pi\sigma^2}} e^{-(y - \hat y)^2 / 2\sigma^2}\Big) = \frac{(y - \hat y)^2}{2\sigma^2} + \tfrac12 \ln(2\pi\sigma^2), \qquad \frac{\partial \ell}{\partial \hat y} = \frac{\hat y - y}{\sigma^2}. \]

The second term and the factor \(1/(2\sigma^2)\) do not depend on \(\hat y\), so minimising this NLL over the network is minimising the squared error: MSE is Gaussian maximum likelihood. The constant that minimises squared error over a sample is its mean.

The numbers
\(\sigma = 1\), prediction 2.5, target 3: \(\ell = 0.125 + 0.919 = 1.044\), of which only the 0.125 (half the squared error) depends on the model; gradient \(-0.5\).

Learning the variance too (heteroscedastic regression): let the network output \(\sigma^2\) as well. Then \(\ell = \tfrac12\big(\ln \sigma^2 + (y - \hat y)^2/\sigma^2\big)\) plus a constant, which is exactly PyTorch's gaussian_nll_loss (with full=False it drops \(\tfrac12\ln 2\pi\), and it clamps \(\sigma^2\) at eps; torch 2.14.1 source in src/inputs/). Setting \(\partial \ell/\partial \sigma^2 = 0\) gives \(\sigma^2 = (y - \hat y)^2\): the model learns its own error size. With residual 0.5, the loss is 0.125 at \(\sigma^2 = 1\) and \(-0.193\) at the optimum \(\sigma^2 = 0.25\) (densities above 1 give negative losses). A known pitfall: the \(1/\sigma^2\) weight lets the model give up on hard points by inflating \(\sigma^2\); {{Seitzer et al., 2022|https://arxiv.org/abs/2203.09168}} propose the \(\beta\)-NLL fix.

Laplace to absolute error (L1)

Model \(y \mid x \sim \text{Laplace}(\hat y, b)\), \(b\) fixed.

\[ \ell = -\ln\Big(\frac{1}{2b} e^{-|y - \hat y| / b}\Big) = \frac{|y - \hat y|}{b} + \ln 2b, \qquad \frac{\partial \ell}{\partial \hat y} = \frac{\operatorname{sign}(\hat y - y)}{b}. \]

The Laplace has heavier tails than the Gaussian, so a large residual is not astronomically improbable and is charged linearly, not quadratically: one outlier cannot dominate the fit. The constant that minimises absolute error over a sample is its median, which ignores how far away an outlier is. The gradient has the same size for every wrong prediction, a sign rather than a difference, because the Laplace is not in the exponential family.

The numbers
\(b = 1\), prediction 2.5, target 3: \(\ell = 0.5 + \ln 2 = 1.193\); gradient \(-1\).

Poisson to the Poisson loss

Model a count \(y \in \{0, 1, 2, \dots\}\), \(y \mid x \sim \text{Poisson}(\lambda)\) with \(\lambda = e^{z}\) (the log link keeps the rate positive).

\[ \ell = -\ln\frac{\lambda^y e^{-\lambda}}{y!} = \lambda - y\ln\lambda + \ln y! = e^{z} - yz + \ln y!, \qquad \frac{\partial \ell}{\partial z} = e^{z} - y = \lambda - y. \]

\(\ln y!\) does not depend on the model, so the loss is \(e^z - yz\) (PyTorch's PoissonNLLLoss with log_input=True).

The numbers (carried and rechecked)
Rate \(\lambda = 2\), observed \(y = 3\): \(P(Y = 3) = 8e^{-2}/6 = 0.180\), NLL \(2 - 3\ln 2 + \ln 6 = 1.712\), of which the model-dependent part is \(2 - 3 \times 0.693 = -0.079\) (a loss that drops constants can be negative); gradient \(2 - 3 = -1\).

The mistake this prevents
Squared error on a yes-or-no label is a Gaussian model of a binary outcome. Through a sigmoid its gradient \((\hat p - y)\,\hat p(1 - \hat p)\) vanishes when the model is confidently wrong (at \(z = -6\) and \(y = 1\), about 200 times smaller than BCE's; worked on {{Calculus and optimisation for ML|n:3c65c17b0d0d81eb8b49ed6a0f897f3b}}). The loss and the distribution are one decision.
