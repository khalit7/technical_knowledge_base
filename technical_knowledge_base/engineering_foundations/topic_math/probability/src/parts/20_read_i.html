10. Sampling: inverse CDF, Gumbel-max and Gumbel-softmax

A computer makes uniform numbers in \([0, 1)\); generation needs draws from \(p = (0.665, 0.245, 0.090)\). Two exact routes:

  • Inverse CDF. Draw \(u\) and return the first value whose CDF reaches it, \(x = F^{-1}(u)\); then \(P(X \le x) = P(u \le F(x)) = F(x)\). Tiny model, CDF \((0.665, 0.910, 1)\): \(u \lt 0.665\) gives cat, \(0.665 \le u \lt 0.910\) dog, otherwise sat; \(u = 0.7\) gives dog. Continuous: the exponential has \(F(x) = 1 - e^{-\lambda x}\), so \(x = -\ln(1 - u)/\lambda\); with \(\lambda = 2\) and \(u = 0.5\), \(x = 0.347\), the median. Hugging Face transformers samples with torch.multinomial(probs, num_samples=1) (v5.18.0 generation/utils.py, excerpt in src/inputs/).
  • Gumbel-max. Add independent Gumbel noise \(g_i = -\ln(-\ln u_i)\) to each logit and take the largest: \(\arg\max_i (z_i + g_i) \sim \operatorname{Categorical}(\operatorname{softmax}(z))\). No normalisation is needed. Uniforms \(u = (0.2, 0.9, 0.5)\) give \(g = (-0.476, 2.250, 0.367)\), \(z + g = (1.524, 3.250, 0.367)\): dog.

Predict, then step: both samplers use the same seeded uniform stream. After 10 draws, will either be within 0.05 of \(p\) on every word? After 10,000?

Two routes from uniform numbers to the same distribution

One uniform per draw for inverse CDF, three for Gumbel-max. Bars are frequencies after each batch; the ticks are \(p\). Steps go 1, 2, 3, 10, 100, 1,000, 10,000 draws; the error shrinks like \(1/\sqrt{n}\) (section 4).

The exponential race, how vLLM samples. Since \(-\ln(-\ln u) = -\ln E\) with \(E = -\ln u\) exponential, \(\arg\max_i (z_i - \ln E_i) = \arg\max_i\, p_i / E_i\). The same draw: \(E = (1.609, 0.105, 0.693)\), \(p_i/E_i = (0.413, 2.323, 0.130)\), also dog. vLLM v0.11.0's random_sample is probs.div_(q).argmax(dim=-1) with q.exponential_(), avoiding the CPU-GPU synchronisation that torch.multinomial causes, per its own comment.

Gumbel-softmax, at the level of why. An argmax has zero gradient almost everywhere, so a discrete sample blocks backpropagation. Replacing the argmax with a softmax at temperature \(\tau\), \(\operatorname{softmax}((z + g)/\tau)\), gives a differentiable approximate one-hot sample (the Gumbel-softmax or Concrete relaxation, {{Jang et al., 2017|https://arxiv.org/abs/1611.01144}}; {{Maddison et al., 2017|https://arxiv.org/abs/1611.00712}}): as \(\tau \to 0\) it becomes the exact Gumbel-max sample, and at larger \(\tau\) it is smoother with lower-variance but biased gradients. The noise \(g\) does not depend on \(z\), so it is a reparameterisation (section 11) for discrete choices. PyTorch's F.gumbel_softmax draws its Gumbels as -empty_like(logits).exponential_().log() (torch 2.14.1).

Used for: text generation; RL rollouts (GRPO and PPO sample several answers per prompt); Gumbel-top-k for sampling without replacement; Gumbel-softmax for discrete latent variables and differentiable architecture search; inverse CDF and Cholesky (section 2) for continuous draws.

Why Gumbel-max gives exactly the softmax (proof)

A standard Gumbel has CDF \(P(g \le x) = \exp(-e^{-x})\) (inverse CDF: \(g = -\ln(-\ln u)\)). So \(M_j = z_j + g_j\) has CDF \(\exp(-e^{z_j - m})\) and density \(e^{z_i - m}\exp(-e^{z_i - m})\). Item \(i\) wins when \(M_i = m\) and every other \(M_j \le m\):

\[ P(i \text{ wins}) = \int_{-\infty}^{\infty} e^{z_i - m} e^{-e^{z_i - m}} \prod_{j \ne i} e^{-e^{z_j - m}}\, dm = \int_{-\infty}^{\infty} e^{z_i} e^{-m} \exp\!\big(-S e^{-m}\big)\, dm, \quad S = \sum_j e^{z_j}. \]

Substitute \(s = e^{-m}\) (\(ds = -s\,dm\)): the integral becomes \(\int_0^\infty e^{z_i} e^{-Ss}\,ds = e^{z_i}/S\), exactly the softmax.
