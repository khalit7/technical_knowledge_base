Derivative workbench

Pick a layer. The workbench runs its forward pass, its hand-derived backward rule (the vector-Jacobian product from the Reading's section 5), and a numerical check: every input entry is nudged by \(\pm h\) and the probe loss \(\tilde L = \bar y \cdot f(\text{inputs})\) is differenced, whose gradient is exactly the VJP. It also builds the full Jacobian with respect to the first input, one VJP per output entry, to show what the backward rule avoids building. Defaults are the Reading's worked numbers; "New random inputs" draws fresh ones.

Derivation

\(y = Wx + b\), \(W\) is \(m \times n\).

  1. One entry: \(y_k = \sum_j W_{kj} x_j + b_k\).
  2. \(\partial y_k / \partial W_{ij} = \delta_{ki} x_j\), so \(\bar W_{ij} = \bar y_i x_j\): \(\bar W = \bar y\,x^\top\).
  3. \(\partial y_k / \partial x_j = W_{kj}\), so \(\bar x = W^\top \bar y\); and \(\bar b = \bar y\).

Jacobian with respect to \(x\): \(W\) itself. Reading section 5a.

\(h = \phi(a)\), entry by entry.

  1. Output \(i\) depends only on input \(i\): the Jacobian is \(\operatorname{diag}(\phi'(a))\).
  2. \(\bar a = \bar h \odot \phi'(a)\).
  3. \(\phi'\): ReLU \([a > 0]\); tanh \(1 - h^2\); sigmoid \(h(1 - h)\); GELU \(\Phi(a) + a\,\varphi(a)\).

Reading section 5b.

\(p = \operatorname{softmax}(z)\).

  1. \(\partial p_i / \partial z_j = p_i(\delta_{ij} - p_j)\): \(J = \operatorname{diag}(p) - pp^\top\) (symmetric).
  2. \(\bar z = J^\top \bar p = p \odot \bar p - p\,(p \cdot \bar p)\).
  3. So \(\bar z = p \odot (\bar p - (p \cdot \bar p)\mathbf 1)\): \(O(K)\), no \(K \times K\) table.

Reading sections 2 and 5c.

\(L = -\ln p_y = -z_y + \ln \sum_j e^{z_j}\).

  1. \(\partial(-z_y)/\partial z_k = -[k = y]\).
  2. \(\partial \ln \sum_j e^{z_j} / \partial z_k = e^{z_k} / \sum_j e^{z_j} = p_k\).
  3. \(\bar z = \bar L\,(p - \mathbf 1_y)\), with \(\bar L = 1\) for a single loss.

Reading section 5d; the target is the third class (sat).

\(\hat x = (x - \mu)\,r\), \(r = (\sigma^2 + \epsilon)^{-1/2}\), \(y = \gamma \odot \hat x + \beta\), \(N\) entries.

  1. \(\bar\gamma = \bar y \odot \hat x\), \(\bar\beta = \bar y\), \(\hat g = \bar y \odot \gamma\).
  2. \(\partial \hat x_i / \partial x_j = r(\delta_{ij} - \tfrac 1N - \tfrac 1N \hat x_i \hat x_j)\).
  3. \(\bar x = r(\hat g - \operatorname{mean}(\hat g) - \hat x \odot \operatorname{mean}(\hat g \odot \hat x))\).
  4. PyTorch's kernel form: \(\bar x = a\,\bar y \odot \gamma + b\,x + c\) with \(a = r\), \(b = (d_b\,\mu - d_s)\,r^3/N\), \(c = -b\mu - d_b\,r/N\), \(d_s = \sum \bar y \odot x \odot \gamma\), \(d_b = \sum \bar y \odot \gamma\).

Reading section 5e; \(\epsilon = 10^{-5}\).

\(S = QK^\top/\sqrt d\), \(A = \operatorname{softmax}_{\text{rows}}(S)\), \(O = AV\).

  1. \(\bar V = A^\top \bar O\), \(\bar A = \bar O V^\top\).
  2. \(D_i = \sum_j A_{ij}\bar A_{ij} = \sum_c \bar O_{ic} O_{ic}\).
  3. \(\bar S = A \odot (\bar A - D\mathbf 1^\top)\).
  4. \(\bar Q = \bar S K/\sqrt d\), \(\bar K = \bar S^\top Q/\sqrt d\).

Reading section 5f.
