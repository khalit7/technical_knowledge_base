The idea in one screen

Training needs the slope of one scalar loss with respect to every parameter. Backpropagation is the chain rule multiplied from the loss end: each layer turns the gradient at its output into the gradient at its input with one vector-Jacobian product (VJP), never building the Jacobian, so every slope comes out of one backward pass that costs about twice the forward pass in FLOPs and is paid for by keeping the forward pass's activations.

One backward pass gives every gradient, each in the shape of its variable

The tiny model with one hidden layer, the network section 5 runs by hand. Left: the forward pass, each value with its shape; orange tags mark what it must keep. Middle: the backward pass, read bottom to top; each blue arrow is one VJP, a matrix-vector product, not a Jacobian. Right (below, on a phone): the weight gradients, each an outer product shaped like its weight.

You need: derivatives, the one-variable chain rule and the tiny model's loss (the root, {{Topic: math|n:3c65c17b0d0d81cdb851c0835b25a538}}, Reading sections 2 and 3); matrix products and transposes ({{Linear algebra for ML|n:3c65c17b0d0d81d89c26e1dab2fcb701}}). The losses themselves are on {{Loss functions|n:3c65c17b0d0d8161a72bc8c572f37d55}}, what happens to the gradient next on {{Optimisers and learning-rate schedulers|n:3c65c17b0d0d817080bbc90954681d09}}, PyTorch's autograd engine on {{Tensors, the dispatcher and autograd|n:3f85c17b0d0d81138595c1c6cd52f795}} and JAX's transforms on {{JAX core|n:3c65c17b0d0d81b7a0d1faba6cef5561}}.

Jacobian \(J\)
every output's slope with respect to every input: outputs by inputs, \(m \times n\).
Layout
which way round a derivative table is written; numerator (Jacobian, \(m \times n\)) or denominator (gradient, \(n \times m\)).
\(\bar v\), the adjoint
the gradient of the loss with respect to \(v\), shaped like \(v\).
VJP, JVP
vector-Jacobian product \(J^\top \bar y\) (reverse mode, one output, every input) and Jacobian-vector product \(J u\) (forward mode, one input direction, every output).
Activation (saved)
a forward value a backward rule needs, kept until the backward pass reaches it.
Checkpointing
keeping only some activations and recomputing the rest during the backward pass.
The running example
The same tiny next-token model as the root page: the context "the cat" is the input \(x = (2, 1)\), the weight matrix \(W\) has one row per word, cat \((1, 0)\), dog \((0, 1)\), sat \((1, -2)\), the scores are \(z = Wx = (2, 1, 0)\), softmax turns them into probabilities \(p = (0.665, 0.245, 0.090)\), and the right next word is sat, so the loss is \(L = -\ln 0.090 = 2.408\). Every formula below is tried on these numbers first.
