1. Functions of a vector: the gradient

The question. A loss depends on many numbers at once. How do you describe how it changes when all of them can move?

The picture first

Think of a function of two numbers, \(f(x_1, x_2)\), as the height of a landscape above the point \((x_1, x_2)\). Standing at one point, you can ask how steeply the ground rises if you walk due east (only \(x_1\) changes) and how steeply if you walk due north (only \(x_2\) changes). Those two slopes are the partial derivatives. Every other direction's slope is a mix of them, so those two numbers describe the whole tilt of the ground at that point.

The words, then the formula

For a function that takes a vector \(x\) with \(n\) entries and returns one number (a scalar), the partial derivative \(\partial f / \partial x_i\) is the slope along entry \(i\) with every other entry held fixed. Stacking all \(n\) of them gives the gradient:

\[ \nabla_x f = \left( \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_n} \right) \]
\(\nabla_x f\)
"grad of \(f\) with respect to \(x\)": a vector with one slope per entry of \(x\), so it has the same shape as \(x\).
\(\partial\)
the curly d of a partial derivative: "only this input moves".

What the gradient is for: it gives the best straight-line (linear) prediction of how \(f\) changes for any small step \(\delta\),

\[ f(x + \delta) \approx f(x) + \nabla_x f \cdot \delta = f(x) + \sum_i \frac{\partial f}{\partial x_i}\,\delta_i \]

In plain words: the change in output is each input's change times that input's slope, added up. The slope along a unit direction \(u\) (the directional derivative) is \(\nabla_x f \cdot u\). It is largest when \(u\) points along the gradient, which is why the gradient is the direction of steepest increase and why training steps the other way.

Worked example
\(f(x_1, x_2) = x_1^2 + 3x_1x_2\) at \(x = (2, 1)\), where \(f = 4 + 6 = 10\). Holding \(x_2\) fixed, \(\partial f/\partial x_1 = 2x_1 + 3x_2 = 7\); holding \(x_1\) fixed, \(\partial f/\partial x_2 = 3x_1 = 6\). So \(\nabla f = (7, 6)\). Prediction for the step \(\delta = (0.01, 0)\): \(10 + 7 \times 0.01 = 10.07\); the exact value is \(2.01^2 + 3 \times 2.01 = 10.0701\). Along the unit direction \(u = (0.6, 0.8)\) the slope is \(7 \times 0.6 + 6 \times 0.8 = 9.0\), a little under the steepest possible slope \(\lVert \nabla f \rVert = \sqrt{85} = 9.22\).

A scalar of a matrix: the gradient is a matrix

Nothing changes when the input is a matrix: one partial derivative per entry, arranged in the same rows and columns. For the tiny model's loss as a function of the \(3 \times 2\) weight matrix, \(\nabla_W L\) is also \(3 \times 2\). Rule: the gradient of a scalar has the shape of the thing you differentiate with respect to. It is the most useful sanity check in this whole subject, and it is exactly what PyTorch stores in W.grad.

The tiny model
The root page derives the gradient of the loss with respect to the scores step by step: \(\nabla_z L = p - y\) \(= (0.665, 0.245, 0.090) - (0, 0, 1)\) \(= (0.665, 0.245, -0.910)\), three slopes for three scores. Read it as: raising the cat score by a small \(\varepsilon\) raises the loss by about \(0.665\varepsilon\); raising the sat score lowers it by about \(0.910\varepsilon\). What it is used for in ML
Every optimiser step (\(W \leftarrow W - \eta \nabla_W L\), with learning rate \(\eta\)); gradient norms for clipping and for spotting exploding or vanishing training; saliency maps (the gradient of a class score with respect to the input pixels or tokens).
