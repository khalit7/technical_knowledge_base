5. Backprop through a two-layer network, by hand

Put a ReLU layer in front of the scores: \(a = W_1 x\), \(h = \operatorname{ReLU}(a)\), \(z = W_2 h\), cross-entropy on sat. This is the root page's Gradient lab network, \(W_1\) (\(3 \times 2\)) with rows \((0.5, 0)\), \((0, 1)\), \((1, -3)\) and \(W_2\) (\(3 \times 3\)) with rows \((2, 0, 1)\), \((0, 1, 0)\), \((-1, 1, 0)\) illustrative, chosen so the scores come out \((2, 1, 0)\) again and one hidden unit is off. Every step below is one of the rules in section 6, and the hero figure at the top is this network. The stage walks it one value at a time, moving in close on each layer.

  1. The network, before anything runs. \(x = (2, 1)\), the plates \(W_1\) and \(W_2\) as above, and the right next word is sat. Predict before it plays: hidden unit 3 will come out negative. What will its row of \(\bar W_1\) be?
  2. Layer 1: \(a = W_1 x\). \(a_1 = 0.5 \times 2 + 0 \times 1 = 1\), \(a_2 = 0 \times 2 + 1 \times 1 = 1\), \(a_3 = 1 \times 2 - 3 \times 1 = -1\), so \(a = (1, 1, -1)\). Six multiply-adds.
  3. ReLU: \(h = \max(0, a) = (1, 1, 0)\). Unit 3 is off. The forward pass keeps \(x\), the sign of \(a\), and \(h\) (orange), because the backward rules need them.
  4. Layer 2: \(z = W_2 h = (2, 1, 0)\). The running example's scores, cat 2, dog 1, sat 0. Nine multiply-adds, 15 forward in all.
  5. Loss. \(p = \operatorname{softmax}(z) = (0.665, 0.245, 0.090)\), so \(L = -\ln 0.090 = 2.408\). The forward pass is done; \(p\) is kept.
  6. Start at the loss: \(\bar z = p - y\). \(\bar L = 1\); softmax and cross-entropy together give \(\bar z = (0.665, 0.245, -0.910)\) (section 6d).
  7. \(W_2\)'s gradient, an outer product: \(\bar W_2 = \bar z\,h^\top\). 3 × 3 like \(W_2\), nine multiply-adds. Its third column is 0 because \(h_3 = 0\): a weight that reads a silent unit gets no gradient.
  8. Back through \(W_2\): \(\bar h = W_2^\top \bar z\). Each hidden unit collects the score gradients through its column of \(W_2\): \(\bar h_1 = 2 \times 0.665 - 1 \times (-0.910)\), \(\bar h_2 = 0.245 + (-0.910)\), \(\bar h_3 = 0.665\), so \(\bar h = (2.240, -0.665, 0.665)\). Nine multiply-adds.
  9. Back through the ReLU: \(\bar a = \bar h \odot [a > 0] = (2.240, -0.665, 0)\). The ReLU's slope is 0 where it was off, so unit 3's 0.665 is blocked.
  10. \(W_1\)'s gradient: \(\bar W_1 = \bar a\,x^\top\). Rows \((4.481, 2.240)\), \((-1.330, -0.665)\), \((0, 0)\), six multiply-adds. Unit 3's row is all zero, the answer to the prediction.
  11. And the input's gradient: \(\bar x = W_1^\top \bar a = (1.120, -0.665)\). What the embedding below would receive. Six multiply-adds: 30 backward in all, twice the forward 15.
  12. One gradient step. \(W \leftarrow W - 0.1\,\bar W\) on both layers, the input held fixed: \(p_{\text{sat}}\) rises from 0.090 to 0.483 and the loss falls from 2.408 to 0.728.

Every number above checked against PyTorch 2.14.1 autograd: largest difference 4.4e-16 (src/two_layer.py).

Three moves did all of it: a matrix product sends \(\bar y\) back through \(W^\top\) and gives its weight \(\bar y\,x^\top\); an elementwise function multiplies by its slope (a ReLU's is 0 or 1); and the loss starts the pass at \(p - y\). Unit 3 was off, so its row of \(\bar W_1\) and its column of \(\bar W_2\) are zero: a unit that is off for every example never learns (a dead ReLU). The matrix-product work was 15 multiply-adds forward and 30 backward, twice, which is section 8's rule on the smallest possible case.
