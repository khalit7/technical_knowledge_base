2. Functions that return a vector: the Jacobian, and the shape of every derivative

The question. A layer does not return one number; it returns a vector. Each output can respond to each input. How do you hold all those slopes?

A function \(f\) that takes \(n\) numbers and returns \(m\) numbers (written \(f: \mathbb{R}^n \to \mathbb{R}^m\), where \(\mathbb{R}^n\) means "lists of \(n\) real numbers") has one slope for every (output, input) pair. Arranged as a table with one row per output and one column per input, they form the Jacobian (after Carl Jacobi):

\[ J = \frac{\partial f}{\partial x} = \begin{pmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{pmatrix}, \qquad J_{ij} = \frac{\partial f_i}{\partial x_j}, \quad J \text{ is } m \times n \]

Row \(i\) is the gradient of output \(i\), laid flat. Column \(j\) says how every output responds when only input \(j\) moves. The linear prediction now reads \(f(x + \delta) \approx f(x) + J\delta\): a matrix times the step.

Three Jacobians to know

A linear map. For \(z = Wx\), each output is \(z_i = \sum_j W_{ij} x_j\), so nudging \(x_j\) moves \(z_i\) by \(W_{ij}\) per unit: \(\partial z_i / \partial x_j = W_{ij}\). The Jacobian of a matrix-vector product with respect to the vector is the matrix itself, \(J = W\), here \(3 \times 2\).

An elementwise function. For \(h = \phi(a)\) applied entry by entry (a ReLU, a tanh), output \(i\) depends only on input \(i\), so the Jacobian is diagonal: \(J = \operatorname{diag}(\phi'(a))\), the matrix with the slopes \(\phi'(a_i)\) on the diagonal and zeros elsewhere.

Softmax, derived without skipping a step. Write \(p_i = e^{z_i} / S\) with \(S = \sum_k e^{z_k}\). Two cases.

  1. The same index, \(j = i\). The quotient rule (slope of top over bottom = (top' times bottom minus top times bottom') over bottom squared), with \(\partial e^{z_i}/\partial z_i = e^{z_i}\) and \(\partial S/\partial z_i = e^{z_i}\): \[ \frac{\partial p_i}{\partial z_i} = \frac{e^{z_i} S - e^{z_i} e^{z_i}}{S^2} = p_i - p_i^2 = p_i(1 - p_i) \]
  2. A different index, \(j \ne i\). The top does not move, the bottom does: \[ \frac{\partial p_i}{\partial z_j} = \frac{0 \cdot S - e^{z_i} e^{z_j}}{S^2} = -p_i p_j \]
  3. Both cases at once, with the Kronecker delta \(\delta_{ij}\) (1 if \(i = j\), else 0): \[ \frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j), \qquad J_{\text{softmax}} = \operatorname{diag}(p) - p\,p^\top \] where \(p\,p^\top\) is the outer product: column times row, a square table whose entry \((i, j)\) is \(p_i p_j\).

The shape of every derivative

The derivative of an output with \(a\) entries with respect to an input with \(b\) entries holds \(a \times b\) numbers. That gives a small table, where \(W\) is a \(p \times q\) matrix:

derivative of ... with respect to ...scalar \(t\)vector \(x\) (\(n\))matrix \(W\) (\(p \times q\))
scalar \(L\)scalarvector, \(n\) (the gradient)matrix, \(p \times q\)
vector \(z\) (\(m\))vector, \(m\)matrix, \(m \times n\) (the Jacobian)3-index array, \(m \times p \times q\)
matrix \(Y\) (\(r \times s\))matrix, \(r \times s\)3-index array4-index array, \(r \times s \times p \times q\)

The bottom-right corner is where matrix calculus gets its reputation. The good news for ML: you never need it. The loss is a scalar, so the only derivatives that must be stored are in the top row, and each has the shape of its parameter. The big arrays appear only in the middle of the chain rule, and section 5 shows that they can always be skipped.

Why the big arrays are wasteful
The derivative of \(z = Wx\) (3 numbers) with respect to \(W\) (6 numbers) is a \(3 \times 3 \times 2\) array of 18 numbers: \(\partial z_i / \partial W_{kl} = \delta_{ik}\, x_l\) (score \(i\) depends only on row \(i\) of \(W\)). Twelve of the 18 are zero. For one real layer with a \(4096 \times 4096\) weight, the same array would have \(4096^3 \approx 6.9 \times 10^{10}\) entries, almost all zero.
