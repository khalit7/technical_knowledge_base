The real autograd graph of a transformer block

This is the graph PyTorch built, read back node by node: one pre-norm transformer block (layer norm, a 2-head causal self-attention written out as explicit matrix products and a softmax, a residual, layer norm, a GELU MLP, a residual), a final layer norm and a tied output layer, on the tokens [3, 1, 4, 1, 5] with width 8, MLP width 32 and a vocabulary of 16. The script walked loss.grad_fn through next_functions, read every _saved_ attribute, and recorded the order the engine ran the nodes during loss.backward() with a pre-hook on each node (src/inputs/measure/graph.py).

Click a node to see what it computes, what it saved and why.

    Nodes are listed in the order the engine executed them. Chips: activation saved is memory held for the backward pass; weight is a saved reference to a parameter, which costs nothing extra. Dimensions printed as -1 and -2 are stored by PyTorch as unsigned integers and converted here. Sizes in bytes (float32).
