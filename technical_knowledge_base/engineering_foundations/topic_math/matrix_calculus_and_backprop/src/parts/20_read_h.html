6. Differentials and the trace trick: derive any matrix gradient without indices

The question. Index-by-index derivations work, but get long for expressions like \(\operatorname{tr}(X^\top A X B)\) or \(\log\det\Sigma\). Is there a way to stay with whole matrices?

Yes: work with the differential \(dL\), the first-order change in \(L\) when every input changes by a small \(dX\). It obeys the familiar rules, applied to whole matrices (the order of factors must be kept, because matrix products do not commute):

ruledifferential
sum, constant\(d(A + B) = dA + dB\), \(\ d(cA) = c\,dA\), \(\ dC = 0\) for a constant
product\(d(AB) = (dA)\,B + A\,(dB)\)
transpose, trace\(d(A^\top) = (dA)^\top\), \(\ d\operatorname{tr}(A) = \operatorname{tr}(dA)\)
inverse\(d(X^{-1}) = -X^{-1}\,(dX)\,X^{-1}\) (differentiate \(XX^{-1} = I\))
log-determinant\(d\ln\det X = \operatorname{tr}(X^{-1}\,dX)\)
elementwise function\(d\,\phi(X) = \phi'(X) \odot dX\)

Three facts about the trace (the sum of the diagonal, \(\operatorname{tr}\)) do the rest: a scalar is its own trace; the trace is unchanged by cycling a product, \(\operatorname{tr}(ABC) = \operatorname{tr}(CAB) = \operatorname{tr}(BCA)\); and \(\operatorname{tr}(G^\top dX) = \sum_{ij} G_{ij}\,dX_{ij}\), the entry-by-entry dot product of two matrices of the same shape. The last one gives the identification rule:

\[ dL = \operatorname{tr}\!\big(G^\top dX\big) \text{ for every } dX \quad\Longrightarrow\quad \nabla_X L = G \]

Because \(\sum_{ij} G_{ij}\,dX_{ij}\) is exactly the linear prediction of section 1 with slopes \(G_{ij}\). The recipe: take the differential, use the cyclic rule to move \(dX\) to the far right inside a trace, and read off what stands in front of it, transposed. Minka's classic note states the recipe as "1. compute the differential 2. massage the result into canonical form after which the derivative is immediately read off as the coefficient of dx, dx, or dX" ({{Minka 2000, Old and New Matrix Algebra Useful for Statistics, p. 2|https://tminka.github.io/papers/matrix/minka-matrix.pdf}}, based on Magnus and Neudecker). His canonical form is \(dy = \operatorname{tr}(A\,dX)\) with the derivative laid out by \(X^\top\), so his \(A\) is the transpose of the gradient \(G\) here: the same rule in the other layout.

Four derivations with the recipe

A linear layer again. With \(y = Wx\) and \(\bar y\) the gradient at the output: \(dL = \bar y^\top dy = \bar y^\top (dW)\,x = \operatorname{tr}(\bar y^\top\, dW\, x) = \operatorname{tr}(x\,\bar y^\top\, dW)\), so \(G^\top = x\,\bar y^\top\) and \(\nabla_W L = \bar y\,x^\top\): section 5a in one line.

A quadratic form \(f = x^\top A x\): \(df = dx^\top A x + x^\top A\,dx = x^\top A^\top dx + x^\top A\,dx\) (a scalar equals its transpose), so \(\nabla_x f = (A + A^\top)\,x\), which is \(2Ax\) when \(A\) is symmetric. With \(A\) rows \((2, 1)\), \((0, 3)\) and \(x = (1, 2)\): \(f = 2x_1^2 + x_1x_2 + 3x_2^2\), and both routes give \((6, 13)\).

A log-determinant (it appears in every Gaussian log-likelihood and in normalising flows): \(d\ln\det X = \operatorname{tr}(X^{-1}dX)\), so \(\nabla_X \ln\det X = X^{-\top}\), the transpose of the inverse. With \(X\) rows \((2, 1)\), \((1, 3)\): \(\det X = 5\) and \(X^{-\top}\) has rows \((0.6, -0.2)\), \((-0.2, 0.4)\). Check one entry: raising \(X_{11}\) by \(h\) makes the determinant \(5 + 3h\), so \(\ln\det\) rises by about \(3h/5 = 0.6h\).

Least squares \(L = \lVert Xw - y \rVert^2 = (Xw - y)^\top (Xw - y)\), with \(X\) the data matrix (one row per example): \(dL = 2(Xw - y)^\top X\,dw\), so \(\nabla_w L = 2X^\top(Xw - y)\), and setting it to zero gives the normal equations \(X^\top X w = X^\top y\).

Carried from the old Linear algebra page (checked)
Fit \(\hat y = w_0 + w_1 t\) to the points \((t, y) = (0, 1), (1, 2), (2, 2)\). With a column of ones, \(X\) has rows \((1, 0), (1, 1), (1, 2)\); \(X^\top X\) has rows \((3, 3)\), \((3, 5)\) and \(X^\top y = (5, 6)\), so \(w = \tfrac{1}{6}(7, 3) = (1.167, 0.5)\). The residuals (targets minus predictions) are \((-0.167, 0.333, -0.167)\): they add up to 0 and are orthogonal to \(t\), which is what \(\nabla_w L = 0\) says. Why solvers prefer a QR factorisation to forming \(X^\top X\) (it squares the condition number, here 2.92 to 8.55) is on the sibling page {{Linear algebra for ML|n:3c65c17b0d0d81d89c26e1dab2fcb701}}.

The other identities the old page listed, all derivable the same way and each checked against PyTorch autograd in src/recompute.py (gradient layout: the result has the shape of the variable):

\(L\)\(dL\)gradient
\(a^\top x\)\(a^\top dx\)\(\nabla_x = a\)
\(x^\top A x\)\(x^\top(A + A^\top)dx\)\(\nabla_x = (A + A^\top)x\)
\(\operatorname{tr}(AX)\)\(\operatorname{tr}(A\,dX)\)\(\nabla_X = A^\top\)
\(\lVert X \rVert_F^2 = \operatorname{tr}(X^\top X)\)\(2\operatorname{tr}(X^\top dX)\)\(\nabla_X = 2X\)
\(\ln\det X\)\(\operatorname{tr}(X^{-1}dX)\)\(\nabla_X = X^{-\top}\)
\(\lVert Xw - y \rVert^2\)\(2(Xw - y)^\top X\,dw\)\(\nabla_w = 2X^\top(Xw - y)\)

\(\lVert X \rVert_F\) is the Frobenius norm, the square root of the sum of squared entries. In numerator layout each gradient would be written transposed.
