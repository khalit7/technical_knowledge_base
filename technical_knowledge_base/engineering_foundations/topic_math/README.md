# Topic: math

Notion: https://app.notion.com/p/3c65c17b0d0d81cdb851c0835b25a538

HTML-only page (`index.html`), built from `src/` by `src/build.sh`, which converts LaTeX to native MathML at build time (`html_utils/tex2mathml.mjs`). Rebuilt from the basics for a rusty reader (about 29 min): follow one prediction of a tiny next-token model through one training step, meeting vectors and matrices, probability, information, derivatives, optimisation and statistics as the step needs them; then the shared objects (cross-entropy four ways, curvature three ways) and how to read a paper's equation. Tabs: Reading, Notation decoder (14 landmark equations quoted exactly, every symbol decoded), Gradient lab, Practice drills (59 problems), Further reading. The old written page is kept verbatim in `src/live.md`, the old out-of-repo embed in `src/inputs/old_embed_topic-math.html`, and both are mapped in `src/coverage.md`.
