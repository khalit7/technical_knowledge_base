Linear algebra in one screen

About 45 minutes to read the main line (about 10,800 words and 900 formulas, slightly over the usual child length because every other maths page is written in this notation); the collapsible derivations add 3 more, and the mistakes and interview tables can be skimmed. Every section can be read alone. Every symbol is defined where it first appears. Worked numbers come from the root page's tiny model (input \(x = (2, 1)\), weight rows cat \((1, 0)\), dog \((0, 1)\), sat \((1, -2)\)) and from one running 2x2 matrix \(A\); real numbers come from GPT-2 small's released weights and two public LoRA adapters. All of them are recomputed by the script in this page's source folder.

A matrix is a map: it rotates, stretches along a few directions, squashes some directions to zero, and rotates again. Almost every linear-algebra question in ML is a question about that picture: which directions survive (rank), how much things stretch (norms, singular values), which directions are special (eigenvectors), how badly errors grow (conditioning), and how much is lost by keeping only the biggest stretches (low-rank approximation).

The one idea to keep
Ask of any matrix: which directions does it keep, how much does it stretch each, and how unequal are the stretches? The SVD answers all three, which is why it sits in the middle of this page.

Two tabs sit beside this one. The {{Matrix playground|#t-play}} lets you type any 2x2 or 3x3 matrix and see its action on the plane, eigenvectors, SVD, rank and condition number. The {{Low-rank lab|#t-lowrank}} truncates real GPT-2 weight matrices to any rank and shows the reconstruction error, the error on real inputs, the model's loss and the parameter count, next to the spectra of two real LoRA updates. Matrix calculus (Jacobians, layouts, gradients of matrix expressions, FLOP counts) lives on the sibling page {{Matrix calculus and backprop|n:3f05c17b0d0d817e9892e01088179c93}}.
