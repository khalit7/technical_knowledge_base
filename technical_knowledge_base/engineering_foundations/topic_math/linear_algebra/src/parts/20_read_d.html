5. Rank, null space and the four subspaces

A \(768 \times 768\) weight matrix has 589,824 numbers; the question is how many genuinely different directions it uses. The rank of a matrix is the number of independent columns, which always equals the number of independent rows, and is the dimension of the set of outputs the map can produce. An \(m \times n\) matrix has rank at most \(\min(m, n)\); a square matrix of full rank is invertible (its map can be undone, \(A^{-1}A = I\), with \(I\) the identity matrix). The null space is the set of inputs the map sends to zero.

For \(\begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix}\) (old page, checked) the second column is twice the first, so the rank is 1 and the map flattens the plane onto the line through \((1, 2)\); its determinant is \(1 \cdot 4 - 2 \cdot 2 = 0\), the same fact seen as area; and the input \((2, -1)\) is sent to \((0, 0)\), as is every multiple of it.

A rank-1 map keeps one input direction and destroys the other

\(\begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix}\). Left, the input plane: the null-space line along \((2, -1)\) and, at right angles to it, the row-space line along \((1, 2)\). Every input on a dashed line parallel to the null space lands on the same output. Right, the output plane: every output lies on the column-space line through \((1, 2)\); \(x = (2, 1)\) and \(x + (2, -1) = (4, 0)\) both land on \((4, 8)\).

The input dimensions are shared out exactly between those that reach the output and those squashed to zero, the rank-nullity theorem:

\[ \operatorname{rank}(A) + \dim \operatorname{null}(A) = n \]

(\(n\) the number of columns; for the rank-1 matrix, \(1 + 1 = 2\)). The tiny model's \(W\) has independent columns \((1, 0, 1)\) and \((0, 1, -2)\), so its rank is 2 and its null space is just \(\{0\}\): no input direction is lost. The gradient the root computes for it, \(\nabla_W L = g\,x^\top\) with \(g = (0.665, 0.245, -0.910)\), is an outer product, so it has rank 1: one training step on one example changes \(W\) along a single direction. That small fact is where LoRA starts (section 12).

Rank in floating point. In exact arithmetic rank is an integer you can read off. In floating point, rounding makes almost every matrix full rank, so the useful question is how many singular values (section 10) are large: the effective rank. Section 12 measures it on real GPT-2 weights.

The four fundamental subspaces

Which outputs can a layer never produce, whatever its input? Which inputs does it ignore? Every \(m \times n\) matrix \(A\) of rank \(r\) comes with four subspaces (lines, planes and their higher-dimensional versions through the origin) that answer these, and Gilbert Strang organises all of linear algebra around them:

SubspaceWhat it holdsLives inDimension
Column space \(C(A)\)every output \(Ax\) the map can produce\(\mathbb{R}^m\)\(r\)
Null space \(N(A)\)inputs sent to zero\(\mathbb{R}^n\)\(n - r\)
Row space \(C(A^\top)\)the span of the rows: the input directions the map "reads"\(\mathbb{R}^n\)\(r\)
Left null space \(N(A^\top)\)output directions the map can never reach\(\mathbb{R}^m\)\(m - r\)

The row space and the null space are orthogonal and together fill \(\mathbb{R}^n\); the column space and the left null space are orthogonal and together fill \(\mathbb{R}^m\). The reason is one line: \(x\) is in the null space when \(Ax = 0\), which says that \(x\) has dot product 0 with every row ({{Strang, The Fundamental Theorem of Linear Algebra, 1993|https://www.jstor.org/stable/2324660}}; MIT 18.06 lectures 9 and 10).

The tiny model can only ever produce scores on one plane inside 3-D

The tiny model's \(W\) (\(3 \times 2\), rank 2). Input side: the row space is the whole plane and the null space is only the origin. Output side: the column space is a plane in 3-D, and the left null space is the line along \((-1, 2, 1)\), at right angles to it.

Here the left null space is the line along \((-1, 2, 1)\), so every score vector this model can ever produce satisfies \(-z_{\text{cat}} + 2 z_{\text{dog}} + z_{\text{sat}} = 0\) (for \(z = (2, 1, 0)\), \(-2 + 2 + 0 = 0\)), whatever the input.

The softmax bottleneck: the same fact at scale. A language model computes its logits as \(z = E h\), with \(h\) the final hidden state (\(d\) numbers) and \(E\) the output matrix (\(V \times d\), one row per token), so the logits live in the column space of \(E\), of dimension at most \(d\). GPT-2 small has \(d = 768\) and \(V = 50{,}257\) and its output layer has no bias (it reuses the embedding table), so all its logit vectors lie in a 768-dimensional subspace of a 50,257-dimensional space. Yang, Dai, Salakhutdinov and Cohen called this the softmax bottleneck: stack the logits for many contexts into one matrix and its rank is at most \(d\); the log-probabilities differ from the logits by one constant per context, which changes the rank by at most 1; so if the true matrix of log-probabilities of language has rank above \(d + 1\), no setting of the weights can reproduce it (their Corollary 1, {{Yang et al., ICLR 2018, arXiv 1711.03953|https://arxiv.org/abs/1711.03953}}). Their fix, a mixture of softmaxes, breaks the linearity.

What it is used for in ML
Collapsed representations, where every embedding lies in a small subspace, show up as low effective rank. The column space says what a layer can output; the null space says what it ignores (an input change along it has no effect, and no gradient flows back along it); the left null space says what it can never produce.
From zero: span, independence, basis, finding a rank by elimination, and a proof of rank-nullity

A linear combination of vectors is a sum of scaled copies, \(c_1 v_1 + c_2 v_2 + \dots\); the span of a set is everything you can reach that way. The span of \((1, 0)\) and \((0, 1)\) is the whole plane; the span of \((1, 2)\) alone is a line through the origin; the span of \((1, 2)\) and \((2, 4)\) is still that same line, because \((2, 4) = 2\,(1, 2)\) adds nothing new. Vectors are linearly independent when none of them is a combination of the others; equivalently, the only way to combine them into the zero vector is with all coefficients 0. \((1, 2)\) and \((2, 4)\) are dependent: \(2\,(1, 2) - 1\,(2, 4) = (0, 0)\).

A basis of a space is a set of independent vectors that spans it; every basis of the same space has the same number of vectors, the dimension. Once a basis is fixed, every vector has unique coordinates in it. \(b_1 = (1, 1)\), \(b_2 = (1, -1)\) is a basis of the plane, and in it the tiny model's input is \(x = 1.5\, b_1 + 0.5\, b_2\) (check: \((1.5 + 0.5, 1.5 - 0.5) = (2, 1)\)). Same arrow, different numbers: "the coordinates of a vector" always means "in some basis", and the eigenvector and SVD sections choose bases that make a matrix simple.

Finding the rank by elimination. Subtract multiples of rows from other rows (this does not change the rank) until no more zeros can be made; the rank is the number of nonzero rows left. For \(M = \begin{pmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 1 & 0 & 1 \end{pmatrix}\): row 2 minus twice row 1 is all zeros; row 3 minus row 1 is \((0, -2, -2)\), not a multiple of row 1. Two nonzero rows remain, so the rank is 2. The input \((-1, -1, 1)\) satisfies \(1 \cdot (-1) + 2 \cdot (-1) + 3 \cdot 1 = 0\) and \(-1 + 0 + 1 = 0\), so \(M\) sends it to zero, and rank-nullity reads \(2 + 1 = 3\).

The tiny model's subspaces, checked. \(m = 3\), \(n = 2\), \(r = 2\): the null space has dimension \(2 - 2 = 0\), the left null space \(3 - 2 = 1\), spanned by \(n = (-1, 2, 1)\): \(n \cdot (1, 0, 1) = -1 + 0 + 1 = 0\) and \(n \cdot (0, 1, -2) = 0 + 2 - 2 = 0\). Training changes \(W\) and therefore the plane, but with 2 numbers per input the scores always live on some plane inside the 3-D space of scores.

Why rank-nullity holds. 1. Pick a basis \(u_1, \dots, u_k\) of the null space (\(k\) is the nullity). 2. Extend it with \(v_1, \dots, v_{n-k}\) to a basis of all of \(\mathbb{R}^n\). 3. Every output \(Ax\) is a combination of \(Av_1, \dots, Av_{n-k}\), because writing \(x\) in the basis, the \(u\) parts are sent to zero. 4. Those \(n - k\) outputs are independent: if \(\sum c_i A v_i = 0\) then \(\sum c_i v_i\) is in the null space, so it is a combination of the \(u\)'s, and since the whole basis is independent all \(c_i = 0\). So the output space has dimension exactly \(n - k\), which is the rank.
