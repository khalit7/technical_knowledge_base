# Linear algebra for ML: vectors to SVD, rank, conditioning, low-rank methods

Notion: https://app.notion.com/p/3c65c17b0d0d81d89c26e1dab2fcb701 (child of Topic: math)

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). Vectors (length, dot product, cosine, projection), matrices as maps and the determinant, matrix multiplication four ways (animated), shapes and broadcasting, independence, span, basis and rank-nullity, Strang's four fundamental subspaces and the softmax bottleneck, vector and matrix norms, orthogonality, projections and QR, least squares, eigenvalues, symmetric and positive definite matrices and Cholesky, the SVD (animated as rotate, stretch, rotate against the eigendecomposition), Eckart-Young and PCA, the condition number (with a float32 normal-equations run and Muon's orthogonalisation), low-rank structure measured on GPT-2 small and two real LoRA adapters (LoRA, MLA, GaLore), attention and embeddings as linear algebra, einsum. Tabs: Reading, Matrix playground (2x2 and 3x3), Low-rank lab (GPT-2 small layer 5 truncated to any rank: errors on real inputs and the model's loss; real LoRA spectra), Further reading. Rebuilds the old "Linear algebra for ML" page; its matrix-calculus facts moved to matrix_calculus_and_backprop. No child pages, databases or video.
