## The 2026-10-24 rebuild to the teaching contract: what changed and why
- **Top**: the core idea in one sentence; a new hero figure (one real slow request as a histogram count with its exemplar, a mini trace, and its log line, joined by one trace ID, with the burn-rate alert named); a one-line "You need"; eight new terms. The old "In one screen" table and "five ideas" list were recaps of the sections (fat), except their cost-per-signal column, which is now in the hero.
- **Sections renumbered 1 to 15** in the subject's order: why and the running example, logs, metrics, percentiles, PromQL, cardinality, RED and USE, traces, traceparent, sampling and exemplars, OpenTelemetry, profiling, one incident, dashboards, alerting.
- **New visuals inline**: averaged percentiles (real replica p99s; the ownership brief names "averaged percentiles lie", which had only a mistakes line), the OpenTelemetry path (a structure that had only a table), and a real Pyrra SLO dashboard photo beside the burn-rate formula.
- **Alert lab tab moved into Reading section 15**: it explains one mechanism (choosing an SLO alert rule), and the Reading tab described it in words; the precision and recall matrix and the generated PromQL went into a closed block. Tabs are now Reading, Real telemetry (a dataset used across the page) and Further reading.
- **No autoplay**: the template controller replaced the old one (which played on first scroll), and the incident animation no longer plays on a mode switch.
- **Closed depth**: versions and the three outages, native histogram history, the precision and recall matrix, alert fatigue, on-call numbers, tools and list prices with the chat product's sizing, the production checklist, and the four mistakes the sections do not already show.
- **Deleted as fat**: the glossary (every term is defined at first use), eight mistakes that restated sections, the "In one screen" recap, signposts and wind-ups.

## Departures from the child-page method
- The burn-rate lab differs from the sibling Reliability engineering's Error budget and alerts tab on purpose: that one spends budget with the final rules; this one compares the workbook's six rules.
- The averaged-percentile figure's pooled value is a bound, not a measurement: per-lookup retrieval times were not kept by the 2026-10-04 run. Rerunning `demo/run.sh` with lookups logged would give the exact value (about 4 minutes, not done here).
