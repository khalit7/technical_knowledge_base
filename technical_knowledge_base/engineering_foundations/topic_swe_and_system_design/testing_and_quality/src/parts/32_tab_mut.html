Mutation lab: which tests notice which bugs?

The retry policy from the Reading tab, its two real test suites, and all mutants mutmut generated for it on . Each mutant was run against every test (src/experiments/killmatrix.py), so this page knows exactly which tests kill which mutant. Tick tests on and off: line coverage saturates long before the mutation score does.

Try: start from "Weak suite" (100% coverage, killed), then add improved tests one at a time and watch which survivors die. Click a mutant to see its line and a test that kills it. Then try the challenge: the fewest tests that kill everything.

src/retrypolicy.py: green edge, a line some selected test runs; red, a line none runs; yellow, the selected mutant's line.

All mutants

Kind: crash mutants raise an error (any test that runs the line kills them); value mutants return a wrong value (only a test that checks the value kills them).
