Breaking or not? Fifteen changes to the chat API

For each proposed change, decide whether an existing, correctly written client could break. Assume clients follow the tolerant-reader rule (ignore unknown fields) unless the change says otherwise. The answers cite the rule they come from: Google's {{AIP-180|https://google.aip.dev/180}}, Anthropic's {{versioning policy|https://platform.claude.com/docs/en/api/versioning}}, Stripe's {{versioning post|https://stripe.com/blog/api-versioning}}, Zalando's {{guidelines|https://opensource.zalando.com/restful-api-guidelines/}}.
