Best resources, in the order to read them

{{FastAPI tutorial|https://fastapi.tiangolo.com/tutorial/}}

Build the demo's pieces yourself: path and query parameters, bodies, validation, errors, dependencies. About 3 h with typing along.

{{Pydantic documentation|https://docs.pydantic.dev/latest/}}

Models, fields, validators, settings; the contract layer of Python services. Carried from the old page. About 1 h 30 min for the core pages.

{{RFC 9110, sections 9 and 15|https://www.rfc-editor.org/rfc/rfc9110.html}}

Methods and status codes from the source; more readable than its reputation. About 1 h.

{{Stripe: Designing robust and predictable APIs with idempotency|https://stripe.com/blog/idempotency}}

Brandur Leach, 2017; the canonical case for keys. Carried from the old page. About 15 min.

{{Brandur Leach: Implementing Stripe-like idempotency keys in Postgres|https://brandur.org/idempotency-keys}}

The full server design: the table, atomic phases, recovery points, locks. About 40 min.

{{Stripe: APIs as infrastructure (versioning)|https://stripe.com/blog/api-versioning}}

Dated versions and transform modules. Carried from the old page. About 15 min.

{{Zalando RESTful API Guidelines|https://opensource.zalando.com/restful-api-guidelines/}}

The most complete public style guide; its error, pagination and compatibility rules are cited here. Carried from the old page. About 1 h 30 min for the whole guide.

{{Google API Improvement Proposals|https://google.aip.dev/general}}

Read AIP-121 (resources), 131 to 136 (standard and custom methods), 158 (pagination), 180 (compatibility). About 1 h.

{{RFC 9457, Problem Details|https://www.rfc-editor.org/rfc/rfc9457.html}}

Short, with examples. About 20 min.

{{OWASP API Security Top 10 (2023)|https://owasp.org/API-Security/editions/2023/en/0x11-t10/}}

The ten ways APIs get broken into, each with examples. About 45 min.

{{RFC 8725, JWT Best Current Practices|https://www.rfc-editor.org/rfc/rfc8725.html}} and {{RFC 9700, OAuth 2.0 Security BCP|https://www.rfc-editor.org/rfc/rfc9700.html}}

Read when you first verify tokens. About 30 min and 1 h.

{{Stripe: receive events in your webhook endpoint|https://docs.stripe.com/webhooks}} and {{Standard Webhooks|https://github.com/standard-webhooks/standard-webhooks/blob/main/spec/standard-webhooks.md}}

Signing, retries, duplicates and ordering from both sides. About 30 min together.

{{Use The Index, Luke: no offset|https://use-the-index-luke.com/no-offset}}

Markus Winand on keyset pagination. About 10 min.

{{Alexis King: Parse, don't validate|https://lexi-lambda.github.io/blog/2019/11/05/parse-don-t-validate/}}

Why validation should produce types. Examples in Haskell; the idea is language-free. About 25 min.
