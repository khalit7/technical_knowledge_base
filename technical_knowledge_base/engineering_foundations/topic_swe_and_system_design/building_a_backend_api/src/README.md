## The 2026-10-24 rebuild: what changed and why
The page used to teach the whole API surface from zero (HTTP, JSON, REST, errors, pagination, idempotency, auth, rate limits, webhooks, SSE, versioning, OpenAPI, gRPC). The protocol pages rebuilt on 2026-10-24 now own those: Service APIs (errors, pagination with this page's Postgres measurement, idempotency keys, rate limits, webhooks, versioning, OpenAPI, gRPC), HTTP, Auth, Streaming and real-time. This page became the owner of **the service behind the contract**, as the brief set out:
- **Top**: the core idea in one sentence (every request runs one pipeline inside one worker process; keep each stage bounded), a hero figure of that pipeline with what the handler borrows and the process's own life, "You need", new terms, and a closed one-line-per-subject table of what moved where (with the key fact and link for each).
- **New core sections, each with its visual inline**: the request lifecycle (stepper over a recorded request: real ASGI scope, measured middleware order), middleware against dependencies against handler (static onion from the recorded order; table), authorising the object in the query (kept, OWASP API1), the data layer (pool arithmetic from Running Postgres; a before/after slider for holding a connection across the model call, Little's law, reproducing Capacity planning's 11,570 by construction; N+1 before/after with four round-trip presets from Query planning and the root), async against threads against workers (measured: 50 requests x 500 ms in four styles; blocking in `async def` made every request wait 25.4 s, the 40-thread pool shows as a second wave, four workers split 20/14/9/7), configuration and secrets (measured pydantic-settings precedence, the missing-setting error, `SecretStr`), background work (measured inline 506.3 ms against BackgroundTasks 4.2 ms; table against a queue), health checks and graceful shutdown (recorded SIGTERM stepper: new connection refused, idle keep-alive closed, slow request finished, background job awaited, lifespan shutdown, exit at 3,426 ms; with a 1 s timeout both cancelled), and the LLM endpoint end to end (stepper over the real handler code with the production additions, plus the captured stream replay).
- **Kept from the old page**: validation (with the before/after of FastAPI's default against problem details), the framework timing, the transaction in the handler and the stuck-key correction, BOLA, disconnect detection, the production checklist (shortened to what other sections do not cover), mistakes that teach something new, JSON rules, corrections (closed).
- **Removed visuals**: the HTTP anatomy widget (HTTP owns the message), the pagination bars and drift animation (Service APIs owns pagination and carries the measurement), the idempotency animation, the JWT verifier and webhook verifier (Service APIs, Auth and Streaming own them), the dated-versions widget and the Breaking or not? quiz tab (Service APIs owns versioning; the contract also rules out quizzes). The Wire lab tab became a closed block inside section 2 (it is the demo's reference data, not a tool used across the page).
- **No autoplay**: `21_js_rd_common.js` and `99_js_tabs.js` are the skill templates; `check_page.mjs` confirms every stepper is still on step 0 after scrolling through the page with normal motion.
- **Title**: kept as in `pages.json`, which no longer describes the page; a new title is proposed in the report.
