# Building a backend API: request lifecycle, data layer, async and workers, shutdown

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). Rebuilt 2026-10-24 to the teaching contract as the owner of the service behind an API: the request lifecycle inside a FastAPI and uvicorn process (routing, middleware, dependencies, validation, handler), authorising the object in the query, the data layer (pools, transactions in handlers, N+1), async against threads against worker processes (measured), configuration and secrets, background work, health checks and graceful shutdown (recorded SIGTERM runs), and an LLM-backed endpoint end to end. The API-contract material it used to teach (errors, pagination, idempotency keys, rate limits, webhooks, versioning, OpenAPI, gRPC) now lives on Service APIs, with HTTP, Auth and Streaming and real-time owning their parts; a closed table at the top links each. Tabs: Reading (27 min, plus 8 in closed details), Further reading. The chat API's exchanges were captured on 2026-10-04 from `src/service/app.py`; the service experiments ran on 2026-10-24 (`src/service/run_experiments.py`). Replaces the API half of the old "API and Code Design" page; its code-design half moved to code_design (`src/handoff_code_design.md`). No child pages, databases or video.
