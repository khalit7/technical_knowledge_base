# Capacity planning and performance: source

`sh build.sh` writes `../index.html` from `parts/` (same build as the parent root: `{{text|url}}` links, `n:<id>` for Notion, `#t-<tab>` for tabs).

- Reading: `parts/20_read_a.html` to `20_read_g.html` (one screen; what performance means and the tail at scale; queueing; load balancing; caching; connection pools; profiling and the GIL; load testing; capacity planning; production table; mistakes; glossary). About 50 minutes (about 11,500 words): a child page owns the depth and the reader starts from zero.
- JS: `21_js_model.js` (every formula and simulation; twin of `model.py`), `22_js_rd_common.js` (animation controller copied from the root via Reliability engineering), `23_js_data.js` (generated by `gen_data.py`), `24_js_chart.js` (line and scatter chart), `25_js_rd_widgets.js` (Reading widgets and tables), `26_js_rd_anim.js` (the two before/after animations), `31_js_lab.js` (Load-test lab), `99_js_tabs.js`.
- Tabs: `31_tab_lab.html` (Load-test lab), `39_tab_more.html` (Further reading).
- Model and checks: `model.py`; `python3 recompute.py` writes `recompute_out.json` (every default, 110 cases); `node check_model.mjs` runs the page's JS on the same cases (1,525 numbers, max relative difference 1.2e-15); `node src/check_ui.mjs` from the repo root clicks every control at 390 dark and 920 light (248 actions, 0 problems).
- Measurements: `lab/server.py` (asyncio HTTP server on a Unix socket, timed-wait work, optional stalls), `lab/loadgen.py` (open and closed loops, four balancing policies), `lab/run_all.py` (all runs, about 19 minutes; run from a short scratch directory with Python 3.12), `lab/summarize.py` -> `inputs/measured.json`; `lab/gil.py` -> `inputs/gil_314.json`, `inputs/gil_314t.json` (CPython 3.14.8 and 3.14.8t from python-build-standalone 20261003). Raw per-request files stayed in scratch.
- Real data: `fetch_peaks.py` -> `inputs/wiki_hourly.json` (Wikimedia hourly page views, September 2026).
- `gen_data.py` writes `parts/23_js_data.js` from the inputs and `recompute_out.json`; rerun after either changes.
- `coverage.json`: what this new page owns from the root and the old children, and the corrections. `viz_ideas.md`: visuals built and rejected.
- Shape: Part B of the topic method (summary table first, mechanisms in order, production table, mistakes, glossary). Departure, as on Reliability engineering: measured sections with real local experiments, because the page's central claims (the hockey stick, coordinated omission, two choices) are cheap to test, and the simulation is checked against them.
