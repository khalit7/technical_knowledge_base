# Queues, streams and async work: source

`sh build.sh` writes `../index.html` from `parts/` (same build as the parent root: `{{text|url}}` links, `n:<id>` for Notion, `#t-<tab>` for tabs).

- Reading: `parts/20_read_a.html` to `20_read_i.html` (one screen, why async, queues and logs, Kafka, delivery semantics, measured, Kafka exactly-once, idempotent consumers, visibility timeouts, dead letters, backpressure and Little's law, dual write and outbox, sagas, events, Python job queues and durable workflows, cron, LLM async, production table, mistakes, glossary). About 50 minutes (about 11,600 words): a child page owns the depth and the reader starts from zero.
- JS: `21_js_rd_common.js` (helpers copied from the root), `22_js_qsim.js` (queue simulator), `23_js_rd_outbox.js` (dual write vs outbox animation), `24_js_rd_part.js` (Kafka murmur2 partitioner widget), `25_js_lab_data.js` (generated by `gen_lab_js.py`), `26_js_rd_saga.js`, `27_js_rd_meas.js` (measured charts and table), `31_js_lab.js` (Queue lab tab), `99_js_tabs.js`.
- Tabs: `31_tab_lab.html` (Queue lab), `39_tab_more.html` (Further reading).
- Measurement: `lab/pg_lab.py` (throughput with and without SKIP LOCKED; redelivery under crashes and short visibility timeouts; dual write vs outbox) and `lab/pg_lab_batch1.py` (outbox relay with one event per transaction), on PostgreSQL 16.2 from the `pgserver` wheel; run from the scratchpad with `uv run --no-project --python 3.12 --with pgserver --with "psycopg[binary]" python pg_lab.py OUT.json` (about 3 minutes). Results in `inputs/lab_measured.json`, `inputs/lab_outbox_batch1.json`.
- Checks: `python3 recompute.py` (writes `recompute_out.json`: murmur2 vectors, lab summaries, every formula on the page, the simulator in Python), `node check_sim.mjs` (the page's JS against Python, exact), `node src/check_ui.mjs` from the repo root (every control at 390 dark and 920 light).
- Research: `inputs/research_kafka.json`, `research_queues.json`, `research_patterns.json` (every quote verbatim with URL and fetch date, 2026-10-04); `coverage.json` maps the handed-off facts of the old "Distributed Systems Basics" page and the root's Step 3 to where they are now, with corrections.
- Shape: Part B of the topic method (summary table first, mechanisms in order, production table, mistakes). Departure: a "measured" section with real experiments, because the page's central claims (redelivery, duplicates, lost events in a dual write) are cheap to test locally.
