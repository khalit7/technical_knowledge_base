# Reliability engineering: source

`sh build.sh` writes `../index.html` from `parts/` (same build as the parent root: `{{text|url}}` links, `n:<id>` for Notion, `#t-<tab>` for tabs).

- Reading: `parts/20_read_a.html` to `20_read_f.html` (one screen, what reliable means, failure modes, timeouts, retries, the measured storm, idempotency, breakers, bulkheads, shedding, degradation, rate limiting, health checks, deploys, SLOs, incidents, postmortems, production table, mistakes, glossary). About 45 minutes (10,250 words): a child page owns the depth and the reader starts from zero.
- JS: `21_js_rd_common.js` (helpers copied from the root), `22_js_engine.js` (simulation engine), `23_js_meas_data.js` (generated by `gen_meas_js.py`), `24_js_rd_static.js` (tables), `25_js_rd_ba.js` (before/after animation), `26_js_rd_rl.js` (rate limiters), `27_js_rd_meas.js` (measured chart), `31_js_lab.js`, `32_js_slo.js`, `99_js_tabs.js`.
- Tabs: `31_tab_lab.html` (Resilience lab), `32_tab_slo.html` (Error budget and alerts), `39_tab_more.html` (Further reading).
- Measurement: `lab/server.py`, `lab/loadgen.py` (stdlib only), `lab/run_all.sh` (6 configurations x 3 seeds, about 14 minutes; run from a short directory because of the Unix socket path limit), `lab/summarize.py` -> `inputs/lab_measured.json`. Raw per-attempt logs stayed in scratch; `inputs/baseline_attempts.txt` is the 30 s no-slowdown run that gave the timeout percentiles.
- Checks: `python3 recompute.py` (writes `recompute_out.json`), `node check_engine.mjs` (page JS against Python, exact), `node src/check_ui.mjs` from the repo root (every control at 390 dark and 920 light).
- Research: `inputs/research_*.json`, every quote verbatim with URL and fetch date (2026-10-04); `coverage.json` lists what this new page owns from the root and siblings, and the corrections.
- Shape: Part B of the topic method (summary table first, mechanisms in order, production table, mistakes). Departure: a "measured" section with a real experiment, because the page's central claim (what stops a retry storm) is cheap to test locally.
