- Reading: `parts/20_read_a.html` (styles, nav, the idea in one screen, sections 1 and 2) to `20_read_f.html` (sections 14 and 15, closed depth: starting configuration, glossary), `20_read_z.html`. Rebuilt 2026-10-24, see below.
- JS: `21_js_rd_common.js` (the explainer-page skill template: never autoplays), `23b_js_lat_data.js` (generated by `gen_lat_js.py`), `28_js_rd_figs.js` (static figures, jitter before/after, goodput curve, predict blocks), `29_js_rd_slo.js` (error budget card, formerly the tab), `22_js_engine.js` (simulation engine), `23_js_meas_data.js` (generated by `gen_meas_js.py`), `24_js_rd_static.js` (tables), `25_js_rd_ba.js` (before/after animation), `26_js_rd_rl.js` (rate limiters), `27_js_rd_meas.js` (measured chart), `31_js_lab.js`, `99_js_tabs.js` (template, key `rel-tab`).
- Tabs: `31_tab_lab.html` (Resilience lab), `39_tab_more.html` (Further reading). The Error budget tab moved into Reading section 12.
- Measurement: `lab/server.py`, `lab/loadgen.py` (stdlib only), `lab/run_all.sh` (6 configurations x 3 seeds, about 14 minutes; run from a short directory because of the Unix socket path limit), `lab/summarize.py` -> `inputs/lab_measured.json`. Raw per-attempt logs stayed in scratch; `inputs/baseline_attempts.txt` is the 30 s no-slowdown run that gave the timeout percentiles.
- Checks: `python3 recompute.py` (writes `recompute_out.json`, now also the jitter and goodput figures), `node check_engine.mjs` (page JS against Python, exact: 20,782 numbers, 0 differences), `node src/check_ui.mjs <dir>` from the repo root (every control at 390 dark and 920 light, plus a check that the before/after animation does not move by itself), `node src/shot_figs.mjs <dir>` (each Reading figure, both themes), `python3 html_utils/ledger.py check <page>`.
- Research: `inputs/research_*.json`, every quote verbatim with URL and fetch date (2026-10-04); `coverage.json` lists what this new page owns from the root and siblings, and the corrections.
- Shape: Part B of the topic method (summary table first, mechanisms in order, production table, mistakes). Departure: a "measured" section with a real experiment, because the page's central claim (what stops a retry storm) is cheap to test locally.

## The 2026-10-24 rebuild to the teaching contract
**What changed and why.**
- **Top**: the core idea in one sentence, a hero diagram (where each defence acts on one chat request), "You need" with the owners of neighbouring concepts, and new terms. The old "In one screen" table and "three ideas" box are carried by the hero, the core sentence and the "work added against work removed" paragraph.
- **A visual beside every core idea** (12 new, all drawn at the measured width): dependency chain, metastable loop, measured latency histogram (real data), deadline propagation, retry amplification, jitter before/after (seeded, checked), breaker state machine, goodput against offered load (the verified engine at 13 loads), probe failure to action, rollout waves, streaming timeouts. The Error budget tab moved inline into section 12 (it explains one mechanism); the Resilience lab stays a tab because it is a tool used across sections 3 to 8.
- **New sections the page owns per OWNERS.md and the brief**: 14, LLM calls (529 and 503 overload codes, SDK retries twice by default, errors after a 200 on a stream, first-token and idle timeouts, retries cost quota; sources fetched 2026-10-24) and 15, chaos testing at the level of when it pays (Principles of Chaos Engineering, Chaos Monkey's weekday 9 to 15 default). Blast radius is defined at the top and used in bulkheads and deploys.
- **Depth into closed blocks**: library defaults and code, retry budgets by library, hedging's numbers, the experiment's limits, breaker defaults and Hystrix's history, adaptive limits, Stripe's four limiters, incident roles, severity levels, the starting configuration, the glossary, the 2026-10-04 status-page reading.
- **Links instead of re-teaching**: idempotency keys (Building a backend API; Distributed systems fundamentals section 9), alert rules (Observability's Alert lab), API-surface rate limits (Service APIs), gateway fallbacks (Gateways and routing), serving SLOs (LLM serving in production), testing (Testing and quality).
- **No autoplay**: template `21_js_rd_common.js`; the before/after animation no longer starts on a mode switch; `check_ui.mjs` checks it stays on step 0.
- **Deleted as fat**: the common-mistakes list (every item restated a core section), meta notes, wind-ups, the old tab bar.
- **Images**: none. The page teaches mechanisms; the SRE book's figures are CC BY-NC-ND, outside the allowed licences.

What made the old page long (library tables, code, defaults, history, a mistakes list restating the core) is closed or deleted; about a fifth of the core words are figure captions.
