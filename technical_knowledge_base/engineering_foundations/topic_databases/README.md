# Topic: databases

Notion: https://app.notion.com/p/3cd5c17b0d0d815d8841ec845f5f3324

HTML-only page (`index.html`), built from `src/` by `src/build.sh`. Taught from zero (about 27 min): follow one chat product's data from a file to a fleet: the relational model and SQL, transactions and isolation, inside the engine (pages, B-tree, WAL, planner), rows vs columns, the other database families as escape hatches from the Postgres default, choosing and the one-way doors, and the ML/LLM angle. Tabs: Reading, SQL playground (real SQLite in the page via sql.js WASM, every lesson also run on Postgres 16), Query plans (real EXPLAIN ANALYZE on 10M messages), Database atlas (59 systems, sourced), Further reading. The old written page is kept verbatim in `src/live.md` and mapped in `src/coverage.md`.
