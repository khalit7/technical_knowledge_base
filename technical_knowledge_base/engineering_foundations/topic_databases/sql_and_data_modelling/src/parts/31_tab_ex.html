Exercises lab: 28 graded exercises on the chat data

Write the query, press Check, and the page's own database grades it: it runs your query and the reference solution on fresh copies of the same data and compares the results.

The data is the Reading tab's: users(id, email, name, plan, country, created_at), chats(id, user_id, title, model, created_at), messages(id, chat_id, parent_id, role, content, tokens, created_at), credits(user_id, balance). Timestamps are text like '2026-03-15 10:00:00' (SQLite has no date type). Grading rules: the last statement that returns rows is compared; column names do not matter but the number and order of columns do; rows must match exactly (numbers to 6 decimal places), in order only where the exercise says "in order", "by id" or similar. Levels: 1 warm-up 2 core 3 harder 4 pro. Your progress is kept in this browser only.
