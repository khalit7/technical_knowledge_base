# Search and vector databases: inverted indexes, BM25, ANN, pgvector

Notion: https://app.notion.com/p/3ef5c17b0d0d815eb4caef9b4cd4d732 (child of Topic: databases)

Tabs: Reading, ANN lab, Retrievers side by side, Further reading.
