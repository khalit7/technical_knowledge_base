# Storage engines and indexes: pages, B-trees, LSM-trees, the WAL, index types

Notion: https://app.notion.com/p/3cd5c17b0d0d8102bc1fd11b22606e1a (child of Topic: databases)

Interactive page: `index.html`, built from `src/` (`sh src/build.sh`; see `src/README.md`). How a table sits on disk (8 KB pages, tuples and their header, TOAST, free space and visibility maps), the buffer pool (clock sweep, ring buffers, double buffering), the write-ahead log (records, LSNs, checkpoints, full-page images, fsync, group commit, synchronous_commit) and a real crash recovery; B-trees (structure, fan-out maths, splits, fill factor, deduplication, skip scan in 18, UUID v4 against v7); LSM-trees (memtable, SSTables, leveled and tiered compaction, bloom filters, tombstones); the RUM trade-off with write, read and space amplification measured on PostgreSQL and RocksDB; heap against clustered tables; Postgres index types and shapes; the measured cost of indexes on writes; column stores in one section. Tabs: Reading, B-tree and LSM lab, Inside real pages (pageinspect output), Further reading. Rebuilds the old page "Storage engines, indexes, and the physics of a query": its planner section goes to Query planning and performance (`src/handoff_planner.md`), its ANN section to Search and vector databases (`src/handoff_vector.md`); no child pages, databases or video.
