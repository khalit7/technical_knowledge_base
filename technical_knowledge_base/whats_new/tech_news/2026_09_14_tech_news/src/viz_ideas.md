## Inspiration
The two animations follow the DeepSeek MLA explainer: the same input (one agent turn, eight tokens), the old method first, drawn to scale (43 against 40 rows; the 128-token replay sliver at its true width), a caption per step, running counters, play/pause/step/scrub/speed, visible-tab-only, paused under reduced motion. The two architectures are deliberately paired across tabs: DeepSeek's encoder-decoder removes decoder work from the prompt, RLT adds sequential decoder work to gain depth. The three-readings card applies the Methodology rule that a leaderboard re-run in place is several dated readings shown side by side.

## What the methodology lacked for this issue
- A rule for **sources that were rewritten after publication without a note** (Real-SWE twice, DeepSeek's changelog within three days, the RLT page within a week): check the issue against the Wayback capture nearest its date, show every later reading as data, and record each change as a dated follow-up.
- A rule for **items with no source link**: search for the primary announcement, link only article-level addresses, and say so where only a site was found; a home-page link in the issue (Scientific American, The Intercept, WIRED) is flagged as such.
- A rule for **"nothing new" claims about release feeds**: check the release APIs directly; the claim is falsifiable and was false here.
