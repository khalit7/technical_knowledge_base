One token at a time against a block of 256 at once

The same 256-token block decoded three ways, drawn as a bar field: each lane is the block laid out 16 by 16 on the floor, and each token's bar rises to the forward pass in which that token became final, so the height of a lane is the number of passes it needed. Autoregressive decoding (orange) writes one token per pass. Speculative decoding (blue: a drafter proposes about 8 tokens, the model verifies them) keeps 3 to 6 per pass, per the report. DiffusionGemma (green) starts from a block of random tokens and refines all 256 in parallel, settling the most certain first and still able to revise them, for about 12 passes on average (at most 48). The dots stream from each lane's model plate while it is still decoding, more dots for more tokens per pass. Drag to turn the scene.

Step by step

  1. The same block, three ways. Three blocks of 256 token positions side by side. The diffusion block starts as 256 random tokens (grey tiles); the other two start empty. Nothing is decoded yet.
  2. Passes 1 to 12: DiffusionGemma refines the whole block. Every pass works on all 256 positions at once and the most certain tokens settle first. Pale bars hold a provisional token that a later pass revises (uniform diffusion lets earlier choices change within the block). Adaptive stopping ends the block once the canvas stops changing, at pass 12 (the report's average). In the same 12 passes autoregressive decoding wrote 12 tokens and speculative decoding about 54.
  3. Passes 13 to 57: speculative decoding finishes. At 4.5 tokens kept per pass (the default; the report gives 3 to 6), the block needs 57 passes. Its bars rise in steps of about 4.5 tokens: each pass adds a short run.
  4. Passes 58 to 256: autoregressive decoding finishes. One token per pass, so the last token is written at pass 256 and that lane rises to the full height. For the same block: 256 against 57 against 12 passes.
  5. The clock in milliseconds. The heights become decode time at the measured speeds on one H100 (FP8, batch size 1). A diffusion pass takes about 14.4 ms (derived: 256 / 1,479 tokens per second / 12 passes) and a speculative pass about 14.9 ms (derived: 4.5 tokens per pass at 303 tokens per second), so passes cost about the same here: the block is done in 173 ms against 845 ms, 4.9 times faster, which is the report's 1,479 against 303 tokens per second. Plain autoregressive decoding has no measured speed in the report, so its lane fades out.

Moving a slider stops the animation and redraws the scene and the numbers in the steps. Other numbers of diffusion passes assume a pass costs the same whatever the number of passes; the report measured the average.

From the {{DiffusionGemma report|https://arxiv.org/abs/2608.00146}}: canvas of 256 tokens, at most 48 denoising steps, about 12 on average with adaptive stopping (Table 2); speculative decoding with a draft of 8 gives 3 to 6 tokens per forward pass; measured on one H100 (FP8, batch size 1), 1,479 tokens per second for DiffusionGemma against 303 for Gemma 4 with multi-token prediction. Illustrative: which cells settle on which pass, which cells are revised, the per-pass acceptance of the drafter (its mean is the slider), and the 4.5 default. Derived: milliseconds per pass = 256 / measured tokens per second / passes for the block (decode only, prefill ignored); the plain autoregressive lane has no measured speed in the report, so it has no time clock.
