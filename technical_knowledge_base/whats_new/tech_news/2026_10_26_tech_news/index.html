Tech news, 19 to 26 October 2026

One week, to Monday 26 October6 storiesReading: 5 min

A week about trust in the layers below the model. A signed LiteLLM release carried a credential stealer, a certificate authority's keys turned out to be computable from its certificates, and two public red-teams found that the monitors watching coding agents miss more than half of determined attacks. At the same time two private pieces of infrastructure opened up: DeepSeek published the engine behind its service, and PyTorch went native on TPU and Trainium. Kimi K3.1 Pro came within three points of the top of the independent index, with three Terminal-Bench scores from three harnesses, and Claude's first new API version since 2023 drops the sampling knobs.

Top stories

1Model23 October

Moonshot's Kimi K3.1 Pro reached fourth on Artificial Analysis's index, three points from the top, with open weights promised.

It is a post-trained Kimi K3 at 2.8T total / 104B active parameters (Artificial Analysis's count), $2 / $10 per million tokens, scoring 55 on Intelligence Index v4.3.2 against Claude Opus 5.5's 58. Its Terminal-Bench 4.0 score depends on the harness: 67% in Artificial Analysis's run, 63.64% on Vals AI's mini-swe-agent harness ($4.57 a test against Opus 5.5's $13.20), 65.7% in Moonshot's own run inside Claude Code. Follow-up, 2 November: on the rebuilt Index v5 it scores 46 (ninth), and no weights or licence had appeared.

Why it matters: a near-frontier model at about a third of the cost per test is worth trying, but only scores from the same harness can be compared.

2Security21 October

A signed LiteLLM release shipped a credential stealer, and a certificate authority's private keys could be computed from its certificates.

LiteLLM 1.107.0 on PyPI (21 October, 11:39 to 13:23 UTC) and four Docker tags took SSH keys, cloud and CI secrets and the proxy's provider keys; the attacker reached the release workflow from an Agent Platform master key committed publicly in May and never revoked, so the trusted-publishing pipeline built and signed the malware itself (1.106.2 is clean). The same week eMudhra disclosed that the keys of 8 intermediate CAs were recoverable; browsers distrusted them and eMudhra is leaving the TLS business.

Why it matters: an LLM gateway holds every provider key you have, and signing proves which pipeline built an artefact, not who controlled it: pin versions and expire long-lived tokens.

3Security22 October

Two public red-teams of the monitors that watch coding agents found the same blind spots.

Anthropic set an Opus 5 attacker against Claude Code's Auto Mode and an approximation of Codex's Guardian: production monitors failed to block more than 55% of attacks, through text aimed at the monitor, sessions coordinating through a shared workspace, compaction hiding earlier steps, and actions the monitor never saw. METR and Redwood found OpenAI's internal monitoring fired only when an agent returned control, missed compaction events (about 10% of Codex traffic) and could be switched off by two client headers.

Why it matters: per-action blocking guards against an over-eager agent, not a persistent adversarial one; monitoring has to run on a clock, see compaction and sit out of the agent's reach.

4Tools21 October

Claude API version 2026-10-21, the first since 2023-06-01, rejects temperature, top_p and top_k.

Under the new version these return a 400 error even at their default values, and document blocks in assistant messages and citations in user messages are rejected; the old version is not deprecated. New SDK majors (Python 2.0.0, TypeScript 1.0.0, Go 2.0.0 and the rest) send the new version by default, send the key as Authorization: Bearer instead of X-Api-Key, and move from MIT to Apache 2.0.

Why it matters: upgrading the SDK changes the API version under you, so code that sets sampling parameters breaks and gateways that read X-Api-Key need a change.

5Tools20 October

DeepSeek open-sourced the inference engine behind its production service, without the parts that make it a service.

DeepInfer (Apache 2.0) serves only DeepSeek-V4.1-Flash, on NVIDIA SM100 and Huawei Ascend 950, with attention data and context parallelism, MoE expert parallelism with EPLB, DeepSeek's own kernels, "DSpark" speculative decoding and batch-invariant, deterministic inference on NVIDIA. Left out: the KV cache system, prefill/decode disaggregation and cross-replica load balancing; the README shows Pareto charts but no numbers. At 2,351 points it was the window's largest Hacker News thread.

Why it matters: it is a frontier lab's production serving layout in readable code, and what it withholds shows which parts of serving are hardest.

DeepInfer repository (15 min) · Our page: Inference and serving
6Chips20 October

PyTorch became native on Google TPUs and AWS Trainium on the same day.

Google (with Meta) open-sourced TorchTPU and AWS put TorchNeuron into public beta, both Apache 2.0, both registering as PyTorch devices with eager modes and a torch.compile path that lowers to StableHLO. Google's own numbers: 98% of 4,917 popular Hugging Face models run, Qwen3 MoE 235B on 64 TPU v7 chips at 1,828 tokens per second against 1,937 for JAX/MaxText, and 27.1% MFU in the 8,192-chip weak-scaling row. Meta says SGLang on TorchTPU runs in its production.

Why it matters: TPU and Trainium capacity no longer means porting to JAX or living with PyTorch/XLA, which widens where you can train and serve.

New in the knowledge base

Papers

  • GRAFT: routing the gradients of monitor-flagged RL samples into an adapter that is deleted after training, instead of penalising them, kept Qwen3-8B from learning the undetected hack a penalty taught (1.6% hacking after deletion against 26%), at a slightly lower solve rate; keyword-style monitors, models up to 8B.
  • Understanding the Benefits of Scaffolds through Computational Separations: same-size students trained on a multi-call harness's traces trailed it by 5 to 16 points on trees of 13 to 40 calls (single runs) and a 4B student matched its teacher; a theorem shows a breadth-first-search harness decides what no fixed-depth transformer with a short chain of thought can, if NL is not in TC0.
