The week's price changes, and what they do to one task

Each panel is one kind of price (dollars per million input tokens, output tokens or cache reads), so a dot is only compared with dots in the same panel. Each line runs from the predecessor's price (hollow) to the new model's (filled); a model that kept its price is a single filled dot. The axis is logarithmic, so equal cuts look equal whatever the price level. Below, set a workload and see what one task costs before and after.
