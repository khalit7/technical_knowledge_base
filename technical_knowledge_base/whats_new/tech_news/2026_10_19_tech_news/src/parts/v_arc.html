Same model, same tasks, two harnesses: ARC-AGI-3 before and after the Provider Adapter

Source: {{ARC Prize results|https://arcprize.org/results}} and the {{Gemini 4 Argon scorecard|https://arcprize.org/results/google-gemini-4-argon}}, read 2026-10-19 (verified, semi-private set). GPT-6 Astra 62.7% standard and 99.95% adapter; GPT-6.1 Sol 52.7% and 96.2% at max effort (the results table's headline for Sol is 96.37%); Gemini 4 Argon 49.8% and 97.5% at low effort, where the standard run completed 42 of 55 tasks because of API errors (incomplete tasks score what they reached); Claude Opus 5 30.16% standard, no adapter entry. Claude Opus 5.5 has no entry yet.

ARC-AGI-3 is a set of interactive game-like environments; a run is scored over all 55 semi-private tasks with partial credit. ARC Prize now verifies each model twice. The standard harness is provider-agnostic: between requests the model carries forward only the notes it chooses to keep. The Provider Adapter uses the lab's own API features: it preserves the model's opaque reasoning state between requests and compacts context. The chart plays the standard harness by itself once in view, one model per step; then switch to the adapter (the buttons above the chart): the models and the tasks stay the same, and only the harness changes.

Step by step

  1. GPT-6 Astra: 62.7%. Under the standard harness the model keeps only the notes it writes for itself between requests. GPT-6 Astra reaches 62.7%, still the best standard score on the board.
  2. GPT-6.1 Sol: 52.7%. GPT-6.1 Sol, a cheaper model, reaches 52.7% at max effort.
  3. Gemini 4 Argon: 49.8%. Gemini 4 Argon reaches 49.8% at low effort, the best non-OpenAI standard score. API errors stopped 13 of the 55 tasks early; they count with whatever partial credit they reached.
  4. Claude Opus 5: 30.16%. Every standard score sits between 30% and 63%: on this harness the benchmark is far from solved. Switch to the Provider Adapter.
  1. GPT-6 Astra: 99.95%. The same model with the Provider Adapter, which keeps its hidden reasoning state from one request to the next and compacts context: 99.95%, up 37 points. The standard score stays drawn in grey.
  2. GPT-6.1 Sol: 96.2%. Up 43.5 points from the same tasks.
  3. Gemini 4 Argon: 97.5%. Up 47.7 points. The pattern now holds for two labs and three models, so it is a property of the harness, not of one model.
  4. Claude Opus 5: no adapter entry. Claude Opus 5 has no adapter entry, and Opus 5.5 none at all, so the gap cannot be read for Anthropic yet. A bare ARC-AGI-3 score without its harness is not a comparable number.
