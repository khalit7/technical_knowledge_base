Why Do Multi-Agent LLM Systems Fail?

Cemri et al., 2025: The fourteen-mode failure taxonomy the paper borrows "reasoning-action mismatch" from; built from bounded task runs, which is the gap this paper fills.

(35 min)

Multi-Agent Risks from Advanced AI

Hammond et al., Cooperative AI Foundation, 2025: Miscoordination, conflict and collusion as the three multi-agent failure modes; the paper offers its runs as evidence for several of these categories.

(1h)

Agentic Misalignment: How LLMs Could Be Insider Threats

Lynch et al., Anthropic, 2025: The single-agent forced-choice study the misinformation and memory-breach sections contrast with: there, a threatened model coerced; here, no world did.

Connected papers in this knowledge base

Agora: Git as Shared Memory for Collective AutoResearch

Same week, opposite question: a leaderless multi-agent research system producing a real result through an append-only shared graph. Emergence World asks what happens to that class of system when some shared content is hostile.

MOLE: Detecting Insider Threats in AI Agents

A model's stated refusal did not predict whether it declined, and monitors missed close to half of completed harm. MOLE says the monitor is weak; Emergence World says even a monitor that fires does not stop the behaviour.

Demystifying Agent Skills: Why They Work - Until They Don't

Reusable skills help until they do not; here agents' saved routines and created tools show the same gap between authoring a capability and using it.

HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

Agents building their own tooling, measured on tasks; Emergence World's agents did it through governance votes, and one world used that path to escalate privileges.

Constitutional AI: Harmlessness from AI Feedback

Model-level alignment, the layer this paper argues is not enough once agents interact for weeks.

ReAct: Synergizing Reasoning and Acting in Language Models

The reason-then-act loop every agent here runs; the phishing results are cases where the reasoning said no and the action said yes.

Anthropic: Claude family

The model behind the Claude world's outreach and vow of silence, and the summariser that read its agents as suicidal.

xAI / SpaceXAI: Grok

Grok 4.3's world collapsed in four days under a retaliation spiral; two Grok agents in the Mixed world survived.

Topics

Topic: agentic-frameworks

A persistent multi-agent world is a framework run for weeks; the failure modes here are its design inputs.

Topic: agentic-harnesses

Where the paper puts the fix: controls at the action boundary, memory provenance, access that does not depend on an agent's judgement.

Topic: benchmarks

An evaluation that runs a society instead of scoring a task that finishes.

Topic: evaluation-and-llm-judges

Opacity, goal drift and expressed values are all scored by LLM judges here; the scorecards are human binary judgements.
