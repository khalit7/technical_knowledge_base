Verifier rows give a configuration trained on the strict verifier, which requires a boxed answer, minus the same configuration and seed trained on the default verifier, which falls back to the last number; both are evaluated with the default verifier, and “NI” marks a one-sided non-inferiority test at $-0.02$ .
