ReAct: Synergizing Reasoning and Acting in Language Models (arXiv HTML v3)

ICLR 2023, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(45 min)

ysymyth/ReAct

the authors' GPT-3 prompting code (MIT licence): one notebook per task, the Wikipedia environment (wikienv.py) and every prompt. PaLM, the model behind the main results, was never released, so the repository reruns the method on text-davinci-002, which OpenAI shut down on 4 January 2024 (its deprecations page), so the notebooks need a current model swapped in. The project page, react-lm.github.io, links it. About 20 minutes for the README and the HotpotQA notebook.

(20 min)

A simple Python implementation of the ReAct pattern for LLMs

Simon Willison, TIL, March 2023: the whole agent loop from scratch in about 40 lines; the fastest way to see that ReAct is just a parse, act, append loop around a prompt.

(10 min)

LLM Powered Autonomous Agents

Lilian Weng, June 2023: places ReAct within the 2023 agent design space (planning, memory, tool use) alongside Reflexion and friends.

(45 min)

ICLR 2023 reviews and discussion

OpenReview: the reviewers' questions and the authors' replies; useful beside this page's evidence section.

(20 min)

Building effective agents

Anthropic, December 2024: what the loop became: "LLMs using tools based on environmental feedback in a loop", and when a fixed workflow is the better choice.

(20 min)

Connected papers in this knowledge base

Language Models are Few-Shot Learners (GPT-3)

2020-05: the few-shot in-context learning paradigm that ReAct pushes to interactive tasks; ReAct's released code runs on a GPT-3 model.

Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks (RAG)

2020-05: fixed retrieve-then-generate; ReAct is the model-directed, iterative alternative that agentic RAG descends from.

Training language models to follow instructions with human feedback (InstructGPT)

2022-03: the RLHF machinery that later trained tool use into models natively, replacing ReAct-style prompting.

DeepSeek-R1

2025-01: reasoning tokens trained by reinforcement learning; interleaved thinking and tool calls are the trained descendant of ReAct's thought channel.
