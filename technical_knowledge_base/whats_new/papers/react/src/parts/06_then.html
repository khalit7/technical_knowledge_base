Same step, six formats. The wire formats follow each provider's documented shape; field values are this episode's, so the messages are illustrative.

Then and now

The loop survived; almost everything around it was replaced. On the right, one step of the paper's own Apple Remote episode (Thought 2, Act 2, Obs 2 of {{Figure 1|ax:S1.F1}}) is written the way each generation of agent stack would carry it, from the 2022 prompt to a 2025 reasoning model thinking between tool calls. Step through it: what changes is who writes the thought, how the action reaches the tool, who parses it, and how the behaviour was learned.

  1. October 2022: the ReAct paper (PaLM-540B, few-shot text). The model continues a prompt of six hand-written trajectories. The harness stops generation at "Observation 2:", splits the text at "Action 2:", runs the action and appends the result as plain text. Everything the model knows about the format came from the exemplars ({{released code|https://github.com/ysymyth/ReAct/blob/master/hotpotqa.ipynb}}).
  2. November 2022: LangChain's zero-shot ReAct agent. The exemplars are replaced by an instruction that lists the tools and the format ("Use the following format: Question / Thought / Action / Action Input / Observation"). Still free text, still parsed, now for any tool a developer registers ({{mrkl/prompt.py|https://github.com/langchain-ai/langchain/blob/v0.0.100/langchain/agents/mrkl/prompt.py}}).
  3. June 2023: function calling. The action leaves the text. The model, trained for it, returns a JSON object naming a function and its arguments; the result goes back as a message of its own. The parsing layer and its failures disappear; the free-text thought becomes optional and is often skipped ({{OpenAI, 13 June 2023|https://web.archive.org/web/20230614000000/https://openai.com/blog/function-calling-and-other-api-updates}}).
  4. 2024: tool-use content blocks. One assistant message can hold a text block (the thought, visible to the next step) followed by a tool_use block; the harness answers with a tool_result. This is ReAct's thought, action, observation as typed blocks ({{Claude tool use, generally available 30 May 2024|https://www.anthropic.com/news/tool-use-ga}}; {{docs|https://docs.anthropic.com/en/docs/agents-and-tools/tool-use/overview}}).
  5. 2025: reasoning models think between tool calls. The thought channel is now reasoning tokens trained by reinforcement learning, and the model emits them between tool calls inside one turn: Claude 4's "extended thinking with tool use" ({{May 2025|https://www.anthropic.com/news/claude-4}}), interleaved thinking ({{docs|https://docs.anthropic.com/en/docs/build-with-claude/extended-thinking}}), and o3 using tools agentically ({{April 2025|https://web.archive.org/web/20250417000000/https://openai.com/index/introducing-o3-and-o4-mini/}}). ReAct's dense thoughts, learned end to end rather than imitated.
  6. 2025 to 2026: the harness loop. The loop the paper wrote in a notebook is now the core of products and SDKs: call the model, run any tool calls, append the results, repeat until it stops calling tools (the finish action). What harnesses add on top is context management, permissions, subagents and memory ({{OpenAI Agents SDK|https://openai.github.io/openai-agents-python/running_agents/}}; {{How Claude Code works|https://code.claude.com/docs/en/how-claude-code-works}}). The pseudo-code is this page's summary of those docs.
