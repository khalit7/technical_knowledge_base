The animation, step by step (switch levels at the top of the card)

  1. The code as Django ships it. Two excerpts of the real repository at the task's base commit: Field.contribute_to_class and its neighbours in django/db/models/fields/__init__.py (lines 742 to 786), where the fix goes.
  2. Find the repository's own names. The released extractor walks the syntax tree of every Django file and keeps classes, public functions, modules, files, directories, module variables and class attributes; it drops Python builtins, keywords, third-party names and a list of common words. Highlighted: the 40 targets in this excerpt. self, name and getattr are reserved; attname is only ever an instance attribute, so it is not a target and survives.
  3. Split each name into tokens. tokenize_identifier splits on underscores, dots and case changes. Every target is rebuilt from tokens, so one token maps the same way everywhere: whatever get becomes, it becomes in every name.
  4. Draw one word per token, from the seed. For each of the 47 tokens, in alphabetical order, the candidate list is shuffled by the seeded generator and the first word not used yet is taken (create_token_mapping). Bold is this seed's choice; a star marks a word the paper itself shows.
  5. Rebuild every name in its original style. reconstruct_identifier keeps CamelCase, snake_case, UPPER_CASE and file suffixes. Its one quirk is visible in Figure 4: a multi-word replacement inside a CamelCase name keeps its underscore, so CharField with char → character_unit becomes Character_unitField.
  6. What the agent sees. Every observation is translated before the agent reads it and every command translated back before it runs. Hover a highlighted name to see the original. The project name itself becomes working_repository (the code's Level 1).
  1. 35 definitions in file order. fields/__init__.py has one long run of top-level definitions: three helper functions, Field and 31 field classes. Level 3 may reorder them only within this run; the imports and assignments around it are anchors.
  2. Which definitions must come first. A class cannot be defined before its base class (or a metaclass, decorator or default argument it names). The released code finds these definition-time dependencies in the syntax tree: green arcs, base above subclass.
  3. Sample an order that respects them. A random topological sort: repeatedly pick, uniformly, one definition whose dependencies are already placed. The released code retries up to 32 times until the order differs from the original.
  4. Check the result. Every arc still points downwards (a red arc would mean a broken import). In the paper the variant is then kept only if all Pass-to-Pass tests still pass and the Fail-to-Pass test still fails.
