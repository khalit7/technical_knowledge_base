RRSI: Regularized Recursive Self-Improvement of Agent Harnesses (arXiv HTML v2)

Preprint, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

Generalization in Adaptive Data Analysis and Holdout Reuse

Dwork, Feldman, Hardt, Pitassi, Reingold, Roth (2015): The theory behind the paper's worry: every look at the same evaluation set adapts the next choice to it, so scores on a reused set drift above the truth. Its reusable-holdout idea is the formal cousin of RRSI's noise band.

(40 min)

What Evolves When We Talk About Harness Evolution?

Ding, Lu, Yu, Li, Jin, Liu, Durrett (2026): Delta attribution: separates edits that install a reusable mechanism from edits that fit the evolution tasks; the paper cites it as evidence that evolution gains often do not transfer.

(20 min)

HarnessCompass

Zhang et al. (2026), arXiv 2608.01918: Concurrent work that makes generalisation an explicit objective of harness evolution, the alternative to RRSI's regularise-the-search approach.

(40 min)

Agentic Harness Engineering (AHE)

Lin et al. (2026): One of the four baselines: an observability-driven evolution loop for coding-agent harnesses; here it reaches 90.7 on the evolve split and ends below the starting harness out of distribution.

(40 min)

HarnessX

Chen et al. (2026): Baseline: a harness built from typed, composable primitives with trace-driven adaptation.

(40 min)

TTHE: Test-Time Harness Evolution

Nie et al. (2026): Baseline: keeps several candidate harnesses and lets an agentic judge pick the one that persists; the largest out-of-distribution drop in Table 1.

(40 min)

Connected papers in this knowledge base

SoL-Pi: Recursively Scaling Auto-Research Loops for Efficient Agent Harness

The same harness-level loop pointed at cost instead of capability: about half of recorded agent token traffic turns out to be harness overhead. RRSI's cost rule is the guard; SoL-Pi is the objective.

Dream-RSI: Recursive Self-Improvement through Evolving Worlds

Keeps the loop's memory as a replayable search history and improves exploration off-policy against it; RRSI keeps an edit ledger and conditions the proposer on it. Neither measures transfer to new benchmarks the way RRSI tries to.

Agora: Git as Shared Memory for Collective AutoResearch

Memory as an append-only Git history that anyone can check out; RRSI's released code also makes every incumbent a commit on an evolve branch.

NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness

Recursive self-improvement through the weights: the harness feeds a training curriculum. RRSI freezes the weights and changes only the harness, and its Limitations section names weight updates as out of scope.

HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

Measures the failure RRSI tries to prevent: in its evolution runs the score a creator could see moved with the held-out score in only 34 of 64 version changes.

Emergence World: Adversarial Stress-Testing of Long-Horizon Multi-Agent Systems

Attacks long-running agent systems of this shape with prompt injection, misinformation and memory exposure; a self-modifying harness is exactly the kind of system it stress-tests.

Prime Agent: A Self-Improving RLM Harness

A harness that versions its own prompts and skills across trajectories: an unregularised loop of the kind RRSI regularises.

JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

Evolves a harness per task at inference time instead of searching one shared harness offline.
