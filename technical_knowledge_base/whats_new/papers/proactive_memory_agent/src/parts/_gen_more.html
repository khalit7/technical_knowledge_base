The paper

Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents (arXiv HTML v1)

arXiv preprint, 2026, the paper itself; the HTML version has the anchors this page links to. abstract page, PDF.

(35 min)

yifannnwu/proactive-memory-agent

Apache-2.0. The memory agent (both phases, the four bank tools, the trigger), the Terminal-Bench runner on a vendored Harbor with Enroot sandboxes, the two run configurations, and five rendered example traces (baseline and memory run of the same task). Not released: the τ²-Bench runs, the ablation variants, the SETA training code and the trained Qwen3.5-27B memory agent (checked 3 October 2026).

(20 min)

Best resources

Example traces, rendered (baseline and memory run of five Terminal-Bench tasks)

the paper's repository: the action agent's and the memory agent's full trajectories, every reminder and bank edit; this page's Replay tab is built from them.

(30 min)

Terminal-Bench: Benchmarking Agents on Hard, Realistic Tasks in Command Line Interfaces

Merrill et al., 2026: the 89-task benchmark and the Terminus 2 harness the paper runs; its Table 2 gives Sonnet 4.5 with Terminus 2 at 42.8% ± 2.8% over at least five runs.

(40 min)

τ²-Bench: Evaluating Conversational Agents in a Dual-Control Environment

Barres et al., 2025: the airline, retail and telecom domains with a simulated user; the benchmark on which the paper's ablations run.

(35 min)

Lost in the Middle: How Language Models Use Long Contexts

Liu et al., TACL 2024: the evidence the paper leans on for "present in context but not used": accuracy depends on where in the context a fact sits.

(30 min)

How to Train Your Advisor: Steering Black-Box LLMs with Advisor Models

Asawa et al., 2025: the advisor line of work the paper sets itself apart from: a second model that steers an executor with free-form advice.

(30 min)

Memory as Action: Autonomous Context Curation for Long-Horizon Agentic Tasks

Zhang et al., 2025: the opposite design choice: the agent itself edits its working memory, trained jointly with the task.

(30 min)

Scaling Long-Horizon LLM Agent via Context-Folding

Sun et al., 2025: branch into sub-trajectories and fold them into summaries, learned with RL; context management by removal.

(30 min)

Reflexion: Language Agents with Verbal Reinforcement Learning

Shinn et al., NeurIPS 2023: verbal reflections on failed attempts stored in an episodic buffer: the across-attempt ancestor of within-run procedural memory.

(30 min)

MemGPT: Towards LLMs as Operating Systems

Packer et al., 2023: the store-and-retrieve memory design the paper calls passive: the model pages records in and out of context on demand.

(40 min)

Mem0: the memory layer for AI agents

Mem0 team (GitHub): the production memory layer used as the retrieval baseline in Table 2 (ADD to write, vector plus BM25 search to read).

(15 min)

SETA: Scaling Environments for Terminal Agents

Shen et al., 2026 (Eigent AI): the executable terminal tasks with verifier rewards on which the open-weight memory agent is trained.

(15 min)

Context windows (Claude API docs)

Anthropic: Claude Sonnet 4.5 has a 200k-token window; the largest action-agent prompt in the released traces is 71k tokens.

(10 min)

Pricing (Claude API docs)

Anthropic: Opus 4.6 at $5 and $25 per million input and output tokens, Sonnet 4.5 at $3 and $15: the prices behind this page's cost estimates.
