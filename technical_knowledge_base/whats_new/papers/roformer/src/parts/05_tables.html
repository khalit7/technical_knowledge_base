Every table of {{§4|ax:S4}}, transcribed from the arXiv HTML (v5) with the printed precision, and every derived number recomputed in recompute.py. Table 2: GLUE, and which split each row comes from

BERT's printed row equals BERT-Base in the {{BERT paper's Table 1|https://arxiv.org/html/1810.04805v2#S4.T1}}, "GLUE Test results, scored by the evaluation server". RoFormer's is the best of four learning rates, averaged, on the validation set ({{§4.3.2|ax:S4.SS3.SSS2}}). The validation-set reference is {{Hugging Face's run_glue example|https://github.com/huggingface/transformers/blob/main/examples/pytorch/text-classification/README.md}} (bert-base-cased, 3 epochs at 2e-5, 5 for MRPC, one seed; its STS-B is Spearman, QQP and MRPC F1, MNLI matched and mismatched accuracy): a same-split reference, not BERT's best, and cased where the paper used uncased.

Table 4: the six pretraining stages

StageMax lengthBatchStepsLossAccuracy

From {{Table 4|ax:S4.T4}}, about 34 GB of Chinese text. Accuracy tracks the stage's maximum length (correlation with log2 length, recompute.py), which the paper reads as RoPE's "excellent generalizability". It is equally what any masked language model shows: with more context, masked tokens are easier to fill. The stages also differ in batch size and steps and run in sequence, so they are not a controlled comparison. The longest length seen is 1,536.
