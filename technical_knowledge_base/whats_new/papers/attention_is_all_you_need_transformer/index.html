The idea in one sentence

Drop recurrence and let every position attend to every other position in one parallel step: the path between any two words falls from n steps to 1, training parallelises across the sequence, and an encoder-decoder built only from attention, a per-position feed-forward layer and Add & Norm beat every earlier translation model at a fraction of the training cost.

How far to trust it: the idea held up completely; the BLEU margins are single runs with no error bars, and two printed numbers disagree with each other or with a recount (Results).

The model at a glance

§3, Figure 1

The whole model is attention, a feed-forward layer and Add & Norm: no recurrence, no convolution. The figure is the base model of Figure 1 in 3D: N = 6 of each layer, dmodel = 512, h = 8, dff = 2048. Step through it in the order data flows; drag it to turn it.

  1. Two stacks. The encoder (left) reads the source sentence; the decoder (right) writes the translation one word at a time. Each is N = 6 identical layers, and every layer outputs dmodel = 512 numbers per word so the residual sums line up.
  2. Words in. Each source word becomes a 512-number embedding (multiplied by √dmodel) plus a fixed sinusoidal positional encoding, at the bottom of the encoder.
  3. Up through the encoder. Every layer runs multi-head self-attention (h = 8 heads), each word looking at every other word, then a position-wise feed-forward network, 512 → 2048 → 512, the same at every position.
  4. Into every decoder layer. The encoder's last output becomes the keys and values of cross-attention in all six decoder layers, so every output position can look at every input position.
  5. The decoder's own words. The translation so far, shifted right by one, enters the decoder. Its first sub-layer is masked self-attention: position i sees only positions up to i.
  6. Add & Norm around every sub-layer. Each is wrapped as LayerNorm(x + Dropout(Sublayer(x))): the residual path (the lines up the sides) lets the signal skip each block, and the norm comes after the sum ("post-LN").
  7. The next word. A linear layer (the embedding matrix, shared) and a softmax turn the decoder's top output into a probability for every token of the vocabulary; the chosen word is appended and the decoder runs again.

The sentence is an illustration; the layout and sizes are the paper's (§3.1). Notice the three kinds of attention: the encoder's self-attention, the decoder's masked self-attention, and cross-attention carrying the encoder's keys and values into every decoder layer.

New terms. Sequence transduction: mapping one sequence to another (translation, parsing). Post-LN: the norm applied after the residual sum, LayerNorm(x + Sublayer(x)). Background the page assumes: RNN encoder-decoders with Bahdanau attention (Sequence models before the transformer).

Problem

§1 Introduction, §2 Background

In 2017 sequence transduction, translation above all, was dominated by recurrent encoder-decoders (LSTMs and GRUs), usually with an attention mechanism between encoder and decoder, and by convolutional alternatives such as ByteNet and ConvS2S (§1, §2). A recurrent network computes its hidden state ht from ht−1 and the input at position t, so training cannot be parallelised along the sequence: that caps how much of a GPU a batch can use, and memory limits batching across examples as sentences get longer. Convolutional models do compute all positions in parallel, but connecting two distant positions takes a stack of layers, O(n/k) for contiguous kernels (ConvS2S) or O(logk n) for dilated ones (ByteNet), so long-range dependency paths stay long (§4).

The question: can attention alone, with no recurrence and no convolution, carry an entire sequence model?

Idea

§4 Why Self-Attention, Table 1

Let every position look at every other position directly, in one step. Section 4 compares layer types on three counts: total computation per layer, how much of it can run in parallel (the minimum number of sequential operations), and the longest path a signal has to travel between two positions, since shorter paths make long-range dependencies easier to learn (§4, Table 1).

LayerComputation per layerSequential operationsLongest path
Self-attentionO(n²·d)O(1)O(1)
RecurrentO(n·d²)O(n)O(n)
ConvolutionalO(k·n·d²)O(1)O(logk(n))
Self-attention, restricted to r neighboursO(r·n·d)O(1)O(n/r)

n is the sequence length, d the representation size, k the kernel width, r the neighbourhood size (Table 1).

When n < d, as with sentence-level word-piece and byte-pair tokens, self-attention is also cheaper per layer than recurrence: n²d < nd² exactly when n < d, so with the base model's d = 512 the crossover is at 512 tokens; for longer sequences the paper suggests the restricted row (§4).       Method: scaled dot-product attention

      §3.2.1, Eq. 1

      The Transformer is an encoder-decoder built only from attention, position-wise feed-forward layers, residual connections and layer normalisation (§3). Attention maps a query and a set of key-value pairs to a weighted sum of the values, the weights coming from how well the query matches each key. With queries and keys of size dk and values of size dv, packed as matrices:

      Attention(Q, K, V) = softmax(QK⊤ / √dk) V
      Equation 1 (§3.2.1). Dot-product rather than additive (Bahdanau) attention, because it is a single matrix multiply: similar in theory, much faster and more memory-efficient in practice.

      The figure runs Equation 1 with real numbers: the first encoder layer of this page's trained toy Transformer (Run a Transformer; dmodel = 24, h = 4, so dk = 6), head 4, on one sentence. The paper's base model does the same with dk = 64.

      1. Each word is a vector. The word's embedding plus its position: 24 numbers here (the bars), 512 in the paper.
      2. Three learned matrices make three vectors. WQ, WK and WV turn every word into a query (what it is looking for), a key (what it offers) and a value (what it hands over), 6 numbers each for this head.
      3. The query meets every key. The chosen word's query is dotted with all seven keys: a large score means a good match.
      4. Divide by √dk. Every score shrinks by √6 ≈ 2.45 (by √64 = 8 in the paper), the scaling the paragraph below explains.
      5. Softmax turns scores into weights. Exponentiate and normalise: the weights are positive and sum to 1.
      6. The output is the weighted sum of the values. z = Σj aj vj: each value flows in with its weight. Every word does this at once, which is the matrix form softmax(QK⊤/√dk)V.

      Query word

      The 1/√dk is the load-bearing detail. If the components of q and k are independent with mean 0 and variance 1, then q·k = Σqiki has mean 0 and variance dk (the paper's footnote 1). Unscaled, the logits spread out as dk grows and push the softmax into regions with tiny gradients; the paper notes that additive attention beats unscaled dot-product attention at large dk (§3.2.1).

      without the 1/√dk, what happens to the largest attention weight over 10 keys as dk grows from 4 to 512?

      Try: these are real random vectors, drawn fresh with each press of Redraw. Drag dk up and watch the unscaled softmax (left) collapse onto one key while its gradient vanishes; the scaled one (right) keeps the same spread at every size.

      Ten keys and one query with components drawn from a standard normal (Box-Muller, seeded). Variance of q·k is measured over 4,000 fresh pairs. "Largest gradient" is the largest entry of the softmax Jacobian, max pi(1 − pi): how much the strongest logit can still move the output. Illustrative inputs; the formula is the paper's.

      Method: multi-head attention

      §3.2.2

      Instead of one attention over dmodel = 512 dimensions, the queries, keys and values are projected h = 8 times with learned matrices WiQ, WiK (dmodel × dk) and WiV (dmodel × dv), with dk = dv = dmodel/h = 64. Each head runs attention in parallel; the h outputs are concatenated and projected back by WO (hdv × dmodel) (§3.2.2).

      MultiHead(Q, K, V) = Concat(head1, …, headh) WO,   headi = Attention(QWiQ, KWiK, VWiV)
      1. One word's vector: 512 numbers. Drawn to scale, one unit of width per 64 dimensions.
      2. Eight projections of 64. Each head has its own WiQ, WiK, WiV (512 × 64), giving it a 64-number query, key and value: 8 × 64 = 512, so the eight heads together cost what one full-width head costs.
      3. Each head attends on its own. Eight independent n × n weight patterns, computed in parallel, each in its own 64-dimensional subspace.
      4. Concatenate, then project. The eight 64-wide outputs side by side make 512 again; WO (512 × 512) mixes them. The projections hold 4 × 512 × 512 weights either way.
      5. What heads learn: real patterns. The toy model's four heads in its second encoder layer on one sentence (rows: queries, columns: keys, height: weight). Each head has learned a different pattern, which a single head would have to average.

      Because each head is h times narrower, the total cost is about that of one full-width head. What it buys: heads can attend to different subspaces and positions at once, where a single head has to average them. In the ablation one head costs 0.9 BLEU against the best setting (24.9 against 25.8), and too many heads hurt as well: 32 heads of 16 score 25.4 (Table 3 rows (A)). The Run a Transformer tab shows every head of a trained toy model, and a one-head version of it.

      Method: the block (post-LN)

      §3.1, §3.2.3, §3.3, §3.4

      The encoder is a stack of N = 6 identical layers with two sub-layers each: multi-head self-attention, then a position-wise feed-forward network. Every sub-layer is wrapped as LayerNorm(x + Sublayer(x)), normalisation after the residual sum ("post-LN"), with dropout on the sub-layer output before it is added. Every sub-layer and the embeddings produce outputs of size dmodel = 512 so the residuals line up (§3.1, §5.4).

      The decoder is also N = 6 layers, with three sub-layers: masked self-attention, where every illegal connection is set to −∞ before the softmax so position i sees only positions up to i (combined with the outputs being shifted right by one, a prediction depends only on earlier words); cross-attention, whose queries come from the decoder and whose keys and values come from the encoder's output, so every output position can look at every input position; and the same feed-forward network (§3.1, §3.2.3).

      1. One encoder layer, five positions. From the bottom: the input vectors, multi-head self-attention, Add & Norm, the feed-forward network, Add & Norm. The model at the top stacks six of these.
      2. Only attention mixes positions. Self-attention is the one sub-layer where a position reads from the others; everything above it works on each position alone.
      3. Residual, then norm. The input skips the sub-layer and is added to its output; LayerNorm comes after the sum: LayerNorm(x + Sublayer(x)), post-LN.
      4. The FFN, position by position. 512 → 2048 (ReLU) → 512, the 4× expansion drawn in depth; the same weights at every position, never mixing them (Equation 2 below).
      5. The decoder's mask. Masked self-attention of the toy model's decoder (second layer, first head) as it translates: query i (rows) uses keys up to i; later positions are set to −∞ before the softmax, so their weight is exactly 0 and training can predict every position of a sentence in one pass.
      FFN(x) = max(0, xW1 + b1) W2 + b2
      Equation 2 (§3.3): the same two linear maps with a ReLU between them at every position (two convolutions of kernel size 1), different from layer to layer; inner size dff = 2048, a 4× expansion.

      Embeddings. One weight matrix is shared by the input embedding, the output embedding and the pre-softmax projection, and in the embedding layers it is multiplied by √dmodel (§3.4); with the shared English-German vocabulary of about 37,000 tokens, that one matrix is 18.9 million of the base model's parameters (37,000 × 512, counted in the tables tab).

      Method: positional encoding

      §3.5

      With no recurrence and no convolution nothing in the model knows word order, so it has to be injected. The paper adds fixed sinusoids to the embeddings at the bottom of both stacks:

      PE(pos, 2i) = sin(pos / 100002i/dmodel),   PE(pos, 2i+1) = cos(pos / 100002i/dmodel)
      Each dimension is a sinusoid; the wavelengths form a geometric progression from 2π to 10000 · 2π (§3.5).
      1. Each pair of dimensions is a clock. Dimensions 2i and 2i+1 hold sin and cos of the same angle, so together they are a hand on a dial (sin across, cos up). Eight of the 256 pairs are drawn; at position 0 every hand points up.
      2. Positions 0 to 6. At position pos hand i has turned by pos / 100002i/512: the first clock a full radian per word (wavelength 2π ≈ 6.3), later clocks ever more slowly.
      3. Positions 6 to 50. Fast hands spin round many times and repeat; slow hands have barely moved. Read together, the hands give every position a different reading, from wavelength 2π up to 10000 · 2π.
      4. An offset is a fixed turn. Moving from position 10 to 15 (k = 5) turns each hand by k / 100002i/512, an angle that depends only on k.
      5. The same turn from anywhere. From 40 to 45 every hand turns by exactly the same angles as from 10 to 15. A turn is a rotation, a linear map, which is why PEpos+k is a linear function of PEpos.

      Why sinusoids: for any fixed offset k, PEpos+k is a linear function of PEpos (each sine and cosine pair is rotated by an angle that depends only on k), which the authors hoped would make attending by relative position easy to learn. Learned absolute embeddings gave nearly identical results (25.7 BLEU against 25.8, Table 3 row (E)); the sinusoids were kept because they might extrapolate to sequences longer than any seen in training (§3.5). What later models use instead (relative biases, ALiBi, RoPE and its scaling) is taught on Positional encodings.

      Left: the encoding of positions 0 (top) to 63 (bottom) across all 512 dimensions at dmodel = 512 (blue negative, orange positive): fast sinusoids on the left, wavelengths up to 10000 · 2π on the right. Right: PEp · PEp+k against the offset k for three starting positions p: the curves coincide, because the dot product depends only on the offset. Computed from the formula above.

      Method: training and decoding

      §5 Training, §6.1
      • Data (§5.1): WMT 2014 English-German, about 4.5 million sentence pairs, byte-pair encoded with a shared source-target vocabulary of about 37,000 tokens; English-French, 36 million sentences, a 32,000 word-piece vocabulary.
      • Hardware and time (§5.2): one machine with 8 NVIDIA P100s. Base model (65M parameters): 100,000 steps at about 0.4 s each, 12 hours. Big model (213M): 300,000 steps at 1.0 s, 3.5 days.
      • Optimiser (§5.3): Adam with β1 = 0.9, β2 = 0.98, ε = 10−9, and a learning rate that rises linearly for 4,000 warmup steps, then falls with the inverse square root of the step (Equation 3, below).
      • Regularisation (§5.4): residual dropout 0.1 (0.3 for the big English-German model); label smoothing εls = 0.1, which "hurts perplexity, as the model learns to be more unsure, but improves accuracy and BLEU".
      • Decoding (§6.1): beam search with beam 4 and length penalty α = 0.6, on an average of the last checkpoints.
      The rest of the recipe, and two small gaps in it

      Batches held about 25,000 source and 25,000 target tokens, sentences grouped by length (§5.1). Dropout is applied to every sub-layer output and to the sums of embeddings and positional encodings (§5.4). Decoding stops at input length + 50; the final model averages the last 5 checkpoints, written every 10 minutes, for base models and the last 20 for big ones (§6.1).

      §5.4 announces "three types of regularization" and lists two (residual dropout and label smoothing). §5.2 gives the base model as 65M parameters; recounting from the stated configuration gives 63.1M (the recount in the tables tab).

      lrate = dmodel−0.5 · min(step−0.5, step · warmup−1.5)
      Equation 3 (§5.3). The two branches meet at step = warmup, so the peak is (dmodel · warmup)−0.5.

      Why it matters

      beyond the paper: later work, each claim linked

      Removing recurrence made training embarrassingly parallel across sequence length, which let compute be spent on model and data size instead of waiting on wall-clock sequential steps. Every frontier LLM (GPT, Claude, Llama, Gemini, DeepSeek), BERT-style encoders, ViT, CLIP, Whisper and most of diffusion's backbone work descend from this design.

      What survived untouched: scaled dot-product attention itself, multi-head projections, and the residual-plus-norm wrapping. What changed were the choices that turned out not to be load-bearing, each taught on the page that owns it: decoder-only won for generation, with cross-attention surviving in multimodal adapters and encoder-decoders holding on in T5 and Whisper (Families and objectives); pre-LN and RMSNorm replaced post-LN LayerNorm (Normalisation, residuals and stability); RoPE replaced the added sinusoids, with interpolation and YaRN to extend the context (Positional encodings); SwiGLU (or GeGLU) replaced the ReLU FFN and biases were dropped; MQA, GQA and MLA shrink the KV cache (Attention variants); FlashAttention makes exact attention IO-aware (Writing kernels), since the O(n²) cost the paper acknowledged is now the central serving bottleneck, also attacked by PagedAttention, sliding windows, and sparse and linear hybrids such as Mamba; and the recipe changed: label smoothing and heavy dropout largely dropped at pretraining scale (PaLM trained without dropout), with Adam's β2 moved to 0.95 and the warmup then decay schedule surviving in cosine form. The Then and now tab morphs the 2017 block into a 2026 one, one sourced change per step.

      Connections. BERT kept the encoder; GPT-3 and Scaling Laws scaled the decoder; T5 kept the encoder-decoder; ViT fed it image patches; RoFormer replaced its positional encoding; FlashAttention and PagedAttention attack the memory and IO costs it created; Mamba tries to remove its O(n²) core. Topics: ml-fundamentals (sequence-model history, attention), llm-training-and-post-training (positional encodings, learning-rate schedules), llms (the ancestor of every family covered). Each is described in Further reading.

      The task: English into Lindu, a made-up language whose word order differs

      Lindu is invented for this page so the task is exactly known and every answer can be checked by rule (grammar.py and 21_js_lang.js). It is verb-final, like Japanese or the German subordinate clause: subject, then any place phrase, then the object marked with su, then the verb. Adjectives follow the noun in mirrored order, the article comes last, and prepositions become postpositions. So the alignment between the languages crosses itself, as English-German translation does, and a model that ignores word order cannot translate it.

      Vocabulary: 2 articles, 5 adjectives, 8 nouns, 4 places, 5 verbs, 3 prepositions, and their 27 Lindu words plus su; 58 entries in one shared vocabulary with the start, end and padding symbols, as the paper shares one BPE vocabulary between English and German (§5.1). The grammar generates 540.8 million distinct sentences; training drew 2,048,000 sentences, 1,231,511 of them distinct, and the 2,000 test sentences behind the accuracies on this page were drawn the same way but never occur in that stream (overlap.py, train.py).

      What breaks without positions

      Without positions the encoder cannot tell "the dog chased the cat" from "the cat chased the dog": attention is a weighted sum over a set, so reordering the source words reorders the encoder's outputs and leaves cross-attention's sums unchanged. The decoder still gets the shape of a Lindu sentence right (it gets of words right) because its own causal mask leaks position: a word can count how many earlier words it sees, as Haviv et al. 2022 found in language models trained without positional encodings. But it has to guess which noun is the subject and which adjective belongs to which noun, so only of sentences come out right. One head is enough on this task (it scores the same as four), unlike the paper's 0.9 BLEU loss on real translation (Table 3 (A)); its attention maps are blunter, as the maps above show.

      Then and now: the 2017 block becomes a 2026 block, one change at a time

      Each step makes one change that later work introduced, names the paper, and recounts the block. The widths stay at the paper's base model (dmodel 512, 8 heads of 64) so every count is comparable; only the design changes. Counts are per decoder layer and computed from the formulas in the caption, not from any one model.

      2017 Transformer to a 2026 decoder-only block (Llama 3, Qwen3 style).

      Parameters per decoder layer at d = 512: attention 4d² (with GQA, 2d² + 2d · g · 64 for g KV heads), FFN 2d · dff (SwiGLU: 3d · dff), plus biases and norm gains while they exist. KV cache: numbers stored per token per layer, 2 × (KV heads) × 64. It starts paused: press play or step.

      What survived

      • Untouched: scaled dot-product attention, softmax(QK⊤/√dk)V; multi-head projections; residual connections with a norm around every sub-layer; an FFN at every position.
      • Survived in form, changed in detail: the 4× FFN expansion survives as a parameter budget, and tied embeddings survive only in small models (the config files are in the closed block below).
      • The warmup: still used everywhere, now before a cosine decay rather than the inverse square root.
      Checked in model config files (read 2 October 2026)
      • FFN width: A SwiGLU FFN with inner size 8/3 × d has the same parameters as a 4× ReLU FFN; current configs go further: Llama 3.1 8B uses 14,336 / 4,096 = 3.5× and Qwen3 8B 12,288 / 4,096 = 3.0×, with three matrices each.
      • Tied embeddings survive only in small models: Llama 3.2 1B and Qwen3 0.6B set tie_word_embeddings to true; Llama 3.1 8B, Qwen3 8B and DeepSeek-V3 set it to false (PaLM ties them, §2). Llama 3.1 is read from the unsloth mirror because Meta's repository is gated.
