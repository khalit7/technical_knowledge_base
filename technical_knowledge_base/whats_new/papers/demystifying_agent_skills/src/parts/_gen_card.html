Demystifying Agent Skills: Why They Work - Until They Don't

Zhiyuan Jiang, Fangrui Huang, Hanwen Xing, Xander Wu, Yipeng Gao, Rui Cao, Mengdi Wang, Shilong Liu, Yijiang Li
Princeton, UC San Diego, Stanford, USC, Johns Hopkins (corresponding authors Mengdi Wang, Shilong Liu, Yijiang Li; Jiang worked on it as a Princeton intern) · August 2026 (arXiv v1, 14 August 2026; the only version so far)

In one line: With the experience held fixed, the same trajectories distilled into a SKILL.md beat them pasted in as workflow memory by +6.06 points over 528 paired Codex runs (one trial per arm; Gemini on Terminal-Bench-Pro favours workflow memory) but do not clearly beat no prior experience (+2.84, interval spans zero); one LLM judge labels most skill effects procedural anchoring (65.7%) rather than knowledge injection (4.5%), skills add a misapplication failure (10.0% of skill runs against 0.8% raw), and as the pool grows to 100 skills actual-use precision falls to 3.3% while task success holds, a metric that mostly counts how many skills an agent opens.

How far to trust it: Believe the direction: on most setups a distilled skill beats the same experience pasted in as workflow traces, and skills bring a misapplication failure of their own. Treat the sizes as provisional. The +6.06 points rests on one trial per arm on 88 Codex tasks and is not significant if a task's six triples are even slightly correlated; Gemini on Terminal-Bench-Pro shows the opposite; the mechanism shares come from one LLM judge that labels identical runs differently; and the retrieval "decoupling" uses a precision metric that mostly counts how many skills an agent opens.
