## Departures from papers.md, and why

- **The live ingredient tests the released code, not only the paper's text.** The paper is an architecture paper (the table's first row), so the toy is the architecture, built exactly as `model.py` builds it at a smaller width. But the code differs from the text in four places (the cross-attention sits in front of GPT-Neo, not in its stack; GPT-Neo is randomly initialised; the cross-attention has no causal mask; sequences are cut at 2,048), and the missing mask decides what the paper's only quantitative evidence (the loss) means. So the toy trains the released version and the fixed version side by side, plus the controls the paper did not run (the small model alone, plain cross-attention, the frozen model fine-tuned instead, one linear layer). The task was designed before training to need the frozen model's knowledge at exactly one step (the answer after "="), and was not tuned afterwards.
- **"The paper's tables, rebuilt" became "The evidence, rebuilt".** The paper has one qualitative table and no figures; what carries the argument is the released transcripts, the data pipeline and the parameter count, so the tab rebuilds those.
- **No "Then and now" tab**: a 2025 preprint with no descendants; the family it belongs to (Flamingo, CALM, adapters, distillation) is one table in "Why it matters".
- **The card's one-line takeaway is corrected**, not copied from the Takeaway property, which says the cross-attention layers are inserted into GPT-Neo and that GPT-Neo-125M is trained (it is a randomly initialised copy of its architecture). The property itself stays in Notion; Khalid may want to edit it.

## The 2026-11-13 layout rollout (split layout, renderer v2 stages, autoplay)

What changed and why:
- **Split layout** (template `02_split.html`, after the page CSS). The paper tab: the core sentence, You need and New terms beside the hero; Idea and Method beside the stage Fig. 1; The leak beside the stage Fig. 2. Run the modules: its intro and the toy paragraph beside Ask the modules. The evidence: the validation-overlap paragraph beside its slider and chart. Full width: Problem, Training (stat tiles), Results, The toy (table), How much to believe, What it takes, Why it matters (table), Connections; in Run the modules the heatmap, seeds chart, curves and test (widgets with one-line notes and no prose to sit beside; `verify_layout.mjs` lists them as outside a split, deliberately); in The evidence the tables and bars.
- **Fig. 1, the CombinedModel as model.py builds it** (`31_js_sc_arch.js`), replaces the clickable 2D architecture diagram. Frozen Qwen2-1.5B as a grey tower of 28 slabs, the GPT-Neo-sized decoder as 12 green slabs (random start), slab side proportional to width (1536, 768); `pre_proj`, `proj` and the per-layer Wq, Wk, Wv as glass plates; g, adapter and gate as blocks; the new output layer as a long glass plate (labelled not to scale). Flows carry the tokens up Qwen2, its last state to `pre_proj`, the split into g and proj, keys and values into the queries, g + proj into the decoder and the decoder's output into the head. Seven steps, the camera moving in close per part; every count from `PAPER.rc` (recompute.py). The old diagram's per-box code facts and the Method's ordered list ("where the layers sit") became its step list, so the Method keeps the paper's description, the equation and the random-weights paragraph.
- **Fig. 2, the leak** (`32_js_sc_leak.js`), replaces the 2D animation (`26_js_leak.js`). The toy's real first-layer cross-attention (mean of 4 heads, seed-0 shipped weights, computed in the browser by `22_js_model.js`) on the same held-out problem, as a 21 × 21 bar field: rows query positions, columns the frozen model's states (white blocks at the front), the floor right of the diagonal tinted orange (released) or grey (masked). Nine steps per mode, two step lists (as released, fixed) with the old captions merged into them: the whole matrix, then the seven rows of the old animation with flows streaming down each column into the row in proportion to its weight, then generation. **Correction**: the old last step showed the released model at "=" on the true prefix, where it writes the right answer (92%), although the problem was chosen because it gets the answer wrong when generating. The generation step now shows the first position where the free-running output departs from the trace ("T", where it writes 16 for 2, having read a from the check line in training), and the list quotes both models' generated traces. The counters (problem, weight on later states, next token, probability of the right token) sit under the lists.
- **Kept 2D**: the hero (a static four-box summary that reflows; Fig. 1 does the same in 3D a screen below), the size bars in the predict reveal, the stat tiles, every table, the Run tab's heatmap (the same matrix as Fig. 2, as a tool with model, layer and position pickers), seeds chart and curves, and the evidence tab's bars and overlap curve (numbers on axes).
- **Motion**: `makeAnim` removed from `11_js_ui.js` (no 2D animation is left). Both stages play once half in view and stop for good on a control (template `S3.stage`). `check_page.mjs` now asserts autoplay instead of forbidding it and steps the stages; `check_stages.mjs` is new.
