# Visuals: built and rejected (WorldTUI article page)

## Built
- **P-worldtui.1 Fig. 1, the keypress-cost widget (hero, live ingredient).** Seven screen changes on an illustrative 32 x 96 session; a row map (written span, copied row, unchanged) drawn to column scale, the longest edit outlined, and four counts (rows changed, sequential steps, without COPY, row-parallel steps). Chosen because the post's two engineering ideas (COPY and parallel rows) are claims about token counts, and moving one variable (the keypress) shows both at once; its defaults land on the post's own numbers independently: the log case gives 3,020 tokens ("around 3,000") and 100 parallel steps ("roughly 100"), and a scroll costs 3 tokens a row. Opens on "Type l", so the prediction prompt's answer is not on screen.
- **P-worldtui.2 Fig. 2, one self-repair example as a 6-step animation** (recording against the model's own screen, the diff in red, the correction in green, then the skipped case). A process, so a step sequence with its step list on the left.
- **P-worldtui.3 Fig. 3, memory readbacks of 64 for four models** (teacher, without layer 7, 12- and 16-layer students), with next-token accuracy and ShellBench as text under each bar. The post's most transferable finding, stated as two metrics that disagree.
- **P-worldtui.4 the tests table** (every score the post and the demo's source give, by test). A table, since the point is which test each number comes from.

## Rejected
- **An error-compounding curve over rollout length**: the post gives no per-step or per-length accuracy, so any curve would be invented. The trust section says it is unmeasured instead.
- **The post's latency bars redrawn**: two numbers, said in one sentence.
- **Embedding the post's videos or the demo**: no licence; the demo is a 208 MB download. Linked instead.
- **A draft-then-verify animation of rows**: the speculative decoding page owns verification; a sentence and a link carry it.
