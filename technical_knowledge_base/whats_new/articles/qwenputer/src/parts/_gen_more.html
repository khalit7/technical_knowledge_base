Responses, in date order

"A custom host runtime is still responsible for loading firmware" (Hacker News comment)

gcr (Hacker News), 29 October 2026, critique: The host loads the firmware, boots the CPU and, while it runs, skips Qwen's own layers by hand; calls the "no external runtime" and "not a plugin" claims a little dishonest for that reason. The code confirms the description (RvChat), and the post itself lists the driver under its limits.

(1 min)

"Ordinary causal attention can do exactly the same thing" (Hacker News comment)

nullc (Hacker News), 29 October 2026, comment: The RAM does not need a recurrent layer: attention can store and look up exact values too, at a memory cost that grows with the number of accesses instead of staying fixed. Correct, and the post's own claim is only that the recurrent version is cheaper.

(1 min)

Qwenputer, an experimental model that treats Gated DeltaNet state as RAM to put a RISC-V CPU in its weights (in Korean)

9bow (PyTorch Korea user group forum), 1 November 2026, analysis: Reads the repository's history: the chart's NUPA bar is the CHIP-8 version's 576-problem result (the commit of 22 October says so, the next one removes the label); a McNemar column, with p = 1.0 for add_or_sub_big, was added and dropped on 19 October; the base column was re-run on 21 October; a firmware bug was fixed and the "never printed a wrong result" line dropped on 20 October. Each point checked here against the commits.

(15 min)

A Developer Compiled a Full RISC-V CPU Into Qwen3.5's Weights

AlphaSignal newsroom, 2 November 2026, coverage: A news write-up, not a rebuttal: its takeaways repeat "no external runtime" and the NUPA 100% figure, while its body says the prototype "requires a custom runtime" and a driver that loads firmware and hides the trace. Shows how the post's two framings travel side by side.

Since the article (papers that build on it)

QwenFX: a coding agent inside the model

8 November 2026: Vercel's fx coding agent, compiled unmodified, runs on the in-weights CPU with Qwen3.5-4B as its model: 15 of 15 small repository tasks, a new executor at about 24,000 trace tokens a second on an L4, the computer as a 125 MB chip file beside base Qwen. The host still renders the chat template, keeps the files and does the git work (the author's README, read 27 November).

(10 min)

Qwenputer-npu and QwenPU: neural networks on the in-weights CPU

30 October 2026: Three added instructions (int8-by-int4 dot products) let Karpathy's 260K-parameter stories260K Llama run as a C program on the CPU, about 41 s a story token on an L4; QwenPU's vector unit cuts that to about 16 s, with a 26.7 GB checkpoint (the repository README, read 27 November).

(10 min)

What it rests on

Hybrid models can hide reasoning in their RNN state

Divyansh Agrawal, 22 October 2026 (the author; Part 2 of the series): The first follow-up: fine-tuned to answer with no visible reasoning, OLMo-Hybrid (write strength allowed up to 2) learns to track a flipping switch silently and generalises to 256 flips; Qwen3.5 (write strength capped at 1 by a sigmoid) does not. Uses the same compiler for its probes.

(9 min)

Building oversight tools into a model's weights

Divyansh Agrawal, 22 October 2026 (the author; Part 3 of the series): The second follow-up: a linear lie probe whose trigger and log are compiled into the weights (91% of lies flagged, no false flags in 28,000 tokens of chat and GSM8K, the log kept in DeltaNet state), and a planted mechanism as an answer key for interpretability tools.

(7 min)

Linear Transformers Are Secretly Fast Weight Programmers

Schlag, Irie and Schmidhuber, ICML 2021 (third-party): The paper the post cites for the delta rule as an associative memory; our owner page teaches the rule from it.

(45 min)

Gated Delta Networks: Improving Mamba2 with Delta Rule

Yang, Kautz and Hatamizadeh, 2024 (third-party): The layer Qwen3.5 uses three times in every four, with the gate and write strength this post pins to 1.

(45 min)

Can LLMs be computers?

Christos Tzamos and others, Percepta, 11 March 2026 (third-party; linked in the Hacker News thread): Earlier work on executing programs inside transformer weights (a WebAssembly interpreter), with its own fast decoding; Qwenputer's difference is that it sits beside an unchanged pretrained model that calls it.

(20 min)

Tracr: Compiled Transformers as a Laboratory for Interpretability

Lindner et al., 2023 (third-party): The best-known earlier compiler from a program to transformer weights (RASP programs); background for the compiler in section 3, which the post does not cite.

(40 min)

Qwen3.5-4B model card

Qwen team (maker): The base model: 32 layers, 24 of them Gated DeltaNet (16 key heads, 32 value heads, 128 x 128 states).
