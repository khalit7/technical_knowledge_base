• QwenFX: a coding agent inside the model (8 November 2026): Vercel's fx coding agent, compiled unmodified, runs on the in-weights CPU with Qwen3.5-4B as its model: 15 of 15 small repository tasks, a new executor at about 24,000 trace tokens a second on an L4, the computer as a 125 MB chip file beside base Qwen. The host still renders the chat template, keeps the files and does the git work (the author's README, read 27 November).
  • Qwenputer-npu and QwenPU: neural networks on the in-weights CPU (30 October 2026): Three added instructions (int8-by-int4 dot products) let Karpathy's 260K-parameter stories260K Llama run as a C program on the CPU, about 41 s a story token on an L4; QwenPU's vector unit cuts that to about 16 s, with a 26.7 GB checkpoint (the repository README, read 27 November).
