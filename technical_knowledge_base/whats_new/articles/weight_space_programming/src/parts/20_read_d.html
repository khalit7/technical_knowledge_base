How much of this to believe

What holds up. The release is unusually complete for a blog post: every prompt, reply, code run, forward pass, network and evaluation is in the {{logs|https://github.com/RikiyaT/lm_understand-logs}} (CC BY 4.0), each number in the post is mapped to the file it comes from, all 1,125 turns were audited to confirm the model's own tools stayed off (Python ran only through the experimenters' sandbox), and the edited Qwen can be rebuilt bit for bit (we did, for the two edited matrices, and both hashes match). Failures are reported, not hidden: the sycophant from weights alone, and the Gemma control. Independent runs reproduced the parts that need no lab: naming the game (Willison on an open 27B model, three of four; a LessWrong ablation study) and writing Breakout networks (514, 550 and 307 against the post's 517.4, arXiv 2611.21449).

Where the evidence is weaker than the wording.

  • Three kinds of result under one claim. Raw weights with no tools appear only in Experiments 1, 2 and 4, on 17K to 172K weights; Experiment 5 writes from zeros with nothing to read; every language-model result used Python, and the headline Qwen result also ran the model 50 times (the hero figure; Honnibal's point, which the post's own Setup boxes support). The first TL;DR ("well past what we'd expect from humans or conventional algorithms") was softened after publication.
  • The Qwen fault was named in the prompt. The task said that fixing repetition "counts" and told Astra to look for answers "cut off at the token limit (often while repeating itself in its thinking)". "Astra spots and fixes" a looping failure is therefore a diagnosis it was pointed toward, carried out well, not a discovery from the weights.
  • The Qwen edit is a known technique. A direction built from activation differences and written against in one matrix is directional steering (the post cites Arditi et al. on refusal); UC San Diego's analysis reproduces it as context-dependent activation steering and shows trained steering vectors cut loops further. Simply turning thinking off gave 53.3% against the steered 57.7% on their 1,152 practice problems.
  • Single runs, with unreported siblings. Each Qwen budget is one run; the released table holds four more Qwen runs not in the post (three made no edit), and the 10, 25 and 50-pass edits are different edits, so the table is not a scaling curve. Experiments 1 to 3 are 3 or 4 items each; Experiment 4 is one try.
  • Reading leans on the input layer and on priors. With the first layer alone Astra named the game 100% of the time, with the last alone 62%; on three new games it recovered the board layout but mostly not the rules (2611.21449); Claude Opus 5.5 on image CNNs followed familiar datasets and broke when labels were permuted (2611.08070). What is read is mostly the layout of where inputs and outputs connect.
  • Baselines and settings chosen for the claim. PPO at 500M steps beats Astra's networks in two of three MinAtar games; the Qwen setting (thinking on, 32,768 tokens) is the one where the base model loops 93% of the time. The addendum states both choices openly, which counts in the authors' favour.

Verdict. The small-network demonstrations are real and replicated: a frontier LLM can compile a designed program into an MLP's weights and read what a small network's input and output layers connect to. The Qwen result is a capable agent doing a known interpretability edit with tools, a prompt hint and forward passes; it shows that the agent can run that workflow end to end, not that it reads 0.8 billion weights.

What the responses said
