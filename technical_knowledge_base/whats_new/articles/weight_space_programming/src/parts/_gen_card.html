Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights

Rikiya Takehi, Jayden Teoh, Alex Zhang, Omar Khattab (MIT CSAIL) · published 2 November 2026

In one line: In one blog post with complete released logs, mostly single runs, GPT-6 Astra named what small networks (17K to 24K weights) were trained for from their raw weights with no tools, wrote MinAtar policies from all-zero weights that beat PPO at 100M steps in all three games (at 500M steps only in Breakout), and, with a Python kernel over Qwen3.5-0.8B's weights and 50 forward passes on practice problems, made a rank-one edit to 131,072 weights (0.016%) that cut thinking loops and raised MATH-500 from 7.9% to 48.1% in a looping-prone setting (thinking on, 32,768 tokens). The same procedure did not improve Gemma 3 270M, which rarely loops.

How far to trust it: Believe the small-network results as demonstrations: the logs are complete, and independent runs reproduced the game naming and the Breakout writing, with the caveat that reading leans on the input layer. Read the Qwen result as an agent doing interpretability with tools, not as reading weights: the prompt named repetition as a failure worth fixing, the direction came from activations measured in forward passes, the edit is directional steering written into one matrix at strength 6, and each budget is one run beside others that made no edit.
